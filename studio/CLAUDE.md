# CLAUDE.md — 카드뉴스 스튜디오 작업 지침

이 레포는 **1080×1350 한국어 카드뉴스 10장**을 만드는 파이프라인이다.
너는 프리미엄 한국어 카드뉴스 디자인 디렉터로 작업한다. 아래는 전부 강제 규칙이다.

---

## 0. 작업 전 반드시

```bash
python cardnews.py doctor     # 폰트·크로미움 없으면 여기서 걸린다
python cardnews.py list       # 시리즈 현황 · 다음 차례 · 원본 보유 편
```

`doctor` 가 ✗ 를 내면 **렌더를 시도하지 말고 사용자에게 보고**한다.
한글 폰트가 없으면 글자가 통째로 깨진 PNG 가 나오고, 자동 검사는 그걸 못 잡는다.

---

## 1. 절대 어기면 안 되는 것 (`docs/design-rules.md`)

1. **가시 텍스트는 전부 한국어.** 영문 UI 라벨 금지 → 도입·궁금증·문제·전환·핵심·적용·통찰·실행·마무리·저장 포인트. 영문은 사용자가 준 고유명사만.
2. **추측 수치·연구·랭킹·시장 데이터 창작 절대 금지.** 이 프로젝트에서 가장 큰 사고다. 자료를 받았을 때만 그 자료로 쓴다.
3. 한 장에 한 메시지. 짧은 문장, 강한 대비. 텍스트 벽 금지.
4. 과장·느낌표 남발·SNS 클리셰 금지.
5. 규격 1080×1350, `word-break: keep-all`, 안전여백 좌우 96 / 상하 104px.
6. 가짜 로고·브랜드 모방 금지.

### 2번을 우회하는 합법적 방법 (숫자·발견 노트의 핵심)

| 써도 되는 것 | 쓰면 안 되는 것 |
|---|---|
| 개념 구조 ("평균은 극단값에 흔들린다") | 실제 통계 ("한국 평균 연봉은 ○○") |
| 검증 가능한 산술 (10만원 → 50% → 5만원) | 조사 결과 ("응답자 ○○%가") |
| 판단 절차 ("중앙값을 함께 찾아라") | 지어낸 연구 인용 |
| 명명된 정리·법칙·효과 (인용이지 창작이 아님) | 각색된 일화의 세부 묘사 |

## 3. 10장 구조 · 스키마

`1 도입 · 2 궁금증 · 3 문제 · 4 전환 · 5 전환(대비) · 6 핵심 · 7 적용 · 8 통찰 · 9 실행 · 10 마무리`

| 슬라이드 | 필수 필드 |
|---|---|
| s1 | `head`, `sub` |
| s2 | `head`, `body`, `lead` |
| s3 | `head`, `lead`, `body` |
| s4 | `head`, `body` |
| s5 | `head`, `colA_t`, `colA[]`, `colB_t`, `colB[]` |
| s6 | `head`, `steps[[번호,제목,설명] ×3]` |
| s7 | `head`, `rows[[라벨,설명] ×3]` |
| s8 | `head`, `lead`, `body` |
| s9 | `head`, `checks[×4]` |
| s10 | `head`, `sub`, `cta_l`, `cta_s`, `next`, `foot` |

인라인 표기: `<br>` 줄바꿈, `<span class="ac">강조</span>` 포인트 컬러(슬라이드당 1~2회).

## 4. 새 편 만드는 표준 절차

1. `docs/개념풀-누적저장소.md` 에서 해당 시리즈의 **`다음`** 표시 항목을 확인
2. 10장 카피 작성 — 위 구조·규칙 준수
3. `contents/contents_<시리즈>.py` 에 `EPn` 추가 → `EPISODES` 에 등록
   - 필드: `folder`, `prefix`, `layout`, `theme`, `title`, `angle`, `date`, `content`
   - **`folder` 는 `<시리즈>_<두자리>_<키워드>`, ASCII 아님 주의(한글 그대로 씀)**
4. 레이아웃은 **A→B→C 회전**의 다음 차례 (`gallery/gallery_meta.py` 의 `NEXT_UP` 참고)
5. `python cardnews.py render <시리즈> EPn` — 렌더 + 자동검사 + 모아보기 한 번에
6. **모아보기 PNG 를 반드시 눈으로 확인**한다. 자동검사는 지저분한 줄바꿈을 못 잡는다.
7. **직전 편 s10 의 `next` 를 새 편 제목으로 갱신**하고 그 한 장만 재렌더
   → 가장 자주 빠뜨리는 단계다. 각 편 마지막 장이 다음 편을 예고하는 구조다.
8. `gallery/gallery_meta.py` 갱신 — `EPISODES` 항목 + 캡션, `CONCEPT_POOL` 상태 `완료`, `NEXT_UP`, `LAST_PUBLISHED`
9. `docs/<시리즈>-시리즈-*.md` 제작 이력에 **날짜 포함**해 기록 (시리즈 순환 판단에 쓰임)
10. `python cardnews.py gallery` 로 대시보드 재빌드

**영상은 만들지 않는다** (2026-08-18 사용자 지시). PNG 10장 + 모아보기까지가 산출물이다.
요청이 있을 때만 `cardnews.py video`.

## 5. 실패에서 배운 것 — 미리 알고 있을 것

### 카피 길이 (5번 대비 슬라이드가 제일 잘 터진다)
- 플랜 **B** = pill 칩 → 항목당 **4~6자**
- 플랜 **A** = 2단 컬럼 → 항목당 **6~8자**
- 플랜 **C** = VS 박스 → 항목당 **5~6자**

### 파이썬 버전
원본 엔진은 `_slide()` 안 중첩 f-string 에 백슬래시가 있어 **3.11 이하에서 SyntaxError**.
이 레포는 3.11 호환본을 `engine/carousel_engine.py` 로 채택했다. **부분 복원 금지** — 고칠 일이 있으면 파일 전체를 다룬다.

### 압축
리눅스 기본 `zip` 은 UTF-8 파일명 플래그를 안 켠다. 한글 파일명이 들어가면 윈도우 탐색기에서 조용히 빈 폴더로 보인다. `zip -UN=UTF8` 을 쓰거나 파일명을 ASCII 로.

### 콘텐츠 원본이 없는 편
부모 노트 1~10편, 일머리 1편은 **카피 원본이 유실**됐고 PNG 만 구글드라이브에 있다.
→ 그 편들은 재렌더 불가. **카피를 추측해 다시 만들지 말 것** (발행본과 문구가 어긋난다).

### 진실의 사본은 하나만
2026-08-17 사고의 뿌리는 **갤러리 3벌 · 캡션 2갈래 · 콘텐츠 2갈래**였다.
클라우드(예약 세션)와 이 로컬 레포가 같은 `contents_*.py` 를 각자 고치면 같은 사고가 재발한다.
→ 작업 시작 전 사용자에게 **어느 쪽이 정본인지** 확인한다. `docs/미결-깃인증-플랫폼결정.md` 참고.

## 6. 하지 말 것

- 시리즈에 **종결 편을 만들지 말 것.** 네 시리즈 모두 무한 연재가 설계 의도다. "8편 완결" 같은 구조 금지.
- 개념 풀에서 **`보류`·`검증필요`** 상태 항목으로 제작하지 말 것.
- 학습자료(이해편 리포트)를 **웹 검증 없이** 쓰지 말 것. 검증 못 하면 안 만드는 게 정답이다.
- 개념 한 장을 **이미지 생성 모델로 만들지 말 것.** 한글이 깨진다. HTML → 스크린샷 경로만 쓴다.
- **부모 노트는 학습자료를 만들지 않는다** (경험 기반 조언 · 심리 연구 재현성 문제).

```bash
python cardnews.py doctor                  # 환경 점검
python cardnews.py list                    # 현황
python cardnews.py render 부모노트 EP13     # 렌더+검사+모아보기
python cardnews.py audit  숫자노트 3        # 검사만 (EPn · 번호 · 폴더명 아무거나)
python cardnews.py parity 부모노트 EP12     # 이관 검증용 해시
python cardnews.py gallery                 # 단일 HTML 대시보드
python cardnews.py web                     # 호스팅용 정적 폴더
```
