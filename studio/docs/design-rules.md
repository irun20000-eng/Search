# 디자인 불변 규칙 (design-rules)

브랜드(테마)가 아무리 바뀌어도 **절대 바뀌지 않는** 품질 가드레일.
변주는 색·폰트·질감·여백 같은 '표면'에서만 일어나고, 아래는 고정한다.

## 규격
- 캔버스: **1080 × 1080 기준의 4:5 → 1080 × 1350px**
- 슬라이드 수: 10장 (도입 → 마무리)
- 안전 여백: 좌우 96px, 상하 104px 이상

## 언어
- 모든 가시 텍스트는 **한국어만**
- 영문은 사용자가 준 브랜드명·도구명·고유명사만 허용 (예: AI)
- 영문 UI 라벨 금지 (Slide / Hook / CTA / Tip 등 → 1장·도입·핵심·전환·실행·마무리·저장 포인트)

## 타이포
- 한글 줄바꿈은 `word-break: keep-all`, `line-break: strict` (단어 중간 끊김 금지)
- 본문 최소 38px, 헤드라인은 슬라이드당 1개 핵심
- 한 슬라이드 = 한 메시지 (텍스트 벽 금지)

## 가독성
- 본문 대비 4.5:1 이상, 큰 제목 3:1 이상 유지
- 포인트 컬러는 **슬라이드당 1~2회**만 (강조어·번호·라인)
- 장식 과잉 금지: 배경 질감은 항상 저채도·저투명

## 카피
- 추측성 수치·연구·랭킹·시장 데이터 **창작 금지** (자료가 있으면 그것만 사용)
- 짧은 문장, 명확한 리듬, 과장·느낌표 남발 금지

## 출력
- PNG로 바로 내보낼 수 있게 슬라이드별 프레임 분리
- 가짜 로고·브랜드 모방 금지
