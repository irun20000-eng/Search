# 콘텐츠 스키마 (Stage 4)

새 주제 = 이 JSON만 채우면 같은 라인(브랜드 × 레이아웃)으로 찍힌다.
카피(콘텐츠)와 디자인(브랜드·레이아웃)은 완전히 분리돼 있다.

## 최상위
| 키 | 타입 | 설명 |
|---|---|---|
| `series` | 문자열 | 하단에 표기되는 시리즈명 (예: "프리랜서 노트") |
| `s1`~`s10` | 객체 | 슬라이드 10장 |

## 인라인 표기 (모든 head/본문 공통)
- `<br>` … 줄바꿈
- `<span class="ac">강조어</span>` … 브랜드 포인트 컬러 강조 (슬라이드당 1~2회 권장)
- `kick`(키커)은 생략 가능 → 자동(도입/궁금증/문제/전환/전환/핵심/적용/통찰/실행/마무리)

## 슬라이드별 필드

| 슬라이드 | 기능 | 필수 필드 |
|---|---|---|
| `s1` | 커버 | `head`, `sub` |
| `s2` | 텍스트 | `head`, `body`, `lead` |
| `s3` | 텍스트 | `head`, `lead`, `body` |
| `s4` | 텍스트 | `head`, `body` |
| `s5` | 대비 | `head`, `colA_t`, `colA[]`, `colB_t`, `colB[]` |
| `s6` | 단계 | `head`, `steps[[번호,제목,설명], ...]` |
| `s7` | 적용/행 | `head`, `rows[[라벨,설명], ...]` |
| `s8` | 텍스트 | `head`, `lead`, `body` |
| `s9` | 체크리스트 | `head`, `checks[]` |
| `s10` | 마무리 | `head`, `sub`, `cta_l`, `cta_s`, `next`, `foot` |

- `colA/colB` … 짧은 단어 3~4개 (대비 항목)
- `steps` … 정확히 3개 권장, 각 `[번호, 제목, 설명]`
- `rows` … 3개 권장, 각 `[라벨, 설명]`
- `checks` … 4개 권장, 짧은 실행 문장

## 최소 예시(발췌)
```json
{
  "series": "프리랜서 노트",
  "s1": { "head": "깎아주는 순간<br><span class=\"ac\">나는 싸진다</span>", "sub": "단가를 낮추면 안 되는 이유" },
  "s5": { "head": "두 종류의 고객",
          "colA_t": "싼 고객", "colA": ["가격에 민감","요구 많음"],
          "colB_t": "제값 고객", "colB": ["가치에 반응","장기 거래"] },
  "s6": { "head": "제값 받는 3단계",
          "steps": [["01","기준 세우기","최저 단가를 먼저 정한다"]] }
}
```

## 라인에 투입
```python
import content_loader as CL
CL.render_deck("content.프리랜서단가.json", brand="newsletter_modern",
               layout="B", outdir="out", prefix="card")
```
- `load()`가 누락·빈값·잘못된 리스트 형식을 한국어로 잡아준다.
- `brand`/`layout`은 selector 규약과 동일(생략 시 auto).

## 카피 작성 규칙 (design-rules 준수)
한 장 한 메시지 · 짧은 문장 · 강한 대비 / 추측 수치·연구·랭킹 창작 금지 / 영문은 고유명사만.
