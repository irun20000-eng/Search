# OpenRouter API로 AI 활용하기 — 키 하나로 GPT·클로드·제미나이 다 쓰기

> 모델마다 계정 만들고 카드 등록하고 SDK 배우는 일을 그만두기 위한 가이드다. **키 하나, 주소 하나로** 여러 회사의 모델을 같은 코드로 부르는 방법을 처음부터 끝까지 따라간다. 약 45분.

## 이 가이드로 만들 것

**"모델 이름 한 줄만 바꾸면 GPT도, 클로드도, 제미나이도 같은 코드로 불리는"** 상태를 만든다.

```
지금                          이 가이드 후
────────────────────         ────────────────────
OpenAI 계정 + 카드            OpenRouter 계정 하나
Anthropic 계정 + 카드    →    키 하나
Google 계정 + 카드            model="..." 만 교체
각각 다른 SDK
```

이렇게 **하나의 API로 여러 생성형 AI 모델을 쓰는** 방식을 통합 API라고 부른다[6].

끝내면 다음을 할 수 있다.

- **돈 한 푼 안 쓰고** 무료 모델로 첫 호출을 성공시킨다
- 기존 OpenAI 코드를 **두 줄만 고쳐** OpenRouter로 옮긴다
- 모델을 갈아끼우며 품질과 비용을 비교한다
- 요금 한도와 요청 한도를 이해하고 사고를 예방한다

다루지 않는 것: 스트리밍 응답, 함수 호출(tool use), 이미지 입력, 프로덕션 배포. 기본기가 잡힌 뒤에 볼 것들이라 "다음으로 할 것"에 남겨 뒀다.

## 사전 준비물

| 항목 | 설명 |
|---|---|
| 이메일 계정 | OpenRouter 가입용 |
| 터미널 또는 파이썬 | 둘 중 하나만 있어도 된다 |
| 신용카드 | **필요 없다** — 무료 모델만 쓸 거면 |

**시작하는 데 돈이 들지 않는다.** OpenRouter에는 ID가 `:free`로 끝나는 무료 모델들이 있고, 이 모델들은 입력·출력 토큰 모두 $0이라 **잔액 0원, 카드 등록 없이** 쓸 수 있다[3][9]. 이 가이드는 전부 무료 모델로 진행한다.

> **다만 무료의 대가는 프라이버시다.** 대부분의 무료 엔드포인트는 받은 프롬프트를 **학습에 쓰거나 공개할 수 있고**, 그래서 무료 모델을 쓰려면 계정 설정에서 그 권한을 명시적으로 켜야 한다[12]. 회사 자료·개인정보·미공개 코드를 무료 모델에 넣지 마라. 그런 내용은 유료 모델을 쓰거나 다른 방법을 찾아야 한다. 2단계에서 설정을 켜기 전에 이 점을 먼저 판단할 것.

> **다만 무료 모델 목록은 계속 바뀐다**[9]. 이 문서에 특정 무료 모델 이름을 못 박아 두면 며칠 뒤 안 맞을 수 있으니, 2단계에서 **현재 살아 있는 무료 모델을 직접 찾는 방법**을 익힌다.

## 1단계 — 가입하고 API 키 발급받기

**할 일**
1. `openrouter.ai` 에 접속해 가입한다(구글 계정 등으로 간편 가입 가능).
2. 계정 메뉴에서 **Keys** 로 들어가 새 키를 만든다.
3. 만들어진 키를 복사해 **안전한 곳에 붙여 둔다.**

**화면에서 확인할 것**
`sk-or-v1-` 로 시작하는 긴 문자열이 나온다. **이 화면을 벗어나면 전체 값을 다시 볼 수 없는 경우가 많으니** 지금 복사해 둔다.

**막히면**
키를 못 봤거나 잃어버렸다면 되찾으려 하지 말고 **새로 만들고 옛 키는 삭제한다.** 키는 언제든 여러 개 만들 수 있고, 용도별로 나눠 두면 나중에 문제가 생겼을 때 하나만 폐기하면 된다.

> **키는 비밀번호다.** 이 키가 노출되면 **다른 사람이 내 계정으로, 내 비용으로** 모델을 쓴다[7]. 그래서 브라우저에서 돌아가는 프론트엔드 코드에는 절대 넣으면 안 된다[7]. 6단계에서 다시 다룬다.

## 2단계 — ★지금 쓸 수 있는 무료 모델 찾기★

**할 일**
1. 먼저 **Settings → Privacy** 로 가서 무료 엔드포인트 관련 데이터 정책을 **켠다**(학습 허용·프롬프트 공개 허용). **이걸 안 켜면 뒤에서 모든 무료 모델이 404로 실패한다**[12].
2. OpenRouter 사이트의 **Models** 페이지로 간다.
3. 가격 필터에서 무료(FREE)만 남긴다.
4. 모델 ID를 그대로 복사한다. `제공사/모델이름:free` 형태다.

> **왜 이 설정이 필요한가** — 무료 엔드포인트 대부분은 프롬프트를 학습에 쓰거나 공개할 수 있는 곳들이다. 그 권한을 꺼 두면 OpenRouter가 무료 요청을 보낼 곳이 하나도 남지 않아 **전부 404가 난다**[12]. 이건 오류가 아니라 내 설정이 만든 결과다. 넣을 내용이 민감하다면 설정을 켜는 대신 유료 모델을 쓰는 편이 맞다.

모델 ID는 **`제공사/모델이름`** 규칙을 따른다[2][5]. 예를 들면 이런 모양이다.

| 형태 | 의미 |
|---|---|
| `openai/gpt-4o` | OpenAI의 GPT-4o (유료) |
| `제공사/모델:free` | 같은 모델의 **무료 변형** — 입력·출력 토큰 $0[3] |

`:free` 접미사가 붙은 것이 무료 변형이고, 떼면 유료 가격이 적용된다[3].

**화면에서 확인할 것**
모델 카드에 **입력/출력 토큰당 가격이 $0** 으로 표시되는지 본다. 복사한 ID가 `:free`로 끝나는지도 함께 확인한다.

**막히면**
Privacy 설정을 켰는데도 안 되면, 제공사 허용/차단 목록이나 Zero Data Retention 같은 설정이 무료 엔드포인트를 전부 걸러내고 있을 수 있다[12].
어제 쓰던 무료 모델이 오늘 목록에 없을 수 있다. **어느 모델이 무료인지는 시간에 따라 바뀐다**[9]. 코드에 모델 이름을 하드코딩해 두면 어느 날 갑자기 실패하니, 설정값으로 빼 두는 습관을 들인다.

## 3단계 — 터미널에서 첫 호출 성공시키기

파이썬을 설치하기 전에 **가장 단순한 방법으로 먼저 성공**해 두는 편이 좋다. 여기서 성공하면 "키는 유효하다"가 확정되므로, 뒤에서 문제가 생겼을 때 원인 범위가 확 줄어든다.

**할 일**
아래를 터미널에 붙여넣는다. `여기에_내_키`와 `여기에_모델ID`만 바꾼다.

```bash
curl https://openrouter.ai/api/v1/chat/completions \
  -H "Authorization: Bearer 여기에_내_키" \
  -H "Content-Type: application/json" \
  -d '{
    "model": "여기에_모델ID",
    "messages": [{"role": "user", "content": "한 문장으로 자기소개 해줘"}]
  }'
```

주소는 `https://openrouter.ai/api/v1` 이고, 대화 요청은 그 아래 `/chat/completions` 로 간다[1].

**화면에서 확인할 것**
`choices` 안에 `message` 가 있고 그 안 `content` 에 한국어 답변이 들어 있으면 성공이다. JSON이 길어 보여도 볼 곳은 거기 하나다.

**막히면**
- `401` → 키가 틀렸다. `Bearer ` 뒤 공백 하나까지 확인한다.
- `400` → 모델 ID가 잘못됐다. Models 페이지에서 다시 복사한다.
- `404` → **모델 이름 문제가 아니다.** 보낼 수 있는 엔드포인트가 하나도 없다는 뜻이고, 무료 모델에서는 십중팔구 **2단계의 Privacy 설정**이 원인이다[12]. ID를 다시 복사해 봐야 소용없다.
- `402` → 잔액 문제다. 유료 모델을 골랐거나, **잔액이 마이너스면 무료 모델에서도 402가 난다**[3].
- `429` → 한도 초과다. 6단계에서 다룬다.

## 4단계 — ★파이썬에서 부르기 (기존 OpenAI 코드 재활용)★

여기가 OpenRouter의 진짜 값어치다. **새 SDK를 배울 필요가 없다.**

**할 일**
1. OpenAI 파이썬 패키지를 설치한다: `pip install openai`
2. 키를 환경변수에 넣는다: `export OPENROUTER_API_KEY="sk-or-v1-..."`
3. 아래를 실행한다.

> **윈도우 PowerShell**은 환경변수 설정이 다르다: `$env:OPENROUTER_API_KEY="sk-or-v1-..."`
> 3단계 `curl` 도 PowerShell에서는 작은따옴표 JSON이 통하지 않으니, 이 파이썬 방식으로 넘어오는 편이 빠르다.

```python
from openai import OpenAI
from os import getenv

client = OpenAI(
    base_url="https://openrouter.ai/api/v1",   # ← 바꾸는 곳 1
    api_key=getenv("OPENROUTER_API_KEY"),      # ← 바꾸는 곳 2
)

completion = client.chat.completions.create(
    model="여기에_모델ID",
    messages=[{"role": "user", "content": "한 문장으로 자기소개 해줘"}],
)

print(completion.choices[0].message.content)
```

**OpenAI를 부르던 기존 코드에서 주소(baseURL)와 키만 바꾸면, 클로드든 제미나이든 라마든 같은 코드로 부를 수 있다**[2][5]. 인터페이스가 OpenAI API와 호환되기 때문이다[8].

원한다면 선택적으로 헤더 두 개를 붙일 수 있다. **없어도 요청은 정상 작동한다**[2].

```python
completion = client.chat.completions.create(
    model="여기에_모델ID",
    extra_headers={
        "HTTP-Referer": "https://내사이트주소",  # 선택 — OpenRouter 순위 표기용
        "X-Title": "내 앱 이름",                  # 선택 (최신 문서는 X-OpenRouter-Title 표기)
    },
    messages=[{"role": "user", "content": "안녕"}],
)
print(completion.choices[0].message.content)
```

**화면에서 확인할 것**
터미널에 모델의 답변 문장이 한 줄 찍히면 성공이다. 3단계 curl과 **같은 답이 나올 필요는 없다** — 같은 모델이어도 매번 조금씩 달라진다.

**막히면**
환경변수가 안 들어갔을 때 **오류 메시지에는 `OPENAI_API_KEY` 가 없다고 뜬다.** OpenAI SDK가 그 이름으로 폴백하기 때문이며, 내가 설정한 이름과 달라 헷갈리기 쉽다. `echo $OPENROUTER_API_KEY`(윈도우 PowerShell은 `echo $env:OPENROUTER_API_KEY`)로 값부터 확인한다.
**더 고약한 경우** — 예전에 `OPENAI_API_KEY` 를 설정해 둔 적이 있다면 오류가 아예 안 나고 그 키가 OpenRouter로 전송돼 `401` 이 난다. 원인이 안 보이면 `api_key=` 에 값을 잠깐 직접 넣어 확인해 보라(확인 후 반드시 지울 것).

## 5단계 — 모델 갈아끼우며 비교하기

**할 일**
4단계 코드에서 **`model=` 한 줄만** 바꿔 가며 같은 질문을 던져 본다. 무료 모델 두세 개로 충분하다.

```python
from openai import OpenAI
from os import getenv

client = OpenAI(base_url="https://openrouter.ai/api/v1", api_key=getenv("OPENROUTER_API_KEY"))

for m in ["모델A:free", "모델B:free", "모델C:free"]:   # ← 2단계에서 복사한 실제 ID로 바꿀 것
    r = client.chat.completions.create(
        model=m,
        messages=[{"role": "user", "content": "초등학생에게 재귀함수를 설명해줘"}],
    )
    print(f"\n===== {m} =====\n{r.choices[0].message.content}")
```

**이게 OpenRouter를 쓰는 가장 큰 이유다.** 하나의 엔드포인트와 하나의 키로 여러 제공사의 수백 개 모델에 접근할 수 있으니[8], 모델 선택을 **추측이 아니라 비교로** 결정할 수 있다.

**화면에서 확인할 것**
모델마다 답변의 길이·말투·정확도가 눈에 띄게 다른지 본다. 내 용도에 어느 쪽이 맞는지는 벤치마크 점수보다 **내 질문으로 직접 비교한 결과**가 훨씬 믿을 만하다.

**막히면**
어떤 모델만 `400` 이 뜨면 그 모델이 목록에서 빠졌거나 ID가 바뀐 것이다. Models 페이지에서 현재 ID를 다시 확인한다. `404` 라면 ID가 아니라 **엔드포인트 라우팅 문제**이므로 2단계 Privacy 설정부터 본다[12].

## 6단계 — ★한도·비용·키 안전 챙기기★

여기를 건너뛰면 나중에 크게 당황한다.

**할 일**
1. 아래 한도를 먼저 이해한다.
2. 키를 코드에 직접 쓰지 않았는지 점검한다.
3. 필요하면 용도별로 키를 나눈다.

**무료 모델의 요청 한도** — 2026-08-08 확인[4]

| 구분 | 한도 |
|---|---|
| 분당 | **20회** — 크레딧을 사도 안 올라간다 |
| 하루 (충전 이력 없음) | **50회** |
| 하루 (누적 $10 이상 충전 경험) | **1,000회** |

여기서 중요한 건 **일일 한도의 조건이 "잔액"이 아니라 "충전 이력"**이라는 점이다. $10을 한 번 충전하면 이후 잔액이 줄어도 1,000회 한도는 유지된다[4]. 반대로 분당 20회는 돈으로 못 올린다[4].

> **실패한 호출도 한도를 깎는다**[4]. 한도는 토큰이 아니라 **요청 횟수** 기준이라, 키를 잘못 넣어 `401`을 스무 번 받으면 그 스무 번이 그대로 일일 한도에서 빠진다. 배우는 동안 `50회`는 생각보다 금방 사라지니, 오류가 나면 **코드를 고치기 전에 오류 코드부터 읽는** 습관이 실질적으로 한도를 아껴 준다.

**충전은 나중에 해도 되지만, 하기 전에 이건 알아야 한다.** 조사 과정에서 자료마다 설명이 엇갈려 이용약관·요금 페이지까지 확인했다[10][11].

| 항목 | 내용 (2026-08-08 확인) |
|---|---|
| 최소 충전액 | **$5** (1회 최대 $25,000)[10] |
| 수수료 | 카드 결제 시 **5.5%, 최소 $0.80**[11] |
| **$5만 충전하면** | 최소 수수료 $0.80이 걸려 **실효 약 16%**[11] |
| $100 충전하면 | $5.50, 즉 표기대로 5.5%[11] |
| 크레딧 만료 | **만료될 수 있다** — 약관상 구매 후 365일[10] |
| 환불 | 구매 후 **24시간 이내**만 가능[10] |

**소액으로 찔러 보는 게 수수료 면에서 가장 불리하다.** $5 충전은 수수료율이 16%까지 뛴다[11]. 그래서 이 가이드는 무료 모델로만 진행하고, 충전은 "무료 한도가 정말 답답해졌을 때" 한 번에 하는 편을 권한다.

> 요금·수수료·만료 정책은 **자주 바뀌고 자료마다 다르게 적혀 있었다.** 실제로 결제하기 전에 반드시 OpenRouter 공식 요금 페이지와 약관에서 직접 확인할 것.

**키 안전 수칙**

| 하지 말 것 | 대신 |
|---|---|
| 프론트엔드 코드에 키 넣기[7] | 서버(백엔드)에서만 호출 |
| 깃에 키 커밋하기 | 환경변수 + `.gitignore` |
| 모든 곳에 같은 키 쓰기 | 용도별로 발급, 문제 시 하나만 폐기 |

> **키를 여러 개 만들어도 한도는 안 늘어난다.** 위 요청 한도는 **계정 단위**다. 키 분리는 사고 시 피해를 줄이기 위한 것이지 한도를 늘리는 수단이 아니다.

**화면에서 확인할 것**
OpenRouter의 활동(Activity) 화면에서 내가 보낸 요청과 소모량이 기록되는지 본다. **모르는 사용량이 찍혀 있다면 키 유출을 의심하고 즉시 폐기**한다.

**막히면**
`429` 가 계속 뜨면 위 표에서 어느 한도에 걸렸는지부터 가른다. 몇 초 만에 다시 풀리면 분당 한도, 하루 종일 막히면 일일 한도다.

## 흔히 막히는 지점

**1. 키를 프론트엔드에 넣어 유출**
가장 비싸게 치르는 실수다. 브라우저로 내려간 코드는 누구나 열어 볼 수 있고, 키가 노출되면 남이 내 비용으로 모델을 쓴다[7]. 반드시 서버에서만 호출한다.

**2. `:free` 를 빼먹고 유료 모델 호출**
`모델이름` 과 `모델이름:free` 는 **다른 것**이다[3]. 접미사를 빠뜨리면 잔액이 없을 때 `402`가 나거나, 잔액이 있으면 조용히 과금된다.

**3. 무료 모델 이름을 코드에 하드코딩**
어느 모델이 무료인지는 시간에 따라 바뀐다[9]. 하드코딩해 두면 어느 날 갑자기 `404`로 죽는다. 설정 파일이나 환경변수로 뺀다.

**4. 분당 한도를 돈으로 풀 수 있다고 오해**
크레딧을 사도 **분당 20회는 그대로다**[4]. 반복문으로 빠르게 여러 번 호출하면 바로 `429`가 뜨니, 호출 사이에 간격을 두거나 재시도 로직을 넣는다.

**5. 오류 코드를 안 보고 코드부터 고침**
`401`(키)·`402`(잔액)·`400`(모델 ID)·`404`(보낼 엔드포인트 없음 — Privacy 설정[12])·`429`(한도)는 원인이 완전히 다르다[3][12]. 특히 **404를 모델 이름 오타로 착각하면 영원히 못 고친다.** **숫자부터 확인하면** 대부분 1분 안에 해결된다. 게다가 **실패한 요청도 일일 한도를 깎으므로**[4] 아무렇게나 재시도하는 것은 그 자체로 비용이다.

## 다음으로 할 것

1. **스트리밍 응답** — 답변을 한 번에 받지 말고 글자가 흘러나오게 한다. 체감 속도가 크게 달라진다.
2. **모델 라우팅** — 쉬운 요청은 싼 모델, 어려운 요청은 좋은 모델로 자동 분배한다. 이 갤러리의 [헤르메스 에이전트 편](https://youtu.be/a_1xAWM5yUI)에 나오는 모델 라우팅과 같은 발상이다.
3. **함수 호출(tool use)** — 모델이 내 함수를 직접 부르게 한다. 에이전트의 출발점이다.
4. **기존 도구에 붙이기** — OpenAI 호환이라 많은 도구가 base URL만 바꾸면 OpenRouter를 쓴다[2].
5. **유료 모델로 넘어가기** — 무료 모델의 한도가 답답해지면 그때 충전한다. 다만 **최소 $5·수수료 5.5%(최소 $0.80)**라 소액 충전이 불리하니[10][11], 6단계 표를 다시 보고 금액을 정할 것.
