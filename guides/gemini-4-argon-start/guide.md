# 제미나이 4 아르곤 활용하기 — 내 요금제로 어디서 쓰는지부터 첫 API 호출까지

> 구글이 2026년 9월 30일 발표하고 10월 13일 일반에 연 최상위 모델 「제미나이 4 아르곤(Gemini 4 Argon)」을 **실제로 써 보기 위한** 가이드다. 「내 요금제로 되나」를 먼저 가르고, 제미나이 앱에서 첫 작업을 맡긴 뒤, 개발자라면 AI 스튜디오와 API까지 간다. 약 50분.

## 이 가이드로 만들 것

아르곤은 **쓰는 곳이 여러 군데이고, 곳마다 필요한 요금제가 다르다.** 앱에서는 되는데 AI 스튜디오에서는 안 되는 일이 실제로 생긴다[14]. 그래서 이 가이드는 「어디서 열리는가」를 첫 단계로 둔다.

```
요금제를 확인한다 ──→ 앱에서 아르곤을 골라 첫 작업 ──→ (개발자) AI 스튜디오에서 시험
                                                     ──→ API로 호출 · 비용 계산
                                                     ──→ (Ultra) 안티그래비티에서 코딩
```

끝내면 다음을 할 수 있다.

- 내 계정에서 아르곤을 **어디서 쓸 수 있는지** 바로 판단한다
- 앱에서 아르곤을 직접 고르고 **사고 수준**을 맞춰 긴 작업을 맡긴다
- 파이썬으로 `gemini-4-argon` 을 호출하고, **빈 응답·400 오류**를 스스로 고친다
- 호출 한 번이 **얼마인지** 계산하고, 11월 30일 이후 요금 변화를 대비한다

다루지 않는 것: 사이버보안 전용 프로그램(페어윈드), 기업용 구글 클라우드 배포, 함수 호출·에이전트 설계. 입문 가이드라 「다음으로 할 것」에 남겼다.

## 사전 준비물

| 항목 | 설명 |
|---|---|
| 구글 계정 | 모든 경로의 출발점 |
| 앱으로 쓸 때 | 구글 AI Pro 또는 Ultra 구독 — 무료·Plus 요금제에는 아르곤이 없다[2][13] |
| API로 쓸 때 | 결제를 연결한 유료 API 프로젝트 — 무료 API 등급에는 아르곤이 없다[8][10] |
| 안티그래비티로 쓸 때 | 구글 AI Ultra 구독, 또는 제미나이 API 이용[7][18] |
| 파이썬 3 | 5단계에서만 필요하다 |

**「아르곤」은 무엇인가.** 구글이 「가장 까다로운 난제를 해결하도록 설계」했다고 소개한 제미나이 4 세대의 첫 모델이다[1]. 구글이 내세운 분야는 소프트웨어 엔지니어링, 법률·금융 같은 기업 지식 업무, 사이버보안 방어다[15]. 발표 직후에는 사이버 방어 조직을 위한 페어윈드 프로그램 참가자만 쓸 수 있었고[1], 10월 13일(미국 시간)에 구독자와 개발자에게 열렸다[2][8].

> **벤치마크는 구글이 낸 숫자다.** 경쟁 모델을 앞섰다는 수치는 구글 발표 자료에서 나왔고, 코딩 점수 일부는 구글 자체 시험 환경에서 잰 것이라는 지적이 있다[16]. 이 가이드는 성능 순위를 다루지 않고, **내 작업에 맞는지 직접 시험하는 방법**을 다룬다.

## 1단계 — 내 요금제로 어디서 쓸 수 있는지 확인하기

**할 일**
1. 내가 쓰는 구글 AI 요금제를 확인한다(구글 계정의 구독 메뉴 또는 제미나이 앱 설정).
2. 아래 표에서 내 줄을 찾는다.

| 요금제 | 제미나이 앱·검색 AI 모드 | AI 스튜디오 | 안티그래비티 | API |
|---|---|---|---|---|
| 무료 | 안 됨 | 안 됨 | 안 됨 | 무료 등급 키로는 안 됨 |
| AI Plus | 안 됨 | 안 됨 | 안 됨 | 별도 |
| AI Pro | **됨** | 유료 API 키가 있어야 | 안 됨 | 별도 |
| AI Ultra | **됨** | **됨** | **됨** | 별도 |
| 유료 API(구독 무관) | 별도 | 유료 키로 됨 | API 이용자 대상 순차 제공[7] | **됨** |

근거: 구글은 10월 13일 Pro·Ultra 구독자에게 제미나이 앱과 검색 AI 모드를 열었고, 무료·Plus는 대상이 아니었다[2][9]. 안티그래비티와 AI 스튜디오는 Ultra 구독자에게 열렸다[7][18]. 구글 코리아 블로그는 안티그래비티 제공 대상에 적격 제미나이 엔터프라이즈 구독자와 제미나이 API 이용자도 적었다[7]. Pro 구독자는 AI 스튜디오에서 유료 API 키가 따로 있어야 한다[14]. API는 유료 등급 고객에게 열렸고, 구글 가격표는 무료 등급과 AI Pro 요금제에서는 쓸 수 없다고 적는다[8][22].

**화면에서 확인할 것**
구독 화면에 **「AI Pro」 또는 「AI Ultra」** 가 보이면 2단계로 간다. 국내 요금은 블로그 정리 기준으로 AI Pro가 월 29,000원이다[17] — 결제 전에는 구글 공식 요금제 페이지에서 다시 확인한다.

**막히면**
「API 요금은 구독에 포함된다」고 생각하기 쉽다. **아니다.** 구독료와 API 토큰 요금은 따로 계산된다[21]. Ultra 구독자도 내 프로그램에서 API로 부르려면 결제가 연결된 API 프로젝트가 필요하다.

> **두 숫자를 헷갈리지 말 것** — 앱 쪽 사용 한도는 「하루 몇 번」 같은 고정 횟수가 아니라 연산량 기준이고, 구글은 아르곤만의 Pro·Ultra 한도를 따로 공개하지 않았다[10]. 예전 모델 시절의 「Pro 하루 100회」 같은 숫자를 아르곤에 그대로 옮기면 안 된다[10].

## 2단계 — 제미나이 앱에서 아르곤을 고르고 사고 수준 정하기

**할 일**
1. 제미나이 앱(웹 또는 모바일)을 최신 버전으로 열고 새 대화를 시작한다.
2. 입력창 근처의 **모델 선택 메뉴**를 연다.
3. **아르곤**을 직접 고른다. 자동 선택에 맡기지 않는다 — 자동 선택이 오가는 범위는 Flash-Lite·Flash·Pro 쪽이라는 정리가 있다[10].
4. 같은 메뉴에서 **사고 수준**을 고른다. 처음에는 중간(medium)으로 둔다.

**사고 수준이란.** 아르곤은 답하기 전에 얼마나 오래 「생각」할지를 낮음·중간·높음 세 단계로 정한다. 기본값은 중간이다[3][5]. 높을수록 어려운 문제에 강해지지만 느려지고, API에서는 그만큼 비용이 든다(6단계).

| 사고 수준 | 맞는 일 |
|---|---|
| 낮음(low) | 요약·번역·형식 바꾸기처럼 답이 분명한 일 |
| 중간(medium, 기본) | 대부분의 업무 — 여기서 시작한다 |
| 높음(high) | 여러 단계로 따져야 하는 분석, 긴 코드, 증명 |

**화면에서 확인할 것**
대화창 위나 입력창 옆의 모델 표시가 **아르곤**으로 바뀌어 있다. 메뉴 이름과 위치는 앱 버전에 따라 다를 수 있으니 「모델을 고르는 곳」을 기준으로 찾는다.

**막히면**
Pro 구독인데 메뉴에 아르곤이 없다면 **아직 내 계정에 롤아웃이 오지 않은 것**일 수 있다. 롤아웃은 단계적이고[2], 구글 원 요금제 페이지에는 「일부 국가의 Pro에 순차 적용 중」이라고 적혀 있다는 보고도 있다[10]. 앱을 업데이트하고 하루 이틀 뒤 다시 본다. 무료·Plus 계정이라면 기다려도 나오지 않는다(1단계 표).

## 3단계 — 아르곤에 맞는 첫 작업 맡기기

**할 일**
1. 「짧은 질문」 대신 **길고 여러 단계인 일**을 하나 고른다. 예: 계약서 초안 검토, 보고서 여러 개를 비교해 한 장으로 정리, 오래된 코드의 구조 설명.
2. 아래 틀로 프롬프트를 쓴다. 목표·맥락·제약·검증 기준을 나눠 적는 방식이다[12].

```
[목표] 첨부한 계약서 3건에서 해지 조건이 서로 다른 부분을 찾아 표로 정리해 줘.
[맥락] 우리 회사는 공급받는 쪽이다. 법률 자문 전 단계의 사전 검토다.
[제약] 계약서에 없는 내용은 추측하지 말고 「계약서에 없음」이라고 적어.
[검증] 표의 각 칸마다 해당 조항 번호를 붙여.
```

3. 자료가 길면 **자료를 먼저 붙이고 질문은 맨 끝에** 쓴다. 긴 문서 묶음에서 권하는 배치다[12].
4. 결과가 마음에 안 들면 사고 수준을 **높음**으로 올려 같은 프롬프트를 다시 보낸다. 「더 깊이 생각해」라고 글로 쓰는 것은 사고 수준 설정을 바꾸지 않는다[3].

**화면에서 확인할 것**
답변에 **「생각하는 중」 같은 표시**가 잠시 보인 뒤 결과가 나온다. 표의 칸마다 조항 번호가 붙어 있는지 — 검증 기준을 지켰는지 — 를 눈으로 확인한다.

**막히면**
답이 중간에 끊기거나 너무 일찍 마무리되면, 프롬프트 끝에 **「항목을 빠뜨리지 말고 끝까지 작성해」** 처럼 분량을 분명히 적는다. 아르곤이 일찍 마무리하는 경향이 있어 테스터들이 시스템 프롬프트에 출력 분량을 따로 알려 줘야 했다는 보고가 있다[11].

> **아르곤이 아닌 것도 쓴다.** 간단한 질문까지 아르곤에 보내면 느리고 한도도 빨리 닳는다. 짧은 일은 Flash 계열에, 길고 어려운 일만 아르곤에 — 이 구분이 절약의 기본이다.

## 4단계 — (개발자) AI 스튜디오에서 시험하기

**할 일**
1. `aistudio.google.com` 에 들어간다.
2. Ultra 구독자가 아니라면 먼저 **결제를 연결한 유료 프로젝트**를 만든다. AI 스튜디오의 API 키·프로젝트 화면에서 무료 프로젝트를 찾아 결제를 설정하고, 최소 금액(영문 문서 기준 10달러, 정확한 금액은 결제 화면에 표시)을 미리 충전한다[6].
3. 모델 목록에서 `gemini-4-argon` 을 고른다[3].
4. 오른쪽 설정에서 사고 수준과 **최대 출력 토큰**을 확인한다.
5. 3단계에서 쓴 프롬프트를 그대로 넣어 앱 결과와 비교한다.

**최대 출력 토큰은 넉넉하게.** 아르곤은 사고와 답변이 **같은 출력 한도를 나눠 쓴다.** 구글 문서는 최소 32,768을 권하고, 한 번의 요청이 기본으로 만들 수 있는 출력은 SDK·스트리밍 기준 65,536토큰이다(직접 HTTP 비스트리밍 요청은 32,768)[3][4][5].

**화면에서 확인할 것**
모델 이름 칸에 **`gemini-4-argon`** 이 보이고, 실행하면 응답 아래에 입력·출력 토큰 수가 표시된다. 이 숫자를 6단계 비용 계산에 쓴다.

**막히면**
Pro 구독자가 AI 스튜디오에서 아르곤을 못 고르는 것은 **오류가 아니라 요금제 구분**이다[14]. 결제를 연결한 유료 API 키로 들어가거나, 앱(2단계)에서 쓴다. 결제를 연결했는데도 무료 등급으로 남는다는 개발자 포럼 보고가 있으니[6], 결제 화면에서 프로젝트 등급을 한 번 더 본다.

## 5단계 — (개발자) 파이썬으로 API 호출하기

**할 일**
1. 터미널에서 구글 공식 SDK를 설치한다.

```bash
pip install -U google-genai
```

2. 4단계의 유료 프로젝트에서 API 키를 만들고 환경변수로 둔다(코드에 직접 적지 않는다).

```bash
export GEMINI_API_KEY="여기에_키"
```

3. 아래 코드를 `argon.py` 로 저장해 실행한다. 모델 ID와 설정 방식은 구글 문서의 예시를 따랐다[3].

```python
from google import genai
from google.genai import types

client = genai.Client()  # GEMINI_API_KEY 환경변수를 읽는다

resp = client.models.generate_content(
    model="gemini-4-argon",
    contents="오래된 C 함수 하나를 러스트로 옮길 때 주의할 점을 다섯 개로 정리해 줘.",
    config=types.GenerateContentConfig(
        max_output_tokens=65536,
        thinking_config=types.ThinkingConfig(thinking_level="medium"),
    ),
)
print(resp.text)
print(resp.usage_metadata)  # 토큰 사용량 — 6단계에서 쓴다
```

**예전 코드에서 지울 것.** 다른 제미나이 모델에서 쓰던 설정 가운데 아르곤에서 **효과가 없거나 오류가 나는 것**이 있다[3][5][11].

| 설정 | 아르곤에서 | 할 일 |
|---|---|---|
| `temperature` · `top_p` · `top_k` | 무시된다(경고 반환) | 지운다 |
| `thinking_budget` | 문서에 따라 경고 또는 400 오류 | `thinking_level` 로 바꾼다 |
| `thinking_level="minimal"` | 400 오류 | low·medium·high 중에서 고른다 |
| 명시적 캐시(`caches.create`) | 지원 안 됨, 오류 | 지운다 — 암묵적 캐시는 기본으로 켜져 있다 |

**화면에서 확인할 것**
터미널에 **답변 다섯 줄**이 나오고, 그 아래 `usage_metadata` 에 입력·출력(사고 포함) 토큰 수가 찍힌다.

**막히면**
오류 숫자부터 본다. **400**이면 위 표의 설정이 남아 있는지, **402**면 선불 잔액이 0인지(6단계), 접근 오류(429 등)면 키가 유료 등급 프로젝트의 것인지(4단계), **응답이 빈 문자열**이면 출력 한도를 사고가 다 써 버린 것이다 — 구글 문서는 이때 `max_output_tokens` 를 올리거나 사고 수준을 낮추라고 안내한다[4]. 오래 걸리는 요청은 HTTP 타임아웃을 15분 이상으로 잡거나 백그라운드 실행을 쓰라고 권한다[3].

> **아주 긴 출력이 필요하면** — 65,536토큰을 넘는 출력은 「긴 디코드(long decode)」 기능으로, 입력과 출력을 합쳐 약 100만 토큰 범위 안에서 만들 수 있다[4]. 다만 9월 발표의 「출력 100만 토큰」[8]을 기본 설정으로 그만큼 나온다고 읽으면 안 된다. 기본 한 번의 요청은 65,536토큰이고, 그 이상은 백그라운드 실행 같은 별도 설정이 필요하다[3][4]. 입문 단계에서는 쓰지 않아도 된다.

## 6단계 — 호출 한 번이 얼마인지 계산하고 관리하기

**할 일**
1. 요금표를 확인한다. API 도입가는 100만 토큰당 **입력 2달러·출력 10달러**이고, 도입가는 **2026년 11월 30일**까지다. 그 뒤에는 **입력 4달러·출력 20달러**가 된다[8][13].
2. 5단계의 `usage_metadata` 숫자로 아래처럼 계산한다.
3. 결제 화면에서 **예산 알림**을 걸어 둔다.

**풀어 보기 — 보고서 비교 한 번의 비용(계산).** 보고서 몇 개를 붙여 입력이 2만 토큰, 사고를 포함한 출력이 1만 토큰이었다고 하자. **사고 토큰도 출력으로 청구된다** — 가격표의 출력 단가에 「사고 포함」이 붙어 있다[20][22].

| 구분 | 도입가(~11/30) | 정가(12월~) |
|---|---|---|
| 입력 2만 토큰 | 0.02 × 2 = 0.04달러 | 0.02 × 4 = 0.08달러 |
| 출력 1만 토큰 | 0.01 × 10 = 0.10달러 | 0.01 × 20 = 0.20달러 |
| **한 번** | **0.14달러** | **0.28달러** |
| 하루 100번 | 14달러 | 28달러 |

같은 작업이 12월부터 **두 배**가 된다. 출력 쪽이 비용의 대부분(0.10 ÷ 0.14 ≈ 71%)을 차지하니, 아낄 곳은 입력보다 **사고 수준과 출력 분량**이다.

**비용을 줄이는 세 가지**
- **사고 수준을 일에 맞춘다** — 요약·번역은 low로 충분하다(2단계 표).
- **같은 앞부분을 재사용한다** — 아르곤은 명시적 캐시를 지원하지 않지만, 같은 긴 앞부분(시스템 지시·문서)을 반복해 보내면 암묵적 캐시가 적용될 수 있다[3]. 캐시된 입력은 입력 단가의 95%가 할인된다[20][22].
- **필요 없는 일은 아르곤에 보내지 않는다** — 3단계의 「아르곤이 아닌 것도 쓴다」.

**화면에서 확인할 것**
결제 콘솔에 **오늘 쓴 금액**이 보이고, 계산한 값과 크게 다르지 않다. 크게 다르면 사고 토큰이 예상보다 많은 것이다.

**막히면**
잔액이 바닥나면 요청이 멈춘다. 유료 등급 상태는 고정이 아니어서, **선불 잔액이 남아 있을 때만** API가 요청을 처리하고, 잔액이 0이 되면 연결된 키의 요청이 HTTP 402로 실패한다[6]. 예산 알림을 걸어 두고, 반복문으로 대량 호출하기 전에 10번만 먼저 돌려 비용을 재 본다.

## 7단계 — (Ultra) 안티그래비티에서 코딩 에이전트로 쓰기

**할 일**
1. 구글 AI Ultra 계정(또는 제공 대상인 API·엔터프라이즈 계정)으로 안티그래비티 데스크톱 앱 또는 CLI를 연다. 아르곤은 두 곳 모두에서 순차 제공된다[7].
2. 모델 선택에서 아르곤을 고른다.
3. 작은 프로젝트로 시작한다 — 「이 폴더의 코드 구조를 설명하고 테스트가 없는 함수를 찾아 줘」처럼 **읽기부터** 맡긴다.
4. 결과가 믿을 만하면 「찾은 함수 하나에 테스트를 써 줘」처럼 쓰기 작업으로 넘어간다.

안티그래비티는 구글이 만든 에이전트 코딩 도구다. 구글은 사내판 안티그래비티에서 약 4주 동안 시험한 결과 에이전트 기반 코드의 비율이 35% 늘고, 배포 뒤 되돌림(롤백) 비율이 30% 줄었다고 밝혔다[7][19]. **구글 내부에서 잰 수치**이니, 내 프로젝트에서는 작은 작업으로 직접 재 본다.

**화면에서 확인할 것**
에이전트 화면의 모델 표시가 **아르곤**이고, 에이전트가 파일을 읽은 기록과 계획이 먼저 나온 뒤 변경 제안이 나온다.

**막히면**
구독으로는 Ultra에서만 열린다(1단계 표). 구글 코리아 블로그는 적격 제미나이 엔터프라이즈 구독자와 제미나이 API 이용자도 제공 대상으로 적었다[7]. Pro 구독자라면 같은 코딩 작업을 제미나이 앱(2단계)이나 유료 API(5단계)로 대신한다.

## 흔히 막히는 지점

**1. 「Pro면 다 된다」고 생각한다**
Pro는 앱과 검색 AI 모드까지다. AI 스튜디오는 유료 API 키, 안티그래비티는 Ultra가 따로 필요하다[2][7][14]. 막히면 기능 고장을 의심하기 전에 1단계 표부터 다시 본다.

**2. 구독료에 API 요금이 들어 있다고 오해한다**
구독과 API 토큰 요금은 별개다[21]. 내 프로그램에서 부르는 순간부터는 6단계의 요금표가 적용된다.

**3. 빈 응답을 모델 고장으로 착각한다**
사고와 답변은 같은 출력 한도를 나눠 쓴다. 한도가 작으면 사고만 하다 끝나 답이 비어 나온다[3][4]. `max_output_tokens` 를 32,768 이상으로 두거나 사고 수준을 낮춘다.

**4. 예전 모델의 설정을 그대로 가져온다**
`temperature`·`top_p`·`top_k` 는 효과 없이 경고만 돌려주고, `thinking_budget` 은 문서에 따라 경고 또는 400 오류, `minimal` 은 오류가 나며, 명시적 캐시는 오류를 낸다[3][5][11]. 경고는 오류처럼 멈추지 않으니 로그에서 놓치기 쉽다.

**5. 12월 요금을 잊는다**
도입가는 11월 30일에 끝나고 같은 호출이 두 배가 된다[8]. 지금 비용을 재면서 **정가 기준으로도** 한 번 계산해 둔다(6단계 표).

## 다음으로 할 것

1. **비교 시험** — 같은 프롬프트 다섯 개를 아르곤과 평소 쓰던 모델에 보내 결과를 나란히 놓는다. 벤치마크가 아니라 **내 일**에서의 차이를 본다.

5. **안티그래비티 깊이 쓰기** — 7단계에서 읽기 작업이 믿을 만해지면 테스트 작성·리팩터링으로 범위를 넓힌다.
