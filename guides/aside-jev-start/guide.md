# Aside와 Jev 시작하기

> 이 가이드는 **Aside 를 설치해 첫 작업을 시켜 보고, Jev 로 첫 판정을 받아 보기까지**를 따라가게 만든 것이다. 약 60분. 둘은 서로 다른 제품이라 **따로 배우고 마지막에 붙인다.**

## 이 가이드로 만들 것

두 가지를 각각 **한 번씩 끝까지** 돌려 본다.

```
[1~4단계]  Aside     내려받기 → 데이터 옮기기 → 첫 작업 → 메모리 확인
[5~6단계]  Jev       플레이그라운드 판정 → 파이썬에서 경계 긋기
```

**왜 이 순서인가.** Aside 는 설치하면 바로 체감되지만 Jev 는 코드를 붙여야 체감된다. 먼저 눈으로 보고 나중에 손으로 만지는 편이 덜 지친다.

## 먼저 알아 둘 것 — 둘은 한 제품이 아니다

단톡방에서 한 묶음으로 도는 경우가 많은데 **만든 곳도 하는 일도 다르다.**

| 이름 | 정체 | 만든 곳 |
|---|---|---|
| Aside | 연동 없이 로그인된 사이트를 직접 조작하는 에이전트 브라우저 [1] | At Your Side, 샌프란시스코 [5] |
| Jev | 글 대신 타입과 확률을 돌려주는 판단 모델 [2] | TypeSafe AI [2] |

둘을 잇는 어댑터는 깃허브에 커뮤니티가 올린 것이고 **공식 통합이 아니다** [7]. 그러니 이 가이드도 따로 다룬다.

## 사전 준비물

| 항목 | 값 | 확인 방법 |
|---|---|---|
| 운영체제 | macOS 15.0 이상 또는 윈도우 [3] | 맥은 설정에서 정보, 윈도우는 설정에서 시스템 정보 |
| 계정 | 이메일 계정 하나 | Aside 가입에 쓴다 |
| 기존 브라우저 | 크롬·사파리·엣지 중 하나 | 데이터를 옮겨 올 원본 |
| 파이썬 | 3.10 이상 [4] | 터미널에서 python3 버전 확인 |
| 시간 | 약 60분 | 임포트 대기 시간이 길 수 있다 |
| 비용 | 0원으로 시작 가능 | Aside 무료는 월 500 크레딧 [6] |

⚠️ **미리 정해 둘 것이 하나 있다.** Aside 는 로그인된 사이트를 대신 조작한다. **오늘은 읽기와 수집까지만 맡기고 결제·발송·게시는 시키지 않는다**고 미리 정해 두자. 이유는 마지막 절에서 설명한다.

## 1단계. Aside 내려받아 설치하기

공식 다운로드 페이지에서 내려받는다 [3]. 겉보기에는 크롬과 거의 같은 브라우저가 깔린다. 크로미엄으로 만들었기 때문이다 [5].

설치가 끝나면 **열고 계정을 만들거나 로그인한다** [3]. 온보딩은 세 덩어리로 되어 있다.

```
  설치 완료  →  [1] 기본 설정  →  [2] 브라우저 데이터 임포트  →  [3] 첫 작업
```

지금은 첫 번째 덩어리만 끝내고 다음 단계로 간다.

**화면에서 확인할 것**: 브라우저가 열리고 주소창 옆이나 사이드에 **에이전트에게 말을 거는 입력칸**이 보인다. 이게 안 보이면 설치가 아니라 로그인이 안 끝난 것이다.

**막히면**: 맥에서 "확인되지 않은 개발자" 경고가 뜨면 시스템 설정의 개인정보 보호 및 보안에서 한 번 허용해 준다. 윈도우 안정판은 2026년 9월 14일에 나왔으니 [3], 그 전에 받아 둔 설치 파일이 있다면 버리고 새로 받는다.

## 2단계. 브라우저 데이터와 비밀번호 옮기기

여기가 Aside 를 쓸 만하게 만드는 단계다. **에이전트는 내가 로그인해 둔 상태를 그대로 쓰기 때문에**, 데이터를 안 옮기면 할 수 있는 일이 거의 없다 [1].

온보딩의 임포트 화면에서 순서대로 한다 [3].

```
  1. 임포트 시작
  2. 원본 프로필 고르기        (크롬 프로필이 여러 개면 쓰던 것)
  3. 시스템 권한 허용
  4. 완료될 때까지 기다리기     ← 여기서 몇 분 걸린다
```

비밀번호와 패스키는 기존 비밀번호 관리자에서 **한 번에 가져올 수 있다** [3]. 사파리를 쓰고 있었다면 사파리에서 내보낸 ZIP 파일을 쓰는 경로가 따로 있다 [8].

**화면에서 확인할 것**: 임포트가 끝난 뒤 즐겨찾기와 열린 탭이 예전 브라우저와 같아 보이고, **평소 쓰던 사이트에 다시 로그인하지 않아도 들어가진다**.

**막히면**: 임포트가 0퍼센트에서 멈춘 것처럼 보이면 대개 시스템 권한을 아직 안 준 것이다. 맥은 전체 디스크 접근 권한을 요구할 수 있다. 권한을 준 뒤에는 **Aside 를 완전히 껐다 켜야** 반영된다.

## 3단계. 첫 작업 시켜 보기 — 읽기부터

이제 에이전트에게 일을 시킨다. **첫 작업은 반드시 읽기·수집으로 잡는다.** 결제나 발송을 첫 작업으로 시키면 무엇이 잘못됐는지 알기 전에 결과가 나가 버린다.

이런 식으로 시킨다.

```
  "내 메일함에서 이번 주에 온 것 중 답장이 필요한 것만 골라서
   보낸 사람과 한 줄 요약으로 표를 만들어 줘."
```

Aside 가 다른 도구와 갈리는 지점이 여기서 보인다. **연동을 붙이지 않고 내가 로그인해 둔 사이트를 직접 연다** [1]. 그래서 API 가 없는 사내 시스템에서도 같은 방식이 통한다.

**화면에서 확인할 것**: 에이전트가 **탭을 스스로 열고 스크롤하는 모습**이 보이고, 마지막에 요청한 형태의 결과가 나온다. 탭이 안 움직이고 텍스트 답만 나오면 그건 그냥 챗봇으로 쓴 것이다.

**막히면**: 작업이 중간에 멈추면 요청이 너무 크게 잡힌 것이다. "메일함 전체 정리" 대신 "이번 주", "읽지 않은 것"처럼 범위를 좁혀 다시 시킨다. 무료 요금제는 월 500 크레딧이라 큰 작업을 반복하면 금방 닳는다 [6].

## 4단계. 메모리가 쌓이는지 확인하기

Aside 는 **브라우징 히스토리를 메모리로 바꿔** 매번 맥락을 다시 설명하지 않게 한다 [1]. 작업이 끝날 때마다 중요했던 사람·회사·결정을 뽑아내는 과정을 **Dreaming** 이라고 부른다 [6].

중요한 것은 **이 메모리를 사람이 읽고 고칠 수 있다**는 점이다. 편집 가능한 로컬 마크다운으로 저장되고 기기에 남는다 [6].

3단계를 한 번 돌린 뒤 **같은 종류의 작업을 다시 시켜 본다.** 두 번째에는 설명이 짧아도 알아듣는지가 관전 포인트다.

**화면에서 확인할 것**: 설정이나 메모리 화면에서 **방금 작업에서 뽑아낸 항목들**이 목록으로 보인다. 틀린 것이 있으면 그 자리에서 고칠 수 있다.

**막히면**: 메모리에 아무것도 없으면 3단계 작업이 끝까지 완주되지 않은 것이다. 중간에 멈춘 작업은 재료를 남기지 않는다. 범위를 더 좁혀 한 번 완주시키고 다시 본다.

## 5단계. Jev 플레이그라운드에서 판정 한 번 받아 보기

여기서부터는 Aside 와 상관없는 별개 제품이다. **Jev 는 글을 쓰지 않는다.** 상태를 받아 **타입이 정해진 값과 확률**을 돌려준다 [2].

물을 수 있는 것은 세 가지뿐이다 [2].

| 이름 | 묻는 것 | 돌려주는 것 |
|---|---|---|
| Noul | 예 또는 아니오 | 값 하나. 그 값이 곧 확신도이고 0.5 는 미정 |
| Choice | 여러 선택지 중 하나 | 선택지별 확률과 전체 확신도. 선택지는 최대 255개 |
| Score | 순서 있는 등급 | 연속 점수와 분포와 확신도 |

플레이그라운드를 열어 로그인하고 **아무 텍스트나 상태로 붙여 넣는다** [4]. 실제 업무 텍스트를 쓰는 편이 감이 온다. 그리고 Noul 로 이렇게 묻는다.

```
  상태 : (고객 문의 메일 본문을 그대로 붙여 넣는다)
  질문 : "이 문의는 환불 요청인가?"
```

**화면에서 확인할 것**: 문장이 아니라 **0과 1 사이의 숫자 하나**가 나온다. 0.93 이면 환불 요청 쪽으로 강하게 기운 것이고, 0.52 면 모델이 헷갈린다는 뜻이다.

**막히면**: 답이 계속 0.5 근처에서만 나오면 질문이 애매한 것이다. "이 문의는 중요한가" 같은 주관적 질문 대신 "이 문의는 환불이라는 단어나 그에 준하는 요구를 담고 있는가"처럼 **판정 기준을 질문 안에 넣는다.**

## 6단계. 파이썬에서 Jev 호출해 자동과 보류의 경계 긋기

마지막이자 실무에서 가장 값이 나오는 단계다. 확률이 숫자로 오기 때문에 **자동 처리와 사람 확인의 경계를 코드로 그을 수 있다.**

준비는 두 줄이다 [4].

```
pip install typesafe-sdk
export TYPESAFE_API_KEY=발급받은키
```

파이썬에서는 클라이언트를 열고 상태와 질문을 넘긴다. 기본 모델은 jev-latest 다 [4]. 그리고 받은 숫자로 이렇게 가른다.

```
  답 = (Noul 판정 결과)

  if 답 > 0.9:      자동으로 환불 절차
  elif 답 < 0.1:    자동으로 일반 문의
  else:             사람에게 넘긴다        ← 애매한 것이 여기 모인다
```

**이 세 줄이 핵심이다.** 기존 분류에서는 어느 건이 애매했는지 사후에도 알기 어려웠는데, 여기서는 가운데 구간이 몇 퍼센트인지 세어 볼 수 있다.

**화면에서 확인할 것**: 터미널에 **파싱 오류 없이 숫자가 바로 찍힌다**. Jev 는 텍스트를 만든 뒤 파싱하는 것이 아니라 샘플링 단계에서 값과 확률을 직접 돌려주기 때문이다 [9].

**막히면**: 인증 오류가 나면 키를 환경변수에 넣고 터미널을 새로 열지 않은 경우가 대부분이다. 파이썬이 3.10 미만이면 설치 자체가 막히니 버전부터 확인한다 [4].

## 흔히 막히는 지점

**1. Aside 를 챗봇으로 쓰고 "별거 없네" 하고 닫는다.**
질문만 하면 그냥 대화형 AI 다. **탭을 열어 조작하게 시켜야** 차이가 난다. 국내 소개 영상 제작자도 처음에는 "코딩 에이전트의 하위호환 아니냐"는 부정적인 글을 올렸다가 다음 날 생각을 바꿨다고 밝힌다 [10]. 첫인상으로 판단하기 쉬운 도구다.

**2. Jev 를 챗GPT 대신 쓰려고 한다.**
안 된다. 국내 정리글이 못을 박는다. "JEV 를 챗GPT처럼 대화나 글쓰기 용도로 대신 사용할 수 있나요? 아니요, 대체하기 어렵습니다" [11]. Jev 는 **경계가 정해진 판정** 전용이고 생성은 LLM 의 몫이다 [9].

**3. Jev 판정을 유일한 관문으로 세운다.**
가장 위험한 실수다. **Jev 의 판단은 프롬프트 인젝션으로 움직일 수 있다** [12]. 심지어 **선택지의 순서만 바꿔도 답이 달라질 수 있다**고 파이단틱 공식 문서가 적는다 [12]. 그래서 권고가 분명하다. Jev 로 만든 가드는 결정론적 검사를 **대체**하는 것이 아니라 **곁에** 두는 것이다 [12].

**4. Aside 의 확인 단추를 습관적으로 누른다.**
Aside 는 결제나 게시나 메시지 같은 민감한 작업에서 **사용자 확인을 기다리도록** 설계돼 있다 [1]. 이 설계는 옳지만, 확인 단추를 보지 않고 누르기 시작하면 무력해진다. 그래서 이 가이드는 첫 작업을 읽기로 잡으라고 한 것이다.

**5. 벤더가 낸 성능 숫자를 그대로 기대치로 잡는다.**
"193배 빠르고 445배 저렴"이라는 보도가 있지만 [13], 같은 모델을 이미 싸고 빠른 소형 모델과 비교한 벤치마크에서는 **5.43배**로 나온다 [14]. **비교 대상이 다르면 배수가 수십 배 차이 난다.** 리뷰어들도 벤더 저장소의 리더보드 주장은 중립 기관이 재현하기 전까지 마케팅으로 보라고 적는다 [6].

## 관련 영상

- **Introducing Aside** (Aside 공식, 1분 28초) — 공식 소개. 무엇을 표방하는지 가장 빠르게 본다 [15]
- **AI 브라우저 Aside 실제 사용법 공개** (AI 겸임교수 이종범, 15분 31초) — 한국어 실사용 시연. 한국인 3명이 창업하고 Y Combinator 가 투자했다는 배경도 여기서 나온다 [10]
- **Aside AI Browser, Real Demo and Source-Grounded Breakdown** (TechWealth Hub, 6분 31초) — 공식 데모와 문서를 근거로 짚어 가는 영어 해설 [16]
- **Aside Browser, le premier vrai AI Browser ?** (Melvynx, 17분 21초) — 다른 AI 브라우저와 비교하며 길게 본 프랑스어 리뷰 [17]

## 다음으로 할 것

- **판정 경계를 자기 데이터로 재 본다.** 6단계의 0.9와 0.1을 그대로 쓰지 말고, 실제 문의 100건을 넣어 가운데 구간이 몇 퍼센트인지 세어 본다. 그 비율이 곧 사람이 볼 물량이다.
- **Aside 를 읽기에서 실행으로 넓힌다.** 다만 넓히기 전에 확인 단추 운영 규칙을 먼저 정한다 [1].
