# 루틴 지침 — 카드뉴스 주간 제작 (Search 전용)

> 사용법: 이 파일 전체(또는 아래 한 줄)를 **claude.ai/code → Routines** 지침란에 붙여넣고,
> 대상 리포 `irun20000-eng/Search`, 주기 주 1~2회(예: 화·목 아침 9시)로 등록.
> 한 줄 버전: `Search 리포의 routines/cardnews-weekly.md 지침을 그대로 수행해줘. 만들 게 없으면 "이번 회차 제작 없음"만 보고.`
>
> **이 루틴은 카피만 쓴다. 렌더는 GitHub Actions 가 한다.**
> 로컬 PC 의 한글 폰트가 기존 편을 렌더한 것과 달라(지침: "21편부터 카드 질감이 갈린다")
> 렌더 환경을 러너로 고정했다. 루틴이 렌더를 시도하지 말 것.
>
> **제작 규칙의 정본은 `studio/CLAUDE.md`** 다. 이 문서와 어긋나면 그쪽이 이긴다.

당신은 `irun20000-eng/Search` 가 체크아웃된 클라우드 에이전트입니다. 회차마다
**한 편**의 카피를 쓰고 브랜치에 올려 놓습니다. 렌더·PR·배포는 자동으로 이어집니다.

## 0. 먼저 읽을 것

1. `studio/CLAUDE.md` — 절대 규칙 6조 · 10장 구조 · 카피 길이 · 실패 교훈
2. `cardnews/cardnews.yaml` 의 `production.concept_pool` — 다음 차례
3. `LESSONS.md` 의 방지 규칙 체크리스트

## 1. 다음 차례 정하기

`cardnews/cardnews.yaml` 에서 고른다.

- `production.next_up.<시리즈>` 에 지정이 있으면 그것
- 없으면 `production.concept_pool.<시리즈>` 에서 상태가 **`다음`** 인 항목
- **`보류`·`검증필요` 상태로는 만들지 않는다**
- 시리즈는 `episodes[].date` 의 시리즈별 최댓값이 가장 오래된 쪽부터

레이아웃은 **A→B→C 회전**의 다음 차례다.

## 2. 카피 쓰기

`studio/CLAUDE.md` 의 10장 구조와 스키마를 그대로 따른다. 특히:

- **추측 수치·연구·랭킹·시장 데이터 창작 절대 금지.** 이 프로젝트에서 가장 큰 사고다.
  개념 구조·검증 가능한 산술·명명된 정리는 되고, 실제 통계·조사 결과·지어낸 인용은 안 된다.
- 가시 텍스트는 전부 한국어. 영문 UI 라벨 금지.
- 카피 길이는 플랜별로 다르다 — B(pill) 4~6자 · A(2단) 6~8자 · C(VS) 5~6자.
  **5번 대비 슬라이드가 제일 잘 터진다.**

## 3. 두 곳에 쓴다 — 하나만 쓰면 렌더가 멈춘다

| 파일 | 넣는 것 |
|---|---|
| `studio/contents/contents_<시리즈>.py` | `EPn = {...}` 카피 본문 + `EPISODES` 에 등록 |
| `cardnews/cardnews.yaml` 의 `episodes` | `folder` · `series` · `title` · `angle` · `layout` · `date` · `images[]` · `caption` |

`folder` 는 `<시리즈>_<두자리>_<키워드>` (한글 그대로).
`images` 는 `<prefix><NN>.webp` 10개 — prefix 는 같은 시리즈의 직전 편을 따른다.

> ⚠️ **yaml 편 항목을 빠뜨리는 것이 가장 흔한 실수다.** 반입 스크립트가 이 경우
> 멈추고 "카피만 쓰고 편 항목을 빠뜨린 경우다" 라고 보고한다.

## 4. 직전 편 예고 갱신

같은 시리즈 **직전 편의 s10 `next`** 를 이번 편 제목으로 바꾼다.
각 편 마지막 장이 다음 편을 예고하는 구조이고, **가장 자주 빠뜨리는 단계**다.

## 5. 브랜치에 올린다

```
브랜치명: claude/cardnews-<시리즈>-<EPn>      예) claude/cardnews-숫자노트-EP4
커밋:     카드뉴스 <시리즈> <EPn> 카피
```

`main` 에 직접 푸시하지 않는다. 브랜치에 올라가면 `cardnews-render.yml` 이
자동으로 렌더해 같은 브랜치에 컷을 커밋하고 PR 을 연다.

## 6. 보고

작업을 마치면 **PushNotification** 으로 알린다. 슬랙·카카오톡은 쓰지 않는다.

- 성공: `카드뉴스 <시리즈> <EPn> 카피 완료 — 렌더 대기, PR 곧 열림`
- 만들 게 없음: `이번 회차 제작 없음 — 개념풀에 '다음' 항목이 없습니다`
- 막힘: 무엇이 막았는지 한 줄

**조용히 끝내지 말 것.** 이 파이프라인의 앞선 실패는 전부 "아무 일도 안 일어나서
몰랐던" 형태였다(2026-08-17 이후 동기화 루틴이 네 차례 빈손). 만들 게 없어도 보고한다.

## 7. 하지 말 것

- **렌더 시도 금지.** `python studio/cardnews.py render` 를 부르지 않는다. 폰트가 다르다.
- **시리즈에 종결 편을 만들지 말 것.** 네 시리즈 모두 무한 연재가 설계 의도다.
- **부모 노트는 학습자료(개념노트)를 만들지 않는다** — 경험 기반 조언·심리 연구 재현성 문제.
- **카피 원본이 없는 편(부모 1~10 · 일머리 1)을 재렌더하지 말 것.** 발행본과 문구가 어긋난다.
- **`main` 직접 푸시 금지.** 사람의 육안 검수 게이트를 건너뛰게 된다.

## 8. 이 뒤에 자동으로 일어나는 일

```
브랜치 push
  → cardnews-render.yml   폰트·크로미움 설치 → 렌더 10장 + 모아보기
                          → webp 변환 → cardnews/assets/ + manifest
                          → link-index 재생성 → 커밋 → PR 열기
  → 사람이 PR 에서 모아보기 확인 → 머지        ★ 유일한 사람 게이트
  → cardnews-sync.yml     main 반영 확인 → Pages 배포
```

사람이 할 일은 **모아보기를 보고 머지 버튼을 누르는 것** 하나다.
이상하면 머지하지 말고 코멘트만 남기면 다음 회차에 카피를 줄여 다시 만든다.
