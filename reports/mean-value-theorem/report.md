# 평균값 정리 (이해편)

> 고속도로 **구간단속**을 생각해 보자. 20 km 구간을 10분에 통과했다면 평균 시속은 120 km다. 그런데 "나는 한 번도 120을 밟은 적 없다"는 항변이 가능할까? **불가능하다.** 어느 순간엔가 계기판은 **정확히 120**을 가리켰다. 이 당연해 보이는 사실이 바로 **평균값 정리(Mean Value Theorem)**이고 [3], 미분학의 절반이 이 한 문장 위에 서 있다. 이 글은 **롤의 정리 → 평균값 정리 → 그 활용**을 그림과 손계산으로 정리한다. 두 함수로 일반화한 **코시 평균값 정리**와 로피탈·테일러로 이어지는 이야기는 짝을 이루는 **[확장편]**에서 다룬다.

## TL;DR
- **평균값 정리(MVT)**: f가 **[a, b]에서 연속**이고 **(a, b)에서 미분가능**하면, `f′(c) = (f(b) − f(a))/(b − a)` 인 c가 (a, b) 안에 **적어도 하나 존재**한다 [3][5].
- **뜻**: 두 점을 잇는 **할선의 기울기**(= 평균변화율)와 **똑같은 기울기의 접선**이 그 사이 어딘가에 있다. 즉 **"평균은 어느 순간엔가 실제로 달성된다"** [3].
- **뿌리는 롤의 정리**: 양 끝 높이가 같으면(`f(a) = f(b)`) **중간에 기울기 0인 지점**이 있다 [2]. MVT는 롤을 **기울여 놓은 것**뿐이다.
- **가치**: 도함수라는 **국소 정보**로 함수의 **전역 행동**을 통제한다. "f′ = 0이면 상수", "f′ > 0이면 증가" 같은 기본 사실이 전부 MVT의 따름정리다 [5].
- **활용**: 부등식 증명(`|sin a − sin b| ≤ |a − b|`, `eˣ > 1 + x`), 증가·감소 판정, 근의 개수 세기, 그리고 구간단속의 수학적 근거 [4][7].
- **조건이 깨지면 결론도 보장되지 않는다**: `f(x) = |x|` 처럼 **뾰족한 점**이 있으면 정리가 결론을 보장하지 못한다(실제로 반례가 된다) [5].

## 핵심 포인트
1. **가정 두 개**: 닫힌구간 **연속** + 열린구간 **미분가능**. 끝점에서는 미분가능하지 않아도 된다 [1][3].
2. **결론은 존재성**: c가 **있다**는 것이지, **어디인지**나 **몇 개인지**는 말해 주지 않는다 [3].
3. **롤 = MVT의 특수한 경우**(f(a) = f(b)), 거꾸로 **MVT는 롤에서 유도**된다 [2].
4. **평균변화율 = 할선 기울기**, **순간변화율 = 접선 기울기**. MVT는 이 둘을 잇는 다리다.
5. **증명의 요령은 보조함수**: 곡선에서 할선을 빼면 양 끝 높이가 같아져 롤을 쓸 수 있다 [5].

## 1. 구간단속 — 평균은 반드시 달성된다

먼저 직관부터 잡자.

어떤 자동차가 시각 a에 위치 f(a), 시각 b에 위치 f(b)에 있었다. **평균 속도**는

`(f(b) − f(a)) / (b − a)`

이다. 평균값 정리가 말하는 것은 이렇다 — **그 구간 어딘가의 시각 c에서, 속도계가 가리킨 순간 속도 f′(c)가 정확히 이 평균 속도와 같았다** [3].

왜 당연한가? 만약 **모든 순간** 평균보다 느렸다면 총 이동거리가 모자랐을 것이고, **모든 순간** 평균보다 빨랐다면 넘쳤을 것이다. 실제 거리가 정확히 맞았다면, 느린 구간과 빠른 구간 사이 **어딘가에서 평균과 같은 순간**이 있어야 한다.

> 이것이 한국 고속도로 **구간단속**의 논리다. 시작점과 끝점의 통과 시각만 재도, **"어느 순간엔가 그 속도였다"**를 수학적으로 확정할 수 있다. 순간 속도를 직접 측정하지 않고도 말이다.

이 직관을 정확한 문장으로 다듬는 것이 이 글의 목표다. 그리고 그 다듬는 과정에서 **왜 '연속'과 '미분가능'이라는 조건이 필요한지**가 자연스럽게 드러난다.

## 2. 롤의 정리 — 출발점

평균값 정리는 하늘에서 떨어지지 않는다. 더 단순한 사실에서 나온다.

### 2-1. 진술
> **롤의 정리(Rolle's theorem).** 함수 f가
> - 닫힌구간 **[a, b]에서 연속**이고,
> - 열린구간 **(a, b)에서 미분가능**하며,
> - **f(a) = f(b)**
>
> 이면, `f′(c) = 0` 인 c가 (a, b) 안에 **적어도 하나 존재**한다 [2][6].

### 2-2. 그림으로 보기
양 끝 높이가 같은 매끈한 곡선을 그려 보자. 올라갔다면 반드시 내려와야 하고, 내려갔다면 반드시 올라와야 한다. **방향이 바뀌는 지점**에서는 접선이 수평이다.

```
   f(a) ●                              ● f(b)     ← 양 끝 높이가 같다
         \          ___(봉우리)        /
          \       /       \          /
           \    /           \       /
            \ /               \    /
             ●(골짜기)          \ /
                                 ●(골짜기)
        ↑ 봉우리·골짜기 어디서든 접선이 수평 → f′ = 0
```

수평인 곳이 **최소한 하나**는 생긴다 — 이것이 롤의 정리다.

### 2-3. 왜 성립하나(증명의 뼈대)
f는 닫힌구간에서 연속이므로 **최댓값과 최솟값을 반드시 갖는다**(최대·최소 정리[^최대최소]) [6][7]. 두 경우로 나뉜다.

- **경우 1 — 최댓값과 최솟값이 모두 양 끝에서 나온다.** f(a) = f(b)이므로 최댓값 = 최솟값이 되고, f는 **상수함수**다. 그러면 (a, b)의 **모든 점**에서 f′ = 0이다.
- **경우 2 — 최댓값이든 최솟값이든 하나가 구간 내부에서 나온다.** 그 내부 점을 c라 하자. 내부의 극값에서는 미분가능하면 **f′(c) = 0**이다(페르마의 정리). 예컨대 c가 **최댓값**인 경우, 왼쪽에서 다가오는 차분몫은 0 이상이고 오른쪽에서 다가오는 차분몫은 0 이하인데 둘 다 f′(c)로 수렴하므로 **f′(c) = 0**일 수밖에 없다. (c가 **최솟값**이면 두 부등호가 반대로 뒤집힐 뿐, 결론은 같다.)

두 경우 모두 f′(c) = 0인 c를 찾았다. □

> 관찰: 증명이 **"닫힌구간 연속 → 최댓값·최솟값 존재"**에 기대고 있다. 이 성질은 실수의 **완비성**에서 나온다. 그래서 롤의 정리는 겉보기보다 훨씬 깊은 곳에 뿌리를 두고 있다. 역사적으로도 이 정리들은 **직관적으로 먼저 쓰이다가 19세기에 와서야 엄밀하게 정리**됐다 [8].

## 3. 평균값 정리 — 롤을 기울이면 된다

### 3-1. 진술
> **평균값 정리(Mean Value Theorem, MVT).** f가 **[a, b]에서 연속**이고 **(a, b)에서 미분가능**하면,
>
> `f′(c) = (f(b) − f(a)) / (b − a)`
>
> 을 만족하는 c가 (a, b) 안에 **적어도 하나 존재**한다 [3][5].

같은 식을 곱셈 꼴로 쓰면 활용할 때 더 편하다:

`f(b) − f(a) = f′(c) · (b − a)`

### 3-2. 그림 — 할선과 평행한 접선
두 점 (a, f(a))와 (b, f(b))를 잇는 직선을 **할선(secant)**이라 한다. 그 기울기가 바로 `(f(b) − f(a))/(b − a)`, 즉 **평균변화율**[^평균변화율]이다 [1].

MVT는 **이 할선과 평행한 접선이 곡선 위 어딘가에 반드시 있다**고 말한다.

```
                                  ●  f(b)
                            ___/⟋
                        ⟋  /        ← 접선 (할선과 평행)
                    ⟋   /
              ⟋      /
   f(a)  ● ⟋       /
         할선
```

### 3-3. 증명 — 할선을 빼면 롤이 된다
증명의 아이디어는 단 하나다. **곡선에서 할선을 빼서 양 끝을 같은 높이로 만든다** [5].

할선의 식은 `ℓ(x) = f(a) + [(f(b) − f(a))/(b − a)] · (x − a)` 이다. 보조함수를

`h(x) = f(x) − ℓ(x)`

로 두자. 그러면
- **h(a) = f(a) − f(a) = 0**
- **h(b) = f(b) − [f(a) + (f(b) − f(a))] = 0**

로 **양 끝 값이 같다(둘 다 0)**. h는 f와 ℓ의 차이므로 [a, b]에서 연속, (a, b)에서 미분가능하다. 따라서 **롤의 정리**를 쓸 수 있고, `h′(c) = 0`인 c가 존재한다. 그런데

`h′(x) = f′(x) − (f(b) − f(a))/(b − a)`

이므로 h′(c) = 0은 곧 `f′(c) = (f(b) − f(a))/(b − a)` 다. □

> 정리하면: **롤 = "양 끝이 같을 때"**, **MVT = "양 끝이 달라도 되게 기울인 버전"**. 그리고 그 '기울임'을 담당하는 것이 보조함수 h = f − 할선이다. (확장편의 코시 평균값 정리도 **똑같은 보조함수 전략**을 쓴다.)

## 4. 가정이 왜 필요한가 — 깨뜨려 보기

정리를 제대로 이해하려면 **가정을 하나씩 빼 봤을 때 무너지는지**를 봐야 한다.

### 4-1. 미분가능성이 깨지면
`f(x) = |x|` 를 [−1, 1]에서 보자.
- 평균변화율: `(f(1) − f(−1))/(1 − (−1)) = (1 − 1)/2 = 0`
- 그런데 f′(x)는 x < 0에서 **−1**, x > 0에서 **+1**이고, **x = 0에서는 미분 불가능**이다.
- 즉 **f′(c) = 0인 c가 하나도 없다.** MVT(그리고 롤)가 성립하지 않는다 [5].

원인은 **x = 0의 뾰족한 점** 하나뿐이다. 가정이 얼마나 필수적인지 보여 준다.

### 4-2. 연속성이 깨지면
[0, 1]에서 `f(x) = x` (단 x < 1), `f(1) = 0` 이라 하자. 끝점에서만 값이 튄다.
- 평균변화율: `(f(1) − f(0))/(1 − 0) = (0 − 0)/1 = 0`
- 그러나 (0, 1)에서 f′(x) = 1 이라 **0이 되는 점이 없다.**

**끝점 하나의 불연속**만으로도 결론이 무너진다.

### 4-3. 그래서 가정의 모양이 이렇다
- **닫힌구간에서 연속**: 최댓값·최솟값의 존재를 보장(롤의 증명에 필요).
- **열린구간에서 미분가능**: 접선을 잴 수 있어야 한다. **끝점에서는 미분가능할 필요가 없다** — 예컨대 `f(x) = √(1 − x²)`는 [−1, 1]에서 연속이고 (−1, 1)에서 미분가능해 MVT를 쓸 수 있다(양 끝에서 접선이 수직이라 미분 불가인데도 문제없다) [1][3].

## 5. 무엇에 쓰나 ① — 미분학의 기본 사실들

MVT의 진짜 가치는 **국소(도함수) → 전역(함수 전체)** 로 정보를 옮겨 주는 데 있다. 우리가 당연히 여기는 규칙들이 사실 전부 MVT의 따름정리다 [5].

### 5-1. "도함수가 0이면 상수함수다"
구간에서 f′ ≡ 0이라 하자. 임의의 두 점 x₁ < x₂에 대해 MVT를 쓰면

`f(x₂) − f(x₁) = f′(c)·(x₂ − x₁) = 0·(x₂ − x₁) = 0`

이므로 f(x₂) = f(x₁). 모든 점에서 값이 같으니 **상수함수**다. □

> 이건 사소해 보이지만 **부정적분에 +C가 붙는 근거**다. "도함수가 같은 두 함수는 상수만큼만 차이 난다"가 여기서 나온다.

### 5-2. "도함수가 양수면 증가함수다"
f′ > 0이라 하자. x₁ < x₂에 대해 `f(x₂) − f(x₁) = f′(c)(x₂ − x₁)`인데, f′(c) > 0이고 x₂ − x₁ > 0이므로 **f(x₂) > f(x₁)**. 즉 **증가**한다. □

**증감표로 그래프를 그리는 모든 문제**가 이 정리 위에 서 있다. "f′의 부호를 보면 오르내림을 안다"는 것은 경험칙이 아니라 **증명된 사실**이고, 그 증명이 MVT다.

### 5-3. 근의 개수 세기
f가 미분가능한데 f′이 어떤 구간에서 **0이 되지 않는다**면, 그 구간에서 f(x) = 0의 근은 **많아야 하나**다.
(만약 서로 다른 두 근 α < β가 있다면 f(α) = f(β) = 0이므로 **롤의 정리**로 f′(c) = 0인 c가 α, β 사이에 있어야 하는데, 이는 가정에 어긋난다.)

## 6. 무엇에 쓰나 ② — 부등식 증명

MVT는 **부등식을 만드는 기계**다. 요령은 늘 같다: `f(b) − f(a) = f′(c)(b − a)`로 바꾼 뒤, **f′(c)의 범위**를 잡는다 [4].

**예 1) `|sin a − sin b| ≤ |a − b|`**
f(x) = sin x 는 어디서나 연속·미분가능. a ≠ b에 대해 MVT를 쓰면
`sin b − sin a = cos c · (b − a)`
양변에 절댓값을 씌우고 `|cos c| ≤ 1` 을 쓰면
`|sin b − sin a| = |cos c|·|b − a| ≤ |b − a|` □

**예 2) x > 0일 때 `ln(1 + x) < x`**
f(t) = ln(1 + t) 에 [0, x]에서 MVT:
`ln(1 + x) − ln 1 = [1/(1 + c)] · x`  (0 < c < x)
c > 0이므로 `1/(1 + c) < 1`, 따라서 `ln(1 + x) < x` □

**예 3) x ≠ 0일 때 `eˣ > 1 + x`**
f(t) = eᵗ 에 0과 x 사이에서 MVT: `eˣ − 1 = e^c · x`.
- **x > 0**이면 c > 0이라 `e^c > 1`, 양변에 x(>0)를 곱해 `eˣ − 1 > x`.
- **x < 0**이면 c < 0이라 `e^c < 1`, 그런데 x가 **음수**라 부등호가 뒤집혀 `e^c · x > 1 · x = x`, 역시 `eˣ − 1 > x`.

두 경우 모두 **eˣ > 1 + x** □ (x < 0에서 부호가 뒤집히는 것을 놓치기 쉬우니 주의.)

> 패턴 정리: **"차이 = 도함수 × 간격"**으로 바꾸고, 도함수를 **위나 아래로 묶으면** 부등식이 나온다.

## 7. Worked Examples — c를 직접 찾아보기

MVT는 c의 **존재**만 말하지만, 간단한 함수에서는 실제로 구할 수 있다.

**예 1) f(x) = x², 구간 [1, 3]**
평균변화율: `(9 − 1)/(3 − 1) = 4`. 한편 f′(x) = 2x이므로 `2c = 4 → c = 2`.
c = 2는 (1, 3) 안에 있다 ✓. (이차함수는 c가 항상 **구간의 중점**에 온다 — 여기서도 (1+3)/2 = 2.)

**예 2) f(x) = x³, 구간 [0, 3]**
평균변화율: `(27 − 0)/(3 − 0) = 9`. f′(x) = 3x²이므로 `3c² = 9 → c² = 3 → c = √3 ≈ 1.732`.
(−√3은 구간 밖이라 버린다.) 중점 1.5보다 **오른쪽**에 있다 — 이차함수와 달리 중점이 아니다.

**예 3) c가 두 개인 경우** f(x) = x³ − x, 구간 [−1, 1]
`f(−1) = −1 + 1 = 0`, `f(1) = 1 − 1 = 0` 이라 평균변화율은 **0** (롤의 상황).
f′(x) = 3x² − 1 = 0 → `c = ±1/√3 ≈ ±0.577`. **둘 다** (−1, 1) 안에 있다.
→ **MVT는 "적어도 하나"를 말할 뿐, 유일하다고 말하지 않는다.**

**예 4) 부등식 활용 — √101의 근사**
f(x) = √x 에 [100, 101]에서 MVT: `√101 − 10 = 1/(2√c)`, 100 < c < 101.
- c > 100이므로 `1/(2√c) < 1/20 = 0.05`
- c < 101 < 102.01 = 10.1²이므로 √c < 10.1, 따라서 `1/(2√c) > 1/20.2 ≈ 0.0495`
→ `10.0495 < √101 < 10.05`. 실제 √101 ≈ 10.0499 ✓ **계산기 없이 소수 셋째 자리까지** 좁혔다.

## 8. 흔한 오해·FAQ

**Q1. c를 구하는 게 목적인가요?**
아니다. MVT의 힘은 **"그런 c가 있다"**는 존재성에 있다. 대부분의 활용(부등식·단조성 증명)에서 c의 정확한 값은 **끝까지 모른 채로** 논증이 끝난다 [3].

**Q2. c는 유일한가요?**
아니다. 예 3처럼 **여러 개일 수 있다.** "적어도 하나"가 정확한 표현이다.

**Q3. 끝점에서 미분 가능해야 하나요?**
아니다. **열린구간 (a, b)**에서만 미분가능하면 된다. 그래서 반원 `√(1 − x²)`처럼 양 끝에서 접선이 수직인 함수에도 쓸 수 있다 [1].

**Q4. 롤의 정리와 평균값 정리 중 뭐가 더 센가요?**
**논리적으로 동등**하다. 롤은 MVT의 특수한 경우(f(a) = f(b))이고, 거꾸로 MVT는 롤로 증명된다(3-3절). 보통 **롤을 먼저 증명하고 MVT를 유도**하는 순서를 쓴다 [2][5].

**Q5. 왜 이 정리가 그렇게 중요하다고들 하나요?**
미분은 **한 점에서의 정보**인데, 우리가 알고 싶은 건 보통 **구간 전체에서의 행동**(증가하나? 상수인가? 얼마나 커지나?)이기 때문이다. **그 둘을 잇는 유일한 다리가 MVT**다. 5장의 따름정리들이 그 증거다 [5].

**Q6. 곡선이 아니라 움직이는 물체(평면 위 곡선)에도 성립하나요?**
**그대로는 성립하지 않는다.** 이는 확장편에서 다루는 중요한 한계이며, 그래서 **부등식 형태**나 **코시 평균값 정리**가 따로 필요해진다.

## 9. 한눈 요약

| 항목 | 내용 |
|---|---|
| 롤의 정리 | [a,b] 연속 + (a,b) 미분가능 + **f(a)=f(b)** ⇒ f′(c)=0인 c 존재 |
| 평균값 정리 | 위 가정(f(a)=f(b) 불필요) ⇒ **f′(c) = (f(b)−f(a))/(b−a)** |
| 곱셈 꼴 | **f(b) − f(a) = f′(c)(b − a)** ← 활용할 땐 이 형태 |
| 기하적 의미 | **할선과 평행한 접선**이 존재 |
| 증명 전략 | **곡선 − 할선**으로 보조함수 → 롤 적용 |
| 따름정리 | f′=0 ⇒ 상수 / f′>0 ⇒ 증가 / 근의 개수 제한 |
| 활용 | 부등식 증명, 증감 판정, 근삿값 추정 |
| 실패 예 | \|x\|(뾰족점), 끝점 불연속 |

**마지막 한 줄** — 평균값 정리는 **"평균은 반드시 어느 순간 실제로 달성된다"**는 상식을, 미분학 전체를 떠받치는 정리로 바꿔 놓은 문장이다. 증감표도, +C도, 부등식 증명도 전부 여기서 나온다. 그리고 이 정리를 **두 함수로 확장**하면 로피탈과 테일러가 열린다 — 그 이야기가 확장편이다.
