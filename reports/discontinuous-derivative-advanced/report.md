# 도함수의 불연속 (확장편)

> 이해편은 `x² sin(1/x)` 하나로 "미분가능해도 도함수는 불연속일 수 있다"를 보였다. 확장편의 질문은 하나다 — **얼마나 나빠질 수 있는가.** 답은 세 층으로 내려간다. **다르부 정리**가 위에서 한 겹 막고(점프 불가), **베르 1류**가 또 한 겹 막으며(모든 점에서 불연속 불가), 그 아래에서 **볼테라 함수**가 진짜 사고를 친다 — 도함수가 **리만적분조차 되지 않는** 것이다 [9]. 마지막 사실이 미적분 기본정리를 지금의 문장으로 만들었고, 르베그 적분이 필요했던 이유의 한 축이다.

## TL;DR

- **도함수 불연속은 제2종(본질적)만 가능하다.** 제거가능·점프형은 평균값 정리로 원천 봉쇄된다 [8][14].
- **다르부 정리(1875)**: 미분가능 함수의 도함수는 연속이 아니어도 사잇값 성질을 갖는다 [1][11]. 증명은 두 갈래 — 최대최소 정리 경유와 평균값 정리+중간값 정리 경유 [1][7].
- **모든 도함수는 베르 1류다.** `fₙ(x) = (f(x+1/n) − f(x))/(1/n)` 이 연속이고 그 점별극한이 `f′` 이기 때문이다 [8]. 따라서 **도함수는 조밀한 집합에서 반드시 연속**이고, **디리클레 함수는 도함수가 될 수 없다** [8].
- **볼테라 함수(1881)**: 모든 점에서 미분가능, `V′` 유계, 그런데 `V′` 이 **측도 1/2 인 집합에서 불연속** → 르베그 판정법에 의해 **리만적분 불가** [9][10].
- **정확한 특성화**: `E ⊂ [a,b]` 가 어떤 도함수의 불연속점 집합이 될 필요충분조건은 **E 가 Fσ 이면서 제1범주(meagre)** 라는 것이다 [8][12]. 위 세 겹 방어의 정확한 한계선이다.
- **미적분 기본정리의 문장이 왜 그 모양인가**가 여기서 설명된다 — "f 가 **적분가능하고** `f = g′`" 라는 이중 가정은 볼테라 때문에 필요하다 [8].

## 핵심 포인트

1. **세 겹의 제약이 서로 다른 도구에서 나온다** — 다르부는 최대최소 정리에서, 제2종 제한은 평균값 정리에서, 조밀 연속성은 베르 범주 정리에서 온다.
2. **다르부 정리는 필요조건이지 충분조건이 아니다** [7]. 사잇값 성질을 가져도 도함수가 아닐 수 있고, 그 간극을 베르 1류와 Fσ·제1범주 조건이 메운다.
3. **"측도 0"과 "제1범주"는 다른 작음이다.** 볼테라의 불연속 집합은 **제1범주이면서 측도 1/2** 이다 — 위상적으로 작고 측도로는 크다. 이 어긋남이 리만적분을 깨뜨린다.
4. **볼테라의 핵심 부품이 이해편의 `x² sin(1/x)` 다** [9]. 국소적 병리를 뚱뚱한 칸토어 집합의 각 점에 심은 것이 볼테라 함수다.
5. **르베그 적분은 이 반례를 우회하지 통과시키지 않는다.** `V′` 은 유계 가측이므로 르베그 적분이 되고, 기본정리가 복원된다 [3][4].

## 1. 직관 압축

이해편의 결론을 한 문단으로 압축한다. `f(x) = x² sin(1/x)`, `f(0) = 0` 은 진폭이 `x²` 로 죽는 무한 진동이다. 진폭이 제곱으로 죽으므로 차분몫 `h·sin(1/h)` 이 `|h|` 에 갇혀 `f′(0) = 0` 이 존재하지만, 미분하면 `f′(x) = 2x sin(1/x) − cos(1/x)` 에서 `cos(1/x)` 항이 **진폭을 잃지 않은 채** 남아 원점 근방에서 −1과 +1을 무한히 왕복한다. 그래서 `f′(0)` 은 있는데 `lim_{x→0} f′(x)` 는 없다 [1][8].

이 아래부터는 이 사실을 **"그럴 수 있다"에서 "정확히 여기까지다"로** 바꾸는 작업이다.

## 2. 불연속의 분류와 다르부 함수

먼저 언어를 정리한다. 점 `a` 에서의 불연속은 세 가지다.

| 유형 | 조건 | 도함수에게 |
|---|---|---|
| **제거가능** | 좌·우 극한이 존재하고 서로 같으나 `f(a)` 와 다름 | **불가능** (§4) |
| **점프(도약)** | 좌·우 극한이 둘 다 존재하나 서로 다름 | **불가능** (§4) |
| **제2종(본질적)** | 좌·우 극한 중 **적어도 하나가 존재하지 않음** | **가능** — 유일하게 허용 |

앞의 둘을 묶어 **단순 불연속(simple discontinuity)** 이라 부른다. 위키백과는 이 결론을 이렇게 적는다 — 다르부 함수의 모든 불연속은 본질적(essential)이며, "불연속점에서 좌·우 극한 중 최소한 하나는 존재하지 않는다" [7].

**다르부 함수**는 사잇값 성질을 갖는 실함수를 말한다 [1][7]. 중간값 정리에 의해 모든 연속함수는 다르부 함수이고, **다르부의 기여는 불연속인 다르부 함수가 존재함을 보인 것**이다 [7].

```
   함수의 계층 (실함수)

   ┌───────────────────────────────────────────────┐
   │  모든 실함수                                   │
   │  ┌─────────────────────────────────────┐      │
   │  │  다르부 함수 (사잇값 성질)           │      │
   │  │  ┌───────────────────────┐          │      │
   │  │  │  베르 1류 ∩ 다르부      │          │      │
   │  │  │  ┌─────────────────┐  │          │      │
   │  │  │  │  도함수          │  │          │      │
   │  │  │  │ ┌─────────────┐ │  │          │      │
   │  │  │  │ │  연속함수    │ │  │          │      │
   │  │  │  │ └─────────────┘ │  │          │      │
   │  │  │  └─────────────────┘  │          │      │
   │  │  └───────────────────────┘          │      │
   │  └─────────────────────────────────────┘      │
   └───────────────────────────────────────────────┘
     ↑ 콘웨이 13진 함수는 여기 (어디서도 연속 아닌 다르부 함수)
```

다르부 함수 계열이 얼마나 넓은지 보여 주는 두 사실이 있다 [7].

- **콘웨이의 13진 함수(Conway's base 13 function)** 는 **어디서도 연속이 아닌** 다르부 함수다 [7]. 즉 사잇값 성질은 연속성을 조금도 함축하지 않는다.
- 별도로, 모든 열린 구간의 상이 실직선 전체가 되는 함수를 **강한 다르부 함수**라 부른다 [7].
- **임의의 실함수는 두 다르부 함수의 합으로 쓸 수 있다** [7]. 따라서 다르부 함수의 모임은 덧셈에 대해 닫혀 있지 않다.

두 번째 사실이 중요한 이유는 이것이다 — **사잇값 성질만으로는 도함수를 특징짓지 못한다.** 다르부 정리는 필요조건일 뿐이고, 충분조건은 §8에서 만난다.

## 3. 왜 그런가 (유도 1) — 다르부 정리의 두 증명

**정리 (다르부, 1875).** `[a,b]` 를 포함하는 열린 구간에서 `f` 가 미분가능하고 `k` 가 `f′(a)` 와 `f′(b)` 사이의 값이면, `f′(c) = k` 인 `c ∈ (a,b)` 가 존재한다 [1].

원논문은 다르부가 1875년 『Annales Scientifiques de l'É.N.S.』 제2계열 4권 109–110쪽에 발표한 「Mémoire sur les fonctions discontinues(불연속함수에 관한 논문)」 이다 [11].

### 증명 A — 최대최소 정리 경유

`f′(a) < k < f′(b)` 라 하자. **보조함수를 세운다.**

```
F(x) = f(x) − kx        (x ∈ [a, b])
```

**1단계.** `F` 는 미분가능하므로 연속이고, 최대최소 정리에 의해 `[a,b]` 의 어떤 점에서 최솟값을 갖는다 [1].

**2단계 — 최솟값이 끝점이 아님을 보인다.** 이것이 증명의 심장이다.

```
F′(a) = f′(a) − k < 0
```

`F′(a) < 0` 이므로 미분계수의 정의에서 **충분히 작은 양수 h 에 대해 `F(a+h) − F(a) < 0`**, 즉 `F(a+h) < F(a)` 다 [1]. 따라서 `F(a)` 는 최솟값이 아니다. 오른쪽 끝도 대칭이다 — `F′(b) = f′(b) − k > 0` 이므로 `b` 왼쪽 가까이에 `F` 값이 더 작은 점이 있다.

**3단계.** 최솟값은 **열린 구간 `(a,b)` 의 어떤 점 `c`** 에서 달성된다. 내부 극값이므로 임계점 정리(페르마 정리)에 의해

```
F′(c) = 0   ⇒   f′(c) − k = 0   ⇒   f′(c) = k    ∎
```

`f′(b) < k < f′(a)` 인 경우는 최댓값을 쓰거나 부호를 뒤집으면 같다 [1].

**이 증명이 쓴 것을 세어 보라** — 최대최소 정리와 임계점 정리뿐이다. **`f′` 의 연속성은 한 번도 쓰이지 않는다.** 다르부 정리가 불연속 도함수에도 통하는 이유가 여기 있다.

### 증명 B — 평균값 정리 + 중간값 정리 경유

두 번째 길은 할선의 기울기를 연속적으로 움직이는 것이다 [7]. `c = (a+b)/2` 로 두고 두 끝점을 다음처럼 움직인다.

```
a ≤ t ≤ c :   α(t) = a,       β(t) = 2t − a
c ≤ t ≤ b :   α(t) = 2t − b,  β(t) = b
```

`t ∈ (a,b)` 에서 항상 `a ≤ α(t) < β(t) ≤ b` 다. 이제 할선 기울기를

```
        f(β(t)) − f(α(t))
g(t) = ───────────────────
          β(t) − α(t)
```

로 정의하면 `g` 는 `(a,b)` 에서 **연속**이고, 끝으로 갈수록 `g(t) → f′(a)` (t→a), `g(t) → f′(b)` (t→b) 이다 [7]. 여기에 **중간값 정리**를 쓰면 `g(t₀) = k` 인 `t₀` 가 있고, 그 `t₀` 에 대해 **평균값 정리**를 쓰면 `f′(x) = g(t₀) = k` 인 `x ∈ (α(t₀), β(t₀))` 가 존재한다 [6][7]. ∎

**두 증명이 말하는 것이 다르다.** A는 "극값은 내부에서 나고 거기서 도함수는 0"이라는 **국소 논법**이고, B는 "할선 기울기는 연속적으로 변하고 모든 할선 기울기는 어떤 접선 기울기다"라는 **평균값 정리의 전역 논법**이다. 후자는 다르부 정리가 사실상 **평균값 정리의 사잇값 버전**임을 드러낸다.

## 4. 왜 그런가 (유도 2) — 제2종 불연속만 가능한 이유

**정리 (스피박 『Calculus』 4판 203쪽).** `f` 가 `a` 에서 연속이고, `a` 를 포함하는 어떤 구간에서 (`x = a` 는 빼고) `f′` 이 존재하며, `lim_{x→a} f′(x)` 가 **존재한다**고 하자. 그러면 `f′(a)` 도 존재하고 `lim_{x→a} f′(x) = f′(a)` 이다 [8][14].

**증명 (평균값 정리).** `f′` 이 `a` 주위 구간에서 존재하고 `f` 가 `a` 에서 연속이므로, 어떤 `h > 0` 에 대해 `f` 는 `[a, a+h]` 에서 연속이고 `(a, a+h)` 에서 미분가능하다. 평균값 정리를 적용하면 `αₕ ∈ (a, a+h)` 가 있어 [6][8]

```
f(a+h) − f(a)
───────────── = f′(αₕ)
      h
```

`a < αₕ < a + h` 이므로 `h → 0⁺` 이면 `αₕ → a` 이고, 가정에서 `lim_{x→a⁺} f′(x)` 가 존재하므로

```
      f(a+h) − f(a)
lim  ───────────── = lim f′(αₕ) = lim   f′(x)
h→0⁺       h         h→0⁺        x→a⁺
```

`h < 0` 쪽도 같은 논법이고, 가정에서 좌우 극한이 일치하므로 `f′(a)` 가 정의되고 그 값과 같다 [8]. ∎

**따름정리 두 개가 여기서 떨어진다** [8].

1. **도함수는 제거가능 불연속을 가질 수 없다.** 극한이 존재하면 위 정리가 `f′(a)` 를 그 극한으로 못 박기 때문이다.
2. **도함수는 점프 불연속을 가질 수 없다.** 좌·우 극한이 둘 다 존재하되 서로 다르면 `f′(a)` 자체가 정의되지 않고([8]의 각주: 좌·우 차분몫이 평균값 정리를 통해 상·하 극한에 묶인다), 그러면 `a` 는 애초에 정의역 밖이라 "불연속"이라 말할 자리도 없다.

**그래서 `f′` 이 `a` 에서 불연속이라면 좌·우 극한 중 최소 하나가 아예 존재하지 않는다** [8]. 이해편에서 `sgn(x)` 가 도함수가 될 수 없다고 한 것 [1] 이 여기서 두 번째 방식으로 증명된다 — 다르부 정리로도 막히고, 점프 금지로도 막힌다.

**한 줄 요약**: `x² sin(1/x)` 의 도함수가 보이는 요동은 **가장 얌전한 병리가 아니라 도함수에게 허용된 유일한 병리**다 [8].

## 5. 도함수는 베르 1류다 — 연속점이 조밀하다

다르부 정리와 §4는 **한 점에서 어떤 모양으로** 끊길 수 있는지를 말했다. 이제 **얼마나 많은 점에서** 끊길 수 있는지로 간다.

**핵심 관찰.** 다음 함수열을 보자 [8].

```
        f(x + 1/n) − f(x)
fₙ(x) = ─────────────────  = n · [ f(x + 1/n) − f(x) ]
              1/n
```

`f` 가 미분가능하면 `f` 는 연속이므로 **각 `fₙ` 은 연속**이다. 그리고 `n → ∞` 일 때 `fₙ(x) → f′(x)` 가 **각 점마다** 성립한다. 즉:

> **도함수는 연속함수열의 점별극한이다.** 이런 함수를 **베르 1류(Baire class 1)** 라 부른다 [7][8].

베르 1류에 대한 고전 정리가 결론을 준다 [7][8].

- **베르 특성화 정리**: 바나흐 공간 `X` 위의 실함수 `f` 가 베르 1류일 필요충분조건은, `X` 의 모든 공집합 아닌 닫힌 부분집합 `K` 에 대해 `f|K` 가 `K` 의 상대위상에서 연속점을 갖는 것이다 [8].
- 따라서 **도함수는 반드시 연속점을 가지며, 나아가 조밀한 집합에서 연속이다** [8]. 여기서 조밀하다는 것은 그 집합의 폐포가 전체 공간과 같다는 뜻이다 [5].
- 위키백과는 이를 집합 언어로 못 박는다 — **도함수가 불연속인 점들의 집합은 제1범주(meagre) Fσ 집합**이다 [7].

**즉각적 귀결.** 디리클레 함수(유리수에서 1, 무리수에서 0)는 **모든 점에서 불연속**이므로 연속점이 하나도 없다. 따라서 **디리클레 함수는 어떤 함수의 도함수도 아니다** [8].

```
   제약이 쌓이는 순서

   [1층] 다르부 정리      → 사잇값 성질을 가져야 한다        (증명 도구: 최대최소 정리)
   [2층] 제2종 제한        → 점프·제거가능 불연속 불가        (증명 도구: 평균값 정리)
   [3층] 베르 1류          → 연속점이 조밀해야 한다           (증명 도구: 베르 범주 정리)
   ───────────────────────────────────────────────────────
   남은 틈: "조밀하지 않은 곳에서는?"  → §6 볼테라가 그 틈을 파고든다
```

## 6. 볼테라 함수 (worked) — 도함수가 리만적분되지 않는다

3층 방어를 뚫는 것이 아니라 **그 틈을 정확히 쓰는** 것이 볼테라의 구성이다. 도함수의 불연속점 집합은 제1범주여야 한다 — **그런데 제1범주 집합이 측도 0일 필요는 없다.**

### 6-1. 뚱뚱한 칸토어 집합 (SVC 집합)

**구성** [10]. `[0,1]` 에서 시작해 가운데 열린 구간 `1/4` 을 제거한다.

```
1단계:  [0,1] → [0, 3/8] ∪ [5/8, 1]                      (길이 1/4 제거)
2단계:  남은 2개 구간에서 각각 가운데 1/16 제거
        → [0,5/32] ∪ [7/32,3/8] ∪ [5/8,25/32] ∪ [27/32,1]
n단계:  남은 2ⁿ⁻¹ 개 구간에서 각각 가운데 1/4ⁿ 제거
```

**제거된 총 길이를 계산한다.**

```
∞     2ⁿ        1    1    1              1/4
Σ  ───────  =  ─── + ─── + ─── + ⋯  =  ───────  =  1/2
n=0  2^(2n+2)   4    8    16           1 − 1/2
```

수치 검증: n = 0..39 까지 부분합이 **0.4999999999995** 로 1/2 에 수렴한다.

따라서 남는 집합 `S` 의 르베그 측도[^측도]는 **1 − 1/2 = 1/2** 다 [10]. 그런데 `S` 는 **어떤 구간도 포함하지 않고**(내부가 공집합), 닫힌집합들의 교집합이므로 **닫혀 있다** [10]. 즉 `S` 는 **아무데도 조밀하지 않으면서(nowhere dense) 측도가 양수**다.

| | 보통 칸토어 집합 | SVC(뚱뚱한 칸토어) 집합 |
|---|---|---|
| 제거 비율 | 매 단계 가운데 1/3 | n단계에 가운데 `1/4ⁿ` |
| 르베그 측도 | **0** | **1/2** |
| 아무데도 조밀하지 않음 | 예 | 예 |
| 닫힌집합 | 예 | 예 |
| 제1범주 | 예 | 예 |

**여기가 요점이다.** 두 집합 모두 위상적으로는 똑같이 작다(제1범주·nowhere dense). 측도로는 하나가 0이고 하나가 1/2 이다. **두 종류의 "작음"이 갈라지는 자리**이고, 리만적분은 측도 쪽을 본다.

역사적으로 이 집합은 1875년 헨리 스미스가 먼저 논의했고 볼테라가 1881년에 비슷한 예를 도입했다 [10].

### 6-2. 볼테라 함수의 구성

부품은 이해편의 그 함수다 [9].

**1단계.** `[0, 1/8]` 안에서 `f′(x) = 0` 인 **가장 큰 x** 를 찾는다. `f′(x) = 2x sin(1/x) − cos(1/x) = 0` 은 `tan(1/x) = 1/(2x)` 와 같고, 수치로 풀면

```
x₀ = 0.092484066532…            (1/8 = 0.125 보다 작다 ✓)

검산 — 인쇄한 이 값을 그대로 넣어 보면
   tan(1/x₀) = 5.406336667
   1/(2x₀)   = 5.406336667      ← 소수 아홉째 자리까지 일치
   f′(x₀)    = 1.4 × 10⁻¹³ ≈ 0
   f(x₀)     = −0.008410635…
```

⚠️ 이 근은 반올림에 예민하다. `x₀` 를 여덟 자리(`0.09248407`)로 잘라 넣으면 `tan(1/x₀)` 이
`5.406324` 로 나와 `1/(2x₀) = 5.406336` 과 **여섯째 자리에서 어긋난다.** `1/x₀ ≈ 10.81` 을
탄젠트에 넣는 구조라 입력 오차가 증폭되기 때문이다. 위에 열두 자리를 실은 이유가 이것이다.

**2단계.** `x₀` 오른쪽으로는 `f(x₀)` 값을 그대로 유지해 `1/8` 까지 상수로 늘인다. 도함수를 0으로 만들어 놓은 지점에서 잘랐으므로 **이어붙인 자리에서도 미분가능성이 유지된다.** 이것이 `x₀` 를 "`f′` 이 0인 마지막 점"으로 고른 이유다.

**3단계.** 이것을 `1/4` 에서 거울로 뒤집어 내려오게 만들고, `[0, 1/4]` 밖에서는 0으로 정의한다. 그런 다음 `[3/8, 5/8]` 로 평행이동한다 — 즉 **SVC 집합 구성에서 처음 제거된 가운데 구간에 정확히 얹는다** [9].

**4단계.** 같은 절차를 `[0, 1/32]` 에서 반복해 두 개의 복사본을 만들고 더한다. **SVC 집합 구성에서 제거되는 모든 구간마다** 이 과정을 반복한 극한이 볼테라 함수 `V` 다 [9]. 애벗은 같은 구성을 "양의 측도를 갖는 칸토어형 집합의 **각 점에** `x² sin(1/x)` 가 원점에서 보이던 행동을 심는 것"으로 서술한다 [15].

### 6-3. `V′` 의 성질과 결론

`V` 는 부품 `f` 와 마찬가지로 **모든 점에서 미분가능**하다 [9]. 그리고 `f′(x) = 2x sin(1/x) − cos(1/x)` 이 0의 임의의 근방에서 값 `+1` 과 `−1` 을 취하므로, **`S` 에서 제거된 각 구간의 양 끝점의 임의의 근방에서 `V′` 이 `+1` 과 `−1` 을 취한다** [9].

결론 세 줄 [9]:

- `V′` 은 **`S` 의 모든 점에서 불연속**이다 — `V` 자신은 `S` 의 모든 점에서 미분가능하고 그 값은 0인데도 그렇다.
- `V′` 은 제거된 각 구간 위에서는 연속이므로, **`V′` 의 불연속점 집합은 정확히 `S`** 다.
- `S` 의 르베그 측도가 양수(1/2)이므로 **`V′` 은 양의 측도를 갖는 집합에서 불연속**이고, **리만적분 가능성에 대한 르베그 판정법**에 의해 **`V′` 은 리만적분 불가능**하다.

**르베그 판정법**: 함수가 리만적분 가능할 필요충분조건은 그 불연속점 집합의 측도가 0인 것이다 [8][9].

**대조 실험이 이 논증을 확정한다.** 같은 구성을 **측도 0인 보통 칸토어 집합**으로 하면 성질 대부분이 그대로인데 **도함수는 리만적분 가능해진다** [9]. 즉 병을 일으킨 범인은 진동도, 불연속의 개수도 아니라 **불연속 집합의 측도**다.

## 7. 미적분 기본정리의 균열

이 반례가 정확히 무엇을 깨는지 보려면 기본정리를 두 문장으로 나란히 놓아야 한다 [8].

**(A) 미적분 기본정리 (참).**

```
f 가 [a,b] 에서 적분가능하고, 어떤 g 에 대해 f = g′ 이면
   ∫ᵃᵇ f = g(b) − g(a)
```

**(B) 기본정리가 아닌 것 (거짓).**

```
f 가 [a,b] 에서 연속이고 (a,b) 에서 미분가능하면
   ∫ᵃᵇ f′ = f(b) − f(a)
```

차이는 **(A)가 "f 가 적분가능하고"를 가정에 넣는 반면 (B)는 그것을 공짜로 얻는다고 착각한다**는 것이다. 볼테라 함수가 (B)의 반례다 — `V` 는 연속이고 모든 점에서 미분가능한데 `∫ V′ dx` 가 **리만 적분으로는 정의되지 않는다** [8][9].

| | 요구 | 볼테라 `V` | 판정 |
|---|---|---|---|
| (A) 가정 1 | `f = g′` | 만족 (`V′ = V′`) | — |
| (A) 가정 2 | `f` 가 적분가능 | **불만족** | (A)는 적용 불가 → 모순 없음 |
| (B) 가정 | `V` 가 연속·미분가능 | 만족 | (B)의 결론이 깨짐 → **(B)는 거짓** |

**"모든 도함수를 적분할 수 있다"는 것은 정리가 아니라 희망이었다.** 리만 적분은 정의역을 잘게 나눠 세로 막대로 근사하는데 [2], 함숫값이 조밀하게 요동치면 어떤 분할을 잡아도 상합과 하합이 붙지 않는다.

**세 갈래의 수습이 있었다.**

1. **르베그 적분** — 정의역이 아니라 **함숫값을 쪼개** 적분을 정의한다 [3]. 측도[^측도]를 먼저 세우고 [4] 그 위에서 적분을 짓는다. `V′` 은 유계이고 가측이므로 **르베그 적분이 존재한다.**
2. **일반화 리만 적분(헨스톡–커즈바일 적분)** — 태그 붙은 분할의 세밀도를 상수가 아닌 함수로 재는 방식으로, 이 문제를 정면으로 고친다 [8].
3. **가정을 명시하기** — (A)처럼 적분가능성을 조건에 적어 두는 것. [8]이 참·거짓 두 버전을 나란히 세워 보이는 것이 정확히 이 구별이다.

## 8. 통합 의미 — 정확한 특성화

지금까지 "이건 안 된다"를 세 겹 쌓았고, 볼테라가 "여기까진 된다"를 보였다. **정확한 경계선은 어디인가.** 답이 있다.

**정리 (브루크너–레너드, 1966).** `E ⊂ [a,b]` 가 어떤 도함수의 불연속점 집합이 될 **필요충분조건**은, `E` 가 **닫힌집합들의 가산합집합(Fσ)이면서 제1범주(meagre)** 인 것이다 [8][12].

위키백과는 같은 사실을 양방향으로 적는다 — 도함수의 불연속점 집합은 제1범주 Fσ 이고, **역으로 실직선의 모든 제1범주 Fσ 부분집합이 어떤 도함수의 불연속점 집합으로 실현된다** [7][12].

**이 정리로 앞의 예들이 제자리를 찾는다.**

| 집합 | Fσ? | 제1범주? | 도함수의 불연속점 집합이 될 수 있나 |
|---|---|---|---|
| 한 점 `{0}` | 예 | 예 | **가능** — `x² sin(1/x)` |
| 유리수 `ℚ` | 예 | 예 | **가능** — 폼페이우형 구성 |
| SVC 집합 `S` (측도 1/2) | 예 (닫힌집합) | 예 | **가능** — 볼테라 함수 |
| 실직선 `ℝ` 전체 | 예 | **아니오** | **불가능** — 디리클레 함수가 도함수일 수 없는 이유 |

**측도는 이 판정에 들어오지 않는다.** 그래서 측도 1/2 짜리 불연속 집합이 허용되고, 그 허용이 리만적분을 깨뜨린 것이다. 위상적 조건(제1범주)과 측도적 조건(리만적분 가능성)이 **서로 다른 것을 재고 있다**는 사실이 이 주제 전체의 요점이다.

**더 미세한 제약도 있다.** 자호르스키(Zahorski)는 도함수의 준위집합 `{x : f(x) > a}` 가 자기 점들 근처에서 얼마나 커야 하는지를 등급 `M₀, …, M₅` 로 나눴고, 다음이 성립한다 [7][13].

- 모든 **유한 도함수**의 준위집합은 `M₃` 에 속한다.
- 모든 **유계 도함수**의 준위집합은 `M₄` 에 속하며, 역으로 `M₄` 에 속하는 집합은 어떤 유계 도함수의 준위집합이다(**필요충분**) [13].

직관적으로 `M₃` 는 "점 근처에 큰 구멍이 없어야 한다", `M₄` 는 "점 근처에서 일정 비율 이상을 차지해야 한다"는 밀도 조건이다 [7].

**마지막으로 한 예를 덧붙인다 — 폼페이우 함수** [8]. `{qₙ}` 을 `[0,1]` 의 유리수 열거, `ΣAₙ < ∞` 인 양수열이라 할 때

```
      ∞
f(x) = Σ Aₙ · ∛(x − qₙ)
     n=1
```

는 바이어슈트라스 M-판정으로 수렴하고, **순증가하며 미분가능**한데 그 **도함수가 조밀한 집합에서 0** 이 된다 [8]. 순증가 함수의 도함수가 조밀하게 0이라는 것은 상당히 반직관적이고, "도함수가 조밀한 집합에서 병리적일 수 있다"의 또 다른 표본이다.

## 10. 함정·체크리스트

- [ ] **"`lim_{x→a} f′(x)` 를 구해 `f′(a)` 로 삼는다"는 극한이 존재할 때만 유효하다** [8][14]. 존재하지 않으면 이 절차는 아무 말도 하지 않는다 — 정의로 돌아가야 한다.
- [ ] **"`f′` 이 `a` 에서 좌극한 1, 우극한 2"라는 설정은 그 자체로 모순이다.** 점프 도함수는 존재하지 않는다 [8].
- [ ] **사잇값 성질을 만족한다고 도함수인 것은 아니다** [7]. 다르부 정리는 필요조건이고, 충분조건은 §8의 Fσ·제1범주 특성화다.
- [ ] **"불연속점이 유한/가산이면 리만적분 가능"은 참이지만 그 역은 거짓이다.** 판정 기준은 개수가 아니라 **측도 0** 이다 [8][9].
- [ ] **제1범주(위상적으로 작음)와 측도 0(측도적으로 작음)을 같은 것으로 쓰지 말 것.** SVC 집합이 반례다 — 제1범주인데 측도 1/2 이다 [10].
- [ ] **"모든 도함수는 적분하면 원래 함수로 돌아온다"는 리만 적분에서 거짓이다** [8][9]. 기본정리 서술에서 적분가능성 가정을 지우지 말 것.
- [ ] **볼테라 함수를 "미분 불가능한 괴물"로 오해하지 말 것.** `V` 는 **모든 점에서 미분가능**하다. 괴물인 것은 `V` 가 아니라 `V′` 이다 [9].
- [ ] **`x²sin(1/x)` 와 `x sin(1/x)` 를 섞지 말 것.** 후자는 0에서 연속이지만 **미분가능하지 않다**. 지수 2가 미분가능성을 만들고, 지수 2에서 딱 도함수 불연속이 남는다.

## 후속 질문·연결

- **복소함수에서는 왜 이 병리가 없나?** 복소미분가능(정칙)하면 무한 번 미분가능하고 해석적이다. 실수의 "한 번 미분가능"이 얼마나 약한 조건인지가 이 대비로 드러난다.
- **`V′` 은 르베그 적분되는데, 그러면 르베그 적분에서 기본정리는 완전한가?** 아니다. 완전한 형태는 **절대연속 함수**에 대해 성립한다 — 미분가능성만으로는 부족하고, 칸토어 함수(악마의 계단)가 그 반례다.
- **도함수가 조밀한 집합에서 불연속인데도 함수 자체는 매끈해 보이는 이유는?** 도함수의 병리가 적분되면서 평균화되기 때문이다. `V` 의 그래프는 눈으로 보면 부드럽다 [9].
- **수치미분·자동미분은 이 문제를 어떻게 겪나?** 조각별 정의 함수에서 자동미분이 경계점에서 뱉는 값은 "한쪽 도함수"이며, 다르부 정리가 금지하는 점프를 소프트웨어는 아무렇지 않게 만들어 낸다 — 수학적 대상과 계산 대상이 갈라지는 지점이다.
