# 양력의 정량 이론 (확장편)

> 이해편은 **"흐름을 아래로 꺾은 반작용"**이라는 정성적 답에 도달했다. 그런데 공학은 **숫자**를 요구한다 — 이 날개가 이 속도에서 **정확히 몇 뉴턴**을 낼 것인가? 그 답이 **쿠타–주코프스키 정리** `L′ = ρ·V·Γ`이며, 여기서 **순환 Γ**가 양력의 정체를 하나의 수로 압축한다. 이 글은 **순환이 무엇이고 어디서 오는지**(쿠타 조건과 점성), **왜 무한날개와 유한날개가 다른지**(유도항력), 그리고 **왜 양력에 한계가 있는지**(실속)를 정량적으로 다룬다.

## TL;DR
- **양력계수**: 실무의 출발점은 `L = ½ · ρ · V² · S · C_L`. 양력은 **속도의 제곱**에 비례하고, 형상·받음각의 효과는 전부 **무차원 계수 C_L**에 담긴다 [6].
- **순환 Γ**: 날개를 둘러싼 닫힌 경로에서 속도를 선적분한 값 `Γ = ∮ v · dl`. 이것이 0이 아니면 양력이 생긴다 [7].
- **쿠타–주코프스키 정리**: 2차원 날개의 단위 길이당 양력은 **`L′ = ρ · V∞ · Γ`** — 밀도·속도·순환의 곱, 그뿐이다 [7][8].
- **순환은 어디서 오나 — 쿠타 조건**: 이상유체 이론만으로는 Γ가 정해지지 않는다(무한히 많은 해가 존재). **"흐름은 뾰족한 뒷전을 매끄럽게 떠난다"**는 조건이 Γ를 **하나로 확정**한다 [9].
- **그 조건을 만드는 것은 점성**: 출발 순간 뒷전에서 **시작 와류**가 떨어져 나가고, 그 반작용으로 날개 주위에 **반대 방향 순환**이 남는다(켈빈의 순환 정리) [10].
- **유한날개의 대가**: 날개 끝에서 압력이 새어 **익단 와류**가 생기고, 이것이 **내리흐름 → 유효 받음각 감소 → 유도항력**을 낳는다. `C_Di = C_L² / (π·AR·e)` [11].
- **한계는 실속**: 받음각이 임계를 넘으면 경계층이 **박리**되어 C_L이 급락한다 [4][12].

## 핵심 포인트
1. **C_L은 형상과 받음각의 함수**이고, 얇은 날개 이론에서 `C_L ≈ 2π·α`(라디안) [8].
2. **Γ ≠ 0이 양력의 필요충분 조건**(2차원 비점성 이론에서) [7].
3. **쿠타 조건이 없으면 양력은 계산 불가** — 수학적으로 해가 무한히 많다 [9].
4. **점성이 없으면 애초에 순환이 생기지 않는다** — 달랑베르의 역설 [10].
5. **가로세로비(AR)가 클수록 유도항력이 작다** — 글라이더 날개가 긴 이유 [11].
6. **모든 것은 결국 압력 적분**이고, 순환은 그것을 요약한 수다.

## 1. 실무의 출발점 — 양력 방정식

항공공학에서 양력은 다음 식으로 다룬다 [6].

`L = ½ · ρ · V² · S · C_L`

| 기호 | 뜻 | 단위 |
|---|---|---|
| L | 양력 | N |
| ρ | 공기 밀도 | kg/m³ |
| V | 대기속도 | m/s |
| S | 날개 면적 | m² |
| **C_L** | **양력계수**(무차원) | — |

`½ρV²`는 **동압(dynamic pressure)**이고 — 베르누이 정리에서 속도가 만드는 압력 항이 바로 이것이다 [1][2] — 나머지 물리는 전부 **C_L 하나**에 압축된다. 여기서 L은 이해편과 같이 **흐름에 수직인 성분**을 뜻한다 [3]. C_L은 **받음각·날개 형상·레이놀즈수·마하수**의 함수다.

> **속도의 제곱**에 비례한다는 점이 실전에서 결정적이다. 속도를 2배로 하면 양력은 **4배**가 된다. 반대로 착륙처럼 느리게 날아야 할 때는 **C_L을 키워야** 하고, 그래서 **플랩**을 내려 캠버와 면적을 늘린다.

### 1-1. 얇은 날개 이론의 결과
2차원 얇은 날개에 대한 이론적 결과는 놀랍도록 단순하다 [8].

`C_L = 2π · α`  (α는 라디안 단위의 받음각, 캠버가 없는 대칭 날개 기준)

라디안을 도(°)로 바꾸면 **받음각 1°당 C_L이 약 0.11 증가**한다. 실제 측정값도 실속 전까지는 이 기울기에 상당히 가깝다. 캠버가 있으면 이 직선이 **왼쪽으로 평행이동**해, **받음각 0에서도 C_L > 0**이 된다 — 이해편에서 "캠버는 효율을 높이는 설계"라 한 것의 정량적 표현이다.

```
  C_L
   │           ╱‾╲  ← 실속(박리)
   │         ╱    ╲
   │       ╱
   │     ╱  기울기 ≈ 2π (라디안당)
   │   ╱
   │ ╱
   └─────────────────── α (받음각)
    0        약 15°
```

## 2. 순환 — 양력을 하나의 수로

### 2-1. 정의
**순환(circulation) Γ**[^순환]는 유체 속의 닫힌 경로 C를 따라 **속도의 접선 성분을 선적분**한 값이다 [7].

`Γ = ∮_C v · dl`

날개를 감싸는 경로에서 이 값을 재면, **날개 위쪽에서 흐름이 빠르고 아래쪽에서 느린 만큼** 0이 아닌 값이 나온다.

```
      ← ← ← ← ← ←   (윗면: 자유흐름 + 순환 성분 → 빨라짐)
    ╱‾‾‾‾‾‾‾‾‾‾‾╲
   │   날개 단면   │   ← 이 경로를 따라 v·dl 적분 = Γ
    ╲___________╱
      → → → → →     (화살표는 '순환 성분'만 그린 것.
                     아랫면 실제 흐름은 여전히 왼쪽으로 가되 느려질 뿐이다)
```

**직관적으로**: 균일한 자유흐름 위에 **날개를 도는 회전 성분**이 얹혀 있다고 보는 것이다. 이 회전이 윗면에서는 흐름과 **같은 방향**이라 속도를 더하고, 아랫면에서는 **반대 방향**이라 속도를 뺀다. 그 결과가 압력 차이다.

(같은 베르누이 관계가 분무기·커브볼처럼 일상에서도 관찰된다 [5].)

> 주의: **공기가 실제로 날개를 빙글빙글 도는 것은 아니다.** Γ는 흐름의 **비대칭성을 하나의 수로 요약한 양**이며, 실제 유체 입자는 날개를 지나쳐 갈 뿐이다.

### 2-2. 쿠타–주코프스키 정리
20세기 초 **마르틴 쿠타**와 **니콜라이 주코프스키**가 각각 도달한 결과가 항공역학의 초석이 되었다 [7].

> **쿠타–주코프스키 정리**: 비압축·비점성·2차원 흐름에서, 스팬 **단위 길이당 양력**은
> `L′ = ρ · V∞ · Γ`
> 이다. (ρ: 밀도, V∞: 자유흐름 속도, Γ: 순환)

놀라운 점은 **날개의 모양이 식에 등장하지 않는다**는 것이다. 형상이 어떻든, 그것이 만들어 낸 **Γ만 같으면 양력이 같다.** 형상의 역할은 **"주어진 받음각에서 얼마나 큰 Γ를 만드느냐"**로 완전히 흡수된다.

**이해편과의 연결**: 이 정리는 이해편의 두 관점을 **하나의 수식으로 통합**한다. Γ는 압력 분포(베르누이)로도, 운동량 플럭스(뉴턴)로도 계산할 수 있고 **같은 값이 나온다** [12][13]. 즉 "뉴턴이냐 베르누이냐"라는 물음은 이 단계에서 **하나의 수 Γ로 수렴**한다.

## 3. 순환은 어디서 오나 — 쿠타 조건

### 3-1. 이론의 결함
여기서 고전 유체역학의 **곤란한 문제**가 등장한다. 비점성·비회전 흐름 이론(퍼텐셜 유동)으로 날개 주위 흐름을 풀면, **Γ 값이 다른 무한히 많은 해**가 전부 방정식을 만족한다. 즉 **수학만으로는 양력이 정해지지 않는다** [9].

각 해는 **뒷전 부근의 흐름 모양**이 다르다.

| Γ 값 | 뒷전에서의 흐름 |
|---|---|
| 너무 작으면 | 흐름이 아랫면에서 뒷전을 **돌아 올라온다** |
| 너무 크면 | 흐름이 윗면에서 뒷전을 **돌아 내려간다** |
| **딱 맞으면** | 흐름이 뒷전을 **매끄럽게 떠난다** |

### 3-2. 쿠타 조건
실제 관측은 명확하다 — **흐름은 뾰족한 뒷전을 매끄럽게 떠난다.** 뒷전을 돌아 급격히 꺾이는 흐름은 **무한대의 속도와 가속도**를 요구하므로 물리적으로 불가능하다.

> **쿠타 조건(Kutta condition)**[^쿠타조건]: 뾰족한 뒷전을 가진 날개에서, 흐름은 **뒷전에서 매끄럽게 떨어져 나간다.** 이 조건이 만족되도록 **Γ가 유일하게 결정된다** [9].

```
   ❌ Γ 부족            ❌ Γ 과다           ✅ 쿠타 조건 만족
    ╲___                ╲___               ╲___
        ↰(돌아 올라옴)       ↱(돌아 내려감)        →→ (매끄럽게 떠남)
```

이것으로 **양력이 계산 가능해진다.** 쿠타 조건은 수학적 공리가 아니라, **점성이 실제로 강제하는 물리적 사실을 비점성 이론에 끼워 넣은 경계조건**이다.

## 4. 점성의 역할 — 시작 와류와 켈빈의 정리

### 4-1. 왜 점성이 필요한가
비점성 유체만 있으면 어떤 일이 벌어질까? 두 가지를 구분해야 한다.
- **달랑베르의 역설**: 정상·비점성·비회전 흐름에서는 물체에 작용하는 **항력이 0**이 된다. (양력이 불가능하다는 뜻은 **아니다** — 순환 Γ만 주어지면 쿠타–주코프스키로 양력이 나온다.)
- **정지 상태에서 순환을 만들 수 없다**: **켈빈의 순환 정리**에 따라 비점성 유체에서는 전체 순환이 보존되므로, 순환이 0인 상태에서 저절로 Γ가 생겨날 수 없다. **그 대칭을 깨는 것이 점성**이다 [10].

즉 실제로 양력이 생기는 것은 **점성이 순환을 만들어 주기 때문**이다.

### 4-2. 시작 와류 — 출발 순간에 일어나는 일
정지해 있던 날개가 갑자기 움직이기 시작하면 다음 순서로 진행된다 [10].

1. **처음 순간**: 순환이 0이다. 흐름이 아랫면에서 뒷전을 **돌아 올라오려** 한다(쿠타 조건 위반 상태).
2. **점성의 개입**: 뒷전을 돌아 올라오는 흐름은 **극심한 속도 기울기**를 만들고, 점성 때문에 그 부분이 **말려 들어가 와류**가 된다.
3. **떨어져 나감**: 이 와류가 날개에서 분리되어 뒤로 흘러간다 → **시작 와류(starting vortex)**.
4. **반작용**: 이 와류를 **시작 와류**[^시작와류]라 하며, **켈빈의 순환 정리**에 따라 **전체 순환은 보존**되어야 한다. 시작 와류가 **한 방향 순환 −Γ**를 가져갔으므로, 날개 주위에는 **반대 방향 순환 +Γ**가 남는다 → **속박 와류(bound vortex)**.
5. **정상 상태**: 이 +Γ가 정확히 **쿠타 조건을 만족시키는 값**이 되고, 그때부터 양력이 안정적으로 발생한다.

```
   출발 직후                    잠시 후
   ┌─────────┐                 ┌─────────┐
   │  날개 →  │                 │  날개 ↺→ │  ← 속박 순환 +Γ (양력 발생)
   └─────────┘                 └─────────┘
        ↻ 와류 생성                          ↻ 시작 와류 −Γ (뒤에 남겨짐)
   (전체 순환 = 0 유지: +Γ와 −Γ가 상쇄)
```

> 이것이 **"왜 양력은 공짜가 아닌가"**의 답이다. 순환은 저절로 생기지 않고, **점성이 뒷전에서 와류를 하나 떼어 낸 대가**로 얻어진다.

## 5. 무한날개에서 유한날개로 — 진짜 비행기

지금까지는 **2차원(무한히 긴 날개)** 이야기였다. 실제 날개는 **끝이 있다.** 이 차이가 결정적인 결과를 낳는다 [11].

### 5-1. 익단 와류
날개 아랫면은 압력이 높고 윗면은 낮다. 그러면 **날개 끝(익단)에서 공기가 아래에서 위로 돌아 넘어간다.** 여기에 전진 운동이 겹쳐 **거대한 소용돌이**가 날개 끝에서 뒤로 뻗는다 — **익단 와류(wingtip vortex)**.

비행운이 날개 끝에서 두 줄로 말려 나가는 장면이 바로 이것이다. 대형기 뒤에서는 이 와류가 **수 분간 지속**되어 뒤따르는 항공기에 위험하므로, 관제에서 **이착륙 간격을 강제**한다.

### 5-2. 유도항력 — 양력의 필연적 대가
익단 와류는 날개 전체에 **추가적인 내리흐름**을 만든다. 그 결과:

1. 날개가 실제로 느끼는 **유효 받음각이 줄어든다.**
2. 양력 벡터가 **뒤로 기울어진다.**
3. 그 뒤로 기운 성분이 **항력**으로 나타난다 → **유도항력(induced drag)**[^유도항력].

`C_Di = C_L² / (π · AR · e)`

| 기호 | 뜻 |
|---|---|
| AR | **가로세로비**[^가로세로비] = 날개폭² / 날개면적 |
| e | 오스왈드 효율 계수(타원 분포면 1, 보통 0.7~0.9) |

**두 가지 중요한 결론**
- **C_L의 제곱**에 비례 → **느리게 날수록**(C_L을 키워야 하므로) 유도항력이 급증한다. 이착륙 때 항력이 큰 이유다.
- **AR에 반비례** → 날개가 **길고 가늘수록** 유도항력이 작다. **글라이더의 날개가 극단적으로 긴 이유**이고, 여객기가 **윙렛**을 다는 이유이기도 하다(익단 와류를 억제).

> 유도항력은 **양력을 만드는 행위 자체가 낳는 항력**이다. 공기 저항(마찰·형상항력)과 달리, **매끈하게 만든다고 없앨 수 없다.**

## 6. 한계 — 경계층과 실속

### 6-1. 경계층
점성 때문에 날개 표면 바로 옆의 공기는 **표면에 붙어 정지**하고(무활조건), 거기서 조금 떨어지면 자유흐름 속도에 도달한다. 이 얇은 층이 **경계층**이다.

### 6-2. 박리와 실속
날개 윗면 뒤쪽에서는 압력이 다시 높아지는데(**역압력 구배**), 경계층 안의 느린 공기는 이 압력 언덕을 **넘지 못하고 멈추거나 역류**한다. 그러면 흐름이 표면에서 **떨어져 나간다** — **박리(separation)** [12].

받음각이 커질수록 이 압력 언덕이 가팔라져 박리점이 앞으로 이동하고, 임계 받음각(여객기 기준 대략 **15° 안팎**, 형상에 따라 다름)을 넘으면 윗면 대부분에서 흐름이 떨어져 **C_L이 급락**한다 — **실속(stall)** [4].

| 상태 | 흐름 | C_L | 항력 |
|---|---|---|---|
| 정상 | 표면에 붙어 흐름 | α에 비례해 증가 | 작음 |
| 실속 직전 | 뒤쪽부터 박리 시작 | 최대 | 증가 |
| **실속** | **윗면 대부분 박리** | **급락** | **급증** |

**회복 방법이 역설적인 이유**: 실속은 "속도가 느려서"가 아니라 **"받음각이 커서"** 생긴다. 그래서 회복은 **기수를 낮춰 받음각을 줄이는 것**이다. 본능적으로 기수를 들면 상황이 악화된다.

> 그래서 실속은 **어떤 속도에서도** 일어날 수 있다. 고속에서 급격히 기수를 당기면 **고속 실속**이 발생한다.

## 7. Worked Examples — 숫자로 확인하기

**예 1) 여객기의 순항 양력계수**
질량 70,000 kg, 날개 면적 S = 122 m², 고도 10 km(ρ ≈ 0.414 kg/m³), 속도 V = 250 m/s인 항공기의 순항 C_L을 구하자.
수평 비행이므로 `L = W = 70,000 × 9.8 = 686,000 N`.
`C_L = 2L / (ρ·V²·S) = 2 × 686,000 / (0.414 × 250² × 122)`
분모 = `0.414 × 62,500 × 122 = 3,156,750`
`C_L = 1,372,000 / 3,156,750 ≈ 0.435`
→ 순항 C_L은 대략 **0.4~0.5** 범위이며, 계산 결과가 그 안에 들어온다.

**예 2) 순환 Γ 구하기**
위 조건에서 날개폭 36 m로 양력이 균일하게 분포한다고 단순화하면, 단위 길이당 양력은
`L′ = 686,000 / 36 ≈ 19,056 N/m`
쿠타–주코프스키에서
`Γ = L′ / (ρ·V) = 19,056 / (0.414 × 250) = 19,056 / 103.5 ≈ 184 m²/s`
(실제 분포는 타원에 가까워 중앙이 더 크고 끝이 0이지만, 규모 감각으로는 충분하다.)

**예 3) 속도와 받음각의 맞바꿈**
같은 무게를 유지하려면 `½ρV²S·C_L`이 일정해야 한다. 속도가 절반으로 줄면 V²이 **1/4**이 되므로, **C_L은 4배**가 되어야 한다. 얇은 날개 이론 `C_L ≈ 2πα`로 보면 **받음각도 약 4배** 필요하다.
> ⚠️ 단, 이 비례는 **실속 전 선형 구간에서만** 성립한다. 실제로 예1의 순항 상태(C_L ≈ 0.435 → α ≈ 4°)에서 속도를 절반으로 줄이면 α가 약 16°가 되어 **§6의 임계 받음각(~15°)을 이미 넘어선다.** 그래서 저속에서는 받음각만으로 버틸 수 없고 **플랩으로 C_L 자체를 키워** 여유를 만드는 것이다. (캠버가 있는 날개에서는 α를 **양력 0 받음각 기준**으로 재야 한다.)

**예 4) 유도항력 비교**
C_L = 0.5, e = 0.8일 때
- 여객기(AR = 9): `C_Di = 0.25 / (π × 9 × 0.8) = 0.25 / 22.6 ≈ 0.0111`
- 글라이더(AR = 30): `C_Di = 0.25 / (π × 30 × 0.8) = 0.25 / 75.4 ≈ 0.0033`
글라이더가 **약 1/3.3**으로 작다. C_Di는 AR에 **정확히 반비례**하므로, 이 비는 가로세로비의 비 30/9 = 3.33과 정확히 같다 — **가로세로비를 3.3배 키운 효과가 그대로** 나타난 것이다.

## 8. 흔한 함정

1. **"순환은 공기가 날개를 도는 것이다."** → 아니다. Γ는 **선적분 값**이며, 실제 입자는 날개를 지나쳐 간다.
2. **"쿠타 조건은 수학적으로 증명된다."** → 아니다. **관측된 물리(점성의 결과)를 비점성 이론에 넣은 경계조건**이다 [9].
3. **"비점성 이론이면 점성은 무시해도 된다."** → 순환을 **만드는 것**이 점성이다. 점성이 없으면 정지 상태에서 Γ가 생겨날 수 없다(켈빈의 순환 정리). 달랑베르의 역설은 그와 별개로 **항력이 0이 된다**는 결과다 [10].
4. **"유도항력은 잘 만들면 없앨 수 있다."** → **양력을 만드는 한 반드시 따라온다.** 줄일 수는 있어도(높은 AR·윙렛) 0으로는 못 만든다 [11].
5. **"실속은 속도가 느려서 생긴다."** → **받음각** 때문이다. 고속에서도 실속한다 [4].
6. **"쿠타–주코프스키에 형상이 없으니 형상은 무관하다."** → 형상은 **Γ를 결정하는 과정**에 들어 있다. 식에 안 보일 뿐이다.
7. **"2차원 이론으로 실제 날개를 계산할 수 있다."** → 유한날개에서는 **내리흐름 보정**이 필수다. 3차원 효과가 유효 받음각을 바꾼다 [11].

## 9. 한눈 요약

| 개념 | 식·관계 | 의미 |
|---|---|---|
| 양력 방정식 | `L = ½ρV²S·C_L` | 실무의 출발점, V²에 비례 |
| 얇은 날개 | `C_L ≈ 2πα` | 받음각 1°당 약 0.11 |
| 순환 | `Γ = ∮ v·dl` | 흐름 비대칭성의 요약 |
| **쿠타–주코프스키** | **`L′ = ρ·V∞·Γ`** | 양력 = 밀도 × 속도 × 순환 |
| 쿠타 조건 | 뒷전에서 매끄럽게 이탈 | Γ를 **유일하게** 결정 |
| 켈빈 정리 | 전체 순환 보존 | 시작 와류 ↔ 속박 와류 |
| 유도항력 | `C_Di = C_L²/(π·AR·e)` | 양력의 필연적 대가 |
| 실속 | 임계 α에서 박리 | C_L 급락, 회복은 기수 낮추기 |

**마지막 한 줄** — 이해편의 "흐름을 아래로 꺾는다"는 말은, 정량적으로 옮기면 **"순환 Γ를 만든다"**가 된다. 그리고 그 Γ는 **점성이 뒷전에서 와류 하나를 떼어 낸 대가**로 얻어지며, 유한한 날개에서는 **유도항력이라는 청구서**가 따라붙는다. 양력은 공짜가 아니라, **정확히 계산 가능한 값을 지불하고 사는 힘**이다.

[^순환]: 순환(circulation, Γ) — 유체 속 닫힌 경로를 따라 속도의 접선 성분을 선적분한 값. 날개를 감싸는 경로에서 0이 아니면 양력이 발생하며, 흐름의 비대칭성을 하나의 수로 요약한 양이다. 실제로 공기가 회전한다는 뜻은 아니다.
[^쿠타조건]: 쿠타 조건(Kutta condition) — 뾰족한 뒷전을 가진 날개에서 흐름이 뒷전을 매끄럽게 떠난다는 조건. 비점성 이론에서 무한히 많던 해 중 물리적으로 실현되는 하나를 골라 주며, 실제로는 점성이 강제하는 결과다.
[^시작와류]: 시작 와류(starting vortex) — 날개가 움직이기 시작할 때 뒷전에서 말려 떨어져 나가는 와류. 켈빈의 순환 정리에 따라 전체 순환이 보존되므로, 이 와류가 가져간 순환의 반대 부호만큼이 날개 주위에 속박 순환으로 남는다.
[^유도항력]: 유도항력(induced drag) — 유한한 길이의 날개에서 익단 와류가 만든 내리흐름 때문에 양력 벡터가 뒤로 기울며 생기는 항력. 양력을 만드는 한 반드시 따라오며, 가로세로비를 키우거나 윙렛으로 줄일 수 있다.
[^가로세로비]: 가로세로비(aspect ratio, AR) — 날개폭의 제곱을 날개 면적으로 나눈 값. 길고 가는 날개일수록 크며, 유도항력이 AR에 반비례하므로 글라이더처럼 효율이 중요한 항공기는 AR을 극단적으로 키운다.
