# 전단변환 실전 (확장편) — 불변량으로 심화문제를 부수는 법

> 이해편이 **"전단변환이 무엇이고 무엇을 보존하나"**였다면, 확장편은 **"그래서 시험장에서 뭘 하느냐"**다. 핵심은 단 하나의 정리다 — **전단변환은 곡선과 직선의 차 f − ℓ을 전혀 바꾸지 않는다** [6]. 이 한 줄에서 삼차함수의 **세 교점 대칭**, **접선 마스터 항등식**, **1/12 넓이 공식**, **16:1 넓이비**, 그리고 사차함수의 **네 교점 대칭**이 전부 쏟아져 나온다. 이 글은 그 유도와 **문제 유형별 사용법**, 그리고 **언제 이 무기를 쓰면 안 되는지**까지 정리한다.

## TL;DR
- **마스터 정리(f − ℓ 불변성)**: 전단 f → f + kx를 걸면 직선 ℓ도 ℓ + kx가 된다. 따라서 **차 f − ℓ은 그대로**다. 곡선과 직선의 **교점 x좌표·접점·둘러싸인 넓이가 전부 전단 불변** [6][7].
- **삼차 세 교점 대칭**: 삼차함수와 **어떤 직선**이 세 점에서 만나든, 그 x좌표의 **합은 항상 −b/a**. 즉 **평균 = −b/3a = 변곡점의 x좌표** [3][10].
- **사차 네 교점 대칭**: 사차함수와 직선이 네 점에서 만나면 x좌표의 **평균은 항상 −b/4a**로 일정. 네 교점이 그 축에 대해 **대칭 배치**된다 [9][11].
- **접선 마스터 항등식**: 접점 t, 재교점 s → **s = −b/a − 2t**. y = ax³로 표준화하면 **s = −2t**로 자명해진다 [4][8].
- **넓이 공식의 정체**: 1/12·1/30 공식은 **전단으로 직선을 수평으로 눕힌 뒤 y = ax³에서 잰 넓이**다. 그래서 계수 |a|와 교점 거리만으로 결정된다 [5][7].
- **전단 면역 판정법**: 문제의 조건과 결론이 **x좌표·넓이·(곡선−직선) 구조로만** 쓰여 있으면 전단 불변 → 표준형으로 옮겨 풀어도 안전. **극값·기울기·길이·각도**가 끼면 불변이 아니다 [4].

## 핵심 포인트
1. **f − ℓ 불변성**이 모든 것의 뿌리. 곡선 대 직선 구도는 전부 전단 불변 [6].
2. **표준화 3단계**: 변곡점을 원점으로 → 전단으로 일차항 제거 → **y = ax³**에서 계산 [8].
3. 삼차: 직선과의 교점 **x좌표 합 = −b/a** (직선이 무엇이든 일정) [3].
4. 사차: 평행이동 + 전단으로 **ax⁴ + px²** (짝함수) → **네 교점 대칭** [9][11].
5. **극값·기울기 문제에는 쓰지 말 것.** 전단이 극점을 옮기고 없애기도 한다 [10].
6. 극값 조건도 **"직선과 접하는 구도"로 번역**하면 다시 불변이 된다.

## 1. 마스터 정리 — 전단은 f − ℓ을 건드리지 못한다

이해편에서 전단변환이 **함수에 일차항 kx를 더하는 변환**임을 봤다 [6]. 여기서 결정적인 관찰이 나온다.

곡선 y = f(x)와 직선 y = ℓ(x)가 있다고 하자. 전단 S(k)를 걸면 **둘 다** 같은 kx가 더해진다:

`f(x) → f(x) + kx` ,  `ℓ(x) → ℓ(x) + kx`

그런데 직선에 일차항을 더해도 **여전히 직선**이다(기울기만 바뀐다). 그리고 두 식의 차는

`(f + kx) − (ℓ + kx) = f − ℓ`

**완전히 그대로다.** 이것이 마스터 정리다.

> **마스터 정리.** 전단변환은 "곡선과 직선"의 차 f − ℓ을 불변으로 둔다. 그러므로 다음이 모두 **전단 불변**이다.
> - 곡선과 직선의 **교점 x좌표**(= f − ℓ = 0의 근)
> - **접점**과 그 **중근 구조**(= f − ℓ의 중근)
> - 두 도형이 **둘러싸는 넓이**(= ∫|f − ℓ|) [7]

왜 강력한가? 시험에 나오는 삼차함수 심화문제의 **대부분이 "곡선과 직선"의 구도**이기 때문이다. 접선, 할선, 수평선, 극값을 지나는 선 — 전부 직선이다. 그 문제들은 **하나도 빠짐없이 y = ax³로 옮겨서 풀 수 있다.**

넓이가 함께 보존되는 근거도 다시 확인해 두자. 전단은 덧셈·상수배를 보존하는 **선형변환(일차변환)**이고 [1], 평면의 선형변환은 하나의 행렬로 표현된다 [2]. 그 행렬은 대각선이 1이고 한쪽 구석에만 k가 있어 **행렬식이 언제나 1**이며 [12], **|행렬식| = 넓이 배율**이므로 넓이가 그대로다 [7]. 즉 이 글의 모든 넓이 논증은 **det = 1**이라는 한 줄에 기대고 있다.

## 2. 불변량 전략 — 3단계 루틴

심화문제에서 실제로 쓰는 절차는 이렇다.

**1단계 — 표준화(옮기기).** 변곡점을 원점으로 평행이동하고, 전단으로 일차항을 없애 **y = ax³**로 만든다 [8]. x좌표는 평행이동한 만큼만 밀리고 전단으로는 **전혀 안 밀린다**는 점을 기억한다.

**2단계 — 쉬운 곳에서 풀기.** y = ax³는 **기함수(원점 대칭)**라 계산이 극적으로 단순하다. 여기서 교점 x좌표·넓이를 구한다.

**3단계 — 되돌리기.** x좌표는 평행이동분만 더해 주면 되고, **넓이는 손댈 필요조차 없다**(전단·평행이동 모두 넓이 보존).

```
원래 문제 ──표준화──▶ y = ax³ 에서의 쉬운 문제
   │                        │
   │                     (풀이)
   ▼                        ▼
정답 ◀──되돌리기(x는 평행이동만, 넓이는 그대로)──┘
```

> 요령: 많은 경우 **1·3단계를 실제로 계산할 필요도 없다.** "어차피 불변이니까 표준형에서의 값이 곧 답"이라는 것만 알면 되기 때문이다.

## 3. 삼차함수의 세 교점 — 합이 일정하다

가장 활용도 높은 불변량부터 보자.

삼차함수 f(x) = ax³ + bx² + cx + d와 **임의의 직선** ℓ(x) = mx + n이 세 점에서 만난다고 하자. 교점의 x좌표는 f − ℓ = 0의 근이다. 그런데

`f(x) − ℓ(x) = ax³ + bx² + (c − m)x + (d − n)`

에서 **x³ 계수와 x² 계수는 직선의 영향을 전혀 받지 않는다.** 따라서 근과 계수의 관계[^근과계수]로 [3]:

`x₁ + x₂ + x₃ = −b/a`   (직선 ℓ이 무엇이든 **항상 같다**)

즉 **평균**은

`(x₁ + x₂ + x₃)/3 = −b/3a = 변곡점의 x좌표`

> **정리.** 삼차함수와 직선의 세 교점은 **그 x좌표의 평균이 언제나 변곡점의 x좌표**다. 직선을 아무리 돌리고 올려도 이 무게중심은 **꿈쩍하지 않는다** [3][10].

이것은 이해편에서 본 **변곡점이 전단 불변**이라는 사실과 정확히 짝을 이룬다. 직선을 바꾸는 것은 (수직 이동을 곁들인) 전단을 거는 것과 같고, 전단은 변곡점을 안 옮기니 무게중심도 안 옮기는 것이다.

**즉시 따라오는 따름정리**
- 두 교점의 x좌표를 알면 **셋째는 자동**: x₃ = −b/a − x₁ − x₂.
- 직선이 변곡점을 지나면 나머지 두 교점은 **변곡점에 대해 대칭**.
- 삼차함수와 직선이 **한 점에서 접하고 다른 한 점에서 만나면** 근이 (t, t, s)이므로 **2t + s = −b/a** → 이것이 다음 절의 마스터 항등식이다.

## 4. 접선 마스터 항등식 — 표준형에서는 자명하다

**주장**: 삼차함수 위의 점 x = t에서 그은 접선이 곡선과 다시 만나는 점의 x좌표는

`s = −b/a − 2t`

**표준형 유도(전단 관점).** 표준화해서 f(x) = ax³라 하자(변곡점 원점, b = 0이므로 s = −2t를 보이면 된다).
- x = t에서의 접선: 기울기 f′(t) = 3at²이므로 `ℓ(x) = 3at²(x − t) + at³ = 3at²x − 2at³`
- 차를 구하면 `f − ℓ = ax³ − 3at²x + 2at³ = a(x − t)²(x + 2t)`
- 근은 t(중근), **−2t**. 따라서 **s = −2t** □

`a(x−t)²(x+2t) = a(x² − 2tx + t²)(x + 2t) = a(x³ + 2tx² − 2tx² − 4t²x + t²x + 2t³) = a(x³ − 3t²x + 2t³)` ✓ (전개 검산)

일반형에서는 마스터 정리로 **f − ℓ의 x², x³ 계수가 f와 같으므로** 근의 합이 −b/a, 즉 `2t + s = −b/a` → `s = −b/a − 2t`가 그대로 성립한다 [4][8].

> 관점의 이득: 표준형에서는 **"−2배"**라는 외우기 쉬운 한 마디로 끝난다. 계수가 지저분한 일반 삼차함수를 만나도 **변곡점 기준으로 −2배**라고 생각하면 된다.

**따름정리(두 근의 평균 접선).** f의 세 실근이 α, β, γ일 때 x = (α+β)/2에서 그은 접선은 x축과 **(γ, 0)**에서 만난다. (t = (α+β)/2를 넣으면 s = (α+β+γ) − (α+β) = γ이고, x축이 그 직선이다.) [8]

## 5. 넓이 공식의 정체 — 왜 |a|와 거리만으로 결정되나

수능 실전에서 쓰는 넓이 공식들은 **전단 불변성의 직접적 결과**다 [5][7].

### 5-1. 삼차 – 접선: 1/12 공식
접점 α(중근), 재교점 β라 하면 §4에서 `f − ℓ = a(x − α)²(x − β)`. 넓이는

`S = | ∫[α, β] a(x−α)²(x−β) dx | = |a| · (β−α)⁴ / 12`

**전단을 걸어도 f − ℓ이 안 변하므로 이 값은 그대로다.** 다시 말해 **접선이 기울어져 있든 수평이든 넓이는 같다.** 그래서 공식이 **|a|와 교점 거리 (β−α)** 두 가지로만 결정된다.

> 직관: 기울어진 접선 구도를 **전단으로 눕혀** 수평 접선 구도로 만들 수 있고, 눕히는 동안 **넓이는 한 톨도 새지 않는다** [7].

### 5-2. 공식 표
치환 u = x − α로 즉시 확인되는 적분들이다 [5]:

- `∫[α, β] (x−α)(x−β) dx = −(β−α)³ / 6`
- `∫[α, β] (x−α)²(x−β) dx = −(β−α)⁴ / 12`
- `∫[α, β] (x−α)²(x−β)² dx = (β−α)⁵ / 30`

| 구도 | 넓이 | 전단 불변? |
|---|---|---|
| 이차함수와 직선(교점 α, β) | \|a\|(β−α)³ / 6 | ✅ |
| 삼차함수와 접선(접점 α, 교점 β) | \|a\|(β−α)⁴ / 12 | ✅ |
| 사차함수와 이중접선(접점 α, β) | \|a\|(β−α)⁵ / 30 | ✅ |

세 공식 모두 **곡선 − 직선** 구도이므로 전단 불변이고, 따라서 **직선의 기울기는 답에 등장하지 않는다.** 공식에 기울기가 없는 이유가 바로 이것이다.

### 5-3. 16:1 넓이비
표준형 y = ax³에서 점 t의 접선 → 재교점 −2t. 접점과 재교점의 거리는 `|−2t − t| = 3|t|`.
그 재교점 −2t에서 다시 접선을 그으면 재교점은 `−2·(−2t) = 4t`, 거리는 `|4t − (−2t)| = 6|t|`.

`A₁ = |a|(3|t|)⁴/12` ,  `A₂ = |a|(6|t|)⁴/12`  →  `A₂/A₁ = (6/3)⁴ = 2⁴ = 16`

**접선을 따라 한 칸 갈 때마다 넓이는 16배.** 표준형에서 보면 "거리가 2배 → 4제곱이니 16배"로 **한 줄**이다 [8].

## 6. 사차함수 — 네 교점 대칭이라는 강력한 무기

사차함수는 자유도가 하나 더 많지만(이해편 §2), 전단은 여기서도 결정적이다.

### 6-1. 표준화
f(x) = ax⁴ + bx³ + cx² + dx + e에 대해
- **좌우 평행이동**(x → x − b/4a)으로 **삼차항 제거** → `ax⁴ + px² + qx + r`
- **전단**(k = −q)으로 **일차항 제거** → `ax⁴ + px² + r`
- **위아래 이동**으로 상수항 제거 → `ax⁴ + px²`

결과는 **짝함수**이므로 **y축 대칭**이다. 원래 좌표계로 되돌리면 대칭축은 **x = −b/4a** [9][11].

> 주의: 원래 사차함수 자체가 좌우대칭인 것은 **아니다**. 정확히는 **"어떤 직선을 기준으로 재면 대칭"**이다. 이를 **전단 대칭**이라 부를 수 있고, 실전에서는 다음 형태로 쓴다.

### 6-2. 핵심 결론 — 네 교점의 평균은 언제나 −b/4a
사차함수와 직선 ℓ이 서로 다른 네 점에서 만난다고 하자. f − ℓ은 사차식이고 **x⁴, x³ 계수는 직선의 영향을 받지 않으므로**

`x₁ + x₂ + x₃ + x₄ = −b/a`  →  **평균 = −b/4a**

즉 **네 교점은 x = −b/4a를 중심으로 대칭적으로 배치**된다. 직선을 어떻게 잡아도 이 중심은 고정이다 [9][11].

**활용**
- 네 교점 중 셋을 알면 **넷째는 자동**.
- 이중접선(두 점에서 접함)이면 접점 두 개가 **중심에서 같은 거리**만큼 떨어져 있다.
- 표준형 `ax⁴ + px²`에서 이중접선은 항상 **수평선**이 되고, 접점은 **±√(−p/2a)**로 대칭. 여기에 1/30 공식을 쓰면 끝난다.

## 7. 전단 면역 판정법 — 이 문제에 써도 되나

가장 중요한 실전 감각이다. **전단으로 옮겨도 답이 안 변하는 문제**를 어떻게 알아보는가?

### 7-1. 판정 기준
문제의 **조건과 결론이 모두** 다음 재료로만 쓰여 있으면 **전단 면역(shear-immune)**[^전단면역]**이다** [4][6]:
- **x좌표**(교점·접점의 위치, 그 차이·비율)
- **넓이**
- **곡선과 직선의 관계**(만난다·접한다·둘러싼다·교점 개수)
- **변곡점**, 이계도함수와 관련된 성질

반대로 다음이 하나라도 끼면 **면역이 아니다**:
- **극댓값·극솟값**(값 자체), **극점의 위치**
- **기울기·미분계수**, **접선의 기울기 값**
- **y좌표·함숫값**
- **길이·각도·수직·거리**

| 문제가 묻는 것 | 전단 면역 | 전략 |
|---|---|---|
| 곡선과 직선의 교점 x좌표 | ✅ | 표준형으로 |
| 둘러싸인 넓이·넓이비 | ✅ | 표준형으로 |
| 접선이 다시 만나는 점 | ✅ | −2배 |
| 실근의 개수(직선과의) | ✅ | 표준형으로 |
| 극댓값 − 극솟값 | ❌ | 원래 함수에서 |
| 접선의 기울기 값 | ❌ | 원래 함수에서 |
| 두 점 사이 거리 | ❌ | 원래 함수에서 |

### 7-2. 면역이 아닌 조건을 면역으로 바꾸기
극값 조건도 **직선과의 관계로 번역**하면 다시 쓸 수 있다. 대표적 번역 사전:

| 원래 표현 | 번역 |
|---|---|
| "x = t에서 극값" | "곡선이 x = t에서 **어떤 수평선과 접한다**" |
| "극댓값을 지나는 수평선" | "곡선과 **중근으로 접하는 직선**" |
| "극댓값 = 극솟값 + h" | (y값이므로 번역 불가 → 원 함수에서) |

예컨대 "극댓값을 지나는 수평선이 곡선과 다시 만나는 점"은 **접점 t(중근) + 재교점 s** 구도이므로 마스터 항등식이 그대로 적용돼 `s = −b/a − 2t`다. 표준형 a(x³ − 3q²x)에서 극대는 x = −q이므로 `s = 0 − 2(−q) = 2q` — 이해편·앞선 보고서의 **2:1 비율관계**가 여기서 자동으로 나온다 [10].

> 통찰: **비율관계는 외우는 공식이 아니라 마스터 항등식의 특수한 경우**다. 극점을 "접하는 직선"으로 바꿔 읽는 순간 전부 한 식에서 나온다.

## 8. 심화 워크스루 — 유형별 실전

> ※ 아래는 특정 회차 기출의 복제가 아니라, 평가원·교육청 기출에서 **반복되는 구조**를 대표 유형으로 재구성한 것이다 [4].

**유형 A) 셋째 교점 찾기.**
"f(x) = x³ − 6x² + 5x + 2 와 직선이 x = 1, x = 2에서 만난다. 셋째 교점의 x좌표는?"
- 근의 합 = −b/a = 6. → `x₃ = 6 − 1 − 2 = 3`.
- **직선이 무엇인지 알 필요도 없다.** 직선의 식을 구해 연립하는 정공법 대비 계산량이 사실상 0.

**유형 B) 접선의 재교점.**
"f(x) = 2x³ + 3x² − x + 1 의 x = 1에서의 접선이 곡선과 다시 만나는 x좌표는?"
- −b/a = −3/2, t = 1 → `s = −3/2 − 2 = −7/2`.

**유형 C) 넓이(1/12).**
"최고차 계수 3인 삼차함수의 x = −1에서의 접선이 곡선과 x = 3에서 다시 만난다. 둘러싸인 넓이는?"
- |a| = 3, 거리 = 4 → `S = 3 · 4⁴/12 = 3 · 256/12 = 64`.
- **접선의 기울기를 구하지 않았다는 점**이 핵심이다(전단 불변이므로 필요 없다).

**유형 D) 넓이비.**
"삼차함수 위 점 P의 접선이 곡선과 Q에서 만나고, Q의 접선이 곡선과 R에서 만난다. 두 영역의 넓이 비는?"
- 표준형에서 거리 3|t| → 6|t|, 4제곱이므로 **1 : 16**.

**유형 E) 사차 네 교점.**
"f(x) = x⁴ − 8x³ + ⋯ 와 직선이 네 점에서 만나고 그중 셋의 x좌표가 1, 2, 4다. 넷째는?"
- 합 = −b/a = 8 → `x₄ = 8 − 1 − 2 − 4 = 1`. 그런데 1은 이미 있으므로 **중복(접점)** 상황임을 알 수 있다 — 조건 검토의 단서가 된다.
- (서로 다른 네 점이라면 문제 조건이 모순이라는 뜻이므로, 이런 계산은 **검산 장치**로도 쓰인다.)

**유형 F) 면역이 아닌 경우.**
"삼차함수의 극댓값과 극솟값의 차가 4다." → **y값 차이**이므로 전단 불변이 아니다. 표준형으로 옮기면 값이 달라지므로 **원래 함수에서** 계산해야 한다(극점 거리 D에 대해 |a|D³/2 사용).

## 9. 흔한 함정

1. **극값 문제에 표준형을 그대로 적용.** 가장 흔한 오용. 전단은 극점을 옮기고 없애기도 한다 [10].
2. **"평균 = 변곡점"을 곡선 위 아무 세 점에 적용.** 이 성질은 **한 직선 위의 세 교점**일 때만 성립한다. 임의의 세 점은 해당 없음.
3. **넓이 공식에서 |a| 누락.** 표준형으로 옮겨도 **최고차 계수는 안 변한다**는 점을 기억(전단·평행이동은 최고차항을 건드리지 않는다).
4. **사차함수가 좌우대칭이라고 단정.** 정확히는 **직선을 기준으로 잰 대칭**이다. 함수 자체의 그래프가 대칭인 것은 이차항만 남는 특수한 경우뿐 [9].
5. **전단이 x좌표를 바꾼다고 착각.** 전단은 **수직으로만** 민다. x좌표를 바꾸는 것은 좌우 평행이동뿐이다 [6].
6. **각도·수직 조건에 사용.** 전단은 각도를 보존하지 않는다. "접선이 서로 수직" 같은 조건이 있으면 즉시 배제 [6].

## 10. 한눈 요약

| 무기 | 내용 | 근거 |
|---|---|---|
| 마스터 정리 | 전단은 **f − ℓ 불변** | 곡선·직선에 같은 kx [6] |
| 표준화 | 변곡점→원점, 전단으로 일차항 제거 → **y = ax³** | 감차형 + 전단 [8] |
| 삼차 세 교점 | x좌표 합 = **−b/a**, 평균 = 변곡점 | 근과 계수 [3] |
| 접선 항등식 | 재교점 **s = −b/a − 2t** (표준형 −2t) | (x−t)² 인수 [8] |
| 1/12 공식 | \|a\|(β−α)⁴/12, **기울기 무관** | f − ℓ 불변 [5][7] |
| 16:1 | 거리 2배 → 4제곱 | 표준형 계산 [8] |
| 사차 네 교점 | 평균 = **−b/4a** 고정 | 근과 계수 [9][11] |
| 면역 판정 | x좌표·넓이·(곡선−직선)만 쓰면 ✅ | 전단 성질 [4] |
| 금지 | 극값·기울기·길이·각도 | 전단 비보존 [10] |

**마지막 한 줄** — 심화문제가 어려운 이유는 계수가 지저분해서가 아니라, **어느 것이 본질이고 어느 것이 변장인지** 구분이 안 되기 때문이다. 전단변환은 그 변장을 벗기는 도구다. **x좌표와 넓이만 남기고 나머지를 지워 버리면**, 대부분의 삼차·사차함수 문제는 **y = ax³ 위의 아주 단순한 질문**으로 무너진다.
