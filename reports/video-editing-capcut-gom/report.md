# 영상 편집 완전 가이드 — 캡컷·곰믹스

> "영상 편집 배우고 싶은데 뭘로 시작하지?" — 가장 많이 나오는 두 이름이 **캡컷(CapCut)**과 **곰믹스(곰랩)**다. 캡컷은 **숏폼·AI·템플릿**으로 무장한 글로벌 강자, 곰믹스는 **초보자용 PC 편집의 국민 프로그램**이다. 이 글은 두 툴을 중심으로 **무엇을 언제 쓰고, 어떻게 편집하는지(활용법)**를 단계별로 정리하고, Vrew·다빈치·프리미어 같은 대안까지 **목적별 선택 지도**로 묶는다. 영상 편집 첫걸음부터 도구 갈아타기 판단까지 한 번에.

## TL;DR
- **캡컷(CapCut)** = 바이트댄스가 만든 **숏폼 특화 편집기**. 모바일·PC·웹 모두 지원, **직관적 UI + 풍부한 템플릿 + 강력한 AI(자동자막·자동편집·배경제거)**로 초보도 바로 시작한다. 무료로도 상당히 쓸 수 있고, 고급 기능은 유료 [2][3][6].
- **곰믹스(곰랩)** = 곰플레이어로 유명한 **곰앤컴퍼니**의 PC 편집 프로그램. **매우 쉬운 인터페이스**로 초보 유튜버의 오랜 선택지. 무료 버전은 **10분·워터마크** 제한, 긴 영상·고급 기능은 **곰믹스 프로/맥스**(유료) [6][7][8].
- **핵심 갈림길**: **숏폼·모바일·AI·템플릿**이면 캡컷, **PC에서 가볍고 쉬운 컷편집·자막**이면 곰믹스가 기본값이다 [1][4].
- **캡컷 요금(2026)**: 무료(1080p·기본편집·기본 AI) / **Standard(~$9.99, 워터마크 제거·모바일 중심)** / **Pro(~$19.99·국내 월 19,800원)** = 4K·풀 AI(모션트래킹·보컬분리)·1,200만+ 소재 [12][13].
- **다른 강자도 알아두자**: **Vrew(브루)** = 음성·자막 기반 텍스트 편집, **다빈치 리졸브** = 무료 전문가용(색보정·VFX), **프리미어 프로** = 업계 표준(유료) [9][10].

## 핵심 포인트
1. **입문 최적 = 캡컷 or 곰믹스.** 둘 다 학습 부담이 낮다. 캡컷은 AI·템플릿, 곰믹스는 단순함이 무기 [3][8].
2. **플랫폼이 선택을 가른다.** 폰으로 숏폼 → 캡컷 모바일, PC로 유튜브 롱폼 → 곰믹스/캡컷 PC [1][6].
3. **무료의 벽을 알자.** 캡컷은 4K·풀 AI가 유료, 곰믹스 무료는 10분·워터마크 [8][12].
4. **AI가 판을 바꿨다.** 자동자막·자동편집·배경제거로 편집 시간이 급감했다 [3][10].
5. **목적별로 다르다.** 음성 콘텐츠는 Vrew, 색보정·전문 작업은 다빈치/프리미어 [9][10].

## 1. 어떤 툴을 고를까 — 지형도 먼저

영상 편집 툴은 많지만, **"누가·무엇을·어디서 만드는가"**로 나누면 지도가 단순해진다 [4][5][10].

| 툴 | 성격 | 강점 | 가격 |
|---|---|---|---|
| **캡컷** | 숏폼·AI·템플릿 | 쉬움·모바일·AI·소재 | 무료+유료 |
| **곰믹스(곰랩)** | 초보 PC 편집 | 매우 쉬움·가벼움 | 무료+유료 |
| **Vrew(브루)** | 음성·자막 기반 | 자동자막·텍스트 컷편집 | 무료+유료 |
| **다빈치 리졸브** | 전문가용 | 색보정·VFX·무료 강력 | 무료+유료 |
| **프리미어 프로** | 업계 표준 | 최강 확장·협업 | 유료 |

이 글은 사용자가 지목한 **캡컷·곰믹스**를 깊게 다루고(§2~§6), 나머지는 **목적별 대안**으로 정리한다(§7~§8). 결론을 먼저 말하면 — **초보의 90%는 캡컷 또는 곰믹스로 충분히 시작**할 수 있다 [3][8].

## 2. CapCut(캡컷) — 숏폼·AI·템플릿의 강자

### 2-1. 정체성
**캡컷**은 틱톡을 만든 **바이트댄스**의 영상 편집기다. **틱톡·인스타 릴스·유튜브 쇼츠** 같은 **숏폼**[^숏폼]에 최적화됐고, **직관적 UI와 방대한 템플릿·AI 기능**으로 "배우지 않고도 바로 편집"이 가능한 게 최대 강점이다 [3][6]. 모바일 앱·PC 프로그램·웹 에디터를 **모두** 제공한다(기능 구성엔 차이가 있다) [1].

### 2-2. 요금 구조 (2026)
캡컷은 2025년 요금제를 개편해 **무료 / Standard / Pro** 3단으로 나뉜다 [12][13].

| 플랜 | 가격(대략) | 핵심 |
|---|---|---|
| **무료** | $0 | 컷·분할·멀티트랙[^멀티트랙]·키프레임[^키프레임]·크로마키[^크로마키]·**1080p 내보내기**·기본 AI·무료 템플릿 |
| **Standard** | 약 $9.99/월 | **워터마크[^워터마크] 제거**·추가 템플릿/전환/효과(주로 모바일). 4K·풀 AI는 미포함 |
| **Pro** | 약 $19.99/월(연 $179.99) · **국내 월 19,800원** | **4K 내보내기·풀 AI(모션트래킹[^모션]·보컬분리·화자별 자막)**·클라우드 100GB+·1,200만+ 로열티프리 소재 |

> **주의**: 무료 플랜은 **만료 없이 계속** 쓸 수 있다. 다만 무료는 **월 AI 자동편집 5회·배경제거 5회·영상당 자동자막 10분** 같은 한도가 있다 [2]. 또 **capcut.com 직접 결제가 앱스토어보다 20~30% 저렴**한 경우가 많다 [13].

### 2-3. 무엇이 되나 — 기능
- **기본 편집**: 자르기·분할·속도조절·전환·필터·음악/효과음 삽입(내장 무료 음악·소재 라이브러리 활용) [2][6][11].
- **AI 기능(캡컷의 진짜 무기)**: **자동 자막**[^자동자막](말→글), **자동 편집(AI auto-cut)**, **배경 제거**, **AI 보이스오버(TTS)**, 템플릿 자동 적용 [3][6][12].
- **템플릿**: 유행 포맷을 골라 내 영상만 끼워 넣으면 완성 — 숏폼 대량 생산에 최적 [3].

### 2-4. 어디서 편집하나 — 플랫폼별
- **모바일 앱**: 숏폼·즉석 편집에 최적. 손가락으로 빠르게 [1].
- **PC 프로그램**: 큰 화면·정밀 편집·롱폼에 유리.
- **웹 에디터**: 설치 없이 브라우저+로그인으로. 협업·간단 작업에 편리 [13].

## 3. 캡컷 실전 — 첫 편집 5단계 + 활용

### 3-1. 첫 영상 5단계 (모바일 기준)
1. **새 프로젝트** → 편집할 영상·사진 선택(여러 개 가능).
2. **타임라인**[^타임라인]에서 **자르기·분할**로 필요한 부분만 남기기(불필요한 구간 삭제).
3. **자막**: "텍스트 → 자동 자막"으로 **말을 글로 자동 변환** → 폰트·색·위치 다듬기 [3].
4. **꾸미기**: 전환(장면 전환), 필터/보정, 배경 음악·효과음, 스티커 추가.
5. **내보내기**: 해상도(무료 1080p) 선택 → **Export**. 틱톡/릴스/쇼츠로 바로 공유 [2].

### 3-2. 시간 아끼는 활용 팁
- **템플릿부터**: 처음엔 유행 템플릿을 골라 클립만 교체 → **10분 만에 숏폼 완성** [3].
- **자동 자막 적극 활용**: 손으로 치지 말고 자동 생성 후 오타만 수정(무료는 영상당 10분 한도 주의) [2].
- **배경 제거**로 인물만 오려 합성(무료 월 5회) [12].
- **PC로 롱폼**: 유튜브 롱폼·정밀 컷은 모바일보다 **PC 버전**이 편하다.

## 4. 곰믹스(곰랩) — 초보 PC 편집의 국민 프로그램

### 4-1. 정체성
**곰믹스**는 곰플레이어로 유명한 **곰앤컴퍼니(곰랩, GOM Lab)**의 PC용 영상 편집 프로그램이다. **"영상 편집 초보자도 쉽게"**를 표방하며, **단순한 타임라인·낮은 학습 곡선**으로 오랫동안 국내 초보 유튜버의 입문 도구였다 [6][8]. Windows PC 전용이다.

### 4-2. 세 가지 버전 — 곰믹스 / 프로 / 맥스
곰믹스는 라인업이 나뉜다. **자기 수준에 맞게** 고르면 된다 [7][8].

| 버전 | 성격 | 특징 |
|---|---|---|
| **곰믹스(무료/2024)** | 입문 | 단순 컷·기초 자막, **매우 쉬움**. 무료는 **10분·워터마크** 제한, 효과 2,000여 종 |
| **곰믹스 프로** | 중급 | 더 많은 효과·기능, 유료 |
| **곰믹스 맥스(GOM Mix Max)** | 상급 | **멀티트랙·크로마키·고급 효과**, 긴 영상 제작에 적합, 유료 |

> **무료의 벽**: 무료 곰믹스는 **완성 영상 10분 제한**과 **워터마크**가 붙는다. 짧은 영상 연습엔 충분하지만, **긴 영상·워터마크 제거**가 필요하면 프로/맥스(유료)로 올라가야 한다. **10일 무료 체험**으로 유료 기능을 먼저 써볼 수 있다 [7][8].

### 4-3. 왜 초보에게 좋나
- **인터페이스가 단순**하다 — 구버전은 타임라인 구조가 특히 쉬워 "일단 만들어 보기"에 좋다 [7].
- **가볍다** — 저사양 PC에서도 무난.
- **한글·국내 환경 친화적** — 메뉴·자막·폰트가 한국 사용자에 맞춰져 있다.

## 5. 곰믹스 실전 — 컷·자막·효과 단계별

1. **다운로드·설치**: 곰랩(gomlab.com) 공식에서 곰믹스 내려받아 설치 [6].
2. **미디어 불러오기**: 영상·이미지·음악 파일을 프로젝트에 추가.
3. **컷 편집**[^컷편집]: 타임라인에서 자를 지점을 잘라 불필요한 구간 삭제, 순서 배치.
4. **자막·텍스트**: 텍스트 추가 → 폰트·크기·색·나타나는 타이밍 지정.
5. **효과·전환**: 2,000여 효과·필터·전환 중 선택 적용(과하지 않게).
6. **오디오**: 배경 음악·효과음 삽입, 볼륨 조절.
7. **출력(인코딩)**[^렌더링]: 해상도·형식 선택 → 내보내기(무료는 10분·워터마크 유의).

> **실사용 팁**: (1) 프로젝트를 **자주 저장**하라(작업 유실 방지). (2) 효과는 **절제**해야 프로처럼 보인다. (3) 긴 영상·다중 자막·크로마키가 필요해지면 **맥스**로 갈아탈 시점이다 [8].

## 6. 캡컷 vs 곰믹스 — 무엇을 언제

두 툴은 **겨냥하는 지점이 다르다** [1][4][6].

| 기준 | **캡컷** | **곰믹스** |
|---|---|---|
| 주 무대 | 모바일·웹·PC (**숏폼**) | **PC**(Windows) |
| 강점 | AI·템플릿·소재·전환 | 단순함·가벼움·한글 친화 |
| AI 기능 | **강력**(자동자막·편집·배경제거) | 상대적으로 약함 |
| 무료 제한 | 4K·풀 AI 유료, 자동자막 10분/영상 | **완성 10분·워터마크** |
| 학습 난이도 | 쉬움 | **매우 쉬움** |
| 최적 용도 | 틱톡·릴스·쇼츠, 트렌디 영상 | PC 컷편집·간단 유튜브 입문 |

**한 줄 결론**
- **숏폼을 폰으로 빠르게·AI로·트렌디하게** → **캡컷**
- **PC에서 부담 없이·쉽고 가볍게 컷과 자막** → **곰믹스**
- 둘 다 무료로 시작 가능하니, **직접 하루씩 써보고** 손에 맞는 쪽을 고르는 게 가장 정확하다.

## 7. 그 외 알아둘 툴 — 목적이 다르면 도구도 다르다

캡컷·곰믹스로 부족하거나 목적이 특수하면 아래를 고려한다 [9][10].

- **Vrew(브루)**: **음성·자막 기반** 편집의 최강자. 말을 자동으로 자막화하고, **텍스트(스크립트)를 지우면 해당 영상 구간이 잘리는** 방식이라 **강의·인터뷰·정보성 영상**에 압도적이다 [9].
- **다빈치 리졸브(DaVinci Resolve)**: 블랙매직디자인의 **전문가용**. **무료 버전도 색보정[^색보정]·컷·오디오·VFX**까지 지원해 "무료 최강 전문 툴"로 꼽힌다. 학습 곡선은 있다 [10].
- **어도비 프리미어 프로**: **업계 표준**. 영화·광고·유튜브 전반에 쓰이며 확장성·협업이 최강. 유료 구독 [10].
- **필모라(Filmora)**: 캡컷·곰믹스와 함께 **가성비** 편집기로 꼽힌다 [4].

## 8. 목적별 추천 — 나에게 맞는 조합

| 목적 | 추천 | 이유 |
|---|---|---|
| **숏폼(틱톡·릴스·쇼츠)** | **캡컷** | AI·템플릿·모바일 최적 |
| **PC 유튜브 입문(가볍게)** | **곰믹스** | 쉬움·한글·저사양 OK |
| **강의·정보성(말 중심)** | **Vrew** | 자동자막·텍스트 컷편집 |
| **긴 유튜브·멀티트랙** | **곰믹스 맥스 / 캡컷 PRO** | 멀티트랙·고급 효과 |
| **색보정·전문 작업** | **다빈치 리졸브** | 무료로 전문 색보정·VFX |
| **업무·협업·업계 표준** | **프리미어 프로** | 확장·협업·안정성 |

> **현실 로드맵**: **캡컷/곰믹스로 시작** → 자막 위주면 **Vrew** 추가 → 더 정밀·전문으로 가면 **다빈치/프리미어**. 처음부터 프리미어를 살 필요는 없다 [10].

## 9. 잘 쓰는 법 — 편집 공통 원칙

툴이 무엇이든 통하는 원칙이다.

1. **기획이 먼저.** 찍기 전에 "무슨 말을 어떤 순서로"를 정하면 편집이 절반으로 준다.
2. **컷을 과감히.** 초보의 영상은 대개 **너무 길다.** 군더더기·침묵·실수 구간을 아끼지 말고 잘라라.
3. **자막은 필수.** 숏폼·정보성은 **소리 없이도 이해되게** 자막을 깔아라(자동자막 활용).
4. **효과는 절제.** 전환·필터를 남발하면 아마추어처럼 보인다. **일관된 톤**이 프로처럼 보이는 비결.
5. **소리가 절반.** 배경음·효과음의 볼륨 밸런스, 목소리 명료도가 완성도를 좌우한다.
6. **자주 저장·백업.** 편집 유실은 흔하다. 프로젝트를 주기적으로 저장하라.
7. **저작권 주의.** 음악·폰트·이미지는 **라이선스**를 확인하라(캡컷·곰믹스 내장 무료 소재부터).

## 10. 흔한 오해·FAQ

**Q1. 캡컷은 무료인가요?**
**기본은 무료**다(만료 없음). 컷·자막·1080p 내보내기까지 무료로 되고, **4K·풀 AI·워터마크 제거** 등이 유료(Standard/Pro)다. 무료는 AI 자동편집·배경제거가 **월 5회**, 자동자막이 **영상당 10분**으로 제한된다 [2][12][14].

**Q2. 곰믹스 무료로 유튜브 영상 만들 수 있나요?**
짧은 영상은 가능하지만 **무료는 완성 10분·워터마크** 제한이 있다. 긴 영상·워터마크 제거는 **프로/맥스(유료)**가 필요하다. 10일 무료 체험으로 먼저 써보라 [7][8].

**Q3. 캡컷과 곰믹스 중 뭘 먼저?**
**폰으로 숏폼이면 캡컷, PC로 쉽게 시작이면 곰믹스.** 둘 다 무료라 하루씩 써보고 손에 맞는 쪽을 고르는 게 정답이다 [1][6].

**Q4. 자막을 자동으로 넣고 싶어요.**
캡컷의 **자동 자막**이 강력하다(무료 영상당 10분). **말 중심 긴 영상**이라면 **Vrew(브루)**가 더 유리하다 — 자동 자막 + 텍스트로 컷편집 [3][9].

**Q5. 전문가처럼 색보정하고 싶어요.**
**다빈치 리졸브**가 정답이다. 무료 버전도 **할리우드급 색보정**을 지원한다. 다만 학습이 필요하다 [10].

**Q6. 캡컷은 어느 나라 앱인가요? 안전한가요?**
바이트댄스(중국계 글로벌 기업)의 앱이다. 국내에선 정상 사용 가능하다. 다만 **민감한 원본·개인정보**를 다룰 땐 클라우드 업로드 범위를 확인하고, 업무용 보안이 중요하면 로컬 편집 툴(곰믹스·다빈치)을 고려하라 [1].

## 11. 한눈 요약 + 빠른 시작

| 항목 | 요점 |
|---|---|
| 캡컷 | 숏폼·AI·템플릿, 모바일/PC/웹, 무료+Standard($9.99)+Pro($19.99·국내19,800원) |
| 곰믹스 | 초보 PC 편집, 매우 쉬움, 무료(10분·워터마크)+프로/맥스 |
| 갈림길 | 숏폼·AI → 캡컷 / PC·쉬움 → 곰믹스 |
| 자동자막 | 캡컷(영상당 10분) · 말 중심이면 **Vrew** |
| 전문·색보정 | **다빈치 리졸브**(무료) / 프리미어(표준·유료) |
| 공통 원칙 | 기획→과감한 컷→자막→효과 절제→소리→저장→저작권 |

**빠른 시작 3단계**: ① 폰이면 **캡컷 앱**, PC면 **곰믹스** 설치(둘 다 무료) → ② **템플릿/샘플로 한 편** 만들어 보며 컷·자막·음악 익히기 → ③ 목적이 뚜렷해지면(말 중심=Vrew, 전문=다빈치) 도구 추가.

**마지막 한 줄** — 영상 편집의 90%는 **"자르고, 자막 넣고, 소리 맞추기"**다. 화려한 툴보다 **하나를 끝까지 써보는 것**이 실력을 만든다. 캡컷이든 곰믹스든, 오늘 **1분짜리 한 편**을 끝까지 완성해 내보내 보라 — 거기서 편집이 시작된다.

[^숏폼]: 숏폼(short-form) — 틱톡·인스타 릴스·유튜브 쇼츠처럼 세로·짧은(대개 15~60초) 영상 포맷. 빠른 편집·자막·트렌디한 효과가 핵심.
[^타임라인]: 타임라인(timeline) — 영상·오디오·자막 클립을 시간 순으로 배치하는 편집 화면의 핵심 작업 공간.
[^멀티트랙]: 멀티트랙(multi-track) — 영상·자막·음악·효과를 여러 층(트랙)으로 겹쳐 편집하는 방식. 복잡한 합성·자막에 필요하다.
[^크로마키]: 크로마키(chroma key) — 초록/파랑 배경을 지우고 다른 배경으로 합성하는 기법('누끼'). 인물만 오려 붙일 때 쓴다.
[^키프레임]: 키프레임(keyframe) — 특정 시점의 위치·크기·투명도 값을 지정해 그 사이를 자동으로 움직이게 만드는 애니메이션 기법.
[^워터마크]: 워터마크(watermark) — 무료 버전 영상에 박히는 프로그램 로고·표식. 유료로 전환하면 제거된다.
[^자동자막]: 자동 자막(STT 자막) — 영상 속 말을 인식해 글자 자막으로 자동 변환해 주는 기능. 손으로 타이핑할 필요를 크게 줄인다.
[^모션]: 모션 트래킹(motion tracking) — 영상 속 움직이는 대상을 추적해 자막·효과가 따라붙게 하는 고급 기능. 캡컷은 Pro 전용.
[^컷편집]: 컷 편집(cut editing) — 불필요한 구간을 잘라내고 필요한 장면만 이어 붙이는 가장 기본적인 편집 작업.
[^색보정]: 색보정(color grading) — 영상의 색감·밝기·대비를 조정해 분위기와 완성도를 높이는 작업. 다빈치 리졸브가 특히 강하다.
[^렌더링]: 렌더링·인코딩(내보내기, export) — 편집한 결과를 하나의 완성 영상 파일로 만들어 저장하는 마지막 단계. 해상도·형식을 여기서 정한다.
