# 도함수가 불연속인 함수 (이해편)

> 교과서는 **"미분가능하면 연속이다"** 를 가르치고 거기서 멈춘다 [3]. 그런데 한 걸음만 더 가면 아무도 묻지 않는 질문이 나온다 — **"그럼 도함수 f′ 도 연속인가?"** 답은 **아니다**. 미분가능한데 도함수가 뚝 끊기는 함수가 실제로 있고, 그중 가장 유명한 것이 `x² sin(1/x)` 다 [7]. 더 흥미로운 것은 그다음이다. 도함수는 불연속일 수 있지만 **아무렇게나 불연속일 수는 없다.** 도함수는 **계단처럼 점프하지 못한다** — 이것이 1875년 다르부가 증명한 것이다 [1][6]. 이 글은 반례 하나를 손으로 끝까지 계산하고, 다르부 정리가 무엇을 금지하는지까지 간다. 증명과 볼테라 함수, 미적분 기본정리의 균열은 짝을 이루는 **[확장편]** 이 맡는다.

## TL;DR

- **미분가능 ⇒ 연속**은 맞다 [3]. 그러나 **미분가능 ⇒ 도함수가 연속**은 **틀렸다** [1].
- 반례는 `f(x) = x² sin(1/x)` (단 `f(0) = 0`). 이 함수는 **모든 점에서 미분가능**하고 `f′(0) = 0` 인데, `f′` 는 **원점에서 불연속**이다 [1][7].
- 이유: `x ≠ 0` 에서 `f′(x) = 2x sin(1/x) − cos(1/x)` 인데, 앞항은 0으로 가지만 **뒷항 `cos(1/x)` 가 −1과 1 사이를 무한히 왕복**해 극한이 없다 [8].
- 그렇다고 도함수가 마음대로 끊기는 것은 아니다. **다르부 정리**: 미분가능한 함수의 도함수는 연속이 아니어도 **사잇값 성질**[^사잇값성질]을 가진다 [1][6].
- 실전적 귀결 하나 — **부호함수 sgn(x) 는 어떤 함수의 도함수도 될 수 없다** [1]. 값이 −1에서 1로 뛰면서 0을 건너뛰기 때문이다.
- 그래서 정리의 가정에서 **"미분가능"** 과 **"연속미분가능(C¹급)"**[^C1급] 이 구별돼 쓰인다. 값이 가장 크게 갈리는 자리가 적분이다 — `f′` 이 연속이면 곧바로 리만적분이 되지만, 그 가정을 빼면 **도함수가 리만적분조차 안 되는 함수**가 열린다 [8].

## 핵심 포인트

1. **미분가능성은 점마다의 성질이고, 도함수의 연속성은 그 위에 얹히는 별개의 성질이다.** 앞이 뒤를 함축하지 않는다 [1].
2. **`x² sin(1/x)` 의 정체는 "진폭이 x² 로 죽는 무한 진동"이다.** 진폭이 빨라 죽으니 함숫값은 미분가능할 만큼 얌전하고, 진동이 무한히 빨라지니 **기울기는 안정되지 못한다**.
3. **도함수의 불연속은 '점프'가 아니라 '요동'이다.** 다르부 정리가 점프를 금지하므로, 도함수가 끊기는 자리에서는 **한쪽 극한 자체가 없다** [6][7].
4. **사잇값 성질은 연속함수만의 것이 아니다.** 다르부의 기여는 "불연속인데도 사잇값 성질을 갖는 함수가 있다"를 보인 것이다 [6].
5. **이 사실은 시험 문제에도 걸린다.** 수학백과는 "다르부 정리를 인지하지 못한 출제자들이 사잇값 성질을 만족하지 않는 f′(x) 를 제시하는 경우가 있어 논란을 일으키기도 한다"고 적는다 [1].

## 1. 교과서가 묻지 않는 질문

고등학교 미적분에서 배우는 순서는 이렇다. 어떤 점에서 **미분계수가 존재하면** 그 점에서 미분가능하다고 부르고 [2], **미분가능하면 그 점에서 연속**이다 [3]. 그리고 역은 성립하지 않는다 — `|x|` 는 원점에서 연속이지만 미분가능하지 않다 [3].

여기까지가 교과서다. 그런데 미분을 한 결과인 **도함수 f′ 자체도 하나의 함수**다[^도함수]. 함수라면 물을 수 있다.

> **f′ 은 연속인가?**

교실에서 다루는 함수들 — 다항함수, 삼각함수, 지수·로그함수 — 은 전부 도함수가 다시 연속이다. 그래서 이 질문은 떠오르지도 않는다. 떠오르더라도 "당연히 연속이겠지"로 넘어간다.

**그 직관이 틀렸다.**

왜 이게 중요한가. 대학 미적분과 해석학에서 정리의 가정을 읽어 보면 **"f 가 미분가능"** 과 **"f 가 연속미분가능(C¹급)"** 이 구별되어 쓰인다[^C1급]. 두 조건이 같은 것이라면 굳이 나눠 쓸 이유가 없다. 나눠 쓰는 이유는 **실제로 다르기 때문**이고, 그 차이를 만드는 것이 이 글의 주인공인 함수들이다.

차이가 가장 비싸게 드러나는 곳은 적분이다. `f′` 이 연속이면 리만적분이 문제없이 되지만, 연속성을 빼는 순간 **도함수를 적분해 원래 함수를 되찾는 일이 실패할 수 있다** [8]. 미적분 기본정리의 문장이 지금의 모양인 이유가 거기 있다 — 확장편에서 다룬다.

## 2. 반례 하나 — x² sin(1/x)

문제의 함수는 이것이다 [1][7].

```
        ⎧ x² · sin(1/x)     (x ≠ 0)
f(x) =  ⎨
        ⎩ 0                 (x = 0)
```

먼저 이 함수의 생김새를 이해해야 한다. `sin(1/x)` 부터 보자. x 가 0에 가까워지면 `1/x` 는 무한대로 커지고, 사인은 그 큰 값을 따라 **−1과 1 사이를 점점 빠르게 왕복**한다. 0 근처 아무리 좁은 구간을 잡아도 그 안에 산과 골이 무한히 들어 있다.

거기에 `x²` 을 곱한 것이 f 다. 곱하는 순간 **진동의 폭이 x² 로 눌린다.**

```
   진폭 비교 (x → 0)

   sin(1/x)      : ─1 ┄┄┄┄ 계속 −1 ~ 1 을 왕복 (죽지 않음)
   x · sin(1/x)  :  진폭 |x|   → 0   (선형으로 죽음)
   x²· sin(1/x)  :  진폭 x²    → 0   (제곱으로 죽음)  ← 우리 함수
```

세 함수 모두 0 근처에서 무한히 진동한다. 차이는 **얼마나 빨리 잦아드느냐**뿐이고, 그 차이가 미분가능성을 가른다.

- `sin(1/x)` 는 0에서 **연속도 아니다**(극한이 없다).
- `x·sin(1/x)` 는 0에서 **연속이지만 미분가능하지 않다.** 차분몫이 `(h·sin(1/h) − 0)/h = sin(1/h)` 라 극한이 없기 때문이다.
- `x²·sin(1/x)` 는 0에서 **미분가능하다.** ← 지금 볼 것

## 3. Worked Example — f′(0) 을 정의대로 구한다

도함수 공식을 쓰면 안 된다. `x = 0` 은 함수가 조각으로 정의된 지점이므로 **미분계수의 정의**로 직접 가야 한다 [2].

**1단계. 차분몫을 세운다.**

```
f(0 + h) − f(0)     h² sin(1/h) − 0
──────────────  =  ───────────────  =  h · sin(1/h)
       h                   h
```

**2단계. 조임정리로 극한을 잡는다.** 사인은 무슨 짓을 해도 −1과 1 사이다.

```
−1 ≤ sin(1/h) ≤ 1
⇒  −|h| ≤ h · sin(1/h) ≤ |h|
```

양쪽 끝이 모두 0으로 가므로 가운데도 0으로 갈 수밖에 없다.

**3단계. 결론.**

```
f′(0) = lim  h · sin(1/h) = 0
       h→0
```

**존재한다.** 값은 0이다. 실제 수치로 확인하면 이렇다.

| h | (f(h) − f(0)) / h = h·sin(1/h) | 한계 \|h\| |
|---|---|---|
| 0.1 | −0.054402 | 0.1 |
| 0.01 | −0.005064 | 0.01 |
| 0.001 | +0.000827 | 0.001 |
| 0.0001 | −0.000031 | 0.0001 |
| 0.00001 | +0.00000036 | 0.00001 |

부호는 제멋대로 튄다(진동하니까 당연하다). 그런데 **크기는 `|h|` 에 갇혀 꼼짝없이 0으로 눌린다.** 이것이 조임정리가 하는 일이다.

**여기서 얻은 것**: `f` 는 원점에서 미분가능하고 `f′(0) = 0` 이다. 원점 밖에서는 곱의 미분법·합성함수 미분법으로 평범하게 계산된다.

```
f′(x) = 2x·sin(1/x) − cos(1/x)        (x ≠ 0)
```

`d/dx[sin(1/x)] = cos(1/x)·(−1/x²)` 이고 여기에 `x²` 이 곱해지면서 `x²` 이 약분돼 `−cos(1/x)` 만 남는 것이 요점이다.

## 4. 그런데 이 도함수는 원점에서 극한이 없다

이제 `f′` 이 원점에서 연속인지 본다. 연속이려면 `x → 0` 일 때 `f′(x) → f′(0) = 0` 이어야 한다.

```
f′(x) = 2x·sin(1/x) − cos(1/x)
        └──── ① ────┘  └─ ② ─┘
```

**① 은 0으로 간다.** 3절과 같은 조임 논법이다(`|2x·sin(1/x)| ≤ 2|x|`).

**② 는 0으로 가지 않는다.** `cos(1/x)` 는 x 가 0에 가까워질수록 더 빠르게 −1과 1을 왕복한다. 두 수열을 잡아 보면 분명해진다.

| 접근 수열 | 그 점에서 `1/x` | `cos(1/x)` | `f′` 값 |
|---|---|---|---|
| `xₖ = 1/(2kπ)` → 0 | `2kπ` | +1 | **−1** |
| `yₖ = 1/((2k+1)π)` → 0 | `(2k+1)π` | −1 | **+1** |

수치로 확인한 결과다.

| k | `xₖ = 1/(2kπ)` | `f′(xₖ)` | `yₖ = 1/((2k+1)π)` | `f′(yₖ)` |
|---|---|---|---|---|
| 1 | 0.15915494 | −1.00000000 | 0.10610330 | +1.00000000 |
| 5 | 0.03183099 | −1.00000000 | 0.02893726 | +1.00000000 |
| 100 | 0.00159155 | −1.00000000 | 0.00158363 | +1.00000000 |

두 수열 모두 0으로 수렴하는데 **도함수값은 −1과 +1로 갈린다.** 하나의 극한값으로 모이지 않으니 `lim f′(x)` 는 **존재하지 않는다**.

```
   f′ 의 그림 (x → 0)

    +1 ┤   ╱╲    ╱╲   ╱╲  ╱╲ ╱╲╱╲╱╲▓▓▓  ← 진폭이 죽지 않는다
       │  ╱  ╲  ╱  ╲ ╱  ╲╱  ╳  ▓▓▓▓▓▓▓
     0 ┼─────────────────────────────●──  ← f′(0) = 0 (정의대로는 존재)
       │ ╲  ╱ ╲  ╱ ╲ ╱  ╱╲  ▓▓▓▓▓▓▓▓
    −1 ┤  ╲╱   ╲╱   ╳   ╲╱ ▓▓▓▓▓▓▓▓▓
       └────────────────────────────────
                                    x=0
```

정리하면 이렇다.

- `f′(0)` **은 존재한다** (= 0). 미분계수의 정의로 계산했다.
- `lim_{x→0} f′(x)` **는 존재하지 않는다.**
- 따라서 **`f′` 은 원점에서 불연속**이다 [1][7].

**미분가능하지만 도함수가 불연속점을 갖는 함수**가 이렇게 손 안에 들어왔다.

## 5. 그래도 도함수는 아무렇게나 끊기지 못한다 — 다르부 정리

여기서 이야기가 끝났다면 "도함수는 아무 함수나 될 수 있다"로 마무리됐을 것이다. 그런데 그렇지 않다.

**다르부 정리 (1875)** [1][6]

> 구간에서 미분가능한 실함수 f 에 대하여, `f′(a)` 와 `f′(b)` 사이의 임의의 값 k 에 대해 `f′(c) = k` 인 c 가 a 와 b 사이에 **적어도 하나 존재한다** [1].

이것은 **중간값 정리와 똑같은 진술**이다. 다만 중간값 정리는 **연속함수**에 대한 것이고, 다르부 정리는 **도함수**에 대한 것이다 — 그 도함수가 연속이든 아니든.

수학백과는 이 관계를 이렇게 정리한다: 사잇값 정리는 연속함수의 성질로 "과거에는 연속함수만의 특성이라고 여기기도 했다. 하지만 주어진 함수가 연속이 아니더라도 사잇값 성질을 얼마든지 만족할 수 있다" [1]. 사잇값 성질을 갖는 함수를 **다르부 함수**라 부르고, 다르부 정리는 **모든 도함수가 다르부 함수임**을 말한다 [1][6].

```
   포함 관계

   ┌──────────────────────────────────────┐
   │            다르부 함수                │   ← 사잇값 성질을 갖는 함수
   │   ┌──────────────────┐               │
   │   │   연속함수        │  ★ f′ = 2x sin(1/x) − cos(1/x)
   │   │  (중간값 정리)     │     ← 여기 산다: 불연속인데 사잇값 성질 O
   │   └──────────────────┘               │
   └──────────────────────────────────────┘
```

원문 논문은 다르부가 1875년에 발표한 「Mémoire sur les fonctions discontinues(불연속함수에 관한 논문)」 이다 [6].

## 6. 그래서 계단은 도함수가 될 수 없다

다르부 정리를 **금지 규칙**으로 읽으면 힘이 세진다. 사잇값 성질이 없는 함수는 **어떤 함수의 도함수도 아니다.**

수학백과가 드는 예가 부호함수다 [1].

```
          ⎧  1   (x > 0)
sgn(x) =  ⎨  0   (x = 0)
          ⎩ −1   (x < 0)
```

`sgn(−1) = −1`, `sgn(1) = 1` 인데 그 사이의 값 `0.5` 를 취하는 점은 **어디에도 없다**. 사잇값 성질이 깨진다. 따라서 [1]:

> `f′(x) = sgn(x)` 인 f 는 **존재할 수 없다.**

이것이 왜 놀라운가. `sgn` 은 딱히 이상한 함수가 아니다. 왼쪽에서 기울기 −1로 내려오다 오른쪽에서 기울기 +1로 올라가는 그래프 — 즉 **`|x|`** — 를 떠올리면 "그 도함수가 sgn 아니냐"고 하고 싶어진다. 그런데 `|x|` 는 **원점에서 미분가능하지 않다** [3]. 원점을 빼면 맞지만, **모든 점에서** 미분가능한 함수의 도함수로는 sgn 이 나올 수 없다.

한 줄로 정리하면 이렇다.

> **도함수는 요동칠 수는 있어도 점프할 수는 없다.**

수학백과는 여기에 실무적 경고를 덧붙인다 — "국내외 각종 시험에서 다르부 정리를 인지하지 못한 출제자들이 사잇값 성질을 만족하지 않는 `f′(x)` 를 제시하는 경우가 있어 논란을 일으키기도 한다" [1]. 즉 **"도함수가 이러이러하다"고 주어진 문제는 그 자체로 모순일 수 있다.**

## 7. 흔한 오해·FAQ

**Q1. 미분가능하면 도함수도 연속 아닌가?**
아니다. 그 둘은 별개다. "미분가능하면 **함수 f 가** 연속"이 참이고 [3], "미분가능하면 **f′ 이** 연속"은 거짓이다 [1]. 두 문장에서 연속의 주어가 다르다는 것이 핵심이다. 헷갈리는 이유는 교과서에서 다루는 함수가 전부 후자까지 만족하기 때문이다.

**Q2. `f′(0) = 0` 인데 `f′(x)` 의 극한이 없다니 모순 아닌가?**
모순이 아니다. **미분계수는 극한으로 정의되지만, 도함수의 연속성은 또 다른 극한**이다. `f′(0)` 은 `(f(h)−f(0))/h` 의 극한이고, `f′` 의 연속성은 `f′(x)` 자체의 극한이다. 앞은 존재하고 뒤는 없다 — 서로 다른 두 극한이니 충돌하지 않는다.

**Q3. 그러면 `lim_{x→a} f′(x)` 를 구해서 `f′(a)` 로 써도 되나?**
**극한이 존재한다면** 써도 된다. 실제로 정리가 있다 — f 가 a 에서 연속이고 a 근방(a 는 빼고)에서 f′ 이 존재하며 `lim_{x→a} f′(x)` 가 **존재하면**, `f′(a)` 도 존재하고 그 극한과 같다 [7]. 문제는 반대다. 이 절차는 **극한이 없을 때 아무것도 말해 주지 않는다.** `x² sin(1/x)` 가 정확히 그 경우이고, 여기서는 정의로 돌아가는 수밖에 없다.

**Q4. 도함수의 불연속은 그러면 어떤 모양인가?**
**요동(진동)이다.** Q3의 정리를 뒤집으면 이렇게 된다 — `f′` 이 a 에서 불연속이면 좌·우 한쪽 극한이 **아예 존재하지 않는다** [7]. 그래서 "왼쪽에서는 1로 가고 오른쪽에서는 2로 간다" 같은 **점프형 불연속은 도함수에게 불가능**하다. 값이 안 정해지는 방식으로만 끊길 수 있다[^제2종불연속].

**Q5. 이런 함수가 실제로 쓸모가 있나, 아니면 병리적 예시일 뿐인가?**
쓸모의 방향이 다르다. 이 예시는 **계산 도구가 아니라 가정의 필요성을 보여 주는 증거**다. 로피탈 정리·테일러 정리·역함수 정리가 조건에 C¹ 을 적을 때, "그 조건이 없으면 정말 깨지느냐"에 답하는 것이 이런 반례다. 게다가 여기서 한 발 더 가면 **도함수가 리만적분조차 안 되는 함수**(볼테라 함수)가 나온다 [8]. 리만 적분은 구간을 잘게 나눠 각 소구간에서 고른 점의 함숫값으로 합을 만들고 그 극한을 취하는데, f 가 연속이면 점을 어떻게 고르든 같은 값에 수렴한다 [5]. 볼테라의 도함수는 그 수렴이 깨지는 자리이고, 그것이 르베그 적분이 필요했던 이유 중 하나가 된다. 확장편에서 다룬다.

## 8. 한눈 요약

| 물음 | 답 | 근거 |
|---|---|---|
| 미분가능 ⇒ 연속? | **참** | [3] |
| 연속 ⇒ 미분가능? | **거짓** (`\|x\|`) | [3] |
| 미분가능 ⇒ 도함수 연속? | **거짓** (`x² sin(1/x)`) | [1][7] |
| 도함수가 점프할 수 있나? | **불가능** (다르부 정리) | [1][6] |
| 도함수가 요동칠 수 있나? | **가능** | [1][7] |

한 문장으로: **미분가능성은 도함수의 존재만 보장하지, 그 도함수의 품행까지 보장하지 않는다. 다만 다르부 정리가 최소한의 품행 — 사잇값 성질 — 을 강제한다.**

## 더 깊이 — 확장편으로

이해편은 반례 하나와 다르부 정리의 **진술**까지 다뤘다. 확장편 **[[도함수의 불연속]]** 은 여기서부터 간다.

- **다르부 정리의 증명 두 가지** — 최대최소 정리를 쓰는 길과, 평균값 정리 + 중간값 정리를 쓰는 길 [1][6].
- **"제2종 불연속만 가능하다"의 증명** — 왜 제거가능·점프형이 원천 봉쇄되는가 [7].
- **도함수는 베르 1류(Baire class 1)다** — 도함수가 연속함수열의 점별극한이라는 사실에서, **도함수는 반드시 조밀한 집합에서 연속**이라는 결론이 나온다. 그래서 **디리클레 함수는 도함수가 될 수 없다** [7].
- **볼테라 함수(1881)** — 모든 점에서 미분가능하고 도함수가 유계인데, **도함수가 리만적분 불가능**하다 [8]. 미적분 기본정리의 서술이 왜 지금의 모양인지가 여기서 설명된다.
- **정확한 특성화** — 어떤 집합이 도함수의 불연속점 집합이 될 수 있는가에 대한 완전한 답 [6][7].

[^제2종불연속]: 좌·우 한쪽 극한이 아예 존재하지 않는 불연속. 극한은 있는데 함숫값과 다른 경우(제거가능)나, 좌우 극한이 둘 다 있으나 서로 다른 경우(점프)와 구별된다. 도함수에게는 이 유형만 허용된다 [7].

## 후속 질문·연결

- 도함수가 **불연속인 점이 무한히 많을** 수도 있나? → 있다. 조밀한 집합에서도 가능하다 [7]. → [[도함수의 불연속]]
- 그렇다면 도함수가 **모든 점에서** 불연속일 수도 있나? → 없다. 도함수는 조밀한 집합에서 반드시 연속이다 [7].
- 도함수를 항상 적분해 원래 함수를 되찾을 수 있나? → **아니다.** 볼테라 함수가 반례다 [8].
