# 미적분의 엄밀화 (확장편)

> 이해편은 **누가 무엇을 했는가**를 따라갔다. 확장편이 다루는 것은 그 뒤에 남은 **불편한 사실**이다 — 뉴턴도 라이프니츠도, 자기 방법이 **왜 옳은지 설명하지 못했다.** 1734년 버클리 주교는 이를 **"사라진 양의 유령"**이라 조롱했고, 그 조롱은 **정당했다.** 미적분은 발명된 지 **약 150년이 지나서야** 논리적으로 봉합된다. 이 글은 배로의 접선 알고리즘을 실제로 굴려 보고, 뉴턴·라이프니츠의 정당화 시도가 어디서 무너지는지 짚고, 코시–바이어슈트라스의 봉합과 20세기의 반전(무한소의 부활)까지 따라간다.

## TL;DR
- **배로는 사실상 알고리즘을 가지고 있었다.** 곡선 식에 `x → x+e`, `y → y+a`를 넣고 **`a`, `e`의 고차항을 버린 뒤 `a/e`를 구하는** 그의 접선법은, 현대의 음함수 미분과 **계산 단계가 일치**한다 [7][8].
- **차이는 언어와 야망이었다.** 배로는 결과를 **부분접선 길이**라는 기하량으로 냈고, 그것을 **함수 일반에 대한 연산자**로 승격시키지 않았다 [7].
- **뉴턴의 정당화 = "처음과 마지막 비"**(prime and ultimate ratios). 『프린키피아』 제1권 제1절 11개 보조정리가 그의 극한 이론이며, "**사라지기 전도 사라진 후도 아닌, 사라지는 그 순간의 비**"라는 서술은 근대적 극한 개념에 매우 가깝다 [9][16].
- **라이프니츠의 정당화 = "무한소는 유용한 허구"**. 그는 `dx`의 실재성 주장을 점차 물리고, **답이 맞으니 쓰라**는 실용적 태도로 후퇴했다 [12].
- **버클리의 공격(1734)이 정확했다.** `dx ≠ 0`으로 나눈 뒤 `dx = 0`으로 버리는 것은 모순이며, 옳은 답이 나오는 것은 **오차가 상쇄되기 때문**이라고 그는 지적했다 [10][11].
- **봉합은 코시(1821)와 바이어슈트라스**가 했다. 무한소를 버리고 **극한**을 원시 개념으로 삼았고, ε–δ 논법으로 "한없이 가까워진다"를 **부등식**으로 번역했다 [5][13][14].
- **반전**: 1966년 로빈슨의 **비표준 해석학**이 무한소를 논리적으로 정당한 대상으로 되살렸다. 라이프니츠의 직관은 틀린 게 아니라 **약 300년 이른 것**이었다 [15].

## 핵심 포인트
1. **"버려도 되는가"가 미적분 300년의 유일한 쟁점**이었다 — 계산법이 아니라 정당화가 문제였다.
2. **배로의 `a/e`가 곧 `dy/dx`**다. 역사적 거리는 개념이 아니라 **표현 수단**에 있었다 [7].
3. **뉴턴의 극한 개념은 오해받았다** — 그는 무한소론자가 아니라 **초기 극한론자**에 가깝다 [9][16].
4. **좋은 기호는 정리(theorem)를 자동화한다** — 연쇄법칙·치환적분이 라이프니츠 표기에서 "보이는" 이유 [4].
5. **엄밀화는 자유를 준다.** ε–δ가 있어야 균등수렴·급수 재배열 같은 병리적 사례를 통제할 수 있다 [13][14].
6. **표기 고집의 대가는 제도로 되돌아온다** — 영국은 1810년대에야 라이프니츠 표기로 갈아탔다 [17].

## 1. 직관 압축 — 이해편 한 문단

17세기에 흩어져 있던 넓이·접선 기법을, 뉴턴은 **운동(유량–유율)**의 언어로, 라이프니츠는 **무한소의 대수(`d`·`∫`)**로 각각 일반화했다. 두 체계를 하나로 묶는 축은 **미적분학의 기본정리** — 미분과 적분이 서로 역연산이라는 사실 — 이며, 이 정리를 처음 명확히 증명한 사람은 뉴턴의 스승 **아이작 배로**였다 [5][6][7]. 이하는 **그 체계들이 논리적으로 어디서 새는가**에서 출발한다.

## 2. 정의·메커니즘 — 세 체계를 현대 언어로

### 2-1. 배로: 미분 삼각형과 부분접선
배로의 도구는 곡선 위 한 점 주위의 아주 작은 직각삼각형 — 이른바 **미분 삼각형**[^미분삼각형] — 이다. 두 변을 `a`(세로 증분), `e`(가로 증분)라 하자.

```
                    ┌ 접선
            P ●─────┤
             ╱│ a   │        a : y 방향 증분
            ╱ │     │        e : x 방향 증분
       ────●──┘     │        t : 부분접선(subtangent)
           e        │
   ────┬─────────────────  x축
       │←──── t ────→│
```

닮음에서 곧바로 **`t : y = e : a`**, 즉

```
   t = y · e / a
```

**`a/e`가 오늘날의 `dy/dx`**이고, `t`는 `y ÷ (dy/dx)`다. 배로는 `a/e`를 **직접 구하는 절차**를 가지고 있었다(§3에서 실제로 굴린다).

### 2-2. 뉴턴: 유량·유율, 그리고 "처음과 마지막 비"
뉴턴은 변수를 시간에 따라 흐르는 **유량**으로, 그 속도를 **유율**로 놓았다 [2][3]. 계산은 무한소 증분 `o`를 도입해 전개한 뒤 `o`를 소거하는 방식이다.

문제는 **`o`를 무엇이라 부를 것인가**였다. 『프린키피아』(1687) 제1권 제1절 — 뉴턴이 **"처음과 마지막 비의 방법"**이라 이름 붙인 절 — 의 보조정리 11개가 그의 답이다 [9][16].

> 사라지는 양들의 **마지막 비**란 사라지기 전의 비도, 사라진 뒤의 비도 아니고, **사라지는 바로 그 순간의 비**다. 그것은 한없이 줄어드는 양들의 비가 **수렴해 가는 극한**이며, 주어진 어떤 차이보다도 가까이 다가가되 결코 넘어서지는 않는다 [16].

**이것은 사실상 극한의 서술이다.** 다만 "수렴한다"를 **부등식으로 정의하지 않았기 때문에**, 증명의 도구가 되지는 못하고 **설명에 머물렀다.**

### 2-3. 라이프니츠: 무한소의 대수와 그 대가
라이프니츠는 `dx`를 **0이 아니지만 어떤 양수보다도 작은 실제 크기**로 다뤘다. 이 가정에서 계산 규칙이 전부 따라 나온다 [4][12].

| 규칙 | 라이프니츠의 유도 방식 | 버리는 항 |
|---|---|---|
| 합 | `d(u+v) = du + dv` | 없음 |
| 곱 | `(u+du)(v+dv) − uv` | `du·dv` |
| 몫 | `u = wv`에 곱 규칙 적용 | `dw·dv` |
| 거듭제곱 | `(x+dx)ⁿ` 이항전개 | `(dx)²` 이상 |

**모든 규칙이 "고차 무한소를 버린다"는 한 가지 조작에 의존한다.** 그리고 그 조작의 정당성은 어디에도 없다. `dx ≠ 0`이어야 나눌 수 있고, `(dx)² = 0`이어야 버릴 수 있는데, **0이 아닌 수의 제곱은 0이 아니다.**

## 3. 왜 그런가 (유도) — 배로의 알고리즘을 실제로 굴리기

배로의 접선법은 다음 절차다 [7][8].

1. 곡선 식에서 `x → x + e`, `y → y + a`로 치환한다.
2. 전개한 뒤, **원래 식으로 상쇄되는 항**을 지운다.
3. **`a`, `e`의 2차 이상 항을 전부 버린다.**
4. 남은 식에서 `a/e`를 푼다.
5. 부분접선 `t = y·e/a`.

### Worked Example ① — 곡선 `x³ + y³ = r³`의 접선

**1~2단계**
```
   (x+e)³ + (y+a)³ = r³
   x³ + 3x²e + 3xe² + e³ + y³ + 3y²a + 3ya² + a³ = r³
```
`x³ + y³ = r³`을 빼면
```
   3x²e + 3xe² + e³ + 3y²a + 3ya² + a³ = 0
```

**3단계 — 고차항 버리기**
```
   3x²e + 3y²a = 0
```

**4단계**
```
   a/e = − x² / y²
```

**5단계**
```
   t = y · e/a = y · (− y²/x²) = − y³ / x²
```

**현대적 검산 (음함수 미분)**
```
   3x² + 3y²·(dy/dx) = 0   →   dy/dx = − x²/y²
   부분접선 = y ÷ (dy/dx) = y · (− y²/x²) = − y³/x²
```

**완전히 일치한다.** 배로의 `a/e`는 `dy/dx`이고, 그의 "고차항을 버린다"는 규칙은 라이프니츠의 "고차 무한소를 무시한다"와 **같은 조작**이다.

> 🔑 **핵심 관찰**: 배로에게 없던 것은 **알고리즘이 아니라 관점**이었다. 그는 결과를 `t`(길이)로 돌려줬다 — 즉 **기하학적 답**을 냈다. `a/e` 자체를 **함수에 딸린 새로운 대상**으로 승격시켰다면, 그것이 곧 도함수였다.

### Worked Example ② — 뉴턴의 유율 방정식

뉴턴이 실제로 다룬 형태의 음함수 `x³ − ax² + axy − y³ = 0`을 유율로 미분한다. 각 항을 시간에 대해 흐르는 양으로 보면

```
   3x²ẋ − 2axẋ + a(ẋy + xẏ) − 3y²ẏ = 0
```

`ẋ`, `ẏ`로 정리하면

```
   ẋ(3x² − 2ax + ay) + ẏ(ax − 3y²) = 0

   ẏ/ẋ = (3x² − 2ax + ay) / (3y² − ax)
```

**현대 표기로 옮기면 그대로 `dy/dx`다.** 뉴턴의 방식이 라이프니츠보다 불리했던 점은 계산력이 아니라, **`ẋ`가 "무엇으로 미분했는지"를 표시하지 않는다**는 것이다. 위 식에서 `ẏ/ẋ`라는 **비를 따로 만들어야** 비로소 `dy/dx`가 된다 — 표기가 한 단계를 더 요구한다.

### Worked Example ③ — 라이프니츠 표기가 정리를 대신 기억해 준다

**곱의 미분법**
```
   d(uv) = (u+du)(v+dv) − uv
         = u·dv + v·du + du·dv
         ≈ u·dv + v·du          ← du·dv 버림
```

**몫의 미분법** — `w = u/v` 즉 `u = wv`에 위 결과를 적용
```
   du = w·dv + v·dw
   dw = (du − w·dv)/v = (du − (u/v)dv)/v

   dw = (v·du − u·dv) / v²
```

**연쇄법칙**
```
   dy/dx = (dy/du) · (du/dx)      ← 형식상 약분처럼 보인다
```

**치환적분**
```
   ∫ f(u) du    에서   u = g(x),  du = g′(x)dx
   → ∫ f(g(x))·g′(x) dx
```

`du`를 **실제로 치환해 넣는** 이 조작은 라이프니츠 체계에서는 자연스럽고, 유율 표기에서는 별도 규칙으로 외워야 한다. **표기가 정리를 흡수한 것**이며, 이것이 대륙 수학이 앞서 나간 실질적 이유다 [4][17].

## 4. 대표 응용 — 기본정리를 두 방식으로 증명하기

### 4-1. 배로식(기하학적) 증명 스케치
`A(x)`를 `0`부터 `x`까지 `f`의 아래 넓이라 하자. `x`에서 `x+e`까지의 넓이 증분은 **높이 `f`인 가느다란 띠**다.

```
        f(x+e) ┄┄┄┄┄┐
        f(x)   ┄┄┄┐ │
                  │▓│  ← 증분 ΔA
   ───────────────┴─┴──────
                  x x+e
```

띠의 넓이는 두 직사각형 사이에 낀다.
```
   f_min · e  ≤  ΔA  ≤  f_max · e
   f_min ≤ ΔA/e ≤ f_max
```
`e`가 줄면 `f_min`, `f_max`가 모두 `f(x)`로 몰리므로 `ΔA/e → f(x)`, 즉

```
   A′(x) = f(x)
```

**넓이 곡선의 접선 기울기 = 원래 곡선의 높이.** 배로가 제10강 명제 11에서 기하로 보인 것이 이것이다 [7][8].

> 위 논증에서 **"몰린다"는 말이 전부**다. 배로도 뉴턴도 라이프니츠도 이 말을 정의하지 못했다. 그것을 정의한 것이 §6의 코시–바이어슈트라스다.

### 4-2. 응용 — 왜 이 정리가 계산을 바꾸는가
기본정리 이전에 넓이를 구하는 일은 **매번 무한합을 직접 계산**하는 일이었다. 예를 들어 `y = x²`의 `0~a` 넓이를 구간을 `n`등분해 구하면

```
   Σ (k=1..n) (ka/n)² · (a/n)
 = (a³/n³) · Σ k²
 = (a³/n³) · n(n+1)(2n+1)/6
 = (a³/6) · (1 + 1/n)(2 + 1/n)
 → a³/3      (n → ∞)
```

**한 곡선을 위해 급수 합 공식 하나가 필요하다.** 반면 기본정리를 쓰면

```
   ∫₀ᵃ x² dx = [x³/3]₀ᵃ = a³/3
```

**"미분하면 `x²`이 되는 것"을 찾는 문제로 바뀐다.** 넓이 계산이 무한합에서 **역연산 탐색**으로 격하되는 것 — 이것이 미적분이 실용적으로 폭발한 이유다 [5][6].

## 5. 통합 의미 — 버클리의 공격이 정확했던 이유

### 5-1. 『해석학자』(1734)
아일랜드의 철학자이자 성직자 **조지 버클리**는 1734년 『해석학자, 또는 어느 신앙 없는 수학자에게 부치는 담론』을 발표했다 [10][11]. 표적은 뉴턴의 유율이었고, 논지는 **"당신들은 종교의 신비를 비웃지만, 당신들의 수학이야말로 이해 불가능한 것을 믿고 있다"**였다.

가장 유명한 대목(제34절)은 이렇다.

> 이 유율이란 무엇인가? **사라져 가는 증분의 속도**다. 그럼 그 사라져 가는 증분이란 무엇인가? 그것은 **유한한 양도 아니고, 무한히 작은 양도 아니고, 그렇다고 아무것도 아닌 것도 아니다.** 그렇다면 **사라진 양의 유령**이라 불러도 되지 않겠는가? [10][11]

### 5-2. 공격의 논리적 핵심
버클리의 지적은 조롱이 아니라 **정확한 논리 비판**이었다. Worked Example ①을 다시 보자.

```
   3x²e + 3xe² + e³ + 3y²a + 3ya² + a³ = 0
```

여기서 `e`로 나누려면 **`e ≠ 0`**이어야 한다. 그런데 그 다음 단계에서 `e²`, `e³` 항을 버리는 근거는 **`e`가 0이나 다름없다**는 것이다.

```
   e ≠ 0   (나누기 위해)          ← 전제 A
   e ≈ 0   (버리기 위해)          ← 전제 B
   A와 B는 양립하지 않는다.
```

버클리는 한 걸음 더 나아가, 미적분이 옳은 답을 내는 것은 **두 개의 오차가 서로 상쇄되기 때문**이라고 주장했다("오차의 보상") [11]. 즉 **결과가 맞다는 것이 방법이 옳다는 증거가 아니다**라는, 반박하기 매우 어려운 지적이다.

### 5-3. 즉각적 효과
버클리의 비판은 **미적분을 멈추지 못했다** — 결과가 너무 잘 맞았기 때문이다. 대신 **정당화 작업을 촉발**했다. 매클로린은 고전 기하학의 극한 논증으로 유율법을 옹호하려 했고, 대륙에서는 오일러가 `dx`를 **실제로 0인 양**으로 다루는 형식적 체계를 세우려 했다. **어느 쪽도 완전하지 않았다** [11].

## 6. 봉합 — 코시에서 바이어슈트라스까지

### 6-1. 코시(1821): 무한소를 극한에 종속시키다
**오귀스탱-루이 코시**는 『해석 교정(Cours d'analyse)』(1821)에서 순서를 뒤집었다 [13].

> 어떤 변수에 차례로 부여되는 값들이 한 고정된 값에 **한없이 가까워져 마침내 원하는 만큼 작은 차이만 남기게 되면**, 그 고정된 값을 나머지 모두의 **극한**이라 부른다 [13].

핵심은 다음이다.
- **극한이 원시 개념**이 되고, 무한소는 **"극한이 0인 변수"**로 *정의*된다.
- 즉 무한소는 **어떤 크기(상수)가 아니라 과정**이다. 버클리가 공격한 "0도 아니고 0이 아닌 것도 아닌 것"이라는 **범주 자체가 사라진다.**

이것으로 도함수를 `lim (f(x+h) − f(x))/h`로 정의할 수 있게 됐다. `h`는 **끝까지 0이 아니며**, 0이 되는 일이 없으므로 **모순이 발생하지 않는다.**

### 6-2. 바이어슈트라스: "한없이 가까워진다"를 부등식으로
코시의 정의에도 **"한없이"·"원하는 만큼"** 같은 서술적 표현이 남아 있었다. **카를 바이어슈트라스**가 이를 **부등식만으로** 바꾼 것이 **ε–δ 논법**이다 [5][14].

```
   lim (x→a) f(x) = L
   ⟺  임의의 ε > 0 에 대하여, 어떤 δ > 0 이 존재해
       0 < |x − a| < δ  이면  |f(x) − L| < ε
```

| 표현 | 이전 | ε–δ 이후 |
|---|---|---|
| "한없이 가까워진다" | 직관·운동 이미지 | `∀ε ∃δ` |
| 무한소 `dx` | 신비한 크기 | **등장하지 않음** |
| 증명 | 그림·설득 | **부등식 조작** |

**시간과 운동이 정의에서 완전히 제거된 것**이 결정적이다. 뉴턴의 "흐름"은 직관으로만 남고, 논리는 정적인 부등식이 떠맡는다 [5][14].

### 6-3. 봉합의 남은 절차
| 시기 | 인물 | 채운 구멍 |
|---|---|---|
| 1821 | 코시 | 극한을 원시 개념으로 [13] |
| **1854 발표 / 1868 출판** | 리만 | 적분의 정의와 가적분 조건 [21] |
| 1860s~ | 바이어슈트라스 | ε–δ, 균등수렴 [5][14] |
| 1872 | 데데킨트·칸토어 | **실수 자체의 구성**(절단 / 코시열) — 극한이 존재할 바탕 [22] |
| 1902 | 르베그 | 측도론적 적분 — 소르본 학위논문 [23] |

주목할 점은 **실수의 엄밀한 구성이 1872년**이라는 것이다. 즉 **미적분은 자기 무대(실수)가 정의되기 전에 200년을 먼저 걸었다.** 수학이 늘 논리 순서대로 발전하지는 않는다는 좋은 사례다 [22]. 극한이라는 개념 자체도 그 바탕 위에서야 온전히 정의된다 [18].

## 7. 반전 — 무한소의 부활(1966)

**에이브러햄 로빈슨**은 1966년 『비표준 해석학』에서, 모형 이론을 써서 실수를 확장한 **초실수(hyperreal)** 체계를 구성했다 [15].

- 초실수에는 **0이 아니면서 모든 양의 실수보다 작은 원소**(무한소)가 **정식 원소로 존재**한다.
- `dy/dx`를 **진짜 몫**으로 계산한 뒤, **표준부분**(무한소를 떼어 내는 사상)을 취하면 도함수가 나온다.
- 이 체계는 **논리적으로 실수 해석학과 같은 정도로 무모순**임이 보장된다.

```
   라이프니츠(1675)   dy/dx = 진짜 분수   →  "정당화 못함"
   바이어슈트라스     dy/dx = 극한 기호   →  "무한소 추방"
   로빈슨(1966)       dy/dx = 진짜 분수   →  "논리적으로 정당"
```

즉 **라이프니츠의 직관은 틀린 것이 아니라, 그것을 떠받칠 논리 도구(모형 이론)가 300년 뒤에 나온 것**이다 [15].

> ⚠️ 단, 오늘날 표준 교육과정과 연구의 기본 언어는 **여전히 ε–δ**다. 비표준 해석학은 강력하지만 **대안 언어**이지 대체 언어가 아니다.

## 8. 표기가 만든 제도 — 영국은 왜 100년을 잃었나

우선권 논쟁의 실질적 결과는 **표기의 분단**이었다 [4][17].

| | 대륙 | 영국 |
|---|---|---|
| 표기 | `dy/dx`, `∫` | `ẋ`(점) |
| 18세기 주역 | 베르누이 형제, 오일러, 라그랑주, 라플라스 | — |
| 전환 시점 | — | **1810년대 이후** |

케임브리지에서는 **시험 제도 자체가 뉴턴 표기를 요구**했다 [17]. 이 고착을 깬 것이 1812년 **배비지·허셜·피콕** 등이 결성한 **해석학회(Analytical Society)** — 라이프니츠 표기를 케임브리지에 도입하려는 목적의 학생 모임이었다 [17].

- 1803년 우드하우스가 라이프니츠 표기 저서를 냈고,
- **1817년 피콕이 상원 시험에 라이프니츠 기호를 도입**,
- 1820년 휴얼이 뒤따르고, 1821년 재차 사용되며 정착,
- **1830년경 널리 채택**됐다 [17].

> 📌 교훈은 수학 내적이지 않다. **표기는 학습·시험·교재·평가에 얽혀 제도가 되고, 제도가 되면 바꾸는 데 세대가 걸린다.** 뉴턴의 개인적 승리가 영국 수학의 집단적 손실이 된 경위다.

## 9. 🗺️ 개념 발전 지도

| 축 | 내용 |
|---|---|
| **가정을 풀면** | ① `dx`를 "실수"로 요구하지 않고 **확장체의 원소**로 허용 → 비표준 해석학(로빈슨) [15]. ② 함수를 매끄럽다고 가정하지 않으면 → 바이어슈트라스의 **어디서도 미분 불가능한 연속함수**, 프랙탈 해석. ③ 적분 대상을 리만 가적분으로 제한하지 않으면 → **르베그 적분**·측도론. ④ 극한을 점별이 아니라 **균등**으로 요구하면 → 함수열의 미분·적분 교환 정리 |
| **무엇이 열리나** | 미분방정식(뉴턴 역학의 언어), 변분법(최소작용), 복소해석(코시 적분정리), 푸리에 해석, 함수해석학, 확률론(측도), 미분기하(다양체 위의 미적분) |
| **어디서 쓰나** | 물리 전 분야, 공학 제어·신호, 경제학의 한계 분석, 기계학습의 경사하강과 역전파(연쇄법칙의 대규모 자동화), 컴퓨터 그래픽스의 곡면 |
| **더 알아야 할 것** | 실수의 완비성(상한 공리), 균등연속·균등수렴, 리만 vs 르베그의 차이, 미분형식과 일반화된 스토크스 정리(기본정리의 최종 형태), 모형 이론 기초 |

**기본정리의 최종 형태**를 하나만 언급하자면, 미분형식의 언어로 쓴

```
   ∫(∂M) ω  =  ∫(M) dω
```

가 그것이다. 배로가 제10강 명제 11에서 곡선 하나에 대해 보인 사실이, **임의 차원의 다양체와 그 경계**에 대한 진술로 확장된 모습이다. 미적분학 기본정리·그린 정리·발산 정리·스토크스 정리가 전부 이 한 줄의 특수한 경우다.

## 10. 함정·체크리스트

- [ ] **"뉴턴은 무한소론자였다"고 단정하지 말 것.** 그는 무한소 증분 `o`를 쓰기도 했지만, 『프린키피아』에서는 **"처음과 마지막 비"**라는 극한적 서술로 정당화하려 했다 [9][16]. 무한소를 실체로 밀어붙인 쪽은 라이프니츠에 가깝다.
- [ ] **"라이프니츠는 무한소가 실재한다고 끝까지 믿었다"도 부정확하다.** 그는 후기에 **유용한 허구**라는 입장으로 이동했다 [12].
- [ ] **"버클리 때문에 미적분이 위기에 빠졌다"는 과장이다.** 계산은 멈추지 않았고, 그의 비판은 **정당화 연구를 촉발**했다 [11].
- [ ] **`dy/dx`를 분수로 다루는 조작을 무비판적으로 일반화하지 말 것.** 표준 해석학에서 `dy/dx`는 **하나의 기호**다. 연쇄법칙·치환적분에서 분수처럼 보이는 것은 **정리가 그렇게 성립하기 때문**이지 약분이 근거가 아니다.
- [ ] **"발견이 먼저 = 우선권"도 "출판이 먼저 = 우선권"도 단일 기준이 아니다.** 두 기준이 정반대를 가리키는 것이 이 사건의 본질이다(이해편 §8).
- [ ] **연도 인용 시 "완성"과 "출판"을 구분할 것.** 『유율법』은 **1671년 완성, 1736년 출판**이다 [3]. 이를 뭉뜽그리면 우선권 서술이 통째로 틀어진다.
- [ ] **국내 자료의 시기 서술 충돌에 주의.** 일부 국내 백과는 라이프니츠를 먼저, 뉴턴을 나중으로 서술하는데 [2], 이는 **출판 순서** 기준으로 읽어야 하며 **발견 시점** 기준 서술 [19]과는 순서가 반대다.
- [ ] **ε–δ를 "어려운 형식주의"로만 치부하지 말 것.** 그것이 있어야 **극한과 적분의 교환, 급수의 항별 미분** 같은 실용적 판단이 가능해진다 [14].

**마지막 한 줄** — 미적분의 역사는 **"계산은 옳은데 이유를 모르는 상태"를 300년 견딘 기록**이다. 배로는 절차를 가졌으나 대상으로 승격시키지 못했고, 뉴턴과 라이프니츠는 대상을 만들었으나 근거를 대지 못했으며, 버클리는 근거가 없음을 정확히 짚었고, 코시와 바이어슈트라스는 근거를 **새로 만들어** 끼워 넣었다. 그리고 로빈슨은 **버려졌던 직관이 옳았음**을 뒤늦게 증명했다. 수학이 스스로를 고쳐 나가는 방식이 이 한 줄기에 다 들어 있다.

- **[[르베그 적분]]** — 리만 적분이 못 다루는 함수는 무엇인가
- **[[비표준 해석학]]** — 초실수 위에서 미적분을 처음부터 다시 쓰면
- **[[실수의 구성]]** — 완비성 없이는 왜 극한이 존재하지 않는가

## 갤러리 안의 이웃 글
이 글이 짚은 지점들은 이미 이 갤러리에 있는 다른 보고서로 곧장 이어진다.
- **무한의 크기(`infinity-set-theory`)** — §6-3의 "1872년 실수의 구성"에서 등장한 **칸토어**가, 거기서는 실수가 왜 셀 수 없는가를 대각선 논법으로 보인다. 실수를 *구성한* 이야기와 실수를 *센* 이야기가 짝을 이룬다.
- **코시 평균값 정리(`mean-value-theorem-advanced`)** — §6-1에서 극한을 원시 개념으로 세운 그 **코시**의 정리다. 이 글이 코시의 *기초 작업*을, 그 글이 코시의 *도구*를 다룬다.
- **로피탈 정리(`lhopital-rule-advanced`)** — 이해편 §5-4에서 언급한 **1696년 최초의 미적분 교과서**가 어떤 정리를 실었고, 그 정리의 실제 발견자가 왜 요한 베르누이로 여겨지는지를 그 글이 이어받는다.
