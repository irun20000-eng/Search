# 코시 평균값 정리 (확장편)

> 이해편이 **"한 함수의 평균은 반드시 달성된다"**였다면, 확장편은 **"두 함수를 동시에 보면 무엇이 열리는가"**다. **코시 평균값 정리(Cauchy Mean Value Theorem)**는 평균값 정리를 두 함수의 **비(比)**로 확장한 것인데 [6], 이 확장 하나로 **로피탈 정리**와 **테일러 정리**가 열린다. 그런데 여기엔 함정이 있다 — **"평균값 정리를 두 번 쓰면 되지 않나?"**는 자연스러운 발상이 **틀린다.** 이 글은 그 이유부터 시작해 증명·의미·활용까지 파고든다.

## TL;DR
- **코시 평균값 정리(CMVT)**: f, g가 [a, b]에서 연속·(a, b)에서 미분가능하면
  `[f(b) − f(a)]·g′(c) = [g(b) − g(a)]·f′(c)` 인 c가 (a, b)에 존재한다 [6][8].
- **핵심 함정**: MVT를 f와 g에 **각각** 적용하면 `f′(c₁)/g′(c₂)`가 되어 **점이 서로 다르다**. 코시 정리의 값어치는 **"같은 한 점 c"**를 보장한다는 데 있다 [6][9].
- **증명은 보조함수 한 줄**: `h(x) = [f(b) − f(a)]·g(x) − [g(b) − g(a)]·f(x)` 를 만들면 h(a) = h(b)가 되어 **롤의 정리**가 그대로 먹는다 [2][8].
- **왜 곱셈 꼴로 쓰나**: 분수 꼴 `[f(b)−f(a)]/[g(b)−g(a)] = f′(c)/g′(c)` 는 **g(a) ≠ g(b)와 g′(c) ≠ 0**을 요구한다. **곱셈 꼴이 더 일반적이고 안전**하다 [6].
- **가치 ①**: **로피탈 정리**의 엄밀한 근거. 0/0 부정형에서 f/g와 f′/g′를 잇는 다리가 바로 CMVT다 [4][10].
- **가치 ②**: **테일러 정리**의 잉여항. MVT는 테일러 정리의 **n = 0인 특수한 경우**다 [11].
- **한계**: 벡터값 함수에서는 평균값 **등식**이 깨진다(원운동 반례). 그래서 해석학은 **평균값 부등식**으로 갈아탄다 [13].

## 핵심 포인트
1. CMVT는 **매개변수 곡선의 MVT** — (g(t), f(t)) 곡선의 할선과 평행한 접선 [6].
2. **g(x) = x**로 놓으면 CMVT가 곧바로 **보통 MVT**가 된다(진짜 일반화) [6].
3. 증명은 **롤 → MVT → CMVT** 사슬의 마지막 고리. 도구는 언제나 **보조함수** [2].
4. **로피탈**은 CMVT의 직접적 따름정리 [4][10].
5. **테일러 정리(라그랑주 잉여항)**는 MVT의 고차 일반화 [11].
6. **적분 평균값 정리**는 같은 아이디어의 적분판 [12].

## 1. 왜 두 함수인가 — 문제 상황부터

이해편의 평균값 정리는 **한 함수**에 대한 이야기였다.

`f(b) − f(a) = f′(c)·(b − a)`

그런데 실전에서는 **두 함수의 비**를 다뤄야 할 때가 많다. 대표적인 것이 **0/0 부정형의 극한**이다:

`lim(x→a) f(x)/g(x)`  (f(a) = g(a) = 0)

여기서 우리가 알고 싶은 것은 **f와 g가 각각 얼마나 빨리 0으로 가는가의 비**다. 한 함수짜리 MVT로는 f와 g를 **따로따로** 다룰 수밖에 없는데, 곧 보겠지만 그렇게 하면 **결정적인 문제**가 생긴다.

또 하나의 동기는 **매개변수 곡선**이다. 평면 위를 움직이는 점 `(x, y) = (g(t), f(t))`를 생각하자. t = a에서 t = b까지 움직였을 때, **출발점과 도착점을 잇는 할선과 평행한 접선**이 도중에 있을까? 곡선의 접선 기울기는 `dy/dx = f′(t)/g′(t)`이고 할선의 기울기는 `[f(b) − f(a)]/[g(b) − g(a)]`이므로, 이 질문이 정확히 코시 평균값 정리다 [6].

## 2. 함정 — "MVT를 두 번 쓰면 되지 않나?"

가장 자연스러운 시도부터 해 보자. f와 g에 **각각** 평균값 정리를 적용한다.

- `f(b) − f(a) = f′(c₁)·(b − a)`  (어떤 c₁ ∈ (a, b))
- `g(b) − g(a) = g′(c₂)·(b − a)`  (어떤 c₂ ∈ (a, b))

나누면 (b − a)가 약분되어

`[f(b) − f(a)] / [g(b) − g(a)] = f′(c₁) / g′(c₂)`

그럴듯해 보인다. 그런데 **치명적인 결함**이 있다.

> ⚠️ **c₁과 c₂는 서로 다른 점이다.** MVT는 각 함수마다 **자기 나름의 점**을 줄 뿐, 두 함수에 대해 **같은 점**을 준다고 보장하지 않는다 [9].

이게 왜 문제인가? 로피탈 정리를 쓰려면 `f′(c)/g′(c)` — **같은 점에서의 도함수 비**가 필요하기 때문이다. `f′(c₁)/g′(c₂)`처럼 점이 어긋나 있으면, c₁과 c₂를 동시에 a로 보낸다 해도 **비의 극한을 통제할 수 없다.**

**구체적 확인.** f(x) = x², g(x) = x³, 구간 [1, 2]로 보자.
- 좌변: `(4 − 1)/(8 − 1) = 3/7 ≈ 0.4286`
- f에 MVT: `2c₁ = (4−1)/(2−1) = 3 → c₁ = 1.5`
- g에 MVT: `3c₂² = (8−1)/(2−1) = 7 → c₂ = √(7/3) ≈ 1.5275`
- 확인: `f′(c₁)/g′(c₂) = 3/7` ✓ (등식 자체는 맞다)
- 그러나 **c₁ ≈ 1.5 ≠ c₂ ≈ 1.5275**. 두 점이 실제로 다르다.

코시 평균값 정리가 주장하는 것은 바로 **"c₁ = c₂ = c인 단 하나의 점을 잡을 수 있다"**는 것이고, 그것이 이 정리의 **전부이자 값어치**다. 이렇게 존재가 보장되는 점을 **중간점**[^중간점]이라 부른다 — 이해편의 평균값 정리에서도 같은 이름의 점이었다 [3].

## 3. 진술 — 곱셈 꼴이 정본이다

> **코시 평균값 정리(Cauchy Mean Value Theorem).** f, g가
> - 닫힌구간 **[a, b]에서 연속**이고
> - 열린구간 **(a, b)에서 미분가능**
>
> 하면, 다음을 만족하는 c ∈ (a, b)가 **적어도 하나 존재**한다 [6][8]:
>
> `[f(b) − f(a)] · g′(c) = [g(b) − g(a)] · f′(c)`

### 3-1. 분수 꼴과 그 조건
교과서에서 자주 보는 형태는 분수 꼴이다:

`[f(b) − f(a)] / [g(b) − g(a)] = f′(c) / g′(c)`

이 꼴로 쓰려면 **추가 조건**이 필요하다 — 분모가 0이면 안 되므로 **g(a) ≠ g(b)** 이고 **g′(c) ≠ 0**이어야 한다.

실용적으로는 **"(a, b)에서 g′(x) ≠ 0"**을 가정하는 경우가 많다. 이때 롤의 정리에 의해 자동으로 g(a) ≠ g(b)가 따라온다(만약 g(a) = g(b)라면 g′이 0이 되는 점이 생겨 가정에 어긋나기 때문이다) [6].

> 그래서 **곱셈 꼴이 정본**이다. 분모 조건을 신경 쓸 필요가 없고, 더 넓은 상황을 포괄한다.

### 3-2. 진짜 일반화인가 — g(x) = x 대입
CMVT에서 **g(x) = x**로 놓아 보자. 그러면 g′ = 1, g(b) − g(a) = b − a 이므로

`[f(b) − f(a)] · 1 = (b − a) · f′(c)`  →  `f(b) − f(a) = f′(c)(b − a)`

**정확히 평균값 정리다.** 즉 CMVT는 MVT를 **진짜로 포함하는** 일반화다 [6].

### 3-3. 기하적 의미 — 매개변수 곡선의 할선과 접선
점 `P(t) = (g(t), f(t))`가 그리는 곡선을 보자.
- **할선의 기울기**: `[f(b) − f(a)] / [g(b) − g(a)]`
- **접선의 기울기**: `dy/dx = f′(t)/g′(t)`  (단 g′(t) ≠ 0일 때)

CMVT는 **이 둘이 같아지는 순간 t = c가 있다**고 말한다. 이해편의 그림(할선과 평행한 접선)이 **매개변수 곡선으로 그대로 옮겨간 것**이다 [6].

```
        ●  P(b) = (g(b), f(b))
       /⟋
     /  ⟋  ← 접선 (할선과 평행)
   /  ⟋
  ●⟋
 P(a) = (g(a), f(a))
```

## 4. 증명 — 보조함수 하나면 끝난다

증명은 이해편과 **완전히 같은 전략**이다: **양 끝 값이 같아지도록 보조함수를 만들어 롤의 정리를 적용한다** [2][7][8].

**보조함수**를 다음과 같이 잡자:

`h(x) = [f(b) − f(a)] · g(x) − [g(b) − g(a)] · f(x)`

**1단계 — 양 끝 값 계산.**
- `h(a) = [f(b) − f(a)]·g(a) − [g(b) − g(a)]·f(a)`
  `= f(b)g(a) − f(a)g(a) − g(b)f(a) + g(a)f(a)`
  `= f(b)g(a) − g(b)f(a)`
- `h(b) = [f(b) − f(a)]·g(b) − [g(b) − g(a)]·f(b)`
  `= f(b)g(b) − f(a)g(b) − g(b)f(b) + g(a)f(b)`
  `= −f(a)g(b) + g(a)f(b) = f(b)g(a) − g(b)f(a)`

**h(a) = h(b)** ✓ (두 식 모두 `f(b)g(a) − g(b)f(a)`로 정확히 같다.)

**2단계 — 롤의 정리 적용.** h는 f, g의 상수배 합이므로 [a, b]에서 연속, (a, b)에서 미분가능하고 h(a) = h(b)다. 따라서 **롤의 정리**에 의해 `h′(c) = 0`인 c ∈ (a, b)가 존재한다.

**3단계 — 정리.**
`h′(x) = [f(b) − f(a)]·g′(x) − [g(b) − g(a)]·f′(x)`
이므로 h′(c) = 0은 곧

`[f(b) − f(a)]·g′(c) = [g(b) − g(a)]·f′(c)` □

> 증명의 교훈: **롤의 정리가 모든 것의 엔진**이다. MVT도 CMVT도 "양 끝을 같게 만드는 보조함수"를 어떻게 설계하느냐의 문제일 뿐이다. 보조함수는 **f와 g를 대칭적으로 섞어** 만든다는 점만 다르다.

## 5. 가치 ① — 로피탈 정리의 엄밀한 근거

CMVT의 가장 유명한 응용이다 [4][10].

**주장(0/0 판).** f(a) = g(a) = 0이고 a 근처에서 g′ ≠ 0이며 `lim(x→a) f′(x)/g′(x) = L`이면
`lim(x→a) f(x)/g(x) = L`

**증명.** x를 a 근처의 점이라 하고, **a와 x 사이의 구간**에 **코시 평균값 정리**를 적용한다(x > a면 [a, x], x < a면 [x, a] — 양쪽 극한 모두 같은 방식이다). 어떤 c(a와 x 사이)에 대해

`f(x)/g(x) = [f(x) − f(a)] / [g(x) − g(a)] = f′(c)/g′(c)`

(첫 등호는 f(a) = g(a) = 0이기 때문이다.) 이제 **x → a**로 보내면 c는 a와 x 사이에 끼어 있으므로 **c → a**(압축). 따라서

`lim(x→a) f(x)/g(x) = lim(c→a) f′(c)/g′(c) = L` □

> 여기서 **§2의 함정**이 왜 치명적이었는지 분명해진다. 만약 c₁ ≠ c₂였다면 `f′(c₁)/g′(c₂)`의 극한을 저렇게 한 번에 처리할 수 없다. **"같은 점 c"**를 보장하는 CMVT가 있어야 로피탈이 **증명**된다.

## 6. 가치 ② — 테일러 정리로 가는 계단

평균값 정리를 다시 써 보자.

`f(b) = f(a) + f′(c)(b − a)`

이것은 **"f를 0차 다항식(상수)으로 근사하고 오차를 도함수로 표현한 것"**이다. 이 발상을 **고차로 밀어붙인 것**이 테일러 정리다 [11]:

`f(b) = f(a) + f′(a)(b−a) + [f″(a)/2!](b−a)² + ⋯ + [f⁽ⁿ⁾(a)/n!](b−a)ⁿ + Rₙ`

여기서 f″는 **이계도함수**(도함수를 한 번 더 미분한 것)이고 [5], 차수가 올라갈수록 더 높은 계도함수가 등장한다. 단, 이 전개가 성립하려면 f가 **(a, b)에서 n+1번 미분가능**하고 f⁽ⁿ⁾이 [a, b]에서 연속이어야 한다 [11].

라그랑주 **잉여항**[^잉여항]은

`Rₙ = [f⁽ⁿ⁺¹⁾(c) / (n+1)!] · (b − a)ⁿ⁺¹`  (어떤 c ∈ (a, b))

**n = 0**을 넣으면 `f(b) = f(a) + f′(c)(b − a)` — **평균값 정리 그 자체**다.

> 즉 **MVT는 테일러 정리의 가장 낮은 층**이고, 테일러 정리는 MVT를 **n차까지 쌓아 올린 탑**이다. 그리고 잉여항의 **코시 형태**를 유도할 때는 코시 평균값 정리가 직접 쓰인다 [11].

## 7. 가치 ③ — 적분 평균값 정리

같은 아이디어의 **적분판**도 있다 [12].

> **적분 평균값 정리.** f가 [a, b]에서 연속이면
> `∫[a, b] f(x) dx = f(c) · (b − a)` 인 c ∈ (a, b)가 존재한다.

**뜻**: 곡선 아래 넓이를 **같은 밑변을 가진 직사각형**으로 바꿀 수 있고, 그 높이 f(c)가 곡선의 **평균 높이**다. "평균은 반드시 실제로 달성된다"는 이해편의 표어가 **적분에서도 그대로** 성립한다.

**미분판과의 연결**: F(x) = ∫[a, x] f 로 두면 미적분의 기본정리로 F′ = f 이고, F에 MVT를 쓰면
`∫[a,b] f = F(b) − F(a) = F′(c)(b − a) = f(c)(b − a)`
— **적분 평균값 정리는 MVT의 다른 얼굴**이다.

## 8. 한계 — 벡터값 함수에서는 등식이 깨진다

CMVT까지 왔으니 **어디까지 통하는지**도 알아야 한다. 결론부터: **벡터값(다차원) 함수에서는 평균값 '등식'이 성립하지 않는다** [13].

**반례(원운동).** `r(t) = (cos t, sin t)`를 [0, 2π]에서 보자.
- 양 끝: `r(0) = (1, 0)`, `r(2π) = (1, 0)` → **차이는 영벡터 (0, 0)**.
- 만약 MVT가 그대로 성립한다면 `r′(c)·(2π − 0) = (0, 0)`, 즉 **r′(c) = (0, 0)**인 c가 있어야 한다.
- 그런데 `r′(t) = (−sin t, cos t)`이고 그 크기는 **항상 1**이다. `|r′(t)| = √(sin²t + cos²t) = 1 ≠ 0`.
- → **그런 c는 존재하지 않는다.** 평균값 등식이 **깨졌다** [13].

직관적으로도 당연하다. 원을 한 바퀴 돌면 **제자리로 돌아오지만 한순간도 멈추지 않았다.** 성분별로 MVT를 쓰면 각 성분마다 **다른 c**가 나오고(§2의 함정과 같은 구조), 그 c들이 일치한다는 보장이 없다.

**그래서 대신 쓰는 것 — 평균값 부등식**[^평균값부등식]**.**
`|r(b) − r(a)| ≤ (b − a) · max |r′(t)|`

등식은 포기하고 **부등식**으로 바꾸면 다차원에서도 살아남는다. 고등 해석학에서 평균값 정리가 주로 **부등식 형태**로 등장하는 이유다 [13].

## 9. Worked Examples — 손으로 확인하기

**예 1) CMVT의 c를 직접 구하기.**
f(x) = x², g(x) = x³, 구간 [1, 2].
- 좌변: `[f(2) − f(1)] / [g(2) − g(1)] = (4 − 1)/(8 − 1) = 3/7`
- 우변: `f′(c)/g′(c) = 2c/(3c²) = 2/(3c)`
- 방정식: `2/(3c) = 3/7` → `14 = 9c` → **c = 14/9 ≈ 1.5556**
- 검산: `2/(3 · 14/9) = 2/(14/3) = 6/14 = 3/7` ✓ 그리고 **c ∈ (1, 2)** ✓
- 비교: §2에서 각각 MVT를 썼을 때는 c₁ = 1.5, c₂ ≈ 1.5275였다. **CMVT의 c ≈ 1.5556은 둘 중 어느 것과도 다르다** — 세 번째 점이다.

**예 2) 로피탈을 CMVT로 직접 확인.**
`lim(x→0) (eˣ − 1) / x²` … 가 아니라 먼저 `lim(x→0) (eˣ − 1)/x` 를 보자.
f(x) = eˣ − 1, g(x) = x. f(0) = g(0) = 0. 구간 [0, x]에 CMVT:
`(eˣ − 1)/x = f′(c)/g′(c) = e^c / 1 = e^c`  (0 < c < x)
x → 0이면 c → 0이므로 극한은 `e⁰ = 1`. ✓ (로피탈을 **정리로 인용하지 않고** CMVT에서 직접 얻었다.)

**예 3) 부등식 — 로그의 평균변화율 가두기.**
0 < a < b일 때 `(ln b − ln a)/(b − a)`의 범위를 잡아 보자.
f(x) = ln x, g(x) = x에 CMVT(= MVT)를 쓰면
`(ln b − ln a)/(b − a) = 1/c`  (a < c < b)
**1/x는 양수 구간에서 감소함수**이므로 a < c < b에서 `1/b < 1/c < 1/a`다. 따라서
`1/b < (ln b − ln a)/(b − a) < 1/a`
가 즉시 나온다. **평균변화율을 양 끝의 도함수 값 사이에 가둔 것**이다.
(검산: a = 1, b = 4이면 가운데 값은 (ln 4)/3 ≈ 0.4621이고, 실제로 1/4 = 0.25 < 0.4621 < 1 = 1/1 ✓)

**예 4) 테일러 잉여항 확인.**
f(x) = eˣ, a = 0, n = 1로 테일러 정리를 쓰면
`eˣ = 1 + x + [e^c/2!]·x²`  (어떤 c가 0과 x 사이)
x = 1이면 `e = 2 + e^c/2`. 실제 e ≈ 2.71828이므로 `e^c/2 ≈ 0.71828` → `e^c ≈ 1.43656` → **c ≈ 0.3622**, 확실히 (0, 1) 안이다 ✓

## 10. 흔한 함정

1. **MVT를 두 번 써서 CMVT를 "증명"하기.** §2의 함정. 점이 어긋난다 [9].
2. **분수 꼴을 조건 없이 쓰기.** `g(a) ≠ g(b)`, `g′(c) ≠ 0`이 필요하다. **곱셈 꼴**로 쓰면 안전 [6].
3. **c의 위치를 안다고 착각.** MVT 계열은 전부 **존재 정리**다. c가 구간의 중점이라는 보장은 없다. (예컨대 **이차함수에서는 항상** 중점이 되지만, 이는 이차함수만의 전유물이 아니고 — 대칭성이 있는 다른 함수도 중점이 될 수 있다 — 일반적으로는 중점이 **아니다**.)
4. **벡터값 함수에 등식 적용.** 원운동 반례. 다차원에서는 **부등식**으로 [13].
5. **로피탈을 CMVT 없이 자명하다고 여기기.** 로피탈의 정당성은 전적으로 CMVT에 의존한다 [4][10].
6. **미분가능성을 닫힌구간에서 요구하기.** 열린구간 (a, b)에서만 필요하다 [1].

## 11. 한눈 요약

| 정리 | 진술 | 증명 도구 |
|---|---|---|
| 롤 | f(a)=f(b) ⇒ f′(c)=0 | 최대·최소 정리 |
| 평균값(MVT) | f(b)−f(a) = f′(c)(b−a) | 롤 + 보조함수(f − 할선) |
| **코시(CMVT)** | **[f(b)−f(a)]g′(c) = [g(b)−g(a)]f′(c)** | **롤 + 보조함수(f, g 혼합)** |
| 적분 MVT | ∫[a,b] f = f(c)(b−a) | MVT + 미적분 기본정리 |
| 테일러 | f(b) = Σ + f⁽ⁿ⁺¹⁾(c)(b−a)ⁿ⁺¹/(n+1)! | MVT의 고차 일반화 |

| 질문 | 답 |
|---|---|
| CMVT는 MVT의 일반화인가? | ✅ g(x)=x 대입하면 MVT |
| MVT 두 번으로 되나? | ❌ 점이 c₁ ≠ c₂로 어긋남 |
| 로피탈의 근거는? | CMVT (같은 점 c 보장) |
| 벡터값에서도 등식? | ❌ 원운동 반례 → 부등식으로 |

**마지막 한 줄** — 코시 평균값 정리는 "정리 하나 더"가 아니라, **평균값 정리를 두 함수의 비로 옮겨 놓은 다리**다. 그 다리를 건너야 **0/0을 뚫는 로피탈**과 **함수를 다항식으로 펼치는 테일러**에 닿는다. 그리고 그 모든 것의 엔진은 여전히 **롤의 정리 하나**다 — 미분학이 얼마나 단단한 하나의 사슬로 엮여 있는지 보여 주는 대목이다.

[^중간점]: 중간점(intermediate point) — 평균값 정리류가 존재를 보장하는 점 c. 정리는 c가 **있다**는 것만 말하고 위치·개수는 말하지 않는다. 함수마다 c가 어디에 오는지를 연구하는 분야가 따로 있을 정도로 미묘한 대상이다.
