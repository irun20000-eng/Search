# 로피탈 정리 (이해편)

> "0/0이 나왔는데 어떡하지?" — 극한을 계산하다 **0÷0**이나 **∞÷∞** 같은 **답이 정해지지 않는 꼴**을 만나면 막힌다. **로피탈 정리(L'Hôpital's rule)**는 이럴 때 **분자·분모를 각각 미분해서** 극한을 뚫는 강력한 계산 도구다 [1][6]. 다만 **아무 때나 쓰면 틀린다** — 이 글은 로피탈의 **진술·직관**, **올바른 적용 3단계**, **손계산 예시**, 그리고 **흔한 오용**을 정리한다. "왜 성립하고 언제 쓰면 안 되는가"의 깊은 이야기는 짝을 이루는 **[확장편]**에서 다룬다.

## TL;DR
- **로피탈 정리**: 극한 lim f(x)/g(x)가 **0/0 또는 ∞/∞**(부정형[^부정형])일 때, **분자·분모를 각각 미분한** lim f′(x)/g′(x)가 존재하면 **원래 극한도 그 값과 같다** [1][6].
- **직관**: 0/0은 "둘 다 0으로 가는데 **누가 더 빨리 가느냐**"의 문제다. 그 '속도'가 곧 **도함수**[^도함수]이므로, **f′/g′의 비**가 답이 된다 [7].
- **올바른 적용 3단계**: ① 값을 대입해 **정말 부정형인지 확인** ② 분자·분모 **각각 미분**(분수의 미분 아님!) ③ **f′/g′의 극한이 존재**하는지 확인 [1][8].
- **변형 부정형도 OK**: 0·∞, ∞−∞, 1^∞, 0⁰, ∞⁰ 등은 **식을 바꿔 0/0이나 ∞/∞ 꼴로** 만든 뒤 적용한다 [2][6].
- **가장 흔한 실수**: **부정형이 아닌데** 로피탈을 쓰는 것(예: 2/0, 3/5). 이건 **틀린 답**을 낳는다 [8].

## 핵심 포인트
1. **부정형일 때만** 쓴다 — 0/0, ∞/∞(및 변형). 아니면 금지 [1][8].
2. **분자·분모를 따로 미분**한다. **몫의 미분법(f/g)′과 전혀 다르다** [6].
3. **필요하면 반복** 적용(미분 후 또 부정형이면 또 미분) [8].
4. **f′/g′ 극한이 없으면** 로피탈은 결론을 못 준다(원극한이 있을 수도 있음) [6].
5. **본질은 미분(변화 속도)** — 그래서 순간변화율이 답을 준다(상세는 확장편) [4].

## 1. 부정형이란 — 왜 바로 답이 안 나오나

극한을 구할 때 대부분은 **값을 대입**하면 끝난다. 예를 들어 lim(x→2) (x²+1)/(x−5) = 5/(−3). 그런데 대입했더니 **0/0**이나 **∞/∞** 같은 게 나오면 이야기가 다르다.

**부정형(indeterminate form)**[^부정형]은 *"사칙연산만으로는 값이 한 가지로 정해지지 않는 꼴"* 이다 [2]. 대표는 **0/0**과 **∞/∞**다. 왜 정해지지 않을까?

- **0/0**: 분자도 0, 분모도 0으로 간다. 그런데 결과는 **경우마다 다르다.**
  - x²/x → 0 (분자가 더 빨리 0)
  - x/x² → ∞ (분모가 더 빨리 0)
  - 3x/x → 3 (같은 속도, 비율만 남음)
  즉 **"0/0"이라는 표기만으로는 답을 알 수 없다** — 그래서 '부정(不定)형'이다 [2].

핵심 통찰: **0/0의 답은 "둘 다 0으로 가는 속도의 비율"에 달렸다.** 이 '속도'가 바로 **미분(도함수)**이다. 로피탈 정리는 정확히 이 아이디어를 정리로 만든 것이다.

> ⚠️ **주의**: 0/0·∞/∞는 부정형이지만, **1/0·2/0**(0으로 나눔, 분자≠0)은 부정형이 **아니다**(발산). **5/3, 2/7** 같은 것도 당연히 아니다. 로피탈은 **부정형에만** 쓴다 [2][8].

## 2. 로피탈 정리 — 진술과 직관

### 2-1. 진술
> **로피탈 정리**: x→a에서 lim f(x)/g(x)가 **0/0 또는 ∞/∞** 꼴이고, 분자·분모가 미분가능하며, **lim f′(x)/g′(x) = L**(유한값 또는 ±∞)이 존재하면,
> `lim(x→a) f(x)/g(x) = lim(x→a) f′(x)/g′(x) = L`
> 이다 (a가 유한수든 ±∞든, 한쪽 극한이든 성립) [1][6].

즉 **"분자·분모를 각각 미분해서 다시 극한을 구하라"**는 것이다.

### 2-2. 직관 — '0으로 가는 속도의 비'
왜 미분이 답을 줄까? a 근처에서 f와 g를 **접선(1차 근사)**으로 바꿔 보자. f(a)=g(a)=0이면,
`f(x) ≈ f′(a)(x−a) ,  g(x) ≈ g′(a)(x−a)`
이므로
`f(x)/g(x) ≈ [f′(a)(x−a)] / [g′(a)(x−a)] = f′(a)/g′(a)`
**(x−a)가 위아래로 약분**되면서 **접선 기울기의 비 f′/g′만 남는다** [7]. 이게 로피탈의 심장이다 — "0/0에서 살아남는 것은 **각자 0으로 가는 속도(기울기)의 비율**"이다. (더 정밀한 이유·엄밀한 증명은 확장편의 코시 평균값 정리.)

## 3. 올바른 적용 3단계

로피탈은 **절차를 지켜야** 맞는다 [1][8].

**1단계 — 부정형인지 확인.** 값을 대입해 **정말 0/0 또는 ∞/∞** 인지 본다. 아니면 **여기서 멈추고** 다른 방법을 쓴다(그냥 대입/인수분해 등).

**2단계 — 분자·분모를 '각각' 미분.** f′과 g′을 따로 구해 **f′/g′**를 만든다.
> ⚠️ **몫의 미분법이 아니다!** (f/g)′ = (f′g−fg′)/g² 과 **전혀 다르다.** 로피탈은 **위는 위대로, 아래는 아래대로** 미분한다 [6].

**3단계 — 새 극한 계산.** lim f′/g′를 구한다.
- 값이 나오면 그게 답.
- **또 부정형이면 다시 로피탈**(반복 가능) [8].
- **극한이 존재하지 않으면**, 로피탈로는 결론을 못 낸다(다른 방법 필요) [6].

## 4. Worked Examples — 손으로 따라가기

**예 1) 지수의 기본극한** lim(x→0) (eˣ − 1)/x
대입 → (1−1)/0 = **0/0** ✓. 미분 → eˣ / 1. x→0 대입 → **e⁰ = 1**.
`lim(x→0) (eˣ−1)/x = lim(x→0) eˣ/1 = 1`

**예 2) 두 번 적용** lim(x→0) (1 − cos x)/x²
대입 → 0/0 ✓. 미분 → sin x / (2x). 또 **0/0** ✓ → 다시 미분 → cos x / 2. x→0 → **1/2**.
`lim(x→0) (1−cos x)/x² = lim(x→0) sin x/(2x) = lim(x→0) cos x/2 = 1/2`

**예 3) 로그** lim(x→1) (ln x)/(x − 1)
대입 → 0/0 ✓. 미분 → (1/x) / 1. x→1 → **1**.

**예 4) ∞/∞ — 성장 속도 비교** lim(x→∞) x / eˣ
대입 → ∞/∞ ✓. 미분 → 1 / eˣ → **0**. (지수가 다항식보다 훨씬 빨리 커진다는 증거.)

**예 5) 반복이 필요한 ∞/∞** lim(x→∞) x² / eˣ
∞/∞ → 2x/eˣ → 또 ∞/∞ → 2/eˣ → **0**. (다항식 x²도 지수 앞에선 진다.)

**예 6) 로그의 성장 속도** lim(x→∞) (ln x)/x
대입 → ∞/∞ ✓. 미분 → (1/x)/1 = 1/x → **0**. (로그는 다항식보다도 느리게 큰다 — "log ≪ 다항식 ≪ 지수"의 첫 칸.)

**예 7) 삼각함수 섞인 0/0** lim(x→0) (tan x − x)/x³
대입 → 0/0 ✓. 미분 → (sec²x − 1)/(3x²). 또 0/0 ✓ → 미분 → (2 sec²x·tan x)/(6x) = (sec²x·tan x)/(3x). 또 0/0 ✓ → 계속 미분하면 x→0에서 **1/3**. (세 번 미분이 필요한 예 — 매 단계 부정형 확인이 관건.)

**예 8) 밑이 x인 거듭제곱** lim(x→0⁺) xˣ (=0⁰ 꼴)
ln y = x ln x = (ln x)/(1/x) → ∞/∞ 변형 → (1/x)/(−1/x²) = −x → 0. 따라서 ln y → 0, **y → 1**. (0⁰ 꼴을 로그로 내려 푸는 대표 예.)

> 팁: **한 번에 안 끝나면** 부정형인지 확인하며 **반복**하라. 단, 매번 **정말 부정형인지** 다시 점검해야 한다. **예 7처럼 세 번**도 걸린다.

### 4-1. 로피탈 없이도 되는 경우 — 더 빠른 길
로피탈이 **유일한 답은 아니다.** 아래는 **기본극한·인수분해·유리화**가 오히려 빠른 경우다. 실전에선 "부정형 → 먼저 정리 → 그래도 안 되면 로피탈" 순서가 안전하다 [8][3].

- **인수분해로 약분** — lim(x→2) (x²−4)/(x−2) = lim (x+2) = **4**. (분자를 (x−2)(x+2)로 쪼개 약분. 미분 없이 끝.)
- **유리화(켤레 곱)** — lim(x→0) (√(1+x) − 1)/x. 분자·분모에 (√(1+x)+1)을 곱하면 x/[x(√(1+x)+1)] = 1/(√(1+x)+1) → **1/2**.
- **기본극한 그대로** — lim(x→0) (sin x)/x = **1**은 **이미 아는 기본극한**이다. 굳이 로피탈로 '증명'하려 들면 **순환논리**에 빠진다(이유는 확장편) [5].

> 판단 기준: **두세 줄로 정리되면 정리로**, 정리가 안 보이고 **매끈하게 미분되면 로피탈로**. 둘 다 되면 검산용으로 병행해도 좋다.

## 5. 변형 부정형 처리 — 0/0·∞/∞로 바꾸기

0/0·∞/∞ 말고도 **부정형은 여럿**이다: **0·∞, ∞−∞, 1^∞, 0⁰, ∞⁰**. 이들은 **식을 변형해** 0/0이나 ∞/∞ 꼴로 만든 뒤 로피탈을 쓴다 [2][6].

- **0·∞ 꼴** → 분수로. 예) lim(x→0⁺) x ln x. 이건 0·(−∞) 꼴.
  `x ln x = (ln x)/(1/x)  (∞/∞로 변형)  → (1/x)/(−1/x²) = −x → 0`
- **∞−∞ 꼴** → 통분·유리화로 하나의 분수로.
- **1^∞, 0⁰, ∞⁰ 꼴** → **자연로그**[^로그]를 씌워 지수를 내린다. 예) lim(x→∞) (1 + 1/x)^x (=1^∞ 꼴).
  `y = (1+1/x)ˣ ,  ln y = x·ln(1+1/x) = ln(1+1/x)/(1/x)  (0/0)  —로피탈→  1`
  따라서 ln y → 1, **y → e**. (자연상수 e의 유명한 정의를 로피탈로 확인.)

> 요령: **"곱·차·거듭제곱 부정형은 → 나눗셈(분수) 부정형으로 번역"** 한 뒤 로피탈. 거듭제곱이면 **로그를 먼저** 씌운다.

## 6. 흔한 오용 — 이러면 틀린다

로피탈은 **강력하지만 위험**하다. 자주 나오는 실수들 [8][6]:

1. **부정형이 아닌데 적용.** 최악의 실수. 예) lim(x→0) (x+2)/(x+1) = 2/1 = 2인데, 부정형인 줄 알고 미분하면 1/1 = 1이라는 **틀린 답**이 나온다. **반드시 1단계(부정형 확인)를 먼저.**
2. **몫의 미분법과 혼동.** (f/g)′을 쓰면 안 된다. **위·아래 따로** 미분.
3. **부정형 확인 없이 무한 반복.** 매 단계 **다시 부정형인지** 점검하지 않고 계속 미분하면 엉뚱한 값이 나온다.
4. **f′/g′ 극한이 없다고 원극한도 없다고 단정.** lim f′/g′가 **진동해 존재하지 않아도**, 원래 극한 lim f/g는 **존재할 수 있다.** 이땐 로피탈이 **적용 불가**일 뿐, 다른 방법으로 풀어야 한다(대표 반례는 확장편) [6].
5. **더 쉬운 방법을 두고 남용.** 인수분해·기본극한으로 두 줄이면 될 걸 굳이 로피탈로 꼬는 경우. **로피탈이 늘 최선은 아니다**(확장편에서 상술).

## 7. 흔한 오해·FAQ

**Q1. 로피탈은 (f/g)를 미분하는 건가요?**
아니다. **분자 f와 분모 g를 각각 따로** 미분해 **f′/g′**를 만든다. 몫의 미분법 (f′g−fg′)/g² 과는 **완전히 다르다** [6].

**Q2. 0/0이면 무조건 로피탈?**
쓸 수 있지만 **최선이 아닐 때가 많다.** 인수분해·유리화·기본극한이 더 빠르고 안전한 경우가 흔하다. 특히 **순환논리 위험**(sin x/x 등)이 있는 극한은 로피탈로 '증명'하면 안 된다(확장편) [5].

**Q3. ∞−∞도 되나요?**
직접은 안 되고, **통분·유리화로 하나의 분수(0/0·∞/∞)로 바꾼 뒤** 적용한다 [2].

**Q4. 몇 번까지 미분해도 되나요?**
**부정형이 유지되는 한 반복**할 수 있다. 단 **매번 부정형인지 확인**해야 한다. (x²/eˣ처럼 두세 번 필요할 수도.)

**Q5. 왜 성립하나요?**
직관은 "0으로 가는 속도의 비 = 기울기의 비 = f′/g′"이고, 엄밀히는 **코시 평균값 정리**로 증명된다. 자세한 건 확장편 [7].

## 8. 한눈 요약

| 항목 | 요점 |
|---|---|
| 언제 | **0/0, ∞/∞**(및 변형) 부정형일 때만 |
| 무엇 | 분자·분모를 **각각 미분** → lim f′/g′ |
| 3단계 | ①부정형 확인 ②각각 미분 ③새 극한(필요시 반복) |
| 변형 | 0·∞·∞−∞은 분수로, 1^∞·0⁰·∞⁰은 로그 씌워 |
| 금지 | 부정형 아닌데 적용 / 몫의 미분법 혼동 |
| 한계 | f′/g′ 극한 없으면 결론 못 냄(원극한은 있을 수도) |

**마지막 한 줄** — 로피탈 정리는 **"0/0의 답은 결국 각자 0으로 가는 속도(미분)의 비"** 라는 통찰을 계산 규칙으로 바꾼 것이다. 강력하지만 **"부정형일 때만, 각각 미분, 매번 확인"** 세 원칙을 지켜야 한다. 그리고 이 도구의 **진짜 가치와 한계**(왜 성립하고, 언제 쓰면 안 되며, 무엇이 본질인가)는 짝을 이루는 **확장편**에서 이어진다.

[^부정형]: 부정형(indeterminate form) — 극한에서 사칙연산만으로는 값이 한 가지로 정해지지 않는 꼴. 0/0, ∞/∞, 0·∞, ∞−∞, 1^∞, 0⁰, ∞⁰ 등이 있다.
[^도함수]: 도함수(derivative) — 각 점에서 함수의 순간변화율(접선 기울기)을 값으로 갖는 함수 f′(x). '미분한다'는 것은 도함수를 구하는 것.
[^로그]: 자연로그(ln) — 밑이 자연상수 e인 로그. 거듭제곱 부정형(1^∞ 등)에서 지수를 곱셈으로 내려 다루기 쉽게 만드는 데 쓴다.
