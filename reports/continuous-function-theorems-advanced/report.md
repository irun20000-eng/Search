# 중간값 정리와 최대·최소 정리의 증명 (확장편)

> 이해편은 두 정리가 **무엇을 보장하는가**를 다뤘고, 유리수 위에서는 둘 다 거짓이라는 사실로 끝났다. 이 글은 그 지점에서 출발한다 — **무엇을 더 가정해야 참이 되는가.** 답은 **딱 하나, 실수의 완비성**이다. 놀랍게도 두 정리 모두 **최소상계 공리 한 줄**에서 나온다. 그리고 이 사슬은 갤러리의 다른 글들이 남겨 둔 빈자리와 정확히 맞물린다 — **평균값 정리**는 "닫힌구간 연속이면 최대·최소가 있다"를 가져다 썼고, **로피탈 정리**는 그 사슬이 완비성에 뿌리를 둔다고만 적어 두었다. 여기서 그 대목을 실제로 증명한다.

## TL;DR
- **출발점은 하나뿐이다.** 공집합이 아니고 위로 유계인 실수 집합은 **최소상계(상한)를 갖는다** — 완비성 공리 [3][4].
- **IVT 증명**: `S = {x ∈ [a,b] : f(x) < k}`의 **상한 `c`를 잡고**, `f(c) > k`와 `f(c) < k`를 각각 연속성으로 반박한다. 남는 것은 `f(c) = k`뿐 [11][18].
- **EVT 증명은 두 단계**다. **① 유계임을 보이고 ② 상한이 도달됨을 보인다.** 볼차노의 원래 증명도 이 순서였다 [13].
- **②의 열쇠는 한 줄짜리 기교**다. 최댓값 `M`이 도달되지 않는다면 `g = 1/(M − f)`가 연속이 되는데, ①을 `g`에 적용하면 `M`이 상한이라는 사실과 모순된다 [19].
- **역사의 아이러니**: 볼차노는 **1817년 IVT**를 순수 해석적으로 증명했고 [14][15], **1830년대에 EVT도 증명**했다. 그런데 그 원고는 **1930년에야 출판**됐고, EVT는 통상 **바이어슈트라스**의 이름으로 불린다 [13].
- **볼차노의 증명은 완결되지 못했다** — 당시 **실수가 아직 정의되지 않았기 때문**이다 [11]. 데데킨트의 실수 구성은 **1872년**이다.
- **현대적 이름은 컴팩트성과 연결성**이다. IVT는 **연결집합의 연속상은 연결**, EVT는 **컴팩트집합의 연속상은 컴팩트**의 특수한 경우다 [12].
- **덤이 하나 더 있다.** 닫힌구간에서는 연속이 자동으로 **균등연속**[^균등연속]이 된다 — 하이네–칸토어 정리 [17].

## 핵심 포인트
1. **두 정리의 유일한 재료는 완비성**이다. 다른 가정은 쓰이지 않는다 [3].
2. **IVT는 상한을 "경계선"으로 쓰고**, EVT는 상한을 "목표값"으로 쓴다 — 같은 도구, 다른 용법.
3. **EVT ①단계(유계성)가 진짜 일**이다. ②단계는 ①의 재활용이다 [19].
4. **완비성을 빼면 즉시 거짓**이 된다 — ℚ 위의 반례가 그것을 보여 준다(§7).
5. **볼차노 → 코시 → 바이어슈트라스**로 이어지는 엄밀화의 실제 현장이다 [11][13][14].
6. **일반화하면 위상수학**이다 — 구간의 특별함은 컴팩트·연결이라는 두 성질이었다 [12].

## 1. 직관 압축 — 이해편 한 문단

IVT는 "사이의 값을 빠짐없이 취한다", EVT는 "최댓값·최솟값이 실제로 도달된다"를 말한다. 둘 다 그림에서는 자명해 보이지만, **유리수 위에서는 둘 다 거짓**이다(`f(x) = x² − 2`가 `ℚ ∩ [0,2]`에서 부호를 바꾸면서도 근이 없다). 그러므로 증명에는 **실수가 유리수와 다른 그 성질**이 반드시 들어가야 한다.

## 2. 출발점 — 완비성 공리 단 한 줄

### 2-1. 진술
> **완비성 공리(최소상계 성질).** 공집합이 아니고 **위로 유계인** 실수 집합 `A`에는 **최소상계 `sup A`가 존재한다** [3][4].

**상계**는 `A`의 모든 원소보다 크거나 같은 수이고, **상한(최소상계)**은 그 상계들 중 **가장 작은 것**이다 [4].

```
   A = { x ∈ ℝ : x² < 2 }

   ────────────●●●●●●●●●●●────┼────────────
                              √2 = sup A
                          ↑
              A 의 원소들      상계는 √2 이상인 모든 수
                              그중 가장 작은 것이 √2
```

**ℚ 안에서는 이 집합의 상한이 존재하지 않는다.** `√2`가 없기 때문이다. 이것이 완비성이 유리수와 실수를 가르는 지점이며 [3][5], 앞으로 나올 두 증명이 **오로지 이 사실 하나에만** 기댄다.

### 2-2. 증명에서 반복해 쓸 두 성질
`c = sup A`라 할 때 다음 두 가지를 계속 쓴다.

| 성질 | 내용 | 쓰임 |
|---|---|---|
| **(상계)** | 모든 `x ∈ A`에 대해 `x ≤ c` | "`c`보다 큰 점은 `A`에 없다" |
| **(최소성)** | 임의의 `ε > 0`에 대해 `c − ε < s ≤ c`인 `s ∈ A`가 존재 | "`c` 바로 왼쪽에 `A`의 원소가 있다" |

**(최소성)**이 특히 중요하다. `c − ε`이 상계라면 `c`가 최소상계라는 데 어긋나므로, `c − ε`보다 큰 `A`의 원소가 반드시 있다.

## 3. 중간값 정리의 증명

### Worked Example ① — 상한법에 의한 IVT 증명

**정리.** `f`가 `[a, b]`에서 연속이고 `f(a) < k < f(b)`이면, `f(c) = k`인 `c ∈ (a, b)`가 존재한다 [11][18].

**증명.**

**1단계 — 집합을 만든다.**
```
   S = { x ∈ [a, b] : f(x) < k }
```
- `f(a) < k`이므로 `a ∈ S` → **`S ≠ ∅`**
- `S ⊆ [a, b]`이므로 **`b`가 상계**

**완비성에 의해 `c = sup S`가 존재하고**, `a ≤ c ≤ b`다 [3][4].

**2단계 — `f(c) > k`는 불가능.**
`f(c) > k`라 하자. `ε = f(c) − k > 0`으로 두면, 연속성에서 `δ > 0`이 있어

```
   |x − c| < δ  ⟹  |f(x) − f(c)| < ε  ⟹  f(x) > f(c) − ε = k
```

즉 `(c − δ, c]` 안의 모든 점에서 `f > k`이므로, **그 점들은 어느 것도 `S`에 없다.**
그런데 `c = sup S`의 **(최소성)**에 의해 `c − δ < s ≤ c`인 `s ∈ S`가 존재해야 한다. **모순.**

> (`c > a`임은 이 가정 자체가 보장한다 — `f(a) < k < f(c)`이므로 `c ≠ a`.)

**3단계 — `f(c) < k`도 불가능.**
`f(c) < k`라 하자. `f(b) > k`이므로 `c ≠ b`, 즉 `c < b`다.
`ε = k − f(c) > 0`으로 두면, 연속성에서 `δ > 0`이 있어

```
   |x − c| < δ  ⟹  f(x) < f(c) + ε = k
```

`c < b`이므로 `c < x < min(c + δ, b)`인 `x`를 잡을 수 있고, 이 `x`는 `f(x) < k`이므로 **`x ∈ S`**.
그런데 `x > c = sup S`다. **(상계)**에 모순.

**4단계.** 2·3단계에서 `f(c) > k`도 `f(c) < k`도 불가능하므로, **`f(c) = k`**. ∎

### 3-1. 증명의 구조를 한눈에
```
   완비성 ──→ c = sup S 가 존재
                  │
        ┌─────────┴─────────┐
     f(c) > k             f(c) < k
        │                    │
   연속성으로 c 왼쪽이     연속성으로 c 오른쪽에
   전부 S 밖 → (최소성) 모순  S 원소 생김 → (상계) 모순
        └─────────┬─────────┘
                  ↓
             f(c) = k
```

**연속성은 "국소적으로 부호가 유지된다"는 데만 쓰였다.** 완비성이 점을 하나 만들어 주고, 연속성이 그 점의 함숫값을 `k`로 못 박는 구조다.

## 4. 최대·최소 정리의 증명

EVT는 IVT보다 한 겹 더 있다. **"상한이 존재한다"에서 "상한이 도달된다"로 건너가야** 하기 때문이다. 볼차노의 원래 증명도 **유계성을 먼저 보이고 그다음 도달을 보이는** 두 단계였다 [13].

### Worked Example ② — ①단계: `f`는 `[a, b]`에서 유계

**주장.** `f`가 `[a, b]`에서 연속이면 `f`는 그 구간에서 유계다.

**증명.**
```
   T = { x ∈ [a, b] : f 가 [a, x] 에서 유계 }
```
- `f`는 `[a, a]`에서 자명히 유계 → `a ∈ T`, **`T ≠ ∅`**
- `b`가 상계 → 완비성에 의해 **`c = sup T` 존재**

`f`가 `c`에서 연속이므로, `ε = 1`에 대해 `δ > 0`이 있어

```
   |x − c| < δ,  x ∈ [a,b]  ⟹  |f(x) − f(c)| < 1  ⟹  |f(x)| < |f(c)| + 1
```

즉 `f`는 `(c − δ, c + δ) ∩ [a, b]`에서 **유계다.**

**(최소성)**에 의해 `c − δ < s ≤ c`인 `s ∈ T`가 있고, `f`는 `[a, s]`에서 유계다.
두 구간을 합치면 `f`는 `[a, s] ∪ ((c−δ, c+δ) ∩ [a,b])`에서 유계 —

- `c < b`라면 `c`보다 **오른쪽 점 `x₀ = min(c + δ/2, b)`까지 유계**가 되어 `x₀ ∈ T`, `x₀ > c`. **(상계) 모순.**
- 따라서 **`c = b`**이고, 위 논증은 `b ∈ T`임도 준다. 즉 **`f`는 `[a, b]`에서 유계**다. ∎

### Worked Example ③ — ②단계: 상한이 도달된다

**주장.** `f`가 `[a, b]`에서 연속이면 `f(x₀) = M`인 `x₀`가 존재한다. 여기서 `M = sup{ f(x) : x ∈ [a,b] }`.

**증명(귀류법).** ①단계로 치역이 유계이고 공집합이 아니므로, 완비성에 의해 **`M`이 존재한다.**
`M`이 도달되지 않는다고 하자. 즉 **모든 `x`에 대해 `f(x) < M`.**

그러면 `M − f(x) > 0`이 항상 성립하므로 다음이 **`[a, b]`에서 연속**이다 [2].

```
   g(x) = 1 / (M − f(x))
```

`g`도 `[a, b]`에서 연속이므로 **①단계를 `g`에 적용**하면 `g`는 유계다. 즉 어떤 `K > 0`이 있어

```
   g(x) ≤ K   for all x
   →  1/(M − f(x)) ≤ K
   →  M − f(x) ≥ 1/K
   →  f(x) ≤ M − 1/K       for all x
```

그런데 이것은 **`M − 1/K`가 `f`의 상계**라는 뜻이고, `M − 1/K < M`이므로 **`M`이 최소상계라는 사실에 모순**이다. ∎

**최솟값**은 `−f`에 같은 논증을 적용하면 된다.

> 🔑 **②단계의 아름다움**: 새 도구를 하나도 쓰지 않는다. **"도달하지 못한다"는 가정이 곧 `1/(M−f)`를 폭발시키는 장치**가 되고, 그 폭발을 ①단계가 금지한다. 이해편 §5의 반례 `f(x) = x` on `[0,1)`을 여기에 대입해 보면 `g = 1/(1−x)`가 실제로 발산하는 것이 보인다 — **반례가 왜 반례인지까지 이 증명이 설명한다.**

## 5. 다른 길 — 볼차노–바이어슈트라스

위 증명은 **상한만** 썼다. 표준적인 다른 경로는 **수열**을 쓴다.

> **볼차노–바이어슈트라스 정리.** 유계인 실수열은 **수렴하는 부분수열을 갖는다** [16].

볼차노는 IVT를 증명하려고 **정확히 이 보조정리가 필요했고**, 오늘날 이 정리에 그의 이름이 붙어 있다 [16].

**EVT의 수열 증명 개요**
1. `M = sup f`라 하고, `f(xₙ) → M`인 점열 `(xₙ)`을 잡는다(상한의 최소성에서 늘 가능).
2. `(xₙ)`은 `[a, b]` 안이라 **유계** → 볼차노–바이어슈트라스로 **수렴 부분수열** `x_{nₖ} → x₀` 존재.
3. `[a, b]`가 **닫힌구간**이므로 `x₀ ∈ [a, b]`.
4. `f`의 **연속성**에서 `f(x_{nₖ}) → f(x₀)`. 그런데 `f(x_{nₖ}) → M`이므로 **`f(x₀) = M`**. ∎

```
   두 경로 비교

   상한법 :  완비성 → sup → 연속성으로 모순 제거      (한 번에)
   수열법 :  완비성 → B–W → 부분수열 수렴 → 연속성   (도구 하나 경유)
```

**어느 쪽도 완비성 밖으로 나가지 않는다.** 실제로 완비성 공리·볼차노–바이어슈트라스·코시 수열의 수렴성 [10]·구간축소법은 **서로 동치**이며, 무엇을 공리로 삼느냐의 차이일 뿐이다.

## 6. 역사 — 볼차노가 둘 다 했는데

| 연도 | 사건 |
|---|---|
| **1817** | **볼차노**, IVT의 **순수 해석적 증명** 발표 — 「부호가 다른 두 값 사이에 실근이 적어도 하나 있다는 정리의 순수 해석적 증명」 [14][15] |
| **1821** | **코시** 『해석 교정』에서 증명 — 널리 읽혔으나 **여전히 무한소를 사용** [11] |
| **1830년대** | 볼차노, 『함수론』에서 **EVT도 증명**(유계성 → 도달 순서) [13] |
| **1854** | **바이어슈트라스**의 증명 — 오늘날 가장 잘 알려진 형태 [11] |
| **1872** | 데데킨트·칸토어, **실수의 구성** |
| **1930** | 볼차노의 『함수론』 원고가 **비로소 출판** [13] |

읽어야 할 대목이 세 가지다.

**① 볼차노의 증명은 완결될 수 없었다.** 실수의 본성이 아직 이해되지 않은 상태였기 때문이다 [11]. 그가 필요로 한 완비성은 **55년 뒤에야** 데데킨트에 의해 구성된다. **정리를 증명하는 데 필요한 대상이 아직 정의되지 않은 채 증명이 먼저 있었던 것**이다.

**② 이름은 늦게 온 사람에게 갔다.** EVT는 통상 **바이어슈트라스 정리**로 불린다 [13]. 볼차노의 EVT 원고가 100년간 서랍에 있었던 탓이다. IVT 쪽에서도 **코시의 1821년 증명이 더 널리 받아들여졌다** [11].

**③ 이것은 갤러리의 다른 글과 같은 이야기다.** **미적분의 엄밀화(`calculus-discovery-advanced`)**에서 본 "미적분은 자기 무대(실수)가 정의되기 전에 200년을 먼저 걸었다"가, 여기서는 **"IVT는 완비성이 정의되기 55년 전에 증명됐다"**로 반복된다.

## 7. 완비성을 빼면 — ℚ 위의 반례

증명이 완비성만 썼다면, **완비성을 없앴을 때 정확히 무너져야** 한다. 실제로 그렇다.

| 정리 | ℚ 위의 반례 | 무엇이 깨지나 |
|---|---|---|
| **IVT** | `f(x) = x² − 2` on `ℚ ∩ [0,2]` | `f(0) = −2 < 0 < 2 = f(2)`, `f` 연속. 그러나 `f(c) = 0`인 **유리수 `c`가 없다** |
| **EVT (유계성)** | `g(x) = 1/(x² − 2)` on `ℚ ∩ [0,2]` | 분모가 **유리수에서는 0이 되지 않으므로 `g`는 연속**이다. 그런데 `x → √2`에서 **발산** — 유계조차 아니다 |
| **EVT (도달)** | `h(x) = x²` on `ℚ ∩ [0, √2)` 꼴 | 상한에 다가가나 **도달점이 ℚ 안에 없다** |

두 번째 줄이 특히 선명하다. `g`는 **정의역 전체에서 멀쩡히 연속인데** 닫히고 유계인 구간에서 유계가 아니다. 우리 증명의 ①단계가 `sup T`를 만들 때 **그 상한이 ℚ 안에 없어서** 논증이 시작조차 되지 않는다.

> 📌 **정리의 참·거짓이 정의역이 사는 수 체계에 달려 있다.** 함수의 식도, 연속성도, 구간의 모양도 전부 같은데 결론만 뒤집힌다. 이것이 완비성이 하는 일이다 [3].

## 8. 일반화 — 구간이 특별했던 진짜 이유

현대적으로 보면, `[a, b]`의 두 성질이 각각 한 정리씩 책임진다 [12].

| 정리 | 일반화된 진술 | `[a,b]`가 만족하는 성질 |
|---|---|---|
| **IVT** | **연결**집합의 연속상은 **연결**이다 | 구간은 **연결**(끊긴 데가 없다) |
| **EVT** | **컴팩트**[^컴팩트]집합의 연속상은 **컴팩트**이다 | 구간은 컴팩트(하이네–보렐: 닫힘 + 유계) |

**IVT가 왜 따라 나오나**: `ℝ`의 연결 부분집합은 **구간뿐**이다. 그러므로 연속상 `f([a,b])`도 구간이고, 구간은 두 원소 사이의 모든 값을 포함한다. **그것이 곧 중간값 성질이다.**

**EVT가 왜 따라 나오나**: `ℝ`의 컴팩트 집합은 **닫히고 유계**다(하이네–보렐). 연속상 `f([a,b])`가 컴팩트이므로 **유계이고 닫혀 있고**, 닫힌 유계집합은 **자신의 상한을 원소로 포함한다.** 즉 **최댓값이 도달된다.**

```
   [a, b]  ──f──→  f([a,b])
   연결          →   연결      = 구간      → 중간값을 취한다     (IVT)
   컴팩트        →   컴팩트    = 닫힘+유계 → 최댓값을 포함한다   (EVT)
```

> 💡 이해편 FAQ의 "왜 하필 닫힌구간인가"에 대한 최종 답이 이것이다. **닫힘·유계라는 두 조건이 따로 필요했던 게 아니라, 합쳐서 컴팩트라는 하나의 성질**이었다. 그리고 §5 반례들이 셋 다 무너졌던 이유도 하나로 정리된다 — **컴팩트하지 않았기 때문이다.**

## 9. 덤 — 닫힌구간은 균등연속까지 준다

닫힌구간이 주는 선물이 하나 더 있다.

> **하이네–칸토어 정리.** **컴팩트** 거리공간에서 정의된 연속함수는 **균등연속**이다. 특히 **닫히고 유계인 구간에서 연속인 실함수는 균등연속이다** [17].

**연속과 균등연속의 차이**
```
   연속     : 각 점 c 마다  ε → δ(ε, c)      ← δ가 점마다 달라도 된다
   균등연속 : 모든 점에 공통  ε → δ(ε)        ← δ 하나로 전 구간을 덮는다
```

`f(x) = 1/x`는 `(0, 1]`에서 연속이지만 **균등연속이 아니다** — `0`에 가까울수록 같은 `ε`에 훨씬 작은 `δ`가 필요하다. **구간이 닫혀 있지 않아서** 생기는 현상이며, 이해편 §5의 첫 반례와 정확히 같은 뿌리다.

**왜 중요한가**: 균등연속은 **리만 적분가능성**의 표준 증명에서 쓰인다. 즉 "닫힌구간에서 연속인 함수는 적분가능하다"의 배후에도 이 정리가 있다.

## 11. 함정·체크리스트

- [ ] **"연속이면 최댓값이 있다"고 외우지 말 것.** 반드시 **닫히고 유계인 구간**이 함께 와야 한다 [1][12].
- [ ] **상한과 최댓값을 같은 것으로 쓰지 말 것.** 상한은 완비성이 늘 보장하지만, **도달은 EVT가 따로 보장하는 별개의 사건**이다 [4][7].
- [ ] **IVT를 "근을 구하는 방법"으로 소개하지 말 것.** 존재정리이며, 위치는 이분법 같은 **다른 절차**가 찾는다.
- [ ] **"중간값 성질을 가지면 연속"은 거짓**이다 — 도함수가 반례(다르부 정리) [8].
- [ ] **EVT 증명에서 ①단계를 건너뛰지 말 것.** `M = sup f`를 쓰려면 **치역이 유계임이 먼저** 필요하다. ①이 없으면 `M` 자체가 존재하지 않는다.
- [ ] **역사 서술에서 "완성"과 "출판"을 구분할 것.** 볼차노의 EVT는 **1830년대 증명 / 1930년 출판**이다 [13]. 이를 뭉뚱그리면 우선권 서술이 통째로 틀어진다.
- [ ] **"볼차노가 완전히 증명했다"고 단정하지 말 것.** 당시 실수가 정의되지 않아 **완결되지 못했다**는 것이 통상적 평가다 [11].
- [ ] **일반화를 말할 때 IVT와 EVT를 한 덩어리로 묶지 말 것.** 하나는 **연결성**, 다른 하나는 **컴팩트성**에서 나오는 **서로 다른 정리**다 [12].

| ℚ에서 | 거짓 | 거짓 |

**마지막 한 줄** — 두 정리의 증명을 끝까지 따라가면 **쓰인 재료가 완비성 하나뿐**임이 드러난다. 연속성은 국소적인 조율만 담당하고, **점을 실제로 만들어 내는 일은 전부 상한이 한다.** 그래서 이 두 정리는 연속함수에 관한 정리라기보다 **실수가 어떤 수 체계인지에 관한 정리**에 가깝다. 볼차노가 1817년에 증명해 놓고도 완결하지 못한 이유, 그리고 유리수 위에서 같은 문장이 거짓이 되는 이유가 모두 여기에 있다 — **그가 증명하려던 것의 바닥이 아직 놓이지 않았던 것이다.**

## 되돌아가기
- **이해편** — 두 정리가 무엇을 보장하고 무엇을 보장하지 않는가, 반례 갤러리(짝문서 `continuous-function-theorems`)

## 갤러리 안의 이웃 글
이 글은 다른 보고서들이 **가져다 쓰기만 했던 대목**을 증명한다.
- **평균값 정리(`mean-value-theorem`)** — 롤의 정리 증명이 "닫힌구간 연속 → 최댓값·최솟값 존재"에 기대고 있다고 적어 둔 그 지점. 이 글 §4가 그 문장의 증명이다.
- **로피탈 정리(`lhopital-rule-advanced`)** — "롤 → 평균값 → 코시 → 로피탈의 사슬이 완비성에 뿌리를 둔다"는 서술의 **뿌리 쪽 한 칸**.
- **미적분의 엄밀화(`calculus-discovery-advanced`)** — 코시(1821)와 바이어슈트라스의 ε–δ, 그리고 1872년 실수의 구성. 이 글의 §6과 같은 시대를 다른 각도에서 본다.
- **무한의 크기(`infinity-set-theory`)** — 완비성을 떠받치는 실수의 크기 문제.

## 후속 질문·연결
- **[[하이네-보렐 정리]]** — 왜 닫힘 + 유계가 컴팩트와 같은 말인가
- **[[구성적 수학]]** — 근의 존재를 "증명"했는데 찾을 수 없어도 되는가
- **[[다르부 정리]]** — 중간값 성질을 가지면서 연속이 아닌 함수들
- **[[리만 적분가능성]]** — 균등연속이 적분을 가능하게 하는 경로

[^균등연속]: 균등연속(uniform continuity) — 임의의 ε에 대해 **정의역 전체에 공통으로 통하는** δ를 하나 잡을 수 있는 성질. 보통의 연속은 δ가 점마다 달라도 되지만, 균등연속은 그렇지 않다. 컴팩트한 정의역 위에서는 연속이면 자동으로 균등연속이 된다(하이네–칸토어 정리).
[^컴팩트]: 컴팩트(compact) — 모든 열린덮개가 유한 부분덮개를 갖는 성질. 실수의 부분집합에서는 **닫히고 유계인 것**과 같다(하이네–보렐 정리). 최대·최소 정리가 성립하는 진짜 이유이며, 닫힘과 유계라는 두 조건이 사실은 하나의 성질이었음을 말해 준다.
