# 무한을 세다 (이해편)

> "무한은 다 똑같이 무한 아닌가?" — 대부분의 직관은 여기서 멈춘다. 그런데 19세기 말, **게오르크 칸토어**는 충격적인 사실을 증명했다. **무한에도 '크기'가 있고, 어떤 무한은 다른 무한보다 진짜로 더 크다.** 이 글은 무한을 '세는' 방법에서 출발해, 자연수의 무한(**가산무한**)과 실수의 무한(**비가산무한**)이 서로 다른 크기임을, 칸토어의 **대각선 논법**으로 손으로 따라가며 이해한다. 논리적 지반(선택공리·불완전성·연속체 가설)은 짝을 이루는 **[확장편]**에서 다룬다.

## TL;DR
- **무한을 세는 열쇠는 '숫자'가 아니라 '짝짓기'다.** 두 집합의 원소를 **하나도 남김없이 일대일로 짝**지을 수 있으면[^일대일] 같은 크기다. 이 기준을 무한에 들이대면 직관이 무너지기 시작한다 [1][5].
- **부분이 전체와 같은 크기일 수 있다(갈릴레오의 역설).** 자연수 전체와 짝수 전체는 `n↔2n`으로 완벽히 짝지어진다 — **짝수가 자연수의 '절반'인데 크기는 같다.** 무한에선 "부분 < 전체"가 깨진다 [1][6].
- **자연수와 같은 크기의 무한을 '가산무한'이라 하고 그 크기를 ℵ₀(알레프 제로)**[^알레프]라 부른다. 정수·유리수까지도 놀랍게 **전부 ℵ₀**다 — 셀 수 있는 무한이다 [1][5].
- **그러나 실수는 다르다.** 칸토어는 **대각선 논법**[^대각선]으로 "실수를 자연수와 짝짓는 목록은 결코 완성될 수 없다"를 증명했다(1891). 실수의 무한은 ℵ₀보다 **진짜로 더 큰** 비가산무한이다 [2][7].
- **무한은 하나가 아니라 무한한 계단이다.** **멱집합 정리**[^멱집합]에 따라, 어떤 집합이든 그 부분집합 전체는 원래보다 반드시 더 크다 → **ℵ₀ < 그다음 < 그다음 …** 끝없이 커지는 무한의 사다리가 존재한다 [3][7].

## 핵심 포인트
1. **크기 비교의 도구 = 일대일 대응(전단사)**. 개수를 못 세는 무한에서도, '짝짓기가 되느냐'는 물을 수 있다 [5].
2. **가산무한(ℵ₀)**: 자연수·정수·유리수. "목록으로 나열 가능"이 본질 [1].
3. **비가산무한**: 실수·구간 (0,1)·무리수. **아무리 나열해도 빠지는 원소가 반드시 생긴다** [2][7].
4. **대각선 논법**: 완성됐다고 가정한 목록에서, 대각선을 비틀어 **목록에 없는 새 원소**를 만들어 모순을 낸다 [2].
5. **무한의 위계**: 멱집합을 취할 때마다 더 큰 무한 → 무한의 크기 자체가 무한히 많다 [3].

## 1. 왜 필요했나 — "무한은 셀 수 없다"는 오래된 금기

고대 그리스부터 무한은 **다루면 안 되는 것**이었다. 아리스토텔레스는 '실무한(actual infinity)'을 거부하고 '잠재무한(potential infinity)' — 끝없이 더할 수 있는 **과정으로서의 무한**만 허용했다 [7]. "무한한 것을 하나의 완성된 대상으로 손에 쥔다"는 발상은 금기였다.

그 금기를 깨는 첫 균열이 **갈릴레오 갈릴레이**(17세기)에게서 나왔다. 그는 이상한 것을 알아챘다. 자연수 1, 2, 3, 4, …를 제곱하면 1, 4, 9, 16, …이 된다. 그런데 제곱수는 자연수의 '일부'일 뿐인데도, **모든 자연수마다 정확히 하나의 제곱수가 대응**한다(n ↔ n²). 그렇다면 자연수와 제곱수는 **같은 개수**인가? '부분'인데 '전체'와 같다니? 갈릴레오는 이 모순 앞에서 *"'같다·크다·작다'는 무한에는 적용되지 않는다"*고 결론짓고 물러섰다 [6].

갈릴레오가 멈춘 그 자리에서, **게오르크 칸토어(Georg Cantor, 1845~1918)**는 250년 뒤 다르게 물었다. *"부분이 전체와 짝지어진다면, 그건 모순이 아니라 무한의 정의 그 자체가 아닐까?"* 그는 무한을 **완성된 대상(집합)**으로 대담하게 붙잡고, 그 크기를 비교하는 수학 — **집합론**을 세웠다 [7]. 이 글의 나머지는 그가 발견한 세계다.

## 2. 무한을 세는 법 — 숫자를 버리고 '짝짓기'를 쓴다

유한한 것은 세면 된다. 사과 3개, 접시 3개. 그런데 **세지 않고도** 두 무리가 같은 개수임을 아는 방법이 있다. **하나씩 짝을 지어 보는 것**이다. 사과마다 접시 하나씩 올렸을 때 **남는 것도 모자란 것도 없으면** 개수가 같다. 숫자를 전혀 몰라도 된다.

칸토어의 천재적 도약은 이 **짝짓기(일대일 대응)**[^일대일]를 무한에 그대로 쓴 것이다.

> **정의(핵심)**: 두 집합 A, B 사이에 **하나도 빠짐없이·겹침없이** 원소를 짝지을 수 있으면(전단사 함수가 존재하면), A와 B는 **같은 크기(같은 기수**[^기수]**)**다.

이 정의의 위력은, **개수를 셀 수 없는 무한에서도 크기 비교가 가능해진다**는 데 있다. "몇 개?"는 못 물어도 "짝지을 수 있나?"는 물을 수 있으니까.

이제 갈릴레오의 역설은 역설이 아니다. 자연수와 짝수는 `n ↔ 2n`으로 완벽히 짝지어진다:

```
자연수:  1   2   3   4   5   ...
         ↕   ↕   ↕   ↕   ↕
짝수:    2   4   6   8   10  ...
```

**남는 짝수도, 짝 못 찾은 자연수도 없다.** 그러므로 둘은 같은 크기다. "짝수는 자연수의 절반"이라는 유한의 직관이 틀렸을 뿐이다. 실제로 수학에서는 이 성질 — **자기 자신의 진부분집합과 일대일 대응이 되는 것** — 을 아예 **무한집합의 정의**로 삼기도 한다(데데킨트 무한) [1][5].

## 3. 가산무한과 ℵ₀ — "셀 수 있는" 무한

자연수 집합 ℕ = {1, 2, 3, …}과 같은 크기인 무한을 **가산무한(countably infinite)**이라 부른다. '가산(可算)'은 말 그대로 **셀 수 있다**는 뜻 — 여기서 '센다'는 건 **1번, 2번, 3번… 번호를 붙여 목록으로 나열할 수 있다**는 의미다 [1].

칸토어는 이 가산무한의 크기에 이름을 붙였다. 히브리 문자 알레프에 아래첨자 0을 단 **ℵ₀(알레프 제로)**[^알레프]. 이것이 **가장 작은 무한**, 즉 최초의 **초한수(transfinite number)**[^초한수]다 [1][8].

여기서 첫 번째 놀라움이 온다. **직관상 훨씬 많아 보이는 집합들도 알고 보면 전부 ℵ₀**다.

**(1) 정수 전체(ℤ)도 가산.** 음수까지 있으니 자연수의 '두 배'처럼 보이지만, 지그재그로 번호를 매기면 빠짐없이 나열된다:
```
0, 1, -1, 2, -2, 3, -3, ...
(1번, 2번, 3번, 4번, 5번, ...)
```
모든 정수가 언젠가 번호를 받는다 → 정수도 ℵ₀.

**(2) 유리수 전체(ℚ)도 가산.** 이건 정말 반직관적이다. 유리수는 수직선 위에 **빽빽이(어떤 두 유리수 사이에도 무한히 많은 유리수가)** 들어차 있다. 그런데도 셀 수 있다. 분수 `분자/분모`를 격자에 배열하고 **대각선을 따라 지그재그로 훑으면**(칸토어의 '첫 번째 대각선 논법'), 모든 유리수에 번호를 매길 수 있다:
```
1/1  1/2  1/3  1/4 ...
2/1  2/2  2/3  ...
3/1  3/2  ...
4/1  ...
→ 대각선으로 훑으며 번호 부여(중복 약분은 건너뜀)
```
빽빽한데도 셀 수 있다니 — **유리수 = ℵ₀** [1][5].

이쯤 되면 자연스러운 예상이 생긴다. *"결국 모든 무한은 ℵ₀ 아닐까? 무한은 역시 다 똑같은 것 아닐까?"* 칸토어 자신도 처음엔 그렇게 기대했다. 그리고 그 기대는 — **실수 앞에서 완전히 무너진다.**

## 4. 대각선 논법 — 실수는 셀 수 없다 (Worked Example)

이 절이 이 글의 심장이다. 칸토어가 1891년 발표한 **대각선 논법**[^대각선]으로, **0과 1 사이의 실수조차 자연수로 번호 매길 수 없음**을 손으로 따라가 보자 [2].

증명 전략은 **귀류법(모순으로 몰기)**이다. "셀 수 있다"고 가정한 뒤, 그 가정이 스스로 모순을 낳게 만든다.

**1단계 — 가정.** (0, 1) 사이의 모든 실수를 **빠짐없이 목록으로 나열했다**고 하자. 각 실수를 무한소수로 적는다. 예컨대:
```
1번:  0. 1  4  1  5  9  2  ...
2번:  0. 3  3  3  3  3  3  ...
3번:  0. 7  1  8  2  8  1  ...
4번:  0. 5  0  0  0  0  0  ...
5번:  0. 2  7  1  8  2  8  ...
 ⋮
```
가정에 따르면, (0,1)의 **모든** 실수가 이 목록 어딘가에 반드시 있다.

**2단계 — 대각선에서 새 수를 만든다.** 목록의 **대각선 자릿수**(1번의 첫째, 2번의 둘째, 3번의 셋째, …)를 뽑는다. 위 예에선 **1, 3, 8, 0, 2, …**

이제 이 대각선 숫자들을 **하나씩 바꿔서** 새로운 소수 b를 만든다. 규칙은 간단하다 — **각 자리 숫자를 다른 숫자로 비튼다**(예: "숫자가 5가 아니면 5로, 5이면 6으로"). 그러면:
```
대각선:      1   3   8   0   2  ...
새 수 b:     5   5   5   5   5  ...   →  b = 0.55555...
```
(규칙상 1→5, 3→5, 8→5, 0→5, 2→5. 만약 어떤 대각선 숫자가 5였다면 그 자리는 6으로.)

**3단계 — 모순.** 이 새 수 b는 목록에 있는가? **없다.** 왜냐하면 b는 설계상:
- **1번 수와 첫째 자리가 다르고**(1번의 대각선 자리를 바꿨으니),
- **2번 수와 둘째 자리가 다르고**,
- **3번 수와 셋째 자리가 다르고**, …
- **n번 수와 n번째 자리가 다르다.**

즉 b는 목록의 **모든 수와 적어도 한 자리에서 다르다.** 따라서 b는 목록의 어떤 수와도 같지 않다. 그런데 b도 엄연히 (0,1) 사이의 실수다. **"모든 실수를 나열했다"는 가정이 거짓**이 된 것이다 — 항상 빠지는 수(b)가 생기니까 [2][7].

**결론.** (0,1)의 실수는 **아무리 나열해도 완성되지 않는다.** 자연수와 일대일로 짝지을 수 없다. 실수의 무한은 ℵ₀보다 **진짜로 더 큰** 무한 — **비가산무한(uncountable)**이다. 이 크기를 흔히 **연속체의 크기**라 부르고 기호로 𝔠 또는 2^ℵ₀로 쓴다 [2].

> **한 줄 정수(精髓)**: 대각선 논법은 "너의 목록이 무엇이든, 나는 그것을 비틀어 **목록에 없는 것**을 만들 수 있다"는 **자기지시(self-reference)의 기술**이다. 이 아이디어는 훗날 괴델의 불완전성 정리와 튜링의 정지 문제로까지 이어진다(→ [확장편]).

## 5. 무한의 무한한 계단 — 멱집합 정리

실수가 자연수보다 크다면, 자연스러운 질문 — **"가장 큰 무한이 있을까?"** 칸토어의 답은 단호하다. **없다.** 무한은 **끝없이 커지는 사다리**를 이룬다.

핵심은 **멱집합(power set)**[^멱집합]이다. 집합 A의 멱집합 P(A)는 **A의 모든 부분집합을 모은 집합**이다. 예를 들어 A = {a, b}이면
```
P(A) = { ∅, {a}, {b}, {a,b} }    (원소 2개 → 부분집합 4개)
```
유한집합에선 원소가 n개면 부분집합은 2ⁿ개로 **항상 더 많다.**

**칸토어의 정리(멱집합 정리)**: 이것이 **무한집합에서도 성립한다.** 어떤 집합 A든, **P(A)는 A보다 반드시 더 크다**(A에서 P(A)로 가는 전단사는 존재할 수 없다). 증명은 놀랍게도 **또 대각선 논법**이다 — "A의 각 원소를 부분집합에 짝지었다"고 가정하면, "자기를 담은 부분집합에 짝지어지지 **않은** 원소들의 모임"이라는 **빠지는 부분집합**을 언제나 만들 수 있다 [3][7].

이 정리의 결과는 어지럽다:
```
ℕ  <  P(ℕ)  <  P(P(ℕ))  <  P(P(P(ℕ)))  <  ...
ℵ₀ <   𝔠   <    ...     <      ...       <  ...
```
**무한보다 큰 무한, 그보다 더 큰 무한 …** 이 계단은 끝나지 않는다. "무한의 크기"라는 것 자체가 **무한히 많이** 있는 것이다. 참고로 실수의 크기 𝔠는 바로 P(ℕ)의 크기, 즉 **2^ℵ₀**와 같다 [3][7].

여기서 20세기 수학 최대의 질문 하나가 태어난다 — **ℵ₀와 𝔠 사이에, 다른 무한이 끼어 있을까, 없을까?** 이것이 **연속체 가설**이고, 그 답이 "증명도 반증도 불가능"이라는 충격적 결말은 **[확장편]**의 몫이다 [4].

## 6. 칸토어라는 사람 — 조롱받은 천재

이 혁명은 순탄히 받아들여지지 않았다. 당대 최고 권위자 **레오폴트 크로네커**는 칸토어의 무한 이론을 *"수학을 타락시키는 것"*이라 맹비난하며 그의 논문 게재와 교수직을 집요하게 방해했다. "실무한을 완성된 대상으로 다룬다"는 발상이 당시엔 신성모독에 가까웠다 [6].

칸토어는 극심한 우울증에 시달렸고, 여러 차례 요양원을 드나들다 1918년 요양원에서 심장마비로 눈을 감았다(제1차 세계대전기의 궁핍 속이었다). 그러나 그가 옳았다. **다비트 힐베르트**는 훗날 이렇게 선언했다 — *"누구도 칸토어가 창조한 낙원에서 우리를 몰아낼 수 없다."* 오늘날 집합론은 **현대 수학 전체의 공통 언어이자 토대**다 [6][8].

## 7. 흔한 오해·FAQ

**Q1. "∞ + 1 = ∞이니까 무한은 다 같다" 아닌가요?**
그건 **기호 ∞로 하는 산수**의 이야기고, 칸토어가 말한 건 **집합의 크기(기수)**다. 크기로 보면 ℵ₀와 𝔠는 명백히 다르다. "무한 + 1 = 무한"은 맞지만(ℵ₀+1 = ℵ₀), 그렇다고 **모든 무한이 같은 크기인 건 아니다** [1].

**Q2. 유리수가 실수 안에 빽빽한데, 왜 유리수는 작고 실수는 큰가요?**
'빽빽함(조밀성)'과 '크기(기수)'는 **다른 개념**이다. 유리수는 조밀하지만 **셀 수 있고**(ℵ₀), 실수는 **셀 수 없다**(𝔠). 실제로 실수 대부분은 무리수이며, **무리수의 무한이 실수의 크기를 결정**한다 [2][5].

**Q3. 대각선 논법에서 만든 b가 사실은 목록 아래쪽에 있는 거 아닌가요?**
아니다. b는 **목록의 n번째 수와 n번째 자리가 다르도록** 설계됐다. 어떤 번호 k를 대도, b는 k번째 수와 **k번째 자리에서 다르다** → b ≠ (k번째 수). **모든** k에 대해 그러므로 b는 목록 어디에도 없다 [2].

**Q4. 소수 표현의 '0.999… = 1.000…' 같은 중복은 문제가 안 되나요?**
된다 — 그래서 실제 증명에선 대각선을 비틀 때 **0과 9를 피해서**(예: 1~8 사이로만) 새 숫자를 고른다. 그러면 이중표현 문제를 깔끔히 피할 수 있다. 논법의 뼈대는 그대로다 [2].

**Q5. 이게 실생활에 무슨 쓸모가 있나요?**
대각선 논법의 **자기지시 아이디어**는 컴퓨터 과학의 근간이다 — **튜링의 정지 문제(멈추는지 판정하는 프로그램은 없다)**, **괴델의 불완전성 정리**가 모두 이 기술의 후예다. 무한의 크기 이론은 계산 가능성·논리의 한계를 그은 도구가 됐다(→ [확장편]) [2].

## 8. 한눈 요약

| 개념 | 뜻 | 크기 |
|---|---|---|
| 일대일 대응 | 두 집합을 남김없이 짝짓기 = 같은 크기 판정법 | — |
| 가산무한 | 자연수처럼 번호 매겨 나열 가능 | **ℵ₀** |
| 정수·유리수 | 지그재그·대각선으로 나열 가능 | ℵ₀ |

**마지막 한 줄** — 칸토어가 남긴 진짜 유산은 특정 정리가 아니라 **관점의 전환**이다. 무한을 두려워해 피하는 대신, **손에 쥐고 크기를 재는** 법을 인류에게 가르쳤다. 그리고 그 잣대를 들이대자, 무한은 하나가 아니라 **끝없는 위계**로 펼쳐졌다. 그 위계 위에서 벌어지는 더 깊고 어지러운 이야기 — **연속체 가설·선택공리·괴델의 불완전성** — 은 짝을 이루는 **확장편**에서 이어진다.

[^일대일]: 일대일 대응(전단사, bijection) — 두 집합의 원소를 하나도 빠짐없이·겹치지 않게 짝짓는 함수. 무한집합의 '크기 같음'을 판정하는 유일한 잣대다.
[^기수]: 기수(cardinality) — 집합의 '크기(원소의 많음)'를 나타내는 수. 유한이면 원소 개수, 무한이면 ℵ₀, 𝔠 같은 초한기수로 표현한다.
[^알레프]: ℵ₀(알레프 제로) — 가장 작은 무한의 크기. 자연수 집합의 기수이며, 셀 수 있는 무한(가산무한)의 크기다.
[^대각선]: 대각선 논법(diagonal argument) — 칸토어가 1891년 창안. 완성됐다고 가정한 목록의 대각선을 비틀어 '목록에 없는 원소'를 만들어 모순을 내는 증명 기법.
[^멱집합]: 멱집합(power set) — 어떤 집합의 모든 부분집합을 모은 집합. 원소가 n개면 부분집합은 2ⁿ개이고, 무한에서도 원래보다 반드시 크다(칸토어 정리).
[^초한수]: 초한수(transfinite number) — 유한을 넘어선 무한의 크기를 나타내는 수. ℵ₀가 가장 작은 초한기수다. '무한대(∞) 기호'와 달리 엄밀히 계산되는 수 체계.
