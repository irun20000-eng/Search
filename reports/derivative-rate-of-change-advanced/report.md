# 변화율로 예측하기 (확장편)

> 이해편은 `f(a + h) ≈ f(a) + f′(a)h` 라는 한 줄로 예측을 만들었다. 그리고 `h`가 10배가 되자 오차가 100배가 되는 것을 관찰만 하고 넘어갔다. **이 글은 그 관찰을 정리(定理)로 바꾸는 데서 시작한다.** 오차를 부등식으로 묶고(테일러), 한 걸음이 모자라면 여러 걸음으로 나누고(오일러), 재료의 오차가 결과로 얼마나 증폭되는지 계산하고(민감도), 변수가 여럿일 때 "방향"을 다루고(기울기 벡터), 마지막으로 **기계가 미분을 어떻게 수행하는지**(자동미분)까지 간다. 이해편을 읽었다고 전제하며, 거기서 한 이야기는 되풀이하지 않는다.

## TL;DR
- **미분계수의 진짜 정의는 "최선의 선형근사의 계수"다**: `f(a+h) = f(a) + f′(a)h + o(h)`. 극한식보다 이쪽이 본질이고, **다변수·함수공간으로 그대로 확장된다** [1][10].
- **테일러 정리(라그랑주 나머지)가 접선 근사의 오차를 부등식으로 묶는다**: `|R₁| ≤ M|h|²/2`, 여기서 `M = max|f″|`. 이해편의 "오차가 `h²`에 비례" 관찰이 여기서 정리로 승격된다 [2][9].
- **관련 변화율은 연쇄법칙의 응용**이다. 서로 묶인 두 양은 변화율끼리도 묶이며, 원뿔 물통에서 **같은 유량인데 수위 상승 속도가 9배 차이** 나는 이유가 여기서 나온다 [11].
- **오차 전파는 `dV/V = n·(dr/r)`** 로 압축된다. `n`제곱 관계면 상대오차가 `n`배로 증폭된다 — 구슬 지름을 0.5% 잘못 재면 부피는 1.5% 틀린다 [10].
- **오일러 방법은 "접선 한 걸음"을 반복하는 것**이고, 전역 오차는 `h`의 1차에 비례한다. 실제로 스텝을 절반으로 줄이면 오차가 대략 절반이 된다 [12][13].
- **수치미분에는 최적 스텝이 존재한다**. 절단오차는 `h`에 비례해 줄고 반올림오차는 `ε/h`로 늘어, 배정밀도에서 최적 `h ≈ √ε ≈ 10⁻⁸` — **유효숫자의 절반을 잃는다.** 자동미분은 이 상충 자체를 없앤다 [15][14].

## 핵심 포인트
1. **`o(h)` 정의가 극한 정의보다 강하다.** "나눗셈"에 기대지 않으므로 입력이 벡터든 함수든 같은 문장이 그대로 성립한다. 야코비안·프레셰 미분이 모두 이 한 줄의 확장이다.
2. **오차 한계는 `f″`의 최댓값을 요구한다.** 근사의 신뢰 구간을 말하려면 **한 점의 정보로는 부족하고 구간 전체의 정보**가 있어야 한다. 국소성의 대가다.
3. **"여러 걸음으로 나누기"는 공짜가 아니다.** 오일러 방법은 걸음마다 접선을 다시 그으므로 오차가 누적된다. 국소오차가 `h²`인데 걸음 수가 `1/h`라 **전역오차는 `h`** 가 된다.
4. **미분은 증폭기다.** 재료의 작은 불확실성이 결과에서 얼마나 커지는지를 도함수가 결정한다. 민감도 분석·조건수·금융의 듀레이션이 전부 이 관점이다 [7].
5. **기계학습은 미분의 대규모 소비자다.** 역전파는 신경망 전용 기법이 아니라 **역방향 자동미분의 한 사례**이며, 수치미분과 달리 기계 정밀도로 정확하다 [14][16].

## 1. 직관 압축

이해편의 내용을 한 단락으로 접어 둔다. **평균변화율은 할선의 기울기, 순간변화율은 극한을 씌워 얻은 접선의 기울기이며, 점마다의 미분계수를 함수로 묶은 것이 도함수다. `f′`는 방향과 속도를, `f″`는 그 속도가 붙는지 죽는지를 말한다("물가는 오르는데 상승세는 둔화"가 `f′>0, f″<0`이다). 그리고 `f(a+h) ≈ f(a) + f′(a)h` 로 한 걸음 앞을 내다본다.** 여기서부터는 이 마지막 문장의 **오차·확장·기계 구현**만 다룬다.

## 2. 정의·메커니즘 — 미분계수는 "최선의 선형근사 계수"다

고등학교에서 배우는 정의는 극한식이다.

```
f′(a) = lim (f(a+h) − f(a)) / h
        h→0
```

그런데 이 식은 **나눗셈에 의존한다.** 입력이 벡터가 되는 순간 `h`로 나눌 수 없어 그대로는 쓸 수 없다. 그래서 해석학은 같은 내용을 **나눗셈 없이** 다시 쓴다.

```
f(a + h) = f(a) + L·h + o(h)      (h → 0)
                  ↑
            이 L이 유일하게 존재하면 f는 a에서 미분가능하고, L = f′(a)
```

`o(h)`는 **"`h`보다 더 빨리 0으로 가는 나머지"**, 즉 `나머지/h → 0` 을 뜻한다.

> **이 정의가 말하는 것**: 미분가능하다는 것은 **함수를 그 점 근처에서 일차함수로 갈아 끼워도 무시할 만한 오차만 남는다**는 뜻이다. `f′(a)`는 "변화율"이기 이전에 **그 일차함수의 계수**다. 접선이 "가장 잘 맞는 직선"인 이유가 정의에 이미 들어 있다 [1].

**왜 이쪽이 더 강한가 — 그대로 확장되기 때문이다.**

| 입력 공간 | `L`의 정체 | 이름 |
|---|---|---|
| `ℝ → ℝ` | 수 하나 | 미분계수 `f′(a)` |
| `ℝⁿ → ℝ` | 행벡터(1×n) | 기울기 벡터 `∇f(a)` [4] |
| `ℝⁿ → ℝᵐ` | 행렬(m×n) | 야코비 행렬 `Jf(a)` |
| 함수공간 → ℝ | 선형범함수 | 프레셰 미분·변분 |

**네 줄이 전부 같은 한 문장**이다: "증분을 선형사상으로 근사하고 나머지는 `o(h)`". 극한식에 머물면 이 통일이 보이지 않는다.

## 3. 왜 그런가 — 테일러 정리와 오차 한계

근사식이라는 발상 자체는 소박한 곤란에서 출발한다 — 계산기가 없을 때 `√82` 같은 값을 어떻게 구할 것인가 [3]. 이해편에서 `√101 ≈ 10.05` 를 얻고 오차가 `0.000124`임을 **사후에** 확인했다. 실무에서는 **참값을 모르는 채로 오차의 상한**을 말해야 한다. 그 도구가 테일러 정리다.

### 3-1. 진술

`f`가 구간에서 두 번 미분가능하면, `a`와 `a+h` 사이의 **어떤 점 ξ**에 대해

```
f(a + h) = f(a) + f′(a)h + (f″(ξ) / 2) h²
           └───── 접선 근사 ─────┘   └── 나머지 R₁ ──┘
```

가 성립한다(라그랑주 나머지) [2][9]. 나머지항이 **이계도함수** [6] 를 품고 있다는 데 주목할 것 — 오차의 크기를 결정하는 것은 곡선이 얼마나 휘었는가다. `ξ`가 어디인지는 모르지만 **구간 안 어딘가**라는 것은 안다. 그래서 구간에서 `|f″| ≤ M` 이면

```
|R₁| ≤ (M / 2) · h²
```

**이해편의 "10배 가면 100배"가 여기서 나온다.** `h²`이 명시적으로 박혀 있다.

> **평균값 정리와의 관계**: `n = 0`인 경우를 쓰면 `f(a+h) = f(a) + f′(ξ)h` 로, 이것이 정확히 **평균값 정리**다. 테일러 정리는 평균값 정리를 고차로 밀어 올린 것이고, 증명도 롤의 정리를 반복 적용해 얻는다.

### 3-2. Worked Example ① — 오차 한계를 실제로 계산하고 검증하기

`f(x) = √x`, `a = 100`.

```
1단계. 2계도함수
   f′(x)  = ½ x^(−1/2)
   f″(x)  = −¼ x^(−3/2)

2단계. 구간에서의 상한 M
   x ≥ 100 이면 x^(3/2) ≥ 1000 이므로
   |f″(x)| = 1/(4 x^(3/2)) ≤ 1/4000 = 0.00025 = M

3단계. 오차 한계 공식에 대입
   |R₁| ≤ (M/2) h² = 0.000125 · h²
```

**세 경우를 예측 상한과 실제 오차로 대조한다.**

| 목표 | `h` | 접선 예측 | 참값 | **실제 오차** | **이론 상한 `0.000125h²`** | 상한이 지켜졌나 |
|---|---|---|---|---|---|---|
| √101 | 1 | 10.05 | 10.049876 | 0.000124 | **0.000125** | ✅ (거의 딱 맞음) |
| √110 | 10 | 10.5 | 10.488088 | 0.011912 | **0.0125** | ✅ |
| √150 | 50 | 12.5 | 12.247449 | 0.252551 | **0.3125** | ✅ |

**해석 세 가지.**
1. **상한이 세 경우 모두 지켜졌다.** 참값을 몰라도 "오차는 0.000125 이하"라고 **미리** 단언할 수 있다.
2. **`h`가 작을수록 상한이 촘촘하다.** `h=1`에서는 상한과 실제가 소수 여섯째 자리까지 일치하고, `h=50`에서는 24% 여유가 생긴다. `ξ`가 어디인지 모른다는 손실이 멀리 갈수록 커진다.
3. **역으로 쓸 수 있다.** "오차를 `10⁻⁶` 이하로 하려면?" → `0.000125h² ≤ 10⁻⁶` → `h ≤ 0.089`. **필요한 정밀도에서 사용 가능 범위를 역산**하는 것이 실무의 표준 절차다.

## 4. 대표 응용 ① — 관련 변화율(related rates)

두 양이 하나의 관계식으로 묶여 있으면, **양쪽 변화율도 묶인다.** 관계식을 시간으로 미분하면서 연쇄법칙을 쓰는 것이 전부다 [11].

### Worked Example ② — 원뿔 물통의 수위

> 위가 열린 **원뿔 물통**이 있다. 깊이 4m, 윗면 반지름 2m. 물을 **분당 2 m³**로 붓는다. 수위가 **3m**일 때 수위는 얼마나 빨리 오르는가?

```
1단계. 변수를 묶는 관계식
   수면의 반지름 r 과 수위 h 는 닮음비로 묶인다
   r / h = 2 / 4 = 1/2   →   r = h/2

2단계. 부피를 h만 남기고 정리 (★ 미분 전에 반드시)
   V = (1/3)π r² h = (1/3)π (h/2)² h = π h³ / 12

3단계. 양변을 t로 미분 (연쇄법칙)
   dV/dt = (π h² / 4) · dh/dt

4단계. 아는 값 대입
   2 = (π · 3² / 4) · dh/dt
   dh/dt = 8 / (9π) ≈ 0.283 m/분
```

**2단계를 건너뛰면 틀린다.** `V = (1/3)πr²h` 를 그대로 미분하면 `dr/dt`가 함께 튀어나와 미지수가 둘이 된다. **미분하기 전에 변수를 하나로 줄이는 것**이 이 문제 유형의 핵심 기술이다.

**얻는 통찰 — 같은 유량인데 속도가 다르다.** 일반해는 `dh/dt = 8 / (πh²)`:

| 수위 `h` | `dh/dt` | 배율 |
|---|---|---|
| 1 m | **2.546 m/분** | 9배 |
| 2 m | **0.637 m/분** | 2.25배 |
| 3 m | **0.283 m/분** | 1배 |

**유량은 내내 2 m³/분으로 일정한데 수위 상승 속도는 9배 차이 난다.** 위로 갈수록 단면이 넓어져 같은 부피가 더 얇게 퍼지기 때문이다. `dh/dt ∝ 1/h²` 라는 관계가 이 현상을 정량화한다 — **물통 모양이 시간 그래프의 모양을 만든다.**

## 5. 대표 응용 ② — 오차 전파와 민감도

미분은 **증폭률**이기도 하다. 입력의 불확실성 `Δx`가 출력에서 `|f′(x)|·Δx` 로 나타난다 [10].

### Worked Example ③ — 상대오차의 거듭제곱 법칙

> 쇠구슬의 지름을 캘리퍼스로 재니 **20.0 mm**, 측정 불확실성은 **±0.1 mm**다. 부피의 불확실성은?

```
1단계. 모형
   V = (π/6) d³        (d = 지름)

2단계. 미분
   dV/dd = (π/2) d²

3단계. 절대오차 전파
   ΔV ≈ (π/2)(20.0)² (0.1) = (π/2)(400)(0.1) ≈ 62.8 mm³

4단계. 상대오차로 환산
   V = (π/6)(20.0)³ ≈ 4188.8 mm³
   ΔV / V ≈ 62.8 / 4188.8 ≈ 0.015 = 1.5%
   반면 Δd / d = 0.1 / 20.0 = 0.005 = 0.5%
```

**정확히 3배다.** 우연이 아니다. 로그 미분으로 일반화하면

```
V = k dⁿ   →   ln V = ln k + n ln d   →   dV/V = n · (dd/d)
```

**`n`제곱 관계면 상대오차가 `n`배로 증폭된다.** 실무 규칙 하나로 압축된다.

| 관계 | 지수 `n` | 입력 상대오차 1%가 만드는 출력 오차 |
|---|---|---|
| 둘레 ∝ 반지름 | 1 | 1% |
| 넓이 ∝ 반지름² | 2 | 2% |
| 부피 ∝ 반지름³ | 3 | 3% |
| 저항 발열 ∝ 전류² | 2 | 2% |
| 케플러 주기² ∝ 거리³ | 3/2 | 1.5% |

**이계도함수의 부호는 곡선의 볼록성을 결정하고, 부호가 뒤집히는 자리가 변곡점이다** [17]. 이 성질이 금융에서는 아예 고유한 이름을 갖고 산다. 채권 가격을 이자율의 함수로 볼 때 **1차 미분에 해당하는 것이 듀레이션**, **2차 미분에 해당하는 것이 볼록성(convexity)** 이다. 볼록성은 채권 가격을 이자율로 두 번 미분한 이계도함수를 가격으로 나눈 값으로 정의된다 [7]. 이자율이 크게 움직일 때 듀레이션(접선)만으로는 예측이 어긋나고, 볼록성 항을 더해야 맞는다 — **3절의 테일러 2차 항을 실무에서 그대로 쓰는 사례**다.

## 6. 대표 응용 ③ — 미분방정식으로 예측: 오일러 방법

이해편에서 커피 냉각 `dT/dt = −k(T − T주변)` 을 세우고 "한 걸음으로는 부정확하다"에서 멈췄다. **여러 걸음으로 나누면 된다.**

```
오일러 방법:  T_{n+1} = T_n + f(t_n, T_n) · h
              ← 매 걸음 접선을 새로 긋는다
```

### Worked Example ④ — 커피, 10분 뒤 온도

조건: `T(0) = 90℃`, 주변 `20℃`, `k = 0.043 /분`. **`T(10)`은?**

```
참값(해석해)  T(t) = 20 + 70 e^(−0.043t)
              T(10) = 20 + 70 e^(−0.43) = 20 + 70(0.65051) = 65.54 ℃
```

**스텝을 줄여 가며 오일러로 계산한다.** (변화율이 `T−20`에 비례하므로 매 걸음 `T−20`에 `(1 − 0.043h)`가 곱해진다.)

| 스텝 `h` | 걸음 수 | 계산 | `T(10)` 추정 | **오차** | 직전 대비 |
|---|---|---|---|---|---|
| 10분 | 1 | `70 × 0.570` | 59.90 ℃ | **5.64** | — |
| 5분 | 2 | `70 × 0.785²` | 63.14 ℃ | **2.40** | ÷2.35 |
| 2.5분 | 4 | `70 × 0.8925⁴` | 64.42 ℃ | **1.12** | ÷2.14 |
| 1.25분 | 8 | `70 × 0.94625⁸` | 64.99 ℃ | **0.54** | ÷2.07 |

**스텝을 절반으로 줄일 때마다 오차가 거의 정확히 절반이 된다**(비율 2.35 → 2.14 → 2.07 로, 2에 수렴한다). 이것이 **오일러 방법이 1차 정확도**라는 뜻이다 [12][13].

**왜 `h²`이 아니라 `h`인가 — 여기가 이 절의 핵심이다.**

```
한 걸음의 오차(국소 절단오차)  ~ C h²      ← 3절의 테일러 나머지 그대로
걸음 수                        = (구간 길이) / h
─────────────────────────────────────────────────
누적 오차(전역 오차)           ~ C h² × (1/h) = C h    ← 한 차수를 잃는다
```

**한 걸음의 정확도와 여정 전체의 정확도는 다르다.** 이 한 차수의 손실이 룽게–쿠타 같은 고차 기법이 존재하는 이유이고, 수치해석 전체를 관통하는 회계다.

## 7. 다변수로 — 기울기 벡터와 방향도함수

변수가 하나면 갈 수 있는 방향은 좌우 둘뿐이다. **변수가 둘 이상이면 방향이 무한히 많고, 방향마다 변화율이 다르다.**

일변수 미분계수가 접선의 기울기라면, 다변수에서는 **접평면의 기울어짐**을 알아야 하는데 이것은 수 하나로 표현되지 않는다 [4]. 그래서 **벡터**가 필요하다.

```
∇f = ( ∂f/∂x , ∂f/∂y )        기울기 벡터(gradient)

Dᵤf = ∇f · u                   단위벡터 u 방향의 변화율(방향도함수) [5]
```

`Dᵤf = |∇f| cos θ` 이므로 세 가지가 즉시 따라온다.

| 방향 | `cos θ` | 변화율 | 뜻 |
|---|---|---|---|
| `∇f`와 같은 방향 | 1 | `+\|∇f\|` (최대) | **가장 가파른 오르막** |
| `∇f`와 반대 방향 | −1 | `−\|∇f\|` (최소) | **가장 가파른 내리막** ← 경사하강법 |
| `∇f`와 수직 | 0 | 0 | **등고선을 따라 걷는 방향** |

**등산에 비유하면 정확하다.** 안개 속에서 발밑 경사만 느낄 수 있을 때, 가장 가파르게 올라가는 방향이 `∇f`이고, 그 반대로 내려가는 것이 **경사하강법**이다. 등고선 위를 걸으면 높이가 안 변하므로 `∇f`와 수직이다.

> **주의**: 편미분이 존재한다고 미분가능한 것은 아니다. `o(h)` 정의(2절)를 만족해야 진짜 미분가능이고, 편미분만 있고 미분 불가능한 반례가 존재한다. 다만 **편미분이 연속이면 미분가능**이라는 충분조건이 있어 실무에서는 대개 문제되지 않는다. 한편 두 번 편미분할 때 순서를 바꿔도 되는 것은 자동이 아니라 **정리(슈바르츠·클레로)** 의 보장이다 [8].

## 8. 기계는 어떻게 미분하나 — 수치미분 vs 자동미분

### 8-1. 수치미분의 딜레마

가장 소박한 방법은 정의를 그대로 쓰는 것이다.

```
f′(x) ≈ ( f(x+h) − f(x) ) / h        (전방차분)
```

**`h`를 작게 할수록 정확해질 것 같지만 그렇지 않다.** 두 오차가 반대로 움직인다.

```
   오차
    │╲                          ╱
    │ ╲  반올림오차 ~ ε/h      ╱  절단오차 ~ h
    │  ╲                     ╱
    │   ╲___             ___╱
    │       ╲___     ___╱
    │           ╲___╱   ← 최적 h ≈ √ε
    └────────────────────────── h
   작음                        큼
```

- **절단오차**: 접선으로 곡선을 대신한 데서 오는 오차. `h`에 비례해 **줄어든다**.
- **반올림오차**: `f(x+h)`와 `f(x)`가 거의 같은 수라 빼면 유효숫자가 대량으로 사라진다(**자리수 소거**[^자리수소거]). `h`가 작을수록 **커진다**.

둘의 합이 최소가 되는 지점이 존재하고, 배정밀도(기계 엡실론[^기계엡실론] `ε ≈ 2.2 × 10⁻¹⁶`)에서 **최적 `h ≈ √ε ≈ 10⁻⁸`** 이다. 이보다 작게 하면 반올림오차가 지배한다 [15].

**대가가 크다**: 최적점에서조차 얻는 정확도는 약 8자리 — **유효숫자의 절반을 잃는다.** 게다가 파라미터가 `n`개인 함수의 기울기를 구하려면 함수를 **`n+1`번** 평가해야 한다. 파라미터가 수억 개인 신경망에서는 계산 자체가 성립하지 않는다.

### 8-2. 자동미분 — 상충 자체를 없애기

**자동미분(AD)** 은 완전히 다른 발상이다. 근사하지 않고, **연쇄법칙을 프로그램의 실행 과정에 직접 적용**한다 [14].

핵심 관찰: 어떤 프로그램이든 결국 **덧셈·곱셈·`exp`·`sin` 같은 기본 연산의 합성**이다. 기본 연산의 도함수는 전부 알려져 있으므로, 계산 그래프를 따라가며 연쇄법칙을 기계적으로 적용하면 **근사 없이 정확한 도함수**가 나온다.

| | 수치미분 | 기호미분 | **자동미분** |
|---|---|---|---|
| 정확도 | 근사(≈8자리) | 정확 | **정확(기계 정밀도)** |
| 스텝 `h` 선택 | 필요(민감) | 없음 | **없음** |
| 식 팽창 | 없음 | 심각(수식이 폭발) | **없음** |
| `n`개 파라미터 기울기 비용 | 함수 평가 `n+1`회 | — | **역방향 모드는 O(1)회 수준** |

**역전파(backpropagation)는 역방향 모드 자동미분의 한 사례**이며, 신경망 전용 기법이 아니라 훨씬 넓게 적용되는 일반 기법이다 [14][16].

> **여기서 반드시 갈라야 할 것**: 역전파는 **기울기를 계산하는 방법**이고, 경사하강법은 **그 기울기로 파라미터를 갱신하는 방법**이다. 둘은 다른 층위이며, 경사하강법보다 정교한 최적화 기법들도 기울기 계산에는 여전히 역전파를 쓴다 [14].

**즉 현대 기계학습은 7절의 `∇f`를 8절의 방법으로 대규모로 계산하는 일**이라고 요약할 수 있다. 이해편 1절의 "지금 얼마나 빨리 변하나"라는 질문이, 수억 차원에서 초당 수천 번 던져지고 있는 셈이다.

## 9. 통합 의미 — 예측이 깨지는 자리

미분 기반 예측은 강력하지만 **무너지는 조건이 분명하다.** 그 경계를 아는 것이 도구를 아는 것이다.

**① 국소성의 한계 — 외삽은 예측이 아니다.**
접선은 접점 근처에서만 유효하다. 그런데 실무에서 가장 흔한 오용이 **"이 추세대로 가면 2030년에는…"** 이다. 3절의 오차 한계는 `h`가 커지면 상한도 `h²`으로 폭발한다고 정직하게 말한다. **모형이 유효한 `h`의 범위를 함께 말하지 않는 예측은 예측이 아니라 수사(修辭)다.**

**② 매끄러움의 한계 — 현실은 자주 뾰족하다.**
미분 가능성은 강한 가정이다. 주가의 점프, 상전이, 충돌, 계약의 만기 — 현실의 중요한 순간은 **정확히 미분 불가능한 자리에서 일어난다.** 이 지점을 다루려고 약미분·분포이론·비평활 최적화 같은 분야가 자랐다.

**③ 민감성의 한계 — 정확한 도함수도 예측을 보장하지 않는다.**
초기조건에 민감한 계(카오스)에서는 미분방정식이 완벽히 정확해도 장기 예측이 불가능하다. 오차가 지수적으로 증폭되기 때문이다. 기상 예보가 열흘을 넘기 어려운 것이 그 예다. **미분은 "지금의 기울기"를 정확히 주지만, 그 기울기가 미래를 얼마나 오래 지배하는지는 별개 문제다.**

**④ 되짚는 통찰**: 세 한계는 모두 **"미분은 한 점의 정보"** 라는 하나의 사실에서 나온다. 한 점에서 얻은 정보로 구간 전체를 말하려면 반드시 추가 가정(`f″`의 상한, 매끄러움, 안정성)이 필요하다. 3절이 그 대가를 `M`이라는 문자로 정직하게 청구했던 것이다.

## 11. 함정·체크리스트

- [ ] **관련 변화율에서 미분 전에 변수를 하나로 줄였나?** (4절) 관계식에 변수가 둘 남은 채로 미분하면 미지수가 둘이 되어 풀리지 않는다. 닮음비·구속조건을 먼저 대입한다.
- [ ] **오차 한계를 말할 때 `M`을 어느 구간에서 잡았나?** (3절) `f″(a)` 한 점의 값이 아니라 **구간 전체의 최댓값**이어야 상한이 보장된다.
- [ ] **`h`의 유효 범위를 함께 명시했나?** 선형근사 결과를 보고할 때 "이 범위에서 오차 ≤ …"가 빠지면 반쪽이다.
- [ ] **전역오차와 국소오차를 섞지 않았나?** (6절) 오일러의 국소오차는 `h²`, 전역오차는 `h`다. 한 차수 손실을 잊고 "스텝을 절반 줄이면 오차가 1/4"이라고 말하면 틀린다.
- [ ] **수치미분에서 `h`를 무작정 줄이지 않았나?** (8절) `10⁻¹²` 같은 값은 오히려 결과를 망친다. 배정밀도 기준 `√ε ≈ 10⁻⁸` 근처가 최적이며, 정확도가 중요하면 자동미분으로 갈아탄다.
- [ ] **편미분 존재를 미분가능성으로 착각하지 않았나?** (7절) 두 방향의 편미분이 있어도 미분 불가능한 함수가 존재한다. 판정은 `o(h)` 정의로 한다.
- [ ] **역전파와 경사하강법을 같은 것으로 쓰지 않았나?** (8절) 전자는 기울기 계산, 후자는 갱신 규칙이다.
- [ ] **`f′ = 0`을 극값으로 단정하지 않았나?** 안장점·변곡점이 반례다. 다변수에서는 헤세 행렬의 부호까지 봐야 한다.
- [ ] **추세 외삽을 예측이라 부르지 않았나?** (9절) 모형의 유효 범위 밖으로 나간 접선은 근거가 없다.

## 후속 질문·연결

- **왜 오일러보다 룽게–쿠타인가?** 한 걸음 안에서 기울기를 여러 번 재어 국소오차의 차수를 밀어 올리는 구조는 어떻게 설계되나 → 수치해석

- **좌표를 바꿀 때 미분은 어떻게 변환되나** → [[야코비안 변환]] · [[벡터]]

[^자리수소거]: catastrophic cancellation. 크기가 거의 같은 두 부동소수점 수를 뺄 때, 앞쪽의 일치하는 유효숫자들이 모두 소거되고 뒤쪽의 부정확한 자리만 남아 상대오차가 급격히 커지는 현상. 수치미분에서 `h`를 지나치게 줄이면 안 되는 직접적 원인이다.

[^기계엡실론]: machine epsilon. 부동소수점 연산에서 `1`과 구별되는 가장 가까운 수와 `1`의 차이. IEEE 754 배정밀도에서 약 `2.2 × 10⁻¹⁶` (`2⁻⁵²`)이며, 그 계산 체계가 가진 상대 정밀도의 한계를 나타낸다.
