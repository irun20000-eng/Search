# 테일러 급수 (이해편)

> 계산기에 `sin 1` 을 누르면 0.8414709848 이 뜬다. **계산기는 그 값을 어떻게 구했을까.** 삼각형을 그려 자로 잰 것이 아니다. 컴퓨터가 할 줄 아는 연산은 **더하기·빼기·곱하기·나누기 넷뿐**이고, 그 넷으로 만들 수 있는 함수는 **다항식**뿐이다. 그래서 답은 하나로 정해진다 — **sin 을 다항식으로 바꿔야 한다.** 그 바꾸는 법이 테일러 급수다 [1]. 이 글은 계수가 왜 하필 `f⁽ⁿ⁾(a)/n!` 인지를 손으로 유도하고, `e` 와 `sin(0.5)` 를 실제로 계산해 오차가 줄어드는 속도까지 본다. 잉여항의 정확한 형태와 **급수가 원래 함수를 배신하는 경우**는 짝을 이루는 **[확장편]** 이 맡는다.

## TL;DR

- **테일러 급수**: `f` 가 `x = a` 에서 한없이 미분가능하면 `f(a) + f′(a)(x−a) + ⋯ + f⁽ⁿ⁾(a)/n! · (x−a)ⁿ + ⋯` 를 만들 수 있다 [1].
- **계수가 `f⁽ⁿ⁾(a)/n!` 인 이유는 억지가 아니라 강제다.** "원래 함수와 도함수값을 n차까지 전부 맞춘다"고 요구하면 계수가 그 값 말고는 될 수 없다(§3).
- `a = 0` 인 경우를 특별히 **매클로린 급수**라 부른다 [4].
- 대표 다섯: `eˣ`, `sin x`, `cos x` 는 **모든 실수에서** 수렴하고, `ln(1+x)` 는 `(−1, 1]`, `1/(1+x)` 는 `(−1, 1)` 에서 수렴한다 [1].
- **몇 항만 써도 놀랍도록 잘 맞는다.** `sin(0.5)` 는 3차항까지만 써도 오차가 `2.6 × 10⁻⁴`, 5차항까지면 `1.5 × 10⁻⁶` 다(§6).
- **다만 무한히 미분가능하다고 급수가 원래 함수와 같아지는 것은 아니다** [1]. 이 균열이 확장편의 주제다.

## 핵심 포인트

1. **다항식은 컴퓨터가 계산할 수 있는 유일한 함수다.** 사칙연산만으로 값이 나온다. 테일러 급수는 그 사실 때문에 필요하다.
2. **접선을 일반화한 것이다.** 1차 테일러 다항식이 바로 접선이고 [2], 차수를 올리면 접선이 못 잡는 휘어짐까지 따라간다.
3. **`n!` 은 미분을 n번 했을 때 튀어나오는 상수를 되돌리는 장치다.** `(x−a)ⁿ` 을 n번 미분하면 `n!` 이 나오므로, 미리 나눠 둬야 계수가 `f⁽ⁿ⁾(a)` 와 맞아떨어진다.
4. **수렴구간이 함수마다 다르다** [1]. `eˣ` 는 아무 데서나 되고 `ln(1+x)` 는 `x = 1` 까지만 된다 — 그 경계가 어디서 오는지가 확장편의 절반이다.
5. **테일러 본인은 이 결과의 가치를 몰랐다.** 1715년에 발표됐지만 **중요성이 인정된 것은 1772년**, 라그랑주가 이것을 미분학의 기본 원리라고 선언하면서였다 [8].

## 1. 왜 필요했나 — 계산기는 sin(1)을 어떻게 구하나

컴퓨터의 산술장치가 할 줄 아는 것은 **덧셈·뺄셈·곱셈·나눗셈** 넷뿐이다. 그 넷을 유한 번 조합해 만들 수 있는 함수를 적어 보면 이렇게 된다.

```
   c₀ + c₁x + c₂x² + ⋯ + cₙxⁿ      ← 다항식
   (여기에 나눗셈을 허용하면 유리함수까지)
```

`sin`, `cos`, `eˣ`, `ln` 은 이 목록에 **없다.** 정의 자체가 사칙연산으로 안 써진다. 그런데 계산기는 이 값들을 소수점 열 자리까지 즉시 내놓는다.

**해법은 하나뿐이다 — 사칙연산으로 만들 수 있는 것 중에서 가장 비슷한 것을 찾아 그걸로 대신한다.** 즉 다항식으로 갈아 끼운다.

그러면 질문이 정확해진다.

> **주어진 함수와 가장 비슷한 n차 다항식은 무엇인가?**

이 질문의 답이 **테일러 다항식**이고, 차수를 무한히 올린 것이 **테일러 급수**다 [1][2].

**역사적으로도 이 순서였다.** 14세기 인도의 마다바가 사인·코사인·아크탄젠트에 대해 **개별 급수**를 이미 찾았고, 1670년 무렵 뉴턴과 그레고리가 각자 방법을 만들었다. 그러나 **함수 일반에 대한 방법**을 처음 발표한 것은 1715년 브룩 테일러였고, 그래서 이름이 그렇게 붙었다 [6]. 테일러의 책은 『Methodus incrementorum directa et inversa』이며, 그가 이 정리를 처음 언급한 것은 **1712년 7월 26일 머신에게 보낸 편지**였다 [8].

## 2. 접선에서 한 걸음 더

이미 아는 것에서 출발하자. 어떤 점 `x = a` 근처에서 함수를 가장 잘 흉내 내는 **일차함수**는 접선이다 [2].

```
   1차 근사(접선):   p₁(x) = f(a) + f′(a)(x − a)
```

이것이 하는 일은 두 가지다 — **높이를 맞추고**(`p₁(a) = f(a)`) **기울기를 맞춘다**(`p₁′(a) = f′(a)`).

접선의 한계는 명확하다. **휘어짐을 모른다.** 그래서 `a` 에서 멀어지면 금세 벌어진다.

```
   같은 점에서 차수를 올려 갈 때 (예: cos x, a = 0)

   차수 0 :  1                          ← 높이만 맞춤
   차수 2 :  1 − x²/2                   ← 휘어짐까지 맞춤
   차수 4 :  1 − x²/2 + x⁴/24           ← 휘어짐의 변화까지
   차수 6 :  1 − x²/2 + x⁴/24 − x⁶/720  ← …

        ▲                     실제 cos x
      1 ┤●╌╌╌╌╮
        │      ╲   ╌╌ 0차: 계속 1
        │       ╲
      0 ┼────────╲────────────▶ x
        │         ╲
        │  2차는 여기까지 붙어 오다 떨어지고,
        │  4차는 더 멀리까지 붙어 온다
```

**아이디어는 이것을 계속 밀어 올리는 것이다** — 높이, 기울기, 휘어짐, 휘어짐의 변화… 를 **n계 도함수까지 전부 맞춘다.**

## 3. 계수는 왜 f⁽ⁿ⁾(a)/n! 인가 (유도)

여기가 이 글의 핵심이다. 공식을 외우는 대신 **강제로 정해지는 과정**을 본다.

**목표를 식으로 적는다.** 구하려는 n차 다항식을 `(x−a)` 의 거듭제곱으로 써 두자.

```
p(x) = c₀ + c₁(x−a) + c₂(x−a)² + c₃(x−a)³ + ⋯ + cₙ(x−a)ⁿ
```

요구 조건은 **`x = a` 에서 원래 함수와 도함수값이 n계까지 전부 일치**하는 것이다.

```
p(a) = f(a),  p′(a) = f′(a),  p″(a) = f″(a),  …,  p⁽ⁿ⁾(a) = f⁽ⁿ⁾(a)
```

**c₀ 부터 하나씩 뽑는다.** `x = a` 를 넣으면 `(x−a)` 가 붙은 항은 전부 0이 되므로

```
p(a) = c₀            ⇒   c₀ = f(a)
```

**한 번 미분하고 다시 대입한다.**

```
p′(x) = c₁ + 2c₂(x−a) + 3c₃(x−a)² + ⋯
p′(a) = c₁          ⇒   c₁ = f′(a)
```

**두 번 미분한다.** 여기서 상수가 처음 튀어나온다.

```
p″(x) = 2c₂ + 3·2·c₃(x−a) + ⋯
p″(a) = 2c₂         ⇒   c₂ = f″(a)/2
```

**세 번 미분한다.**

```
p‴(x) = 3·2·1·c₃ + 4·3·2·c₄(x−a) + ⋯
p‴(a) = 6c₃        ⇒   c₃ = f‴(a)/6 = f‴(a)/3!
```

**규칙이 보인다.** `(x−a)ⁿ` 을 n번 미분하면 지수가 하나씩 내려오면서 곱해진다.

```
(x−a)ⁿ  →  n(x−a)ⁿ⁻¹  →  n(n−1)(x−a)ⁿ⁻²  →  ⋯  →  n(n−1)⋯2·1 = n!
```

그래서 n번 미분한 뒤 `x = a` 를 넣으면 **`n! · cₙ`** 만 살아남는다.

```
p⁽ⁿ⁾(a) = n! · cₙ = f⁽ⁿ⁾(a)     ⇒   cₙ = f⁽ⁿ⁾(a) / n!
```

**`n!` 은 장식이 아니다.** 미분이 만들어 내는 상수 `n!` 을 **미리 나눠서 상쇄**해 두는 장치다. 그래야 계수 자리에 `f⁽ⁿ⁾(a)` 가 깨끗하게 앉는다.

이렇게 얻은 것이 **n차 테일러 다항식**이고 [2], 차수를 무한히 올린 것이 **테일러 급수**다 [1].

```
             ∞   f⁽ⁿ⁾(a)
f(x)  ~     Σ   ────────  (x − a)ⁿ
            n=0    n!
```

`a = 0` 인 경우를 따로 **매클로린 급수**라 부른다 [4].

## 4. 대표 급수 다섯 개

`a = 0` 에서 전개한 다섯 개다 [1].

| 함수 | 매클로린 급수 | 수렴구간 |
|---|---|---|
| `eˣ` | `1 + x + x²/2! + x³/3! + ⋯` | `(−∞, ∞)` |
| `sin x` | `x − x³/3! + x⁵/5! − ⋯` | `(−∞, ∞)` |
| `cos x` | `1 − x²/2! + x⁴/4! − ⋯` | `(−∞, ∞)` |
| `ln(1+x)` | `x − x²/2 + x³/3 − ⋯` | `(−1, 1]` |
| `1/(1+x)` | `1 − x + x² − x³ + ⋯` | `(−1, 1)` |

**두 가지를 짚어 둘 만하다.**

- **`sin` 에 짝수차 항이 없다.** `sin` 은 기함수라 `f(0) = f″(0) = f⁗(0) = ⋯ = 0` 이기 때문이다. `cos` 은 반대로 홀수차가 없다.
- **위 다섯은 수렴구간 안에서 원래 함숫값으로 정확히 수렴한다** [1]. 이것이 당연하지 않다는 것이 확장편의 이야기다.

## 5. Worked Example — e 를 손으로 구한다

`eˣ` 에 `x = 1` 을 넣으면 급수가 이렇게 된다.

```
e = 1 + 1 + 1/2! + 1/3! + 1/4! + ⋯ = Σ 1/n!
```

**분수로 끝까지 더해 보자.**

| 마지막 항 `n` | 항 수(`n+1`) | 부분합(분수) | 부분합(소수) | 참값과의 오차 |
|---|---|---|---|---|
| n = 1 | 2개 | 2 | 2.0000000000 | 7.18 × 10⁻¹ |
| n = 2 | 3개 | 5/2 | 2.5000000000 | 2.18 × 10⁻¹ |
| n = 3 | 4개 | 8/3 | 2.6666666667 | 5.16 × 10⁻² |
| n = 4 | 5개 | 65/24 | 2.7083333333 | 9.95 × 10⁻³ |
| n = 5 | 6개 | 163/60 | 2.7166666667 | 1.62 × 10⁻³ |
| n = 6 | 7개 | 1957/720 | 2.7180555556 | 2.26 × 10⁻⁴ |
| n = 9 | **10개** | 98641/36288 | 2.7182815256 | 3.03 × 10⁻⁷ |

참값은 `e = 2.7182818285…` 다.

**읽을 것 두 가지.**

- **열 개 항으로 소수점 여섯 자리가 맞는다.** 분모의 `n!` 이 폭발적으로 커지기 때문이다 — `9! = 362880` 이라 그 항은 이미 `2.8 × 10⁻⁶` 밖에 안 된다.
- **오차가 매 단계 대략 한 자릿수씩 줄다가 점점 더 빨리 줄어든다.** 등비수열보다 빠르다. 이것이 계승이 분모에 있는 급수의 특징이다.

## 6. Worked Example — sin(0.5), 오차가 줄어드는 속도

이번에는 `sin x = x − x³/3! + x⁵/5! − ⋯` 에 `x = 0.5` 를 넣는다. 참값은 `sin(0.5) = 0.4794255386…` 이다.

**1차까지.** `p₁(0.5) = 0.5`

```
오차 = |0.4794255386 − 0.5| = 2.06 × 10⁻²
```

**3차까지.** `p₃(0.5) = 0.5 − (0.5)³/6 = 0.5 − 0.0208333333 = 0.4791666667`

```
오차 = 2.59 × 10⁻⁴
```

**5차까지.** `p₅(0.5) = 0.4791666667 + (0.5)⁵/120 = 0.4791666667 + 0.0002604167 = 0.4794270833`

```
오차 = 1.54 × 10⁻⁶
```

**7차까지.** `p₇(0.5) = 0.4794255332`

```
오차 = 5.37 × 10⁻⁹
```

표로 모으면 이렇다.

| 차수 | 근삿값 | 오차 | 앞 단계 대비 |
|---|---|---|---|
| 1 | 0.5000000000 | 2.06 × 10⁻² | — |
| 3 | 0.4791666667 | 2.59 × 10⁻⁴ | 약 1/80 |
| 5 | 0.4794270833 | 1.54 × 10⁻⁶ | 약 1/168 |
| 7 | 0.4794255332 | 5.37 × 10⁻⁹ | 약 1/288 |

**항 두 개를 더할 때마다 오차가 백 배 이상 줄어든다.** 그리고 줄어드는 배율 자체가 커진다 — 계승이 분모에서 점점 세게 눌러 주기 때문이다.

**실용적으로 무슨 뜻인가.** 계산기가 `sin(0.5)` 를 소수 **일곱** 자리까지 맞히려면 **항 네 개**면 충분하다(여덟째 자리는 아직 어긋난다 — 오차가 `5.37 × 10⁻⁹` 라 `5 × 10⁻⁹` 를 살짝 넘는다). 곱셈 몇 번과 나눗셈 몇 번이면 끝난다.

## 7. 어디까지 믿을 수 있나 — 수렴구간

여기서 조심할 것이 나온다. **급수를 만들 수 있다는 것과 그것이 수렴한다는 것은 다른 이야기다.**

`1/(1+x)` 의 매클로린 급수 `1 − x + x² − x³ + ⋯` 를 보자. 이건 등비급수이므로 `|x| < 1` 에서만 수렴한다 [1].

```
   x = 0.5  →  1 − 0.5 + 0.25 − 0.125 + ⋯ = 0.666… = 1/1.5   ✓ 맞는다
   x = 2    →  1 − 2 + 4 − 8 + 16 − ⋯                        ✗ 발산한다
```

그런데 `1/(1+x)` 자체는 `x = 2` 에서 아무 문제 없이 `1/3` 이다. **함수는 멀쩡한데 급수가 못 따라간다.**

수렴하는 `x` 들을 모으면 **구간**이 되고 [1], 그 구간의 반지름을 **수렴반경**[^수렴반경]이라 부른다. 함수마다 다르다.

| 함수 | 수렴반경 | 왜 거기서 멈추나 |
|---|---|---|
| `eˣ`, `sin x`, `cos x` | `∞` | 분모의 `n!` 이 무엇이든 이긴다 |
| `ln(1+x)` | `1` | `x = −1` 에서 함수 자체가 `−∞` 로 간다 |
| `1/(1+x)` | `1` | `x = −1` 에서 분모가 0이 된다 |

앞의 둘은 이유가 눈에 보인다. **그런데 이유가 안 보이는 경우가 있다** — 확장편에서 다룬다.

## 8. 흔한 오해·FAQ

**Q1. 무한히 미분가능하면 테일러 급수가 그 함수와 같아지나?**
**아니다.** 이것이 가장 흔한 오해다. 수학백과는 못을 박는다 — 테일러 급수의 수렴구간이 `(−∞, ∞)` 인데도 **해석적이 아닐 수 있다** [1]. 즉 급수가 온 실직선에서 잘 수렴하는데 그 합이 원래 함수가 아닌 경우가 실제로 있다. 확장편의 §5가 그 함수를 다룬다.

**Q2. 그럼 §4의 다섯 개는 왜 믿어도 되나?**
그 다섯은 **수렴구간 안의 모든 `x` 에서 원래 함숫값으로 수렴한다는 것이 확인된** 경우다 [1]. 확인하는 도구가 **테일러 정리**이고, 원래 함수와 n차 테일러 다항식의 오차 `Eₙ(x) = f(x) − pₙ(x)` 가 0으로 가는지를 본다 [1][3]. 그 오차를 `(n+1)`계 도함수로 표현해 주는 것이 테일러 정리의 역할이다 [3].

**Q3. `n!` 없이 그냥 `f⁽ⁿ⁾(a)(x−a)ⁿ` 을 더하면 안 되나?**
안 된다. §3에서 봤듯 `(x−a)ⁿ` 을 n번 미분하면 `n!` 이 튀어나온다. `n!` 로 나누지 않으면 n번 미분했을 때 `n!·f⁽ⁿ⁾(a)` 가 되어 조건이 깨진다. 실제로 `n = 5` 만 돼도 계수가 **120배** 어긋난다.

**Q4. 왜 하필 `x = a` 근처에서만 잘 맞나?**
**정보를 `a` 한 점에서만 긁어 왔기 때문이다.** 테일러 다항식이 쓰는 재료는 `f(a), f′(a), f″(a), …` 뿐이고 전부 `a` 에서의 값이다. 그러니 `a` 에서 멀어질수록 근거가 약해진다. `(x−a)ⁿ` 이라는 형태 자체가 "`a` 에서 얼마나 떨어졌나"를 벌점으로 매기는 구조다.

**Q5. 근사를 잘하려면 차수를 올리면 되나, 아니면 `a` 를 옮기면 되나?**
**둘 다 되고, 보통 `a` 를 옮기는 쪽이 싸다.** `sin(3.1)` 을 구할 때 `a = 0` 에서 전개하면 `x = 3.1` 이 멀어 항이 많이 필요하지만, `a = π` 에서 전개하면 `x − a ≈ −0.0416` 이라 두세 항이면 끝난다. 실제 수치 라이브러리가 쓰는 전략이 이것이다(구간을 잘게 나눠 각 구간의 중심에서 전개).

## 9. 한눈 요약

| 물음 | 답 |
|---|---|
| 무엇인가 | 함수를 `(x−a)` 의 거듭제곱 무한합으로 바꾼 것 [1] |
| 계수는 | `f⁽ⁿ⁾(a)/n!` — 조건에서 **강제로 정해진다**(§3) |
| `n!` 은 왜 | `(x−a)ⁿ` 을 n번 미분하면 `n!` 이 나오므로 미리 상쇄 |
| `a = 0` 이면 | 매클로린 급수 [4] |
| 얼마나 잘 맞나 | `sin(0.5)` 는 항 네 개로 오차 `5.37 × 10⁻⁹`(§6) |
| 항상 되나 | **아니다.** 수렴구간이 있고, 수렴해도 원래 함수와 다를 수 있다 [1] |

한 문장으로: **테일러 급수는 한 점에서 긁어모은 미분 정보만으로 함수 전체를 다항식으로 복원하려는 시도이고, 그 시도가 어디까지 성공하는지가 나머지 이야기 전부다.**

## 더 깊이 — 확장편으로

이해편은 **급수를 만드는 법**과 **그것이 잘 맞는다는 관찰**까지 왔다. 확장편 **[[테일러 정리]]** 는 "얼마나 잘 맞는지를 어떻게 보증하는가"와 "언제 보증이 깨지는가"로 간다.

- **잉여항 네 형태** — 페아노·라그랑주·코시·적분형. 각각 가정과 쓰임이 다르다 [3][7].
- **테일러 정리는 평균값 정리의 고차 일반화다** — `n = 0` 이 정확히 평균값 정리다 [5][7].
- **수렴반경의 진짜 이유는 복소평면에 있다** — `1/(1+x²)` 는 실수축에서 아무 문제가 없는데 수렴반경이 1이다. 범인은 `±i` 다 [6].
- **급수가 함수를 배신하는 순간** — `e^(−1/x²)` 는 무한히 미분가능하고 모든 계수가 0이라 급수가 항등 0인데, 함수는 0이 아니다 [1][6].
- **보렐 정리** — 어떤 수열을 아무렇게나 가져와도 그것을 테일러 계수로 갖는 매끄러운 함수가 존재한다 [6]. 계수는 함수를 거의 결정하지 못한다는 뜻이다.
