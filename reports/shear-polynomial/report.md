# 전단변환으로 다항함수 보기 (이해편)

> "삼차함수는 왜 다들 비슷하게 생겼을까?" 계수를 아무리 바꿔도 결국 **S자 아니면 단조 증가**, 둘 중 하나다. 이건 우연이 아니다. **모든 삼차함수는 사실상 y = ax³ 하나가 변장한 것**이고, 그 변장의 정체가 바로 **전단변환(shear transformation)**이다 [4][5]. 이 글은 **자유도 → 선형변환 → 전단변환 → 보존되는 것**의 순서로, 다항함수를 "식"이 아니라 **"변환으로 옮겨 다니는 하나의 도형"**으로 보는 눈을 만든다. 이 관점을 심화문제 풀이 무기로 바꾸는 법은 짝을 이루는 **[확장편]**에서 다룬다.

## TL;DR
- **자유도로 세어 보기**: 이차함수 y=ax²+bx+c의 계수 3개는 **평행이동만으로** 전부 정리돼 y=ax² 하나가 된다. 그런데 **삼차함수는 평행이동만으로 y=ax³까지 못 간다** — **일차항이 끝까지 남는다** [4].
- **그 일차항을 지우는 변환이 전단변환**: (x, y) → (x, y + kx). 그래프로는 **y = f(x) → y = f(x) + kx**, 즉 **일차항만 갈아끼우는** 변환이다 [5].
- **전단변환의 핵심 성질 = 넓이 보존**: 행렬식이 1이기 때문이다. 행렬식의 절댓값이 곧 **넓이 배율**이므로, det = 1이면 도형이 찌그러져도 **넓이는 그대로** [3][6].
- **x좌표는 아예 안 변한다**: 전단은 점을 **위아래로만** 민다. 그래서 교점·접점의 **x좌표가 완전히 보존**된다 [5].
- **그래서 결론**: 모든 삼차함수는 **평행이동 + 전단변환(둘 다 넓이 보존)**으로 **y = ax³**가 된다. 삼차함수 문제의 넓이·x좌표 관계는 전부 **y = ax³에서 계산해도 같다** [4][8].

## 핵심 포인트
1. **자유도(자유롭게 정할 수 있는 수)** 관점: 이차는 평행이동으로 끝, 삼차는 **하나가 남는다** [4].
2. **선형변환**은 "덧셈과 상수배를 보존하는 변환"이고 **행렬**로 표현된다 [1].
3. **전단변환 행렬은 대각선 1, 한쪽 구석에 k** — 그래서 det = 1 [5][10].
4. **행렬식의 절댓값 = 넓이 배율.** |det| = 1이면 넓이 보존(부호는 방향만 뜻한다) [3][6].
5. **변곡점은 전단에 끄떡없다**: (f + kx)″ = f″ 이므로 이계도함수가 그대로 [7].
6. **극점은 전단에 흔들린다**: (f + kx)′ = f′ + k 이므로 극점이 움직이고, 심지어 **사라지기도** 한다 [7].

## 1. 문제의식 — 다항함수는 왜 다 비슷하게 생겼나

교과서에서 삼차함수를 배우면 그래프가 딱 두 종류로 나온다: **봉우리와 골짜기가 있는 S자**, 아니면 **계속 오르기만 하는 단조 곡선**. 계수 a, b, c, d를 아무리 바꿔도 이 둘을 벗어나지 못한다.

이차함수는 더 심하다. y = ax² + bx + c는 계수가 3개인데, 완전제곱으로 정리하면

`y = a(x + b/(2a))² + (c − b²/(4a))`

즉 **y = ax²를 좌우·위아래로 옮긴 것**일 뿐이다. 계수 3개가 있어도 **모양은 a 하나로 결정**된다.

여기서 자연스러운 질문이 나온다. **"삼차함수도 마찬가지 아닐까?"** 결론부터 말하면 **거의 맞지만, 딱 하나가 모자란다.** 그 모자란 하나를 메우는 도구가 전단변환이고, 이 글의 주인공이다 [4].

> 이 관점은 유튜브 채널 **수학한수**의 영상 **「이 영상으로 다항함수를 보는 눈이 바뀝니다」**(2026-02-28, 10분 13초)가 정리한 틀을 따른다. 영상은 *일차·이차함수의 자유도 → 삼차함수의 자유도와 대칭점 → 전단변환 → 전단에서 보존되는 것들 → 전단 동형과 전단 면역 조건* 순으로 전개하며, 같은 주제의 **3부작 시리즈**로 이어진다 [4].

## 2. 자유도로 세어 보기 — 무엇이 끝까지 남는가

**자유도(degree of freedom)**[^자유도]란 "내가 자유롭게 정할 수 있는 수의 개수"다. 다항함수의 자유도를 세고, 거기서 **평행이동으로 없앨 수 있는 것**을 빼 보자.

우리가 쓸 수 있는 평행이동은 두 가지다: **좌우 이동(x축 방향)**과 **위아래 이동(y축 방향)**. 즉 **평행이동은 자유도 2개를 소모**한다.

### 2-1. 이차함수 — 평행이동으로 끝
y = ax² + bx + c는 계수 **3개**.
- **좌우 이동**으로 일차항 b를 없앤다(완전제곱).
- **위아래 이동**으로 상수항을 없앤다.
- 남는 것: **a 하나.**

3 − 2 = 1. 딱 맞아떨어진다. 그래서 **모든 이차함수는 y = ax²의 평행이동**이고, 모양을 정하는 건 a뿐이다(바로 위 완전제곱 계산이 그 증명이다).

### 2-2. 삼차함수 — 하나가 남는다
y = ax³ + bx² + cx + d는 계수 **4개**.
- **좌우 이동**으로 이차항 b를 없앨 수 있다. x를 x − b/(3a)로 바꾸면 x²항이 정확히 사라진다(이 조작은 고전적으로 **감차 삼차식(depressed cubic)** 만들기라 부른다) [8].
- **위아래 이동**으로 상수항을 없앤다.
- 남는 것: **a, 그리고 일차항 계수** — **두 개.**

4 − 2 = 2. 이차함수와 달리 **a 말고도 하나가 더 남는다.** 정리하면 삼차함수는 평행이동만으로 여기까지 간다:

`y = ax³ + px`   (p는 남은 일차항 계수)

이 p가 **모양을 실제로 바꾼다.** f′ = 3ax² + p 이므로 극점이 생기는 조건은 **p/a < 0**이다. 예컨대 **a > 0**일 때는 p < 0이면 봉우리·골짜기가 생기고(S자), p ≥ 0이면 단조 증가한다. (a < 0이면 부호가 뒤집혀 p > 0에서 S자, p ≤ 0에서 단조 **감소**다.) 앞에서 본 "두 종류"의 정체가 바로 이 p다.

| 함수 | 계수 개수 | 평행이동이 실제로 지우는 것 | 남는 것 |
|---|---|---|---|
| 일차 y=ax+b | 2 | **1개뿐** (상수항) | **1** (기울기 a) |
| 이차 y=ax²+bx+c | 3 | 2 (일차항·상수항) | **1** (a) |
| 삼차 y=ax³+bx²+cx+d | 4 | 2 (이차항·상수항) | **2** (a, 일차항 p) |
| 사차 y=ax⁴+⋯ | 5 | 2 (삼차항·상수항) | **3** (a, 이차항, 일차항) |

> ⚠️ 표를 읽는 주의: **"계수 개수 − 2"가 늘 답은 아니다.** 일차함수는 평행이동을 두 방향으로 걸어도 `a(x+s) + b + t = ax + (as+b+t)`가 되어 **상수항 하나만 움직이고 기울기는 꿈쩍하지 않는다.** 즉 평행이동 두 개가 **겹쳐서** 실질적으로 하나 몫만 한다. 이차 이상에서는 두 이동이 각각 다른 계수를 지우므로 뺄셈이 그대로 성립한다.

> 핵심: **삼차부터는 평행이동만으로 표준형에 도달하지 못한다.** 남은 **일차항**을 없앨 새 도구가 필요하다 — 그게 전단변환이다 [4].

## 3. 선형변환과 행렬 — 도구 준비

### 3-1. 선형변환이란
**선형변환(일차변환, linear transformation)**[^선형변환]은 평면의 점을 다른 점으로 옮기되, **덧셈과 상수배를 보존**하는 변환이다 [1]. 좌표로 쓰면 상수항 없는 일차식으로 표현된다:

`(x, y) → (ax + by, cx + dy)`

이걸 **행렬**로 묶어 쓴다. 열벡터 (x, y)에 행렬을 곱하는 형태다:

```
[ a  b ] [ x ]   [ ax + by ]
[ c  d ] [ y ] = [ cx + dy ]
```

회전·대칭·확대축소·전단이 전부 이 틀에 들어간다 [2].

### 3-2. 행렬식의 절댓값 = 넓이 배율
행렬식(determinant)[^행렬식] det = ad − bc는 **역행렬 존재 여부를 판정**하는 수인 동시에 [3], 기하적으로는 훨씬 직관적인 의미를 갖는다:

> **|det| = 그 변환이 넓이를 몇 배로 만드는가.**

넓이 1인 정사각형이 변환 후 평행사변형이 되는데, 그 평행사변형의 넓이가 정확히 |det|다. 그러므로 **|det| = 1인 변환은 도형을 찌그러뜨려도 넓이를 바꾸지 않는다** [3][6].

이 한 줄이 이 글 전체의 심장이다.

## 4. 전단변환 — 카드 뭉치를 밀듯이

### 4-1. 정의와 그림
**전단변환(shear transformation)**[^전단]은 이런 변환이다 [5]:

`(x, y) → (x, y + kx)`

즉 **x좌표는 그대로 두고, y만 kx만큼 밀어 올린다.** 행렬로 쓰면:

```
[ 1  0 ] [ x ]   [   x    ]
[ k  1 ] [ y ] = [ kx + y ]
```

대각선이 1이고 한쪽 구석에만 k가 있는 모양 — **이 생김새가 전단의 지문**이다 [10].

**직관**: 책상에 카드를 수북이 쌓아 놓고 **위쪽을 옆으로 슥 밀면** 옆면이 평행사변형이 된다. 카드 한 장 한 장은 **찢어지지도 겹치지도 않고**, 카드 개수도 그대로다. 그래서 **부피(넓이)가 보존**된다 [5].

### 4-2. 행렬식은 반드시 1
```
det = 1 × 1 − 0 × k = 1
```
k가 무엇이든 **항상 1이다.** k가 곱해지는 자리는 0과 짝을 이루므로 행렬식 계산에 아예 기여하지 못하기 때문이다 [10]. 따라서 **전단변환은 언제나 넓이 보존**이고, 방향(시계/반시계)도 뒤집지 않는다 [5][6].

### 4-3. 그래프에 적용하면 — "일차항만 갈아끼우기"
이제 핵심이다. 함수 y = f(x)의 그래프는 점 **(x, f(x))**의 모임이다. 여기에 전단변환을 먹이면

`(x, f(x)) → (x, f(x) + kx)`

이 되고, 이 점들의 모임은 곧 **y = f(x) + kx의 그래프**다.

> **전단변환 = 함수에 일차항 kx를 더하는 것.** 그래프 세계에서 전단은 "**일차항만 바꾸는 변환**"이다 [4][5].

2장에서 삼차함수에 **일차항 하나가 끝까지 남았던 것**을 떠올리자. 전단변환은 정확히 **그 일차항을 조준하는 도구**다. 우연이 아니라, 필요해서 등장한 것이다.

## 5. 무엇이 보존되고 무엇이 안 되나

전단변환을 쓰려면 **무엇을 믿고 무엇을 의심해야 하는지**를 정확히 알아야 한다.

### 5-1. 보존되는 것 ✅
- **x좌표.** 전단은 점을 **수직으로만** 민다. 교점·접점의 x좌표는 **완전히 그대로** [5].
- **넓이.** det = 1 [3][6].
- **직선은 직선으로.** 선형변환이므로 직선이 휘지 않는다 [2].
- **이계도함수.** (f + kx)″ = f″. 일차항은 두 번 미분하면 사라지기 때문이다.
- **변곡점.** f″ = 0인 x가 안 변하고 x좌표도 안 변하므로, **변곡점은 변곡점으로** 간다 [7].
- **점대칭(대칭점).** 삼차함수의 변곡점 대칭도 그대로 유지된다 [7].

### 5-2. 보존되지 않는 것 ❌
- **일차도함수.** (f + kx)′ = f′ + k. 기울기가 통째로 k만큼 밀린다.
- **극대·극소.** f′ = 0의 해가 달라지므로 극점이 **이동**한다. 심지어 k를 크게 잡으면 **극점이 아예 사라진다**(S자 → 단조 증가) [7].
- **y좌표·함숫값.**
- **길이·각도·수직 관계.** 전단은 모양을 찌그러뜨린다. 넓이만 지킬 뿐이다 [5].

| 대상 | 전단에서 | 이유 |
|---|---|---|
| x좌표 | ✅ 불변 | 수직으로만 민다 |
| 넓이 | ✅ 불변 | det = 1 |
| 직선 | ✅ 직선 유지 | 선형변환 |
| 변곡점 | ✅ 불변 | f″가 안 변함 |
| 극점 | ❌ 이동·소멸 | f′ → f′ + k |
| 길이·각도 | ❌ 변함 | 등거리변환이 아님 |

> 실전 감각: **"x좌표와 넓이를 묻는 문제 = 전단으로 옮겨도 안전"**, **"극값이나 기울기를 묻는 문제 = 전단하면 답이 달라진다."** 이 구분이 확장편의 출발점이다.

## 6. 삼차함수의 진짜 정체 — 표준화 3단계

이제 조립하자. 임의의 삼차함수 y = ax³ + bx² + cx + d를 이렇게 옮긴다.

**1단계 — 좌우 평행이동.** x를 x − b/(3a)로 바꿔 **이차항을 없앤다.** 이건 변곡점을 y축 위로 옮기는 것과 같다 [8].
결과: `y = ax³ + px + q`

**2단계 — 위아래 평행이동.** 상수항 q를 없앤다. 이제 **변곡점이 원점**이다.
결과: `y = ax³ + px`

**3단계 — 전단변환.** k = −p인 전단을 걸어 **일차항을 없앤다.**
결과: `y = ax³`

```
ax³+bx²+cx+d  --좌우이동-->  ax³+px+q  --위아래이동-->  ax³+px  --전단(k=−p)-->  ax³
     (일반형)                (감차형)                 (변곡점=원점)          (표준형)
```

세 단계에 쓴 변환은 **평행이동 2번 + 전단 1번**, **전부 넓이를 보존**한다. 그러므로:

> **모든 삼차함수는 넓이를 보존하는 변환으로 y = ax³와 이어져 있다.**
> 따라서 삼차함수의 **넓이 문제와 x좌표 관계**는 **y = ax³에서 계산한 결과를 그대로 가져다 써도 된다** [4][8].

이것이 "삼차함수가 다 비슷하게 생긴" 진짜 이유다. 겉보기 계수가 달라도 **넓이·x좌표의 세계에서는 전부 같은 곡선**이기 때문이다.

## 7. Worked Examples — 손으로 확인하기

**예 1) 전단은 정말 일차항만 바꾸는가**
f(x) = x³ − 4x 에 k = 4인 전단(y → y + 4x)을 걸면
`f(x) + 4x = x³ − 4x + 4x = x³`
S자였던 곡선이 **단조 증가하는 y = x³**가 됐다. **삼차항·이차항은 손도 대지 않았다.** 극점은 사라졌지만 변곡점(원점)은 그대로다.

**예 2) 변곡점은 정말 안 움직이는가**
f(x) = x³ + 6x² 의 변곡점: f″ = 6x + 12 = 0 → **x = −2**.
전단(k = 5)을 걸면 g = x³ + 6x² + 5x, g″ = 6x + 12 = 0 → **x = −2**. **동일하다.** 일차항은 두 번 미분하면 사라지므로 당연한 결과다.

**예 3) 극점은 정말 움직이는가**
f(x) = x³ − 3x 의 극점: f′ = 3x² − 3 = 0 → **x = ±1** (극점 2개).
k = 3 전단: g = x³ − 3x + 3x = x³, g′ = 3x² = 0 → **x = 0 하나뿐이고 극값도 아니다.** 극점이 **소멸**했다.
→ 극점을 묻는 문제에 전단을 함부로 쓰면 안 되는 이유다.

**예 4) 넓이는 정말 보존되는가**
곡선 y = x³ − 3x 와 직선 y = −2x 로 둘러싸인 부분을 생각하자. 차이는
`f − ℓ = (x³ − 3x) − (−2x) = x³ − x = x(x−1)(x+1)`
여기에 전단 k를 걸면 **곡선도 ℓ도 똑같이 kx가 더해지므로 차이는 그대로** x³ − x다. 넓이는 |f − ℓ|의 적분이므로 **전단과 무관하게 같다.** (이 "차 f − ℓ이 불변"이라는 사실이 확장편의 핵심 무기가 된다.)

**예 5) 표준화 실습**
f(x) = 2x³ + 6x² + 9x + 4 를 표준형으로.
- 변곡점: f″ = 12x + 12 = 0 → x = −1. 좌우로 +1 이동(x → x − 1 대입) 하면 이차항이 사라진다.
- 실제로 f(x−1) = 2(x−1)³ + 6(x−1)² + 9(x−1) + 4 = 2x³ + 3x − 1.
- 위아래로 +1 이동 → 2x³ + 3x. 전단 k = −3 → **2x³**.
→ 겉보기엔 복잡했지만 정체는 **y = 2x³**였다.

## 8. 흔한 오해·FAQ

**Q1. 전단변환은 그래프를 기울이는 건가요?**
정확히는 **각 점을 자기 x좌표에 비례해 위아래로 미는** 변환이다. x = 0인 점은 안 움직이고, x가 클수록 많이 밀린다. 그 결과 도형이 기울어져 보인다 [5].

**Q2. 왜 하필 넓이가 보존되죠?**
행렬식이 1이기 때문이다. **|행렬식| = 넓이 배율**이라는 사실이 먼저 있고, 전단행렬은 구조상 행렬식이 항상 1이 된다 [3][6][10].

**Q3. 모든 삼차함수가 y = ax³라면, 극값이 있는 것과 없는 것의 차이는 뭔가요?**
**전단으로 옮겨 다니는 도중의 서로 다른 모습**이다. 같은 y = ax³라도 k를 얼마나 되돌리느냐에 따라 S자가 되기도, 단조가 되기도 한다. 즉 **극값의 유무는 곡선의 본질이 아니라 "어떤 전단 상태에 있는가"**의 문제다 [4].

**Q4. 그럼 극값 문제는 이 관점이 쓸모없나요?**
아니다. 극값을 **"어떤 직선과 접하는 구도"**로 바꿔 읽으면 다시 전단 불변이 된다. 예컨대 "극댓값을 지나는 수평선"은 전단 후 기울어진 직선이 되지만, **곡선과 그 직선의 교점 x좌표는 그대로**다. 이 재해석이 확장편의 핵심이다.

**Q5. 이차함수에도 전단을 쓸 수 있나요?**
쓸 수는 있지만 **얻는 게 없다.** 이차함수는 평행이동만으로 이미 y = ax²가 되므로 전단이 할 일이 남지 않는다. 전단이 진짜 위력을 발휘하는 건 **삼차 이상**이다 [4].

**Q6. 사차함수는요?**
사차함수는 평행이동만 쓰면 **3개**(a, 이차항, 일차항)가 남고, 여기에 **전단으로 일차항까지** 지워도 **2개**(a, 이차항 p)가 끝까지 남는다. 삼차함수와 달리 **이차항은 전단으로 지울 수 없다.** 그래서 표준형이 `y = ax⁴ + px²` 꼴이고, 이 표준형은 **짝함수(y축 대칭)**다.
단, **원래 사차함수 자체가 좌우대칭이라는 뜻은 아니다.** 대칭이 되는 것은 전단으로 옮긴 뒤의 모습이고, 원래 좌표계에서는 **"어떤 직선을 기준으로 재면 대칭"**이라고 말해야 정확하다. 이 구분이 실전에서 중요한 이유는 확장편에서 다룬다 [9].

## 9. 한눈 요약

| 개념 | 내용 |
|---|---|
| 자유도 | 삼차는 계수 4개 − 평행이동 2 = **2개 남음**(a, 일차항) |
| 전단변환 | (x, y) → (x, y + kx), 그래프로는 **f → f + kx** |
| 전단행렬 | 대각선 1, 구석에 k → **det = 1** |
| 행렬식 의미 | **절댓값이 넓이 배율**. \|det\| = 1이면 넓이 보존 |
| 보존 ✅ | x좌표, 넓이, 직선, 이계도함수, **변곡점** |
| 보존 ❌ | 극점(이동·소멸), 기울기, y좌표, 길이·각도 |
| 표준화 | 평행이동 2번 + 전단 1번 → **y = ax³** |
| 결론 | 삼차함수의 **넓이·x좌표 관계 문제 = y = ax³ 문제** (절대 x좌표는 평행이동분만큼 밀린다) |

**마지막 한 줄** — 다항함수를 계수 네 개짜리 식으로 보면 경우의 수가 끝없지만, **넓이를 보존하는 변환의 눈**으로 보면 삼차함수는 **y = ax³ 하나**뿐이다. 문제를 풀 때 우리가 정말 다루는 대상은 늘 그 하나였다는 것 — 이 시선의 전환이 계산량을 근본에서 줄인다.

[^자유도]: 자유도(degree of freedom) — 어떤 대상을 정하기 위해 자유롭게 고를 수 있는 수의 개수. 다항함수에서는 계수의 개수가 자유도이며, 평행이동·전단 같은 변환으로 그중 몇 개를 '없앨' 수 있는지가 표준형을 정한다.
[^선형변환]: 선형변환(일차변환, linear transformation) — 벡터의 덧셈과 상수배를 보존하는 변환. 평면에서는 상수항 없는 일차식으로 표현되며, 항상 하나의 행렬에 대응된다.
[^행렬식]: 행렬식(determinant) — 정사각행렬에 하나의 수를 대응시키는 값. 역행렬 존재를 판정하며, 기하적으로는 **그 절댓값**이 변환의 넓이(부피) 배율을 뜻한다(부호는 방향이 뒤집혔는지를 나타낸다).
[^전단]: 전단변환(shear transformation) — 한 방향의 좌표는 그대로 두고 다른 좌표를 그에 비례해 미는 변환. (x, y) → (x, y + kx). 카드 뭉치를 옆으로 미는 모습과 같으며 넓이를 보존한다.
