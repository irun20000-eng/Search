# 함수·사상·매핑·변환·연산자·범함수 (이해편)

> "함수(function)", "사상(寫像)", "매핑(mapping)", "변환(transformation)", "연산자(operator)", "범함수(functional)" — 수학책을 넘기다 보면 **비슷해 보이는데 다르게 부르는** 이 말들에 걸려 넘어진다. 결론부터: **이들은 대부분 '같은 뿌리(대응)'에서 나온 형제들**이고, **분야·입출력·역사에 따라 옷을 갈아입었을 뿐**이다. 이 글은 각 용어를 **구체 예시로 구분**하고, **왜 굳이 다르게 부르는지**를 정리한다. 더 깊은 통합(범주론의 '사상')은 짝을 이루는 **[확장편]**에서 다룬다.

## TL;DR
- **공통 뿌리는 '대응(對應)'** 하나다. 집합 X의 각 원소에 집합 Y의 원소를 **하나씩 짝짓는 규칙** — 이게 **함수**[^함수]이자, 이름만 다른 나머지 용어들의 본질이다 [1][2].
- **함수(function)**: 가장 흔한 이름. 특히 **수 → 수**(실수→실수)의 대응에서 기본으로 쓴다. 예: f(x)=x² [1].
- **사상·매핑(map/mapping)**: **함수의 더 일반적인 이름.** 어원은 '지도 제작'(지구 표면 → 종이). 분야에 따라 **"구조를 보존하는 함수"**를 가리키기도 한다(위상=연속함수, 선형대수=선형사상) [3][4].
- **변환(transformation)**: 대개 **집합에서 자기 자신으로**(같은 공간) 가는 함수. 예: 회전·대칭 같은 기하변환, 선형변환 [3].
- **연산자(operator)·범함수(functional)**: 입력이 **함수나 벡터** 같은 '구조화된 대상'일 때 쓴다. **연산자**는 함수→함수(예: 미분 D), **범함수**는 함수→**수(스칼라)**(예: 정적분) [5].

## 핵심 포인트
1. **다 같은 '대응'** 이다 — 정의역[^정의역]의 각 원소에 공역[^공역]의 원소를 하나 짝짓는 규칙 [1][2].
2. **이름은 '무엇을 강조하느냐'로 갈린다** — 입출력의 종류, 분야, 보존하는 구조 [3][4].
3. **함수=수↔수, 사상=일반·구조보존, 변환=자기공간, 연산자=함수↔함수, 범함수=함수↔수** [3][5].
4. **어원·언어도 한몫** — map은 지도에서, function은 라이프니츠에서, 독일어 Abbildung=사상 [3].
5. **엄밀히는 상당수가 동의어** — 문맥이 뜻을 정한다. 겁먹을 필요 없다 [2].

## 1. 왜 헷갈리나 — 하나의 개념, 여러 이름

수학을 배우다 보면 같은 자리에서 서로 다른 단어가 튀어나온다. 고등학교에선 **함수**라고 배운 걸, 대학 선형대수에선 **선형변환** 또는 **선형사상**이라 부르고, 위상수학에선 **연속사상(연속함수)**, 미분방정식에선 **미분연산자**, 변분법에선 **범함수**라 한다. "다 다른 개념인가?" 싶어 주눅이 든다.

핵심을 먼저 못 박자.

> **이 용어들은 대부분 '같은 것(대응)'을 가리키며, 문맥이 어떤 구조·입출력을 강조하느냐에 따라 이름이 갈릴 뿐이다** [2][3].

실제로 국내 수학 사전조차 **'사상'을 "대응, 변환 또는 함수"** 와 사실상 동의어로 정의한다 [2]. 즉 이들은 **경쟁하는 개념이 아니라, 같은 개념의 여러 별명**에 가깝다. 아래에서 뿌리부터 하나씩 벗겨 본다.

## 2. 뿌리 하나 — '대응'이라는 공통 뼈대

모든 용어의 바닥에는 **대응(對應)**이 있다.

> **정의**: 집합 X의 **각 원소**에 집합 Y의 **원소를 하나씩** 짝지어 주는 규칙 f를, X에서 Y로의 **함수(사상)**라 한다. X를 **정의역**[^정의역], Y를 **공역**[^공역]이라 하고, x에 대응되는 y=f(x)를 x의 **상(image)**이라 한다 [1][2].

그림으로:
```
   X (정의역)            Y (공역)
     a  ─────────▶ ●
     b  ─────────▶ ●     ← 각 원소가 '빠짐없이·하나씩' 대응
     c  ─────────▶ ●
```
두 규칙만 지키면 된다 — **① X의 모든 원소가 짝을 가진다(빠짐없이)**, **② 한 원소는 짝이 하나뿐(오직 하나)**. 이 뼈대는 함수든 사상이든 변환이든 **완전히 동일**하다 [1][7]. 여러 대응을 **이어 붙이는 것(합성, f∘g)** 역시 어느 이름에서든 똑같이 작동한다 — g로 보낸 뒤 f로 다시 보내는 식이다 [6]. 앞으로 볼 모든 이름은 **"이 대응이 무엇에서 무엇으로 가고, 무엇을 보존하느냐"**를 덧붙인 것일 뿐이다.

## 3. 함수(function) — 가장 흔한 이름, 주로 수 → 수

**함수**는 이 대응의 **가장 대중적인 이름**이다. 특히 **수를 넣으면 수가 나오는**(실수→실수) 대응에서 기본으로 쓴다 [1].

- 예: **f(x) = x²** — 2를 넣으면 4, −3을 넣으면 9. 수 하나에 수 하나가 대응.
- 예: **삼각함수 sin, 로그함수 log, 지수함수 exp** — 모두 수→수.

'함수(函數)'라는 한자어는 **'상자(函)에 수(數)를 넣는다'**는 이미지로 흔히 설명된다 — 입력 수를 넣으면 출력 수가 튀어나오는 상자. 용어 자체는 라이프니츠가 곡선과 관련된 양을 부르며 도입했고, **함수가 무엇인지 엄밀히 정의하는 데만 수백 년**이 걸렸다(초기엔 '식으로 쓸 수 있는 것'에 가까웠다가, 지금의 '대응' 정의로 정착) [1].

> 정리: **함수 = 대응의 표준 이름, 특히 수↔수 맥락에서 기본값.**

## 4. 사상·매핑(map / mapping) — 함수의 일반형, 어원은 '지도'

**사상(寫像)**·**매핑(mapping)**은 **함수의 더 일반적인 이름**이다. 수뿐 아니라 **점·도형·함수·집합 등 무엇이든** 대응시킬 때 즐겨 쓴다 [3].

- **어원이 재밌다** — map은 **지도 제작**에서 왔다. **지구 표면(정의역)을 종이(공역)에 옮겨 그리는 것**이 곧 mapping이다. 각 지점을 종이 위 한 점에 대응시키니, 이보다 함수를 잘 보여주는 그림도 없다 [3].
- 한자어 **'사상(寫像)'** 은 **'상(像)을 옮겨 베낀다(寫)'** — 지도의 번역에 딱 맞는다. 독일어로도 사상은 **Abbildung**('본떠 그림')이다 [3].

중요한 뉘앙스 하나: 많은 분야에서 **map은 그냥 '함수'지만, 종종 "그 분야가 중시하는 구조를 보존하는 함수"**를 뜻한다 [3][4].
- **위상수학**에서 map = **연속함수**(위상 구조를 보존) [8]
- **선형대수**에서 (선형) map = **선형변환/선형사상**(덧셈·상수배를 보존)

즉 "map/사상"이라고 하면, 문맥에 따라 **"단순한 함수" 또는 "구조를 존중하는 함수"** 둘 다 될 수 있다. 이 "구조 보존"의 일반화가 바로 확장편의 **모피즘(morphism)**이다.

> 정리: **사상·매핑 = 함수의 일반형(무엇이든 대응). 종종 '구조 보존'의 뉘앙스가 붙는다.**

## 5. 변환(transformation) — 자기 자신으로 (같은 공간)

**변환**은 대개 **집합에서 자기 자신으로** 가는 함수를 가리킨다(정의역=공역) [3]. "바꾼다"는 어감처럼, **같은 공간 안에서 원소를 다른 위치로 옮기는** 그림이다.

- **기하변환**: 평면의 점을 평면의 점으로 — **회전·대칭(반사)·평행이동·확대**. 도형을 같은 평면 안에서 움직인다.
- **선형변환**: 벡터공간[^벡터]을 자기 자신으로 보내며 **덧셈·상수배를 보존**하는 함수. 행렬이 대표적. (단, 선형대수에선 V→W 일반도 '선형변환'이라 부르는 관습이 있어 문맥을 봐야 한다.)
- **좌표변환**: 같은 공간을 다른 좌표계로 다시 기술.

> 정리: **변환 = 주로 '같은 공간 안에서' 원소를 옮기는 함수(자기사상).** '움직임·바꿈'의 뉘앙스.

## 6. 연산자(operator)와 범함수(functional) — 입력이 '함수·벡터'일 때

여기서부터는 **입력 자체가 수가 아니라 함수나 벡터** 같은 **구조화된 대상**이다. 그래서 이름이 또 갈린다 [5].

**연산자(operator, 작용소)**: **함수를 넣으면 함수가 나오는** 대응(또는 벡터공간 V→V/W). "함수에 작용해 다른 함수를 만든다".
- **미분 연산자 D**: 함수 f를 넣으면 도함수 f′이 나온다. **D(x²) = 2x**. 입력도 함수, 출력도 함수.
- **적분 연산자**: 함수를 넣으면 (부정)적분 함수가 나온다.

**범함수(functional)**: **함수(또는 벡터)를 넣으면 '수(스칼라)'가 나오는** 특별한 연산자. 출력이 **하나의 수**다 [5].
- **정적분 ∫₀¹ f(x)dx**: 함수 f를 넣으면 **넓이라는 수 하나**가 나온다.
- **곡선의 길이·에너지**: 곡선(함수)을 넣으면 길이(수)가 나온다 → 변분법의 핵심.

수학적으로 정리하면 [5]:
- **선형연산자** = 벡터공간 V → 벡터공간(대개 V 자신 또는 W)
- **선형범함수** = 벡터공간 V → **스칼라 체**[^스칼라] (출력이 수)
- 둘 다 **선형사상(선형변환)의 특수한 경우**다.

> 정리: **연산자 = 함수→함수, 범함수 = 함수→수.** "입력이 구조화된 대상"일 때의 이름.

## 7. 한눈 정리표 — 입출력으로 구분

지금까지를 **"무엇에서 무엇으로 가는가"**로 한 줄에 세우면 명료하다 [1][3][5].

| 이름 | 전형적 입력 → 출력 | 대표 예시 | 강조점 |
|---|---|---|---|
| **함수(function)** | 수 → 수 | f(x)=x², sin x | 대중적 기본, 수↔수 |
| **사상·매핑(map)** | 집합 → 집합(무엇이든) | 지도, 선형사상, 연속사상 | 일반형·구조 보존 |
| **변환(transformation)** | 공간 → **같은 공간** | 회전, 대칭, 선형변환 | 자기 자신으로, '움직임' |
| **연산자(operator)** | 함수 → 함수 | 미분 D, 적분 | 입력이 함수 |
| **범함수(functional)** | 함수 → **수** | 정적분, 길이·에너지 | 출력이 스칼라 |
| **(준)동형·모피즘** | 구조 → 구조(보존) | 군준동형, 연속함수 | 구조 보존의 일반화(→확장편) |

**언어별 대조**도 알아두면 좋다: 영어 function / map / mapping / transformation / operator / functional, 독일어 **Abbildung**(사상)·Funktion(함수), 한국어 **함수·사상·매핑·변환·연산자(작용소)·범함수**. 같은 대상을 언어와 전통이 다르게 이름 붙인 것이다 [3].

## 8. 왜 다르게 부르나 — 여섯 가지 이유

이제 핵심 질문. **왜 굳이 다르게 부를까?** 이유는 크게 여섯이다 [2][3][4].

1. **입출력의 종류가 다르다.** 수↔수(함수), 함수↔함수(연산자), 함수↔수(범함수), 공간↔같은 공간(변환). **무엇을 넣고 무엇이 나오는지**가 이름을 가른다.
2. **분야마다 중시하는 '구조'가 다르다.** 위상은 **연속성**, 선형대수는 **선형성**, 군론은 **연산 보존**을 중시한다. 그래서 각 분야는 "그 구조를 보존하는 함수"에 고유 이름을 붙인다 — 연속사상, 선형변환, 준동형 [3][4].
3. **어원·역사가 다르다.** map은 **지도 제작**에서, function은 **라이프니츠**의 곡선 논의에서 왔다. 뿌리가 다르니 어감도 다르다 [1][3].
4. **강조하고 싶은 성질이 다르다.** '변환'은 **바꾼다·움직인다**는 능동적 어감을, '연산자'는 **작용한다**는 어감을 준다. 같은 대응이라도 화자가 강조점을 이름에 담는다.
5. **언어·번역 전통이 다르다.** 독일 전통의 Abbildung이 '사상'으로, 영미의 function이 '함수'로 들어와 **한 언어 안에 여러 계보가 공존**한다 [3].
6. **추상화 수준이 다르다.** 구체적 대응(함수) → 구조 보존(사상·준동형) → 범주론의 최상위 추상(**모피즘**). 위로 갈수록 이름이 더 일반적이 된다(→확장편) [3][4].

> 한마디로: **이름의 차이는 "이 대응에서 무엇이 중요한가"를 압축한 신호**다. 겁먹을 게 아니라, **이름만 봐도 맥락을 읽는 힌트**로 쓰면 된다.

## 9. 흔한 오해·FAQ

**Q1. 함수와 사상은 다른 건가요?**
본질은 **같다**(둘 다 '대응'). 관습적으로 **함수는 수↔수**에, **사상은 더 일반적인 대상(점·함수·집합)**이나 **구조 보존** 맥락에 즐겨 쓸 뿐이다. 국내 사전도 사상을 "대응·변환·함수"와 동의로 정의한다 [2].

**Q2. 변환은 함수의 무엇인가요?**
대개 **정의역=공역(같은 공간)**인 함수다. 회전·대칭처럼 **자기 자신으로** 보낸다. 단 선형대수에선 V→W도 '선형변환'이라 부르는 관습이 있어 문맥을 봐야 한다 [3].

**Q3. 연산자와 함수의 차이는?**
연산자는 보통 **입력이 함수(또는 벡터)**인 경우에 쓴다. 미분 D처럼 **함수를 넣어 함수를 얻는다.** 수↔수면 그냥 함수라 부른다 [5].

**Q4. 범함수는 왜 따로 부르나요?**
**출력이 '수 하나(스칼라)'**이기 때문이다. 함수를 넣어 넓이·길이·에너지 **같은 수**를 얻는 대응 — 정적분이 대표. 변분법·최적화의 핵심 도구라 이름이 필요했다 [5].

**Q5. 그럼 아무 이름이나 써도 되나요?**
문맥이 허용하면 상당수는 통용된다. 하지만 **관습을 따르는 게 소통에 유리**하다 — 위상에선 '연속사상/연속함수', 선형대수에선 '선형변환/선형사상', 변분법에선 '범함수'. **틀린 이름은 아니어도, 어색하면 오해를 부른다.**

## 10. 한눈 요약

| 질문 | 답 |
|---|---|
| 공통 뿌리는? | **대응** — 각 원소에 하나씩 짝짓기 |
| 함수는? | 대응의 표준 이름, 주로 수↔수 |
| 사상·매핑은? | 함수의 일반형(어원=지도), 종종 구조 보존 |
| 변환은? | 주로 같은 공간으로(자기사상), '움직임' |
| 연산자는? | 함수→함수 (예: 미분 D) |
| 범함수는? | 함수→수 (예: 정적분) |
| 왜 다르게? | 입출력·분야 구조·어원·강조·언어·추상화 수준 |

**마지막 한 줄** — 이 여러 이름은 수학을 어렵게 만드는 장애물이 아니라, **"이 대응에서 무엇이 중요한가"를 알려주는 이정표**다. 뿌리가 하나(대응)임을 알면, '사상'도 '연산자'도 '범함수'도 더 이상 낯선 외국어가 아니다. 그리고 이 모든 이름을 **하나의 관점('화살표')으로 통합**하는 현대수학의 언어 — **범주론의 사상(morphism)** — 은 짝을 이루는 **확장편**에서 이어진다.

[^함수]: 함수(function) — 정의역의 각 원소에 공역의 원소를 하나씩 대응시키는 규칙. '사상·매핑'과 본질적으로 같으며, 특히 수↔수 맥락에서 기본으로 쓴다.
[^정의역]: 정의역(domain) — 함수에 '넣을 수 있는' 입력들의 집합. f(x)=√x의 정의역은 x ≥ 0.
[^공역]: 공역(codomain) — 함수의 출력이 '속할 수 있는' 집합. 실제로 값이 닿는 부분집합은 치역(상, image)이라 한다.
[^벡터]: 벡터공간(vector space) — 덧셈과 상수배(스칼라배)가 정의된 공간. 화살표(벡터)들의 세계로, 선형대수의 무대다.
[^스칼라]: 스칼라·체(scalar/field) — 벡터에 곱하는 '수'. 실수 ℝ·복소수 ℂ처럼 사칙연산이 되는 수 체계를 체(field)라 한다.
