# 연속함수의 두 정리 (이해편)

> **"끊기지 않은 선을 그으면 중간값을 다 지나간다."** · **"닫힌 구간에서 끊기지 않은 함수는 가장 높은 점과 가장 낮은 점을 반드시 갖는다."** — 둘 다 너무 당연해서 증명할 것이 있나 싶다. 실제로 이 두 정리는 **연속함수의 당연한 성질로 오랫동안 그냥 쓰였다** [1]. 그런데 이것들은 **증명이 필요할 뿐 아니라, 그 증명이 실수 체계의 가장 깊은 성질에 닿아 있다.** 이 글은 두 정리가 **무엇을 보장하고 무엇을 보장하지 않는지**, 그리고 **조건 하나만 빼도 어떻게 무너지는지**를 반례로 확인한다. 증명 자체와 완비성 이야기는 짝을 이루는 **[확장편]**에서 다룬다.

## TL;DR
- **중간값 정리(IVT)**[^IVT] — `f`가 닫힌구간 `[a, b]`에서 연속이고 `f(a)`와 `f(b)` 사이에 값 `k`가 있으면, **`f(c) = k`인 `c`가 `[a, b]` 안에 존재한다** [11].
- 국내 교과서는 이를 **사잇값 정리**라 부른다. **중간값 정리와 같은 말**이다 [8].
- **최대·최소 정리(EVT)**[^EVT] — `f`가 **닫히고 유계인** 구간 `[a, b]`에서 연속이면, 그 구간에서 **최댓값과 최솟값을 반드시 갖는다** [1][12].
- **둘 다 "존재한다"만 말한다.** 어디에 있는지, 몇 개인지는 **말해 주지 않는다** — 이것이 존재정리의 성격이다.
- **EVT의 조건 셋(닫힘·유계·연속)은 하나도 뺄 수 없다.** 셋 중 하나만 빠져도 반례가 즉시 나온다(§5).
- **IVT의 실전 쓸모는 "근이 있다"를 보증하는 것**이다. `f(a) < 0 < f(b)`면 그 사이에 근이 있다 — 계산기의 **이분법**이 여기서 나온다.
- **역은 성립하지 않는다.** 중간값 성질을 가진다고 연속인 것은 아니다 — **도함수**가 그 반례다(§8, 확장편) [8].

## 핵심 포인트
1. **IVT = 값의 빈틈이 없다**(치역이 구간이 된다) [11].
2. **EVT = 봉우리와 골짜기가 실제로 존재한다**(상한이 도달된다) [1].
3. **닫힌구간**이 핵심 — 열린구간에서는 둘 다 무너질 수 있다 [12].
4. **존재정리는 위치를 알려 주지 않는다** — 찾는 것은 별개의 일(이분법·뉴턴법).
5. **EVT가 없으면 미분학이 서지 않는다** — 롤의 정리가 EVT 위에 서 있다 [6].
6. **유리수 세계에서는 둘 다 거짓이다** — 실수라서 성립한다(확장편).

## 1. 두 정리를 한 문장씩

먼저 정확한 진술부터.

> **중간값 정리(Intermediate Value Theorem).** 함수 `f`가 닫힌구간 `[a, b]`에서 **연속**이고, `k`가 `f(a)`와 `f(b)` 사이의 값이면, `f(c) = k`를 만족하는 `c`가 `[a, b]` 안에 **적어도 하나** 존재한다 [11].

> **최대·최소 정리(Extreme Value Theorem).** 함수 `f`가 닫힌구간 `[a, b]`에서 **연속**이면, `f`는 `[a, b]`에서 **최댓값과 최솟값을 갖는다** [1][12].

두 정리의 성격이 다르다는 점을 먼저 잡아 두자.

| | 중간값 정리 | 최대·최소 정리 |
|---|---|---|
| 보장하는 것 | **값의 빈틈 없음** — 사이의 모든 값을 취한다 | **극단값의 존재** — 최고점·최저점이 실제로 있다 |
| 그림으로 | 가로선을 그으면 **반드시 만난다** | 그래프에 **꼭대기와 바닥이 있다** |
| 쓰이는 곳 | 근의 존재, 이분법, 고정점 | 최적화, 롤의 정리 → 평균값 정리 |
| 필요한 조건 | 닫힌구간 + 연속 | 닫힌구간 + **유계** + 연속 |

## 2. 왜 당연해 보이는 것을 증명하나

국내 백과도 이 두 정리를 두고 **"연속함수의 당연한 성질로 오랫동안 다루어져 왔다"**고 적는다 [1]. 그림을 그려 보면 반박할 여지가 없어 보인다. 그런데 증명이 필요한 이유가 있다.

### 2-1. "그림이 그렇게 보인다"는 증명이 아니다
연속함수 중에는 **그림으로 그릴 수 없는 것**이 수두룩하다. 예를 들어 어디에서도 미분되지 않는 연속함수가 존재하는데, 그런 함수의 그래프는 **손으로 그릴 수가 없다.** 손그림에서 얻은 직관을 그런 함수에까지 적용해도 되는지는 **따로 확인해야 한다.**

### 2-2. 결정적인 이유 — 유리수에서는 거짓이다
이것이 핵심이다. 다음 함수를 보자.

```
   f(x) = x² − 2       (x 는 0 ≤ x ≤ 2 인 유리수만)
```

- `f(0) = −2 < 0`, `f(2) = 2 > 0` — **부호가 바뀐다.**
- `f`는 다항식이므로 **연속이다.**
- 그런데 `f(c) = 0`인 유리수 `c`는 **없다.** `√2`가 유리수가 아니기 때문이다.

**유리수만 있는 세계에서 중간값 정리는 거짓이다.** 그림은 똑같이 "이어져" 보이는데도.

> 🔑 그러므로 IVT·EVT는 **연속성만으로 성립하는 것이 아니라, 실수라는 무대가 빈틈없이 채워져 있어야 성립한다.** 그 "빈틈없음"이 **실수의 완비성**[^완비성]이며 [3], 두 정리의 증명은 결국 거기서 나온다(확장편).

## 3. 중간값 정리 — 무엇을 보장하나

### 3-1. 그림으로
```
   f(b) ┤                    ●
        │                 ╱
      k ┼ ─ ─ ─ ─ ─ ─ ╳ ─ ─ ─ ─   ← 이 가로선을 반드시 만난다
        │        ╱  ↑
   f(a) ┤  ●            c 가 여기 어딘가에 있다
        └───┬─────────┬────
            a         b
```

`f(a)` 아래에서 시작해 `f(b)` 위로 끝났다면, **중간 높이 `k`를 건너뛸 수 없다.** 건너뛰려면 어딘가에서 **점프**해야 하는데, 연속이라는 가정이 그것을 금지한다.

### 3-2. 가장 많이 쓰는 형태 — 근의 존재
`k = 0`인 특수한 경우가 실전에서 가장 많이 쓰인다. 이 형태를 **볼차노 정리**라고 부르기도 한다 [13].

> `f`가 `[a, b]`에서 연속이고 **`f(a)`와 `f(b)`의 부호가 다르면**, `(a, b)` 안에 **`f(c) = 0`인 `c`가 존재한다.**

### 3-3. 무엇을 보장하지 **않는가**
여기가 오해가 잦은 지점이다.

| 오해 | 사실 |
|---|---|
| "근이 **하나** 있다" | **적어도 하나**다. 여러 개일 수 있다 |
| "근이 어디 있는지 알려 준다" | **위치는 전혀 모른다** |
| "부호가 안 바뀌면 근이 없다" | **아니다.** `f(x) = x²`는 `[−1, 1]`에서 부호가 안 바뀌지만 근이 있다 |
| "근을 구하는 방법이다" | **존재만 말한다.** 구하는 것은 이분법·뉴턴법의 일 |

## 4. 최대·최소 정리 — 무엇을 보장하나

### 4-1. 그림으로
```
        │      ●최댓값
        │    ╱   ╲
        │  ╱       ╲
        │╱           ╲___
        │                 ●최솟값
        └───┬─────────────┬──
            a             b
        ← 닫힌구간: 양 끝점이 포함된다 →
```

**핵심은 "도달한다"는 것**이다. 함숫값이 아무리 커져도 **상한에 도달하지 못할 수 있는데**(§5), 닫힌구간에서 연속이면 **상한이 실제 함숫값으로 실현된다** [1][7].

### 4-2. 왜 이게 중요한가 — 미분학이 여기 얹혀 있다
`[a, b]`에서 연속이고 `f(a) = f(b)`인 함수를 생각하자. **롤의 정리**는 이때 `f′(c) = 0`인 점이 있다고 말한다 [6].

그 증명의 첫 줄이 이것이다.

```
   EVT → [a,b] 에서 최댓값·최솟값이 존재한다
        → 그 극값이 구간 내부에 있으면 거기서 접선이 수평이다
        → f′(c) = 0
```

즉 **롤 → 평균값 정리 → 코시 평균값 정리 → 로피탈**로 이어지는 미분학의 사슬 전체가 **EVT를 첫 벽돌로 삼는다.** 갤러리의 **평균값 정리(`mean-value-theorem`)** 보고서가 "닫힌구간 연속 → 최댓값·최솟값 존재에 기대고 있다"고 적어 둔 그 대목이 바로 이 정리다.

## 5. 조건 셋 중 하나만 빼면 — 반례 갤러리

EVT의 조건은 **① 닫힘 ② 유계 ③ 연속** 셋이다. **하나만 빼도 즉시 무너진다.** 이 표가 이 글에서 가장 중요하다.

| 빠진 조건 | 반례 | 무슨 일이 생기나 |
|---|---|---|
| **닫힘** ✕ | `f(x) = 1/x` on `(0, 1]` | `x → 0⁺`에서 **무한대로 발산** — 최댓값 없음 |
| **닫힘** ✕ (유계인데도) | `f(x) = x` on `[0, 1)` | 위로 `1`에 다가가지만 **`1`에 도달 못 함** — 최댓값 없음 |
| **유계** ✕ | `f(x) = x` on `[0, ∞)` | 끝없이 커짐 — 최댓값 없음 |
| **연속** ✕ | `f(x) = x` (`0 ≤ x < 1`), `f(1) = 0` | 값은 `1`에 다가가나 **끝에서 뚝 떨어짐** — 최댓값 없음 |

두 번째 줄이 특히 교훈적이다.

```
   f(x) = x  on  [0, 1)

   1 ┤ ─ ─ ─ ─ ─ ─ ○   ← 이 점이 없다
     │          ╱
     │       ╱
   0 ┤ ●
     └──┬────────┬──
        0        1

   상한(sup) = 1  ✓ 존재한다
   최댓값(max)    ✗ 존재하지 않는다
```

**"위로 유계"와 "최댓값이 있다"는 다른 말이다.** 상한은 늘 존재하지만(완비성), **도달은 별개의 사건**이다. EVT가 실제로 주장하는 것은 **"닫힌구간 + 연속이면 상한이 도달된다"**는 것이며, 여기가 이 정리의 알맹이다.

### 5-1. IVT 쪽 반례 — 연속을 빼면
```
   f(x) = −1  (−1 ≤ x < 0)
           1  ( 0 ≤ x ≤ 1)

    1 ┤        ●━━━━━
      │
    0 ┼ ─ ─ ─ ─ ─ ─ ─ ─   ← 이 높이를 절대 취하지 않는다
      │
   −1 ┤━━━━━○
      └──┬───┬───┬──
        −1   0   1
```

`f(−1) = −1`, `f(1) = 1`인데 **`f(c) = 0`인 `c`가 없다.** 점프 한 번이 중간값 정리를 통째로 무너뜨린다.

## 6. Worked Example — 실제로 써 보기

### 예 1) 근이 존재함을 보이기
**문제**: `x³ − x − 1 = 0`이 실근을 가짐을 보여라.

`f(x) = x³ − x − 1`은 다항식이므로 **모든 실수에서 연속**이다 [2].

```
   f(1) = 1 − 1 − 1 = −1  < 0
   f(2) = 8 − 2 − 1 =  5  > 0
```

`f`는 `[1, 2]`에서 연속이고 `f(1) < 0 < f(2)`이므로, **중간값 정리에 의해 `f(c) = 0`인 `c`가 `(1, 2)`에 존재한다.** ∎

> 우리는 `c`를 **구하지 않았다.** 그런데도 **있다는 것은 증명했다.** 이것이 존재정리의 힘이자 한계다.

### 예 2) 이분법 — 존재를 위치로 바꾸기
IVT는 위치를 안 알려 주지만, **반복 적용하면 위치를 좁힐 수 있다.** 위 문제를 이어 가자.

```
   [1, 2]        중점 1.5 : f(1.5) = 3.375 − 1.5 − 1 =  0.875 > 0 → [1, 1.5]
   [1, 1.5]      중점 1.25: f(1.25)= 1.953 − 1.25 − 1 = −0.297 < 0 → [1.25, 1.5]
   [1.25, 1.5]   중점 1.375: f(1.375)=2.598−1.375−1 =  0.223 > 0 → [1.25, 1.375]
   [1.25, 1.375] 중점 1.3125: f ≈ −0.051 < 0            → [1.3125, 1.375]
```

**한 번에 구간이 절반씩 줄어든다.** `n`번 반복하면 오차가 `(b−a)/2ⁿ` 이하다. 10번이면 약 `1/1024`, 20번이면 약 `1/1,000,000`.

**매 단계마다 IVT가 "이 구간 안에 근이 있다"를 보증**해 주기 때문에 이 절차가 성립한다. 계산기와 컴퓨터가 방정식을 푸는 가장 기본적인 방법이다.

### 예 3) 고정점 — 반드시 제자리인 점이 있다
**문제**: `f`가 `[0, 1]`에서 연속이고 `0 ≤ f(x) ≤ 1`이면, `f(c) = c`인 `c`가 존재함을 보여라.

`g(x) = f(x) − x`로 두자. `g`도 연속이다 [2].

```
   g(0) = f(0) − 0 = f(0) ≥ 0
   g(1) = f(1) − 1 ≤ 0        (∵ f(1) ≤ 1)
```

`g(0) ≥ 0`이고 `g(1) ≤ 0`이므로, 중간값 정리에 의해 `g(c) = 0`인 `c`가 있다. 즉 **`f(c) = c`.** ∎

이것이 **고정점 정리**의 가장 단순한 형태이며 [9], 브라우어르 고정점 정리의 1차원 판이다.

> 💡 재미있는 해석: 어떤 지도를 **같은 나라 안에서** 아무리 구겨 놓아도, **원래 자리와 정확히 겹치는 점이 반드시 하나 있다.**

### 예 4) EVT — 최적화가 성립하는 근거
**문제**: `[0, 4]`에서 `f(x) = x³ − 6x² + 9x`의 최댓값을 구하라.

여기서 **EVT가 하는 일**을 정확히 보자.

1. `f`는 다항식 → `[0, 4]`에서 연속. **EVT가 "최댓값이 존재한다"를 보장한다.**
2. **존재가 보장되었으므로**, 후보를 다 조사해 가장 큰 것을 고르면 그것이 답이다.
3. 후보 = **임계점**(`f′ = 0`) + **끝점** [10].

```
   f′(x) = 3x² − 12x + 9 = 3(x−1)(x−3)  →  임계점 x = 1, 3
   f(0) = 0
   f(1) = 1 − 6 + 9  = 4
   f(3) = 27 − 54 + 27 = 0
   f(4) = 64 − 96 + 36 = 4
```

**최댓값 4** (`x = 1`과 `x = 4`에서 도달), 최솟값 0 (`x = 0`과 `x = 3`).

> 📌 **2번 단계가 EVT 없이는 성립하지 않는다.** "후보 중 최대"가 곧 "전체 최대"가 되려면, **최대가 존재한다는 것이 먼저 보장**되어야 한다. 존재하지 않는 것의 후보를 비교하는 일은 의미가 없다. 열린구간에서 이 절차를 그대로 쓰면 틀리는 이유가 이것이다.

|---|---|
| **수치해석** | 이분법 — 근의 존재를 IVT로 보증하고 구간을 반씩 줄인다 |
| **미분학** | 롤 → 평균값 정리의 첫 벽돌이 EVT [6] |
| **최적화** | "최적해가 존재한다"를 EVT가 보장(닫히고 유계인 영역) |
| **경제학** | 균형의 존재 증명 — 고정점 정리 계열 [9] |
| **일상 논증** | "어제는 A, 오늘은 B니까 그 사이 어느 순간 C였다" — 연속성 가정이 숨어 있다 |

> ⚠️ 마지막 줄에 함정이 있다. **"그 사이 어느 순간 C였다"는 대상이 연속적으로 변할 때만 참이다.** 사람 수, 계단식 요금처럼 **뛰는 양**에는 적용할 수 없다.

## 8. 자주 나오는 질문

**Q1. 사잇값 정리와 중간값 정리는 다른 건가요?**
**같은 정리**다. 국내 교과서는 주로 **사잇값 정리**, 대학 교재나 번역서는 **중간값 정리**를 쓴다. 영어로는 둘 다 Intermediate Value Theorem [8][11].

**Q2. 근이 몇 개인지도 알 수 있나요?**
**아니다.** IVT는 **적어도 하나**만 말한다. 개수를 알려면 도함수로 증가·감소를 따지는 등 **추가 도구**가 필요하다.

**Q3. 열린구간 `(a, b)`에서는 왜 안 되나요?**
IVT는 **열린구간에서도 성립한다**(두 점 사이 값을 다룰 뿐이므로). 문제는 **EVT**다. 끝점이 없으면 상한에 다가가기만 하고 **도달하지 못할 수 있다** — §5의 `f(x) = x` on `[0, 1)`가 그 예다.

**Q4. 중간값 성질을 가지면 연속인가요?**
**아니다.** 유명한 반례가 **도함수**다. 미분가능한 함수의 도함수는 **연속이 아닐 수 있는데도 중간값 성질을 반드시 가진다** — 이것이 **다르부 정리**다 [8]. 즉 **"중간값 성질 ⇒ 연속"은 거짓**이다.

**Q5. 최댓값과 극댓값은 다른가요?**
다르다. **극댓값**은 주변보다 큰 값(국소), **최댓값**은 구간 전체에서 가장 큰 값(전역)이다. §6 예 4에서 `x = 3`은 극솟값이지만 최솟값이기도 하고, `x = 4`는 극점이 아니지만(끝점) 최댓값이다. **그래서 후보에 끝점을 반드시 넣어야 한다** [10].

**Q6. 왜 하필 "닫힌구간"인가요?**
닫힌구간 `[a, b]`는 **닫혀 있고 유계**라는 두 성질을 함께 갖는다. 이 조합을 현대 수학에서는 **컴팩트**라 부르며, EVT가 성립하는 진짜 이유가 그것이다(확장편) [12].

## 9. 한눈 요약

| | 중간값 정리 (IVT) | 최대·최소 정리 (EVT) |
|---|---|---|
| 진술 | 사이의 값을 반드시 취한다 | 최댓값·최솟값이 반드시 존재한다 |
| 필요 조건 | 닫힌구간에서 연속 | 닫히고 **유계**인 구간에서 연속 |
| 결론의 성격 | **존재** (위치·개수 모름) | **존재** (위치 모름) |
| 대표 응용 | 근의 존재, 이분법, 고정점 | 최적화, 롤의 정리 |
| 조건을 빼면 | 점프 한 번에 무너짐 | 셋 중 하나만 빠져도 무너짐 |
| 유리수에서 | **거짓** | **거짓** |
| 뿌리 | 실수의 완비성 [3] | 실수의 완비성 [3] |

**마지막 한 줄** — 이 두 정리가 가르치는 것은 **"당연해 보이는 것일수록 무엇에 기대고 있는지 물어야 한다"**는 것이다. 끊기지 않은 선이 중간값을 지나간다는 사실은 그림에서는 자명하지만, 그 자명함은 **실수가 빈틈없이 채워져 있다는 사실**에 통째로 의존하고 있었다. 유리수만 있는 세계로 옮겨 놓는 순간 같은 그림이 거짓이 된다. **직관이 옳았던 것이 아니라, 우리가 서 있던 무대가 좋았던 것이다.**

[^IVT]: 중간값 정리(Intermediate Value Theorem, IVT) — 닫힌구간에서 연속인 함수는 두 끝점의 함숫값 사이에 있는 모든 값을 구간 안 어딘가에서 실제로 취한다는 정리. 국내 교과서의 '사잇값 정리'와 같은 말이다. 값의 존재만 말할 뿐 위치나 개수는 말하지 않는다.
[^EVT]: 최대·최소 정리(Extreme Value Theorem, EVT) — 닫히고 유계인 구간에서 연속인 함수는 그 구간에서 최댓값과 최솟값을 반드시 갖는다는 정리. '극값 정리'라고도 한다. 핵심은 상한의 존재가 아니라 상한이 실제 함숫값으로 **도달된다**는 데 있다.
[^완비성]: 실수의 완비성(completeness) — 위로 유계이고 공집합이 아닌 실수 집합은 반드시 최소상계(상한)를 갖는다는 성질. 실수와 유리수를 가르는 결정적 차이이며, 극한에 관한 논의를 가능하게 하는 바탕이다. IVT와 EVT는 모두 이 성질에서 유도된다.
