# 테일러 정리 (확장편)

> 이해편은 급수를 **만드는 법**과 그것이 잘 맞는다는 **관찰**까지 왔다. 확장편의 질문은 둘이다 — **얼마나 잘 맞는지를 어떻게 보증하는가**, 그리고 **언제 보증이 깨지는가.** 앞은 잉여항이 답한다. 뒤는 세 단계로 무너진다: 급수가 **발산**할 수 있고(수렴반경), 수렴해도 **원래 함수가 아닐** 수 있으며(`e^(−1/x²)`), 심지어 **계수를 아무렇게나 지정해도 그런 함수가 존재한다**(보렐 정리) [11]. 마지막 사실은 테일러 계수가 매끄러운 함수를 거의 결정하지 못한다는 뜻이다. 그리고 이 균열은 **복소수로 넘어가면 통째로 사라진다.**

## TL;DR

- **테일러 정리**는 `f(x) = pₙ(x) + Rₙ(x)` 에서 **잉여항 `Rₙ` 을 구체적으로 써 주는** 정리다. 형태가 넷이고 가정이 각각 다르다 [3][8].
- **라그랑주형** `Rₙ = f⁽ⁿ⁺¹⁾(c)/(n+1)! · (x−a)ⁿ⁺¹` 이 가장 널리 쓰인다 [3]. `n = 0` 이면 **정확히 평균값 정리**다 [5][8].
- **라그랑주 한계는 생각보다 빡빡하다** — `sin(0.5)` 에서 `n` 을 제대로 고르면 한계가 실제 오차의 **1.01배**다(§4). 잘못 고르면 14배까지 헐거워진다.
- **수렴반경은 실수축을 봐서는 설명되지 않는다.** `1/(1+x²)` 는 모든 실수에서 매끄럽고 유계인데 매클로린 급수의 수렴반경이 1이다 — 범인은 복소평면의 `±i` 다 [7].
- **`e^(−1/x²)` 는 무한히 미분가능하고 모든 계수가 0이라 급수가 항등 0**, 수렴반경 `+∞` 인데 함수는 0이 아니다 [1][10]. 실해석에서 **무한 미분가능성은 해석성을 함축하지 않는다** [7].
- **보렐 정리**: 아무 수열이나 가져와도 그것을 0에서의 도함수열로 갖는 매끄러운 함수가 존재한다 [10][11]. **계수는 함수를 결정하지 못한다.**

## 핵심 포인트

1. **잉여항의 네 형태는 강함의 사다리다.** 페아노는 가정이 가장 약하고 정보가 가장 적으며, 적분형은 가정이 가장 세고 정보가 가장 많다 [8].
2. **테일러 정리는 평균값 정리를 고차로 밀어 올린 것이다** [5][8]. 그래서 증명도 평균값 정리 계열에서 나온다.
3. **"수렴한다"와 "원래 함수로 수렴한다"는 완전히 다른 두 진술이다** [1]. 이해편의 다섯 예가 둘 다 만족한 것은 확인된 사실이지 자동이 아니다.
4. **해석적이 아닌 매끄러운 함수는 병리적 예외가 아니라 압도적 다수다.** 보렐 정리가 그것을 정량화한다 [11].
5. **복소해석으로 넘어가면 이 모든 균열이 닫힌다.** 근방에서 복소미분가능하면 그것만으로 무한 번 미분가능하고 자기 테일러 급수와 국소적으로 같아진다 [14] — 실수의 "미분가능"이 얼마나 약한 조건인지가 여기서 드러난다.

## 1. 직관 압축

이해편의 결론을 한 문단으로. 요구 조건 "`x = a` 에서 함숫값과 n계까지의 도함수값을 전부 맞춘다"를 `p(x) = Σcₖ(x−a)ᵏ` 에 강제하면, `(x−a)ⁿ` 을 n번 미분할 때 나오는 `n!` 때문에 `p⁽ⁿ⁾(a) = n!cₙ` 이 되고, 따라서 `cₙ = f⁽ⁿ⁾(a)/n!` 이 **선택이 아니라 유일한 답**이 된다 [1][2]. 이 다항식은 오차 관점에서도 최적이다 — 테일러 다항식은 같은 차수에서 **점근적으로 가장 잘 맞는(asymptotic best fit)** 유일한 다항식이다 [8].

여기서부터는 **오차를 재는 일**이다.

## 2. 테일러 정리 — 잉여항 네 형태

`Rₙ(x) = f(x) − pₙ(x)` 라 두자. 이 `Rₙ` 을 어떻게 쓰느냐에 따라 정리가 넷으로 갈린다 [8].

| 형태 | 잉여항 | 가정 | 무엇을 주나 |
|---|---|---|---|
| **페아노** | `hₙ(x)(x−a)ⁿ`, `hₙ(x) → 0` | `f` 가 `a` 에서 **n번 미분가능**(그 점에서만) | 크기는 모르고 **차수만** — 극한 계산용 |
| **라그랑주** | `f⁽ⁿ⁺¹⁾(c)/(n+1)! · (x−a)ⁿ⁺¹` | `a`와 `x` 사이 열린구간에서 `n+1`번 미분가능, `f⁽ⁿ⁾` 이 닫힌구간에서 연속 | **구체적 상한** — 오차 보증서 |
| **코시** | `f⁽ⁿ⁺¹⁾(c)/n! · (x−c)ⁿ(x−a)` | 라그랑주와 같음 | 라그랑주가 안 먹히는 자리(예: 이항급수) |
| **적분형** | `∫ₐˣ f⁽ⁿ⁺¹⁾(t)(x−t)ⁿ/n! dt` | `f⁽ⁿ⁾` 이 닫힌구간에서 **절대연속**[^절대연속] | `c` 라는 미지수가 없다 — 가장 정직하다 |

**국내 수학백과가 싣는 것은 라그랑주형이다** [3].

> 원점 0을 포함하는 열린 구간에서 정의된 `(n+1)`번 미분가능한 함수 `y = f(x)` 와 구간 위의 임의의 점 `x` 에 대하여
> `f(x) = f(0) + f′(0)x + f″(0)/2!·x² + ⋯ + f⁽ⁿ⁾(0)/n!·xⁿ + f⁽ⁿ⁺¹⁾(c)/(n+1)!·xⁿ⁺¹`
> 을 만족하는 `c` 가 0과 `x` 사이에 존재한다 [3].

**네 형태를 강함의 사다리로 읽어야 한다.**

```
   가정 약함 ─────────────────────────────▶ 가정 셈
   정보 적음 ─────────────────────────────▶ 정보 많음

   페아노          라그랑주 / 코시            적분형
   (한 점에서       (구간에서 n+1번           (f⁽ⁿ⁾ 절대연속)
    n번 미분)        미분, f⁽ⁿ⁾ 연속)

   "오차는 (x−a)ⁿ    "오차 = 어떤 c 에서의     "오차 = 이 적분값"
    보다 작은 차수"    도함수값 × 상수"          (c 없음)
```

**페아노형이 왜 유용한가.** 가정이 `a` **한 점에서만** n번 미분가능이면 된다 [8]. 그래서 로피탈이 안 통하는 극한을 뚫을 때 쓴다 — 크기를 몰라도 차수만 알면 되는 자리다. [[로피탈 정리]] 확장편이 다루는 기법이 이것이다.

## 3. 왜 그런가 (유도 1) — 평균값 정리의 고차 일반화

라그랑주형에서 `n = 0` 을 넣어 보자.

```
n = 0 :   f(x) = f(a) + f′(c)(x − a)
```

**이것이 평균값 정리다** [5]. 양변을 정리하면 `(f(x) − f(a))/(x − a) = f′(c)` — 할선의 기울기와 같은 접선이 사이에 있다는 바로 그 문장이다.

그러니까 **테일러 정리는 평균값 정리를 고차로 밀어 올린 것**이고 [5][8], 증명도 같은 계열에서 나온다.

**증명 스케치(코시 평균값 정리 경유).** 보조함수를 잡는다.

```
g(t) = f(x) − [ f(t) + f′(t)(x−t) + ⋯ + f⁽ⁿ⁾(t)/n! · (x−t)ⁿ ]
h(t) = (x − t)ⁿ⁺¹
```

**1단계.** `g(x) = 0` 이고 `g(a) = Rₙ(x)` 다. 정의를 그대로 쓴 것이다.

**2단계 — 여기가 요점이다.** `g(t)` 를 `t` 로 미분하면 **망원경처럼 거의 전부 상쇄된다.** 곱의 미분법으로 각 항이 앞 항의 미분을 지우고, 마지막 하나만 살아남는다.

```
g′(t) = − f⁽ⁿ⁺¹⁾(t)/n! · (x − t)ⁿ
```

**3단계.** `h′(t) = −(n+1)(x−t)ⁿ` 이므로 [[코시 평균값 정리]]를 `g, h` 에 적용하면 `a`와 `x` 사이의 어떤 `c` 에서

```
 g(x) − g(a)     g′(c)        − f⁽ⁿ⁺¹⁾(c)/n! · (x−c)ⁿ       f⁽ⁿ⁺¹⁾(c)
───────────── = ────── = ──────────────────────────── = ───────────
 h(x) − h(a)     h′(c)        − (n+1)(x−c)ⁿ               (n+1)!
```

**4단계.** 좌변은 `(0 − Rₙ(x)) / (0 − (x−a)ⁿ⁺¹) = Rₙ(x)/(x−a)ⁿ⁺¹` 이다. 정리하면

```
Rₙ(x) = f⁽ⁿ⁺¹⁾(c)/(n+1)! · (x − a)ⁿ⁺¹     ∎
```

**2단계의 상쇄가 이 증명의 전부다.** `h(t)` 를 다른 것으로 고르면 코시형이 나온다 — 잉여항의 형태가 여럿인 이유가 바로 여기, **보조함수 선택의 자유**에 있다.

## 4. Worked 1 — 라그랑주 한계는 얼마나 빡빡한가

보증서는 실제 오차보다 커야 쓸모가 있지만, **너무 크면 무의미하다.** 실제로 재 보자.

`sin x`, `a = 0`, `x = 0.5`. 모든 계수의 도함수가 `|f⁽ⁿ⁺¹⁾| ≤ 1` 이므로 라그랑주 한계는 `|Rₙ| ≤ 0.5ⁿ⁺¹/(n+1)!` 이다. 참값은 `sin(0.5) = 0.4794255386…`.

| n | `pₙ(0.5)` | 실제 오차 | 라그랑주 한계 | 한계 ÷ 실제 |
|---|---|---|---|---|
| 1 | 0.5000000000 | 2.0574 × 10⁻² | 1.2500 × 10⁻¹ | **6.08배** |
| 2 | 0.5000000000 | 2.0574 × 10⁻² | 2.0833 × 10⁻² | **1.01배** |
| 3 | 0.4791666667 | 2.5887 × 10⁻⁴ | 2.6042 × 10⁻³ | **10.06배** |
| 4 | 0.4791666667 | 2.5887 × 10⁻⁴ | 2.6042 × 10⁻⁴ | **1.01배** |
| 5 | 0.4794270833 | 1.5447 × 10⁻⁶ | 2.1701 × 10⁻⁵ | **14.05배** |
| 6 | 0.4794270833 | 1.5447 × 10⁻⁶ | 1.5501 × 10⁻⁶ | **1.00배** |

**패턴이 선명하다.** 짝수 `n` 에서는 한계가 실제 오차의 **1.00~1.01배**로 거의 정확하고, 홀수 `n` 에서는 6~14배로 헐거워진다. 그리고 그 헐거움이 `n` 이 커질수록 **더 나빠진다**.

**왜인가.** `sin` 은 기함수라 짝수차 계수가 전부 0이다. 그래서 `p₁ = p₂`, `p₃ = p₄`, `p₅ = p₆` 로 **다항식이 같다.** 그런데 한계식 `0.5ⁿ⁺¹/(n+1)!` 은 `n` 에만 의존하므로, **같은 다항식에 대해 `n` 을 하나 올려 잡으면 한계가 확 좁아진다.**

**실무 규칙이 여기서 나온다.** 오차 한계를 계산할 때는 `n` 을 **"계수가 0이 아닌 마지막 차수"가 아니라 "다음 0이 아닌 항 직전까지"** 로 잡아야 한다. 같은 다항식 `p₅ = p₆` 에 대해 `n = 5` 로 잡으면 한계가 `2.17 × 10⁻⁵`, `n = 6` 으로 잡으면 `1.55 × 10⁻⁶` — **한 끗 차이로 보증서가 정확히 14배 좁아진다.**

## 5. 수렴반경의 진짜 이유는 복소평면에 있다

이해편 §7은 `ln(1+x)` 와 `1/(1+x)` 의 수렴반경이 1인 이유를 "`x = −1` 에서 함수가 터진다"로 설명했다. **눈에 보이는 이유였다.** 그런데 눈에 안 보이는 경우가 있다.

```
              1
   f(x) = ─────────
            1 + x²
```

이 함수는 **모든 실수에서 정의되고 매끄럽고, 값이 항상 `(0, 1]` 안에 있다.** 터지는 곳이 없다. 그런데 매클로린 급수는

```
   1/(1+x²) = 1 − x² + x⁴ − x⁶ + ⋯
```

이고 **수렴반경이 1이다** [7]. 등비급수라 `|x| < 1` 에서만 수렴한다.

**위키백과가 범인을 지목한다** — "대응하는 복소함수가 `x = i` 와 `x = −i` 에서 특이점을 갖기 때문" [7].

```
        복소평면

              i ●  ← 여기서 분모가 0
              │
     ─────────┼─────────  실수축
              │
             −i ●  ← 여기서도

        원점에서 두 특이점까지의 거리 = 1
        → 수렴반경 = 1
```

**멱급수의 수렴반경은 중심에서 가장 가까운 특이점까지의 거리다.** 실수축만 보면 아무 일도 없지만, 급수는 복소평면 전체의 사정을 알고 있다. 실직선 위를 걷는 사람이 **보이지 않는 곳의 지형 때문에 걸음이 막히는 것**이다.

**이 사실이 주는 교훈**: 실해석에서 설명되지 않는 현상이 복소해석에서 한 줄로 설명되는 일이 흔하다. 수렴반경이 그 대표 사례다.

## 6. Worked 2 — 급수가 발산하는 것을 눈으로 본다

숫자로 확인하면 실감이 다르다. `1/(1+x²)` 의 부분합을 항 개수별로 계산했다.

| `x` | 참값 | 6항까지 | 11항까지 | 21항까지 |
|---|---|---|---|---|
| 0.5 | 0.80000000 | 0.7998 | 0.8000 | 0.8000 |
| 0.9 | 0.55248619 | 0.3964 | 0.6069 | 0.5591 |
| 1.0 | 0.50000000 | 0 | 1 | 1 |
| **1.5** | **0.30769231** | **−39.61** | **2302** | **7.655 × 10⁶** |

**세 가지가 보인다.**

- `x = 0.5` 는 빠르게 수렴한다.
- `x = 0.9` 는 **경계 근처라 느리게, 진동하며** 수렴한다(0.3964 → 0.6069 → 0.5591 로 참값 0.5525 를 감싸며 좁혀 든다).
- `x = 1.0` 은 경계 위라 `0, 1, 0, 1, …` 을 오간다 — 수렴하지 않는다.
- `x = 1.5` 는 **폭발한다.** 참값이 0.3077 인 자리에서 부분합이 **765만**이다.

`ln(1+x)` 도 같은 실험을 하면 경계가 칼같다.

| `x` | 참값 | 200항 부분합 | 판정 |
|---|---|---|---|
| 0.5 | 0.40546511 | 0.40546511 | 일치(차이 `1.1 × 10⁻¹⁶`) |
| 1.0 | 0.69314718 | 0.69065343 | 수렴하지만 **느리다**(차이 `2.5 × 10⁻³`) |
| 1.05 | 0.71783979 | **−43.46001174** | 발산 |

**`x = 1.05` 가 무섭다.** 함수값은 0.718 로 지극히 평범한데 200항을 더하면 **−43.46** 이 나온다. 수렴반경 밖에서 부분합은 아무 의미가 없다.

**`x = 1` 의 위치도 눈여겨볼 것.** 수렴은 하는데 200항으로도 소수 셋째 자리에서 틀린다 — 교대급수라 수렴 속도가 `1/n` 이기 때문이다. **수렴반경 안이라고 실용적인 것은 아니다** [7].

## 7. 급수가 함수를 배신하는 순간 — e^(−1/x²)

이제 가장 깊은 균열이다. 지금까지는 급수가 **발산**해서 문제였다. 이번에는 **아주 잘 수렴하는데 답이 틀린다.**

```
            ⎧ e^(−1/x²)     (x ≠ 0)
   f(x) =   ⎨
            ⎩ 0             (x = 0)
```

**수학백과의 서술이 정확하다** [1].

> 이 함수는 한없이 미분가능하며, 특히 `f(0) = f′(0) = f″(0) = ⋯ = f⁽ⁿ⁾(0) = ⋯ = 0` 이다. 따라서 이 함수의 테일러 급수는 `0 + 0·x + 0·x² + ⋯` 로 주어지고 수렴반경은 `+∞` 이다. 그러나 이 급수의 합은 `x = 0` 에서만 원래 함수로 수렴하므로 이 함수는 `x = 0` 에서 해석적이 아니다 [1].

**왜 모든 도함수가 0인가.** 도함수를 계산해 보면 항상 `p(1/x)·e^(−1/x²)` 꼴, 즉 **유리함수 × 지수감쇠** 다 [10]. 그리고 지수감쇠가 어떤 거듭제곱보다도 세다.

**숫자로 보면 압도적이다.**

| `x` | `f(x) = e^(−1/x²)` | `x¹⁰` | `f(x)/x¹⁰` |
|---|---|---|---|
| 1.00 | 3.68 × 10⁻¹ | 1.00 × 10⁰ | 3.68 × 10⁻¹ |
| 0.50 | 1.83 × 10⁻² | 9.77 × 10⁻⁴ | 1.88 × 10¹ |
| 0.20 | 1.39 × 10⁻¹¹ | 1.02 × 10⁻⁷ | 1.36 × 10⁻⁴ |
| 0.10 | 3.72 × 10⁻⁴⁴ | 1.00 × 10⁻¹⁰ | **3.72 × 10⁻³⁴** |
| 0.05 | 1.92 × 10⁻¹⁷⁴ | 9.77 × 10⁻¹⁴ | **1.96 × 10⁻¹⁶¹** |

`x = 0.05` 에서 함숫값이 `10⁻¹⁷⁴` 이다. **`x¹⁰` 으로 나눠도 여전히 `10⁻¹⁶¹`** 이다. 어떤 거듭제곱으로 나눠도 0으로 간다 — 그것이 "모든 계수가 0"의 수치적 의미다 [10].

**결론**: 이 함수의 매클로린 급수는 온 실직선에서 완벽하게 수렴한다. **합이 0일 뿐이다.** 그리고 함수는 `x ≠ 0` 에서 0이 아니다.

> **실해석에서 무한 미분가능성은 해석성을 함축하지 않는다** [7].

**용어를 정리해 두자.** 어떤 점을 포함하는 열린 구간에서 자기 테일러 급수의 합과 같으면 그 점에서 **해석적**이라 한다 [7]. 그러면 포함관계가 이렇게 된다.

```
   { 해석함수 }  ⊊  { C^∞ 함수 }  ⊊  { C¹ 함수 }  ⊊  { 미분가능 함수 }
        ↑                 ↑
        │                 └─ e^(−1/x²) 가 여기 산다
        └─ eˣ, sin, cos, 다항식 …
```

**복소수로 넘어가면 이 첫 번째 포함이 등호가 된다.** 위키백과의 표현이 정확하다 — "근방에서 복소도함수가 존재한다는 것은 **매우 강한 조건**이다. 그것은 정칙함수가 무한 번 미분가능하고 국소적으로 자기 테일러 급수와 같음을 함축한다" [14]. 나아가 정칙함수는 정의역 안에 들어가는 **어떤 원판에서든** 자기 테일러 급수와 일치한다 [14]. `e^(−1/z²)` 는 `z = 0` 에서 **본질적 특이점**을 가져 애초에 그 점에서 정칙이 아니고, 그래서 반례가 되지 못한다. **실수의 "미분가능"이 얼마나 약한 조건인가** — 이 서가의 [[도함수의 불연속]] 이 다른 각도에서 같은 이야기를 한다.

## 8. 보렐 정리 — 계수는 함수를 결정하지 못한다

`e^(−1/x²)` 를 "재수 없는 예외 하나"로 치부하고 싶어진다. **정반대다.**

**보렐 정리(보렐 보조정리).** 위키백과의 서술 [10]:

> 실수 또는 복소수의 임의의 수열 `α₀, α₁, α₂, …` 에 대하여, 원점에서 이 수들을 도함수로 갖는 매끄러운 함수 `F` 가 실직선 위에 존재한다. 특히 **어떤 수열이든 매끄러운 함수의 테일러 급수 계수로 나타날 수 있다** [10].

보렐 보조정리 문서는 같은 것을 더 일반적으로 적는다 — 열린구간 `I` 와 매끄러운 함수열 `f₀, f₁, …` 에 대해 `∂ᵏF/∂tᵏ|₍₀,ₓ₎ = fₖ(x)` 인 매끄러운 `F` 가 존재하며, 보조공간 없이 적용하면 **0에서의 도함수가 임의의 수열이 되는 매끄러운 함수**를 얻는다 [11].

**이것이 무슨 뜻인가.**

- `αₙ = n!·nⁿ` 처럼 **미친 듯이 커지는 수열**을 가져와도 그런 매끄러운 함수가 있다. 그 함수의 테일러 급수는 **수렴반경이 0** 이다 — 원점 말고는 아무 데서도 수렴하지 않는다. 수학백과도 이 경우를 언급한다 [1].
- 즉 **"테일러 계수를 안다"는 것은 매끄러운 함수에 대해 거의 아무 정보도 아니다.** 계수 전체가 같아도 함수는 얼마든지 다를 수 있다(차이가 `e^(−1/x²)` 꼴이면 된다).

**해석함수와의 대비가 극적이다.** 해석함수는 정반대다 — **한 점 근방의 계수 전체가 함수를 완전히 결정한다.** 연결된 영역에서 두 해석함수의 모든 계수가 한 점에서 일치하면 영역 전체에서 같은 함수다.

```
   같은 "계수 전체" 를 알 때

   해석함수  →  함수가 유일하게 결정된다
   C^∞ 함수  →  아무것도 결정되지 않는다 (보렐)
```

**테일러 급수의 힘은 급수 자체가 아니라 '해석적'이라는 가정에서 나온다**는 것이 이 절의 요점이다.

## 9. 왜 57년 동안 아무도 몰랐나

이 정리의 역사는 **발견보다 인정이 훨씬 늦은** 사례다. 연표만 놓아도 이상하다.

| 해 | 일 |
|---|---|
| 14~15세기 | 케랄라에서 마다바(c.1350–c.1425) 또는 그 후계자들이 **사인·코사인·아크탄젠트의 급수**를 이미 갖고 있었다 [9] |
| 1712 | 테일러가 **7월 26일 머신에게 보낸 편지**에서 이 정리를 처음 언급한다 [12] |
| 1715 | 『Methodus incrementorum directa et inversa』 출판 — 오늘날의 테일러 급수가 여기 들어 있다 [12] |
| 1742 | 매클로린이 『Treatise of fluxions』(2권 763쪽)에서 `a = 0` 인 특수경우를 쓴다 [13]. 저자는 1698년생 스코틀랜드 수학자다 [6] |
| **1772** | **라그랑주가 이것을 미분학의 기본 원리라고 선언한다** — 여기서 처음으로 중요성이 인정됐다 [12] |
| 1785 | 비로소 "테일러 급수"라는 이름이 붙는다 [12] |

**출판에서 인정까지 57년, 이름이 붙기까지 70년이다.**

**귀속에 관해 두 가지를 바로잡아 둘 만하다.**

- **마다바의 저작은 남아 있지 않다.** 이 급수들을 그에게 돌리는 근거는 후대 케랄라 학파인 닐라칸타 소마야지(1444–1544)와 지에슈타데바(c.1500–c.1575)의 저술이며, 거기에 명확한 귀속이 있다 [9]. "마다바가 테일러보다 먼저였다"는 문장은 **개별 급수에 대해서만** 참이고, 함수 일반에 대한 방법은 아니다 [7][9].
- **매클로린은 자기 것이라 하지 않았다.** MacTutor 는 이렇게 적는다 — "매클로린 급수는 테일러의 더 일반적인 결과와 독립적으로 발견된 착상이 아니며, **매클로린은 테일러의 기여를 인정한다**" [13]. 그럼에도 오늘날 `a = 0` 인 경우는 그의 이름으로 불린다 [4].

**왜 57년이 걸렸는가 — 여기서부터는 추측이다**(출처가 뒷받침하는 것은 연도뿐이다). 다만 단서가 하나 눈에 띈다. **가장 널리 쓰이는 잉여항의 이름이 '라그랑주형'이다** [3][8]. 그리고 이 정리의 가치를 알아본 사람도 라그랑주다 [12]. 급수를 "무한히 계속되는 다항식"으로 형식적으로만 다루는 동안 이 정리는 **계산 요령**이었고, **오차를 재는 항이 붙는 순간 정리가 됐다** — 두 이름이 겹치는 것이 우연은 아닐 것이다.

## 10. 🗺️ 개념 발전 지도

| 방향 | 내용 |
|---|---|
| **가정을 풀면** | `f⁽ⁿ⁾` 의 연속을 빼면 → 페아노형만 남는다(크기 정보 상실). **해석성을 빼면** → `e^(−1/x²)`·보렐 정리의 세계. **`n → ∞` 를 포기하면** → 유한 테일러 다항식 + 잉여항, 즉 수치해석의 실전 형태. 반대로 **복소수로 올라가면** → 정칙 = 해석이 되어 균열이 닫히고, 로랑 급수가 특이점까지 흡수한다. |
| **무엇이 열리나** | 멱급수와 수렴반경(코시–아다마르), 해석접속, 로랑 급수와 유수정리, 점근전개(수렴하지 않는데 유용한 급수), 파데 근사, 자동미분의 고차 모드, 섭동이론. |
| **어디서 쓰나** | 수치 라이브러리의 초월함수 구현(구간 분할 + 각 구간 중심 전개) / 물리의 섭동 전개 / 최적화의 2차 근사(뉴턴법) / 오차 한계 보증이 필요한 임베디드·금융 계산 / 머신러닝의 손실함수 국소 근사. |
| **더 알아야 할 것** | 코시–아다마르 공식, 절대연속성(적분형 잉여항의 가정) [8], 해석접속과 단일값 정리, 점근급수의 최적 절단(발산하기 직전까지 더하는 기술), 보렐 총합법 — 발산하는 급수에서 값을 되찾는 방법. |

## 11. 함정·체크리스트

- [ ] **"무한히 미분가능하니까 테일러 급수로 쓸 수 있다"는 틀렸다** [1][7]. 쓸 수는 있지만 그 합이 원래 함수라는 보장이 없다. 보장은 **잉여항이 0으로 감**을 보여야 얻는다.
- [ ] **라그랑주 한계를 계산할 때 `n` 을 아껴 잡지 말 것.** 계수가 0인 차수까지 포함해 `n` 을 올리면 한계가 훨씬 좁아진다 — §4에서 9~14배 차이가 났다.
- [ ] **수렴반경을 실수축에서 찾지 말 것** [7]. `1/(1+x²)` 처럼 실수축에 아무 이상이 없어도 복소 특이점이 반경을 정한다.
- [ ] **수렴반경 안이라고 실용적인 것은 아니다.** `ln 2` 를 `ln(1+x)` 의 급수로 구하면 200항으로도 소수 셋째 자리에서 틀린다(§6). 수렴 속도는 별개 문제다.
- [ ] **수렴반경 밖의 부분합은 근삿값이 아니라 쓰레기다.** `1/(1+1.5²)` 를 21항으로 계산하면 참값 0.31 자리에 **765만**이 나온다.
- [ ] **`e^(−1/x²)` 를 "미분 불가능한 괴물"로 오해하지 말 것.** 무한히 미분가능하다. 문제는 미분가능성이 아니라 **해석성**이다 [1][10].
- [ ] **테일러 계수가 같다고 함수가 같은 것이 아니다** [10][11]. 해석함수에서만 참이다.
- [ ] **매클로린 급수를 테일러와 별개의 발견으로 소개하지 말 것.** MacTutor 는 매클로린 자신이 테일러의 기여를 인정했다고 적는다 [13].

## 후속 질문·연결

- **수렴반경을 계수만 보고 계산할 수 있나?** 있다 — 코시–아다마르 공식이 `1/R = limsup |cₙ|^(1/n)` 을 준다. §5의 기하학적 설명과 이 대수적 공식이 같은 값을 낸다는 것이 멱급수 이론의 출발점이다.
- **수렴하지 않는 급수가 쓸모 있을 수 있나?** 있다. **점근전개**는 발산하는데도 처음 몇 항이 극도로 정확하다 — 물리에서 표준 도구다. 이때 기술은 "발산하기 직전에 끊는 것"이다.
- **`e^(−1/x²)` 는 쓸모없는 반례인가?** 정반대다. 이 함수가 **콤팩트 지지 매끄러운 함수(범프 함수)** 의 재료이고, 그것이 분포이론·유한요소법·미분기하의 단위분할을 떠받친다. **해석적이지 않다는 결함이 곧 유용성이다** — 해석함수는 한 구간에서 0이면 전체에서 0이라 범프를 만들 수 없다.
- **테일러 급수와 푸리에 급수는 무엇이 다른가?** 테일러는 **한 점의 미분 정보**로 전체를 복원하려 하고, 푸리에는 **구간 전체의 적분 정보**를 쓴다. 그래서 푸리에는 미분가능하지 않은 함수에도 통한다.
