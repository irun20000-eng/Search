## 영상 설명

코드를 한 줄도 쓰지 않고, 그록봇에게 메시지 다섯 개를 보내서 홈페이지를 만들고 배포까지 했어요. 그록봇이 제 말을 지시서로 바꾸고, Cursor 클라우드 에이전트가 코드를 짜서 결재 서류(PR)를 올려요. 저는 확인하고 머지만 허락했어요. 이 과정을 준비부터 프롬프트까지 그대로 따라 하실 수 있게 보여 드려요.

🧭 오늘의 구조
나(말로 부탁) → 그록봇 '코딩' 봇(지시서로 바꿈) → Cursor 클라우드 에이전트(코드 · 직접 확인 · 스크린샷) → GitHub PR(결재 서류) → 머지하면 배포 주소에 반영

✅ Cursor 클라우드 에이전트가 좋은 점
· 내 컴퓨터가 아니라 클라우드에 있는 자기 컴퓨터에서 일해요
· 브라우저를 직접 열어 눌러 보며 확인해요
· 확인한 화면을 스크린샷으로 PR에 붙여 줘요 → 코드를 몰라도 눈으로 검토
· 여러 일을 동시에 맡길 수 있어요
· 마지막 머지는 언제나 사람이 해요

📊 실제로 걸린 시간 (2026-11-26 실측)
· 첫 페이지 요청 → PR: 32분
· 머지·배포: 약 1분
· 말로 수정(참고 화면 고르고 다시 요청) → PR: 11분
· 전체: 약 53분 · 보낸 메시지 5개 · 머지 승인 2번
제 예상(20분)보다 두 배 넘게 걸렸지만, 그동안 화면 앞에 있을 필요는 없었어요.

🧰 준비 4단계
1. GitHub에서 빈 저장소 만들기
2. Cursor 대시보드 → Integrations → GitHub 연결 (저장소는 하나만 선택)
3. Cursor 대시보드 → Cloud Agents → PR 자동 생성 확인, PR 이미지 설정 확인
4. 그록봇 '코딩' 봇에게 저장소 이름을 알려 주고 접근 확인

💳 요금 (2026-11-26 cursor.com/pricing 화면 기준)
새로 가입하면 Premium 30달러부터 클라우드 에이전트와 그록봇이 들어 있어요. 8달러 Plus에는 없어요. 이미 Cursor Pro나 예전 SuperGrok을 쓰고 있다면 지금 요금제로 되는지 먼저 확인하세요.

📌 영상 속 실제 요청 (1단계 · 링크 주소는 줄임)
GitHub 저장소 [내 저장소]에 내 유튜브 채널 '배움의 달인' 소개 페이지를 한 페이지로 만들어 줘. Cursor 클라우드 에이전트에게 맡기고, 위에서부터 이렇게:
1. 첫 화면: '배움의 달인 · 코딩 몰라도 AI로 일하는 법'. 글자가 한 줄씩 올라오고 배경 그라데이션이 천천히 흐르게.
2. 숫자 카운터: 영상 150편, 구독자 1.8만 명. 화면에 보이면 0부터 올라가게.
3. '이런 걸 배워요' 카드 3장(Claude Code, 그록봇, AI 영상 제작). 스크롤하면 한 장씩 떠오르고, 마우스를 올리면 살짝 들리게.
4. 최근 영상 3개: 썸네일과 제목, 누르면 유튜브로 이동.
5. 맨 아래 구독 버튼: 천천히 숨 쉬듯 커졌다 작아지게.
움직임 줄이기 설정을 켠 사용자에게는 애니메이션을 끄게.
확인 기준: 빌드 통과 · 브라우저로 직접 열어 맨 위부터 구독 버튼까지 스크롤하며 찍은 스크린샷을 PR에 붙일 것 · 링크가 모두 올바른 주소로 열릴 것.

📌 영상 속 실제 요청 (2단계 · 말로 수정)
Portrait 느낌으로 가자. 지금 배포된 페이지를 이렇게 고쳐 줘.
1. 전체 분위기를 Portrait 첫 화면처럼 바꿔 줘. 밝은 바탕, 가운데 큰 제목, 제목 둘레에 내 영상 썸네일 카드들이 비스듬히 떠 있게. 색·배치 느낌만 참고하고 그대로 베끼지는 말고, 다른 회사 로고나 이름은 쓰지 마.
2. 구독 버튼은 더 크고 눈에 띄게.
3. 휴대폰에서도 글씨가 작지 않게, 썸네일 카드가 제목을 가리지 않게.
확인 기준: 빌드 통과 · 고치기 전·후 화면을 데스크톱과 휴대폰 크기로 찍어 PR에 나란히 붙일 것. 새 PR로 올려 줘. 머지는 하지 말 것.
