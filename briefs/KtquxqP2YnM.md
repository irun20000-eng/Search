## 영상 설명

클로드 코드, 이제 화면도 작업 방식도 내 입맛대로 바꿀 수 있습니다. Claude Code Mods(모드)의 원리와 훅(Hook), 공식 예시를 살펴보고 직접 만든 학습 노트와 Cache Watch를 보여드립니다.
코드가 왜 바뀌었는지 옆에서 읽고, 컨텍스트와 비용도 한눈에 확인할 수 있습니다. 원하는 기능을 클로드에게 설명해서 나만의 모드를 만드는 방법까지 알아봅니다.

🔑 핵심 인사이트
1. Token Weather로 컨텍스트 사용량에 따라 달라지는 날씨 표시 만들기
2. Blast Radius로 위험한 명령이 실행되기 전 영향 범위를 보고 진행·취소 선택하기
3. Prompt, Before, After, Stop으로 훅을 연결하는 대표적인 시점 이해하기
4. Replay Theater로 작업 중 바뀐 코드를 별도 패널에서 다시 보기
5. 직접 만든 학습 노트와 Cache Watch로 코드 변경 이유, 캐시 타이머, 컨텍스트, 비용 확인하기

📝 상세 가이드 요약
🚀 Part 1. Claude Code Mods와 Hook: 공식 모드 예시를 보면서 특정 시점에 작업을 실행하는 훅의 원리를 설명합니다
🚀 Part 2. 나만의 모드 만들기: 공식 문서와 샘플을 참고해 클로드에게 필요한 기능을 요청하고, 평소 작업 방식에 맞는 모드를 추천받습니다
🚀 Part 3. 화면과 실행 흐름 바꾸기: 새 패널 추가, 기존 UI 변경, 도구 호출 제어, 코드 변경 기록 확인에 모드를 활용합니다
🚀 Part 4. 직접 만든 모드 시연: 코드 작성·변경 이유를 알려주는 학습 노트와 사용 현황을 모아 보여주는 Cache Watch를 소개합니다
