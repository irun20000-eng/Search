# 파스칼–페르마 서신

> 확률론은 도박장에서 시작됐다. 그것도 **아주 구체적인 질문 하나**에서.

## 질문을 던진 사람

1654년, 파리의 도박꾼 **앙투안 공보**가 [[블레즈 파스칼]]에게 실무적인 질문 몇 가지를 보냈다[2]. 그중 하나가 이른바 **점수 문제**였다.

> 두 사람이 같은 돈을 걸고 여러 판을 겨루기로 했다. 먼저 몇 판을 이기면 판돈을 다 가진다.
> 그런데 승부가 끝나기 전에 게임이 중단됐다. **판돈을 어떻게 나눠야 공평한가?**

파스칼은 이 문제를 툴루즈의 [[피에르 드 페르마]]에게 보냈고, 그해 여름 두 사람 사이에 **다섯 통의 편지**가 오갔다[2].

## 왜 이것이 시작점인가

이 문제는 그전에도 [[카르다노]]·파치올리·타르탈리아가 손을 댔지만 답이 갈렸다[1]. 두 사람이 다른 점은 **서로 다른 방법으로 접근해 같은 답에 도달했다**는 것이다.

| | 접근 |
|---|---|
| 페르마 | 남은 판을 끝까지 치렀을 때 나올 **모든 경우를 나열**하고 세었다 |
| 파스칼 | 중단 시점에서 거꾸로 따져 들어가는 **재귀적 계산**을 썼다 |
| 공통 결론 | 판돈은 이미 이긴 판수가 아니라 **앞으로 이길 가능성**에 비례해 나눈다 |

"앞으로 이길 가능성"을 수로 다룰 수 있다는 것 — 이것이 확률이라는 개념의 출발이다[3].

## 남은 것

역사학자들이 **1654년을 근대 확률론의 시작으로 보는 이유**가 여기 있다[3]. 두 사람은 이 서신을 계기로 확률론의 공동 창시자로 평가된다[4].

이어서 하위헌스가 1657년에 이를 소개하는 소책자를 냈고, 반세기 뒤 야코프 베르누이의 『추측술』(1713)이 큰 수의 법칙까지 나아가면서 확률은 하나의 분야가 된다[5].

## 수업에서 쓴다면

**확률 단원 도입에 그대로 쓸 수 있다.** 점수 문제를 그대로 던지고 학생에게 "어떻게 나누는 게 공평한가"를 먼저 물으면, 대개 "이긴 판수 비율대로"라는 답이 나온다. 그것이 왜 불공평한지를 따지는 과정이 곧 페르마의 경우 나열이다.

앞선 세대 수학자들도 답이 갈렸던 문제라는 점을 덧붙이면, 틀린 답을 낸 학생도 부끄럽지 않다.
