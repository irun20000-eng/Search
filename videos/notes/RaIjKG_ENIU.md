# 왕초보도 가능한 수백만원짜리 웹사이트 제작 과정 총정리 — 클로드코드 핵심 디자인 스킬 + 실무팁

> 한 줄 요약: 외주 수백만 원짜리 병원 홈페이지를 **클로드 코드 + 디자인 스킬 2개**(Anthropic의 **frontend-design**, **UIUX 프로맥스**)로 만든다. 핵심은 "AI 티"를 지우는 것 — **고퀄 사이트의 8요소**를 클로드에게 직접 물어 기준으로 삼고, 만든 뒤 **10점 만점 자가채점→일괄 개선**. 이미지·영상이 퀄리티의 80%라 더미로 두고 실사/AI 이미지로 교체, **21st.dev** 컴포넌트로 스크롤 효과, **프리텐다드** 폰트 통일, 의료광고법 체크, 모바일 반응형, 마지막에 **GitHub→Vercel 무료 배포**.

## 1. AI 티를 지운다 — 문제의식과 전체 순서 · [00:00](https://youtu.be/RaIjKG_ENIU?t=0)
- **3줄 요약**
  - AI로 만든 사이트는 10중 8~9가 티가 남 — 한글 깨짐·과장 광고 문구·"딱 봐도 AI" 디자인.
  - 순서: 클로드 코드 설치 → **디자인 스킬 2개 업그레이드** → 프롬프트 하나로 사이트 생성 → 다듬기 → **무료 배포**.
  - 완성도는 대행사 수백만 원 외주 수준, 방문 환자는 AI로 만든 줄 모를 정도 목표.
- **핵심 인용**: "AI로 만든 사이트는 10중 8~9 티가 납니다."
- **내 팁**: '티를 지운다'는 목표는 앞 영상(신영선 블로그)의 '저품질 회피·휴먼 터칭'과 같은 문제의식 — AI 산출물의 마지막 10%가 진짜 관건.

## 2. ★고퀄 사이트를 가르는 8요소★ · [02:03](https://youtu.be/RaIjKG_ENIU?t=123)
- **3줄 요약**
  - 클로드에게 직접 물으니 비싼/싼 사이트를 가르는 요소 8개: **관점·타이포그래피·색상·위계·이미지·애니메이션·모바일 최적화·(보이지 않는) 디테일**.
  - 이 8개를 기억해 두고 사이트를 다 만든 뒤 하나씩 지켜간다.
  - Wix/Imweb 같은 빌더도 쉽지만 결국 템플릿화돼 브랜드 이미지가 안 담김 — "어디서 본 느낌"을 벗어나야 함.
- **핵심 인용**: "비싼 사이트와 싼 사이트를 가르는 요소가 여덟 가지라고 하더라고요."
- **내 질문**: '기준을 AI에게 물어 체크리스트화'하는 건 앞 영상(신영선의 '잘 쓴 글 기준' 학습)과 동일한 발상 — 판정 기준을 먼저 세우는 것.

## 3. 디자인 스킬 2개 설치 · [02:44](https://youtu.be/RaIjKG_ENIU?t=164)
- **3줄 요약**
  - 스킬 = 클로드용 설명서(특정 분야 실력을 끌어올리는 텍스트 파일). 기본 클로드 디자인은 '그럭저럭'.
  - **① frontend-design**(Anthropic 제작): AI스러운 글꼴 금지, 다채로운 디자인. 스킬 페이지 복사→"이 스킬 설치해 줘".
  - **② UIUX 프로맥스**: UI 스타일 57개·색상 팔레트 95개·폰트 조합 56개 내장. "npm으로 이 플러그인 설치해 줘"로 설치, 큰 디자인 변경 시 직접 호출.
- **핵심 인용**: "스킬은 클로드를 위한 설명서, 특정 분야의 실력을 끌어올리는 텍스트 파일."
- **내 팁**: 스킬로 실력을 끌어올리는 방식은 앞 영상(힉스필드 스킬 5개, 클로드 Skills PPT)과 동일 — 반복 역량을 스킬로 패키징.

## 4. 프롬프트·레퍼런스로 생성 + "질문해 줘" 한 줄 · [04:10](https://youtu.be/RaIjKG_ENIU?t=250)
- **3줄 요약**
  - 결과를 가르는 건 **브리핑 차이**: 구체적일수록 좋고, 말로 어렵다면 **레퍼런스**(Dribbble·Awwwards 스크린샷 캡처)를 붙여넣기.
  - 무드(청결·신뢰·세련)를 입력하고 UIUX 프로맥스 스킬을 탭으로 호출 → 프롬프트 끝에 **"명확히 하기 위해, 잘 이해 안 되면 질문을 해 줘"** 한 줄이 결정적(만들기 전 생각하게 함).
  - 클로드가 기술 스택(Next.js+Tailwind 선택)·부가 페이지를 되물음 → 서밋 → 초안 완성 → 브라우저 실행. 실제 정보 대신 **더미 데이터** 먼저.
- **핵심 인용**: "잘 이해가 안 되면 질문을 해 줘. 이 한 줄이 클로드가 만들기 전에 잠깐 생각하게 만듭니다."
- **내 질문**: '질문해 줘' 한 줄로 선(先)명확화를 유도하는 건 앞 영상(신영선의 setup 인터뷰)의 '요구사항을 먼저 캐내기'와 같은 패턴 아닐까?

## 5. 이미지·영상이 80% + 21st.dev 애니메이션 · [07:06](https://youtu.be/RaIjKG_ENIU?t=426)
- **3줄 요약**
  - 홈페이지 퀄리티의 **80%는 이미지·영상**이 결정 → 실사 준비가 최선, 없으면 Grok으로 인물 생성→ChatGPT로 16:9·가운데 정렬→**제미나이로 '천천히 움직이는 영상'** 생성 → 폴더에 넣고 "히어로 섹션 뒤에 추가해 줘".
  - 8요소 자가채점: 기준을 붙여넣고 "10점 만점 몇 점?" → "한꺼번에 적용할 개선안 묶음 보고 적용해 줘"로 **일괄 수정**(효율↑).
  - **21st.dev**: 바로 쓰는 컴포넌트·스크롤 효과 라이브러리 → 'Copy Prompt' 후 "히어로 섹션에 이 효과 추가해 줘"(히어로 확대·카드 등장·캐러셀). 섹션 전환도 은은하게 다듬기.
- **핵심 인용**: "홈페이지의 80%는 이 이미지와 홈페이지에 들어가는 영상의 퀄리티가 결정합니다."
- **내 팁**: '자가채점→일괄 개선' 루프는 이 프로젝트의 '리뷰→수정 반복'과 정확히 같은 품질 루프. 이미지·영상 우선은 힉스필드 영상의 '이미지 먼저' 원칙과도 통함.

## 6. 마감 8단계 — 의료광고법·프리텐다드·모바일·Vercel 배포 · [13:11](https://youtu.be/RaIjKG_ENIU?t=791)
- **3줄 요약**
  - **의료광고법 체크**: "한국 의료 광고법에 의거해 위반 사항 체크해 줘"로 리스크 사전 점검. **폰트는 프리텐다드로 통일**(상업적 무료·가독성).
  - **모바일 반응형**(8단계): 환자 대부분 폰으로 유입 → "모바일 최적화 위해 반응형으로" 요청(Next.js는 반응형 내장이라 손댈 게 적음). F12 리스폰시브로 기기별 확인.
  - **배포**: GitHub 새 저장소 생성→"깃허브에 저장해 줘"(링크 붙여넣기)→**Vercel** 로그인→Add New Project→Import→Deploy→Visit. **전 과정 무료**. (상담폼→회사 메일 연동 등 실기능은 별도 강의 안내.)
- **핵심 인용**: "이 배포까지 저희는 무료로 다 해 봤습니다."
- **내 질문**: '의료광고법 체크'처럼 도메인 규제를 AI에 물어 검수하는 건 앞 영상(힉스필드 광고표시법 검토)과 같은 '컴플라이언스 게이트' 아닐까?

## TL;DR (5줄)

1. **목표**: 외주 수백만 원 병원 홈페이지를 클로드 코드로 — 핵심은 **"AI 티" 제거**(월 3만 원, 수정도 무제한).
2. **스킬(★)**: frontend-design(Anthropic, AI 글꼴 금지) + UIUX 프로맥스(스타일 57·팔레트 95·폰트 56) 두 개 설치.
3. **기준(★)**: 고퀄 8요소(관점·타이포·색상·위계·이미지·애니메이션·모바일·디테일)를 클로드에 물어 체크리스트화 → 생성 후 **10점 자가채점→일괄 개선**.
4. **재료**: 이미지·영상이 퀄리티의 80% — 더미로 두고 Grok/ChatGPT/제미나이로 인물·영상 제작, **21st.dev** 컴포넌트로 스크롤 효과. 프롬프트 끝 "질문해 줘" 한 줄.
5. **마감·배포**: 의료광고법 체크 + **프리텐다드** 폰트 통일 + 모바일 반응형 → GitHub→**Vercel 무료 배포**.
