# 디자인 끝판왕 클로드 디자인 30분 만에 마스터하기 (5대 피처 총정리)

> 한 줄 요약: 하나의 가상 서비스(빨래 구독 '빨래대마왕')로 **클로드 디자인 5대 피처**를 관통. **핵심 전제 = 디자인 시스템**: 브랜드 테마(컬러·폰트)를 고정해 PPT·문서·웹 모든 산출물의 일관성 확보(프리셋 6종 or 직접 연결). ①**프로토타입**: 기능이 실제 동작하는 시제품(옵션 클릭→가격 즉시 변동), 편집은 **트윅**(틀 유지+변형 비교)·**에디트**(텍스트 바로). ②**슬라이드**: 클로드 기반이라 클로드 코드·디자인 시스템과 연동·일관성이 강점, 이미지 부족하면 **공유→PPT/PDF 추출**하거나 **캔바·감마·구글슬라이드 커넥트**로 보완. ③**도큐먼트**: 클로드의 **한국어 텍스트 강점**이 그대로. ④**와이어프레임**: 여러 시안 자동 비교 → **앱 만들기 전에 뼈대로 시간·토큰 절약**, 확정 후 클로드 코드에 넘겨 앱 제작. ⑤**애니메이션**(대업데이트): 히어로 섹션 모션을 프롬프트로, 이제 **MP4 비디오로 바로 추출**(프리미어·캡컷 편집). ★큰 변화: 클로드 디자인이 **요금제 토큰을 공유**(별도 소모→공유)해 효율↑. 마무리 메시지: **완벽주의를 버리고 만들고 수정 반복**하는 게 시작.

## 1. ★전제 — 디자인 시스템으로 브랜드 테마 고정 + 토큰 공유★ · [00:00](https://youtu.be/24IV_DA5Yh4?t=0)
- **3줄 요약**
  - 클로드 디자인 출시 3개월, 첫 주 100만 유저. 초기 이슈: **별도 토큰**이라 크레딧 순삭 → **최근 업데이트로 요금제 토큰 공유**(효율↑).
  - 접속: claude.ai/design 또는 앱 좌측 하단 '디자인'(웹/앱 동일).
  - **디자인 시스템**: 브랜드 컬러·폰트를 고정 → PPT·문서·웹 등 매번 테마 설정하는 번거로움·컬러 사고 방지, 일관성 자동 확보. 프리셋 6종 or 기존 테마 직접 연결.
- **핵심 인용**: "따로 토큰을 소모시키는 게 아니라 요금제 토큰을 같이 쓰게 했어요. 아주 효율적으로 클로드 디자인을 사용할 수 있게."
- **내 팁**: '디자인 시스템에 브랜드 등록→모든 산출물 통일'은 이 갤러리 VnMAgSd(오빠두엑셀 클로드 디자인)의 우측 디자인 시스템과 동일 원칙 — 이번 편은 5피처를 한 서비스로 관통하는 실습.

## 2. ★① 프로토타입 — 동작하는 시제품 + 트윅/에디트★ · [02:58](https://youtu.be/24IV_DA5Yh4?t=178)
- **3줄 요약**
  - **프로토타입**=완성 전 흐름·디자인을 대략 구현한 시제품. 프롬프트에 서비스 설명+핵심 기능(구독 세부→가격 변동, 특수 케이스 클릭, 최종 가격+버튼)을 예시까지 3줄로. 애매하면 클로드가 먼저 질문("Decide for me"로 위임 가능).
  - 결과 화면: 왼쪽=채팅, 오른쪽=**캔버스**. 협업은 코멘트(댓글)·클로드 지시.
  - **트윅**(Tweaks)=틀 유지하며 색감 등 변형을 만들어 **비교**(디자인은 비교해야 판단), **에디트**=텍스트 바로 수정. 프로토타입은 **기능 실제 체험**(주2회→6.9만원, 옵션 추가 즉시 반영).
- **핵심 인용**: "트윅은 기존의 틀은 유지하면서 원하는 디자인적으로 약간의 변화를 주고 싶을 때… 디자인은 비교를 하지 않고서는 볼 수 있는 게 많이 없기 때문에."
- **내 질문**: '트윅으로 변형본을 나란히 비교'는 이 프로젝트 품질 루프의 A/B·다안 비교와 같은 원리 — 한 안 고집 대신 대안 병치가 디자인 판단의 핵심 아닐까?

## 3. ★②③ 슬라이드·도큐먼트 — 연동·일관성 + 한국어 강점★ · [08:15](https://youtu.be/24IV_DA5Yh4?t=495)
- **3줄 요약**
  - **② 슬라이드(PPT)**: 다른 PPT 툴은 클로드/클로드 코드와 연동이 매끄럽지 않으나, 클로드 디자인은 슬라이드+모든 디자인을 만들어 **디자인 시스템과 일관성·조합**이 강점. 피칭덱(정부지원 사업) 5장 구성. 디자인 템플릿만 바꿔도 색감 전환.
  - 이미지가 없어 아쉬우면 **공유→PPT/PDF 추출** 후 다른 툴로, 또는 **커넥트로 캔바·감마·구글 슬라이드 연동**해 편하게 수정(한국 미리캔버스는 미연동, 캔바 추천).
  - **③ 도큐먼트(문서)**: 구독 후 빨래 여정 페이지. 클로드 기반이라 **한국어 텍스트 강점**(세탁기 이모티콘·"문앞에서 문앞까지" 한 줄 카피 자동). 브랜드 컬러는 트윅으로.
- **핵심 인용**: "클로드 디자인은 클로드를 기반으로 한 디자인 툴이잖아요. 텍스트를 쓰는 것에 있어서 이점을 아주 강하게 가지고 있죠."
- **내 팁**: '클로드 디자인↔캔바/감마/클로드 코드 커넥트'는 도구 간 핸드오프 — 초안은 클로드 디자인, 마감은 캔바로 분업하는 실무 동선.

## 4. ★④ 와이어프레임 — 시안 비교로 시간·토큰 절약 → 클로드 코드로★ · [15:07](https://youtu.be/24IV_DA5Yh4?t=907)
- **3줄 요약**
  - **와이어프레임**=디자인적 뼈대(프로토타입=시제품과 구분). 요청 시 클로드가 **여러 구조(시안)를 자동 비교** 제시(디자인 외주처럼).
  - **앱을 다 만든 뒤 고치면 토큰·시간 낭비** → 와이어프레임 단계에서 비교·확정하는 게 유용. 폰트가 과하게 친근하면 트윅으로 정갈한 고딕/명조로 교체.
  - 확정한 와이어프레임을 **클로드 코드에 넘겨 앱 제작** → 예상 형태 안에서 디자인이 나오는 게 장점.
- **핵심 인용**: "앱을 다 만들어 놓고 AI로 그걸 고치기 시작하면 토큰도 엄청 쓰고 시간도 엄청 쓰게 되고… 와이어프레임을 만들어 보시는 건 아주 유용한 선택입니다."
- **내 질문**: '값싼 뼈대에서 결정→비싼 실행'은 이 프로젝트가 반복 확인한 토큰 경제(설계는 저비용, 실행만 고비용)와 동일 — 와이어프레임이 그 저비용 결정 지점 아닐까?

## 5. ★⑤ 애니메이션(대업데이트) — 히어로 모션 + MP4 추출★ · [19:14](https://youtu.be/24IV_DA5Yh4?t=1154)
- **3줄 요약**
  - **애니메이션**: 웹페이지 로드 시 히어로 섹션 모션(빨래 쏟아짐→글자 튀어나옴)을 프롬프트로. 재생 1회·CTA 버튼·색·슬라이드 페이드 등 지정. 원래 모션그래픽은 고되거나 외주였음.
  - 결과가 아쉬우면 템플릿 변경+추상적 명령("더 그럴듯하게")으로 개선. 세부 색·톤은 트윅·세팅으로 수렴.
  - ★업데이트 핵심: 이제 **쉐어→MP4 비디오로 바로 추출** 가능 → 프리미어·캡컷에서 추가 편집. 디즈니급 기대는 금물이나 **웹 히어로·유튜브 글자 팝업 모션그래픽**엔 충분.
- **핵심 인용**: "이제는 그냥 쉐어한 다음에 비디오 형태로 그대로 수출할 수 있게 되었습니다. 프리미어 프로나 캡컷에 넣어서 편집을."
- **내 팁**: '클로드 디자인→MP4→편집툴'은 이 큐레이션의 구글 Flow(원카AI)·홍아린 영상공장 편과 만나는 지점 — 디자인 도구가 영상 파이프라인으로 확장. 마무리 교훈은 프로젝트 철학과 동일: **완벽주의 버리고 만들고 수정 반복**.

## TL;DR (5줄)

1. **디자인 시스템(★)**: 브랜드 테마 고정으로 5피처 산출물 일관성. 큰 변화 = 요금제 **토큰 공유**로 효율↑.
2. **프로토타입**: 동작하는 시제품(옵션→가격 즉시). 트윅(변형 비교)·에디트(텍스트) 편집.
3. **슬라이드·도큐먼트**: 클로드 코드·디자인 시스템 연동 일관성 + **한국어 텍스트 강점**. 이미지 부족 시 캔바/감마 커넥트.
4. **와이어프레임(★)**: 여러 시안 자동 비교 → 앱 제작 전 뼈대로 시간·토큰 절약 → 클로드 코드로 넘김.
5. **애니메이션(★)**: 히어로 모션을 프롬프트로, 이제 **MP4 추출** 가능. 결론: 완벽주의 버리고 만들고 수정 반복.
