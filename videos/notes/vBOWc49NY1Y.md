## 5. 실무 스킬 커스텀 팁: argument-hint와 자동 호출 비활성화(disable-model-invocation) · [12:33](https://youtu.be/vBOWc49NY1Y?t=753)
- **3줄 요약**
  - 프론트매터에 **argument-hint**를 정의하면 슬래시 명령어 입력 시 주제와 청중 입력 가이드가 화면에 미리보기로 노출된다.
  - **disable-model-invocation: true** 옵션을 부여하면 클로드가 문맥을 자의적으로 판단해 멋대로 스킬을 자동 실행하는 현상을 방지한다.
  - 설치된 스킬이 많을수록 의도치 않은 간섭을 배제하고 사용자가 명령어를 직접 찍어 부르는 **명시적 호출 통제**가 안전하다.
- **핵심 인용**: "그런데이 옵션을 트로로 해 놓게 되면 모델이 질문을 출론해서 스킬을 자동으로 부르는 것을 끌 수가 있습니다 기세일을 시키는 거죠 네 뭐 물론이 원작자의 의도가 있을 순 있어요 근데 저 개인적으로 쓴다라고 했을 때는 저는 무조건 이거는 명시적으로 부를 때만 호출되게 만들 거 같아요"
- **내 팁**: 다수의 전문 스킬을 등록해 사용할 때는 `disable-model-invocation: true` 설정을 추가하여 일반 질의 도중 엉뚱한 스킬이 불필요하게 트리거되는 혼선을 차단한다.

1. **쉬운 설명 전환**: 장황하고 어려운 클로드의 전문 기술 설명을 유아 수준으로 쉽게 풀어주는 ELI5 스킬의 실무 효용성을 검증한다.
2. **시각 도식화 아티팩트**: 커뮤니티 스킬은 번호표와 밴드 비유를 담은 5단계 HTML 아티팩트 다이어그램을 생성해 직관성을 높인다.
3. **청중 맞춤형 페르소나**: 깃허브 스킬은 빵가루 텍스트 비유와 함께 5세·10세·15세·40세 이상 네 단계 연령 및 직무별 어휘 수준을 유연하게 제어한다.
4. **SKILL.md 구조 분석**: 인기 스킬 지시문을 역분석하여 나이별 금지 어휘와 청중 관심사 프롬프트 설계 노하우를 체득한다.
5. **프론트매터 제어 옵션**: argument-hint로 입력 가이드를 띄우고 disable-model-invocation으로 의도치 않은 자동 발동을 차단한다.
