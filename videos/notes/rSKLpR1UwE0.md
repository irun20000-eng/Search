# “자동화 끝판왕” 요즘 핫한 AI Aside 브라우저 셋팅부터 설치까지 올인원 핵심 총정리

> 한 줄 요약: 라이브 실습 강의 녹화본으로, **어사이드** 설정 화면을 왕초보 기준으로 한 칸씩 짚는다. 가장 값나가는 대목은 **디폴트(태스크) 모델** — 그 자리가 어사이드로 남아 있으면 **크레딧이 다 털린다**고 화자가 제 실패로 경고하며, GPT·클로드 계정을 연결(클릭 후 로그인, API 발급 불필요)한 뒤 자기 모델로 바꾸라고 한다. 이어 **에이전트 알림·퍼미션**, **스킬·MCP·메모리**, **패스워드 CSV 임포트·루틴**을 훑고, 하이라이트로 **클로드 코드에 어사이드 CLI 를 붙여** 클로드를 **중간 지휘자**로 쓰는 구성을 시연한다(화자는 CLI 와 MCP 를 둘 다 연결하라고 권하지만, 화면에서 깔고 연결하는 것은 CLI 하나다). 못 박는 원칙은 **「맥락과 실행을 분리한다」**이고, 어사이드는 **컴퓨터가 꺼지면 돌아가지 않는다**는 전제도 함께 밝힌다.

## 1. 설치와 기본 — 쓰던 브라우저에서 끌어온다 · [00:05](https://youtu.be/rSKLpR1UwE0?t=5)
- **3줄 요약**
  - 강의는 시청자가 같이 깔고 로그인한 상태에서 따라오게 하는 **실습 형식**이다. 설치 뒤 **동기화** 단계에서 크롬·엣지·웨일·사파리 등 쓰던 브라우저의 **즐겨찾기·북마크를 그대로 가져올 수 있다**.
  - 기본 검색은 바꿀 수 있다. 화자는 퍼플렉시티를 구독해 연결해 뒀다가 해지해서 지금은 구글로 돌려놓았다고 밝힌다.
  - **단축키는 기본값**을 쓰고 있다. 본인은 스플릿 키보드로 바꿔 알트 키가 없어 자기 단축키를 만들기 어렵다고 말하면서도, 단축키를 세팅하지 않아도 불편한 점은 없다고 덧붙인다.
- **핵심 인용**: "제가 대신 실패를 해 드릴게요. 제가 대신 동과 시간 써서 실패해 드릴테니까 요렇게 하시면 됩니다."
- **내 팁**: 이 영상의 값어치는 기능 소개가 아니라 **이미 돈을 쓴 실패 목록**이다. 설정 화면을 처음 여는 쪽이면 뒤의 모델 대목부터 먼저 보고 와도 손해가 없다.

## 2. 에이전트 설정 — 알림과 퍼미션 · [02:23](https://youtu.be/rSKLpR1UwE0?t=143)
- **3줄 요약**
  - **알림**은 화자 본인이 켜 두었다. 여러 창을 동시에 작업시킬 때 소리와 메시지가 떠서 중간에 확인하기 좋다는 이유다.
  - **퍼미션**은 선택지다. 화자는 **전체 승인(풀 액세스)**으로 두었고 — 어사이드가 스스로 읽고 쓰는 것을 전부 허용하는 설정이다 — 다만 **보안 측면에서는 가드를 쓰라는 권고가 있다고 전하며**, 혼자 입력하고 클릭하고 지울 수도 있다는 점이 불안하면 가드로 하면 된다고 안내한다.
  - 작업 중 명령을 **바꾸고 싶은 경우**와 **작업이 끝난 뒤 후속 지시로 넣는 경우**의 설정이 따로 있고, 화자는 후자를 쓴다. **작업 폴더 지정**도 클로드·코덱스처럼 켜 두라고 한다.
- **핵심 인용**: "저는 전체 승인 해 놨습니다. 어 이거는 쉽게 말하면은 그냥이 풀 엑세스를 하면은 1기 쓰기를 전체다 승인하겠다는 거예요."
- **내 팁**: 풀 액세스는 **화자 본인의 선택**이고, 같은 자리에서 가드 권고를 전하고 있다. 로그인된 브라우저를 대신 조작하는 도구라는 점을 생각하면, 처음에는 가드로 두고 어디까지 손대는지 본 뒤에 넓히는 쪽이 내 기준으로는 마음이 편하다 — 영상은 가드 권고를 전하기만 하고 근거는 다루지 않는다.

## 3. ★모델 설정 — 화자는 디폴트 모델 탓에 크레딧이 털렸다★ · [04:25](https://youtu.be/rSKLpR1UwE0?t=265)
- **3줄 요약**
  - 연결은 간단하다. 자막이 **「컨택」**으로 들리는 연결 버튼을 눌러 GPT·클로드 등 쓰는 계정을 고르고 **로그인하면 끝**이다 — API 발급이나 복잡한 입력이 필요 없다.
  - 문제는 그 아래 **태스크 모델(디폴트 모델)**이다. 그 자리가 어사이드로 남아 있으면 **어사이드 크레딧이 털린다고 화자는 제 경험으로 경고한다**. 계정을 연결한 다음 **자기가 쓰려는 모델로 바꿔 놓아야** 한다.
  - 화자는 전부 **오퍼스 5.5** 로 맞춰 놓았다. 원래는 **아스트라**로 해 뒀다가 오퍼스 5.5 가 **웹 제어**와 계획을 짜는 추론 쪽에서 가장 만족스럽다는 것이다. 반면 **이미지·캡차·스크린샷 같은 시각 작업은 GPT** 로 지정했다. **아스트라**에서 자막이 「6.1솔 소」로 들리는 모델을 골라 OBS 스튜디오 세팅을 시켰더니, 오퍼스 5.5 가 10~15분에 끝낸 일을 30~40분 썼다고 말한다.
- **핵심 인용**: "이렇게 되어 있으면은 안 돼요. 그럼 어사이드 크레딧이 저처럼 다 털리시는 거예요. 예. 저처럼 다 털리는 거예요."
- **내 팁**: 설치 직후 **가장 먼저 확인할 한 칸**이 여기다. 기능을 둘러보기 전에 태스크 모델이 무엇으로 되어 있는지 보고 바꿔 두면, 화자가 겪은 일을 둘러보는 동안 되풀이하지 않는다.

## 4. 플러그인·MCP·메모리가 각각 맡는 것 · [07:53](https://youtu.be/rSKLpR1UwE0?t=473)
- **3줄 요약**
  - **스킬**은 어사이드를 쓰면서 생긴 **업무 레시피·매뉴얼**이다. 어사이드 폴더에 저장되고, 어사이드는 아무렇게나 작업하지 않고 **그 내용을 토대로** 움직인다.
  - **MCP** 는 **외부 도구**다. 화자는 어사이드의 **손발이 되어 주는 도구들**이라 부르고, 필요한 것만 골라 연결하면 된다고 말한다.
  - **메모리**는 어사이드를 쓰면서 **기록되는 내용이 폴더에 정리되는 것**이다. 시키지 않아도 어사이드가 스스로 정리하며, 관련 설정은 대개 이미 켜져 있을 것이라고 안내한다.
- **핵심 인용**: "스킬은 내가 어사이드를 사용하면서 생긴 업무 레시피 매뉴얼이라고 생각하시면 돼요."
- **내 질문**: 스킬·메모리가 쌓이는 폴더는 어디이고 직접 열어 고칠 수 있는가. 영상은 저장된다는 사실과 설정 위치만 보여 주고, 파일 구조나 편집 방법은 다루지 않는다.

## 5. 패스워드·루틴·Developers · [09:02](https://youtu.be/rSKLpR1UwE0?t=542)
- **3줄 요약**
  - **패스워드**는 쓰던 브라우저에서 옮겨 온다. 크롬·웨일 등에서 비밀번호를 **CSV 로 내려받아 임포트**하면 어사이드에 저장되고, 로그인이 안 될 때는 자막이 **「매니저 유즈 디폴트」**로 들리는 항목을 먼저 켜라고 안내한다. 맥은 패스워드 항목으로 연동되는 것 같다고(자막 「맥은이 패스워드 요걸로 아마 연결이 되는 거 같은데」) 말하면서, 안 되면 CSV 경로를 쓰라고 덧붙인다.
  - **루틴**이 자동화다. 정해진 시간에 매일 어사이드가 하는 일이며, 만드는 법으로는 **어사이드에게 말로 시키는 방식**을 보여 준다.
  - **Developers** 에 **어사이드 CLI** 와 **어사이드 MCP** 가 있고, 화자는 이 둘을 기억하라고 강조한다. **리모트 컨트롤**이 프로 요금제를 쓰는 이유라고 밝히고, **미니 팝업**은 필요 없어 껐다. **(라이브 응대 중 곁말 — 학습 내용과 분리: 한국인이 만들었지만 실리콘밸리에서 만들어져 한국어 최적화가 안 되어 있다는 언급)**
- **핵심 인용**: "일단 같이 한번 만들어 볼게요. 너무 쉬워요. 그냥 어사이드한테 시키면 됩니다. 이거 매일 뭐 몇 시에 또는 뭐 며칠 몇 무슨 요일마다 작동될 수 있게 루틴화해 줘. 루틴 만들어 줘 하면 얘가 그냥 알아서 이렇게 여기 추가해 갖고 만들어 줘요."
- **내 팁**: **대화로 시키면 항목이 추가된다**(UI 로 만드는 경로는 영상에서 다루지 않는다) — 반대로 말하면 이미 걸린 루틴이 무엇인지 그 목록을 주기적으로 열어 봐야 한다.

## 6. ★하이라이트 — 클로드를 중간 지휘자로 세운다★ · [12:18](https://youtu.be/rSKLpR1UwE0?t=738)
- **3줄 요약**
  - 설치 자체는 별게 없다고 미리 말한다. 중요한 것은 **왜 연결하는가**다 — 클로드 코드에 어사이드 CLI 를 붙이면, 사람이 클로드에 말하고 **클로드가 어사이드에 명령을 보내 작업을 수행한 뒤 결과를 답변**한다. 화자는 이 자리를 **중간 지휘자**라 부른다.
  - 부수 효과가 하나 더 있다. 클로드는 작업 폴더 안에서 돌고 **거기에 히스토리가 남으므로**, 어사이드 스킬을 따로 남기지 않아도 어사이드를 활용한 기록이 클로드 쪽에 쌓인다. 그 폴더는 클로드로도 코덱스로도 접근할 수 있다.
  - 연결 방식은 두 가지다. **CLI 는 명령으로 작업을 요청**하고, **MCP 는 실행 환경에 어사이드 도구를 쥐여 준다**. 둘 다 연결해 두면 상황에 맞는 쪽을 알아서 고른다고 설명한다.
- **핵심 인용**: "CLI는 명령으로 작업을 요청하고 MCP는 실행 환경의 어사이드 도구를 도구를 주어지는 거예요. 예 두 개다 연결하면 됩니다."
- **내 팁**: 둘 중 무엇을 쓸까를 고민하지 말라는 것이 결론이다. 다만 **CLI 와 MCP 가 하는 일이 다르다**는 구분은 기억해 둘 가치가 있다 — 작업이 안 돌 때 어느 쪽 연결을 의심할지가 달라진다.

## 7. ★별표 50개 — 맥락과 실행을 분리한다★ · [14:34](https://youtu.be/rSKLpR1UwE0?t=874)
- **3줄 요약**
  - 먼저 전제를 못 박는다. **어사이드는 컴퓨터가 꺼지면 돌아가지 않는다.** 계속 켜 두어야 하며, 화자는 본인 노트북이 주 7일 돌고 있어 뜨겁다고 말한다.
  - 그리고 강조 표시를 붙인 원칙이 나온다 — **어사이드는 실행 도구**이고, **맥락을 저장해 주는 도구는 그와 다르다**. 시키면 움직이는 쪽과 기억을 쌓는 쪽을 섞지 말라는 것이다.
  - 그래서 어사이드가 작업한 **방식과 결과물을 스킬로만 남기지 말고 과정까지 전부 매뉴얼로** 남기라고 한다. 그 매뉴얼이 모이면 **위키**가 된다.
- **핵심 인용**: "맥락이랑 실행을 분리해야 돼요. 다시 한번 더. 맥락과 실행을 분리한다. 어사이드는 무슨 도구다? 실행을 하는 도구다."
- **내 팁**: 앞 챕터의 중간 지휘자 구성이 이 원칙의 실행판이다 — 맥락은 클로드 쪽 폴더에 쌓이고 어사이드는 실행만 한다. 루틴을 걸기 전에 **기록이 어디에 남는지**부터 정해 둘 것.

## 8. CLI 설치 실연과 뉴스레터 자동화 시연 · [15:59](https://youtu.be/rSKLpR1UwE0?t=959)
- **3줄 요약**
  - 절차는 **세팅 → 디벨로퍼스 → 어사이드 CLI → 「카피 커맨드」**(자막 표기) 로 명령을 복사한 뒤, 클로드나 코덱스에 붙여 넣고 **「여사이드 CLI 연결 설치해 줘」**(자막 표기)라고 말하는 것이다. 화자는 자신은 서버에서 쓰고 있어 로컬에는 안 깔려 있었던 것 같다고 말하며 그 자리에서 함께 깐다.
  - 시연 지시는 말하듯 던진다 — **「어사이드 활용해 가지고 우리 지금 뉴스레터 자동화 진행하고 있는 거 어디까지 세팅됐고 내가 뭘 해야 되는지 정리해서 핵심만 간단하게 보고해 봐」**. 그러면 클로드가 그 말을 정리해 어사이드로 넘기고, 오른쪽 어사이드 창에서 루틴 수동 테스트가 돌아간다. 답이 영어로 와서 한국어로 설명하라고 되돌린다.
  - 그래서 결론은 **어사이드 화면을 직접 볼 이유가 줄어든다**는 것이다. 화자는 따로 자동화해 둔 카드뉴스가 자기 유튜브 내용으로 이메일에 도착하는 것도 보여 준다. **(뒷부분은 라이브 수강생 응대 구간 — 학습 내용과 분리)**
- **핵심 인용**: "그러니까 사실 어사이드를 실질적으로 이제 볼 화면을 볼 이유가 별로 없어져요. 이렇게 연결해서 쓰면은 이해되시나요?"
- **내 질문**: 중간 지휘자를 거치면 작업이 느려지거나 비용이 더 드는가. 영상은 편해진다는 점만 보여 주고, 클로드와 어사이드 양쪽에서 토큰·크레딧이 어떻게 쓰이는지는 비교하지 않는다.

## TL;DR (5줄)
1. **첫 설정은 모델**: 화자는 태스크(디폴트) 모델이 어사이드로 남아 있어 제 크레딧이 털렸다고 경고한다 — 계정을 연결한 뒤 쓰려는 모델로 바꿔 둘 것.
2. **모델 분담**: 화자는 아스트라에서 옮겨 와 웹 제어·추론을 오퍼스 5.5 로, 이미지·캡차·스크린샷을 GPT 로 나눠 지정했다.
3. **세 갈래 정리**: 스킬은 업무 매뉴얼, MCP 는 외부 도구(손발), 메모리는 시키지 않아도 쌓이는 기록이다.
4. **CLI 연결 — MCP 도 함께 권한다**: 클로드 코드에 붙이면 클로드가 중간 지휘자로 어사이드에 명령을 보내고, 작업 기록은 클로드 쪽 폴더에 남는다(화면에서 연결한 것은 CLI 다).
5. **원칙과 전제**: 화자는 맥락과 실행을 분리해 과정까지 매뉴얼로 남기라고 하며 그것이 모여 위키가 된다고 말한다 — 단, 어사이드는 컴퓨터가 꺼지면 돌아가지 않는다.
