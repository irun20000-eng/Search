# Hermes Agent, 데스크톱 앱에 이렇게 연결하면 완전히 달라집니다! (VPS+테일스케일 연동)

> 한 줄 요약: 헤르메스 데스크톱 앱을 **로컬이 아니라 외부 VPS 백엔드에 연동**해 '24시간 AI 직원'을 만드는 실전. 구조는 **노트북(조종석)=데스크톱 앱 + VPS(엔진)=호스팅어 도커 헤르메스 + 테일스케일(사설망) 연결**. 호스팅어 원클릭 배포 → 오픈AI 코덱스 연동 → 데스크톱 앱 설치 → 테일스케일로 노트북·VPS 연결 → 포트(9119→4860) 열기 → `hermes serve` 백엔드 → 리모트 게이트웨이 연결. 장점: 노트북 꺼도 24시간·어디서든·로컬 보안 유지·스킬/메모리 싱크.

## 1. 왜 데스크톱 앱 + 외부 서버인가 · [00:00](https://youtu.be/Lkk2ubF1AZ8?t=0)
- **3줄 요약**
  - 헤르메스는 반복 작업·보고 + 텔레그램/슬랙 외부 지시가 강점이나 **데스크톱 앱이 없어** PC 실시간 작업엔 아쉬웠음 → 최근 데스크톱 앱 출시.
  - 헤르메스는 **24시간 켜두는 AI 직원**이 핵심이라, 데스크톱 앱도 로컬이 아니라 **외부 서버와 연동**하는 게 포인트.
  - 맥미니는 비싸니 **호스팅어 VPS**로 설치·연동(쿠폰 제공).
- **핵심 인용**: "이 데스크톱 앱도 로컬 PC에서 그냥 돌리는 게 아니라 외부 서버랑 어떻게 연동하고 쓸 수 있게 구현하는지가 포인트."
- **내 질문**: '조종석(로컬)과 엔진(원격)의 분리'는 앞 영상들의 클라우드 대시보드·에이전트 패턴과 같은 발상 — 개인 인프라의 표준 아키텍처가 되어가는 걸까?

## 2. 구조 3요소 + 로컬 설치의 단점 · [01:21](https://youtu.be/Lkk2ubF1AZ8?t=81)
- **3줄 요약**
  - ① 노트북의 **데스크톱 앱 = 조종석**(화면·조작·세팅) ② VPS의 헤르메스 = **엔진/백엔드**(실제 작업) ③ **테일스케일 사설망**으로 연결.
  - 로컬만 설치 시 단점: PC 끄면 정지, 재부팅 시 장기작업 에러, 무거운 작업 시 느림, 기기 변경 재세팅, **보안**(내 노트북 전체에 에이전트 접근).
  - → "직원에게 내 사적 노트북을 그냥 주는 격" → 24시간 외부 머신 권장(필요한 정보만 주어 보안↑).
- **핵심 인용**: "마치 직원을 한 명 채용하는데 … 내가 사적으로 쓰고 있는 노트북을 그냥 제공해 주고 이거 같이 써서 작업해라라고 하는 것과 같아요."
- **내 팁**: 외부 머신은 맥미니(가성비↑ 가격↑) vs VPS 임대(하드웨어 불필요·월 구독) — 시작은 VPS 추천.

## 3. 호스팅어 VPS 구매 + 원클릭 도커 배포 · [04:28](https://youtu.be/Lkk2ubF1AZ8?t=268)
- **3줄 요약**

  - 서버 위치=지연 짧은 곳, OS=**우분투 24.04**. **쿠폰으로 추가 10% 할인**. 루트 비번 자동 생성·저장, 멀웨어 스캐너·도커 관리자 체크.
  - 콘솔 → 도커 매니저 → 컴포즈 → **원클릭 배포** → 템플릿 'hermes' 선택 → 어드민 유저네임/패스워드(저장) → 배포 → 도커 컨테이너에 설치(버튼 하나).
- **핵심 인용**: "그냥 버튼 하나 누르면 바로 이렇게 설치를 해 주게 됩니다."
- **내 팁**: 도커 컨테이너로 설치하는 이유 = 관리 용이 + 여러 개(테스트/실사용) 분리 운용.

## 4. 오픈AI 코덱스 연동 + 대시보드 · [09:14](https://youtu.be/Lkk2ubF1AZ8?t=554)
- **3줄 요약**
  - 포트 4860 링크 → 어드민 로그인 → 대시보드(터미널 없이 CLI 헤르메스 사용). 호스팅어 제공 API는 비용 → **ChatGPT 구독 시 코덱스 연동**.
  - 오픈AI **OAuth는 대시보드에서 못 하고** 도커 컨테이너 터미널에서 제공 커맨드 실행 → URL+코드로 계정 로그인 → 리프레시하면 연동, 모델을 **코덱스 5.5(GPT-5.5)**로 스위치.
  - 대시보드에서 파일·스킬·플러그인·채널 관리, **프로파일에서 description·soul.md**(에이전트 성격·작동 방식) 설정.
- **핵심 인용**: "터미널에 들어갈 필요 없이 그냥 이 대시보드 여기서 … 바로 쓰실 수가 있어요."
- **내 팁**: soul.md는 에이전트의 페르소나(이름·톤·작동 규칙) — 프로필별로 여러 '직원'을 만들 수 있다.

## 5. ★데스크톱 앱 + 테일스케일 사설망 + 포트 열기★ · [13:19](https://youtu.be/Lkk2ubF1AZ8?t=799)
- **3줄 요약**
  - hermes AI.net/desktop에서 앱 설치(클로드 코드·코덱스와 유사 UI: 세션·모델·스킬·메시징·아티팩트·직원 선택·터미널). 핵심 설정 = **게이트웨이**(로컬 vs 리모트).
  - **테일스케일**로 원격 연결: tailscale.com 다운로드·로그인 → 내 노트북 자동 등록, 호스팅어 터미널(루트)에서 테일스케일 설치+`tailscale up`+로그인 → **같은 계정으로 노트북·VPS 연결**.
  - 도커 접근 위해 **포트 열기**: YAML 편집기에서 `"<VPS IP>:9119:4860"` 추가(9119=앱 접속 포트, 4860=컨테이너 헤르메스 포트) → 배포.
- **핵심 인용**: "내 실제 작업은 VPS 컴퓨터에서 돌아가는 거고 요거를 테일스케일이라는 사설 망으로 연결을 해 주는 거다."
- **내 질문**: 테일스케일 사설망 vs 공개 인터넷+OAuth — 개인용은 사설망이 안전한데, 팀 공유 시엔 어느 쪽이 맞을까?

## 6. 백엔드 실행 + 리모트 게이트웨이 연결 · [20:19](https://youtu.be/Lkk2ubF1AZ8?t=1219)
- **3줄 요약**
  - 헤르메스만 설치됐지 백엔드는 미실행 → 대시보드 세션에서 "리모트 게이트웨이로 테일스케일 IP:9119 연결하고 싶다, `hermes serve`로 열어라" **요청** → 에이전트가 셋업하고 넣을 주소를 알려줌.
  - 데스크톱 앱 설정 → 게이트웨이 → **리모트 게이트웨이**에 IP 입력 → Save & Reconnect → 어드민 아이디·패스워드로 사인 → 연동 완료.
  - 리모트라 문서는 **VPS의 파일**(내 로컬 아님)인데도 앱에서 프리뷰·수정 가능. 세션을 '프로젝트'로 전환해 폴더별 관리.
- **핵심 인용**: "내 로컬 파일이 아닌데도 이렇게 연동을 해 놨기 때문에 프리뷰하고 수정하고 요런 작업도 바로 이 앱에서 할 수 있기 때문에 굉장히 편리합니다."
- **내 팁**: `hermes serve`는 구버전에서 작동 안 할 수 있어 신규 버전 업데이트 필요.

## 7. 텔레그램 연동 + 멀티 직원 + 마무리 · [25:55](https://youtu.be/Lkk2ubF1AZ8?t=1555)

  - 기존 프로필(자비스·헤밍웨이·뉴턴)은 **게이트웨이 URL만 변경**해 여러 직원 전환. 슬랙과 달리 세션 '+'로 다른 작업을 별도 요청하기 편하고, 외부(슬랙·텔레그램) 작업도 앱에서 이어서.
  - 크론 잡·이력·툴콜 확인, 스킬·메모리가 슬랙·텔레그램과 **싱크**. 정리: VPS 24시간 배포 + 테일스케일로 노트북·백엔드 연동 → 노트북 꺼도 24시간·어디서든·보안 유지.
- **핵심 인용**: "내 노트북이 꺼져 있더라도 24시간 동안 이제 헤르메스 에이전트가 돌아갈 수 있고요."
- **내 질문**: 로컬 작업이 슬랙·텔레그램 채널과 스킬·메모리까지 싱크된다는 건, '어디서 접속하든 같은 직원'이라는 경험 — 개인 AI 인프라의 이상적 형태 아닐까?

## TL;DR (5줄)

1. **목표**: 헤르메스 데스크톱 앱을 로컬이 아니라 **VPS 백엔드에 연동**해 노트북이 꺼져도 도는 24시간 AI 직원.
2. **구조**: 노트북 데스크톱 앱(조종석) + VPS 도커 헤르메스(엔진) + **테일스케일 사설망** 연결.
3. **배포**: 호스팅어 VPS(KVM2·우분투 24.04·쿠폰) → 도커 **원클릭 배포** → 터미널에서 **오픈AI 코덱스 OAuth** 연동(코덱스 5.5).
4. **연결(★)**: 데스크톱 앱 설치 → 테일스케일로 노트북·VPS 같은 계정 연결 → YAML로 **포트 9119→4860** 열기 → `hermes serve` → **리모트 게이트웨이** 연결.
5. **활용·장점**: soul.md로 직원 페르소나, 텔레그램 연동, 멀티 직원(URL 전환), 크론·이력 확인. 노트북 꺼도 24시간·어디서든·로컬 보안 유지·스킬/메모리 싱크(단 월 비용).
