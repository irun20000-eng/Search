# 노가다 끝! 클로드로 영상 공장 완성 (ft. 캡컷, 리모션) | AI 영상 자동화

> 한 줄 요약: 영상 편집 노가다를 **클로드가 소스 파일을 만들고 편집 프로그램에 넣기만** 하는 흐름으로. 클로드 앱의 **채팅·코드** 두 메뉴만 사용. **3가지 효과 레시피**: ①**카운팅/카운트다운 숫자**(채팅에 "0→10 카운팅 SRT 파일" → 캡컷 타임라인에 드래그 → 속도↑, ★파일명 끝 **.srt** 확인 — txt면 안 열림) ②**형광펜 하이라이트**(코드 메뉴에 이미지+프롬프트, OCR로 텍스트 위치 잡아 강조 단어 위에 형광 효과 → 렌더 → 캡컷) ③**박스 순차 등장 애니메이션**(리모션 필요 — 클로드 코드가 만든 코드를 실제 영상으로 뽑는 도구). 리모션은 **노드JS 설치(MSI)→`node -v` 확인→클로드 코드 메뉴에서만 설치**(채팅·코워크 불가). 핀터레스트 레퍼런스+프롬프트로 몇 분 만에 애니메이션, **"배경 투명하게"**로 캡컷용 MP4. 한국어도 프롬프트+이미지만으로. **핵심 3원칙: ①프롬프트 먼저 지키기 ②숫자로 수정 요청 ③저장 포맷 확인**. 처음엔 다르게 나와도 말로 수정하면 금방.

## 1. ★셋업 + 효과① 카운팅/카운트다운 SRT★ · [00:35](https://youtu.be/2l4s9yS_q6k?t=35)
- **3줄 요약**
  - 클로드 앱 설치(앱이 웹보다 편함). 좌측 상단 **채팅·코워크·코드** 중 오늘은 **채팅과 코드만**.
  - **효과①**: "0에서 10까지 올라가는 카운팅 숫자 **SRT 파일** 만들어줘"(달러·%·만원 단위 붙이기 가능). 캡컷 타임라인에 드래그→자막 레이어→폰트·크기·색 바꾸고 **속도 조절로 빠르기↑**.
  - **카운트다운**은 "카운팅→카운트다운, 60에서 1로" 한 줄만 변경. 영상 시작 전 or 광고 타임 활용.
- **핵심 인용**: "파일 이름 끝에 SRT가 붙어 있는지 꼭 확인해 주세요. txt 파일로 저장되면 다음 단계에서 안 열립니다. 제일 자주 실수하는 포인트."
- **내 팁**: '.srt vs .txt' 저장 함정은 이 프로젝트 LESSONS의 실수 모음과 같은 성격 — 자동화는 이런 사소한 포맷 검증에서 갈림(카드뉴스 편의 '파일명 영문'과 동류).

## 2. ★효과② 형광펜 하이라이트 (코드 메뉴 + OCR)★ · [02:21](https://youtu.be/2l4s9yS_q6k?t=141)
- **3줄 요약**
  - 텍스트 위로 형광펜이 올라오는 강조 효과. 클로드 **코드** 메뉴에서 새 섹션, 이미지 드래그+프롬프트(이미지 불러와 **OCR로 텍스트 위치**를 잡고 강조 단어 위에 형광).
  - **바꿀 부분은 강조 단어 하나**(예: '천만'), 나머지 프롬프트는 그대로.
  - 클로드 코드가 작업 권한 요청 → 귀찮으면 자동 모드/"항상 허용". 이미지를 못 읽으면 경로(바탕화면 폴더)에 직접 넣기. 렌더 버튼→캡컷 타임라인에 올려 위치.
- **핵심 인용**: "이미지를 불러오고 OCR로 텍스트 위치를 잡은 다음 (강조 단어) 위로 형광 효과를 만들어 달라는 내용입니다."
- **내 질문**: 'OCR로 위치 잡아 그 위에 효과'는 큐레이션 디자이너 DK의 브라우저 셀렉트와 같은 계열 — 좌표를 말로 지정하는 대신 AI가 요소를 인식하는 패턴 아닐까?

## 3. ★효과③ 준비 — 리모션 + 노드JS 설치★ · [04:11](https://youtu.be/2l4s9yS_q6k?t=251)
- **3줄 요약**
  - 본격 모션그래픽은 **리모션**(클로드가 만든 코드를 실제 영상 파일로 뽑는 도구) 필요. 리모션 전에 **노드JS 설치**.
  - 노드JS: 구글 검색→공식사이트→도커 말고 아래로 내려 **MSI 설치 프로그램** 버튼→다음/완료(기본값). 확인: 터미널(맥 스팟라이트/윈도우 cmd)에서 **`node -v`**→숫자 나오면 성공(안 되면 재부팅).
  - 리모션은 **반드시 클로드 코드 메뉴에서 설치**(채팅·코워크 불가). 명령어 붙여넣기→템플릿은 **헬로 월드**→패키지 설치 완료→명령어 한 번 더. **처음 한 번만**.
- **핵심 인용**: "리모션은 반드시 코드 메뉴에서 설치해야 합니다. 채팅이나 코워크에서 설치하려고 하면 작동이 안 됩니다."
- **내 팁**: '노드JS→리모션→MP4'는 이 갤러리 데키랩 영상 자동화 계열과 같은 코드 렌더 파이프라인 — 비개발자가 넘어야 할 환경 설치 단계를 친절히 분해.

## 4. ★효과③ 실행 — 박스 순차 애니메이션 + 투명 배경★ · [05:56](https://youtu.be/2l4s9yS_q6k?t=356)
- **3줄 요약**
  - **레퍼런스 이미지**를 핀터레스트에서 검색·저장 → 클로드 코드에 드래그+프롬프트. **바꿀 부분은 `place this titles within them` 뒤 박스 텍스트** 하나. 완성되면 브라우저 미리보기 자동(몇 분).
  - 캡컷용으로 **"배경을 투명하게 해줘"**(박스는 어색하지 않게 유지)→내보내기 MP4. **한국어도 프롬프트+이미지만으로**(클로드 이미지+세 카드/네 토글 순차 등장 예시, 글자 안 깨짐).
  - 이미지가 반영 안 되면 실제 파일을 클로드가 요청하는 위치(퍼블릭 폴더)에 넣기. 일일이 애니메이션·모션그래픽 편집 불필요.
- **핵심 인용**: "여러분이 바꿔야 될 부분은 딱 하나입니다. place this titles within them 뒤에 박스 안에 넣고 싶은 텍스트를 써 주시면 됩니다."
- **내 질문**: '프롬프트에서 딱 한 곳만 교체'는 큐레이션 스티브(카드뉴스)·오빠두엑셀(템플릿 양산)과 같은 템플릿화 — 재사용 프롬프트에 변수 하나만 노출하는 실무 설계 아닐까?
