# 누구나 따라하는 25분 완성 클로드코드 가이드 — 나만의 주식 AI 대시보드 만들기

> 한 줄 요약: 코드 한 줄 없이 클로드 코드로 '나만의 애널리스트 비서'(주식 뉴스 대시보드)를 만드는 라이브. VS Code 확장 설치 → 독립 디렉토리 세팅 → **프로젝트 지침(하네스)으로 설계 문서(.md) 생성 → @참조로 에이전트 구현** → 네이버 검색 API 키 발급(.env) → 키워드별 뉴스 실시간 대시보드 → design.md(슬랙) 스킬로 디자인까지. 핵심 메시지는 "코딩 실력이 아니라 **원하는 것을 명확히 정리·전달하는 능력**(가비지 인 가비지 아웃)".

## 1. 코드 한 줄 없이 만드는 클로드코드 에이전트 — 인트로 · [0:00](https://youtu.be/3Q9Gg75Ob4o?t=0)
- **3줄 요약**
  - 완성 데모 먼저 보여줌: 기업을 월별·일자별 소팅, 키워드 추가, 업데이트 버튼으로 실시간 뉴스 반영.
  - 오늘 목표 = 클로드 코드로 나만의 에이전트를 **설치→API 연결→대시보드**까지 라이브 구축(60대도 따라할 수준).
  - 유일하게 필요한 능력: "내가 뭘 원하는지 **말로 잘 설명**하는 것"(코딩 실력 아님).
- **핵심 인용**: "코딩 실력이 아니라, 글을 통해서 내가 원하는 것을 전달하는 것입니다."
- **내 질문**: '설명 능력'이 곧 실력이 되는 시대에, 요구사항 정의(스펙 라이팅)가 새로운 코어 스킬 아닌가?

## 2. 시작 전 이것부터 세팅 — VS Code 확장 + 독립 디렉토리 · [0:47](https://youtu.be/3Q9Gg75Ob4o?t=47)
- **3줄 요약**
  - 클로드 데스크탑 다운로드 페이지 → VS Code 확장에서 **엔트로픽 공식 '클로드 코드 for VS Code'**(다운로드 ~2천만) 설치. 프로 요금제 필요.
  - VS Code 내 실행 두 방식: **익스텐션 대화창**(발표자 선호, 글 읽기 편함) vs **터미널**(가볍고 기능 다양하나 비개발자엔 덜 직관적).
  - **에이전트마다 독립 디렉토리**('주식 대시보드')를 새로 만들어 작업 → 다른 파일과 혼재 방지(발표자는 5~6개 창 병행).
- **핵심 인용**: "각각 목적에 맞는 디렉토리를 명확하게 구분해 두시고 독립적으로 수행하시는 거를 추천."
- **내 팁**: 화면 3분할 멘탈모델 — 좌(파일=사물함)·중(채팅=작업)·우(문서 뷰어). 모드는 플랜/오토/바이패스/매뉴얼로 권한 조절.

## 3. 잠도 안 자는 나만의 비서 — 무엇을 시킬까(기능 리스트업) · [7:56](https://youtu.be/3Q9Gg75Ob4o?t=476)
- **3줄 요약**
  - 만들 것 = '애널리스트 비서': 매일 아침 내 종목 시세·뉴스를 읽어 대시보드에 브리핑.
  - 기능 3개를 리스트업: ① 키워드(삼성전자·SK하이닉스·엔비디아)별 네이버 뉴스 데일리 분류 ② 대시보드 내 신규 키워드 추가 ③ '업데이트' 버튼으로 현시간 기준 실시간 동기화.
  - 이 리스트를 한 채팅창에 넣고 **플랜 모드**로 "구현 에이전트 만들어 줘" → 10~15분 뒤 구현 계획·아키텍처 산출(복잡).
- **핵심 인용**: "이 친구는요. 잠도 안 자고요. 매일 아침 내 종목의 시세를 확인해 주고요."
- **내 질문**: '반복하는 나의 정보 소비 루틴'을 그대로 자동화 대상으로 삼는 접근 — 나의 어떤 루틴이 대시보드화 가능한가?

## 4. ★여기서 대충하면 결과물이 무너진다 — 하네스 지침 설계★ · [10:20](https://youtu.be/3Q9Gg75Ob4o?t=620)
- **3줄 요약**
  - '가비지 인 가비지 아웃': ① AI는 **내가 정한 범위 안에서만** 움직임(대충 시키면 대충) ② 컨텍스트가 길어지면 **누락** → **CLAUDE.md로 복귀 시스템** 마련 ③ 워크플로를 작게 쪼개 투두로.
  - 클로드 데스크탑 '프로젝트'에 **'맞춤형 대시보드' 지침**(목적·입력·출력 양식·제약조건 + 하네스 스펙 + 폴더구조=스킬/에이전트/아웃풋 분리)을 넣어둠.
  - 이 지침이 **역질문**(뉴스 수집 방식→네이버 검색 API / 분류 방식→빠른 결정적 / 업데이트 방식→수동)으로 내 의도를 끌어내 **설계 문서(.md)** 생성 → 디렉토리에 저장 후 **@참조로 에이전트 구현**.
- **핵심 인용**: "채팅창에만 지시를 하게 되면 이 채팅창을 끄게 되면은 에이전트는 이 맥락을 잊어버리거든요."
- **내 팁**: 지침 자체도 클로드와 대화하며 만든다. 레퍼런스는 '일잘러 장피' 유튜브 → 자기 기능 추가 → 하네스로 누락 개선.

## 5. API 키 발급, 겁먹을 필요 없다 — 네이버 검색 API + .env · [15:23](https://youtu.be/3Q9Gg75Ob4o?t=923)
- **3줄 요약**
  - 스킬·서버·지침서 문서 생성 완료 → "네이버 개발자 센터 키를 넣어 주세요". 키 발급도 채팅에 "어떻게 발급받아?"로 물어 절차 안내받음.
  - 네이버 개발자 센터 → 애플리케이션 등록 → 사용 API '검색' + 환경 '웹 설정'(URL도 에이전트가 알려줌) → **클라이언트 아이디(공개OK) + 시크릿 키(보안 필수)**.
  - 키는 **.env 파일**에 저장. 네이버 앱 무료 한도 **하루 25,000회**(초과 시 과금 가능 → 시크릿 키 유출 주의).
- **핵심 인용**: "발급받은 값은 .env 파일에 넣으면 됩니다."
- **내 질문**: 막히는 지점(API·URL)마다 에이전트에게 되물어 진행하는 '대화형 온보딩' — 문서 안 읽고도 진행되는 게 축복이자 함정 아닐까?

## 6. 드디어 열어본 블랙박스 — 실동작 + UI 반복 개선 · [18:55](https://youtu.be/3Q9Gg75Ob4o?t=1135)
- **3줄 요약**
  - localhost 대시보드는 **내 데스크탑에서만** 열림(공유해도 본인만). 가이드를 안 줬으니 결과는 블랙박스 — 엔비디아·삼성전자·테슬라 키워드 추가 시 관련 기사 리스트업(오늘 날짜 기준).
  - 첫 UI가 불편 → "**월별·일자별 블록형**으로 변경", "**매일경제 뉴스만 필터링**" 등 반복 지시로 개선.
  - 같은 명령도 LLM은 블랙박스라 결과가 사람마다 다름 → **사용 의도를 전달**하면 선호에 맞게 조정 가능.
- **핵심 인용**: "같은 명령어를 입력했다라고 하더라도 LLM과 AI는 블랙박스이기 때문에 동일하게 나올 수가 없습니다."
- **내 팁**: 디자인·레이아웃은 한 번에 안 됨 → 헤더 좌측 이동, 배경 흰색, 회사별 접이식 블록 등 구체적 레이아웃을 짚어 반복.

## 7. 미감 없어도 따라하는 디자인 꿀팁 — design.md(슬랙) 스킬 · [20:54](https://youtu.be/3Q9Gg75Ob4o?t=1254)
- **3줄 요약**
  - '볼트 에이전트' 오픈소스 **디자인 키트(design.md)** — 유명 브랜드의 색감·타이포·폰트·버튼 규정을 그대로 가져옴. 코드 복사 → 신규 세션에 "프로젝트 경로에 다운받아 줘".
  - 발표자는 **슬랙**의 usage 부분을 복사("보라 버튼·파스텔 톤·직관적 폰트") → "이 디자인을 내 레이아웃에 적용해 줘".
  - 최종: 매경 필터 + 슬랙 디자인을 동시 적용, 회사별 접이식 블록, 실시간 업데이트(7/7 오후 9시 1분 뉴스까지 반영, 키워드 1초 추가). **코드 한 줄도 안 침**.
- **핵심 인용**: "이런 식으로 자유자재로 만들 수 있다라는 것이 바이브 코딩의 정말 핵심입니다. 코드 전혀 한 줄도 안 쳤죠."
- **내 질문**: 브랜드 design.md를 '테마 팩'처럼 갈아끼우는 방식은, 내 프로젝트에도 재사용 가능한 디자인 자산이 될 수 있지 않을까?

## TL;DR (5줄)

1. **목표**: 코드 없이 클로드 코드로 '주식 뉴스 애널리스트 비서' 대시보드 구축(설치→API→디자인 라이브).
2. **세팅**: VS Code 공식 확장(익스텐션 대화창 선호) + **에이전트별 독립 디렉토리**, 화면 3분할·권한 모드(플랜/오토) 이해.
3. **핵심(★)**: 가비지 인 가비지 아웃 — 프로젝트 **지침(하네스)**으로 설계 문서(.md)를 뽑고 **@참조로 구현**, CLAUDE.md로 컨텍스트 누락 방지.
4. **연결**: 네이버 검색 API 키를 **.env**에 저장(무료 25,000회/일, 시크릿 키 보안), 막히면 채팅에 되물어 진행.
5. **개선**: UI는 블랙박스라 사람마다 다름 → 의도·레이아웃을 반복 지시, **design.md(슬랙)** 스킬로 브랜드 디자인까지 코드 없이 적용.
