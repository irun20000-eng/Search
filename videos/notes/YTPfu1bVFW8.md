# "이게 공짜라고?" 쇼츠 자동화: 글만 넣으면 영상+목소리까지 완성 (클로드 코드)

> 한 줄 요약: **클로드 코드(Claude Code)**와 코드로 조작하는 영상 편집기 **리모션(Remotion)**을 결합하고, **클리피(Klipy) API** 기반 자막·움짤 자동 배치, **오픈AI 위스퍼(Whisper)** 음성 동기화, 그리고 피노키오로 설치한 무료 로컬 **QN3 TTS 보이스 클로닝**을 통합하여 텍스트 대본 입력 한 줄만으로 영상, 목소리, 자막, 모션 그래픽이 일괄 완성되는 무인 숏폼 제작 파이프라인을 구축한다.

 - AI를 주체적 뇌로 삼지 않고 사용자의 **명확한 의도를 실행하는 손발**로 제한하여 운용한다.
- **핵심 인용**: "ai 시대의 진짜 경쟁력은 툴을 다루는 기술이 아닙니다 그 툴로 무엇을 할지 생각하는 설계 역량입니다."
- **내 팁**: 파이프라인 구축 전 단순 반복 업무와 AI 창의 영역을 명확히 구분하는 설계도를 먼저 작성한다.

## 2. 코드로 편집하는 AI 전용 영상 편집기 리모션(Remotion) 도입 · [02:19](https://youtu.be/YTPfu1bVFW8?t=139)
- **3줄 요약**
 - **리모션(Remotion)**은 마우스 타임라인 방식이 아닌 **React 코드로 영상을 편집**하는 AI 전용 도구다.
 - 풀 영상 컷편집 대체용이 아닌 **인트로 모션 그래픽 및 데이터 시각화 애니메이션**에 특화되어 있다.
 - 클로드 코드에 리모션 스킬셋을 학습시켜 대본 입력만으로 **영상 편집 코드를 자동 생성**한다.
- **핵심 인용**: "리모션은 쉽게 말해서 코드로 조작하는 AI를 위한 영상 편집기라고 생각을 하시면 됩니다."
- **내 질문**: 리모션의 React 코드 기반 렌더링 시 고해상도 모션 그래픽의 비디오 출력 처리 속도가 궁금하다.

## 3. ★클리피(Giphy/Klipy) GIF 움짤 검색 및 위스퍼 음성 동기화★ · [06:17](https://youtu.be/YTPfu1bVFW8?t=377)
- **3줄 요약**
 - **클리피(Klipy) API 키**를 발급받아 텍스트 문맥에 상응하는 **GIF 움짤**을 자동 검색 및 배치한다.
 - 녹음 오디오 파일을 **오픈AI 위스퍼(Whisper)** 모델로 전달하여 자막 타임스탬프를 자동 동기화한다.
 - 클로드 코드 시스템 프롬프트(`claude.md`)에 **스프라이트·움짤 처리 가이드**를 등록하여 자동화한다.
- **핵심 인용**: "직접 녹음한 파일을 주고 그것으로 영상을 만들기 먼저 해봅시다 이것은 오픈 AI의 위스퍼를 쓸 겁니다."
- **내 팁**: 클리피(Klipy) API 키를 먼저 발급받아야 문맥에 맞는 GIF를 자동 검색·배치할 수 있다.

## 4. 피노키오 기반 로컬 QN3 TTS 보이스 클로닝 무제한 구축 · [09:41](https://youtu.be/YTPfu1bVFW8?t=581)
- **3줄 요약**
 - 유료 클라우드 서비스 대신 **로컬 open-source QN3 TTS** 모델을 컴퓨터에 직접 설치한다.
 - 원클릭 설치 도구인 **피노키오(Pinokio)**를 이용하여 코딩 없이 클릭 몇 번으로 AI 모델을 구현한다.
 - 3~10초 분량의 단기 음성 샘플을 전달하여 **내 목소리 기반 커스텀 보이스 클로닝**을 완료한다.
- **핵심 인용**: "11랩스 같은 서비스에 돈을 내고 쓰는 게 아니라 쉽게 말하면 TTS 전용 AI를 내 컴퓨터에 설치하는 방식입니다."
- **내 팁**: 피노키오로 QN3 TTS를 설치할 때는 원클릭 흐름을 그대로 따라가면 되고, 클로닝용 음성 샘플은 3~10초 분량이면 충분하다.

## 5. ★텍스트 입력 단 한 줄로 완성되는 풀 쇼츠 자동화 제작 파이프라인★ · [12:56](https://youtu.be/YTPfu1bVFW8?t=776)
- **3줄 요약**
 - **대본 텍스트 한 줄**을 클로드 코드에 전달하여 전체 자동화 프로세스를 가동한다.
 - QN3 TTS 보이스 생성, 위스퍼 동기화, 클리피 GIF 배치, 리모션 비디오 렌더링이 **원스톱 연결**된다.
 - 단순 도구 조합을 넘어 자신만의 사업 맥락이 녹아든 **고유 영상 자동화 시스템**을 완성한다.
- **핵심 인용**: "이렇게 텍스트만 줘도 자막 그래픽부터 움짤 TTS 보이스 편집까지 AI가 알아서 1부터 10까지 알아서 해주는 구조가 완성이 됐습니다."
- **내 팁**: 텍스트 입력만으로 영상이 추출되도록 리모션 렌더링 명령어까지 포함한 마스터 스크립트를 세팅해 둔다.

## TL;DR (5줄)
1. **설계 역량**: 자동화 도구 자체보다 무인 파이프라인의 전체 구조를 정의하는 설계 역량을 우선시한다.
2. **리모션 편집기**: React 코드로 제어되는 리모션을 도입하여 AI가 모션 그래픽 편집 코드를 자동 작성하게 한다.
3. **움짤·자막 동기화**: 클리피 API로 맥락 맞춤 GIF를 추출하고 위스퍼 모델로 자막 타임스탬프를 동기화한다.
4. **로컬 TTS 구축**: 피노키오 앱을 통해 QN3 TTS를 설치하고 3~10초 샘플로 내 목소리 보이스 클로닝을 구현한다.
5. **풀 쇼츠 자동화**: 대본 입력 단 한 줄로 음성, 움짤, 자막, 리모션 비디오 렌더링까지 풀 자동화 파이프라인을 완성한다.
