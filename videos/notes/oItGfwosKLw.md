# 노트북LM 그냥 쓰지 마세요! 무료 크롬 확장 프로그램 7가지로 활용도 200%

> 한 줄 요약: 노트북LM(내가 준 자료만 공부하는 '수석 비서')의 **자료 수집·정리**를 자동화하는 무료 크롬 확장 7가지 — ① Web Importer(웹·유튜브 1클릭 임포트) ② YouTube to NotebookLM(재생목록·채널 통째) ③ 그랩(Ctrl+우클릭 스크롤로 여러 링크 낚아채기) ④ **GoFullPage(전체 페이지 스크린샷 → 슬라이드·인포그래픽 재료)** ⑤ Link Source Automator(재생목록 링크 표로 안전 배치) ⑥ AI Sidebar(글 속 링크 골라 소스로) ⑦ BookShelf 폴더 매니저(드래그 정리).

## 1. 노트북LM이란 + 도구 설치법 · [00:00](https://youtu.be/oItGfwosKLw?t=0)
- **3줄 요약**
  - 제미나이=인터넷을 찾는 '만능 박사', **노트북LM=내가 준 자료만 공부하는 '수석 비서'**(넣은 책·뉴스·유튜브 안에서만 답 + 요약 + 오디오 오버뷰).
  - 도구는 모두 **크롬 웹스토어**에서 설치, 사용법 동일. 우측 상단 퍼즐 아이콘 → 핀으로 버튼 고정.
  - 이 비서 능력을 10배로 키우는 7개 확장 소개.
- **핵심 인용**: "노트북 LM은 오직 내가 준 자료만 가지고 공부하는 나만의 수석 비서."
- **내 팁**: 노트북LM의 병목은 '자료를 넣는 수고' — 확장들은 대부분 그 임포트/수집을 자동화한다.

## 2. ①Web Importer ②YouTube to NotebookLM — 임포트 자동화 · [01:38](https://youtu.be/oItGfwosKLw?t=98)
- **3줄 요약**
  - **① Web Importer**: 웹페이지·유튜브를 클릭 한 번으로 임포트, 오디오 오버뷰를 팟캐스트 피드로 동기화. '노트북에 추가'로 저장+요약, 가져온 자료로 오디오 오버뷰(팟캐스트) 생성.
  - **② YouTube to NotebookLM**: 유튜브 영상 즉시 추가 + **전체 재생목록·채널 추출**, 동영상 오버뷰로 요약·하이라이트. 수십 개 영상을 한 번에(주소 복사 불필요).
  - 가져온 영상들로 **동영상(비디오) 오버뷰**까지 간단 제작.
- **핵심 인용**: "재생 목록이나 채널에 있는 모든 영상을 한꺼번에 옮길 수 있어서 … 일일이 복사해서 붙여 넣는 수고를 하지 않아도 돼서."
- **내 질문**: '임포트→오디오/비디오 오버뷰'까지 원클릭이면, 콘텐츠 소비가 '수집→재생성'으로 바뀌는데 원저작자 맥락은 어디까지 보존될까?

## 3. ③그랩 — 여러 링크를 한 번에 낚아채기 · [04:54](https://youtu.be/oItGfwosKLw?t=294)
- **3줄 요약**
  - **③ 그랩(Grab)**: 텍스트 URL을 클릭 가능한 링크로 변환, 선택한 탭만 복사. 화면을 '낚아채서' 가져오는 개념.
  - 채널의 많은 영상을 하나하나 복사 말고 **Ctrl 누른 채 마우스 우클릭 + 아래로 스크롤** → 전부 네모 안에 잡혀 복사.
  - 노트북LM '소스 추가 → 웹·유튜브 URL'에 붙여넣으면 차르륵 추출(유튜브·웹사이트 모두).
- **핵심 인용**: "컨트롤 키를 누른 상태에서 마우스 오른쪽 버튼을 동시에 누르고 아래로 이렇게 쓱 스크롤 하면 이게 전부 네모 안에 다 잡혀요."
- **내 팁**: 여러 링크를 한꺼번에 소스로 넣는 게 목적이라면 그랩의 'Ctrl+우클릭 드래그'가 가장 빠른 수집 동작.

## 4. ★④GoFullPage — 전체 캡처로 슬라이드·인포그래픽 재료★ · [06:40](https://youtu.be/oItGfwosKLw?t=400)
- **3줄 요약**
  - **④ GoFullPage(고풀페이지)**: 카메라 버튼으로 페이지 맨 위~아래를 스크롤해 **큰 사진 한 장**으로 캡처(PNG/JPG/PDF).
  - 노트북LM에 넣어 요약하거나, **PPT·인포그래픽 재료**로 활용 — 예: 캔바에서 슬라이드 템플릿을 골라 GoFullPage로 전체 캡처.
  - 그 이미지 + 만들 자료를 노트북LM에 넣어 **슬라이드·인포그래픽을 한꺼번에 생성**(클릭 몇 번). "스크린 캡처 중 가장 편리".
- **핵심 인용**: "제일 위에서 제일 밑에까지 스크롤 해서 화면 전체를 커다란 사진 한 장으로 찰칵 찍어 줍니다."
- **내 질문**: 원하는 템플릿을 통째로 캡처해 '스타일 참조 이미지'로 주는 건, 앞 영상들의 '디자인 MD'와 같은 발상(레퍼런스를 재료화) 아닐까?

## 5. ⑤Automator ⑥AI Sidebar ⑦BookShelf — 대량 처리·관리 · [08:19](https://youtu.be/oItGfwosKLw?t=499)
- **3줄 요약**
  - **⑤ Link Source Automator**: 재생목록의 제목·링크를 **표로 정리**(추가 전 삭제 가능), '모두 추가' 시 하나씩 안전하게 배치 + 실시간 진행 + 멈춰도 이어서.
  - **⑥ AI Sidebar**: 글 속 파란 링크(예: 나무위키 각주)를 골라 소스로 넣음 — 필요한 서브 자료만 한꺼번에 정리.
  - **⑦ BookShelf 폴더 매니저**: 폴더 생성·드래그 앤 드롭 정렬(설정에서 한국어). 노트북을 원하는 폴더에 바로 → 나중에 찾기 편리.
- **핵심 인용**: "중간에 혹시 멈추더라도 하던 데부터 다시 시작하니까 속 터질 일도 없고요."
- **내 팁**: 대량 임포트는 컴퓨터가 멈추기 쉬운데, Automator의 '실시간 진행+재개'가 안정성을 준다.

## TL;DR (5줄)

1. **노트북LM**은 내가 준 자료만 공부하는 수석 비서 — 병목은 '자료 수집·정리', 이를 확장 7개로 자동화.
2. **임포트**: ① Web Importer(웹·유튜브 1클릭+오디오 오버뷰) ② YouTube to NotebookLM(재생목록·채널 통째, 동영상 오버뷰).
3. **수집**: ③ 그랩(Ctrl+우클릭 스크롤로 여러 링크 낚아채기) ⑥ AI Sidebar(글 속 링크만 골라 소스).
4. **재료화(★)**: ④ GoFullPage로 페이지·템플릿을 전체 캡처 → 노트북LM에서 슬라이드·인포그래픽 생성.
5. **관리**: ⑤ Link Source Automator(재생목록 링크 표·안전 배치) ⑦ BookShelf(폴더 드래그 정리). 링크는 영상 더보기란.
