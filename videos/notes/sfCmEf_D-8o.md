# 코딩 0줄로 200만원짜리 홈페이지 만들기 (AI 티 안 나는 비법 공개)

> 한 줄 요약: 외주 수백만 원짜리 홈페이지를 **클로드 코드 + frontend-design 공식 스킬**로 코딩 없이. "화장품 웹사이트 만들어 줘"만으론 **AI 티**가 나므로, ① **frontend-design 스킬**(뻔한 디자인 회피 + 자기검증)을 설치하고 ② **구글 Flow로 무료 포토리얼 이미지·영상**을 만들되 **프롬프트는 클로드에 '공통 스타일 앵커'로 생성**시켜 톤 일관 ③ 이미지·영상을 폴더에 넣고 **오토 모드**로 "외주 수준으로" 요청 ④ 캡처 첨부로 수정, 클로드에게 개선점 역질문, **21st.dev류 효과 프롬프트 복붙**, 레퍼런스 사이트 캡처로 따라 만들기 ⑤ **Netlify 드래그로 배포**. 핵심은 개발 지식이 아니라 **'무엇을 만들지' 내용만 말하는 것**.

## 1. 문제 — 그냥 시키면 AI 티, frontend-design 스킬 · [00:00](https://youtu.be/sfCmEf_D-8o?t=0)
- **3줄 요약**
  - 외주 수백만 원 웹사이트를 코딩 없이 말로만. "화장품 웹사이트 만들어 줘"는 깔끔하지만 **누가 봐도 AI 티** → 외주 수준엔 부족.
  - 해결: **frontend-design(클로드 공식 스킬)** 설치 — 클로드가 **뻔한 디자인을 피하고 결과물을 자기검증**하며 디테일을 챙기게 구조화됨.
  - "이 스킬 설치해 줘"로 바로 설치 후 활용.
- **핵심 인용**: "이 스킬을 사용하면 클로드가 … 스스로 뻔한 디자인은 만들지 않으려고 노력하고 … 계속해서 자기 검증을 거치기 때문에 AI 티가 안 나는 결과물."
- **내 팁**: frontend-design 스킬은 앞 영상(잭피디)에서도 첫 번째로 설치한 것과 동일 — 'AI 티 제거'의 공통 1순위 도구.

## 2. ★무료 포토리얼 이미지 — 구글 Flow + 클로드 프롬프트★ · [02:43](https://youtu.be/sfCmEf_D-8o?t=163)
- **3줄 요약**
  - 이미지의 80%가 퀄리티를 결정(앞 영상들과 동일) → **구글 Flow로 무료** 이미지·영상 제작(류칸/고급 숙소 예시).
  - 프롬프트는 클로드에 위임: "포토리얼·색·톤·무드가 모두 유사한 이미지 프롬프트 만들어 줘" → 클로드가 **공통 스타일 앵커**를 분리해 각 프롬프트에 붙여 코드 블록으로 → 톤 일관.
  - Flow에 붙여 16:9 생성 → 애니메이션 적용으로 영상까지. (모델·스튜디오·촬영 수백만 원 작업을 무료로 대체.)
- **핵심 인용**: "공통 스타일 앵커를 붙여서 바로 복사할 수 있도록 코드 블록을 각각 만들어 달라고."
- **내 질문**: '공통 스타일 앵커로 이미지 톤 통일'은 앞 영상(힉스필드 레퍼런스 시트, 모션그래픽 스타일 시트)의 '일관성 자산화'와 정확히 같은 발상 아닐까?

## 3. 제작 — 폴더에 에셋 + 오토 모드로 "외주 수준" · [05:37](https://youtu.be/sfCmEf_D-8o?t=337)
- **3줄 요약**
  - 만든 이미지·영상을 **프로젝트 폴더에 첨부** → "외주 수준으로 디테일 살리고 폴더 안 이미지·영상 활용해 웹사이트 제작해 줘".
  - **오토 모드**(입력창 하단): 매번 허가 묻는 걸 없앰 — 웬만한 수정은 클로드가 알아서, 꼭 필요할 때만 되물음.
  - 결과: 예약 사이트 레이아웃을 갖추되 AI 느낌 없이, 에셋을 자연스럽게 녹인 산출물. 다국어·요금 캘린더·결제·예약을 붙여 실사용으로 발전 가능.
- **핵심 인용**: "이미지 영상 몇 장만 쥐어주고 웹사이트 만들어 줘라고만 요청한 것뿐인데 … 너무 뛰어난 결과물."
- **내 팁**: '오토 모드'는 앞 영상(스펙주도개발의 새 세션·자동 진행)과 대비되는 편의 기능 — 단, 자기검증 없는 자동 진행은 검수 필요(다음 섹션).

## 4. 수정 — 캡처 첨부·역질문·효과 복붙·레퍼런스 따라하기 · [07:45](https://youtu.be/sfCmEf_D-8o?t=465)
- **3줄 요약**
  - 첫 결과 후 입맛대로 수정: 한 페이지를 기능별 여러 페이지로 분리, **바꿀 부분을 캡처 첨부** → 클로드가 어떻게 고칠지 먼저 물어보고 제안.
  - **역질문**: "훑어보고 추가·수정할 점 제안해 줘" → 클로드가 문제·개선점 제시. **핵심은 개발 지식이 아니라 '무엇을 만들지' 내용만 말하는 것**.
  - **효과 라이브러리(21st.dev류)**: 스크롤 화면 전환 등 'Copy Prompt' → 클로드에 붙여 적용. **레퍼런스 사이트를 위→아래 캡처 첨부**해 그 느낌으로 따라 만들기.
- **핵심 인용**: "저는 웹사이트 개발에 필요한 지식은 전혀 이야기하지 않고 있고 … 들어갈 내용에 대해서만 이야기하고 있다."
- **내 질문**: 효과 복붙·레퍼런스 캡처는 앞 영상(잭피디 21st.dev, Jay Choi Firecrawl 추출)과 같은 '규칙 가져오기' 계열 — 도구만 다르고 발상은 동일 아닐까?

## 5. 배포 — Netlify 드래그 + 모바일 확인 · [11:19](https://youtu.be/sfCmEf_D-8o?t=679)
- **3줄 요약**
  - 개발한 사이트는 내 PC에서만 실행 → **배포**로 남에게 공개. "다른 사람도 볼 수 있게 배포하자"로 클로드에 요청(GitHub 등 여러 방법).
  - 이 영상에선 **Netlify**에 프로젝트 폴더를 **드래그&드롭** → 비밀번호와 함께 접근 가능한 링크로 배포(일정 시간).
  - **모바일 환경에서도 안 깨지고** 잘 나옴. 판매뿐 아니라 포트폴리오·가족·기념일 홈페이지도 쉽게.
- **핵심 인용**: "코드를 단 한 줄 치지 않고도 클로드를 통해 나만의 웹사이트를 개발하고 배포하는 과정까지."
- **내 팁**: 배포는 앞 영상(잭피디 Vercel, 인스타 GitHub 저장소)과 같은 마지막 단계 — 이 영상은 **Netlify 드래그**라는 더 쉬운 대안 제시.

## TL;DR (5줄)

1. **문제**: "웹사이트 만들어 줘"만으론 AI 티 → 외주 수준 불가. 해결의 1순위는 **frontend-design 스킬**(뻔한 디자인 회피+자기검증).
2. **이미지(★)**: **구글 Flow로 무료** 포토리얼 이미지·영상, 프롬프트는 클로드가 **공통 스타일 앵커**로 톤 통일.
3. **제작**: 에셋을 폴더에 넣고 **오토 모드**로 "외주 수준으로" 요청 → 에셋을 자연스럽게 녹인 결과.
4. **수정**: 캡처 첨부 수정, **클로드에 개선점 역질문**, 21st.dev류 효과 복붙, 레퍼런스 사이트 캡처로 따라 만들기. 핵심은 **'무엇을' 내용만 말하기**.
5. **배포**: **Netlify 드래그&드롭**으로 링크 공개(모바일도 OK). 판매·포트폴리오·기념일까지, 코딩 0줄.
