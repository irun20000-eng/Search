## 1. ★AI 브라우저 어사이드(Aside)의 개념과 리얼 워크(Real Work) 지향점★ · [00:00](https://youtu.be/9ZzF5iGj0BM?t=0)

  - 쿠팡에서 무선 청소기 정보를 수집해 구글 스프레드시트에 표 서식까지 맞춰 정리하는 시연을 통해 실효성을 입증한다.
  - 어사이드의 핵심 지향점은 단순 웹 탐색을 넘어 이미 로그인된 환경에서 복잡한 다단계 업무를 완수하는 **리얼 워크(Real Work)**에 있다.
- **핵심 인용**: "어사이드가 특히 강조하고 있는 건 단순히 웹사이트를 조작할 수 있다는 것보다는 브라우저에서 실제로 하는 업무를 AI에게 맡길 수 있다는 점입니다"
- **내 팁**: 텍스트 답변만 요구하는 일반 검색 프롬프트와 달리 내가 브라우저에서 마우스와 키보드로 수행하려던 행동 순서를 그대로 자연어로 설명해야 에이전트가 정확히 작업을 완수한다.

## 2. 어사이드 설치·구독 연동 및 탭 스타일 환경 설정 · [03:16](https://youtu.be/9ZzF5iGj0BM?t=196)

  - 자체 플랜 외에도 기존에 구독 중인 **ChatGPT·클로드 계정 또는 개별 API 키**를 직접 연동해 추가 비용 부담을 낮춘다.
  - 상단 가로 탭 방식인 **샌프란시스코**와 왼쪽 세로 사이드바 탭 방식인 **뉴욕** 스타일 중 작업 성향에 맞춰 UI를 전환할 수 있다.
- **핵심 인용**: "채지나 클로드 같이 이미 쓰고 있는 구독 플랜이 있으시면 기존 구독을 어사이드에 연결해서 사용할 수도 있습니다"

## 3. ★로컬 메모리 시스템과 에이전트 전용 패스워드 매니저★ · [05:33](https://youtu.be/9ZzF5iGj0BM?t=333)
- **3줄 요약**
  - 과거 방문했던 사이트와 작업 맥락을 기억해 어제 보았던 특정 후보자 프로필 검색과 같은 **연속적 문맥 명령**을 수행한다.
  - 브라우징 이력 데이터는 외부 클라우드 서버가 아닌 **사용자 기기 내부(Local)**에 저장되는 설계라고 영상은 설명한다.
  - **에이전트 전용 패스워드 매니저**를 탑재하여 AI 모델에 비밀번호 텍스트를 노출하지 않고 브라우저가 입력란을 자동 완성해 로그인한다.
- **핵심 인용**: "중요한 건 로그인 과정에서 비밀번호 자체를 AI 모델에게 보여 주는 방식이 아니라 브라우저가 필요한 입력란에 자동으로 채워주는 방식으로 동작한다는 점인데요"
- **내 팁**: 민감한 계정 정보 유출이 걱정된다면 로컬 메모리에 무엇이 쌓이는지 설정에서 먼저 확인하고, 자동 입력되는 비밀번호 관리자 연동 범위를 사내 업무 계정 위주로 선별 지정한다. 로컬 저장이라는 설명만으로 안전을 단정하지는 말 것.

## 4. 백그라운드 탭 실행 및 파일 접근 보안 권한 제어 · [08:37](https://youtu.be/9ZzF5iGj0BM?t=517)
- **3줄 요약**
  - 영상은 에이전트의 파일 접근 권한이 읽기 전용부터 전체 허용까지 **3단계**로 나뉘어 통제된다고 소개한다.
  - 결제나 메일 발송 등 실제 결과에 큰 영향을 미치는 액션 전에는 **파이널 컨펌(Final Confirm)**을 통해 사용자 승인을 요구한다.
  - 에이전트의 웹 조작은 **별도 백그라운드 탭**에서 비동기로 진행되어 사용자가 다른 탭에서 진행 중인 작업의 화면 포커스를 빼앗지 않는다.
- **핵심 인용**: "이런 에이전트 작업은 별도의 백그라운드 탭에서 진행되기 때문에 작업 과정을 확인하면서도 제가 사용하고 있는 화면에 포커스를 빼앗기지 않습니다"
- **내 팁**: 중요한 비즈니스 메일이나 결제 작업을 지시할 때는 반드시 가드 모드와 파이널 컨펌 옵션을 활성화해 메일 초안 작성까지만 위임하고 최종 발송은 직접 확인 후 처리한다.

## 5. 멀티 서비스 크로스 연계: Gmail 일정 확인 후 캘린더 자동 등록 · [10:23](https://youtu.be/9ZzF5iGj0BM?t=623)
- **3줄 요약**
  - 단일 웹페이지 조작을 넘어 **Gmail과 구글 캘린더** 등 서로 다른 웹서비스를 넘나들며 복합 업무를 완결한다.
  - 메일 본문에서 날짜, 시간, 장소, 안건을 추출한 뒤 캘린더로 이동해 세부 설명이 첨부된 **일정을 원스톱으로 생성**한다.
  - 작업을 쪼개서 반복 지시할 필요 없이 최종 목적을 담은 **단일 통합 프롬프트**만으로 모든 후속 단계를 알아서 연결한다.
- **핵심 인용**: "여기서 중요한 건 제가 메일을 찾아 줘 내용을 정리해 줘 캘린더를 열어 줘 일정을 만들어 줘 이렇게 각각 따로 요청한게 아니라는 점입니다 하나의 요청만 했는데 Gmail에서 필요한 정보를 확인하고 그 내용을 바탕으로 구글 캘린더로 이동해서 후속 작업까지이어서 처리한 거죠"
- **내 팁**: 서로 다른 2개 이상의 SaaS 서비스를 연동할 때는 각 서비스에 사전에 로그인 세션이 유지되어 있는지 먼저 확인한 후 통합 명령을 내려야 에이전트의 중간 이탈을 막을 수 있다.

## 6. 루틴(Routine) 자동화 및 스킬·MCP·CLI 확장 기능 · [12:14](https://youtu.be/9ZzF5iGj0BM?t=734)
- **3줄 요약**
  - 매일 아침 반복되는 정보 취합이나 모니터링 작업을 **루틴(Routine)**으로 등록해 매번 명령을 재입력할 필요 없이 자동 실행한다.
  - 사용자의 이전 작업 패턴을 스캔해 자주 쓰이는 웹 작업을 **자동 루틴으로 추천**받거나 대화 도중 즉시 루틴으로 등록할 수 있다.
  - 구글 계정 및 문서용 내장 스킬 외에도 **MCP(Model Context Protocol)** 연동과 개발자용 **CLI**를 지원해 클로드 코드 등과 연계 가능하다.
- **핵심 인용**: "반복적으로 해야 하는 브라우저 업무가 있다면 처음 한번 작업 방법을 정해 놓고 이후에는 루틴으로 자동화해서 사용하는 방식도 가능합니다"
- **내 질문**: 어사이드의 루틴 기능이 백그라운드에서 주기적으로 웹페이지를 모니터링할 때 특정 웹페이지 구조 변경이나 캡차(CAPTCHA) 발생 시 어떤 방식으로 사용자에게 알림을 전달하는가?

## TL;DR (5줄)
1. **행동 중심 AI 브라우저**: 어사이드는 텍스트 질의응답을 넘어 브라우저 내부에서 클릭, 탐색, 입력을 직접 대행하는 리얼 워크를 구현한다.
2. **비용 절감 및 호환성**: 맥OS를 우선 지원하며 북마크와 쿠키를 승계하고, 기존 보유한 ChatGPT·클로드 구독이나 API 키를 직접 연결해 사용한다.
3. **로컬 보안 아키텍처**: 브라우징 컨텍스트를 기기 내 로컬 메모리에 저장하고 비밀번호를 모델에 노출하지 않는 에이전트 패스워드 매니저를 보안 설계로 내세운다.
4. **안전한 백그라운드 제어**: 3단계 파일 권한과 최종 승인 기능을 제공하며 백그라운드 탭에서 작업이 돌아가 메인 브라우징 포커스를 침해하지 않는다.
5. **크로스 서비스 및 루틴**: Gmail 일정의 캘린더 등록처럼 다중 웹사이트 연계 작업을 단일 명령으로 처리하고 반복 업무를 루틴으로 자동화한다.
