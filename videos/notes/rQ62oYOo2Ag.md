# 클로드 CoWork으로 매일 2시간 아끼는 실무 활용법 (feat. 실무 레시피 팩)

> 한 줄 요약: 개발자용 클로드 코드가 아니라 **실무자용 CoWork(데스크탑 앱, 폴더 직접 접근)**로 회의록·영수증·엑셀·발표·계약서·대시보드·일정을 자동화하는 실전. 반복되는 규칙·프롬프트는 **스킬 MD**(내가 만들어야 함), 여러 기능 묶음은 **플러그인**, 외부 연동은 **커넥터**. 핵심 반복 메시지: **"첫째도 둘째도 셋째도 데이터"**, 모델은 작업에 맞게(오퍼스/소네트/하이쿠), 그리고 **"속도가 아니라 방향의 최적화"** + AX(업무 프로세스 재설계).

## 1. 클로드 3형제 + 크레딧 최적화 = 모델 선택 · [00:00](https://youtu.be/rQ62oYOo2Ag?t=0)
- **3줄 요약**
  - 앤트로픽(구글·오픈AI 출신)의 클로드 = 헌법적 AI로 안전·신뢰. 챗 / **CoWork(실무자용 데스크탑 앱)** / 코드(개발자용 CLI) 3형제.
  - 코드가 먼저 나왔지만 터미널이 불안한 사람을 위해 **CoWork**이 나옴 — "실무엔 CoWork 정도면 충분". 챗은 폴더 접근 불가, CoWork은 폴더 접근+자동화.
  - **크레딧 효율의 첫째 = 작업에 맞는 모델**: 오퍼스 4.7(최고 성능·최다 소모) / 소네트(중간) / 하이쿠(저비용, 단순 반복엔 충분). 다 오퍼스로 쓰면 크레딧이 활활 탐.
- **핵심 인용**: "한 번 쓰면 빠져나올 수 없는 클로드 CoWork."
- **내 팁**: '오퍼스가 좋다니 다 오퍼스'가 낭비의 주범 — 질문·텍스트는 하이쿠, 고퀄 디자인만 오퍼스.

## 2. 폴더 연결 + 스킬/플러그인/커넥터 · [06:46](https://youtu.be/rQ62oYOo2Ag?t=406)
- **3줄 요약**
  - 꿀팁 4: ① **폴더 먼저 연결**(자주 놓침, 바탕화면 폴더에 자료를 넣고 실습) ② 스킬(깃허브에 많음, 크리에이터로 직접 제작) ③ 커넥터(피그마·슬랙 연결) ④ 플러그인(마케팅 보이스 등 기능 묶음).
  - **스킬 vs 플러그인**: 스킬=레시피(반복 업무·회사 규칙·자주 쓰는 프롬프트 하나), 플러그인=주방 세트(여러 기능 한 번에). 다 설치하면 다 토큰 → 하나씩 테스트.
  - 반복 작업은 **스케줄**로 예약(에이전트). MCP 연동은 예전엔 하루 종일도 못 했는데 지금은 예스 몇 번으로 쉬움.
- **핵심 인용**: "남의 스킬 MD로는 내 일을 자동화할 수 없다. 나의 스킬 MD는 내가 만들어야 된다."
- **내 질문**: 스킬(개인 반복)과 플러그인(팀 단위 구성)의 경계 — 내 업무 중 무엇을 스킬로 굳히고 무엇을 플러그인으로 가져올까?

## 3. 문서 자동화 — 회의록·영수증·엑셀 · [10:37](https://youtu.be/rQ62oYOo2Ag?t=637)
- **3줄 요약**
  - 폴더 연결 후 파일명만 붙여 엔터 → 회의록 분석(안건·결정·액션 아이템), "워드로 만들어 줘" 하면 폴더에 바로 저장(다운로드 불필요, 수백 페이지도).
  - 영수증: "폴더의 모든 영수증을 엑셀로"(사진 1장에 영수증 2개까지 인식). "불명확은 '확인 필요', 중복은 '중복 의심'으로 표시"하면 임의로 안 하고 물어봄.
  - **보안 원칙**: 재무 파일은 이름·개인정보를 빼고 올림(매칭은 로컬), 회사명 든 재무제표 업로드 금지.
- **핵심 인용**: "이 작은 시간들이 모여서 제 삶을 풍요롭게 해 주는 거거든요."
- **내 팁**: 다운로드·업로드의 마이크로 시간을 없애는 게 폴더 접근의 진짜 가치 — 반복·단순부터 자동화.

## 4. 발표·보고서·검증 프롬프트 — 쪼개서 다듬기 · [18:30](https://youtu.be/rQ62oYOo2Ag?t=1110)
- **3줄 요약**
  - 발표는 한 번에 말고 **구조 설계→가이드 제안→슬라이드→메시지 재정리**로 쪼갤수록 퀄리티↑(글쓰기의 개요→글쓰기). 목표·타깃·핵심 메시지·시간 등 정보값을 많이 넣고, 말투(~임/~음)도 지정.
  - **주장 검증**: "냉정하게 — 내가 인식 못한 맹점·숨겨진 가정·잠재 리스크를 중점 분석"(AI는 너무 착함). **미래 예측**: "10년 다섯 시나리오+발생 가능성·파급력·촉발 요인".
  - 하이 퀄 디자인은 오퍼스 4.7(소네트와 차이 큼), 토큰 아끼려면 분량 먼저 지정.
- **핵심 인용**: "한 번 쓰고 바로 디자인을 절대 시키지 않습니다. 계속 시켜야 돼요."
- **내 질문**: '한 번에'가 아니라 '단계로 다듬기'가 품질을 만든다는 건, AI에게도 초안→퇴고의 인간적 창작 리듬이 유효하다는 뜻 아닐까?

## 5. 에이전트 자동화 — 뉴스 리포트·일정·일일 브리핑 · [22:41](https://youtu.be/rQ62oYOo2Ag?t=1361)
- **3줄 요약**
  - 매일 아침 **AI 뉴스 리포트**를 임시 저장함에(컴퓨터 유스 끄면 발송 안 함). "48시간 이내" 등 조건을 검. 프롬프트 세팅 후 테스트 방법까지 알려줌.
  - **일정 등록**을 가장 자주 씀(핸드폰 앱, 말로) — 연차 빼주고, 밥 시간·미팅 준비 시간까지 챙겨 "비서보다 나음". 캘린더+슬랙이 다 연결돼야 강력(슬랙에서 생긴 일정도).
  - 슬랙 **일일 브리핑**(매일 5:30, 문서·메시지·메일 통합 → 오늘 완료/내일 할 일, 발송 안 한 것도 알림).
- **핵심 인용**: "정말 비서보다 나아요."
- **내 팁**: 커넥터(캘린더+슬랙+Gmail) 통합이 자동화의 파워를 결정 — 단일 앱 연결로는 이 수준이 안 나옴.

## 6. ★디자인 MD + 클로드 디자인 = 데이터·자산의 힘★ · [28:28](https://youtu.be/rQ62oYOo2Ag?t=1708)
- **3줄 요약**
  - **디자인 MD**: 사이트 URL을 "분석해 디자인 시스템 만들어 줘" → 톤앤매너·컬러·폰트를 가이드로('흉내', 일반 PPT엔 충분). MD는 MarkText/MacDown·Reduct로 예쁘게. 크롬 확장으로 사이트의 디자인 MD를 뽑을 수도.
  - 실무 프로젝트는 폰트 H1 사이즈·볼드까지 일일이 지정 — "AI가 주는 걸 그대로 쓸 수 없다". 어려우면 **designmd.app**의 정리된 MD·컬러칩 활용.
  - **클로드 디자인**이 좋아진 건 '디자인 과정(타깃·목적 넣기)을 물어보는 기능'으로 옮긴 것 + 토큰 대량 소모. 피그마 가이드/깃허브 링크가 정리된 **자산 있는 팀이 AI도 잘 씀** = "첫째도 둘째도 셋째도 데이터".
- **핵심 인용**: "결국엔 자산이 있는 팀들은 AI도 잘 쓸 수밖에 없어요."
- **내 질문**: 디자인 MD가 '따라 만들기'라 카피가 쉽다면, 디자이너의 진짜 차별점은 MD를 '어느 환경에서든 잘 나오게' 설계하는 메타 역량 아닐까?

## 7. AX — 프로세스 재설계와 '방향의 최적화' · [37:02](https://youtu.be/rQ62oYOo2Ag?t=2222)
- **3줄 요약**
  - **AX** = 일하는 방식·의사결정·비즈니스 구조를 **AI 중심으로 재설계**(그냥 AI 쓰기가 아님). 실제로 순서가 바뀜(디자인 가이드를 맨 처음에). 컨설팅 시 20~30%는 '잘못 쓰는 것' 교정만으로 해결.
  - 핵심 = **데이터/학습**: 누군가의 머릿속에만 있는 안목을 데이터로 정리해 에이전트에 학습, 조직에 내재화돼야 AX(개인도 동일). "업무에 AI를 끼워넣는 방식은 과거".
  - "관리직은 사라지고 직접 일하는 사람만 살아남는다 / 에이전시는 멸망한다"(기업이 직접 일할 수 있게 됨). **"속도가 아니라 방향의 최적화"** — 타고는 있되 방향을 보라.
- **핵심 인용**: "업무 프로세스나 조직의 재설계 없이는 진정한 AX 전환은 불가능합니다."
- **내 질문**: '방향의 최적화'가 개인에게 뜻하는 건, 무엇을 자동화할지보다 '무엇을 계속 할지(내 방향)'를 먼저 정하는 것 아닐까?

## TL;DR (5줄)

1. **CoWork**: 실무자용 데스크탑 앱, **폴더 직접 접근**으로 회의록·영수증·엑셀·발표·계약서·일정을 자동화(개발자용 코드보다 접근 쉬움).
2. **모델·크레딧**: 오퍼스(고퀄 디자인)/소네트/하이쿠(단순 반복)를 **작업에 맞게** — 다 오퍼스로 쓰는 게 크레딧 낭비 1순위.
3. **구조**: 반복은 **스킬 MD**(내가 제작), 기능 묶음은 **플러그인**, 외부는 **커넥터**(캘린더+슬랙+Gmail 통합이 자동화의 힘).
4. **품질**: 한 번에 말고 **구조→가이드→제작→재정리로 쪼개 다듬기**, 재무·개인정보는 빼고, 출처를 넣게 하고, 보안 유의.
5. **AX(★)**: 첫째도 둘째도 셋째도 **데이터**(머릿속 안목을 학습). 업무 프로세스·조직 재설계가 본질, **속도가 아니라 방향의 최적화**.
