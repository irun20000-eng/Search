# 이걸 무료로 쓴다고? '노트북LM 슬라이드' 역대급 업데이트 — 9가지 실전 예제 + 50종 템플릿

> 한 줄 요약: **제미나이 3.1 + 나노바나 2** 탑재로 노트북LM 슬라이드가 급진화 — 예전엔 안 되던 **회사 템플릿 재현·이미지 맥락 인식·상세 스타일 지시**가 다 된다. 핵심은 **통제권이 넘어가기 전 ①소스 ②커스텀 프롬프트(스타일)를 정제**하는 것. 워크플로우: **리서치로 소스 수집→신뢰도 정제(느낌표/더하기로 대표소스 상단 고정)→맞춤 프롬프트 설정→슬라이드 목차를 먼저 만들어 메모→소스로 변환→목차+스타일로 슬라이드 생성**. **기업용 PPT**는 회사 PPT를 분석해 **JSON 가이드 코드**를 뽑고, 그 코드를 노트북LM·제미나이 캔버스·젠스파크 어디에 넣어도 회사 템플릿에 맞는 슬라이드 생성(폰트만 아직 미지원). 무료 슬라이드 하루 3개 제한은 **계정 여러 개**로 우회.

## 1. 노트북LM이란 + 3.1/나노바나2 업데이트 · [00:53](https://youtu.be/vjT43Qy0M4k?t=53)
- **3줄 요약**
  - 노트북LM = 흩어진 회사 자료(엑셀·워드·PDF·녹취록)를 취합해 정제된 보고서를 만드는 **웹기(웹 기반)** 도구. **내가 넣은 레퍼런스만으로 답변**해 프롬프트를 꼼꼼히 안 써도 정확.
  - **제미나이 3.1**: 여러 소스를 각각이 아니라 **하나의 컨테이너로 인식**해 요약 정교화, 그림만 넣어도 순서·맥락 이해.
  - **나노바나 2**(나노바나 프로 경량): 프로보다 잘 만들고 속도 2배, **텍스트 인식·맥락 이해 성능 대폭 개선** → 이게 이번 급진화의 핵심.
- **핵심 인용**: "여러 가지 모델 중에서 딱 하나만 고르세요라고 한다면 저는 노트북LM을 쓸 거 같아요."
- **내 팁**: 앞 영상(꿘샘AI Gemini Notebook)이 리브랜딩·환각을 다뤘다면, 이 영상은 3.1/나노바나2로 **슬라이드 제작 실무**가 가능해진 지점을 파고듦.

## 2. ★핵심 원칙 — 통제권 넘기기 전 소스·프롬프트 정제★ · [07:35](https://youtu.be/vjT43Qy0M4k?t=455)
- **3줄 요약**
  - 자료 취합·요약은 이미 ChatGPT로 했으나, **회사 템플릿 슬라이드**는 안 됐음 → 이제 **AI가 80%**(디자인까지 회사 템플릿), 남은 20%(**인사이트·스토리텔링·최종 검토**)는 사람이.
  - AI에 요청하는 건 **외주 맡기는 것** — 실행 누른 순간 통제권이 넘어가므로, 그 전에 **①소스 ②커스텀 프롬프트(슬라이드=스타일/디자인)**를 꼼꼼히.
  - "딸깍 100% 자동화"는 아직 없음. 정제된 소스 + 상세한 스타일 지시가 퀄리티를 가름.
- **핵심 인용**: "통제권이 넘어가기 전에 내가 최대한 정제해서 넘겨야 돼요. 딱 두 개 — 소스, 그리고 커스텀 프롬프트."
- **내 질문**: '외주=통제권 이전 전 정제'는 앞 영상 전부(스펙주도개발, 오팔 프롬프트 5구성)의 '선(先)명확화'와 정확히 같은 결 아닐까?

## 3. 소스 정제 + 맞춤 프롬프트 설정 · [11:53](https://youtu.be/vjT43Qy0M4k?t=713)
- **3줄 요약**
  - 새 노트북→리서치(패스트/딥, 무료 소스 50개)로 자료 수집. **소스 정제 2단계**: ①불필요·저신뢰 소스 나열해 삭제(1·2·3차 구분, 최신성 검토) ②주제별 **대표 소스**를 **느낌표(!)로 이름 변경해 상단 고정**.
  - 원하는 대표 소스만 체크해 보고서를 만들면 퀄리티 급상승. **맞춤 프롬프트**(설정→커스텀): 역할·배경·지시를 AI가 써주면 복사해 저장(예: 중학생 학습 교보재 제작).
  - 답변 길이는 전문 보고서 시 **'길게'** 체크(같은 비용이니 심도↑).
- **핵심 인용**: "소스의 개수가 많으면 좋긴 하지만 개수보다도 퀄리티가 중요해요."
- **내 팁**: 느낌표(대표 소스)/더하기(에셋)로 소스 우선순위를 시각 관리하는 건 앞 영상(옵시디언 PARA)의 '정보 우선순위화'와 같은 발상.

## 4. ★슬라이드 목차 먼저 → 스타일로 생성(만화·이미지 인식)★ · [24:25](https://youtu.be/vjT43Qy0M4k?t=1465)
- **3줄 요약**
  - 바로 스타일만 주면 **구성(각 슬라이드 내용)이 내 손을 벗어남** → **슬라이드 목차를 먼저 생성→메모 저장→소스로 변환(더하기로 '슬라이드 목차')** 후, "목차 소스를 엄격 준수 + 디자인 스타일" 지시로 생성.
  - 만화 스타일이면 **스토리까지 구성**(놀라움). **저작권**: 나노바나2로 강화 — 디즈니 계열 업로드 차단, 원피스 등은 **캐릭터명 언급 없이 이미지 첨부**해 "이 PNG 캐릭터로 생성".
  - **이미지 맥락 인식**: 키오스크 사용 영상만 넣어도 단계별 안내 슬라이드를 로고 인식·버튼 강조까지 자동 생성(예전엔 불가). 슬라이드 **수정**(제목·색·캐릭터 성별·3D)은 새 자료 생성으로 원본 유지.
- **핵심 인용**: "이걸 만들기 전에 내가 어떻게 구성할지를 미리 정하고 그 구성까지 함께 넘겨 주면 좀 더 정확한 보고서."
- **내 질문**: '목차(구성)를 먼저 확정 후 생성'은 앞 영상(코워크 스킬, 스펙주도개발)의 '계획 먼저'와 동일 — 구성 확정이 결과 정확도의 핵심 아닐까?

## 5. ★기업용 PPT — JSON 가이드 코드(범용)★ · [48:31](https://youtu.be/vjT43Qy0M4k?t=2911)
- **3줄 요약**
  - 회사 PPT를 넣고 "비율·컬러·상하단 구성·반복 장식을 분석해 **JSON 가이드 코드**로" → 슬라이드 마스터용 코드 생성(주소·이름 등만 교체).
  - 이 **JSON 코드는 범용** — 노트북LM뿐 아니라 **제미나이 캔버스·젠스파크** 등 PPT 만드는 모든 AI에 넣으면 회사 템플릿에 맞는 슬라이드. "이 JSON 구조 엄격 준수 + 헤더·컬러 적용"으로 생성 → 회사 템플릿과 거의 동일(**폰트만 아직 미지원**, 한글 노토산스 통일).
  - 제미나이 캔버스는 **편집 가능한 슬라이드**(노트북LM은 그림) → 구글 슬라이드로 내보내 나노바나로 이미지·슬라이드 재편집.
- **핵심 인용**: "이 JSON 코드를 넣어 주면 이 가이드에 따라서 슬라이드가 만들어진다 … 회사 템플릿이다라고 봐도 무방."
- **내 팁**: 'JSON 가이드 코드로 디자인 시스템을 범용화'는 앞 영상(Jay Choi Firecrawl 규칙 추출, 잭피디 8요소)의 '규칙 자산화'와 같은 계열 — 한 번 만든 규칙을 여러 도구에 재사용.

## TL;DR (5줄)

1. **업데이트**: **제미나이 3.1 + 나노바나 2**로 노트북LM 슬라이드가 회사 템플릿 재현·이미지 맥락 인식·상세 스타일 지시까지 가능.
2. **원칙(★)**: 실행=외주. **통제권 넘기기 전 ①소스 ②커스텀 프롬프트(스타일)** 정제. AI가 80%, 인사이트·검토는 사람이 20%.
3. **소스**: 리서치 수집→신뢰도 정제→**느낌표로 대표 소스 상단 고정**. 맞춤 프롬프트·'길게' 설정.
4. **생성(★)**: **슬라이드 목차 먼저**(메모→소스 변환)→목차+스타일로 생성. 만화 스토리·이미지 맥락 인식(키오스크 영상→안내 슬라이드). 저작권은 캐릭터명 없이 이미지 첨부.
5. **기업 PPT(★)**: 회사 PPT→**JSON 가이드 코드** 추출 → 노트북LM·제미나이 캔버스·젠스파크 어디든 넣어 회사 템플릿 재현(폰트만 미지원). 무료 하루 3개는 계정 다수로 우회.
