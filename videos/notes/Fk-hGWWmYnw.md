## 1. ★구글 안티그래비티 실행 및 폴더 접근 메커니즘★ · [00:00](https://youtu.be/Fk-hGWWmYnw?t=0)
- **3줄 요약**
 - 안티그래비티는 단순 대화를 넘어 **지정 폴더 내 파일**을 직접 탐색, 생성, 수정하는 개발 환경이다.
 - 탐색 창과 대화 인터페이스가 결합되어 코딩 및 문서 작업 결과를 **실시간 시각화**하여 확인한다.
 - 로컬 프로젝트 폴더 바인딩을 통해 에이전트 작업 영역을 안전하게 **격리 및 지정**한다.
- **핵심 인용**: "이 안티그래비티는 폴더를 엑세스해서 AI 작업을 하는 겁니다 우리 대화만 하는 게 아니고요."
- **내 팁**: 프로젝트 시작 시 작업 전용 폴더를 먼저 지정하여 에이전트가 다른 영역의 파일을 훼손하지 않도록 보호한다.

## 2. 좌뇌 Gemini와 우뇌 Claude 모델 시너지 활용 · [01:30](https://youtu.be/Fk-hGWWmYnw?t=90)
- **3줄 요약**
 - **제미나이(Gemini)**는 두 배 넓은 컨텍스트 메모리를 바탕으로 전체 문맥 파악 및 정보 추출에 우수하다.
 - **클로드(Claude)**는 정밀한 표현 및 디스플레이 조작 기술이 뛰어나 정교한 파일 작성에 강점을 보인다.
 - 좌뇌와 우뇌의 역할처럼 **두 모델을 교차 임대 사용**하여 단일 모델의 한계를 상호 보완한다.
- **핵심 인용**: "오른쪽 뇌는 제미나이 왼쪽 뇌는 클로드 작업을 할 수가 있는 거죠."
- **내 질문**: 프로젝트 진행 도중 제미나이에서 클로드로 모델을 교체할 때 기존 대화 스레드의 토큰 손실이 발생하는지 궁금하다.

## 3. ★파일 일괄 자동 생성과 승인(Accept) 프로세스★ · [02:52](https://youtu.be/Fk-hGWWmYnw?t=172)
- **3줄 요약**
 - 대화창 출력을 지양하고 명령 시 **여러 개 마크다운(.md) 파일**을 폴더 내에 일괄 자동 생성한다.
 - 에이전트가 생성한 파일은 임시 상태로 대기하며 사용자의 **승인(Accept)** 절차를 거쳐 최종 반영된다.
 - 구조적 분석 명령을 통해 다수 파일 간의 연관성과 핵심 기법을 **통합 리포트**로 추출한다.
- **핵심 인용**: "작성하되 이거를 실제로 쓸지는 승인을 기다리는 거예요."
- **내 팁**: 일괄 파일 생성 작업 시 `Accept All` 버튼을 활용하기 전 미리보기 창에서 개별 파일의 정합성을 일차 점검한다.

## 4. 클로드 코드 독립 에이전트 연동과 세션 메모리 유실 방지 · [06:57](https://youtu.be/Fk-hGWWmYnw?t=417)
- **3줄 요약**
 - 안티그래비티 내 버튼 클릭으로 독립 구동되는 **클로드 코드(Claude Code)**를 직접 연결한다.
 - 새 대화 세션 전환 시 이전 세션의 단기 기억이 초기화되는 **메모리 유실 문제**가 발생한다.
 - 다수의 에이전트를 **오픈 에이전트 매니저**에서 동시 가동하여 병렬 멀티태스킹을 구현한다.
- **핵심 인용**: "새로운 세션이 시작되면 이전에 했던 대화들 이전에 했던 세션들 기억은 다 사라지게 됩니다."
- **내 팁**: 에이전트 매니저에서 여러 작업을 동시 실행할 때 각 에이전트별 진행 상태와 승인 요청 알림을 주기적으로 확인한다.

 - 두 모델의 지침을 동기화하기 위해 **심볼릭 링크(Symbolic Link)**로 두 메모리 파일을 연결한다.
 - 단일 지침 파일 수정만으로 모든 AI 에이전트가 **동일한 맥락과 메모리**를 유지하게 조치한다.

- **내 팁**: 윈도우/맥 환경에서 심볼릭 링크 명령어를 작성하여 `claude.md`와 `gemini.md`를 쌍둥이 구조로 자동 동기화한다.

## TL;DR (5줄)
1. **폴더 바인딩**: 안티그래비티의 폴더 바인딩 기능을 통해 AI가 로컬 파일을 직접 생성·수정하게 구축한다.
2. **듀얼 에이전트**: 문맥 추출에 뛰어난 제미나이와 디테일에 강한 클로드를 듀얼 에이전트로 배치해 시너지를 낸다.
3. **안전 승인 구조**: 에이전트가 자동 작성한 파일은 사용자의 승인(Accept) 절차를 거치도록 안전장치를 마련한다.
4. **멀티태스킹 관리**: 오픈 에이전트 매니저를 활용해 여러 개의 독립 에이전트를 병렬 가동하고 상태를 제어한다.
5. **메모리 동기화**: `claude.md`와 `gemini.md`를 심볼릭 링크로 연결하여 세션 초기화 시에도 맥락을 유지시킨다.
