# 옵시디언에 제미나이 붙이니 AI 세컨드 브레인이 진짜 됐다! | 무료 오픈소스 플러그인

> 한 줄 요약: 제작자가 직접 만든 무료 오픈소스 옵시디언 플러그인 **Master of Knowledge**는 **Gemini File Search**로 내 노트(약 1,310개)를 동기화해, ① **Chat**(내 노트 기반 답변+출처) ② **Agent**(Antigravity CLI로 웹서치+리포트 자동 작성) ③ **Budget**(월 $7 상한, 실사용 ~$0.0077) ④ **Graph**(노트 구조 시각화)를 제공한다. 핵심은 "대부분의 AI는 **내 맥락을 모른다**"는 문제를 옵시디언 안에서 풀어, LLM 요청 때마다 **내 지식 DB를 맥락으로** 쓰는 **나만의 맞춤형 지식 작업실**을 만드는 것. 단순 저장이 아니라 **'지식 가드닝'**(가지치기·업데이트)에 방점.

## 1. 콜드오픈 — 내 노트로 인사이트 노트를 써준다 · [0:00](https://youtu.be/VYXr0M7IYJk?t=0)
- **3줄 요약**
  - 동기화한 약 **1,310개 노트**를 바탕으로 **AX 전략 인사이트 노트를 작성**하고 **출처(소스)까지** 함께 준다.
  - 생성된 노트에 옵시디언 스킬로 **프로퍼티(속성)**도 자동 작성되고, 관련 사내 지식 노트들과 **연결**된다.
  - 함께 더 좋은 **'지식 가드닝(Knowledge Gardening)'** 서비스를 만들어보자는 초대로 시작.
- **핵심 인용**
- **내 질문**
- "답변 + 출처 노트 연결"은 우리 노트가 `[[링크]]`로 연결되는 것과 같은 구조 — 소스 추적성이 곧 신뢰다.

## 2. 왜 만들었나 — AI는 내 맥락을 모른다 · [1:39](https://youtu.be/VYXr0M7IYJk?t=99)
- **3줄 요약**
  - 요즘 AI는 많지만 **내 생각·내 기록·내가 읽은 자료를 모른다** — 답은 그럴듯해도 내 맥락과 동떨어진다.
  - **Master of Knowledge**는 이 문제를 **옵시디언 안에서** 해결하려고 만든 플러그인.
  - 한 문장 정의: "옵시디언에 쌓인 내 노트를 **AI가 검색하고 연결하고 다시 글로 만들어주는 지식 작업실**".
- **핵심 인용**
- **내 질문**
- 영상2(세컨드 브레인)와 같은 문제의식 — "내 데이터를 AI의 맥락으로". 도구만 옵시디언+제미나이로 다르다.

## 3. 5가지 기능 개요 — Sync·Chat·Agent·Budget·Graph · [2:44](https://youtu.be/VYXr0M7IYJk?t=164)
- **3줄 요약**
  - ① **Sync**: 내 볼트의 마크다운 노트를 **Gemini File Search**로 동기화(전체가 아닌 **선택 폴더** 기준으로 지식 베이스 구성). ② **Chat**: 동기화된 노트에 질문하면 **노트 기반 답변 + 어떤 노트를 참고했는지 소스**까지.
  - ③ **Agent**: 질의응답을 넘어 **글쓰기·조사·정리**를 위임 — **Antigravity CLI를 래핑**(제미나이 프로 요금제면 별도 API 과금 없이 사용). ④ **Budget**: API 비용 관리(실사용 **약 $0.0077**, 월 **$7 상한**으로 과금 방지).
  - ⑤ **Graph**: 노트를 그래프로 시각화, 리빌드/주제 검색으로 구조 확인.
- **핵심 인용**
- **내 질문**
- 5기능이 곧 "수집→질의→생성→비용관리→시각화" 파이프라인 — 우리 video2post(수집→노트→갤러리)와 판박이 구조다.

## 4. 설치 — BRAT로 베타 플러그인 추가 · [5:20](https://youtu.be/VYXr0M7IYJk?t=320)
- **3줄 요약**
  - 대부분의 플러그인은 **BRAT**(브라트, Beta Reviewers Auto-update Tool)로 설치. 설정 → BRAT → **Add Beta Plugin**.
  - 저장소 식별자(예: `ReallyGood83/…`, `omg-search`)를 넣고 **Add Plugin** → **Master of Knowledge**가 설치됨.
  - 좌측에 **리본 아이콘**(뇌 모양)이 생기고, 위치를 옮길 수 있으며 클릭하면 플러그인 패널이 열린다.
- **핵심 인용**
- **내 질문**
- BRAT는 GitHub 저장소를 옵시디언에 바로 붙이는 통로 — 오픈소스 배포/설치 경로가 표준화돼 있다는 게 인상적.

## 5. 설정 — Gemini API 키·모델·싱크 폴더·버짓 · [7:10](https://youtu.be/VYXr0M7IYJk?t=430)
- **3줄 요약**
  - 설정에서 **Gemini API 키**를 붙여 넣고 검증(Valid). 모델은 3.5 Flash가 추천이지만, 제작자는 **2.5 Flash / 3.1 Flash Lite**를 사용(모델별 품질 만족도가 다르니 각자 테스트 권장).
  - **Sync 폴더**: 볼트 전체가 아니라 **약 5개 폴더**만 선택(뉴스레터·논문·강의안 등 재활용할 것들). **애드 버튼**으로 여러 폴더 추가.
  - **먼슬리 버짓**(월 $7 등)과 **Antigravity CLI 경로**(Auto-detect) 설정, **오토 싱크**(선택 폴더에 새 노트 생기면 자동 동기화, 원치 않으면 off).
- **핵심 인용**
- **내 질문**
- "볼트 전체가 아닌 선택 폴더만 싱크"는 컨텍스트·비용 최적화 — 우리도 `notes/`만 대상으로 좁히는 것과 같은 절제.

## 6. 싱크 원리 — Gemini File Search 인덱싱 (로컬 대비 빠름) · [12:40](https://youtu.be/VYXr0M7IYJk?t=760)
- **3줄 요약**
  - 선택 폴더에 새 노트가 생기면 **Gemini File Search**에 마크다운이 자동 동기화. 약 **1,321개 시도에 에러 11개** 수준으로 대부분 성공.
  - 제작자의 **LLM 위키('알다')**는 **로컬 LLM 인덱싱**이라 트레이드오프로 **느린데**, **Gemini API 인덱싱은 시간이 크게 단축**되고 비용도 저렴.
  - **Force Sync**(강제 일괄 동기화), **Clear Sync Data**(동기화 데이터 초기화 — 폴더 재구성 시 지웠다가 다시 싱크).
- **핵심 인용**
- **내 질문**
- 로컬 임베딩(정확·느림) vs 클라우드 API(빠름·저비용)의 트레이드오프 — 우리 자막 수집의 로컬 Chrome 의존과 비슷한 선택 구조다.

## 7. Chat 기능 — 노트 기반 답변 + 새 노트 생성 · [14:06](https://youtu.be/VYXr0M7IYJk?t=846)
- **3줄 요약**
  - "150명 조직의 **AX 전략 인사이트 노트** 작성해 줘" → 싱크된 1,310개 노트를 근거로 답변 + **소스 노트** 제시. (작년 12월 Gemini API 기반 챗봇을 업데이트한 기능.)
  - **Apply → Create New Note**로 질문+답변을 **별도의 새 노트**로 저장(Insert at cursor / Append도 가능).
  - 이렇게 **응답 결과물을 다시 지식 DB에 축적**하는 선순환. 옵시디언 스킬로 **프로퍼티**도 자동 작성.
- **핵심 인용**
- **내 질문**
- "출력을 다시 입력으로" — 우리 파이프라인도 노트가 갤러리가 되고 그 태그가 다시 탐색에 쓰이는 순환이 있다.

## 8. Agent 기능 — Antigravity CLI로 리포트 자동 생성 · [18:18](https://youtu.be/VYXr0M7IYJk?t=1098)
- **3줄 요약**
  - **Agent**는 **Antigravity CLI**를 활용(설치 필요). "150명 조직 AX 전략 노트 + **최신 AX 트렌드 웹서치** 반영 리포트" 요청.
  - 챗보다 시간이 걸리지만, **웹서치 + 내 노트 맥락**으로 리포트를 만들어 지정 폴더(예: `47-MOKA`)에 새 노트로 저장(속성·시각화 포함, Mermaid는 깨질 수 있어 수정 필요).
  - 핵심 차이: 일반 AI 요청은 **내 맥락이 없지만**, Agent 결과물은 **싱크한 노트를 맥락으로** 사용 → 소스가 함께 나온다.
- **핵심 인용**
- **내 질문**
- "웹서치 + 내 지식"의 결합이 Agent의 진짜 가치 — 외부 최신성과 내부 맥락을 합치는 게 리서치 자동화의 핵심이다.

## 9. 지식 가드닝 철학 & 그래프 · [22:28](https://youtu.be/VYXr0M7IYJk?t=1348)
- **3줄 요약**
  - 이 플러그인은 지식을 **단순 저장**이 아니라 **가드닝(가지치기·업데이트)** 하기 위한 것 — 썩은 부분은 도려내고 좋은 부분은 키운다.
  - 강의·연구를 많이 하는 사람은, LLM에 어떤 요청을 하든 **내 싱크된 노트가 맥락**이 되어 **나만의 맞춤형 지식 DB**를 구축·활용하는 게 목표.
  - **Graph**: 상위 300 노드 시각화(줌 가능)하지만, 실제론 **태그값으로 보는 게 더 편함**. 태그로 관련 노트를 한 번에 확인.
- **핵심 인용**
- **내 질문**
- "저장이 아니라 가드닝" — 우리 LESSONS.md·메모리도 쌓기만 하지 말고 주기적으로 틀린 걸 도려내야(가지치기) 품질이 유지된다.

## 10. 마무리 — 오픈소스, 포크해서 함께 · [24:05](https://youtu.be/VYXr0M7IYJk?t=1445)
- **3줄 요약**
  - **오픈소스**로 제공(GitHub 주소는 설명란·고정 댓글). 내 것만이 정답은 아니니 **포크·업데이트·재공유** 환영.
  - 옴니서치/파일서치로도 되지만, **LLM 위키처럼** 검색어 하나로 여러 관련 노트를 동시에 관리·확인하게 만든 게 차별점.
  - 메시지: 지식 DB는 **구축 자체보다 활용**이 핵심 — AI로 생산성·지식관리에 실제로 써야 의미가 있다.
- **핵심 인용**
- **내 질문**
- "구축보다 활용" — LLM 위키/세컨드 브레인 붐의 공통 교훈. 만들어만 두면 죽은 데이터, 매일 굴려야 산다.

## TL;DR (5줄)

1. **Master of Knowledge**(무료 오픈소스 옵시디언 플러그인)는 **Gemini File Search**로 내 노트(~1,310개)를 동기화해 AI가 검색·연결·작성한다.
2. 5기능: **Sync**(선택 폴더) · **Chat**(노트 기반 답변+출처) · **Agent**(Antigravity CLI 웹서치+리포트) · **Budget**(월 $7 상한, ~$0.0077) · **Graph**(시각화).
3. 설치는 **BRAT**로, 설정은 **Gemini API 키 + 모델(2.5/3.1 Flash) + 싱크 폴더 + 버짓 + Antigravity 경로**.
4. 로컬 LLM 인덱싱(느림) 대비 **Gemini API 인덱싱은 빠르고 저렴**; 결과물은 다시 노트로 저장돼 지식 DB가 **순환·성장**한다.
5. 철학은 단순 저장이 아닌 **'지식 가드닝'** — LLM 요청마다 내 노트를 맥락으로 쓰는 **맞춤형 지식 DB**, 구축보다 **활용**이 핵심.
