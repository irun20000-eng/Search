# 제미나이 노트북 역대급 신기능 3가지 (핵심압축)

> 한 줄 요약: **노트북LM에서 업그레이드된 제미나이 노트북(Gemini Notebook)**의 핵심 신기능 3가지인 **채팅창 자연어 파일 및 차트 생성**, **외부 웹 검색 기반 부족한 소스 보완**, 그리고 **14개 사내 문서를 4대 주제로 묶어주는 소스 자동 라벨링** 기능을 활용하여 내 원본 데이터 기반의 100% 신뢰도 높은 산출물을 도출하는 실전 방법을 제시한다.

## 1. ★채팅창 파일·차트 생성 및 확장된 사고 기반 이미지 한글화★ · [00:00](https://youtu.be/HP8YODI7HhY?t=0)
- **3줄 요약**
  - 우측 카드 버튼 없이 채팅창에 말로 요청하여 **원형 차트 PNG 및 엑셀 파일**을 직접 생성한다.
  - 카페 장부 CSV 파일 6개 중 단가표 체크를 해제하여 **지출 분석에 필요한 소스만 선택 반영**한다.
  - 영문 차트 이미지를 제미나이에 넣고 **확장된 사고(Thinking)**를 켜서 13개 항목의 한글 차트로 정확히 변환한다.
- **핵심 인용**: "재미나이 노트북은 내 자료만 보고 결과물을 만들 수 있기 때문에 그대로 초안으로 쓸 수 있습니다 이제부터 제나이 노트북 채팅창을 이용해서 세무사 보낼 정리표를 엑셀로 회의롱 요약을 워드로 발표 자료를 PPT로 자유롭게 요청할 수 있습니다."
- **내 팁**: 복잡한 숫자 차트 이미지 생성 시 제미나이 노트북에서 영문으로 1차 수치를 확정한 뒤 제미나이 확장 사고 모드로 한글화 변환한다.

## 2. ★내 데이터 기반 웹 소스 자동 탐색 및 지원사업 대조★ · [03:55](https://youtu.be/HP8YODI7HhY?t=235)
- **3줄 요약**
  - 업로드된 사업 정보(업력 2년 4개월)를 먼저 읽고 3개 공고문과 대조하여 **신청 자격 요건을 표로 판별**한다.
  - 내 조건(1인 제조업, 여성 대표)에 맞춰 부족한 지원사업을 **외부 웹에서 스스로 검색하여 추천**한다.
  - 검색된 외부 공고 중 유효한 항목을 클릭하여 **노트북 내부 소스로 즉시 가져오기(Import)**한다.
- **핵심 인용**: "원래 노트북은 제가 넣은 자료 밖으로 안 나갔어요 이제는 내 자료를 다 읽은 다음에 뭐가 비었는지 보고 웹에서 찾아옵니다."
- **내 팁**: 지원사업이나 정책 공고를 탐색할 때 내 사업장 현황 문서를 먼저 등록해 두면 AI가 맞춤형 필터링 후 외부 공고를 가져온다.

## 3. 마감일 기준 공고 정렬 및 만료 데이터 분리 필터링 · [05:50](https://youtu.be/HP8YODI7HhY?t=350)
- **3줄 요약**
  - 외부에서 가져온 공고들 중 **이미 마감된 사업을 제외**하고 마감일 순서로 재정렬한다.
  - 각 사업별 지원 내용과 내 사업체가 해당 공고에 적합한 이유를 **명확한 근거 문장**으로 제시한다.
  - 외부 웹 검색 데이터는 날짜 오류가 섞일 수 있으므로 **반드시 제공된 원문 링크를 재검증**한다.
- **핵심 인용**: "원래 노트북은 넣은 자료 안에서만 답했어요 이제는 요청하면 내 자료를 먼저 읽고 뭐가 비었는지 판단한 다음에 밖에서 채워올 수도 있습니다 다만 찾아온 걸 그대로 믿지 마시고 원문에서 한번 확인하세요."
- **내 팁**: 웹에서 끌어온 공고 리스트는 프롬프트에 "마감일 지난 것 제외" 조건을 명시하여 최신 유효 공고만 표로 추출한다.

## 4. ★대용량 소스 자동 라벨링(Grouping)과 심층 질의★ · [06:35](https://youtu.be/HP8YODI7HhY?t=395)
- **3줄 요약**
  - 규정집, 복지 안내, 연말정산 등 **14개 혼합 문서**를 한 노트북에 넣으면 답변 밀도가 얕아지는 문제가 발생한다.
  - **자동 라벨 기능**을 클릭하면 근무/휴가, 급여/정산, 복리후생, 운영/보안 4개 그룹으로 자동 분류된다.
  - 필요한 복리후생 그룹만 체크하고 질의하면 80만 복지 포인트의 **신청 및 환급 절차까지 심층 답변**을 제공한다.
- **핵심 인용**: "자료가 많으면 골고루 훑느라 약 볼 것만 남기면 같은 문서라도 훨씬 깊게 꺼내 줍니다."
- **내 팁**: 노트북 내 문서가 10개 이상 쌓이면 자동 라벨 버튼을 눌러 그룹화한 뒤 필요한 카테고리만 체크하여 깊이 있는 답변을 유도한다.

## 5. 원본 데이터 기반 초안 작성의 차별점과 활용 원칙 · [08:35](https://youtu.be/HP8YODI7HhY?t=515)
- **3줄 요약**
  - 일반 생성 AI는 모르는 정보를 그럴듯하게 환각(Hallucination)으로 채우는 위험이 있다.
  - 제미나이 노트북은 사용자가 제공한 **업로드 문서만을 100% 참조**하므로 즉시 실무 초안으로 활용 가능하다.
  - 정확성이 요구되는 세무, 회계, 사내 규정 문서는 **노트북에서 1차 검증 후 산출**하는 원칙을 준수한다.
- **핵심 인용**: "다른 도구는 모르는 부분을 그럴 듯하게 채울 확률이 높습니다 재미나이 노트북은 내 자료만 봅니다 그래서 나온 결과를 그대로 초안으로 쓸 수 있습니다."
- **내 질문**: 자동 라벨링된 그룹별 소스에 대해 특정 부서별 접근 권한을 나누어 다자간 공유할 수 있는 워크스페이스 권한 제어 기능이 제공되는지 궁금하다.

## TL;DR (5줄)
1. **자연어 파일 생성**: 채팅창 입력만으로 CSV 소스 기반 원형 차트 PNG 및 엑셀 결과물을 즉시 생성한다.
2. **확장된 사고 변환**: 제미나이 확장 사고 모드로 영문 차트를 13개 항목의 오차 없는 한글 차트로 변환한다.
3. **웹 소스 탐색**: 내 사업 정보를 바탕으로 부족한 지원사업을 외부 웹에서 탐색해 내부 소스로 가져온다.
4. **소스 자동 라벨링**: 14개 문서를 4개 그룹으로 묶어 필요한 카테고리만 활성화함으로써 답변 깊이를 극대화한다.
5. **100% 팩트 기반**: 업로드한 자료만을 근거로 답변하므로 환각 없는 신뢰도 높은 실무 초안을 확보한다.
