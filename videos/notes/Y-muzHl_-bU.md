# 노트북LM이 사라졌다? ‘Gemini Notebook’ 신기능 총정리 — 무료·Pro·Ultra 차이 & 되는/안 되는 기능

> 한 줄 요약: NotebookLM이 **‘Gemini Notebook’으로 리브랜딩**(로고 파란색·LM→Gemini). 신기능은 **등급별로 차등** 배포 — ①**엑셀 실제 연산·데이터 분석**(Pro) ②**진짜 PPTX 생성**(기존은 이미지, 이제 편집 가능한 .pptx, **Ultra 전용**) ③**소스 기능 확장**(내 소스만이 아니라 **구글 검색으로 외부 자료를 끌어와 추가**) + 컬렉션(폴더)·고정·표지 이미지 등 소소한 UI 개선. **트레이드오프**: 외부 검색+제미나이 3.5/3.6 플래시 탑재로 **환각 발생** → 예전의 "소스 안에서만"이라는 최대 장점이 흔들려 **출처·근거 확인 필수**. 발표자는 구글의 배포 시스템 혼란·성능 저하를 강하게 비판.

## 1. 왜 지금 총정리 + 등급별 차등 배포 · [00:01](https://youtu.be/Y-muzHl_-bU?t=1)
- **3줄 요약**
  - 신기능이 조금씩 나와 개별 영상화가 어려워, 그동안의 업데이트를 한 번에 정리(실제 업무·생활 활용 관점).
  - 이번 업데이트는 **유료/무료를 구분해 차등 배포** — 무료엔 안 되는 것, Pro에도 안 보이는 것(Ultra 전용)이 존재.
  - 예전엔 Ultra→(1~2일)Pro→(수주~한 달)무료로 순차 배포됐으나 **요즘 그 시스템이 무너짐**.
- **핵심 인용**: "등급별로 즉 유료자와 무료 사용자들을 구분을 해서 신기능들을 업그레이드를 했습니다."
- **내 팁**: '등급별 차등'은 앞 영상(힉스필드/CoWork의 유료 티어) 논의와 같은 맥락 — 기능 접근이 요금제에 묶임.

## 2. 구글 배포 혼란·제미나이 성능 저하 비판 · [02:27](https://youtu.be/Y-muzHl_-bU?t=147)
- **3줄 요약**
  - 제미나이 3.5(Pro)가 7/17 출시 무산되고 **3.6 플래시/플래시 라이트만** 먼저 나옴 → 클로드 페이블5·ChatGPT 5.6 대비 성능이 크게 뒤처진다는 평가.
  - 핵심 엔지니어 2명이 각각 클로드·OpenAI로 이탈했다는 소문 등 **내부 혼란**을 원인으로 지목.
  - (발표자 사견) 일반 사용자는 굳이 비싼 클로드 불필요("짜장면집에 스포츠카"), ChatGPT 5.6도 충분히 좋음. 단 **NotebookLM 자체는 아직 쓸 만**.
- **핵심 인용**: "요즘은 구글이 무슨 일인지 모르겠지만 아예 그런 시스템 자체가 무너졌습니다."
- **내 질문**: 발표자의 모델 우열 평가는 주관·시점 의존이 크니, 노트는 '기능 사실' 위주로 남기고 성능 순위는 참고만 하는 게 맞지 않을까?

## 3. ★핵심 신기능 3가지 — 연산·PPTX·소스검색★ · [05:36](https://youtu.be/Y-muzHl_-bU?t=336)
- **3줄 요약**
  - **① 엑셀 실제 연산(Pro)**: 예전엔 표를 정리·인사이트 제시만(연산은 환각 우려로 차단) → 이제 **실제 계산·데이터 분석** 수행.
  - **② 진짜 PPTX 생성(Ultra 전용)**: 기존 '슬라이드 자료'는 다운받아도 **이미지**라 편집 불가 → 이제 채팅창에서 "N장짜리 PPTX로" 하면 **편집 가능한 .pptx** 생성. (월 100불≈19만 원, Pro엔 아직 미배포.)
  - **③ 소스 기능 확장**: 예전엔 내가 넣은 소스만으로 답변 → 이제 **구글 검색으로 외부 자료를 찾아 소스로 추가**. AI 검색(AI 모드) 결과를 '노트북으로 보내기'도 생김.
- **핵심 인용**: "이제는 실제적으로 재미나가 연산을 하기 시작했다. 계산도 해 줍니다."
- **내 팁**: '이미지 PPT → 진짜 PPTX'는 앞 영상(클로드 Skills PPT)과 대비 — 편집 가능 산출물이 실무 가치를 가른다.

## 4. UI 개선 — 리브랜딩·컬렉션·고정·표지 · [10:13](https://youtu.be/Y-muzHl_-bU?t=613)
- **3줄 요약**
  - **리브랜딩**: 'NotebookLM'→'Gemini Notebook'(로고 파란색), 제미나이 안에서도 노트북 접근. 홈이 **고정됨·추천 노트북·최근 노트북** 3구성으로 변경.
  - **컬렉션(폴더)**: 노트북이 수십 개로 많아질 때 시리즈별로 묶는 폴더. 이름·이모티콘 지정 가능. **고정**은 자주 쓰는 노트북을 맨 위로.
  - **표지 이미지**: 노트북에 책 표지처럼 커버 이미지 업로드 가능. (다만 영상 내내 **잦은 에러**로 일부 기능이 안 보이는 상황 반복.)
  - **추천 노트북**: 구글이 직접 블룸버그·논문 등을 소스로 큐레이션해 제공(예: 50대 기업 실적).
- **핵심 인용**: "컬렉션 만들어서 이름 쓰고 여러 가지를 클릭해 가지고 가져오면 하나의 컬렉션으로 만들 수 있다. 일종의 폴더."
- **내 질문**: 컬렉션·고정은 앞 영상들(옵시디언 PARA, 노션 DB)의 '정보 정리 체계'와 같은 니즈 — 노트북이 많아질수록 폴더링이 필수 아닐까?

## 5. ★트레이드오프 — 환각 유입 & 출처 확인 필수★ · [16:55](https://youtu.be/Y-muzHl_-bU?t=1015)
- **3줄 요약**
  - AI 엔진이 3.1→**3.5/3.6 플래시**로 갱신되고, 소스가 **외부 검색까지 확장**되면서 **환각 현상 발생**.
  - NotebookLM의 최대 장점이던 **"내가 허락한 소스 안에서만 답변"**이 흔들림 — 외부의 나쁜 정보가 섞일 수 있음.
  - 따라서 이제는 **출처·근거를 항상 요구**하고 **한 번 더 검증**하는 과정이 필요. 결론적으로 "좋아진 것보다 나빠진 면도".
- **핵심 인용**: "이제는 그 출처 근거를 항상 해 달라고 해야 됩니다. 한 번 더 체크를 하시는 과정이 필요해졌다."
- **내 팁**: '외부 검색 개방 → 환각 → 출처 검증'은 앞 영상(스펙주도개발의 '검증 절차 필수', 신영선의 '사실확인 체크리스트')과 같은 결 — 개방성이 커질수록 검증이 필수.

## TL;DR (5줄)

1. **리브랜딩**: NotebookLM → **Gemini Notebook**(로고 파란색). 홈이 고정됨·추천·최근 3구성, **컬렉션(폴더)**·고정·표지 이미지 추가.
2. **핵심 3(★)**: ①엑셀 **실제 연산·분석**(Pro) ②**편집 가능한 PPTX 생성**(Ultra 전용) ③**소스 외부 검색 확장**(구글 검색으로 자료 추가).
3. **등급 차등**: 무료·Plus·Pro·Ultra로 기능 차등, 예전의 순차 배포(Ultra→Pro→무료)가 무너져 Pro에도 PPTX/시네마틱 미배포.
4. **트레이드오프(★)**: 외부 검색+3.5/3.6 플래시로 **환각 유입** → "소스 안에서만"이란 최대 장점 약화 → **출처·근거 확인 필수**.
5. **평가**: 발표자는 구글 배포 혼란·제미나이 성능 저하를 강하게 비판(주관 포함). 노트북 자체는 무료로도 대부분 되는 게 강점 유지.
