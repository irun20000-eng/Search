# 이건 진짜 90%가 몰라요 — 제미나이 @멘션 7가지 마법 (슈퍼 생산성)

> 한 줄 요약: 제미나이 채팅창에 **골뱅이(@)로 특정 앱만 콕 집어 호출**하면 웹 검색을 끄고 내 데이터만 뒤져 **할루시네이션이 제로에 가까워진다**. Gmail은 **기간·발신자·키워드·출력** 4요소로, Docs는 정확한 제목으로. 진짜 핵심은 **여러 앱을 한 번에 부르는 멀티 멘션(슈퍼 워크플로우)** — @Gmail→@드라이브→@Docs→@캘린더처럼 **정보 확인→분석→기록→실행** 순으로 엮어 원스톱 경비 보고·프로젝트 인수까지 한 프롬프트로.

## 1. @멘션 = 웹과 내 데이터 분리 · [00:00](https://youtu.be/Nk5TTif1cDQ?t=0)
- **3줄 요약**
  - 권한(출입증)이 있어도 잘 시키는 게 중요 — "내 메일 찾아줘"는 검색 결과와 내 메일이 뒤섞일 수 있음.
  - 채팅창 **골뱅이(@)** → 연동 앱 리스트에서 수동 선택. **@Gmail**을 붙이면 인터넷 검색을 끄고 내 메일만 뒤짐.
  - = **할루시네이션을 줄이는 가장 확실한 방법**(웹 결과와 내 데이터를 물리적으로 분리). @는 "외부와 단절, 내 정보에만 집중"하라는 명령.
- **핵심 인용**: "골뱅이를 붙이고 뒤에 앱 이름을 클릭한다는 건 … 외부 세상과는 단절하고 내 정보에만 집중하라는 아주 강력한 명령."
- **내 팁**: 정확도가 중요한 개인 데이터 작업은 반드시 @멘션 — 앞 영상들의 NotebookLM '소스 한정'과 같은 '경계 긋기' 원리.

## 2. 7가지 앱 + Verify AI · [01:25](https://youtu.be/Nk5TTif1cDQ?t=85)
- **3줄 요약**
  - **캘린더**(일정 조회·추가), **Keep**(메모), **Tasks**(투두·알림), **Gmail**(검색·요약·답장), **Docs**(문서 생성·수정), **드라이브**(PDF/PPT/시트 검색), **뮤직**(가사로 검색).
  - **Verify AI** = AI 생성물 검증(암호화로 조작 여부 증명) — 제미나이 생성 이미지는 거의 100% 찾아냄.
  - 각 앱을 @로 특정해 그 앱에만 집중시킴.
- **핵심 인용**: "구글 뮤직을 사용하신다면 가사만으로도 노래 검색이 가능하고요."
- **내 질문**: 구글 생태계 전체가 @멘션으로 하나의 명령 표면이 되면, 'AI 비서'의 실체는 결국 '내 데이터 접근 권한 + 정확한 지시' 아닐까?

## 3. ★Gmail 4요소 — 기간·발신자·키워드·출력★ · [03:33](https://youtu.be/Nk5TTif1cDQ?t=213)
- **3줄 요약**
  - 단순 "메일 읽어줘"가 아니라 **조건부 검색+연속 행동**. 예: "지난 3개월 [카드사]의 '결제 완료' 메일만 날짜·항목·금액순 표로, 합계도."
  - 핀셋 4요소: **① 기간 ② 발신자 ③ 키워드 ④ 출력** — 연말정산·비용 처리 시 메일을 안 열어도 됨.
  - 응용: 메일 속 '내 할 일'만 추출, 이전 히스토리 반영한 답장, 긴 스레드의 **타임라인 복원**(시작·목적·바뀐 결정·최근 합의).
- **핵심 인용**: "기간, 발신자, 키워드, 출력 이 네 가지만 기억을 하시면 … 메일을 일일이 열어 볼 필요가 전혀 없습니다."
- **내 팁**: 제미나이를 **레드 팀**으로 — 비판적/중립적/실행자 관점을 부여하면 답변 질이 달라진다.

## 4. Docs·드라이브·캘린더 — 제목·핀셋·스마트 스케줄러 · [07:44](https://youtu.be/Nk5TTif1cDQ?t=464)
- **3줄 요약**
  - **Docs**: 주제만 던지면 뼈대+살(제목·대상·목적·목차·톤 지정). ★가장 중요한 건 **정확한 제목** 언급(시간 단축). 어조 교정·용어 쉽게·불릿 정리도.
  - "AI는 검색기가 아님" — "찾아줘"에서 멈추지 말고 **가공 명령**("찾은 정보로 요약해 줘") 추가.
  - **캘린더+Tasks**: 가용 시간 분석("수~금 10~17시 1시간 이상 빈 시간"), **맵스** 호출로 이동 시간까지 계산해 "여유 30분 있는 시간대".
- **핵심 인용**: "단순히 찾아조에서 멈추지 말고 찾은 정보를 바탕으로 … 가공하는 명령을 추가하는 습관."
- **내 질문**: 파일 제목이 곧 검색 성능이라는 건, AI 시대의 파일 네이밍이 '나를 위한' 게 아니라 'AI가 찾기 위한' 메타데이터가 된다는 뜻 아닐까?

## 5. ★멀티 멘션 슈퍼 워크플로우★ · [10:34](https://youtu.be/Nk5TTif1cDQ?t=634)
- **3줄 요약**
  - @멘션은 **한 번에 하나가 아님** — 여러 앱을 한 프롬프트로. 예 원스톱 경비 보고: @Gmail(영수증 메일)→@드라이브(지출 템플릿 채우기)→@Docs(증빙 보고서 생성).
  - 프로젝트 인수 예: @Gmail(쟁점 3가지)→@드라이브(PDF로 해결 방안)→@Docs(대응 전략 문서)→@캘린더(검토 일정 추가).
  - **순서가 중요**: 정보 확인→분석→기록→실행(앞 단계 결과로 다음 수행). 명확한 파일명 + 마지막에 출력 형태 지정.
- **핵심 인용**: "여러 맨션을 한 번에 불러서 사용하는 슈퍼 워크 플로우인데요. 이게 … 슈퍼 생산성이죠."
- **내 팁**: 멀티 멘션은 앞 영상들의 '워크플로우 자동화'를 노코드로 구현한 것 — 순서 설계가 곧 파이프라인 설계.

## 6. 문제 해결 · [13:38](https://youtu.be/Nk5TTif1cDQ?t=818)
- **3줄 요약**
  - 파일을 못 찾으면: ① 파일명 정확한지 ② **PDF가 이미지 스캔본이면 못 읽음**(NotebookLM으로 텍스트화) ③ 공유 문서 말고 **내 드라이브** 저장본 ④ 회사 계정은 관리자가 스마트 기능·개인 맞춤 설정 켜야(보안팀).
- **핵심 인용**: "PDF가 이미지 스캔본인 경우에는 내용을 못 읽을 수 있습니다. 텍스트가 드래그가 돼야."
- **내 팁**: 이미지 스캔본 → NotebookLM 텍스트화는 앞 영상(교사용 코워크)의 데이터 정리와 연결되는 실무 팁.

## TL;DR (5줄)

1. **@멘션**: 골뱅이로 특정 앱만 호출 → 웹 검색 차단, 내 데이터만 → **할루시네이션 제로**.
2. **7앱**: 캘린더·Keep·Tasks·Gmail·Docs·드라이브·뮤직 + Verify AI(생성물 검증).
3. **Gmail 4요소(★)**: 기간·발신자·키워드·출력. 답장은 히스토리 반영, 긴 스레드는 타임라인 복원, 관점 부여로 레드팀화.
4. **Docs·캘린더**: 정확한 제목이 검색 성능, 핀셋 추출·가공 명령, 캘린더+맵스로 스마트 스케줄러.
5. **멀티 멘션(★)**: @Gmail→@드라이브→@Docs→@캘린더를 **정보→분석→기록→실행** 순으로 엮어 원스톱 자동화. 파일명·출력 형태 지정 필수.
