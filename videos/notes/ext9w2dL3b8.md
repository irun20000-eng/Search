# 클로드+힉스필드로 상세페이지 제작방식이 바뀝니다 (Higgsfield MCP x GPT Image 2 x Seedance 2.0)

> 한 줄 요약: **힉스필드 MCP를 클로드 커넥터에 연결**하면 클로드 채팅창 안에서 **상세페이지 디자인 → 영상 변환 → GIF 모션까지** 한 번에. 힉스필드가 **GPT Image·나노바나·클링·시덴스 등 여러 AI 모델을 한 플랫폼에서** 제공하는 게 핵심 가치(툴을 오갈 필요 없음). 실무 성공의 관건은 **"상세페이지 만들어 줘"가 아니라 카피라이팅·이미지 프롬프트·디자인 스타일 규칙을 구체적으로** 주는 것, 수정도 "텍스트 수정"이 아니라 **"이 문장을 안 움직이게"처럼 정확히** 지시하는 것. 연습은 저모델(소넷 4.6)로 토큰 절약, 클로드 Pro + 힉스필드 **Plus**(스타터 미지원) 구독 필요.

## 1. 힉스필드 MCP를 클로드 커넥터에 연결 · [00:00](https://youtu.be/ext9w2dL3b8?t=0)
- **3줄 요약**
  - 클로드 채팅창에서 **상세페이지 디자인+영상+GIF 모션까지** 한 번에 제작 가능.
  - 힉스필드 가입 후 상단 **MCP** 메뉴(클로드·커서·오픈클로드 등 지원) → 클로드 선택 → **MCP URL 복사**.
  - 클로드 데스크탑 채 메뉴 → 커스터마이즈 커넥터 → **커스텀 커넥터 추가**(이름 '힉스필드', URL 붙여넣기) → 연결·동의 → 도구는 **항상 허용**(불안하면 승인 필요).
- **핵심 인용**: "클로드 MCP 연결이 아주 간편하게 끝난 거예요."
- **내 팁**: 힉스필드 MCP 연결은 앞 영상(오빠두 힉스필드 13가지, 태오 GWS)과 같은 커넥터 패턴 — 이번은 상세페이지 특화.

## 2. ★모델 선택 + 디자인 스타일 규칙★ · [02:30](https://youtu.be/ext9w2dL3b8?t=150)
- **3줄 요약**
  - 클로드 모델: Opus 4.8·페이블5는 고성능이나 **토큰 많이 씀** → **연습은 소넷 4.6** 같은 낮은 모델, 나중에 상향.
  - **핵심**: "상세페이지 만들어 줘"가 아니라 **카피라이팅 + 이미지 프롬프트 + 디자인 스타일 규칙을 정확히** 줘야 원하는 결과.
  - 실무는 **실제 촬영 이미지** 사용, 특히 **제형(텍스처) 컷**이 필요한 상세페이지는 제품 제형을 반드시 파악하고 제작.
- **핵심 인용**: "상세 페이지 만들어 줘라고 하기보다는 디자인 스타일을 정확하게 주면서 완성을 해 달라고 하면."
- **내 질문**: '스타일 규칙을 구체적으로'는 앞 영상 전부(오팔 프롬프트 5구성, Jay Choi 레퍼런스)의 공통 결론 — 구체성이 결과를 가른다.

## 3. 상세페이지 생성 + 모델별 수정(GPT Image·나노바나) · [03:59](https://youtu.be/ext9w2dL3b8?t=239)
- **3줄 요약**
  - 프롬프트 입력 → 힉스필드가 **GPT Image 모델로 상세페이지 1안·2안** 동시 생성. **Recreate**(프롬프트 유지·다른 디자인), **Edit**(가독성 등 부분 수정).
  - **나노바나 모델로 편집** 요청도 가능 — 레퍼런스 이미지를 주면 반영. GPT Image vs 나노바나 비교(발표자는 GPT가 더 깔끔).
  - 여러 수정 방법(리크리에이트·에디트·레퍼런스)을 시연하며 원하는 방향으로 좁혀감.
- **핵심 인용**: "GPT가 좀 더 디자인을 잘해 준다라고 느껴지긴 합니다."
- **내 팁**: 한 플랫폼서 GPT Image·나노바나를 오가며 비교·수정 — AI마다 잘하는 분야가 달라 비교가 실무 품질을 높임.

## 4. ★영상 변환(클링/시덴스) + GIF 모션★ · [06:20](https://youtu.be/ext9w2dL3b8?t=380)
- **3줄 요약**
  - 이미지에 마우스 올려 **Animate** 클릭 → 영상 변환. 결과가 과하면 **"클링(Kling)으로 만들어 줘"**로 모델 변경(상세페이지에 클링 많이 씀, 손 표현 더 예쁨).
  - 부분 수정도 **정확히**: "텍스트 안 움직이게"가 아니라 **"'끈적임 없이 3초만에 흡수됩니다'를 안 움직이게"**처럼 지목.
  - 완성 영상을 **"GIF 이미지로 만들어 줘"** → 힉스필드가 영상을 찾아 GIF 생성 → 다운로드로 저장(상세페이지 업로드용).
- **핵심 인용**: "정확히 '끈적임 없이 3초만에 흡수됩니다'를 안 움직이게 줘. 이런 식으로 정확하게 요청."
- **내 질문**: 이미지→영상→GIF가 채팅창 안에서 이어지는 건 앞 영상(오팔 이미지→영상 자동화)과 같은 '한 흐름 연결' 가치 아닐까?

## 5. 구독·요금제 + 실무 활용 원칙 · [08:59](https://youtu.be/ext9w2dL3b8?t=539)
- **3줄 요약**
  - 힉스필드는 **GPT Image·시덴스·클링·나노바나 등 여러 AI를 한 곳에서** — 서비스를 오갈 필요 없음. 클로드 Pro + 힉스필드 **Plus**(스타터 미지원, Plus부터). 월단위로 먼저 써보고 연단위 전환 권장.
  - **실무 원칙**: 결과물이 멋져도 실무에 못 쓰면 구독료 아까움 → **카피·이미지 프롬프트·디자인 스타일 구체화** + **AI마다 잘하는 분야 비교**.
  - "AI를 쓰는 것보다 **AI에게 어떻게 요청하는지**가 더 중요". 섹션마다 프롬프트 입력은 비효율 → 상세페이지 전 과정 **디자인 에이전트**로 효율화(별도 업데이트 안내).
- **핵심 인용**: "이제는 AI를 사용하는 것보다 AI에게 어떻게 요청하는지가 더 중요해졌습니다."
- **내 팁**: '한 플랫폼서 다중 모델 + 요청의 구체성'은 이 배치 전체(오팔·코워크·힉스필드)의 공통 결론 — 도구 통합과 프롬프트 구체성이 실무의 두 축.

## TL;DR (5줄)

1. **연결**: **힉스필드 MCP URL을 클로드 커스텀 커넥터**에 추가 → 채팅창서 상세페이지 디자인·영상·GIF까지.
2. **모델·스타일(★)**: 연습은 **소넷 4.6**(토큰 절약). "상세페이지 만들어 줘"가 아니라 **카피+이미지 프롬프트+디자인 스타일 규칙** 구체화(실무는 실제 이미지·제형 파악).
3. **생성·수정**: **GPT Image**로 1·2안 생성, Recreate/Edit/레퍼런스로 수정, **나노바나 편집** 병행 비교.
4. **영상·GIF(★)**: Animate로 영상 변환(과하면 **클링**으로), 부분 수정은 문장 지목해 정확히 → **"GIF로 만들어 줘"**로 GIF 저장.
5. **구독·원칙**: 힉스필드가 **GPT Image·시덴스·클링·나노바나를 한 곳에서**(클로드 Pro+힉스필드 **Plus**). 핵심은 **요청의 구체성**과 **AI별 강점 비교**.
