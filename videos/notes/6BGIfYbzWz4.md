# 카드뉴스 한 땀 한 땀 만드시나요? 자동화로 대량 제작하세요! 제미나이 잼스(Gems) + 캔바 대량 제작! 구글 시트 연동부터 매직 미디어 이미지 교체 팁까지 🎨🤖⚡(ver.2)

> 한 줄 요약: **제미나이 잼스(Gems)**를 활용해 10장 분량의 카드뉴스 기획안과 이미지 프롬프트를 자동 생성하고, 이를 **구글 시트**와 연동하여 **CSV 파일**로 내보낸 뒤, **캔바(Canva)의 대량 제작 앱**을 통해 템플릿 필드에 데이터를 일괄 매핑하여 순식간에 10페이지 카드뉴스를 완성하고 **매직 미디어(Magic Media)** AI 이미지 교체로 퀄리티를 높이는 디자인 자동화 워크플로우를 완벽하게 정리한다.

## 1. ★제미나이 잼스 활성화 및 카드뉴스 기획 비서 설정★ · [00:00](https://youtu.be/6BGIfYbzWz4?t=0)
- **3줄 요약**
  - 카드뉴스 콘텐츠를 수작업으로 한 땀 한 땀 제작하던 비효율을 개선하기 위해 **제미나이 잼스(Gems)** 기반 맞춤형 기획 비서를 구축한다.
  - 제미나이 설정(톱니바퀴 아이콘) 메뉴에서 잼스 기능을 활성화한 뒤 **새 잼**을 생성하여 전문 카피라이터 프롬프트를 설정한다.
  - 사전 세팅된 잼스는 사용자가 주제만 입력하면 카드 역할, 메인 카피, 서브 카피, 이미지 생성 프롬프트까지 일괄 기획하도록 설계된다.
- **핵심 인용**: "나만의 맞춤형 AI 인공지능 잼스로 카드 뉴스 내용을 짜고 구글 시트 복사해서 캔바에 대량 제작하기까지 이 과정 혹시 일일이 다 한 땀 한 땀 하고 계셨나요"
- **내 팁**: 잼스 프롬프트에 10장의 카드 번호와 각 장의 역할(표지, 문제 제기, 솔루션, 실천 팁 등)을 표 형태로 출력하도록 미리 정의해 두면 구글 시트 내보내기 시 별도 가공이 필요 없다.

## 2. 저속노화 라이프스타일 10장 기획안 생성 및 모델 선택 · [02:09](https://youtu.be/6BGIfYbzWz4?t=129)
- **3줄 요약**
  - 40대 직장인과 주부를 타깃으로 하는 **저속노화 라이프스타일 실천법** 주제를 입력하여 총 10장의 카드뉴스 기획안을 생성한다.
  - 영상은 안정성과 속도를 이유로 **플래시(Flash) 계열** 생성 모델을 권장한다.
  - 출력 결과에는 표지부터 본문 8장, 결론까지 일목요연하게 정리된 **메인 카피**, **핵심 키워드**, **해시태그**, **이미지 생성 프롬프트**가 포함된다.
- **핵심 인용**: "여기 적어 놓은 대로 이 아이는 카드 뉴스 전문 기획자이자 카피라이터고요 제가 주제를 입력하면 아래 기준에 맞춰서 총 열 장의 카드뉴스를 기획해 주는 전문 비서예요"
- **내 팁**: 카드뉴스 본문 텍스트는 가독성을 위해 긴 문장의 메인 카피와 짧고 명확한 서브 카피(핵심 키워드)로 위계를 나누어 기획하는 것이 효과적이다.

## 3. 구글 시트 연동 및 대량 제작용 CSV 데이터 추출 · [03:42](https://youtu.be/6BGIfYbzWz4?t=222)
- **3줄 요약**
  - 제미나이 출력 결과의 더보기 메뉴에서 **시트로 내보내기**를 실행하여 생성된 기획안 테이블을 스프레드시트로 즉시 변환한다.
  - 스프레드시트 내에 카드 순서대로 정리된 핵심 키워드, 메인 카피 텍스트, 이미지 생성 프롬프트 컬럼 데이터가 깔끔하게 안착된다.
  - 캔바 대량 제작 시스템에서 인식할 수 있도록 구글 시트 파일 메뉴에서 **CSV 확장자** 형태로 로컬 다운로드한다.
- **핵심 인용**: "새 스프레드시트가 생성되었습니다라고 나오고요 시트 열기라고 눌러 주시면 이제 시트가 아까 내용대로 생성이 되는 것을 보실 수가 있습니다"
- **내 팁**: CSV로 저장하기 전 구글 시트에서 오탈자나 불필요한 줄바꿈을 미리 검수해 두면 캔바 템플릿에 데이터가 연동된 후 디자인이 깨지는 문제를 사전에 방지할 수 있다.

## 4. 캔바 템플릿 세팅 및 데이터 필드 매핑 준비 · [05:03](https://youtu.be/6BGIfYbzWz4?t=303)
- **3줄 요약**
  - 캔바에서 표지와 결론을 제외한 **본문 공통 템플릿** 1장을 기준으로 글자 크기, 행간, 타이틀 색상, 폰트 스타일을 사전에 세팅한다.
  - 주제 분위기(저속노화)에 맞춰 묵직한 타이틀 색상과 가독성 높은 폰트를 적용하고 배경 레이아웃 구도를 정돈한다.
  - 템플릿 상에 메인 카피 영역과 서브 카피(소제목) 영역의 텍스트 상자를 명확히 배치하여 데이터 연동 위치를 확보한다.
- **핵심 인용**: "이 한 장이 본문이고요 표지랑 마지막 장을 제외한 본문 여덟 장이 이대로 포맷이 될 거고요 표지와 마지막 장은 여러분들께서 추가하셔서 조금 보완을 하신 다음에 하시면 좋겠습니다"
- **내 팁**: 캔바 대량 제작 기능은 기준 템플릿 1장의 레이아웃을 그대로 복제하므로 텍스트 상자의 너비와 정렬(좌측 정렬 또는 가운데 정렬)을 넉넉하게 잡아두어야 긴 문장도 깔끔하게 들어간다.

## 5. ★캔바 대량 제작 앱 구동과 10페이지 일괄 생성★ · [07:12](https://youtu.be/6BGIfYbzWz4?t=432)
- **3줄 요약**
  - 캔바 좌측 메뉴의 **대량 제작(Bulk Create)** 앱을 실행하고 다운로드했던 CSV 데이터 파일을 업로드한다.
  - CSV 헤더 필드 중 메인 카피와 서브 카피 데이터를 캔바 템플릿의 해당 텍스트 상자에 **데이터 연결(드래그 앤 드롭)** 방식으로 매핑한다.
  - 계속 버튼을 누르고 페이지 생성을 클릭하면 1페이지부터 10페이지까지 지정된 포맷으로 카드뉴스가 **단 몇 초 만에 일괄 생성**된다.
- **핵심 인용**: "대량 제작 여기 똑같은 아이콘 보이시죠 얘랑 똑같은 아이콘 요걸 눌러 주시면 저처럼 이게 꺼내져요 그래서 쓰시면 되시겠고 데이터 업로드 눌러 주신 다음에 아까 다운 받은 요거 마지막 걸로 열기 눌러 주시면 자동으로 아까 그 포맷에 있던 소제목 보이시죠"
- **내 팁**: 대량 생성 직후 표지와 마지막 결론 페이지는 템플릿 레이아웃이 단조로울 수 있으므로 추천 템플릿 디자인을 추가 적용하여 차별화된 표지 비주얼을 구성하는 것이 좋다.

## 6. 매직 미디어 AI 이미지 생성 및 가로형 레이어 교체 실전 팁 · [11:08](https://youtu.be/6BGIfYbzWz4?t=668)
- **3줄 요약**
  - 캔바 내장 AI 이미지 생성 도구인 **매직 미디어(Magic Media)**를 열고 구글 시트에 기재된 이미지 프롬프트를 복사하여 입력한다.
  - 디자인 일관성을 유지하기 위해 카드뉴스 세트 전체에 동일한 스타일(바이브런트 등)을 적용하여 통일감을 부여한다.
  - 템플릿의 프레임 비율에 맞게 정사각형(1:1) 대신 **가로형 비율**로 생성하여 이미지가 잘리지 않고 프레임에 자연스럽게 배치되도록 조정한다.
- **핵심 인용**: "정사각형 말고 지금 저는 세팅이 가로가 조금 더 기니까 가로형으로 하고 바꿔서 해 보도록 하겠습니다 여러분들도 미리 세팅한 템플릿에 맞춰서 비율 조정하실 수 있거든요"
- **내 팁**: 이미지를 프레임에 교체할 때 배경으로 자동 고정되어 드래그가 안 되는 경우 이미지를 우클릭하여 '배경에서 분리'를 선택한 뒤 새 이미지를 교체하면 손쉽게 수정할 수 있다.

## TL;DR (5줄)
1. **잼스 기획**: 제미나이 맞춤형 잼스를 통해 10장 구성의 카드뉴스 카피와 이미지 프롬프트를 자동 기획한다.
2. **시트 및 CSV 연동**: 생성된 표를 구글 시트로 즉시 내보내고 캔바 연동을 위해 CSV 포맷으로 저장한다.
3. **템플릿 최적화**: 캔바에서 본문 기준 템플릿의 폰트, 행간, 텍스트 박스 위치를 사전 세팅한다.
4. **대량 제작 자동화**: 캔바 대량 제작 앱으로 CSV 필드를 연결하여 10장의 카드뉴스를 일괄 자동 생성한다.
5. **AI 이미지 커스텀**: 매직 미디어 도구로 가로형 프롬프트 이미지를 생성해 템플릿별 비주얼을 완성한다.
