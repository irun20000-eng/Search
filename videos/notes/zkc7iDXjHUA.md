# Hermes Agent에 한국 AI를 붙이면 생기는 일!

> 한 줄 요약: 외산 AI 모델의 어색한 한국어 표현 한계를 극복하기 위해, **에르메스 에이전트(Hermes Agent)**에 국산 독자 파운데이션 모델인 **업스테이지 솔라 프로(Solar Pro)** API를 프로바이더로 연동하고, GPT·Grok·DeepSeek을 결합한 **MOA(Mixture of Agents) 믹스 파이프라인**을 구축하여 **자연스러운 고품질 한국어 에듀테크 분석 리포트**를 작성하고 **옵시디언(Obsidian) 인박스**에 자동 저장하는 워크플로우를 제시한다.

## 1. ★국산 독파모델 솔라 프로(Solar Pro) 도입과 한국어 강점★ · [00:00](https://youtu.be/zkc7iDXjHUA?t=0)
- **3줄 요약**
  - 외산 모델이 '교포 에이전트' 느낌을 준다면 국내 모델인 **솔라 프로(Solar Pro)**는 진짜 '한국인 직원' 느낌을 준다.
  - 업스테이지 콘솔에서 API 키를 발급받아 에르메스 에이전트의 프로바이더 목록에 등록한다.
  - 국산 독자 파운데이션 모델의 뛰어난 한국어 문장 구사력을 에이전트 시스템에 적극 이식한다.
- **핵심 인용**: "외산 모델들은 어 교포 교포 에이전트라는 생각이 들었다고 한다면 어 우리나라의 독파모델을 사용했을 때는 이제 그야말로 이제 한국인 에이전트 한국인 직원을 채용한 기분이 들었어요."
- **내 팁**: 업스테이지 개발자 사이트에서 API 키를 생성하고 에르메스 에이전트 설정의 프로바이더 토글을 켜서 솔라 모델을 바인딩한다.

## 2. 에르메스 에이전트 API 키 설정 및 연결 테스트 · [04:36](https://youtu.be/zkc7iDXjHUA?t=276)
- **3줄 요약**
  - 에르메스 에이전트 우측 상단 오픈 세팅의 **프로바이더(Provider)** 메뉴로 진입한다.
  - 목록 하단의 **Upstage Solar** 토글을 켜고 복사한 API 키를 붙여넣는다.
  - 대화창에서 예의 바른 인사 테스트를 진행하여 정상적인 통신 응답을 확인한다.
- **핵심 인용**: "최신 업데이트된 NMS 에이전트에서는 가장 아래에서 세 번째 업스테이지 솔라라는 모델이 보입니다 그리고 이것을 톡을 열어 주시고요 여기에 지금 복사하신 API 키를 붙여 넣게 해 주시면 됩니다."
- **내 팁**: API 키 등록 후 기본 프롬프트로 인사말 테스트를 먼저 수행하여 연결 상태의 정상 여부를 확인한다.

## 3. ★MOA(Mixture of Agents) 구조와 어그리게이터 모델 설계★ · [06:54](https://youtu.be/zkc7iDXjHUA?t=414)
- **3줄 요약**
  - **MOA(Mixture of Agents)**는 단일 모델이 아닌 여러 특화 모델을 조합해 최상의 결과물을 내는 기술이다.
  - 리서치 레퍼런스 모델로 **GPT(Luna Pro), Grok 4.5, DeepSeek V4 Flash**를 다중 배치한다.
  - 각 모델의 분석 내용을 최종 취합·합성하는 **어그리게이터(Aggregator)**로 솔라 프로를 지정하여 'DPM' 프리셋을 생성한다.
- **핵심 인용**: "어그리게이터로 저는이 독파모델 중에이 한글 한글화시키는 그 한글의 맛을 어 이용을 하고 싶거든요 그래서 다양한 레퍼런스들 뭐 GPT 루나 프로나 그다음에 그록이 작업한 내용을 제출할 때이 업스테이지의 솔라 프로4로 좀 글이 있는 그런 리포트를 받아보기 위해서이 DPM미ure 오브 에이전트 기능을 사용하도록 한 겁니다."
- **내 팁**: 리서치는 정보력이 우수한 외산 모델에 맡기고, 최종 리포트 합성 어그리게이터는 한국어 능력이 뛰어난 솔라 프로로 지정해 시너지를 낸다.

## 4. 대화를 통한 MOA 프리셋 자동 생성 팁 · [09:33](https://youtu.be/zkc7iDXjHUA?t=573)
- **3줄 요약**
  - 초보자가 수동으로 여러 모델을 조합하기 어려울 때는 **에이전트에게 MOA 프리셋 생성을 직접 요청**한다.
  - 솔라 프로를 어그리게이터로 두고 리서치 모델을 추천해 프리셋을 만들어 달라고 지시한다.
  - 에이전트가 최적 모델 조합을 분석하여 원클릭으로 새로운 MOA 프리셋을 자동 구성한다.
- **핵심 인용**: "구독자님들께서 잘 모르시는 그 모델들을 막 공부해서 일일이 해 보시고 하시는 것보다 LMS 에이전트가 일을 할 거니까 일 할 친구에게 조사해서 어 세팅을 해 달라고 요청을 하시는게 제가 볼 때는 어 초보자분들께는 정말 좋은 팁이 될 것 같습니다."
- **내 팁**: 복잡한 모델 조합 설정은 에르메스 에이전트 대화창에 목적을 설명하고 프리셋 세팅을 전담시켜 설정 시간을 단축한다.

## 5. ★K-12 AI 교육 리포트 생성 및 옵시디언(Obsidian) 자동 저장★ · [12:04](https://youtu.be/zkc7iDXjHUA?t=724)
- **3줄 요약**
  - 4개 모델이 협업하는 DPM MOA 모드로 **2026 대한민국 K-12 AI 에듀테크 리포트 작성**을 지시한다.
  - 외산 모델이 조사한 방대한 팩트를 솔라 프로가 자연스러운 한국어 문맥으로 완벽히 통합한다.
  - 완성된 보고서는 로컬의 **옵시디언 `00-Inbox` 폴더**에 마크다운 파일로 자동 기록 및 보관된다.
- **핵심 인용**: "총네 개의 모델들이 각각의 특성 장점들을 활용을 해서 어 제출을 해 주고 그것을 솔라 프로포가 수합을 한 다음에 어 가장 퀄리티가 좋은 한글로 리포트를 작성해 준다고 보시면 될 거 같아요."
- **내 질문**: 옵시디언 인박스로 저장된 마크다운 리포트에 프론트매터 태그와 내부 위키링크([[...]])를 자동 생성하여 지식 그래프를 확장하는 세부 프롬프트가 지원되는지 궁금하다.

## TL;DR (5줄)
1. **솔라 프로 연동**: 업스테이지 API를 에르메스 에이전트에 등록해 자연스러운 한국어 구사력을 확보한다.
2. **MOA 아키텍처**: GPT, Grok, DeepSeek의 리서치 결과물을 솔라 프로가 취합하는 4개 모델 협업 구조를 세팅한다.
3. **어그리게이터 역할**: 한국어에 특화된 국산 모델을 최종 합성 주체로 두어 번역투 없는 고품질 문장을 산출한다.
4. **프리셋 자동화**: 에이전트 대화를 통해 사용자 목적에 맞춘 MOA 프리셋 설정을 손쉽게 자동 생성한다.
5. **옵시디언 저장**: 완성된 심층 에듀테크 분석 리포트를 로컬 옵시디언 인박스 폴더로 자동 전송·보관한다.
