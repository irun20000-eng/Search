# 99%는 모르는 종이 질감 모션그래픽, 감각 없이도 만드는 법 (feat. 구글 Flow 옴니)

> 한 줄 요약: EBS 다큐·Vox 스타일의 '종이 콜라주 모션그래픽'을 감각 없이도 무료로 만드는 워크플로우 — **핀터레스트에서 레퍼런스(감각)를 다운 → 구글 Flow에 올려 '스타일 시트'(일관성 기준)를 만들고 → 그 시트로 각 씬 이미지(나노바나나 0크레딧) → 종이 콜라주 모션그래픽 영상화**. 퀄리티는 Seedance로↑, 나레이션은 구글 AI 스튜디오 Gemini TTS로 무료. 핵심 통찰: **"창작하지 말고 감각을 많이 접하라"** + **스타일 시트 하나만 바꾸면 다른 영상을 무한 반복 제작**.

## 1. 이미지가 뼈대 + "감각을 접하라" · [02:08](https://youtu.be/REGLr2rGvgs?t=128)
- **3줄 요약**
  - 모션그래픽에서 가장 중요한 건 **기준이 되는 이미지**(뼈대) — 이미지 감성이 좋으면 영상도 좋고, 애매하면 프롬프트를 잘 써도 퀄리티가 안 남.
  - "감각이 없는데요"에 대한 답: **창작하지 말고 감각을 많이 접하라** — 잘하는 사람도 레퍼런스를 쌓아 영감을 얻음.
  - **핀터레스트**에서 'Vox 스타일 디자인' 검색 → 마음에 드는 이미지를 **여러 장** 다운(이게 '내 감각'이 됨).
- **핵심 인용**: "창작을 하지 마시고 감각을 많이 접하시면 됩니다."
- **내 질문**: '감각=다운로드 가능한 레퍼런스'라는 관점은 앞 영상들의 '디자인 MD/레퍼런스 재료화'와 같은 발상 — 취향도 자산화·재사용되는 시대 아닐까?

## 2. ★구글 Flow — 스타일 시트로 일관성★ · [04:11](https://youtu.be/REGLr2rGvgs?t=251)
- **3줄 요약**
  - **구글 Flow**(랩스) New Project에 레퍼런스 이미지 드래그 업로드. 교육용은 클립이 여러 개라 스타일이 따로 놀면 이질감 → **기준점 '스타일 시트'를 먼저 제작**.
  - **에이전트를 켜고**(초보 추천 — 단계별로 잡아주고 대화로 수정) 프롬프트: "에셋으로 넣을 시트 이미지(스타일·컬러 팔레트·텍스트·숫자 포함), 저작권 피해 약간 변형해 내 스타일로."
  - Flow 팁: **드래그로 여러 이미지 한꺼번에 선택**, **한 번에 최대 10개**.
- **핵심 인용**: "그 기준점이 되는 시트를 만들 겁니다. … 스타일이 다 따로 놀게 되면 영상 전체적으로 봤을 때는 이질감이 존재."
- **내 팁**: '스타일 시트 = 영상의 디자인 시스템' — 앞 영상(코워크)의 design.md와 같은 역할(일관성의 단일 기준).

## 3. 씬 이미지 + 모션그래픽 영상화 · [07:42](https://youtu.be/REGLr2rGvgs?t=462)
- **3줄 요약**
  - "그 시트와 비슷한 형식으로 각 씬 이미지 제작"(텍스트 최소·로고/이미지 위주). **나노바나나(이미지 모델)는 0크레딧(무료)** → 씬별로 많이 뽑아 **하트**로 골라 모음.
  - 하트한 이미지를 올려 "각 상황에 맞는 **종이 콜라주 모션그래픽**으로 영상화" → 크레딧 사용 승인.
  - ★크레딧: 무료 **하루 50**(월 1500) vs 유료 구글 원 프로 **월 1000** → 무료가 더 많이 쓸 수 있음. 무료 50 먼저, 모자라면 유료 병행.
- **핵심 인용**: "무료는 하루 50크레딧이니까 30일이면 … 무료가 유료보다 더 많이 쓸 수 있는 그런 말도 안 되는 상황."
- **내 질문**: 무료 크레딧이 유료보다 총량이 많은 역설 — 초기 유저 확보용 정책인데, 매일 접속하는 사용자에게 최적화된 구조 아닐까?

## 4. 퀄리티·나레이션·확장 — Seedance·TTS·Remotion · [11:01](https://youtu.be/REGLr2rGvgs?t=661)
- **3줄 요약**
  - 퀄리티↑는 **Seedance**(움직임 표현 한 수 위) — Dreamina/CapCut에서, ChatGPT로 "이 프롬프트를 Seedance 15초용으로" 변환 + **옴니 레퍼런스**로 시트 이미지 첨부.
  - 나레이션(교육 영상의 핵심)은 **구글 AI 스튜디오**에서 무료 — Playground → Models → Speech → **Gemini Flash TTS Preview**, Scene·샘플 컨텍스트로 스타일 반영, 대본 넣고 Run → 다운로드.
  - 편집에서 클립 순서 배치 + 나레이션·배경음악. **스타일 시트만 바꾸면 다른 영상 무한 반복**. 정밀 차트는 **Remotion**(추후).
- **핵심 인용**: "스타일 시트 하나만 또 다른 스타일로 적용을 한다면 무한 반복으로 다른 영상들도 마음대로 만들어 낼 수가 있습니다."
- **내 팁**: 이미지(나노바나나)·영상(Seedance)·음성(Gemini TTS)이 전부 무료 티어로 조립 가능 — 콘텐츠 제작의 진입장벽이 사실상 0.

## TL;DR (5줄)

1. **원리**: 모션그래픽은 **이미지가 뼈대** — "창작 말고 감각을 접하라", 핀터레스트에서 Vox 스타일 레퍼런스를 여러 장 다운.
2. **일관성(★)**: 구글 Flow에서 **스타일 시트**를 먼저 만들어 클립 간 이질감 제거(에이전트 켜고 작업, 최대 10장/드래그 선택).
3. **제작**: 시트로 각 씬 이미지(**나노바나나 0크레딧**, 하트로 선별) → **종이 콜라주 모션그래픽** 영상화.
4. **크레딧**: 무료 하루 50(월 1500) > 유료 월 1000 — 무료 먼저, 부족하면 유료.
5. **확장**: 퀄리티는 **Seedance**(옴니 레퍼런스), 나레이션은 **구글 AI 스튜디오 Gemini TTS**(무료), 차트는 Remotion. 스타일 시트만 갈아끼우면 무한 반복.
