# 구글 AI 3대 업데이트 총정리 — 구글 Vids AI아바타 + 노트북LM 쇼츠 + Gemini×NotebookLM 연동

> 한 줄 요약: 2026년 구글의 실전용 업데이트 3가지 — ① 구글 Vids의 'AI 아바타'로 내 썸네일 얼굴을 입힌 말하는 아바타 만들기, ② NotebookLM 비디오 오버뷰의 '쇼츠' 생성(아직 한글 자막 폰트 깨짐, 영어는 고퀄), ③ Gemini에서 내 NotebookLM 노트를 불러와 Canvas로 인터랙티브 HTML 학습페이지(플래시카드·퀴즈)를 만들고 링크 공유.

## 1. 인트로 — "충격은 줄었지만 생태계는 여전히" · [00:00](https://youtu.be/xkSY_A-Y1Mc?t=0)
- **3줄 요약**
  - 구글이 2025년만큼의 센세이션은 못 보여주지만, 최근 업데이트 중 실사용에서 매력적이었던 기능 3가지를 소개한다.
  - 다룰 것: 구글 Vids(AI 아바타), NotebookLM 쇼츠, Gemini×NotebookLM 연동.
  - 세 기능 모두 "업무·교육 자료 제작"이라는 실용 목적에 초점.
- **핵심 인용**: "구글만이 가지고 있는 이 사용성, 생태계의 부분은 결코 무시할 수 없는 것 같습니다."
- **내 질문**: 센세이션(모델 성능) 대신 '생태계 통합'으로 승부하는 구글 전략은 개인 생산성 워크플로우에 어떤 락인을 만드는가?

## 2. 구글 Vids — 'AI 아바타' 커스텀 생성 · [01:25](https://youtu.be/xkSY_A-Y1Mc?t=85)
- **3줄 요약**
  - Start New Video → **AI 아바타** → Create Custom Avatar. 기본 아바타에 아시아인이 없어 직접 생성한다.
  - 설정: 성별 Male / 나이 Young Adult / **Racial Background = East Asian** / Outfit 캐주얼 → Create.
  - 생성된 동양인 남성 아바타 후보 중 하나를 골라 Refine Select로 넘어간다.
- **핵심 인용**: "이제는 Create Custom Avatar에서 자기의 커스텀한 아바타를 또 만들 수 있거든요."
- **내 질문**: 인종·연령·복장을 파라미터로 고르는 아바타 생성이 표준이 되면, '내 채널 브랜드 얼굴'을 코드처럼 버전 관리할 수 있을까?

## 3. 내 썸네일로 '내 얼굴 아바타' 만들기 + 음성·립싱크 · [03:10](https://youtu.be/xkSY_A-Y1Mc?t=190)
- **3줄 요약**
  - 지난 영상 **썸네일 이미지를 업로드**하고 "이 이미지 그대로 사용하게 해 줘"가 가장 안정적인 Refine 프롬프트 → 내 얼굴이 아바타에 반영됨(간헐적으로 불안정).
  - 음성은 Select Voice에서 'Teacher' 남자 목소리 선택, 아바타 이름 지정 → 한글 대본 입력 → **Preview로 소리 확인 후 Generate**.
  - Generate하면 대본에 맞춰 **입 모양 립싱크**까지 된 말하는 아바타 영상 완성.
- **핵심 인용**: "그러면 이제 이 아바타가 이 대본에 입, 립싱크까지도 해 주는 겁니다."
- **내 팁**: 일반 아이폰 사진보다 **썸네일 형식(이미지+텍스트)** 파일을 훨씬 잘 인식 → 얼굴 소스는 썸네일류로 올려라.

## 4. NotebookLM — 비디오 오버뷰의 '쇼츠' 생성 · [06:12](https://youtu.be/xkSY_A-Y1Mc?t=372)
- **3줄 요약**
  - NotebookLM 업데이트로 **비디오 오버뷰에 'Shorts'** 기능 추가 → 90초 이내 세로 쇼츠 자동 생성(생성에 5분 이상 소요).
  - **한계: 한글 자막 폰트가 깨져서 출력**됨(더빙 음성은 한국어 정상). 자막이 필수인 쇼츠엔 아직 부적합.
  - 자막이 (아직) 영어만 정상 → **영어 콘텐츠/영어 교육자에겐 지금도 고퀄**. 한국어 지원은 시간 문제.
- **핵심 인용**: "아직까지는 쇼츠 화면에 한글 자막, 한글 폰트가 잘 적용이 되지 않는 것 같습니다."
- **내 질문**: '자막 없이 더빙만'으로도 쓸 수 있는 쇼츠 포맷(예: B-roll+내레이션)이라면 지금 당장 실전 투입 가능하지 않을까?

## 5. Gemini × NotebookLM 연동 — 노트를 'Canvas 인터랙티브 학습페이지'로 · [08:35](https://youtu.be/xkSY_A-Y1Mc?t=515)
- **3줄 요약**
  - Gemini 입력창 → 업로드(more) → **Notebooks**에서 내 NotebookLM 노트를 그대로 불러온다.
  - 노트 선택 후 **Canvas** + 프롬프트("이 노트를 학습할 수 있는 인터랙티브 HTML 페이지 생성, 완전 학습 가능해야 함") → **클릭 반응형 HTML + 플래시카드 + 실전 퀴즈(오답 체크 포함)** 생성.
  - 교사·직원 교육 자료로 바로 활용 가능한 수준.
- **핵심 인용**: "이 노트를 학습할 수 있는 인터랙티브한 HTML 페이지를 생성해 줘. 완전 학습이 가능해야 한다."
- **내 질문**: NotebookLM(소스 관리) → Gemini Canvas(산출물 생성)의 파이프라인은, 지금 내 video2post 파이프라인(노트→갤러리)과 사실상 같은 패턴 아닌가?

## 6. 공유 & 마무리 — 링크로 학습페이지 배포 · [11:20](https://youtu.be/xkSY_A-Y1Mc?t=680)
- **3줄 요약**
  - 완성된 HTML은 **다운로드**뿐 아니라 **Share 링크 공유** 가능 → 공유자가 Gemini 로그인 상태면 링크로 접속해 함께 사용.
  - 교사가 아이들과 함께 쓰는 학습 콘텐츠를 만들어 **수업 링크로 배포**하는 활용을 제안.
  - 총평: 모델 자체 충격은 줄었지만 구글의 사용성·생태계 통합은 무시 못 함.
- **핵심 인용**: "공유 링크를 공유해서 수업에 활용하실 수도 있을 것 같습니다."
- **내 질문**: '로그인 필요' 공유 장벽 때문에, 완전 공개 배포는 여전히 HTML 다운로드→자체 호스팅(예: GitHub Pages)이 더 낫지 않나?

## TL;DR (5줄)

1. **구글 Vids AI 아바타**: 인종·성별·복장으로 아바타를 만들고, 내 **썸네일 이미지**를 올려 "그대로 사용해 줘"로 내 얼굴을 입힌 뒤 음성·**립싱크** 말하는 영상까지 생성.
2. **얼굴 소스 팁**: 일반 사진보다 이미지+텍스트가 섞인 **썸네일 형식**을 훨씬 잘 인식한다.
3. **NotebookLM 쇼츠**: 90초 세로 쇼츠 자동 생성 — 단 **한글 자막 폰트 깨짐**(더빙은 정상), 영어 콘텐츠엔 지금도 고퀄.
4. **Gemini×NotebookLM**: Gemini에서 내 노트를 불러와 **Canvas**로 플래시카드·퀴즈가 있는 인터랙티브 HTML 학습페이지를 만들고 **링크 공유**.
5. **관전 포인트**: 구글은 모델 성능 경쟁보다 **툴 간 생태계 통합(Vids·NotebookLM·Gemini Canvas)**으로 실사용 가치를 만든다.
