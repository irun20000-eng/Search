## 1. 텍스트를 생성하지 않는 AI 모델 제브(Jev)의 등장과 배경 · [00:00](https://youtu.be/mhgCbF6_IKo?t=0)
- **3줄 요약**
  - 대화나 설명, 문장 작성 기능이 전혀 없음에도 **대량 데이터 분류와 매칭 작업**에서 폭발적인 반응을 얻고 있는 제브를 소개한다.
  - 단순 수치 비교를 넘어 맥락을 읽어야 하는 고객 불만 수준이나 채용 조건 매칭 같은 **정성적 판단을 정량적 점수**로 변환한다.
  - 프로그램이 즉각 처리할 수 있는 숫자 형태의 판단 결과만을 도출하여 기존 LLM의 비효율을 걷어내는 보조 도구로 작동한다.
- **핵심 인용**: "정작이 모델은 문장 하나 쓰지 못합니다 대화를 나눌 수도 없고 왜 그렇게 판단했는지 설명해 주지도 않죠 그렇다면 어떻게 이런 작업들을 처리하는 걸까요"
- **내 팁**: 제브는 긴 글을 작성하는 대화형 모델이 아니므로, 복잡한 비즈니스 로직에서 사람의 직관적 해석이 필요한 텍스트를 수치 데이터로 정량화하는 용도로 접근해야 한다.

## 2. ★기존 LLM과의 차이점: 순차 생성 vs 병렬 판단 아키텍처★ · [02:15](https://youtu.be/mhgCbF6_IKo?t=135)
- **3줄 요약**
  - 기존 언어 모델은 다음 토큰을 하나씩 순차적으로 예측·생성하므로 단순 분류 작업에서도 **불필요한 시간과 토큰 비용이 발생**한다.
  - 제브는 문장 생성을 배제하고 문의 유형, 환불 요청 여부, 불만 점수 등 **여러 질문을 병렬(Parallel)로 동시 평가**하도록 설계되었다.
  - 하나의 답을 기다린 뒤 다음 질문을 넘기는 대신 단일 요청으로 복합 판단을 일괄 산출하여 압도적인 속도와 저비용을 달성한다.
- **핵심 인용**: "타입세이프의 설명에 따르면 재부는 자유로운 문장 생성 대신 여러 판단 결과를 병렬로 출력하도록 설계했습니다 앞서 본 문의를 예로 들면 문의 유형은 무엇인지 환부를 요구하는지 불만의 정도는 어느 수준인지를 한 번의 요청에 함께 넣을 수 있습니다"
- **내 팁**: 고객 메시지 하나에 여러 판별 기준(유형, 환불 여부, 긴급도)이 필요할 때 질문을 쪼개어 여러 번 호출하지 말고 단일 요청에 병렬로 묶어 전달하면 처리 속도를 극대화할 수 있다.

## 3. ★제브의 3대 질의 구조(Bool, Choice, Score)와 불확실성 확률 반환★ · [04:02](https://youtu.be/mhgCbF6_IKo?t=242)
- **3줄 요약**
  - 질문 구조는 **조건 충족 여부를 묻는 Bool, 다중 선택지 중 고르는 Choice, 단계별 척도를 평가하는 Score**의 3가지로 나뉜다.
  - 단순 분류 라벨만 반환하는 것이 아니라 각 선택지별 **확률(예: 결제 85%, 기술 10%)을 함께 제공**하여 판단의 신뢰도를 전달한다.
  - 확률이 명확한 문의는 해당 부서로 즉시 자동 전송하고 51% 대 49%처럼 애매한 문의는 사람 검토 목록으로 분기 처리할 수 있다.
- **핵심 인용**: "정리하면 어떤 조건에 해당하는지 확인할 때는 덜 여러 항목 중 하나로 분류할 때는 초이스 정도를 평가하고 순서를 매일 때는 스코어를 사용하는 겁니다 그리고 같은 내용을 보고 판단하는 질문이라면이 세 가지를 하나의 요청에 함께 넣을 수 있습니다"
- **내 팁**: 자동화 파이프라인 설계 시 제브가 반환하는 세부 확률값을 임계치(예: 80% 이상은 자동 처리, 80% 미만은 수동 검토)로 활용하면 오분류 리스크를 크게 줄일 수 있다.

## 4. 타입세이프 가입, 5달러 충전 및 클로드 코드 공식 스킬 설치 · [06:37](https://youtu.be/mhgCbF6_IKo?t=397)

- **내 팁**: 클로드 코드에서 제브를 연동할 때는 API 키를 코드나 프롬프트에 직접 노출하지 말고 `.env` 환경 변수 파일에 격리 보관해야 보안 누출을 방지할 수 있다.

## 5. 대량 고객 문의 100건 실전 파이프라인: 제브 분류와 클로드 답변 자동화 · [10:04](https://youtu.be/mhgCbF6_IKo?t=604)
- **3줄 요약**
  - 고객 문의 100건 중 환불 및 시스템 오류는 담당자와 기술팀 검토로 넘기고 단순 사용법 문의는 클로드가 안내문을 참조해 답변 초안을 짠다.
  - 제브가 문의 유형, 환불 여부, 장애 심각도를 **5건 동시 병렬 기준 0.32초**에 평가하고 처리 목록을 자동 분할한다.
  - 전체 100건의 제브 분류 처리에 **단 5초와 약 0.017달러(2센트 미만)**만이 소요되어 극단적인 시간 및 비용 절감을 입증한다.
- **핵심 인용**: "앞서 테스트한 다섯 건까지 합친 100건의 제부 예상 사용률은 약 0.017달러 2c가 최 안되는 금액입니다 다만이 수치는 재부 분류에 대한 것으로 클로드가 답변 초안을 작성하고 대시보드를 만드는 시간과 비용은 포함하지 않습니다"
- **내 팁**: 전체 파이프라인을 LLM에 전적으로 맡기지 말고, 저비용·초고속 제브로 1차 분류 및 라우팅을 수행한 뒤 실제 답변 작성이 필요한 정형 문의에만 클로드를 선별 투입해야 API 비용을 획기적으로 절감할 수 있다.
