# 엑셀 보고서 자동화 종결 — 클라우드플레어(R2+Workers)로 100% 무료 실시간 웹 대시보드

> 한 줄 요약: 엑셀을 몰라도 되는 실시간 사내 대시보드 만들기 — ① 파워쿼리로 폴더 파일을 마우스 10클릭 취합 → ② AI(Gemini/클로드)로 데이터+스타일가이드를 주고 HTML 대시보드 생성 → ③ 클라우드플레어 **R2(창고, 무료 10GB)** 에 저장, **Workers(공개 서버)** 로 바인딩 배포, **Zero Trust Access(무료 50계정)** 로 로그인 보안 → ④ 별도 **업로드 전용 Worker + 비밀키 + 엑셀 VBA '데이터 동기화' 버튼**으로 데이터 갱신 자동화(대시보드 1분마다 자동 반영). 전부 무료 티어(임직원 ~500명까지).

## 1. 인트로 — 무엇을 만드나 · [0:00](https://youtu.be/vPR4eVtTqvo?t=0)
- **3줄 요약**
  - 회사에서 반복하던 피벗·PPT 보고서 작업을 **내 PC에서 자동화**하는 실시간 웹 대시보드를 만든다.
  - 핵심 툴은 **클라우드플레어(Cloudflare)** — 전 세계 웹의 ~20%를 떠받치는 서비스, 보안도 뛰어남.
  - **엑셀을 하나도 몰라도** 예쁜 보고서를 만들 수 있다(AI 덕분).
- **핵심 인용**: "이 대시보드는 1분마다 업데이트를 계속 하는 거예요."
- **내 질문**: '엑셀 종결'이라는 도발적 제목의 실체는 '엑셀=데이터 소스, 시각화·배포=웹'으로 역할을 분리한 것 — 스프레드시트의 미래 위치는 어디인가?

## 2. 클라우드플레어 개념 — R2(창고) vs Workers(서버) · [1:52](https://youtu.be/vPR4eVtTqvo?t=112)
- **3줄 요약**
  - 예전엔 R2·페이지·워커를 따로 연동해야 했지만, 이번에 **모두 'Workers' 하나로 통합**돼 구축이 쉬워짐.
  - **R2 = 데이터 저장 창고**: 무료 10GB(사실상 무제한), 업로드 월 100만·조회 월 천만 회.
  - **Workers = 데이터를 읽어 대시보드를 띄우는 서버**: 하루 10만 요청. 둘 다 **임직원 ~500명까지 무료 티어**로 충분.
- **핵심 인용**: "이 모든 서비스를 워커 하나로 통합했어요."
- **내 팁**: 저장(R2)과 노출(Workers)을 물리적으로 분리 → 원본은 잠그고 가공 결과만 공개하는 게 보안 설계의 핵심.

## 3. 파워쿼리로 폴더 파일 마우스 10클릭 취합 · [4:17](https://youtu.be/vPR4eVtTqvo?t=257)
- **3줄 요약**
  - 데이터 탭 → 가져오기 → **파일에서 → 폴더에서** → 폴더 선택 → **결합 및 로드** → 시트 확인 → 로드까지 **딱 10번 클릭**(키보드 불필요).
  - 폴더에 신규 연도 파일을 추가하고 표 우클릭 → **새로고침**만 하면 자동 반영되는 재사용 보고서.
  - 2016 버전은 '데이터 변환'으로 파워쿼리 편집기 → Content 펼치기 → 시트 선택 → 닫기 및 로드. (주의: **폴더 경로 바뀌면 파워쿼리 경로도 수정** 필요.)
- **핵심 인용**: "폴더 안에 있는 데이터를 마우스 클릭 10번이면 만들 수 있다."
- **내 질문**: 이 '취합'이 오늘 유일하게 손으로 하는 작업 — 이후 파이프라인 전체의 신뢰성은 이 소스 정합성에 달려 있다.

## 4. AI로 대시보드 생성 — 데이터 + 구성기획 + 스타일가이드 3단 프롬프트 · [8:39](https://youtu.be/vPR4eVtTqvo?t=519)
- **3줄 요약**
  - 무료면 **Gemini(프로 모델 무료 제공)**, 유료면 클로드 추천. 취합 데이터를 **Ctrl+Shift+V(텍스트로)** 붙여넣기.
  - 3단계 프롬프트: ① 구성요소·레이아웃 초안(KPI·차트 목록) → ② **스타일 가이드**(브랜드 250여 개 디자인 시스템 중 '삼성페이' 검색 적용) → ③ 대시보드 생성.
  - 완성된 **코드 다운로드** → 파일명을 **index**로 바꾸고 엑셀 데이터와 한 폴더에. 로컬 실행 시 검색·연도 실시간 필터 되는 대시보드 확인(엑셀/파워BI로는 며칠 걸릴 결과).
- **핵심 인용**: "이렇게 되는데도 엑셀을 쓰실 거예요?"
- **내 팁**: 실무에선 초안을 회사 분석 목표에 맞게 수정하라(영상은 수업이라 초안 그대로 사용).

## 5. R2 버킷 생성 + 파일 업로드 + 로컬 테스트 · [16:28](https://youtu.be/vPR4eVtTqvo?t=988)
- **3줄 요약**
  - 무료 가입(개인용/1인/빌드) → R2 구독(**개시하려면 카드 등록 필요**, 사용량은 사실상 무료).
  - **Create bucket**(이름은 고유값), Location은 한국이면 아시아, **반드시 'Standard'**(Infrequent Access는 무료 한도 제외) → 데이터·index 파일 드래그 업로드.
  - Settings의 **Public Development URL을 일시적으로만** 켜서 index 주소로 동작 테스트 → 확인 후 반드시 다시 끔.
- **핵심 인용**: "R2 이 창고는 저장소기 때문에 기본값은 공유가 안 되는 게 기본값이에요."
- **내 질문**: 무료를 강조하지만 R2 개시에 카드 등록이 필수 — '무료 티어 + 카드 담보' 모델의 실제 과금 리스크는?

## 6. Workers로 공개 배포 + R2 바인딩 + 이름 정리 · [22:23](https://youtu.be/vPR4eVtTqvo?t=1343)
- **3줄 요약**
  - 창고(R2)는 잠근 채 **외부 공개용 페이지 = Workers**를 만든다. Compute → Create application → **Hello World** → Deploy → Edit code에 노션 제공 대시보드 워커 코드 붙여넣기.
  - **Binding**으로 R2 버킷 연결(같은 클라우드플레어라 내부 바인딩 가능, 변수명 BUCKET) → Deploy. R2의 퍼블릭 URL은 다시 **Disable**.
  - Workers 이름을 Rename(예: OPD 웹레포트)해 **깔끔한 공개 URL** 확보.
- **핵심 인용**: "원본 데이터는 금고 안에 딱 잠겨 있는 거예요. 아무도 못 봐. 하지만 그 대시보드만 … 볼 수 있는 깔끔한 URL."
- **내 팁**: 바인딩은 같은 플랫폼 내부 연결이라 키·URL 노출 없이 저장소를 안전하게 참조하는 방식.

## 7. Zero Trust Access로 로그인 보안(무료 50계정) · [27:38](https://youtu.be/vPR4eVtTqvo?t=1658)
- **3줄 요약**
  - 클라우드플레어 **Access(Zero Trust)** 로 로그인 페이지 제공 — 무료 티어 **50계정**까지. Free 모델로 Activate.
  - Custom Pages에서 로그인 페이지 브랜딩(회사명·로고·안내문·배경색) → Workers의 **Domains에서 Public을 Restricted로** 변경해 접근 제한.
  - **Manage Policy → 이메일 추가(최대 50)** → 접속 시 이메일로 **액세스 코드** 발송받아 인증(1차 외부 보안만으로 사내 대시보드엔 충분, JWK 2차 보안은 선택).
- **핵심 인용**: "무료로 로그인 보안까지 다 처리해 주는 이런 대시보드를 무료로 할 수 있는 시대가 왔다."
- **내 질문**: 이메일 OTP 방식 50계정 무료 — 중소 규모 사내 툴 인증 문제를 사실상 공짜로 해결하는데, 왜 더 안 알려졌을까?

## 8. ★데이터 갱신 자동화 — 업로드 Worker + 비밀키 + 엑셀 VBA 버튼★ · [33:59](https://youtu.be/vPR4eVtTqvo?t=2039)
- **3줄 요약**
  - 읽기용 워커와 별도로, 외부 요청으로 **R2 데이터를 덮어쓰는 업로드 전용 Worker** 생성(노션 3-1 코드, 열면 'POST only') → R2 버킷 바인딩(BUCKET).
  - 아무나 못 쓰게 Settings 변수 **UPLOAD_SECRET=abc123** 등록(읽기는 불가, 쓰기 방지용 비밀키).
  - 엑셀 **Alt+F11 → 모듈에 VBA 붙여넣기**, 상단 설정값 3개(**업로드 워커 POST 주소 / 비밀번호 / 시트명**) 채우면 '데이터 동기화' 버튼 완성. 새로고침→동기화 클릭 → **대시보드 1분 내 자동 갱신**.
  - (참고) **구글 드라이브·원드라이브는 CORS 제약**으로 안전하게 못 씀 → R2 방식 권장.
- **핵심 인용**: "이 워커는 … R2 저장소에 있는 데이터를 바꾸도록 동작하는 워커기 때문에 POST만 가능한 워커."
- **내 팁**: 읽기 워커/쓰기 워커를 분리하고 쓰기에만 비밀키를 거는 게 공개 엔드포인트 보안의 정석.

## TL;DR (5줄)

1. **아키텍처**: 엑셀(파워쿼리 취합) → AI가 HTML 대시보드 생성 → 클라우드플레어 R2(저장)+Workers(공개)+Access(로그인).
2. **취합**: 파워쿼리 '폴더에서'로 마우스 10클릭, 신규 파일은 새로고침만으로 반영되는 재사용 보고서.
3. **생성**: 데이터+구성기획+스타일가이드 3단 프롬프트(Gemini 프로 무료), 코드 받아 index.html로.
4. **배포·보안**: R2는 잠그고 Workers로만 노출(Binding), Zero Trust로 무료 50계정 이메일 OTP 로그인.
5. **갱신 자동화(★)**: 업로드 전용 Worker + UPLOAD_SECRET 비밀키 + 엑셀 VBA '데이터 동기화' 버튼 → 대시보드 1분마다 자동 반영. 전부 무료 티어.
