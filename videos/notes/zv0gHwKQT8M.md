# AI 영상 제작, 이 두 개면 다 됩니다 — 클로드 + 힉스필드 MCP 13가지 실전 활용법

> 한 줄 요약: **힉스필드(Higgsfield) MCP를 클로드에 연결**하면 클로드가 '기획', 힉스필드가 '생성'을 맡아 광고·쇼츠·설명영상·웹페이지까지 만든다. 두 대원칙 = **① 기획을 먼저**(AI에 맡기되) **② 이미지를 먼저 만들고 영상으로**(영상이 가장 비쌈). 나만의 **가상 캐릭터 등록**(레퍼런스 시트 4K), **스킬 5개**(3D쇼츠·익스플레이너·애드스크립트·애드크리에이터 등)로 슬래시 한 번에 제작, 한국어 **나레이션 가이드**까지. "딸깍 한 번의 마법은 없지만, 몇십 시간이 몇 분으로."

## 1. 왜 MCP인가 + 두 대원칙 · [00:05](https://youtu.be/zv0gHwKQT8M?t=5)
- **3줄 요약**
  - 예전 AI 영상은 카메라·조명·움직임을 다 입력해야 했고, 이미지를 넣어도 움직임을 디테일하게 요청 안 하면 잘 안 나옴.
  - **MCP** = 클로드에게 '기획'을 맡기는 것(프롬프트 자체를 AI가). 이제 기획+제작을 한 곳에서.
  - **원칙 ① 기획을 먼저**(모든 AI 공통), **② 이미지를 먼저 만들고 영상으로**(영상이 가장 비싸니 비용·시간 절약). '딸깍 마법'은 없음("구독하면 월 천만원"은 사기).
- **핵심 인용**: "AI를 잘 쓰려면 그 앞에서 기획하는 과정에 반드시 들어가야 돼요."
- **내 팁**: '기획 먼저·이미지 먼저'는 앞 영상들(코워크 선계획, 모션그래픽 스타일 시트)의 절약 원칙과 동일 — 비싼 단계 전에 싼 단계로 검증.

## 2. 힉스필드 기본 앱 + 캐릭터 등록 · [05:13](https://youtu.be/zv0gHwKQT8M?t=313)
- **3줄 요약**
  - '슈퍼 컴퓨터' 앱: 여러 각도·조명 변경 등. **블랙타임(BlackTime)**(이미지 1장→인스타 영상, 15크레딧≈1,000원, 배경 자동), **믹스드 미디어**(아기 사진→3D 캔버스, 10프레임 권장).
  - 매번 사진 올리기 불편 → **나만의 가상 캐릭터 등록**: 셀카 6장(정면·측면·위·아래) → 노션 프롬프트로 **레퍼런스 시트(4K)** 생성(GPT Image 2).
  - **시네마 스튜디오 → My Elements → New Element**로 이름('미')+이미지 등록 → 이후 "미를 참고해서"로 내 캐릭터 영상. 배경도 'office'로 등록 가능.
- **핵심 인용**: "일관된 캐릭터 시트를 만들어 줘야 … 일관성 있는 영상과 이미지 결과물."
- **내 질문**: 캐릭터·배경을 '엘리먼트'로 등록해 재사용하는 건 앞 영상(모션그래픽 스타일 시트, 노션 템플릿)의 '일관성 자산화'와 같은 발상 아닐까?

## 3. ★클로드 × 힉스필드 MCP 연결 + 권한★ · [13:58](https://youtu.be/zv0gHwKQT8M?t=838)
- **3줄 요약**
  - 힉스필드 → MCP → 클로드 선택 → 링크 복사. 클로드 → 설정 → **커넥터** → 커스텀 커넥터 추가 → MCP URL 붙여넣기 → 로그인·승인.
  - **권한 설정**: 대부분 '항상 허용', 단 **비용 드는 4개(3D·오디오·이미지·영상 생성)는 '승인 필요'**, 결제수단 변경은 차단.
  - ★비용 구조: 기획·검토는 클로드 토큰만, **힉스필드 크레딧은 영상 생성 때만**(5초≈50크레딧)★. 모델은 페이블, 작업량 엑스트라~최대.
- **핵심 인용**: "실제로 익스필드 크레딧은 영상 만들 때에만 씁니다."
- **내 팁**: 커넥터 권한을 '생성은 승인 필요'로 두는 게 크레딧 폭주 방지 — 앞 영상(CoWork 모델 선택, 오르카)의 비용 관리와 같은 결.

## 4. ★스킬 5개 — 슬래시 한 번에 제작★ · [22:54](https://youtu.be/zv0gHwKQT8M?t=1374)
- **3줄 요약**
  - 자주 쓰는 기능을 **스킬**로 등록(클로드 설정→스킬→업로드) → 채팅에 **슬래시(/)**로 검색해 사용(복잡한 프롬프팅 불필요).
  - **3D 쇼츠 크리에이터**(기획→검토→이미지→스토리보드→영상, 크레딧 절약), **익스플레이너 스튜디오**(설명 영상, "물과 기름은 왜 안 섞일까?"), **애드스크립트**(제품 사진/링크→광고표시법 검토+HTML 기획안), **애드 크리에이터**(포스터+영상).
  - 대사 발음 팁(마침표로 끊어 발음 쉽게), 막힌 영상은 "블록됐어, 다시 생성"으로.
- **핵심 인용**: "복잡한 프롬프팅 할 필요가 없습니다. 슬래시를 입력하고 검색하시면."
- **내 질문**: 스킬(기획→이미지→검토→영상 순서를 내장)은 앞 영상들(코워크 플러그인 패키징, ralph-loop)의 '워크플로우를 스킬로 굳히기'와 정확히 같은 패턴 아닐까?

## 5. 나레이션·광고·웹페이지 · [32:58](https://youtu.be/zv0gHwKQT8M?t=1978)
- **3줄 요약**
  - **나레이션 가이드(한국어)**: 힉스필드 보이스는 영어로만 나와, 노션에 한국어 목소리 목록을 별표로 정리(별표 2개면 웬만하면 잘 됨). 60초 영상은 영상 4+음성 4를 싱크. 자막은 텍스트 오류 많아 편집으로 처리 권장.
  - **광고**: 사진만 던지면 애드스크립트가 광고표시법까지 검토해 기획안 → 애드 크리에이터로 포스터+쇼츠(홈런볼·티그레 예시, 통일감 있어 그대로 사용 가능).
  - **웹페이지**: 클로드 디자인에 애니메이션+브랜드 가이드(예: 성심당)를 소스로, 노션의 '스크롤 시 애니메이션' 프롬프트로 → 스크롤에 반응하는 빵집 홈페이지(페이블).
- **핵심 인용**: "이제는 진짜 그 상상만 하면 진짜 만들 수 있는 시대가 된 거 같아요."
- **내 팁**: 브랜드 가이드 시트를 클로드 디자인에 넣는 방식은 앞 영상들(design.md, 디자인 MD)의 '레퍼런스 재료화'와 동일 — 디자인 일관성의 공통 해법.

## TL;DR (5줄)

1. **연결**: 힉스필드 MCP를 클로드 커넥터에 등록 → 클로드가 기획, 힉스필드가 생성. 생성 도구만 '승인 필요'로.
2. **원칙(★)**: ① 기획을 먼저 ② 이미지를 먼저 만들고 영상으로(영상이 비쌈, 크레딧은 영상 생성 때만).
3. **캐릭터**: 셀카 6장→레퍼런스 시트(4K)→My Elements에 등록 → "미 참고해서"로 일관된 캐릭터·배경 재사용.
4. **스킬(★)**: 3D 쇼츠·익스플레이너·애드스크립트·애드 크리에이터 등 5개를 슬래시로 — 기획→검토→이미지→영상 순서 내장.
5. **산출물**: 광고 포스터·쇼츠(광고표시법 검토), 한국어 나레이션(별표 2개 목소리), 스크롤 반응 웹페이지(클로드 디자인+브랜드 가이드). "상상만 하면 만드는 시대."
