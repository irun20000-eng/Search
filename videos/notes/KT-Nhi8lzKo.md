# 현시점 클로드 가장 쉽게 쓰는 법 — 코워크+스킬로 피그마 디자인 자동화

> 한 줄 요약: 클로드 데스크탑의 **챗·코워크·코드 3구조**를 이해하고, **피그마 MCP를 커넥터로 연결** → **① 챗에서 카드뉴스 워크플로우를 만들어 스킬(.md)로 굳히고 ② 코워크 스케줄에 예약**하면, 매일 정해진 시간에 AI가 **트렌드를 스스로 리서치 → 피그마에 카드뉴스를 자동 생성**한다. 스킬은 **일관성·팀 자산화·토큰 절약(점진 로딩)·챗/코워크/코드 호환**의 4이점. 주의: 피그마 자동화는 **토큰이 많이 소모**돼 Pro로 시작·시간 분산 연습 권장, 피그마도 **프로페셔널(월 500크레딧)** 정도 필요, 예약 작업은 **컴퓨터가 켜져 있어야** 실행(절전 방지).

## 1. 클로드 데스크탑 3구조 — 챗·코워크·코드 · [00:00](https://youtu.be/KT-Nhi8lzKo?t=0)
- **3줄 요약**
  - 모든 기능 활용엔 **데스크탑 앱 설치**가 유리. 클로드는 **챗·코워크·코드** 3기능(왼쪽 메뉴).
  - **챗**(대화형: 아이디어·기획·질문 / 뉴챗·프로젝트·커스터마이즈·아티팩트), **코워크**(AI가 실제 작업 수행, 데스크탑 전용), **코드**(결과물 실행).
  - 세 기능을 **하나의 흐름으로 연결**해 쓰는 게 핵심 — 질문 수준을 넘어 '일을 맡기고 결과물을 만드는' 단계.
- **핵심 인용**: "챗이 단순한 대화형 AI라면 코워크는 한 단계 더 나아가서 AI가 실제로 작업까지 대신 수행."
- **내 팁**: 챗·코워크·코드 3분류는 앞 영상(신영선 setup, 태오 GWS)의 '기능별 이해 후 조합'과 같은 온보딩 구조. 라이브 아티팩트(커넥터 실시간 대시보드)도 신설.

## 2. 코워크 메뉴 + 요금제·토큰 유의 · [04:06](https://youtu.be/KT-Nhi8lzKo?t=246)
- **3줄 요약**
  - 코워크 메뉴: **뉴테스크·프로젝트·스케줄(자동 실행)·커스터마이즈·디스패치(작업 분할 병렬)** + 신설 **라이브 아티팩트**(커넥터 실시간 상태 대시보드).
  - 자동화엔 **유료 요금제 필요** — 처음엔 Pro로 가볍게, 검증 후 Max로. 클로드는 **토큰 소모가 큼**(특히 코워크 자동화).
  - 단계별로 나눠 충분히 연습 후 매일 자동화가 무리 없을 때 Max 권장.
- **핵심 인용**: "코크 기능에서 자동화 기능을 심층적으로 사용을 할 때에는 더 많이 토큰이 소요."
- **내 질문**: 디스패치(작업 분할 병렬)는 앞 영상(롱폼 영상의 서브에이전트 오케스트레이션)과 같은 팬아웃 — 코워크에 내장된 병렬 처리 아닐까?

## 3. ★피그마 MCP 커넥터 연결★ · [08:06](https://youtu.be/KT-Nhi8lzKo?t=486)
- **3줄 요약**
  - **MCP** = 직접 디자인하지 않아도 클로드가 **내 피그마 계정에 연결돼 디자인 작업을 대신** 수행하게 하는 기능. 커넥터로 연결만 하면 AI가 판단해 작업.
  - 피그마 외 캔바·노션·슬랙·구글드라이브 등 다양한 외부앱 연결 가능. 연결: **커넥터 관리 → 커넥터 둘러보기 → 피그마 검색 → 계정 연동**(웹형/데스크탑형).
  - 연동 완료 후 인스타 캐러셀 카드뉴스 자동화를 **① 챗에서 스킬 만들기 ② 코워크 스케줄 예약** 2단계로 진행.
- **핵심 인용**: "피그마 MCP를 커넥터로 연결만 해 주면 AI가 스스로 판단해서 작업까지 수행."
- **내 팁**: 커넥터로 외부앱 연결은 앞 영상(태오 GWS, Jay Choi Firecrawl)과 같은 계열 — 클로드에 손발을 붙이는 통합.

## 4. ★스킬 4이점 + 카드뉴스 스킬 만들기★ · [11:24](https://youtu.be/KT-Nhi8lzKo?t=684)
- **3줄 요약**
  - **스킬 4이점**: ①일관된 결과(반복 프롬프트 불필요) ②팀 노하우 자산화(공유) ③**토큰 효율**(점진 로딩으로 필요 정보만) ④챗·코워크·코드 **전체 호환**.
  - 커스터마이즈→스킬 만들기→**"클로드와 함께 창작하기"** → 준비한 프롬프트 입력 → 카드뉴스 디자인을 **피그마에 직접 생성**(HTML 내보내기, 1080×1350 슬라이드, 커버~CTA 레이어까지 자동).
  - 이 워크플로우를 분석해 **스킬 파일(.md)**로 저장 → 이후 "카드뉴스 만들어 줘" 한 줄이면 스킬 구동.
- **핵심 인용**: "스킬은 점진적인 로딩 방식을 사용하기 때문에 필요한 정보만 단계적으로 불러와요. 불필요한 토큰 사용을 줄일 수 있죠."
- **내 질문**: '워크플로우 완성→스킬로 굳히기'는 앞 영상 전부(오팔 스킬, 데키랩, 인스타 스킬크리에이터)의 공통 결론 — 스킬화가 자동화의 전제 아닐까?

## 5. 코워크 스케줄 예약 + 토큰·비용 유의 · [16:59](https://youtu.be/KT-Nhi8lzKo?t=1019)
- **3줄 요약**
  - **스케줄 예약**(코워크 전용): 스킬 호출 + "매일 오전 7시 피그마 트렌드 카드뉴스 만들어 줘" 한 줄 → 매일 AI가 **트렌드 리서치→기획→피그마 생성**을 진행 상황·컨텍스트까지 투명하게 보여줌.
  - **주의**: 예약 작업은 **컴퓨터가 켜져 있어야** 실행(절전 방지 활성화), 연습 후엔 삭제(토큰 계속 소모). 피그마 자동화는 토큰 소모가 커 **연속 2~3회면 일 할당량 소진** → 하루 1~2회 시간 분산.
  - **비용**: 피그마도 **프로페셔널(월 500 AI 크레딧)** 정도면 시작 충분. 토큰 절약법 = **스킬 먼저 만들기 + 다른 툴과 분산**. 클로드는 시간대별·주간 한도 구조.
- **핵심 인용**: "예약된 작업은 컴퓨터가 깨어 있는 동안에만 실행됩니다."
- **내 팁**: '예약 작업은 PC 켜져 있어야'는 앞 영상(데키랩 유튜브 요약의 로컬 루틴)과 동일한 제약. 토큰 절약을 위한 '스킬화+툴 분산'은 이 프로젝트의 비용 관리와 같은 결.

## TL;DR (5줄)

1. **구조**: 클로드 데스크탑 **챗·코워크·코드**를 하나의 흐름으로. 코워크는 AI가 실제 작업 수행(스케줄·디스패치·라이브 아티팩트).
2. **연결(★)**: **피그마 MCP를 커넥터로 연결** → AI가 내 피그마 계정에 디자인을 직접 생성(캔바·노션·슬랙도 가능).
3. **스킬(★)**: 챗에서 카드뉴스 워크플로우 완성 → **스킬(.md)로 저장**. 4이점 = 일관성·팀 자산화·**토큰 절약(점진 로딩)**·전체 호환.
4. **자동화**: 코워크 **스케줄 예약** + 스킬 호출 한 줄 → 매일 AI가 **트렌드 리서치→피그마 카드뉴스 자동 생성**.
5. **비용(★)**: 피그마 자동화는 토큰 큼 → Pro 시작·하루 1~2회 분산·**스킬 먼저**. 피그마는 프로페셔널(월 500크레딧). 예약은 **PC 켜져 있어야** 실행.
