# 평생 공짜인 Make, 재피어? 노코드 자동화 n8n 서버 무료 호스팅

> 한 줄 요약: 매달 구독료가 발생하는 Make, Zapier 또는 고가의 클라우드 서비스 대신, **구글 클라우드(GCP) 평생 무료 e2-micro VM** 인스턴스와 **도커(Docker)**를 활용하여 **n8n 자동화 서버를 자체 구축**하고, **클라우드플레어(Cloudflare) 무료 SSL 및 DDNS**, **엔진엑스(Nginx) 리버스 프록시**를 결합하여 연간 1,000원 안팎의 도메인 비용만으로 완벽한 보안과 편의성을 갖춘 24시간 가동 서버를 세팅하는 전 과정을 제시한다.

## 1. ★n8n 호스팅 필요성과 구글 클라우드 프리티어 VM 생성★ · [00:00](https://youtu.be/kdt5J2bpchM?t=0)
- **3줄 요약**
  - 로컬 컴퓨터 실행 시 PC가 꺼지면 24시간 예약 작업이나 웹훅 수신이 중단되는 한계가 있다.
  - **구글 클라우드 플랫폼(GCP)**의 상시 무료 티어인 **e2-micro 인스턴스(30GB 디스크)**를 생성한다.
  - 오리건(us-west1) 등 프리티어 지원 리전을 선택하여 추가 비용 청구 없는 가상 서버를 확보한다.
- **핵심 인용**: "구글은 가입 기간에 상관없이 무료인 플랜을 가지고 있습니다 저희처럼 간단한 자동화나 실습을 하고자 하는 경우 적합하다고 할 수 있습니다."
- **내 팁**: GCP VM 인스턴스 생성 시 반드시 e2-micro 및 표준 영구 디스크 30GB 이하로 설정하여 무료 범위를 유지한다.

## 2. 도커(Docker) 기반 n8n 설치 및 방화벽 포트 개방 · [04:06](https://youtu.be/kdt5J2bpchM?t=246)
- **3줄 요약**
  - SSH 터미널에 접속하여 **도커(Docker)** 엔진을 설치하고 데이터 보존용 볼륨을 생성한다.
  - `docker run` 명령어로 n8n 공식 컨테이너를 가동하여 **5678번 포트**로 서버를 실행한다.
  - GCP VPC 네트워크 방화벽 설정에서 **5678 포트 인바운드 규칙**을 추가하여 브라우저 접속을 허용한다.
- **핵심 인용**: "IP 주소가 건물 주소라면 포트는 건물의 층수라고 생각하면 됩니다."
- **내 질문**: 도커 컨테이너 업데이트 시 기존 생성해 둔 n8n 워크플로우와 크리덴셜 데이터를 안전하게 백업 및 마이그레이션하는 절차가 궁금하다.

## 3. ★클라우드플레어(Cloudflare) 무료 SSL 인증서 및 도메인 바인딩★ · [06:34](https://youtu.be/kdt5J2bpchM?t=394)
- **3줄 요약**
  - IP 직접 접속 시 발생하는 보안 경고를 해결하기 위해 **클라우드플레어 DNS**에 개인 도메인을 연결한다.
  - 클라우드플레어가 제공하는 **무료 SSL/TLS 인증서**를 적용하여 안전한 `https://` 보안 통신을 구축한다.
  - 복잡한 숫자 IP 대신 기억하기 쉬운 고유 도메인 주소로 n8n 접속 편의성을 극대화한다.
- **핵심 인용**: "클라우드 플레어가 자동으로 SSL 인증을 해주기 때문에 https 연결을 사용할 수 있습니다."
- **내 팁**: 도메인 등록 후 클라우드플레어 프록시(오렌지 구름)를 활성화하여 원본 서버 IP 노출을 방지한다.

## 4. ★엔진엑스(Nginx) 리버스 프록시 구축과 5678 포트 은닉★ · [08:49](https://youtu.be/kdt5J2bpchM?t=529)
- **3줄 요약**
  - 80번 포트로 들어온 웹 트래픽을 내부 5678번 n8n 포트로 전달하는 **Nginx 비서(Reverse Proxy)**를 설치한다.
  - Nginx 설정 파일에 도메인을 바인딩하고 프록시 패스 및 웹훅 헤더 전달 규칙을 작성한다.
  - 외부로 열려 있던 5678 방화벽 문을 닫고 **Nginx를 거친 보안 트래픽만 허용**하도록 격리한다.
- **핵심 인용**: "80층에 온 손님을 5678층으로 안내해라라는 내용입니다 중요한 것은 클라우드 플레어에서 오신 손님들만 비서의 안내를 받아 도착할 수 있기 때문입니다."
- **내 팁**: n8n 환경 변수에 `WEBHOOK_URL` 도메인을 명시하여 웹훅 노드가 올바른 외부 주소를 반환하도록 세팅한다.

## 5. DDNS(Dynamic DNS) 동기화와 백그라운드 무중단 실행 · [10:53](https://youtu.be/kdt5J2bpchM?t=653)
- **3줄 요약**
  - 유료 고정 IP 대신 **DDclient**를 설치하여 GCP 임시 외부 IP 변경 시 클라우드플레어 DNS를 자동 갱신한다.
  - 백그라운드 데몬 실행 플래그(`-d`)를 적용하여 **SSH 터미널 창을 닫아도 24시간 연속 가동**되게 설정한다.
  - 컨테이너에 재시작 정책을 적용해 서버가 재부팅되어도 n8n과 DDNS 갱신이 끊김 없이 이어지도록 한다.
- **핵심 인용**: "클라우드 플레어의 DDNS 기능을 이용하면 고정 IP를 사용하지 않아도 됩니다."
- **내 팁**: `docker run -d` 옵션과 `--restart=always` 플래그를 함께 적용하여 서버 재부팅 시에도 n8n이 자동 실행되도록 구성한다.

## TL;DR (5줄)
1. **GCP 무료 VM**: 구글 클라우드의 상시 무료 e2-micro 인스턴스를 활용해 24시간 가동되는 서버 환경을 마련한다.
2. **도커 간편 구축**: 도커 볼륨과 컨테이너 실행으로 설치 복잡도를 낮추고 n8n 서버를 즉시 기동한다.
3. **무료 SSL 적용**: 클라우드플레어에 도메인을 연결해 무료 SSL 인증서 기반 HTTPS 보안 접속 환경을 완성한다.
4. **Nginx 프록시**: Nginx 리버스 프록시를 구성하여 5678 포트를 은닉하고 웹훅 주소 라우팅을 최적화한다.
5. **DDNS 자동 갱신**: DDclient로 동적 IP 변경을 자동 동기화하고 백그라운드 모드로 24시간 무중단 가동한다.
