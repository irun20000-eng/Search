# 코딩 몰라도 OK — 클로드 코드로 100만 원짜리 사이트 만들기 | 구글시트 자동 저장까지

## 6. 디자인 시스템 적용하기 (DESIGN.md) · [6:22](https://youtu.be/y6HIrsG7pE8?t=382)
- **3줄 요약**
  - 첫 결과물은 평범하다 — 여기서 끝내면 실패. **디자인도 파일로 던질 수 있다.**
  - **getdesign.md**(Stripe·Vercel·Linear·Notion·Apple 등 유명 기업의 디자인 시스템을 DESIGN.md로 역공학해 모아둔 무료 사이트)에서 **Stripe(결제 회사, 깔끔한 디자인으로 유명)**의 규칙을 받아 `design.md`로 저장 + 로고 이미지도 폴더에 넣고, "이 문서를 처음부터 끝까지 그대로 적용해 줘"라고 시킨다.
  - "앞으로 모든 페이지도 이 디자인으로"라고 한 줄 박아두면 이후 페이지가 통일된 톤으로 나온다. → 감각 없어도 고수처럼 보이는 가장 빠른 길.
- **핵심 인용**
- **내 질문**
- getdesign.md의 디자인은 실제 기업을 "역공학"한 것이라는데, 상용 사이트에 그대로 쓸 때 저작권·트레이드드레스 문제는 없을까?

## 7. 원칙 3 — 완료된 기능은 두고 하나씩 누적하며 쌓기 · [7:40](https://youtu.be/y6HIrsG7pE8?t=460)

  - 고수는 **"지금 건 그대로 두고 OO만 추가해 줘"**로 하나씩 쌓는다. 메뉴만 시켜도 똑똑한 AI는 연결될 페이지까지 같은 디자인으로 자동 생성.
  - 누적 예: 출강 이력 카드 → 숫자 카운트업(0→3,400) → 카드 클릭 펼침 → 상단 흐르는 띠 → 문의 폼 동작(빈칸이면 경고) → **모바일 반응형**. "디테일은 요청한 만큼 나온다."

- **내 질문**

## 8. 원칙 4 — 마음에 안 드는 부분 고치기 및 버그 수정 · [11:10](https://youtu.be/y6HIrsG7pE8?t=670)
- **3줄 요약**
  - 코드 몰라도 화면 보고 일상어로 "이거 이상해, 이렇게 해 줘"라고 하나씩 고치면 된다(간격 too far → 클로드가 직접 측정해 수정).
  - **추상적 표현도 통한다**: "스트라이프 홈페이지처럼 더 고급스럽게" 한마디로 디자인이 확 좋아진다(처음에 디자인 시스템 파일을 줬기 때문).
  - AI도 실수한다(로고 사라짐·남색 박스 2개·카드 펼치면 내용 사라짐) → 당황 말고 **증상을 하나씩** 고쳐 달라 요청. 수정할 곳을 **이미지 캡처**로 보여주면 더 좋다.
- **핵심 인용**
- **내 질문**
- "증상을 일상어로"가 통하는 건 어디까지일까 — 기능 로직 버그도 일상어 설명만으로 고쳐질까?

## 9. 구글 시트 연동 — 고객 문의 자동 저장 · [13:40](https://youtu.be/y6HIrsG7pE8?t=820)
- **3줄 요약**
  - 문의를 볼 수 없으면 장난감 — 가장 쉽고 무료인 방법이 **구글 시트 연동**(서버 불필요).
  - 방법: 클로드에게 "문의가 구글 시트에 한 줄씩 쌓이게 해 줘. 코딩 못 하니 구글 쪽 클릭 단계를 쉬운 말로 순서대로 알려줘"라고 시킴 → AI가 절차를 안내.
  - 시트 생성 → **Apps Script**에 AI가 준 코드 붙여넣기 → **배포 시 액세스 권한을 '모든 사용자'로 설정(여기서 제일 많이 막힘)** → 배포 URL을 클로드에 던지면 폼과 연결 완료. 테스트 문의가 시트에 한 줄 쌓인다.
- **핵심 인용**
- **내 질문**
- Apps Script 웹앱을 "모든 사용자" 공개로 두면 스팸·악용 위험은 없나? (문의 폼이 공개 엔드포인트가 됨)

## TL;DR (5줄)

1. **코드 0줄로 "작동하는" 사이트** — 클로드 코드 데스크톱 앱(유료 요금제 필수) + Git으로 강사 섭외 사이트를 만든다.
2. **4원칙이 핵심** — ①재료는 파일(`about.md`)로 ②결과를 그림 그리듯 구체적으로(역할 부여 포함) ③완료분은 두고 하나씩 누적 ④마음에 안 들면 일상어로 하나씩 수정.
3. **디자인도 파일로** — 디자인 시스템 사이트에서 Stripe 등의 규칙을 `design.md`로 받아 통째로 적용하면 감각 없어도 고수처럼.
4. **진짜 작동의 핵심은 데이터** — 문의 폼을 **구글 시트 + Apps Script**로 연동(배포 권한 '모든 사용자' 주의)해 고객 문의를 자동 저장.
5. **시리즈 1편** — 2편 관리자 페이지, 3·4편 수익화 예고. 아웃트로는 유료 크루 홍보.
