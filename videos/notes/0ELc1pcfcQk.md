# 요즘 핫한 ADE 오르카(Orca) 소개 — 여러 AI 코딩 에이전트를 워크트리로 관리

> 한 줄 요약: **Orca**는 모델이 아니라 여러 AI 코딩 에이전트를 **폴더/워크스페이스 단위로 관리**해 주는 도구(ADE, 맥·리눅스·윈도우·무료). 핵심은 **워크트리(git worktree)** 기반 병렬 작업 — 같은 파일 세트를 여러 버전으로 동시에 돌리고 완료 시 **알림**. 스플릿 터미널, 내장 파일 뷰어·브라우저, **엘리먼트 그랩(Ctrl+C로 UI 요소를 잡아 에이전트에 전달)**, 어노테이트, 그리고 **오르카 모바일(QR)**로 외출 중에도 명령. 여러 에이전트를 돌리는 개발자·바이브 코더에게 관리가 쉬운 툴.

## 1. Orca란 — 에이전트 상태 관리 · [00:00](https://youtu.be/0ELc1pcfcQk?t=0)
- **3줄 요약**
  - 여러 AI 코딩 에이전트를 여러 폴더에서 돌리면 **언제 어떤 에이전트가 끝났는지** 알기 어려움(원래는 터미널을 커스텀해 이동).
  - Orca를 쓰면 **폴더 구조 단위로 에이전트들을 관리**하고 지금 상태를 볼 수 있음. 무료, 모델이 아니라 **관리 툴**.
  - 개발자·바이브 코더 모두에게 활용도↑.
- **핵심 인용**: "이 폴더 구조 단위로 이 에이전트들을 관리하고 얘네들이 지금 어떤 상태인지 보실 수 있습니다."
- **내 질문**: 에이전트를 여러 개 병렬로 돌리는 게 일상이 되면서 '에이전트 오케스트레이션 대시보드'가 필수가 되는데, 앞 영상(Hermes 데스크톱)과 같은 흐름 아닐까?

## 2. ★워크트리 — 같은 파일을 여러 버전 병렬★ · [01:28](https://youtu.be/0ELc1pcfcQk?t=88)
- **3줄 요약**
  - 깃은 버전을 저장하지만, 하나의 파일을 동시에 두 방향(빨강/파랑)으로 수정할 순 없음. **워크트리**는 그 상태를 그대로 '복사'.
  - V1을 들고 가 빨강=V2, V1에서 파랑=V3 — **같은 파일 세트로 두 버전을 병렬 작업**. 하나의 파일에 여러 작업을 하면 병합 시 충돌이 나는데, 워크트리로 **충돌을 덜 만듦**.
  - 깃으로 직접 하면 어렵지만, Orca는 프로젝트 → **New Workspace** → 에이전트(클로드) 선택 → 자동 실행 + **완료 시 알림**.
- **핵심 인용**: "동일한 파일 같은 거를 가지고 파일 세트를 가지고 두 개의 버전으로 작업을 한다고 보시면 돼요."
- **내 팁**: 워크트리는 앞 영상(루프 엔지니어링)의 '서브에이전트 병렬'을 파일/브랜치 레벨에서 안전하게 구현한 것 — 충돌 없는 병렬의 기반.

## 3. 관리 편의 — 스플릿 터미널·파일 뷰어·브라우저 · [04:00](https://youtu.be/0ELc1pcfcQk?t=240)
- **3줄 요약**
  - 여러 워크스페이스로 **언제 끝났는지 파악** → 에이전트를 여러 개 쓰는 사람에게 관리 쉬움. 우클릭 → **Split Terminal**로 화면 분할, 탭 추가/종료(X) 쉬움.
  - 사이드바에서 작업 파일 확인(MD·이미지 등 웬만한 파일 다 읽힘) — VS 코드에서 하던 걸 Orca 안에서.
  - HTML 파일을 **Ctrl+클릭**하면 Orca 내장 브라우저로 열림.
- **핵심 인용**: "이 오르카 ADE에서 웬만한 것들은 처리가 된다."
- **내 질문**: 터미널·파일 뷰어·브라우저·에이전트를 한 창에 통합한 'ADE(Agent Development Environment)'는 IDE의 다음 형태 아닐까?

## 4. ★엘리먼트 그랩 + 어노테이트 + 오르카 모바일★ · [05:27](https://youtu.be/0ELc1pcfcQk?t=327)
- **3줄 요약**
  - 내장 브라우저에서 **페이지 엘리먼트를 Ctrl+C로 잡으면**(선택 요소·접근성 이름 등) 그걸 에이전트에 넣어 "이 버튼 빨간색으로" → 어떤 버튼인지 아니 빠르게 수정. **어노테이트(주석)**도.
  - 바이브 코더에게 편함 — 브라우저를 왔다갔다하며 셀렉터 잡기 귀찮은데 **그랩**으로 잡고 에이전트에 명확히 설명(헤르메스 에이전트가 HTML 읽어 수정).
  - **오르카 모바일**: QR로 앱 연결 → 외출 중에도 모든 탭에 명령, UI가 매우 예쁨.
- **핵심 인용**: "이 그랩을 눌러서 잡고 하면 … 에이전트에게 더 명확하게 설명해 줄 수 있고."
- **내 팁**: '엘리먼트 그랩 → 에이전트 지시'는 앞 영상(6개 프롬프트)의 'AI에게 정확한 맥락 주기'를 UI 레벨에서 구현 — 셀렉터 대신 시각 선택.

## TL;DR (5줄)

1. **정체**: Orca = 여러 AI 코딩 에이전트를 **폴더/워크스페이스 단위로 관리**하는 ADE(무료, 크로스플랫폼). 모델이 아니라 관리 툴.
2. **워크트리(★)**: git worktree 기반으로 같은 파일 세트를 여러 버전 **병렬 작업**(충돌↓), 완료 시 알림.
3. **편의**: New Workspace로 에이전트 실행, Split Terminal, 내장 파일 뷰어·브라우저(HTML Ctrl+클릭).
4. **UI 그랩(★)**: 브라우저 요소를 **Ctrl+C로 잡아** 에이전트에 전달 → 정확·빠른 수정, 어노테이트 주석.
5. **모바일**: 오르카 모바일(QR)로 외출 중에도 모든 탭에 명령. 여러 에이전트 돌리는 개발자·바이브 코더에게 최적.
