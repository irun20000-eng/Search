# 여러분은 왜 요약하나요? 나처럼 생각하는 GPT와 유튜브 요약

> 한 줄 요약: 천편일률적인 단순 요약 서비스의 한계를 극복하기 위해, **구글 딥마인드의 셀프 디스커버(Self-Discover)** 프레임워크를 적용하여 **노션(Notion)**에 정의한 사용자 고유의 관점과 멘탈 모델 질문을 추출하고, **n8n 백엔드와 전용 크롬 익스텐션(Chrome Extension)**을 연동하여 유튜브 영상의 핵심을 개인 맞춤형 마크다운 및 디스코드 코멘트로 생성하는 시스템을 구축한다.

## 1. ★천편일률적 영상 요약의 한계와 관점 중심 요약의 필요성★ · [00:00](https://youtu.be/_PdvWiuJF-M?t=0)
- **3줄 요약**
  - 기존 요약 툴은 모든 사용자에게 동일한 축약을 제공하여 **개인의 정보 탐색 목적**을 충족하지 못한다.
  - 영상에서 대본을 추출하고 요약하는 과정에서 발생하는 **정보 손실**을 목적 적합성으로 보완해야 한다.
  - 사용자가 지닌 **고유한 관점(문제 해결, 스토리텔링 등)**에 답할 수 있는 맞춤형 요약 시스템을 설계한다.
- **핵심 인용**: "비디오 요약이란 행위의 효용이 생기지 않았던 이유는 비디오를 요약하는 나의 목적에 맞지 않게 천편일률적인 요약을 제공했기 때문입니다."
- **내 팁**: 영상 시청 전 자신이 얻고자 하는 핵심 질문(기술 원리, 적용 방안 등)을 명확한 관점으로 사전 정의한다.

## 2. n8n 유튜브 자막 추출 커스텀 노드와 GPT 요약 워크플로우 · [04:17](https://youtu.be/_PdvWiuJF-M?t=257)
- **3줄 요약**
  - 로컬 구동이 가능한 오픈소스 **n8n**을 설치하여 데이터 보안과 커스텀 확장성을 확보한다.
  - 커뮤니티 커스텀 노드를 통해 유튜브 URL로부터 **전체 영상에서 자막 텍스트**를 직접 추출한다.
  - OpenAI GPT 노드를 연결하여 자막 텍스트를 1차 분석하는 **기본 요약 파이프라인**을 구축한다.
- **핵심 인용**: "n8n에는 독특하게도 코드가 공개되어 있어 내 컴퓨터에서 실행이 가능합니다 이는 보안이 중요한 회사 프로젝트나 개인적인 용도로 사용할 때에도 큰 장점입니다."
- **내 팁**: n8n 커뮤니티 노드 관리자에서 유튜브 자막 다운로드 모듈을 설치해 공식 노드에 없는 기능을 보완한다.

## 3. ★웹훅(Webhook) 기반 크롬 익스텐션 제작 및 마크다운 렌더링★ · [09:07](https://youtu.be/_PdvWiuJF-M?t=547)
- **3줄 요약**
  - n8n의 **웹훅 트리거(Webhook Trigger)**를 활성화하여 브라우저 확장 프로그램의 신호를 수신한다.
  - 4개 파일(manifest, background, popup HTML/JS)로 **경량 크롬 익스텐션**을 개발하여 현재 유튜브 탭 URL을 전송한다.
  - **Marked.js 라이브러리**를 팝업 UI에 내장하여 GPT가 반환한 마크다운 서식을 깔끔한 시각 디자인으로 렌더링한다.
- **핵심 인용**: "크롬 익스텐션은 앞서 보여 드렸던 노트 GPT처럼 구글 크롬에 붙일 수 있는 작은 프로그램이라고 생각하면 됩니다."
- **내 질문**: 크롬 익스텐션에서 대용량 영상의 자막 요약 응답이 지연될 때 로딩 인디케이터를 처리하는 최적의 비동기 패턴이 궁금하다.

## 4. 노션(Notion) 데이터베이스 연동과 사용자 고유 질문 주입 · [14:06](https://youtu.be/_PdvWiuJF-M?t=846)
- **3줄 요약**
  - 노션 API 인티그레이션을 생성하고 관점 목록이 담긴 **질문 데이터베이스** 접근 권한을 부여한다.
  - n8n의 **노션 노드**와 머지(Merge) 노드를 활용하여 영상 자막과 노션 내 질문 리스트를 동시에 준비시킨다.
  - 미리 정의된 질문을 프롬프트에 동적으로 주입하여 **사용자 의도에 직결된 요약문**을 생성한다.
- **핵심 인용**: "어떤 비디오를 요약하든 동일한 질문을 사용하기 때문에 동일한 정보가 추출되면 요약 결과물을 해석하는 속도가 빨라질 수 있습니다."
- **내 팁**: 노션 DB에 질문 목록을 등록해 두면 팀원들과 동일한 관점의 템플릿을 실시간으로 공유·수정할 수 있다.

## 5. ★구글 딥마인드 셀프 디스커버(Self-Discover) 프레임워크 구현★ · [18:03](https://youtu.be/_PdvWiuJF-M?t=1083)
- **3줄 요약**
  - **셀프 디스커버(Self-Discover)**는 추상적인 멘탈 모델에서 구체적 지침으로 내려가는 사고 프레임워크다.
  - Stage 1: 영상 자막을 분석하여 노션의 여러 관점 중 **답변 가능한 핵심 질문을 자동 선별(Select)**한다.
  - Stage 2: 선별된 질문을 바탕으로 **구체적 실행 지침(Implement)**을 도출하고 최종 마크다운 리포트를 완성한다.
- **핵심 인용**: "이 방법의 진정한 의의는 높은 추상성에서 낮은 추상성으로 한 단계씩 들어가는 사고 과정을 언어 모델 워크플로에 잘 녹여냈다는 점에 있습니다."
- **내 팁**: 셀프 디스커버 구조를 적용하여 요약 전 영상에 적합한 질문을 먼저 선택하게 함으로써 답변의 밀도를 극대화한다.

## 6. 웨이트(Wait) 노드를 활용한 디스코드 코멘트 전송 및 브랜딩 · [27:25](https://youtu.be/_PdvWiuJF-M?t=1645)
- **3줄 요약**
  - 익스텐션에서 요약 확인 후 사용자가 입력한 추가 코멘트를 수신하기 위해 **웨이트(Wait) 노드**를 배치한다.
  - 사용자가 전송 버튼을 누르면 대기 상태가 해제되며 **요약문과 코멘트가 디스코드 채널로 전송**된다.
  - 공간을 밝히는 횃불 콘셉트의 **밝히다 브랜딩**을 UI와 봇에 적용하여 프로덕트 완성도를 제고한다.
- **핵심 인용**: "웨이트 노드가 웹훅에 반응하도록 설정하고 최대 대기 시간을 1시간으로 설정합니다."
- **내 팁**: 웹훅 기반 다단계 인터랙션 설계 시 웨이트 노드에 적절한 타임아웃을 지정한다.

## TL;DR (5줄)
1. **관점 중심 요약**: 천편일률적인 단순 요약 대신 사용자의 목적과 질문에 부합하는 맞춤형 요약 구조를 설계한다.
2. **n8n 자막 추출**: 로컬 n8n과 커뮤니티 노드를 활용해 안전하고 유연한 유튜브 자막 추출 파이프라인을 구축한다.
3. **크롬 익스텐션**: 웹훅 트리거와 Marked.js를 적용한 경량 크롬 확장 프로그램을 제작해 브라우저 팝업을 구현한다.
4. **셀프 디스커버**: 구글 딥마인드의 추상화 사고 모델을 도입해 영상별 최적 질문을 선별하고 심층 요약 지침을 생성한다.
5. **디스코드 공유**: 웨이트 노드로 사용자 코멘트 입력을 대기한 후 맞춤 요약 결과와 함께 팀 디스코드로 동시 전송한다.
