# AI 코딩을 10배 더 강력하게! Antigravity 특수 도구(MCP) 6종 완벽 가이드 (설명부터 설치 하는 방법, 사용법까지) [짱쉬운 바이브코딩, 10/16]

> 한 줄 요약: **구글 안티그래비티(Antigravity)** 환경에서 **모델 컨텍스트 프로토콜(MCP)**을 결합하여 고립된 AI 모델에 외부 데이터 연동용 손발을 달아주고, **실시간 문서 탐색(Context7)**, **단계별 사고(Sequential Thinking)**, **HWPX 한글 문서 생성**, **노트북LM 연동**, **플레이라이트(Playwright)**, **로컬 파일 시스템 제어** 등 핵심 MCP 6종의 설치부터 제이슨 설정 및 디버깅 실습까지 완벽히 마스터하는 가이드를 제시한다.

## 1. ★안티그래비티 한계 극복과 MCP 도구 개요★ · [00:00](https://youtu.be/itrJPsD4V6A?t=0)
- **3줄 요약**
 - 기본 안티그래비티 환경은 로컬 브라우저 및 고유 문서 양식 조작 기능이 고립된 한계를 지닌다.
 - AI 모델에 외부 손발을 달아주는 **MCP(Model Context Protocol)** 특수 장비를 결합한다.
 - 외부 어플리케이션 연동을 통해 단순 대화를 넘어 **물리적 업무 자동화 단계**로 진입한다.
- **핵심 인용**: "생각만 하던 이 AI에게 물리적인 손과 발을 달아주는 특수 장비를 이제 입히셔야 돼요."
- **내 팁**: 기본 프롬프트만으로 한계에 부딪힐 때 외부 툴 연동 표준인 MCP 적용 가능 여부를 먼저 검토한다.

## 2. MCP 프로토콜 표준 규격과 특수 장비 결합 메커니즘 · [02:18](https://youtu.be/itrJPsD4V6A?t=138)
- **3줄 요약**
 - **MCP**는 앤트로픽에서 개발한 LLM과 외부 도구 간 표준 통신 오픈소스 프로토콜이다.
 - 파편화되어 있던 개별 연결 방식을 **USB-C 규격처럼 단일화**하여 통합 관리 편의성을 제공한다.
 - 안티그래비티 엔진에 웹슈터 같은 MCP 서버를 결합하여 **에이전트 조작 역량**을 극대화한다.
- **핵심 인용**: "MCP라는 것은 AI 모델을 외부 데이터, 도구, 어플리케이션과 표준화된 방식으로 안전하게 연결하는 기술을 뜻합니다."
- **내 질문**: 커스텀 개발된 사내 보안 시스템에도 MCP 표준 프로토콜 규격을 적용하여 연동할 수 있는지 궁금하다.

- **핵심 인용**: "공무원 집단으로서 한글과 떨어질래야 떨어질 수가 없는 상태입니다 고로 AI한테 한글 파일을 읽거나 만들게 할 수가 있습니다."

## 5. ★MCP 제이슨 환경 설정과 안티그래비티 스토어 연동★ · [08:11](https://youtu.be/itrJPsD4V6A?t=491)

- **내 팁**: `mcp_config.json` 편집 후에는 반드시 저장 후 리프레시 버튼을 눌러 서버 작동 정상 여부를 확인한다.

## 6. HWPX 문서 및 파일시스템 MCP 조작 실습 · [31:45](https://youtu.be/itrJPsD4V6A?t=1905)
- **3줄 요약**

 - 프롬프트 지시로 HWPX 한글 모듈을 가동하여 **`Hello.hwpx` 마크다운 연동 문서**를 자동 생성한다.
 - 생성된 파일을 한컴 오피스에서 직접 열어 **텍스트 정상 삽입 및 양식 생성**을 완벽히 검증한다.
- **핵심 인용**: "한글 오피스가 제대로 열리고 헬로가 완성된 걸 볼 수 있습니다 AI가 한글 파일을 생성해서 만들 수 있다는 걸 증명한 거죠."
- **내 팁**: HWPX 한글 자동 생성 결과는 반드시 한컴 오피스에서 직접 열어 텍스트·양식이 정상 반영됐는지 확인한다.

## TL;DR (5줄)
1. **MCP 결합**: 안티그래비티에 MCP 규격을 적용하여 로컬 파일 조작 및 브라우저 제어 권한을 부여한다.
2. **핵심 6종 선정**: Context7, 사고 분할, HWPX 한글, 노트북LM, 플레이라이트, 파일시스템 MCP를 핵심 도구로 채용한다.
3. **제이슨 일괄 이식**: `mcp_config.json` 파일에 검증된 서버 설정을 붙여넣어 복잡한 절차 없이 일괄 설치한다.
4. **툴 다이어트**: 판단 지연을 방지하기 위해 사용하지 않는 MCP 툴 옵션은 설정에서 비활성화해 활성 툴 개수를 줄인다.
5. **한글 문서 자동화**: HWPX MCP 조작으로 텍스트 입력과 마크다운 연동 한글 파일 생성을 실전 검증한다.
