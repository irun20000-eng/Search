- **3줄 요약**
  - 프롬프트 구성의 4가지 핵심 요소인 **인물, 상황, 목적, 방법**을 명확히 구분하여 설정한다.
  - 불투명한 정보 전달 대신 AI가 사용자에게 역으로 질문하는 **인터뷰 방식**을 도입하여 맥락을 구체화한다.
  - 상호작용 형태의 **맥락 부여**를 통해 일방적 정보 전달보다 완성도 높은 결과를 도출한다.
- **핵심 인용**: "저는 인물 상황 목적 방법 중에 두 번째인 상황을 많이 강조를 합니다."
- **내 팁**: 프롬프트를 작성할 때 AI가 먼저 역으로 질문하도록 인터뷰 형식을 요청하여 구체적인 맥락 정보를 전달한다.

## 2. ★클로드 코워크 기반 업무 대시보드 구축★ · [03:34](https://youtu.be/GUBZ1YsuVRQ?t=214)
- **3줄 요약**
  - **클로드 코워크 스킬 커넥터**를 통해 구글 캘린더, Gmail, 슬랙 등 다양한 외부 앱을 통합 연동한다.
  - 최근 일정, 미답장 이메일, 마감 과제 등을 한눈에 파악할 수 있는 **인터랙티브 대시보드**를 생성한다.
  - 매일 아침 새로고침만으로 실시간 업데이트 데이터를 확인하여 업무 효율성을 대폭 끌어올린다.
- **핵심 인용**: "이 코워크가 좋은 게 사실 내 컴퓨터에 있는 로컬 파일하고 연동이 된다는 게 되게 큰 장점이잖아요."
- **내 질문**: 구글 캘린더나 Gmail 외에 사내 자체 데이터베이스나 보안 정책이 걸린 외부 서비스도 커넥터로 연동이 가능한지 궁금하다.

## 3. 로컬 폴더 연동과 자동 보고서 생성 · [05:40](https://youtu.be/GUBZ1YsuVRQ?t=340)
- **3줄 요약**
  - **로컬 프로젝트 폴더**를 통째로 등록하여 개별 파일 첨부 없이 수십 개 자료를 직접 참조하도록 조치한다.
  - 제안서, 계약 현황, 설문 결과 데이터를 바탕으로 **8페이지 보고서 PDF**를 일괄 생성한다.
  - 원본 폴더 내 파일만 수정 및 업데이트하면 동일한 프롬프트로 보고서를 재생성할 수 있는 체계를 갖춘다.
- **핵심 인용**: "굳이 막 파일을 직접 첨부하지 않아도 그냥 폴더 하나만 연동해 두면은 파일만 업데이트해 주면은 그냥 똑같이 다시 만들 수가 있는 식입니다."
- **내 팁**: 반복 보고서를 생성할 때는 프로젝트 폴더에 자료 파일만 지속적으로 업데이트하여 재요청하는 구조를 만든다.

## 4. 대화 누적 방지를 통한 클로드 토큰 절약 기법 · [08:50](https://youtu.be/GUBZ1YsuVRQ?t=530)
- **3줄 요약**
  - 대화가 길어질수록 이전 맥락 전체를 재읽으며 **토큰 소비량**이 제곱 형태로 급증한다.
  - 수정 사항 발생 시 새 채팅을 덧붙이지 않고 **프롬프트 편집(수정)** 기능을 활용하여 이전 컨텍스트 누적을 방지한다.
  - 대화가 20개 이상 누적되면 내용을 **마크다운**으로 요약 정리한 뒤 새로운 세션으로 이관하여 작업을 지속한다.
- **핵심 인용**: "대화가 너무 길게 쌓이지 않도록 유지를 하는 게 중요합니다."
- **내 팁**: 대화가 길어져 답변이 마음에 들지 않을 때는 새 메시지를 계속 추가하지 말고 이전 프롬프트를 직접 편집하여 컨텍스트 누적을 막는다.

## 5. ★개인 맞춤 설정과 세션 초기화를 활용한 토큰 루틴 관리★ · [12:13](https://youtu.be/GUBZ1YsuVRQ?t=733)
- **3줄 요약**
  - 반복 지침을 **개인 맞춤 설정**이나 **프로젝트 지침**에 등록하여 프롬프트 작성 시 발생하는 토큰을 소모하지 않도록 방지한다.
  - 첨부 문서는 PDF나 워드 대신 구조 계산이 없는 **마크다운(.md) 형식**으로 변환하여 전달함으로써 토큰 소모를 단축한다.
  - **오전 7시 예약 작업**으로 5시간 단위 세션 한도 초기화 타이밍을 출근 시간에 맞춰 효율적으로 세팅한다.
- **핵심 인용**: "예약 작업 7시에 하나걸어 주는 것만으로도 토큰을 아주 루틴적으로 계획적으로 사용을 할 수가 있습니다."
- **내 팁**: 클로드의 5시간 세션 초기화 타이밍을 맞추기 위해 출근 전 오전 7시에 간단한 자동 예약 작업을 설정해 둔다.

## TL;DR (5줄)
1. **프롬프트 구조화**: 인물·상황·목적·방법 4요소 중 상황(맥락)을 강조하고 역질문 인터뷰 방식으로 구체화한다.
2. **대시보드 연동**: 클로드 코워크 커넥터로 구글 캘린더와 Gmail을 연결해 실시간 업무 인터랙티브 대시보드를 구축한다.
3. **로컬 폴더 자동**: 컴퓨터 내 리서치 폴더 전체를 연동하여 파일 첨부 없이 고품질 PDF 보고서를 자동 생성한다.
4. **컨텍스트 토큰 절약**: 대화 누적에 따른 토큰 폭증을 막기 위해 프롬프트 수정 기능과 마크다운 요약 이관 기법을 적용한다.
5. **세션 루틴 관리**: 개인 맞춤 설정 활용, 마크다운 파일 변환, 오전 7시 예약 작업을 통해 5시간 단위 한도를 스마트하게 순환한다.
