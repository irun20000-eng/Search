# (인건비 절약) AI 직원 자동화 방법, "이제 화면 녹화 던져주면 그대로 따라합니다." 클로드 코워크

> 한 줄 요약: **클로드 코워크(Claude Cowork)**의 **레코더(Recorder) 스킬**을 활용하여 사용자의 화면 녹화 영상(과정)과 프롬프트(기준)를 결합 학습시킴으로써, 별도의 코딩이나 프로그램 개발 없이 **쇼핑몰 피팅컷 멀티포즈 일괄 생성**, **상품 등록**, **CS 처리**, **네이버 광고 세팅** 등 웹 브라우저 기반 이커머스 반복 업무를 완전 자동 수행하는 AI 직원 구축법을 제시한다.

## 1. ★화면 녹화 반 AI 업무 학습과 레코더 스킬 개요★ · [00:00](https://youtu.be/CmhzT5v-NYY?t=0)
- **3줄 요약**
  - 매뉴얼 제작이나 코딩 없이 **업무 수행 화면 녹화 영상**을 AI에 전달하여 자동 학습시키는 체계를 구축한다.
  - 업무 흐름은 **녹화, 학습, 스킬 저장, 반복 실행**의 4단계 정밀 프로세스로 간소화된다.
  - 한 번 학습된 스킬은 퇴사나 품질 변동 없이 일정한 퀄리티로 브라우저 상에서 자동 반복 수행된다.
- **핵심 인용**: "내가 하던 대로 하는 걸 보여주기만 하면 되는 거예요 원본 녹화하고 학습시키고 스킬로 만들어놓고 반복시키는 겁니다."
- **내 팁**: 매뉴얼이나 코드 작성 없이 평소 작업 과정을 천천히 화면 녹화하여 AI 교육 자료로 활용한다.

## 2. 레코더 스킬 원리 및 윈도우 환경에서의 적용 방안 · [01:38](https://youtu.be/CmhzT5v-NYY?t=98)
- **3줄 요약**
  - **클로드 코워크**는 사용자의 컴퓨터 화면과 폴더 구조를 직접 인식하여 업무를 수행한다.
  - 맥(Mac) 전용 스킬 환경이라도 윈도우에서 화면 녹화 후 **특정 폴더에 비디오를 업로드**하여 동일하게 학습시킬 수 있다.
  - AI가 영상 속 클릭 위치, 메뉴 진입 순서, 입력 값을 정밀하게 분석하여 스킬 자산으로 변환한다.
- **핵심 인용**: "화면을 녹화하고 클로드 코워크에 들어가서 네가 보고 알아서 학습해서 스킬로 만들어라고 시켰는데 아주 정상적으로 작동되더라고요."
- **내 질문**: 맥 전용 레코더 스킬 외에 윈도우 환경에서 영상 화면 학습 시 클릭 좌표 오차를 줄이는 최적의 녹화 해상도가 궁금하다.

## 3. ★쇼핑몰 피팅컷 멀티포즈 제작 업무 녹화 및 학습 가이드★ · [02:30](https://youtu.be/CmhzT5v-NYY?t=150)
- **3줄 요약**
  - 핏 빌더 멀티포즈 체인지 메뉴에서 **4K 화질 및 1:1 비율** 설정 후 5가지 포즈 프롬프트를 입력하는 과정을 녹화한다.
  - 영상은 **작업 과정**을 가르치고 프롬프트는 **세부 작업 기준**을 제시하여 학습 완성도를 극대화한다.
  - 신입 직원 교육하듯 천천히 또박또박 작업 과정을 보여줄 때 AI의 패턴 학습 성공률이 覝대된다.
- **핵심 인용**: "영상은 과정을 가르치는 거고요 프롬프트는 기준을 가르치는 겁니다."
- **내 팁**: 화면 녹화 시에는 신입 사원에게 보여주듯 천천히 작업하고, 영상(과정)과 프롬프트(기준)를 함께 전달하여 학습 정확도를 높인다.

## 4. 자동 브라우저 조작을 통한 피팅컷 일괄 생성 실습 · [04:05](https://youtu.be/CmhzT5v-NYY?t=245)
- **3줄 요약**
  - 학습 완료 후 단 한 줄의 명령만으로 AI가 **브라우저 접속, 이미지 업로드, 포즈 변경, 다운로드**를 자동 진행한다.
  - 마우스 커서가 브라우저 상에서 스스로 움직이며 인간의 개입 없이 작업을 마무리한다.
  - 여러 컬러 및 품목의 사진을 배열로 지정하여 수십 장의 피팅컷 포즈를 순차적으로 자동 일괄 생성한다.
- **핵심 인용**: "저는 손 하나 안 대고 크롬 창에서 마우스 커서가 그냥 알아서 움직입니다."
- **내 팁**: 반복 작업을 실행할 때 단일 작업에 그치지 않고 여러 제품이나 색상 옵션을 배열로 묶어 일괄 자동 수행을 지시한다.

## 5. ★댓글·CS·상품등록·광고세팅 등 이커머스 업무 확장★ · [06:17](https://youtu.be/CmhzT5v-NYY?t=377)
- **3줄 요약**
  - 녹화 기반 자동화는 피팅컷 외에도 **리뷰 댓글 작성, CS 응대, 상품 등록, 네이버 광고 세팅** 등으로 확장된다.
  - 상품 등록 시 10분 이내의 녹화 영상과 상품별 폴더 정리를 결합하여 자동 등록 스킬을 세팅한다.
  - 하이버, 네이버, 에이블리 등 **플랫폼별 스킬을 세분화**하여 오작동 없는 정밀 자동화를 구현한다.
- **핵심 인용**: "매일마다 반복하는 업무 진행하실 때 녹화 버튼 하나만 눌러놓으세요 그게 그대로 AI한테 교육 자료가 됩니다."
- **내 팁**: 플랫폼별로 상품 등록이나 CS 규격이 다른 경우 각 플랫폼 전용 스킬로 세분화하여 학습시켜 실수를 방지한다.

## TL;DR (5줄)
1. **노코드 자동화**: 코딩 없이 화면 녹화 영상만으로 AI에게 업무 조작 순서를 직관적으로 학습시킨다.
2. **윈도우 호환**: 영상 녹화 파일을 클로드 코워크 폴더에 업로드하여 맥/윈도우 제약 없이 동일하게 적용한다.
3. **정밀 학습 기법**: 작업 순서를 보여주는 녹화 영상과 품질 기준을 제시하는 프롬프트를 결합하여 학습시킨다.
4. **브라우저 자동 조작**: 마우스 이동, 이미지 업로드, 프롬프트 입력, 파일 다운로드까지 손 하나 대지 않고 자동 처리한다.
5. **이커머스 전반 확장**: 상품 등록, CS 응대, 리뷰 댓글, 광고 세팅 등 반복적인 웹 업무 전체로 자동화를 확장한다.
