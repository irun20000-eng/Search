# “외주비 300만원 아꼈어요” 클로드코드로 카피라이팅·네이버 블로그 자동화 하는 방법

> 한 줄 요약: **클로드 코드로 블로그 초안(글+제목+메타+태그+이미지)을 1분 만에** 뽑아내는 오픈소스 세팅. 핵심은 **하네스 엔지니어링 3원리**(① 브랜드/경험을 폴더에 저장 ② '잘 쓴 글'의 객관적 기준 학습 ③ 메모리 누적)로, GPT/제미나이처럼 매번 초기화되지 않고 **우리 말투·데이터가 쌓여 점점 최적화**된다. 단 **네이버 자동 업로드는 금지**(저품질 리스크) — 초안까지만 자동화하고 발행은 사람이 직접 타이핑(휴먼 터칭).

## 1. 왜 블로그 자동화인가 — 외주·SaaS 비용 절감 · [00:00](https://youtu.be/uepJ7wDJOnE?t=0)
- **3줄 요약**
  - 블로그 마케팅 외주는 월 100~500만 원, 대체 AI SaaS도 월 3~15만 원 구독으로 고정비 발생.
  - 클로드 코드 하나면 그 비용 없이 **내 입맛대로 자유자재**로 뽑고, 자료·데이터가 누적·기억됨.
  - 결과물이 **정말 사람이 쓴 글 같은 퀄리티**로 완성 — 오늘 이걸 오픈소스로 무료 제공.
- **핵심 인용**: "외주 비용 한 2, 300만 원 나가는 거 바로 다 아낄 수 있고."
- **내 질문**: 'SaaS 구독 대신 내가 소유한 시스템에 데이터 누적'은 앞 영상들(옵시디언 세컨드브레인, 노트북LM)의 '자산화' 논리와 같은 결 아닐까?

## 2. 완성 결과물 시연 — 서식복사·이미지·1분 완성 · [01:33](https://youtu.be/uepJ7wDJOnE?t=93)
- **3줄 요약**
  - '서식 포함 복사'를 누르면 도입-본론-결론 글이 통째로 복사돼 블로그에 붙여넣기만 하면 됨.
  - 오른쪽에 **제목·메타 설명·태그**도 따로 복사 가능, **나노바나(Nano Banana)로 이미지도 블로그 톤에 맞게 자동 생성**.
  - 키워드만 입력하면(못 찾으면 AI가 알아서 조사) 이미지·체크리스트·해시태그까지 **1분 안에** 초안 완성.
- **핵심 인용**: "이 모든 것들이 한 1분도 안 걸려요. … 우리가 할 건 뭐냐? 키워드만 입력해 주면 돼요."
- **내 팁**: '글·제목·메타·태그·이미지'를 한 번에 산출하는 건 앞 영상(힉스필드 스킬)처럼 **워크플로우를 슬래시로 굳힌** 형태.

## 3. ★자동 발행은 금지 — 저품질 방지 & 휴먼 터칭★ · [02:51](https://youtu.be/uepJ7wDJOnE?t=171)
- **3줄 요약**
  - 입력까지 자동화할 수도 있지만 네이버 블로그는 **AI 티/입력 속도까지 측정**해 저품질 로직에 걸릴 위험.
  - 오랜 기간 키운 블로그가 다운/누락되면 마케팅 효과 자체가 사라지므로 리스크 회피가 우선.
  - 그래서 **초안까지만 자동, 발행은 복사→직접 타이핑**으로 최소한의 사람 손길(휴먼 터칭)을 의도적으로.
- **핵심 인용**: "블로그를 딱 들어가는 순간은 사람티를 많이 내는 게 의도적으로 그렇게 하는 게 좋아요."
- **내 질문**: '자동화의 경계선을 어디에 긋느냐'(발행 직전에서 멈춤)는 리스크 관리의 핵심 — 다른 자동화에도 적용할 원칙 아닐까?

## 4. 세팅 — 오픈소스 설치·온보딩(setup)·예시글 학습 · [06:32](https://youtu.be/uepJ7wDJOnE?t=392)
- **3줄 요약**
  - Git·Node.js 설치 후 깃허브 오픈소스를 다운 → 클로드 코드에서 `setup` 입력 → AI가 **인터뷰형 온보딩**(회사명·업종·타겟·서비스·톤 등). 상세히 답할수록 폴더 구조·퀄리티↑.
  - `setup-포스트(글 예시)` 단계: 기존 블로그 글 3~5개를 링크/복사로 제공 → **우리 말투·톤·문장 나눔을 학습**. (네이버 블로그는 본문 추출이 막혀 F12→설정→자바스크립트 비활성화 후 긁어 복사.)
  - `setup-도메인(키워드)` 단계: 카테고리 주요 키워드를 "직접 조사해"로 시키면 AI가 다 찾아줌 — **일을 떠넘길 때 "네가 해"로 되돌려야** 함.
- **핵심 인용**: "네가 해. 나한테 시키지 말고 네가 해라고 해 줘야 됩니다."
- **내 팁**: 예시글·키워드를 미리 학습시키는 건 앞 영상들(코워크 레시피, 브랜드 가이드 시트)의 '레퍼런스 재료화'와 동일.

## 5. 글 생성 — /blog new·API키(제미나이·네이버)·검토 · [12:34](https://youtu.be/uepJ7wDJOnE?t=754)
- **3줄 요약**
  - `/blog new <키워드>`로 실행 → `output` 폴더에 날짜별로 글·이미지 생성. `.env`에 **제미나이 API 키 + 네이버 클라이언트 ID/시크릿**을 넣어야 키워드 리서치·이미지 생성이 작동(없으면 해당 작업 스킵).
  - 글은 톤·문장을 우리 블로그에 맞춰 작성하고 **사실 확인 체크리스트·이미지 삽입 위치·키워드 빈도**까지 자동 지정. (예: "견적서 세 장 받으니 30만~800만 원" 식 후킹 도입부.)
  - 완성 후 **사람이 확인할 것**(수치 실제화·표현 검토·이미지 재생성)을 알려주고, 웹페이지 형태로 복사하기 좋게 최종 정리.
- **핵심 인용**: "건너뛴 작업 키워드 리서치 … API 키가 없어 가지고 수동 리서치로 대체."
- **내 질문**: '생성→건너뛴 작업·사람 확인사항 리포트'는 앞 영상(3D 쇼츠 스킬)의 '검토 게이트'와 같은 안전장치 아닐까?

## 6. ★핵심 원리 — 하네스 엔지니어링 3원칙 & 폴더 구조★ · [18:35](https://youtu.be/uepJ7wDJOnE?t=1115)
- **3줄 요약**
  - 예전엔 신경 쓰면 글 1편에 4시간, 지금은 15분. 문제는 **매번 까먹고·톤도 다르고·상위노출 규칙 미적용**이라 AI를 정교히 컨트롤 못 함 → 하네스 엔지니어링 적용.
  - 3원칙: **① 지식 저장**(브랜드/경험/포트폴리오를 폴더에 → 팀원 바뀌어도 AI가 참고, 인수인계 불필요) **② 객관적 기준**(잘 쓴 글의 공통점을 점수 기준으로) **③ 메모리**(저장·누적→같은 실수 반복 안 함, 시스템이 디벨롭).
  - 구조: `CLAUDE.md`(메인 지시서, 항상 최우선 로드) + `knowledge`(브랜드팩트 등 자료실) + `keyword-bank` → 에이전트·슬래시 커맨드가 **사전 컨텍스트 로드→키워드 리서치→콘텐츠 생성→'잘 쓴 글' 규칙 검수→이미지→휴먼 터칭 업로드** 순으로 작동.
- **핵심 인용**: "매번 똑같은 실수 반복하는 게 아니라 … 기억되고 저장되는 게 그게 시스템이라 생각."
- **내 팁**: ①지식저장 ②판정기준 ③메모리 3원리는 이 프로젝트의 `LESSONS.md`(실수 방지 규칙 누적) 운영과 **정확히 같은 패턴** — 저장·기준·기억이 품질을 복리로 키운다.

## TL;DR (5줄)

1. **가치**: 월 100~500만 외주·구독 SaaS 없이 클로드 코드로 블로그 초안(글·제목·메타·태그·이미지)을 **1분**에 — 무료 오픈소스.
2. **원칙(★)**: 자동은 **초안까지만**, 네이버 발행은 저품질 리스크 때문에 **사람이 직접 타이핑**(휴먼 터칭).
3. **세팅**: Git/Node 설치→`setup` 인터뷰 온보딩(상세히!)→기존 글 3~5개로 말투 학습→키워드는 "네가 해"로 AI에 위임.
4. **생성**: `/blog new 키워드`→`output`에 글·이미지, `.env`에 제미나이·네이버 API 키 필요, 사실확인 체크리스트+사람 확인사항 리포트까지.
5. **핵심(★)**: 하네스 엔지니어링 3원리 = ①지식 폴더 저장 ②'잘 쓴 글' 객관 기준 ③메모리 누적 → GPT처럼 초기화되지 않고 **우리 톤·데이터가 복리로 최적화**(`CLAUDE.md`+knowledge+keyword-bank 구조).
