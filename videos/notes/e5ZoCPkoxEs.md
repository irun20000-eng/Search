# 노트북LM을 활용한 나만의 AI 연구소 만들기 (알라딘X골든래빗 라이브)

> 한 줄 요약: 노트북LM의 정체성은 **"내가 제공한 소스만 읽는 전담 연구원"** — 인터넷 전체가 아니라 업로드한 문서 한정으로만 답하고 **출처 위치까지 정확히** 제시해 환각이 거의 없다. 하루키 스캔본으로 소스 기반 Q&A·팟캐스트·슬라이드를, 여러 유튜브 영상을 묶어 출처 표기 종합요약을, **딥 리서치로 '김영하 작가' 스타일 소스를 수집→첨삭 프롬프트를 생성→ChatGPT/클로드/제미나이 비교**까지 시연. 발표자의 결론: LM은 '자료 학습·분석'용으론 값어치를 하지만 일상 질문엔 부적합, 글쓰기 첨삭은 (통념과 달리) **ChatGPT가 클로드보다 낫다**.

## 1. 오프닝 & 노트북LM이란 — 범용 AI와의 결정적 차이 · [6:44](https://youtu.be/e5ZoCPkoxEs?t=404)
- **3줄 요약**
  - 라이브 웨비나(파워유저 대상 복습 톤). 노트북 = '나만의 작업 공간(전용 책상)', '새로 만들기'로 시작.
  - **범용 AI(ChatGPT·클로드·제미나이)**: 인터넷 모든 문서를 학습한 '답변 머신'.
  - **노트북LM**: 인터넷을 참조하지 않고 **오직 사용자가 제공한 소스 한정**으로 답변 = "내 책상 위 자료만 읽는 전담 연구원".
- **핵심 인용**: "노트북LM은 내 책상 위에서 내가 제공한 자료만 읽는 전담 연구원이다."
- **내 질문**: '소스 한정'이라는 제약이 오히려 신뢰성(검증 가능성)을 만든다 — 범용 AI의 환각 문제를 구조적으로 회피하는 설계 아닌가?

## 2. 소스 제공 방법 & 데이터 프라이버시 관점 · [10:11](https://youtu.be/e5ZoCPkoxEs?t=611)
- **3줄 요약**
  - 자료/아이디어가 있는 사람이 쓰는 도구(없으면 그냥 ChatGPT에 대화가 편함).
  - 소스 방법: **파일 업로드 / 웹·유튜브 링크 / 구글 드라이브 / 텍스트 붙여넣기 / 웹 검색(패스트·딥 리서치)**.
  - 프라이버시: "업로드하면 기본적으로 공개될 수 있다"는 전제를 깔아라(유튜브→GPT-4o 학습 사례). 발표자는 '내 자료=공공재'로 여기고 감수.
- **핵심 인용**: "어떤 자료든 … 일단 업로드하면 그 자료는 기본적으로 공개될 수 있다."
- **내 팁**: 소스 검색의 '패스트 리서치'(빠름) vs '딥 리서치'(심층·양질·느림)를 목적에 따라 선택.

## 3. 실습① 하루키 스캔본 소스 Q&A — 출처 기반 답변 · [14:44](https://youtu.be/e5ZoCPkoxEs?t=884)
- **3줄 요약**
  - 무라카미 하루키 에세이 스캔 PDF(이미지 200p, OCR 아님) 업로드 → 노트북이 텍스트 추출(시간 소요).
  - "이 책에서 재미있는 에피소드 소개·요약" → '신주쿠역 안내방송 녹음으로 스팸전화 응징', 'soup or salad→슈퍼 샐러드 오해' 등 **책 한정** 답변.
  - **답변마다 출처** → 클릭 시 해당 페이지로 정확히 이동. 소스는 '추가' 버튼으로 무제한 확장(하루키 전작 모아 질의 가능).
- **핵심 인용**: "그 답변이 어디에 존재하는지 출처의 위치까지도 정확하게 제공한다."
- **내 질문**: 이미지 스캔본도 내부 텍스트 추출로 질의가 되는데, 저작권 자료를 '개인 학습'으로 넣는 것의 경계는?

## 4. 실습② 소스 → 다양한 포맷 템플릿 · [22:27](https://youtu.be/e5ZoCPkoxEs?t=1347)
- **3줄 요약**
  - 오른쪽 템플릿: **AI 오디오 오버뷰(5~6분 팟캐스트, 심층/요약/비평/토론 관점 지정)**, **슬라이드(자세한/발표자용, 분량·언어·목차 지정)**, 동영상, 플래시카드·퀴즈·마인드맵, 보고서(브리핑·학습가이드·블로그), 인포그래픽, 데이터 표.
  - 실제로 하루키 소스로 **~23분 팟캐스트**와 **표지~결론까지의 PPT**가 생성됨.
  - 한계: 슬라이드 한 장이 통째 이미지라 PPT 다운로드해도 세부 편집 어려움 / **목차는 반드시 사용자가 직접** 짜야 하고, LM이 목차를 줘도 중간 페이지를 누락(환각)하니 **총 페이지 수를 명시**.
- **핵심 인용**: "세부적인 목차 기획은 꼭 여러분이 직접 해 주셔야 돼요."
- **내 팁**: '영혼 없는 AI 유튜브 영상'(딱 봐도 AI)은 효과 없으니 만들지 말라 — 도구는 학습·발표 보조로.

## 5. 실습③ 여러 유튜브 영상 묶어 출처 표기 종합 요약 · [33:40](https://youtu.be/e5ZoCPkoxEs?t=2020)
- **3줄 요약**
  - '웹사이트'로 김대식 교수 영상 여러 개(58·45·31·10~15분, 총 ~2시간)를 링크로 삽입(Shift+Enter로 추가).
  - 프롬프트: **"모든 자료를 관통하는 핵심 주제 3가지 + 문장마다 출처 표시 + 추론한 부분은 '추정' 표기(환각 금지)"**.
  - 결과: 핵심 주제 3가지가 **각 소스 자막 출처와 함께** 정리 → 출처 클릭 시 해당 지점 이동(환각 아님 확인).
- **핵심 인용**: "자료에 명확하지 않아 추론한 부분은 추정이라고 표시해라. 즉 환각하지 마라."
- **내 질문**: '출처 강제 + 추정 표기' 프롬프트 패턴은 범용 AI에도 이식 가능한 환각 억제 기법 아닌가?

## 6. 실습④ ★'김영하 작가' 첨삭 AI 만들기 — 딥리서치→프롬프트 생성→모델 비교★ · [44:10](https://youtu.be/e5ZoCPkoxEs?t=2650)
- **3줄 요약**
  - **딥 리서치**로 '김영하+첨삭' 소스 수집 → 철학 추출(초고는 쓰레기·빠른 집필, 퇴고에 공, 설명 말고 '보여주는 글쓰기'·오감).
  - 소스 기반으로 **"김영하 작가처럼 첨삭하는 프롬프트를 완벽하게 만들어줘"** → 생성된 첨삭 프롬프트를 복사해 **ChatGPT·클로드·제미나이**에 각각 자기 글로 실행.
  - 비교 결과: **재미나이=냉정하나 성의 부족**, **ChatGPT=원인분석+문장별 첨삭+재구성+한마디로 가장 친절**, 클로드=원인 진단 강점. "글쓰기는 클로드"라는 통념과 달리 **ChatGPT가 더 낫다**는 평가.
- **핵심 인용**: "요즘은 오히려 글 쓰기는 클로드보다 ChatGPT가 더 잘 써 줍니다."
- **내 팁**: 만날 수 없는 전문가의 '분신 AI'는 → ①공개 자료를 딥리서치로 수집 ②그 소스로 페르소나 프롬프트 생성, 두 단계로 만든다.

## 7. 마무리 — 토큰 경제와 노트북LM의 진짜 쓸모 · [54:44](https://youtu.be/e5ZoCPkoxEs?t=3284)
- **3줄 요약**
  - **클로드 웹챗 = 코드(코워크) 토큰과 공유** → 웹챗 대화가 구독 한도를 갉아먹음. 바이브 코딩 하는 사람에겐 클로드 웹챗 비권장(ChatGPT는 코덱스와 토큰 분리).
  - 소스 개수 한도: 무료 50 / 7,900원 요금제 100 / 재미나이 프로 300개(노트북 자체는 무제한).
  - 노트북LM의 진짜 쓸모 = **논문·긴 영상 등 자료 학습·분석**(arXiv PDF 넣어 다국어 논문도 한글로). 단 재미나이 환각이 잦아 사람 검증 필수, 일상 질문엔 부적합.
- **핵심 인용**: "공부하고 싶은 내용, 분석해야 될 자료 … 쓰실 때는 노트북 LM이 그나마 가장 쓸 만하다."
- **내 질문**: 웹 채팅과 코딩의 토큰 풀이 공유된다는 지적이 사실이라면, 도구별 '토큰 회계'를 아는 것이 실사용 비용 최적화의 핵심 아닌가?

## TL;DR (5줄)

1. **정체성**: 노트북LM = 내가 준 소스만 읽고 **출처까지 제시**하는 전담 연구원 → 범용 AI 대비 환각이 거의 없고 검증이 쉽다.
2. **입력**: 파일·웹/유튜브 링크·드라이브·텍스트·웹 검색(패스트/딥). 단 업로드 자료는 '공개될 수 있다'는 전제.
3. **가공**: 한 소스를 팟캐스트·슬라이드·퀴즈·마인드맵·보고서·인포그래픽 등 **다양한 포맷**으로 — 목차는 사람이 직접, 페이지 누락(환각) 주의.
4. **종합·페르소나(★)**: 여러 긴 영상을 '출처 표시+추정 표기(환각 금지)' 프롬프트로 요약 / 딥리서치로 전문가 스타일 소스를 모아 **'분신 AI' 첨삭 프롬프트** 생성.
5. **실전 조언**: 글쓰기 첨삭은 ChatGPT>클로드(체감), 클로드 웹챗은 코딩 토큰을 공유하니 주의, 노트북LM은 논문·자료 학습용으로 값어치를 한다.
