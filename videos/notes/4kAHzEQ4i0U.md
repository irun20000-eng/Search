# 옵시디언 활용도 500%! Obsidian Excalidraw + Claude Code + GraphView 완전 활용법

> 한 줄 요약: 옵시디언 커뮤니티 플러그인 **Excalidraw**는 그림 파일이 **순수 텍스트**라서 **Claude Code가 직접 읽고 그린다**. 기존 **캔버스(Canvas) 다이어그램을 Excalidraw로 자동 변환**하는 것까지 시연하고, **코어 플러그인 그래프 뷰**로 태그 연결을 시각화한다. 마지막으로 AI에게 파일 경로를 빠르게 넘기는 **단축키(파일경로 복사 / 시스템 절대경로 복사)** 세팅으로 토큰·시간을 아끼는 실전 팁을 준다.

  - 이어서 Excalidraw 그림도 **AI가 읽고 그려 준다**는 결과를 미리 보여주며 시작.
  - 핵심 메시지: 플러그인 설치부터 단축키까지 "이제 AI가 대신 만들어 준다".
- **핵심 인용**

## 2. 인트로 — 오늘 소개할 Excalidraw 플러그인 · [0:24](https://youtu.be/4kAHzEQ4i0U?t=24)
- **3줄 요약**
  - 진행자(오후다섯씨) 인사 후, 옵시디언 상단 탭에 열린 **Excalidraw 드로잉 파일**을 소개.
  - 사각형·자유 드로잉·글씨·화살표·지우기 등 **손그림 도구**로 쓸 수 있는 유용한 플러그인.
  - 오늘의 진짜 관심사는 "이 Excalidraw를 **AI가 그릴 수 있느냐**"를 확인하는 것.

- **내 질문**

## 3. Excalidraw 설치 — 좋은 커뮤니티 플러그인 고르는 기준 · [1:01](https://youtu.be/4kAHzEQ4i0U?t=61)
- **3줄 요약**
  - 설정(하단 톱니바퀴) → **커뮤니티 플러그인 → 탐색**에서 검색해 설치(현재 5,125개 플러그인 등록).
  - **좋은 플러그인 고르는 기준 2가지**: ① **다운로드 수가 많은지**(검증됨), ② **업데이트가 최근인지**(방치되지 않았는지). 1년 넘게 업데이트 없는 건 피하라.
  - 설치 후 활성화하면 좌측 아이콘에서 **New Drawing**으로 새 그림을 만들 수 있다.
- **핵심 인용**
- **내 질문**
- '다운로드 수 + 최신 업데이트'는 npm/VS Code 확장 고를 때와 똑같은 신뢰 신호 — 플러그인 생태계 공통 휴리스틱이구나.

## 4. Excalidraw 파일의 비밀 — 텍스트라 AI가 읽는다 · [3:31](https://youtu.be/4kAHzEQ4i0U?t=211)
- **3줄 요약**
  - VS Code에서 같은 볼트 폴더(`mr5pm`)를 열면 Excalidraw·임시·캔버스 **세 폴더**가 보인다.
  - Excalidraw 파일을 열면 **사람은 못 읽는 알 수 없는 문자들**로 가득 — 하지만 **텍스트 파일**이라 AI는 읽고 무슨 그림인지 이해한다.
  - 지난 영상의 **캔버스(Canvas)**도 같은 원리(텍스트라 AI가 읽고 쓰고 구조화) — 이번엔 그걸 Excalidraw로 확장.
- **핵심 인용**
- **내 질문**
- 캔버스는 JSON, Excalidraw는 자체 텍스트 포맷 — 둘 다 "AI가 편집 가능한 그림"이라는 점에서 이미지(PNG)와 결정적으로 다르다.

## 5. 캔버스 다이어그램 → Excalidraw 자동 변환 시연 · [4:43](https://youtu.be/4kAHzEQ4i0U?t=283)
- **3줄 요약**
  - 변환하려는 **캔버스 예제 파일의 경로를 우클릭 → 경로 복사**해 Claude Code에 알려준 뒤 "이 파일을 Excalidraw로 그려 줘"라고 요청.
  - Claude가 파일을 먼저 읽고 복잡한 캔버스 다이어그램을 해석 → **Excalidraw 다이어그램 형태로 재생성**('Agent OS' 도식이 깔끔히 그려짐).
  - 결론: **AI가 캔버스를 읽어 Excalidraw로 변환**하는 게 실제로 동작함을 확인.
- **핵심 인용**
- **내 질문**
- 포맷 A(캔버스 JSON) → 포맷 B(Excalidraw)로 AI가 **다이어그램을 트랜스파일**하는 셈 — 도식의 의미를 보존하며 표현만 바꾸는 작업이 얼마나 안정적일지 궁금.

## 6. 코어 플러그인 그래프 뷰 — 노드=문서, 태그로 연결 · [5:57](https://youtu.be/4kAHzEQ4i0U?t=357)
- **3줄 요약**
  - **그래프 뷰**는 옵시디언 회사가 공식 제공하는 **코어 플러그인**. 각 **노드=하나의 문서(노트)**, 노트들은 **태그**로 서로 연결된다.
  - 실제 메인 볼트를 열면 수많은 파일이 연결돼 있고, **그룹마다 색상**을 지정해 분포·연결 패턴을 한눈에 본다('클로드' 태그로 묶인 문서들처럼).
  - 시각화가 잘 안 될 때도 **AI에게 요청하면 분포를 알아서 정리**해 준다.
- **핵심 인용**
- **내 질문**
- 태그 기반 그래프가 "지식의 연결 지도"라면, 노트에 다는 tags 프런트매터 설계가 곧 그래프 품질을 좌우하겠구나.

## 7. 파일 경로 정확히 지정하기 — 토큰·메모리 절약 · [8:00](https://youtu.be/4kAHzEQ4i0U?t=480)
- **3줄 요약**
  - 파일이 많아지면 AI가 특정 파일을 찾느라 **토큰(=비용)과 메모리를 낭비**한다 — 폴더·태그만 알려줘선 부족.
  - 최선은 **작업에 필요한 파일 경로를 명확히 찍어** "이 파일을 읽고 답해 줘"라고 요청하는 것.
  - 경로 전달은 우클릭 3단계로도 되지만, **단축키를 만들면** 훨씬 빠르다.
- **핵심 인용**
- **내 질문**
- "경로를 명시해 컨텍스트를 좁힌다"는 건 Claude Code에서 파일을 `@경로`로 직접 지목하는 것과 같은 원리 — 정확한 컨텍스트가 곧 비용 절감이다.

## 8. 단축키 세팅 — 상대경로 vs 절대경로 복사 · [8:43](https://youtu.be/4kAHzEQ4i0U?t=523)
- **3줄 요약**
  - 설정 → **단축키**에서 "파일 경로 복사"에 키를 할당(진행자는 **Option+Cmd+S**). 이미 쓰는 키와 겹치면 **충돌 경고**가 뜨니 피할 것.
  - **파일 경로 복사** = 프로젝트 내부 **상대 경로**, **시스템 루트에서 현재 파일 경로 복사**(진행자는 **Ctrl+Option+S**) = **절대 경로**.
  - 진행자는 여러 볼트를 오가므로 **절대 경로를 주로 사용**(다른 프로젝트 폴더에서도 통하니까).
- **핵심 인용**
- **내 질문**
- 여러 볼트를 쓸 땐 절대경로가 안전하지만, 팀 공유·git 저장소에선 상대경로가 이식성이 좋다 — 상황에 따라 둘 다 단축키로 두면 최고겠다.

## 9. 마무리 — Excalidraw·그래프 뷰·단축키 요약 · [11:04](https://youtu.be/4kAHzEQ4i0U?t=664)

- **내 질문**

## TL;DR (5줄)

1. **Excalidraw**(커뮤니티 플러그인)는 그림이 **텍스트 파일**이라 Claude Code가 직접 읽고 그린다.
2. 플러그인은 **다운로드 수 + 최근 업데이트**로 신뢰도를 판단해 고른다.
3. 기존 **캔버스 다이어그램을 Excalidraw로 자동 변환**하는 것까지 AI가 해낸다(경로 복사 → "그려 줘").
4. **코어 플러그인 그래프 뷰**는 노드=문서, **태그로 연결**해 지식 분포를 색상으로 시각화한다.
5. AI에 파일을 넘길 땐 **경로를 명시**해 토큰을 아끼고, **단축키**(상대=파일경로 / 절대=시스템경로 복사)로 빠르게 전달한다.
