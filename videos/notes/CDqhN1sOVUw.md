# 스레드(Threads) 자동화 프로그램 무료로 드립니다 — 글 발행부터 댓글 자동답글까지

> 한 줄 요약: n8n/Make 같은 유료 구독 대신 **메타 공식 창구(무료)**로 스레드 자동화를 한다. **공개 계정 전제** → 메타 개발자 사이트에서 **앱 생성(이용사례=Threads API Access)** → **권한 11개 중 4개만**(기본 켜진 basic + content_publish + manage_replies + read_replies) → **내 계정을 '스레드 테스터'로 등록**(위쪽 일반 테스터 아님, 아래 섹션의 Threads Tester ← 최대 함정) → 폰 스레드 앱에서 **초대 수락** → 설정 탭에서 버튼 하나로 **60일 액세스 토큰** 발급(주의: **Threads App ID는 아래쪽 다른 값**). 글 발행은 사람이(2단계·500자 제한→체인), **댓글 답글은 자동**(키워드 매칭). 링크는 첫 댓글에 1개만(2개면 스팸 삭제). 프로그램은 무료 배포.

## 1. 개념 — 유료 대신 메타 공식 무료 창구 · [00:00](https://youtu.be/CDqhN1sOVUw?t=0)
- **3줄 요약**
  - 새벽 답글도 컴퓨터가 자동으로 — n8n/Make 없이 **구독료 0원**. 단 **비공개 계정은 불가**(공개 계정에만 토큰 발급).
  - 검색되는 스레드 자동화는 대부분 n8n/Make(버튼 편하지만 매달 과금). 메타는 **공식 창구를 무료**로 열어둠 = 남의 열쇠를 빌리던 걸 **내 열쇠 직접 발급**으로.
  - 솔직한 3가지: **초기 세팅·글 올리기 버튼은 사람이**, **댓글 답글만 기계가**(신상 문의·수강 후기 답글이 밤에도 자동).
- **핵심 인용**: "지금까지는 남의 열쇠를 달마다 빌렸던 거고 … 우리가 할 건 내 열쇠를 직접 발급받는 겁니다."
- **내 팁**: '공식 API 무료 + 공개 계정 전제 + 발행은 사람/답글은 자동'은 앞 영상(방구석컴퍼니 인스타 자동화)과 완전히 같은 구조 — 같은 채널의 스레드판.

## 2. 앱 생성 + ★권한 4개★ · [01:23](https://youtu.be/CDqhN1sOVUw?t=83)
- **3줄 요약**
  - 메타 개발자 사이트 **앱 만들기**(5단계: 앱 상세·이용 사례·비즈니스·요구사항·개요). **이용 사례 = Threads API Access** 선택(순간 다른 이용사례 회색 잠김 — 정상). 비즈니스 "연결 안 함", 요구사항 "없음", 만들기(비밀번호 재확인).
  - 권한 목록 **11개 중 4개만**: **basic(기본 켜짐)** + **threads_content_publish**(글 올리기) + **manage_replies**(답글 쓰기) + **read_replies**(답글 읽기).
  - 읽기/쓰기 권한이 서로 달라 **하나만 켜면 반쪽만 작동**(읽는데 답 못 달거나, 답은 다는데 댓글을 못 가져옴).
- **핵심 인용**: "권한은 열쇠에 붙는 기능 표시 같은 거라서 읽기 표시만 붙은 열쇠로는 답을 못 씁니다."
- **내 질문**: 인스타 영상의 게시 권한 직접 추가와 판박이 — 메타 API 계열의 '권한 개별 활성화'가 공통 함정 아닐까?

## 3. ★최대 함정 — '스레드 테스터' 등록 + 폰에서 수락★ · [02:44](https://youtu.be/CDqhN1sOVUw?t=164)
- **3줄 요약**
  - 앱 역할→사람 추가 창에서 **위쪽 일반 '테스터'를 고르면 안 됨** → 화면을 내려 **"이 앱에 대한 추가 역할" 섹션의 'Threads Tester'**를 선택(이게 대부분 실패하는 자리, 잘못 골라도 화면상 아무 일도 안 일어나 원인 파악 어려움).
  - 사용자명 입력 후 **자동완성 목록을 클릭**해야 등록(타이핑만 하면 안 잡힘) → 상태 '대기 중'.
  - **수락은 개발자 콘솔이 아니라 폰 스레드 앱**에서: 설정→웹사이트 권한→초대 수락 → 대기 중 해제.
- **핵심 인용**: "위에 있는 저 테스터 고르시면 안 돼요 … 아래 스레드 테스터. 잘못 골라도 이 화면에선 아무 일도 안 일어난다."
- **내 팁**: 등록(콘솔)과 수락(폰 앱)이 화면이 갈려 "초대는 했는데 왜 안 되지"에서 멈추는 자리 — 절차 순서를 모르는 게 문제지 기술이 아님.

## 4. ★60일 토큰 발급 — Threads App ID 주의★ · [04:10](https://youtu.be/CDqhN1sOVUw?t=250)
- **3줄 요약**
  - 이용 사례→Threads API Access→**설정 탭**. **주의: 앱 ID가 2개** — 앱 목록의 ID ≠ 이 화면의 **Threads App ID**(아래쪽에 따로 표기). 공식 문서도 Threads App ID를 쓰라고 명시, 위쪽 걸 넣으면 계속 실패.
  - 화면 아래 **사용자 토큰 생성기** → 내 계정 옆 "액세스 토큰 생성하기" 버튼 → **60일 장기 토큰**이 즉시 나옴(1시간 만료 토큰 뚫는 비법 불필요).
  - **60일 뒤 만료**, 갱신 가능하나 **발급 24시간 후부터** 갱신 걸림.
- **핵심 인용**: "버튼이 처음부터 장기 토큰을 줍니다 … 60일 뒤엔 만료됩니다. 갱신은 발급하고 24시간이 지나야."
- **내 질문**: '두 개의 앱 ID 중 아래쪽 Threads App ID' 같은 미세 함정은 앞 영상(인스타 토큰)의 '한 번만 보이는 토큰'처럼, 자격증명 발급 단계가 자동화의 진짜 병목 아닐까?

## 5. 실행 — 글 발행(2단계·체인) + 자동답글 + 한도·스팸 규칙 · [05:33](https://youtu.be/CDqhN1sOVUw?t=333)
- **3줄 요약**
  - **글 발행**: 만들기→올리기 **2단계**(사이 텀은 정상). **한 편 500자 초과면 아예 안 올라감** → 긴 글은 **체인으로 분할**. 발행 버튼은 사람이.
  - **자동 답글**: 내 글 댓글을 훑어 **정해둔 키워드**가 보이면 답글("공부" 댓글→링크, "자료" 댓글→신청서). read/manage_replies 권한 사용. DM 없어 **공개 답글**(오히려 답글 쌓이면 노출↑).
  - **규칙**: 링크는 **첫 댓글에 1개만**(2개 넣으면 스팸으로 **원글까지 삭제**), 2번째는 키워드 답글로. **한도 하루 글 50·답글 1000**(앱 새로 만들어도 계정 단위 합산). 댓글은 **끝까지 읽어야**(첫 장만 긁으면 오래된 댓글 누락). 대시보드로 발행수·토큰 잔여일·자동 on/off 관리. 프로그램 **무료 배포**.
- **핵심 인용**: "링크는 첫 댓글에 하나까지. 두 번째 링크는 … 키워드 답글로 빼세요."
- **내 팁**: '500자 체인·스팸 링크 규칙·키워드 답글'은 앞 영상(신영선 블로그 저품질 회피)과 같은 '플랫폼 규칙 준수'. 다음 편은 "올릴 글을 기계가 뽑아내는 단계"로 이어짐.

## TL;DR (5줄)

1. **가치**: n8n/Make 유료 대신 **메타 공식 API 무료**로 스레드 자동화. **공개 계정** 필수. 프로그램 무료 배포.
2. **앱·권한(★)**: 앱 생성(이용사례=Threads API Access) → 권한 **11개 중 4개**(basic+content_publish+manage_replies+read_replies). 하나 빠지면 반쪽 작동.
3. **테스터(★)**: 위쪽 일반 테스터 X → 아래 **'Threads Tester'** 등록(자동완성 클릭) → **폰 스레드 앱에서 초대 수락**. 최대 함정.
4. **토큰(★)**: 설정 탭 하단 생성기로 **60일 토큰** 즉시 발급. **Threads App ID(아래쪽 다른 값)** 사용 필수. 24시간 후 갱신 가능.
5. **실행**: 글은 사람이(2단계·500자→체인), **답글은 자동(키워드)**. 링크 첫 댓글 1개(2개면 원글 삭제), 하루 글50·답글1000, 댓글 끝까지 읽기.
