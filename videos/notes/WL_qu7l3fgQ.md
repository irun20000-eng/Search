# 클로드 코드는 이제 API 키 없이 래딧·X·유튜브·링크드인·깃허브·V2EX·RSS 14개 채널을 읽을 수 있습니다

> 한 줄 요약: 클로드 코드는 기본적으로 인터넷(X·레딧·유튜브 등)에 못 나가서, 결국 사람이 브라우저를 열어 복붙 심부름을 하게 된다. **agent-reach**는 **파이썬 패키지 하나(`pip install`)**로 에이전트가 **X·유튜브·레딧·GitHub·일반 웹 등 14개+ 채널을 직접 읽고 검색**하게 해준다 — **API 키도 결제도 불필요**. 핵심 개념은 **셀프 힐링 라우터**: 한 통로가 막히면 알아서 다음 통로로 우회한다. 설치·X 검색·유튜브 자막 요약·GitHub 레포 분석까지 실제로 시연하며, "AI를 세상에 연결해 **세상을 재료로 쓰게** 만드는" 것이 요지.

## 1. 문제 — 세상에서 제일 똑똑한 녀석이 인터넷엔 못 나간다 · [0:00](https://youtu.be/WL_qu7l3fgQ?t=0)
- **3줄 요약**
  - 클로드 코드에 X 링크를 주고 분석시켜도 못 하는 경우가 많다 — **원래 못 하는 일**이기 때문(학습 시점에 시간이 멈춰 있음).
  - "지금 X에서 유행하는 키워드 알려줘" → 십중팔구 **"정보에 접근할 수 없습니다"**.
  - 그래서 결국 사람이 직접 브라우저를 열고 검색·복사해 채팅창에 붙여 넣는 **심부름**을 하게 된다.
- **핵심 인용**
- **내 질문**
- 우리 자막 수집도 "AI가 유튜브에 직접 못 가서" 사람이 브라우저를 여는 구조 — 정확히 같은 벽이다. agent-reach가 이걸 뚫는지 궁금.

## 2. agent-reach — 파이썬 패키지 하나로 14채널 · [1:25](https://youtu.be/WL_qu7l3fgQ?t=85)
- **3줄 요약**
  - 보통은 채널마다 **API 키 발급 + 카드 결제 + 사용량 제한 + 플랫폼별 상이한 사용법**에 지친다.
  - **agent-reach**는 **파이썬 패키지 하나**만 설치하면 X·유튜브·레딧·GitHub·일반 웹 등 **14개+ 채널**을 에이전트가 읽고 검색 — **API 키·결제 없음**.
  - **셀프 힐링 라우터**: 한 통로가 막히면 **알아서 다음 통로로 자동 우회**(X가 막히면 다른 길로).
- **핵심 인용**
- **내 질문**
- "막히면 다른 경로로 우회"는 우리 자막 파이프라인의 폴백 사고와 동일 — MCP→timedtext→패널→확장처럼. 라우팅을 도구가 알아서 하면 이상적이다.

## 3. 마케팅 거품 걷어내기 & 설치 두 갈래 · [2:08](https://youtu.be/WL_qu7l3fgQ?t=128)
- **3줄 요약**
  - "별 4만 개! 5만 개 찍기 전에 북마크" 같은 **마케팅 냄새**에 처음엔 뒤로 뺐지만, 깔아보니 **거품은 거품이어도 물건은 진짜**였다.
  - 개발자만 쓰는 것 아니다 — **터미널에 한 줄**, 그것도 어려우면 **클로드 코드에게 시키면** 된다.
  - 설치 2가지: ① **`pip install agent-reach`** 직접 입력 ② **설치 문서 링크를 클로드 코드에 던져** "이거 보고 깔아줘"(도구의 진짜 매력).
- **핵심 인용**
- **내 질문**
- "문서 링크를 던지면 알아서 설치" — 이게 되려면 클로드가 그 링크를 읽어야 하는데, 바로 그 능력을 agent-reach가 준다는 순환이 재밌다.

## 4. 설치 시연 — 클론 → 닥터 진단 → 전체 채널 · [3:26](https://youtu.be/WL_qu7l3fgQ?t=206)
- **3줄 요약**
  - 클로드 코드를 **`--chrome` 파라미터**로 실행 → agent-reach 레포 주소를 주고 "클론하고 설치해줘". `CLAUDE.md`를 읽어 설치법(파이썬 패키지) 확인 → **가상환경(venv)**에 설치.
  - **닥터(진단)**로 상태 확인: 13개 채널 중 **6개 즉시 사용 가능**(GitHub·YouTube·V2EX·RSS 등), 스킬 자동 등록(트위터/X·레딧·LinkedIn·중국 플랫폼 등), 전체 시맨틱 검색은 선택 설치.
  - "모두 설치해줘" → 나머지 채널 설치(중간에 **OS 암호**를 물으면 정확히 입력), 일부는 **인증/크롬 확장 수동 설치**만 남는다.
- **핵심 인용**
- **내 질문**
- "닥터로 진단 → 즉시 가능/선택 설치 구분"은 좋은 온보딩 UX — 우리 파이프라인도 사전 점검(preflight) 단계가 이런 역할이다.

## 5. X 검색 시연 — 셀프 힐링 라우터가 실제로 우회 · [5:34](https://youtu.be/WL_qu7l3fgQ?t=334)
- **3줄 요약**
  - "X에서 요즘 **Loop Engineering** 반응 모아줘" → agent-reach 스킬로 X 검색 시도. 공식 X API는 비싸므로 **전체 플랫폼 대상 검색**이 관건.
  - **1차 404 → 2차 실패 → 트위터 CLI 업그레이드 → 3차 체인 3단계에서 Open CLI(크롬 확장) 백엔드**로 전환 — 이게 **셀프 힐링**의 실제 동작. (중간에 확장 인증이 필요하면 프롬프트로 사실을 알려주면 된다.)
  - Open CLI 확장을 쓰므로 **브라우저를 계속 열어둔 상태 유지** 필요. 6개 계정 대상으로 트윗·**댓글(리플라이) 반응**까지 수집.
- **핵심 인용**
- **내 질문**
- 404→CLI→크롬확장으로 3단 폴백하는 게 우리 자막 경로(MCP→fetch→네이티브 패널→Glasp 확장)와 판박이 — "여러 통로를 들고 있다"가 핵심.

## 6. X 반응 분석 & 유튜브 자막 요약 · [8:24](https://youtu.be/WL_qu7l3fgQ?t=504)
- **3줄 요약**
  - X 반응 정리: 열광("추상화의 다음 단계", "Loop Engineering은 시스템 설계 스킬") vs 회의("비용·토큰 폭탄", "리브랜딩일 뿐", "사람 개입 필요") — 좋아요·조회수·키워드까지 정리.
  - 유튜브: 링크를 주면 **yt-dlp 백엔드로 자막 통째 추출**(영어 자막 8,838단어) → **핵심 3가지**로 요약. 몇십 분 영상을 처음부터 볼 필요 없음.
  - 예시 대상은 Anthropic 창업자 **다리오·다니엘라 아모데이** 밀착 다큐 번역 — 안전을 외치던 회사의 1조 달러 역설, **"1~5년 내 사무직 신입 절반 소멸"** 경고, AI 군비경쟁·펜타곤 충돌 등.
- **핵심 인용**
- **내 질문**
- "유튜브 자막 추출→핵심 요약"이 바로 우리 video2post가 하는 일 — agent-reach로 그 수집 단계를 자동화할 수 있을지 검토할 가치가 있다.

## 7. GitHub 레포 분석 · [10:24](https://youtu.be/WL_qu7l3fgQ?t=624)
- **3줄 요약**
  - GitHub 레포 주소를 주고 "뭐 하는 건지 + 최근 변경점 정리해줘" → agent-reach의 **gh CLI 백엔드**로 분석.
  - 예: **Pixel3D**(Tencent ARC 개발, 단일 이미지 → 고품질 3D 생성 모델) — 주요 기능·최근 추가·버그 수정·라이선스·커뮤니티 이슈를 정리.
  - 포인트: **스타 개수가 아니라** 코드가 어디까지 개발됐고 어느 분야에 쓰이는지 **실질 정보**를 본다.
- **핵심 인용**
- **내 질문**
- "스타 수 말고 실질"이라는 관점이 좋다 — 표면 지표가 아니라 실제 상태를 읽는 게 AI 리서치의 가치다.

## 8. 활용 예시 4가지 — 세상을 재료로 쓰기 · [11:10](https://youtu.be/WL_qu7l3fgQ?t=670)
- **3줄 요약**
  - ① **에러 해결**: 에러 메시지를 레딧/GitHub 이슈에서 같은 사례 검색 → 해결책 정리("남이 먼저 밟은 지뢰를 대신 찾아옴").
  - ② **부실한 라이브러리 문서**: 레포의 최근 이슈·PR을 읽어 사용법 정리. ③ **영어 공식 문서**: 페이지를 읽고 중요 부분만 한국어 번역(웹페이지도 잘 읽음).
  - ④ **콘텐츠 기획**: "이 주제 요즘 X·유튜브에서 뭐가 회자되나" 트렌드 조사. **공통점 = 에이전트가 '세상을 재료로' 쓰기 시작**(작년치 지식만 우려먹지 않음).
- **핵심 인용**
- **내 질문**
- "세상을 재료로" = 최신성 확보. 우리 노트도 ASR 고유명사를 웹 검색으로 확정하는 것과 같은 결 — 외부 최신 정보로 내부를 보정.

## 9. 셀프 힐링 라우팅 & 마무리 · [12:34](https://youtu.be/WL_qu7l3fgQ?t=754)
- **3줄 요약**
  - 플랫폼은 자동 접근을 자주 막는다 — **오늘 되던 게 내일 막힐 수** 있다. 보통 도구는 거기서 포기하지만 agent-reach는 **여러 통로**를 들고 있어 조용히 다음 길로 갈아탄다.
  - 오늘 한 일은 결국 "책상 앞에만 앉아 있던 녀석에게 **밖에 나가 직접 보고 오라고 문 하나 달아준 것**".
  - 마무리: "에이전트에게 제일 먼저 뭘 시켜보고 싶은가?" 댓글 요청. 발표자는 "일단 내 채널 댓글부터 읽어오라 시켜보겠다(조금 무섭지만)".
- **핵심 인용**
- **내 질문**
- "오늘 되던 게 내일 막힌다"는 정확히 우리가 겪은 자막 API 차단(PO토큰) 상황 — 다경로 라우팅이 곧 견고함이다.

## TL;DR (5줄)

1. 클로드 코드는 기본적으로 인터넷에 못 나가 사람이 복붙 심부름을 하게 되는데, **agent-reach**가 이 벽을 뚫는다.
2. **파이썬 패키지 하나(`pip install agent-reach`)**로 X·유튜브·레딧·GitHub·웹 등 **14개+ 채널**을 API 키·결제 없이 읽고 검색.
3. **셀프 힐링 라우터**: 한 경로(404 등)가 막히면 트위터 CLI→Open CLI 크롬 확장으로 **자동 우회**.
4. 실제 시연: X 반응 수집, 유튜브 **자막 추출→핵심 3요약**, GitHub 레포 실질 분석(Pixel3D 등).
5. 활용: 에러 해결·라이브러리 문서·웹 번역·트렌드 조사 — 요지는 에이전트가 **'세상을 재료로'** 쓰게 만드는 것.
