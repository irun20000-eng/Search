# 클로드 x 카카오톡으로 나만의 AI 직원 만들기ㅣ커넥터, 아티팩트, Play MCP 실습 포함

> 한 줄 요약: PC가 꺼져 있어도 클라우드 서버에서 스스로 작동하는 클로드의 예약 작업(Scheduled Tasks)과 **플레이 MCP(Play MCP) 카카오톡 나채방**, **구글 캘린더 커넥터**를 연동하여, 매일 아침 출근길 개인 맞춤형 일정·주식·부동산 알림을 수신하고, 중요 일정을 **아티팩트(Artifacts) 시각 보고서**로 공유하며, 금요일 퇴근 전 **주간 업무 진척표를 자동 집계**하는 완전 자율형 AI 직원 구축 파이프라인을 제시한다.

## 1. 클로드 플랜별 핵심 차이와 3대 도구(커넥터·예약됨·아티팩트) 구조 · [02:17](https://youtu.be/lKBK0elPEtM?t=137)
- **3줄 요약**
  - 무료 플랜 대비 유료 프로 플랜의 결정적 차이는 **클라우드 백그라운드 예약 작업(Scheduled Tasks)** 지원 여부와 5배의 사용량이다.
  - 외부 도구와 소통하는 통로인 **커넥터(MCP)**, PC 종료 후에도 서버에서 도는 **예약됨**, 별도 웹 페이지로 공유되는 **아티팩트**가 3대 축이다.
  - 최신 고성능 모델을 활용해 복잡한 비즈니스 로직과 자동화 지침을 정밀하게 제어할 수 있다.
- **핵심 인용**: "클로드 자체적인 서버에서 진행이 되는 기능이기 때문에 여러분들께서이 예약된 기능을 사용하셔서 어떤 작업을 예약하셨을 때 이후에 PC가 꺼져 있어도 자동으로 돌아가서 진행이 되는 그런 기능이라고 생각해 주시면 될 것 같습니다"
- **내 팁**: PC를 종료한 야간이나 출근 전에도 알림을 수신하려면 로컬 스크립트 대신 클라우드 서버에서 독립 실행되는 클로드 유료 플랜의 예약됨(Scheduled Tasks) 기능을 기반으로 파이프라인을 설계해야 한다.

## 2. ★구글 캘린더 커넥터 연동과 태그 기반 일정 등록 지침 설계★ · [09:23](https://youtu.be/lKBK0elPEtM?t=563)
- **3줄 요약**
  - 클로드 채팅창의 커넥터 메뉴에서 **구글 캘린더를 원클릭 연동**하여 대화창 내에서 일정을 직접 생성·조회한다.
  - 단순 날짜 입력을 넘어 **업무 목적 명시, 기존 일정과의 시간 중복 자동 검증, 중요도별 색상 태그(빨간색 등)** 부여 지침을 구조화한다.
  - 미팅이 종료되었을 때 '완료' 상태 태그를 캘린더에 동기화 반영하도록 지침을 세팅하여 체계적인 이력 관리를 구현한다.
- **핵심 인용**: "구글 캘린더 연결돼 있으니까 구글 캘린더 활용한다는 내용도 나오죠 그래서 외부 미팅 등록했습니다 미리 그날 일정을 다 확인했고 오후 2시에서 3시 사이에 겹치는 일정이 없었습니다"
- **내 팁**: 일정 등록 지침 프롬프트에 '기존 일정과 시간 충돌 시 즉시 되묻고, 중요 미팅은 빨간색 태그로 표시하라'는 조건을 사전 지정해 두면 캘린더를 직접 확인하지 않고도 중복 등록 실수를 방지할 수 있다.

## 3. ★플레이 MCP(Play MCP) 카카오톡 나채방 연동과 출근길 자동 브리핑★ · [17:35](https://youtu.be/lKBK0elPEtM?t=1055)

  - 클로드 커넥터에 플레이 MCP 계정을 연결함으로써 클로드가 내 카카오톡 나에게 보내기 채팅방으로 메시지를 전송하는 권한을 획득한다.
  - **매일 오전 8시 예약 작업**을 등록해 오늘 진행할 일정과 이번 주 마감 업무를 정돈된 양식으로 카카오톡 브리핑을 수신한다.

## 4. 플레이 MCP 확장 도구: 주식 시세·부동산 실거래가 정기 알림 구축 · [24:10](https://youtu.be/lKBK0elPEtM?t=1450)

  - 장 시작 직후(오전 9시) 삼성전자·SK하이닉스 예상 체결가/호가 알림과 장 마감 후 급등주 및 시장 브리핑을 자동화한다.
  - 관심 등록한 아파트 단지의 신규 실거래가 체결 내역이나 목표 지역 신규 청약 공고 발생 시 카카오톡으로 즉시 알림을 받는다.

- **내 팁**: 관심 주식 종목이나 부동산 아파트 단지의 실거래가 알림을 예약할 때는 장 시작(오전 9시)과 장 마감(오후 3시 반) 등 트리거 시점을 명시하여 정기 브리핑 형태로 요청하는 것이 효율적이다.

## 5. 아티팩트(Artifacts) 기반 이번 주 중요 일정 시각화 보고서 자동화 · [29:10](https://youtu.be/lKBK0elPEtM?t=1750)
- **3줄 요약**
  - 캘린더에 축적된 일정 중 '중요' 태그 항목과 D-Day 마감 임박 건을 추출해 **인터랙티브 웹 페이지 형태의 아티팩트**로 시각화한다.
  - 텍스트 줄글 보고 대신 한눈에 파악 가능한 대시보드 링크를 생성하여 상사, 팀원, 외부 강사에게 깔끔하게 공유한다.
  - 대시보드 갱신 작업을 예약 작업으로 승인 등록해 두면 별도 요청 없이도 매주 최신 일정 현황이 자동 리프레시된다.
- **핵심 인용**: "아티팩트라는 기능이 여러분들이 오늘은 이런 일정을 확인하기 위한 용도로 사용을 하시지만 제 생각에는 저처럼 뭐 다른 여러 가지 필요에 따라서 충분히 공유하는 보고서 형태로 시각화해서 사용이 가능하신 거 그 부분도 한번 확인을 하시면 좋을 것 같습니다"
- **내 팁**: 아티팩트 보고서를 팀원이나 외부 협력사에 공유할 때는 대화창 전체를 공유할 필요 없이 우측 상단 아티팩트 개별 링크만 추출하여 전달하면 대화 전문을 노출하지 않고 시각 자료만 깔끔하게 전달할 수 있다.

## TL;DR (5줄)
1. **3대 자동화 인프라**: 클라우드 서버에서 독립 실행되는 예약됨(Scheduled Tasks), 도구 연동 커넥터(MCP), 시각 공유 아티팩트를 결합한다.
2. **캘린더 지침 고도화**: 구글 캘린더를 연결하고 일정 충돌 자동 검증과 중요도 색상 태그를 부여해 대화형 일정 등록을 표준화한다.
3. **카카오톡 출근길 브리핑**: 플레이 MCP 나채방을 연동하여 매일 오전 8시 당일 일정과 주간 마감 업무를 카카오톡으로 자동 수신한다.
4. **금융·부동산 확장 알림**: 주식 장 시작·마감 호가 및 지수 브리핑, 아파트 실거래가 체결 알림 등 생활 밀착형 도구를 추가 확장한다.
5. **보고서 및 주간 진척표**: 주간 중요 일정을 시각화 아티팩트로 공유하고 금요일 퇴근 전 완료율(%)이 집계된 누적 진척표를 자동 생성한다.
