# 클로드 코드로 인스타 자동화, 진짜 되나요? 됩니다! (카드뉴스 자동 발행)

> 한 줄 요약: 카드뉴스를 만드는 것에서 끝내지 않고 **인스타 자동 발행까지** 클로드 코드로. 준비물은 **클로드 프로($20/월)+인스타 계정**. 관문은 **① 계정을 프로페셔널+공개로 전환**(개인·비공개는 토큰 안 나옴, 페이스북 페이지는 불필요) **② 메타 개발자 콘솔에서 앱 생성+게시 권한(instagram_business_content_publish)+인스타그램 테스터 역할+한 번만 보이는 액세스 토큰** 발급(제일 귀찮지만 딱 한 번). 이후 **카드는 HTML로 짜서 캡처**(1080×1350, 일관·무료·HTML 몰라도 됨), 에러는 "복사해서 클로드에 붙여넣기"로 해결, **자동 발행은 공식 API라 도달 안 깎임**. 마지막에 **스킬 크리에이터로 전 과정을 스킬화** → 한 문장이면 제작+발행.

## 1. 개요 + 준비물 + 계정 전환(첫 관문) · [00:00](https://youtu.be/VLdlf8qPwdo?t=0)
- **3줄 요약**
  - 카드뉴스는 많이들 만들지만 대부분 손으로 올림 — 이 영상은 **올라가는 것까지**. 코딩은 한 줄도 안 침(메타 콘솔 클릭만 좀 귀찮음).
  - 준비물: **클로드 프로($20/월, 클로드 코드 포함)** + **인스타 계정**. (클로드 코드 설치·GitHub 연결·플러그인은 명령 한 줄씩이라 영상선 건너뜀, 문서로 제공.)
  - **첫 관문 = 계정**: 개인 계정은 자동 업로드 권한 자체가 안 나옴 → **프로페셔널(비즈니스/크리에이터)로 전환**(폰 설정, 5분, 무료, 팔로어·게시물 유지). 추가 조건: **공개 계정**이어야 토큰 발급. **페이스북 페이지는 불필요**.
- **핵심 인용**: "인스타 개인 계정으로는 자동 업로드가 안 열려요 … 프로페셔널 계정으로 바꿔야 열려요."
- **내 팁**: 카드뉴스 선택 이유(저장률 릴스 3배)는 콘텐츠 전략 근거 — 주제 문장만 바꾸면 블로그 요약·신메뉴 홍보로 재활용.

## 2. ★메타 개발자 콘솔 — 앱 생성 5칸★ · [01:46](https://youtu.be/VLdlf8qPwdo?t=106)
- **3줄 요약**
  - 손이 제일 많이 가는 곳(내 계정에 내가 올릴 권한을 발급, 심사·승인 없음). 앱 만들기 → 5칸: **앱 상세정보·이용 사례·비즈니스·요구사항·개요**.
  - **이용 사례**(첫 함정): 추천 6개에 인스타그램이 없음 → 왼쪽 필터 **'콘텐츠 관리'** → **'Instagram에서 메시지 및 콘텐츠 관리'** 선택.
  - **비즈니스**: "아직 비즈니스 포트폴리오 연결하고 싶지 않음"(페이지 불필요 확인). **요구사항**: "확인된 요구사항 없음"(심사·서류 X). **개요→만들기**(비밀번호 재확인).
- **핵심 인용**: "지금 하는 건 내 계정에 내가 올릴 권한을 나한테 주는 작업이에요. 심사도 승인도 없습니다."
- **내 질문**: 이 10여 번 클릭이 유일한 병목이자 '딱 한 번'인 부분 — 자동화의 초기 세팅 비용을 어디까지 감수하느냐의 전형 아닐까?

## 3. ★게시 권한 + 인스타그램 테스터 + 액세스 토큰★ · [03:36](https://youtu.be/VLdlf8qPwdo?t=216)
- **3줄 요약**
  - **게시 권한(핵심)**: 1번 '필수 권한 추가'의 기본 목록엔 **사진 게시 권한이 없음** → 왼쪽 '권한 및 기능'에서 **`instagram_business_content_publish`**를 찾아 직접 추가(→'테스트 준비 완료'). 빼먹으면 발행에서 권한 에러.
  - **인스타그램 테스터 역할**: 2번 토큰 생성에서 로그인해도 "개발자 역할 권한 부족"이 정상 → 왼쪽 **역할→역할→더 보기→인스타그램 테스터**로 내 아이디 추가(자동완성서 계정 클릭 필수). 인스타 설정(앱 및 웹사이트→테스터 초대)에서 **수락**.
  - **액세스 토큰**: 2번 토큰 생성→'이해합니다' 체크→복사. **토큰은 한 번만 표시**(닫으면 재발급) → 복사 즉시 클로드에 "이 문자열 저장해 줘". **60일마다 갱신**(그것도 클로드에 위임).
- **핵심 인용**: "이 토큰은 한 번만 보여 줍니다. 복사하자마자 클로드 코드에 이 문자열 저장해 줘 하고 붙여 놓으면 됩니다."
- **내 팁**: 반복 규칙 — **에러 문구를 그대로 복사해 클로드에 붙여넣기**(권한 저장 실패·부품 미설치 등 대부분 이걸로 해결). 자격증명 취급은 사용자가 직접(토큰 복사)해야 하는 영역.

## 4. 카드 제작 — HTML로 짜서 캡처 · [05:26](https://youtu.be/VLdlf8qPwdo?t=326)
- **3줄 요약**
  - 지시는 한글 한 문장 + "웹페이지로 만들어 화면 찍어줘": *"AI 초보 팁 주제로 카드뉴스 만들어 줘. 비율 4:5로"* (주제·장수·비율만, 폰트·색 지정 X). **4:5**가 인스타 세로 최대.
  - 클로드가 **표지·본문·안내 카드를 HTML로 짜고 캡처 도구로 한 장씩 1080×1350**로 뽑음(캡처도 클로드가). 이 방식의 3이유: **①숫자로 정한 크기·색·줄간격 → 열 장이 동일 ②이미지 비용 0원 ③HTML 몰라도 됨**.
  - **첫 실행은 대개 에러**(캡처용 브라우저 부품 미설치) → 에러 복사→붙여넣기로 클로드가 설치 후 재실행. **사람 눈 검수 필수**(클로드는 자기 결과물을 안 열어봄 → 제목 잘림 등) → "2번 카드 줄바꿈 고쳐줘"로 수정. 제작+검수 6분 9초.
- **핵심 인용**: "클로드는 자기가 만든 결과물을 스스로 열어보지 않거든요 … 사람 눈이 한 번은 들어가야 해요."
- **내 질문**: 'HTML→스크린샷 캡처'로 일관·무료 이미지를 뽑는 건 앞 영상(데키랩 모션그래픽 Remotion, 오빠두 웹페이지)의 '코드로 시각물 생성'과 같은 계열 아닐까?

## 5. 자동 발행 + 스킬화 + 시간/주의 · [08:29](https://youtu.be/VLdlf8qPwdo?t=509)
- **3줄 요약**
  - **발행**: "방금 만든 카드 인스타에 올려줘" → 9장을 **무료 GitHub 공개 저장소에 먼저 업로드**(인스타는 공개 URL 이미지만 받음, 최초 1회 연결) → 묶어서 발행 요청(토큰 사용). **공식 API 발행은 손 발행과 동일 대우, 도달 안 깎임**(제재 대상은 자동 좋아요·댓글·팔로우).
  - **주의**: 하루 100건 상한(카드 세트=1건), **캡션·해시태그 매번 동일 복붙은 스팸** → "캡션도 매번 새로" 함께 지시.
  - **스킬화**: **스킬 크리에이터(Anthropic 공식 플러그인)** 설치 → "지금 한 작업 스킬로 저장" → 이후 *"이번 주 카페 신메뉴로 카드뉴스 만들어 올려줘"* 한 문장이면 전 과정 재실행(발행은 승인 버튼으로). 사람 손 3곳: 주제 정하기·카드 확인·최초 토큰 세팅. **첫 세팅 1~2시간, 이후 10분 안쪽**.
- **핵심 인용**: "공식 창고로 글을 올리는 건 손으로 올린 것과 똑같이 대우받아요. 도달도 안 깎입니다."
- **내 팁**: '전 과정을 스킬로 묶기'는 앞 영상 다수(데키랩 모션·힉스필드·클로드 디자인 taste)와 같은 결론 — 검증된 워크플로우를 스킬로 굳혀 한 문장화.
