# 매번 시트 복사하지 마세요, 버튼 한 번이면 끝납니다 | 엑셀 템플릿 자동화

> 한 줄 요약: 매번 기존 시트를 수작업으로 복사하거나 지우던 비효율을 해결하기 위해, **엑셀 이름 상자**와 **조건부 서식**을 활용한 기본 초기화 테크닉부터 웹 기반 **리본 메뉴 빌더**로 노코드 메뉴를 구성하고 **VBA 시트 복사 매크로**를 연결한 뒤, 모든 통합 문서에서 작동하는 **엑셀 추가 기능(.xlam)**으로 등록하고 **외부 공유 보안 차단 해제**까지 완벽히 마스터하는 실무 템플릿 자동화 파이프라인을 제시한다.

## 1. 엑셀 기본 기능을 활용한 입력 범위 초기화와 조건부 서식 강조 · [00:00](https://youtu.be/e1KYWoDrmBM?t=0)
- **3줄 요약**
  - 컨트롤(Ctrl) 키로 입력 범위를 다중 선택한 뒤 **이름 상자**에 이름을 지정해 두면 클릭 한 번으로 입력값만 일괄 삭제할 수 있다.
  - 병합된 셀이 포함된 경우 경고창 발생 후 재삭제해야 하는 한계와 인보이스 번호 등 필수 데이터 누락 위험이 존재한다.
  - **조건부 서식의 빈 셀 강조 규칙**을 적용해 초기화 시 필수 입력 칸을 노란색으로 강조하고 값 입력 시 채우기가 사라지도록 자동화한다.
- **핵심 인용**: "이런 식으로 값을 초기화했을 때 반드시 입력해야 되는 셀은 노란색으로 강조가 되고요 값을 입력하면 이렇게 채우기가 사라지는 자동화 서식을 만들 수 있습니다"
- **내 팁**: 거래처명, 날짜 등 누락 위험이 큰 셀은 조건부 서식에서 셀 값 '빈 셀' 규칙을 지정해 배경색을 채워두면 입력 누락 실수를 사전에 차단할 수 있다.

## 3. 콜백 매크로 설정과 VBA 시트 복사 코드 연동 · [06:21](https://youtu.be/e1KYWoDrmBM?t=381)
- **3줄 요약**
  - 각 버튼 클릭 시 실행될 고유한 **콜백(Callback) 매크로 이름**을 지정하여 충돌 없이 매핑되도록 설정한다.
  - 리본 빌더에서 자동 생성된 XML/VBA 코드를 복사하고 엑셀 파일 내에 템플릿 시트들을 드래그하여 통합한다.
  - **Alt+F11 단축키**로 매크로 편집기를 열어 표준 모듈을 삽입하고 시트 복사 매크로에 복사할 원본 시트명을 큰따옴표로 지정한다.
- **핵심 인용**: "여기에서 주의 사항은 여기 있는 콜백 매크로는 고유값이기 때문에 겹치지 않도록 만드는 것만 주의하시면 되겠습니다"
- **내 팁**: 시트 복사 명령 뒤에 지정하는 시트 이름은 실제 통합 문서에 존재하는 템플릿 시트 탭 이름과 띄어쓰기까지 100% 일치해야 런타임 오류가 발생하지 않는다.

## 4. ★엑셀 추가 기능(.xlam) 저장 및 글로벌 메뉴 등록★ · [10:11](https://youtu.be/e1KYWoDrmBM?t=611)
- **3줄 요약**
  - 완성된 통합 문서를 일반 파일이 아닌 **엑셀 추가 기능(.xlam)** 형식으로 변환하여 저장한다.
  - 추가 기능 기본 저장 경로에 파일을 배치하면 엑셀 옵션의 추가 기능 관리자에서 손쉽게 체크 등록할 수 있다.
  - 등록이 완료되면 특정 파일에 국한되지 않고 **PC에서 열리는 모든 신규·기존 엑셀 파일**에 '내 템플릿' 메뉴가 나타나며, 추가 기능 체크를 해제하기 전까지 유지된다.
- **핵심 인용**: "이렇게 만드시면 이제 모든 엑셀에이 추가 기능이 적용되기 때문에 이런 식으로 모든 파일에서 내 템플릿 메뉴를 편리하게 사용할 수 있습니다"
- **내 팁**: 다른 팀원에게 추가 기능 파일을 배포할 때는 엑셀 옵션 > 추가 기능 > 찾아보기 창으로 파일을 직접 드래그해 넣도록 안내하면 경로 설정 오류를 줄일 수 있다.

## 5. 외부 배포 시 윈도우 매크로 차단 해제 및 메뉴 유지보수 · [12:38](https://youtu.be/e1KYWoDrmBM?t=758)
- **3줄 요약**
  - 인터넷이나 메일로 전달받은 매크로 파일은 윈도우 보안 정책에 의해 기본적으로 실행이 차단(MOTW)된다.
  - 배포받은 .xlam 파일 우클릭 후 속성 메뉴로 진입해 보안 항목의 **차단 해제(Unblock)** 체크박스를 활성화해야 정상 실행된다.
  - 추후 서식이 늘어나 버튼을 추가할 때는 리본 메뉴 빌더의 **다른 파일 불러오기** 기능으로 기존 설정을 불러와 손쉽게 유지보수한다.
- **핵심 인용**: "외부로 공유하실 때에는요 받은 파일을 우클릭하신 다음에 속성으로 이동하시면 오른쪽 밑에 차단 해제라는 옵션이 표시됩니다이 옵션을 클릭해서 매크로 차단을 푸신 다음에 등록하도록 안내하는 것만 주의해 주시고요"
- **내 질문**: 윈도우 그룹 정책(GPO)으로 인해 로컬 파일 속성의 차단 해제 체크박스가 비활성화되어 있는 사내 엔터프라이즈 환경에서는 신뢰할 수 있는 위치(Trusted Location) 경로 등록만으로 우회가 가능한가?

## TL;DR (5줄)
1. **기본 초기화와 누락 방지**: Ctrl 다중 선택과 이름 상자로 초기화 범위를 지정하고 조건부 서식 빈 셀 강조로 필수값 누락을 방지한다.
2. **노코드 리본 메뉴 구축**: 오빠두엑셀 리본 메뉴 빌더를 활용해 코딩 없이 나만의 탭, 그룹, 버튼, 맞춤 아이콘을 시각적으로 디자인한다.
3. **고유 콜백 및 VBA 연동**: 버튼별 고유 콜백 매크로를 생성하고 Alt+F11 모듈에 시트 복사 함수를 넣어 템플릿 시트명을 매핑한다.
4. **글로벌 추가 기능 등록**: .xlam 형식으로 저장한 뒤 엑셀 추가 기능에 등록하여 모든 엑셀 문서에서 버튼 클릭 한 번으로 시트를 불러온다.
5. **보안 해제 및 사후 관리**: 외부 공유 시 파일 속성에서 윈도우 매크로 차단을 해제하며 리본 빌더의 파일 불러오기로 메뉴를 지속 업데이트한다.
