# 2026년 클로드 하나로 끝내는, AI 영상 완전 자동화 올인원 강의 l 47분 연속 재생

## 1. ★클로드와 픽스필드 MCP 연동 및 권한 설정★ · [00:00](https://youtu.be/8XVVzAgn3g8?t=0)
- **3줄 요약**
  - 클로드와 영상 생성 플랫폼 픽스필드를 **MCP(Model Context Protocol)** 프로토콜로 직접 연결한다.
  - 외부 도구 조작 권한을 부여하여 복사·붙여넣기 없이 **단일 채팅창**에서 영상 생성을 제어한다.
  - 보안 성향에 따라 도구 권한을 승인 필요 또는 **항상 허용**으로 맞춤 설정한다.
- **핵심 인용**: "이제는 AI 툴 안에서 클릭 몇 번만 하면 영상을 자동으로 생성을 해 줍니다."
- **내 팁**: 픽스필드 MCP 설정 시 읽기 및 쓰기 도구 권한을 항상 허용으로 지정하여 불필요한 승인 팝업을 줄인다.

## 2. ★클로드 스킬 업로드와 전 단계 자동 기획 팩토리★ · [05:03](https://youtu.be/8XVVzAgn3g8?t=303)
- **3줄 요약**
  - 영상 제작 단계별 규칙이 정의된 **콘텐츠 팩토리 스킬**을 클로드에 업로드하여 장착한다.
  - 이미지 한 장 입력만으로 시장 트렌드 분석과 **50편 분량의 추천 콘텐츠 캘린더**를 자동 기획한다.
  - 영화 감독처럼 페르소나, 장면 프롬프트, 캡션이 담긴 **마스터 시트**를 체계적으로 도출한다.
- **핵심 인용**: "같은 클로드를 쓰더라도 스킬이 있냐 없냐에 따라서 결과물이 정말 많이 차이가 납니다."
- **내 팁**: 초기 기획 단계에서 팩토리 스킬을 구동해 플랫폼별 최적 후킹 전략과 콘텐츠 캘린더를 일괄 생성한다.

## 3. 일관성 유지를 위한 캐릭터 시트 제작과 영상 일괄 생성 · [21:17](https://youtu.be/8XVVzAgn3g8?t=1277)
- **3줄 요약**
  - 인물 일관성을 위해 정면, 측면, 후면 포즈가 담긴 **캐릭터 시트(Character Sheet)**를 사전 제작한다.
  - 제작된 시트를 픽스필드에 등록하여 여러 장면에서도 **동일한 페르소나와 외모**를 유지한다.
  - 클릭 몇 번으로 7개 이상의 드라마 쇼츠 컷을 **배치 단위로 자동 렌더링**한다.
- **핵심 인용**: "위 인물에 대한 캐릭터 시트를 제작해 줘라고 하면 훨씬 더 이미지나 영상 일관성이 유지가 됩니다."
- **내 질문**: 다양한 의상이나 조명 변화가 큰 야외 장면에서도 캐릭터 시트의 얼굴 일관성이 완벽히 유지되는지 궁금하다.

  - 머리에 불이 붙는 특수 효과처럼 특정 부위의 **빛 반사와 마스킹**을 자연스럽게 자동 합성한다.

- **내 팁**: 실사 합성 시 프롬프트에 유지할 요소(표정, 입 모양)와 변경할 요소(배경, 특수 효과)를 분리 명시한다.

## 5. 텍스트 프롬프트 기반 4K 시네마틱 애니메이션 및 다큐 제작 · [36:28](https://youtu.be/8XVVzAgn3g8?t=2188)

- **내 팁**: 고화질 시네마틱 영상 제작 시 클로드 스킬을 활용하여 초 단위 샷 브레이크다운 프롬프트를 먼저 생성한다.

1. **MCP 연결**: 픽스필드 원격 MCP를 클로드에 연동하여 단일 채팅 인터페이스에서 영상 생성을 조작한다.
2. **스킬 기반 기획**: 콘텐츠 팩토리 스킬을 활용해 시장 트렌드 조사, 후킹 설계, 50편 기획 캘린더를 자동화한다.
3. **캐릭터 시트**: 정면·측면 캐릭터 시트를 사전 구축하여 다수 컷에서도 인물 얼굴 일관성을 완벽히 유지한다.
4. **시댄스 특수 합성**: 시댄스 2.0 4K로 실사 촬영본의 배경 교체, 부분 특수 효과, 가상 오브젝트 합성을 처리한다.
5. **무인 파이프라인**: 텍스트 프롬프트 기반으로 4K 애니메이션, 다큐, 상업 광고 비디오까지 무인 일괄 생산한다.
