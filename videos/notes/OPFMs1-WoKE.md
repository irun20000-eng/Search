# 클로드 영상 자동화 3탄 — 모션그래픽 꿀팁 (Remotion 활용)

> 한 줄 요약: 애프터이펙트 같은 전문 툴 없이 **클로드 코드 + Remotion(리모션)**으로 모션그래픽을 프롬프트만으로 만든다. 핵심은 **① 만들 영상을 최대한 구체적으로 서술**(어떤 화면이 어떤 순서·느낌으로) **② 병렬 에이전트로 여러 영상 동시 생성**(에이전트 12개가 각자 제작 → 빠름) **③ 초안 먼저 뽑고 말로 다듬기**(로고·효과음·배경음·속도 추가) **④ 마음에 든 방식은 스킬로 저장**해 재사용. 차트레이스·웨이브폼(음악 파형)·여행경로 등 실사용 퀄리티.

## 1. 왜 모션그래픽 + 전문 툴 없이 클로드로 · [00:01](https://youtu.be/OPFMs1-WoKE?t=1)
- **3줄 요약**
  - 모션그래픽은 영상 퀄리티의 필수 요소(심심한 구간 채우고 긴 설명을 한 장면으로) — 하지만 애프터이펙트 등 전문 툴은 진입장벽이 높음.
  - 오늘은 전문 툴 없이 **클로드에서 프롬프트만으로** 모션그래픽 제작(영상에 나온 예시 전부 프롬프트로 제작).
  - 처음이 막막하지 않게 **바로 쓰는 프롬프트 12종**을 미리 준비(후반에 배포 방법 안내).
- **핵심 인용**: "전문 툴을 따로 사용하지 않고 클로드에서 프롬프트만으로 이런 영상들을 만들 수 있는 방법."
- **내 팁**: 3탄 = 앞선 편집 자동화·리모션 소개편의 후속. "전문 툴 대체"는 앞 영상들(블로그·웹사이트 자동화)의 '외주/전문성 대체'와 같은 결.

## 2. 세팅 — Remotion 설치 + 프로젝트 폴더 · [01:15](https://youtu.be/OPFMs1-WoKE?t=75)
- **3줄 요약**
  - **Remotion** 세팅(Node.js 설치 전제)은 별도 영상 참고, 5분이면 완료. 클로드 코드는 데스크탑 앱/VS Code/안티그래비티 등 편한 환경에서.
  - 프로젝트 폴더 하나(예: '모션그래픽') 만들고 터미널에서 리모션 설치 → 클로드 새 세션 열면 제작 준비 완료.
- **핵심 인용**: "노드 JS와 리모션이 설치되어 있다는 가정으로 계속 이어가 볼 건데요."
- **내 질문**: 프로젝트 폴더+도구 설치를 전제로 두는 건 앞 영상(신영선·잭피디)의 '오픈소스 클론 후 세팅'과 동일한 온보딩 구조 아닐까?

## 3. ★핵심 원칙 — 구체적 서술 + 병렬 에이전트★ · [02:39](https://youtu.be/OPFMs1-WoKE?t=159)
- **3줄 요약**
  - 가장 중요한 포인트: **만들 영상을 프롬프트에 최대한 자세히**(어떤 화면이 어떤 순서로, 어떤 느낌으로) → 구체적일수록 결과↑.
  - 막막함 해소용 **대표 모션그래픽 유형 12종 프롬프트**를 public 폴더에 넣고 바로 생성 가능(마음에 드는 것만 골라 써도 됨).
  - **병렬 제작**: "별도 에이전트로 병렬로 만들어 줘" → 에이전트 하나가 12개를 순차 제작하는 대신 **에이전트 12개가 동시에** 각 프롬프트를 처리 → 훨씬 빠름.
- **핵심 인용**: "클로드 에이전트가 총 12개 생성되면서 각자 이 프롬프트에 있는 내용들을 확인하고 영상들을 만들어 주기 때문에 훨씬 더 빠르게."
- **내 팁**: 병렬 에이전트 팬아웃은 앞 영상(그래프 엔지니어링의 '분배→일꾼→병합')과 정확히 같은 패턴 — 대량 작업을 동시에 펼쳐 시간 단축.

## 4. 렌더링 + 실전 예시(차트레이스·로고·효과음) · [04:46](https://youtu.be/OPFMs1-WoKE?t=286)
- **3줄 요약**
  - Remotion 스튜디오에서 원하는 영상의 웨이브 버튼→**Render Video**로 즉시 렌더(또는 클로드에게 "영상 파일로 렌더링해 줘").
  - **차트레이스**(회사별 AI 모델 벤치마킹 순위 업치락뒤치락) 예시 — 실제 리서치 기반 고퀄 결과. 글씨체·배경음·효과음·이미지 추가로 완성도 향상.
  - public 폴더에 **기업 로고 이미지 + 효과음(두둥)**을 넣고 "로고 추가·마지막에 효과음 나오게 수정" → 반영됨.
- **핵심 인용**: "복잡한 툴을 사용할 필요 없이 클로드에게 자연어로 내가 원하는 방식대로 만들어 달라고만 요청하면."
- **내 질문**: 자료(로고·효과음)를 폴더에 넣고 참조시키는 방식은 앞 영상(신영선 knowledge 폴더, 힉스필드 엘리먼트 등록)의 '재료 자산화'와 동일 아닐까?

## 5. 웨이브폼·여행경로 + 초안→다듬기→스킬화 · [08:21](https://youtu.be/OPFMs1-WoKE?t=501)
- **3줄 요약**
  - **웨이브폼(음악 파형)**: 배경 이미지 + 팝뮤직 MP3 + 길이 30초 지정 → 음악에 맞춰 스펙트럼이 움직이는 영상(플레이리스트 채널에 유용).
  - **여행경로**: 세계지도 + 도시 10여 개 + 첨부한 비행기 캐릭터 + BGM + "비행 속도 너무 빠르지 않게" → 다큐 느낌 경로 모션그래픽.
  - **워크플로우 원칙**: 한 번에 완성하려 말고 **초안 먼저 → 마음에 안 드는 부분 말로 다듬기 → 원하는 결과 나오면 스킬로 저장/파일로 분리**해 재사용.
- **핵심 인용**: "일단 초안을 뽑아 보신 다음에 마음에 안 드는 부분을 하나씩 말로 다듬어 가고 … 해당 방식을 스킬로 저장."
- **내 팁**: '초안→반복 다듬기→스킬화'는 이 프로젝트의 품질 루프(build→review→fix→반복)와 동일. 검증된 절차를 스킬로 굳히는 건 앞 영상 다수(힉스필드·ralph-loop)의 공통 결론.

## TL;DR (5줄)

1. **가치**: 애프터이펙트 없이 **클로드 코드 + Remotion**으로 모션그래픽을 프롬프트만으로 — 전문 툴/시간을 AI 자연어로 대체.
2. **세팅**: Node.js+Remotion 설치(5분), 프로젝트 폴더에 리모션 설치 후 클로드 새 세션.
3. **원칙(★)**: ①만들 영상을 **구체적으로 서술** ②**병렬 에이전트**로 여러 영상 동시 생성(12개 프롬프트 준비).
4. **다듬기**: 렌더는 스튜디오 버튼/자연어. 차트레이스·웨이브폼·여행경로 등 초안 후 **로고·효과음·배경음·속도**를 말로 추가.
5. **워크플로우(★)**: 한 번에 완성 X → **초안→말로 다듬기→스킬/파일로 저장해 재사용**. 프롬프트 12종은 데키랩 오픈채팅서 배포.
