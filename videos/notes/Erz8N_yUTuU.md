# 아직도 직접 하세요? AI 초보도 쓰는 Aside 자동화

> 한 줄 요약: 복잡한 API나 MCP 코딩 설정 없이 크롬 브라우저의 로그인 세션과 비밀번호를 그대로 승계하는 **AI 브라우저 A사이드(Aside)**의 설치 절차부터, **기존 ChatGPT·Claude 유료 구독 연동**, 단축키 기반 **미니 팝업(Mini Popup)** 세팅, 로컬 폴더를 연동해 파일과 문서를 자율 정리하는 **3단계 권한 제어(Read-only/Guard/Full Access)** 및 파이널 컨펌 안전장치, 그리고 **반복 웹 업무를 자동화하는 루틴(Routine)** 구축법까지 초보자 맞춤형 실무 가이드를 제시한다.

## 1. A사이드(Aside) 도입 배경과 설치 전 기존 브라우저 세션 정리 · [00:00](https://youtu.be/Erz8N_yUTuU?t=0)
- **3줄 요약**
  - 컴퓨터와 인터넷 환경에서 사람이 반복 수행하던 번거로운 웹 클릭·검색 작업을 대신 처리해 주는 **AI 브라우저 A사이드**를 소개한다.
  - 설치 중 데이터 마이그레이션 충돌이나 팝업 차단 오류를 방지하기 위해 **작업 관리자에서 크롬·엣지 프로세스를 완전 종료**해야 한다.
  - 가입 시 구글이나 애플 소셜 계정을 선택하고 안내 링크를 통해 팝업 허용 후 프로그램을 정상 다운로드한다.
- **핵심 인용**: "작업 관리자 눌러 주신 다음에 작업 관리자에서 저희 마지막으로 엣지 여러분들이 사용하시는 거 꺼 주시면은 되겠습니다"
- **내 팁**: A사이드 설치 중 브라우저 데이터 가져오기 오류가 발생하지 않도록 작업 관리자에서 기존 크롬이나 엣지 프로세스를 완전히 종료하고 실행해야 세션 충돌을 방지할 수 있다.

## 2. ★크롬 데이터 임포트와 로컬 패스워드 매니저 보안 설정★ · [02:43](https://youtu.be/Erz8N_yUTuU?t=163)
- **3줄 요약**
  - 기존 크롬의 쿠키, 북마크, 저장된 비밀번호를 **택배 업체처럼 A사이드로 일괄 마이그레이션**하여 별도 로그인 세팅을 생략한다.
  - 개발자용 API나 MCP 설정 없이도 노션, 피그마, 구글 시트 등 웹 서비스가 기본 내장 스킬로 즉시 연동된다.
  - 자체 패스워드 매니저를 선택하고 **윈도우 헬로(생체인식) 서명과 복구용 마스터 키**를 저장하여 비밀번호를 직접 입력하지 않고 자동 로그인을 위임한다.
- **핵심 인용**: "택배 업체가 직접 물건을 만들지는 않지만 얘네를 가져다 주잖아요 사이드는 그런 역할입니다 크롬에 이미 있는 비밀 번호를 가져오는 역할이라고만 생각해 주시면 되겠습니다"
- **내 팁**: 브라우저 마이그레이션 시 기존 크롬의 패스워드 매니저를 연동하고 윈도우 헬로 생체인식을 활성화해 두면 비밀번호를 외울 필요 없이 안전하게 자동 로그인을 위임할 수 있다.

## 3. UI 테마(샌프란시스코·뉴욕) 및 상시 호출 미니 팝업 설정 · [05:20](https://youtu.be/Erz8N_yUTuU?t=320)
- **3줄 요약**
  - 상단 가로 탭 방식인 **샌프란시스코**와 왼쪽 세로 사이드바 방식인 **뉴욕** 스타일 중 취향에 맞춰 레이아웃을 선택한다.
  - 단축키 `Ctrl+Space`를 누르면 화면 어디서든 AI 질의응답 창이 즉시 열리는 **미니 팝업(Mini Popup)** 기능을 상시 활성화한다.
  - 윈도우 환경에 익숙한 사용자는 탭 영역 우클릭을 통해 가로 탭 보기로 손쉽게 전환할 수 있다.
- **핵심 인용**: "컨트롤 스페이스를 눌러 주시면 언제 어디서든이 A드가 나와 가지고 질문을 받을 수가라는 겁니다 그래서 요거까지 추가를 해 볼게요"
- **내 팁**: 문서 작성이나 영상 시청 중 즉각적인 질의가 필요하다면 단축키 `Ctrl+Space`로 팝업을 띄우거나 `Ctrl+2`로 사이드바 탭을 열어 작업 흐름을 끊지 않고 질문할 수 있다.

## 4. 외부 모델(ChatGPT·Claude) 연동과 내장 스킬 생태계 · [07:00](https://youtu.be/Erz8N_yUTuU?t=420)
- **3줄 요약**
  - A사이드 자체 유료 플랜을 결제하지 않아도 **기존 보유한 ChatGPT나 Claude 계정을 연결**하여 비용 부담을 없앤다.
  - 기본 대화 모델은 가벼운 일상용 모델로 지정하고 이미지 생성 모델은 최상위 품질 모델로 설정한다.
  - 크롬 탭 탐색, 구글 독스, 시트, 노션 조작 스킬이 사전 내장되어 있어 추가 확장 프로그램 설치 없이 복합 업무를 처리한다.
- **핵심 인용**: "어 A 사이드를 굳이 결제하지 않으셔도 클로드를 연결해서 사용하실 수가라는 건데요 근데 여기에서 제가 복수의 모델을 사용하고 싶어도 그게 불가능하더라고요"
- **내 팁**: A사이드 전용 유료 플랜을 추가 결제하지 말고 설정의 프로바이더 메뉴에서 이미 보유 중인 ChatGPT나 Claude 계정을 직접 연결하면 추가 비용 없이 브라우저 에이전트를 가동할 수 있다.

## 5. ★로컬 프로젝트 폴더 연결과 3단계 권한 제어(Read-only/Guard/Full Access)★ · [09:54](https://youtu.be/Erz8N_yUTuU?t=594)
- **3줄 요약**
  - PC 내 실제 폴더를 **프로젝트로 마운트**하여 내부 파일 요약, 텍스트 분석, 구조 정리 작업을 대화형으로 지시한다.
  - 파일 접근 모드는 **Read-only(읽기 전용), Guard(매번 질문), Full Access(완전 자율 실행)** 3단계로 엄격히 구분된다.
  - Full Access 모드에서도 파일 삭제 등 중대 작업 전 **파이널 컨펌(Final Confirm)**을 거치며, 폴더 간 이동 시에는 최상위 부모 폴더를 등록해야 한다.
- **핵심 인용**: "가장 추천하는데요 풀 엑세스는 뭐냐 내가 맘대로 만들게라는 겁니다 삭제든 뭐든 다 할게라는 건데 어 이거 하면 제가 뭐 실수를 지우지 않을까요 막 지멋대로 컴퓨터 삭제하지 않을까요 이런 얘기 많이 하시는데 여기에서 A사이드의 좋은 점 파이널 컨펌인입니다"
- **내 팁**: 두 개 이상의 로컬 폴더 간에 파일을 정리·이동시키는 작업을 시킬 때는 하위 폴더들을 각각 등록하지 말고 이들을 모두 포함하는 최상위 부모 폴더를 프로젝트로 한 번에 등록해야 한다.

## 6. 반복 루틴(Routine) 자동화 및 실습 자료 안내 (홍보 구간 — 학습 내용과 분리) · [12:41](https://youtu.be/Erz8N_yUTuU?t=761)
- **3줄 요약**
  - 매일·매주 반복되는 웹 리서치나 데이터 취합 업무를 **루틴(Routine)**으로 등록해 단일 클릭으로 자동 반복 실행한다.
  - 사용자가 작업 방법을 몰라도 대화 이력에서 반복 패턴을 AI가 감지해 **루틴으로 역추천**해 주는 기능을 제공한다(무료 3개 지원).
  - 영상에서 다룬 모델 연동, 권한 세팅 체크리스트 및 실습 자료를 댓글 참여자에게 무료 배포하는 채널 이벤트를 안내한다.
- **핵심 인용**: "아래에 있는 내가 반복하는 일을 찾아 가지고 루틴을 만들어 줘라는 버튼이 있습니다 요거 눌러 가지고 루틴을 얘한테 찾아 달라고 요청하는 기능도 있으니까 요거 한번 참고해 주시면 좋을 것 같고요"
- **내 질문**: A사이드의 백그라운드 루틴이 무료 3개 제한을 초과하거나 복잡한 멀티스텝 웹 스크래핑을 수행할 때, 브라우저가 꺼진 상태에서도 로컬 스케줄러(cron 또는 Windows Task Scheduler)와 결합하여 무중단 자동화를 구현할 수 있는 방법은 무엇인가?

## TL;DR (5줄)
1. **간편한 마이그레이션**: 크롬의 쿠키와 북마크를 즉시 가져오며 작업 관리자에서 기존 브라우저를 종료해 충돌 없이 세팅한다.
2. **생체인증 패스워드 매니저**: 브라우저 자체 매니저와 윈도우 헬로 생체인식으로 비밀번호를 직접 입력하지 않는 자동 로그인을 지원한다.
3. **직관적 탭과 미니 팝업**: 샌프란시스코·뉴욕 UI를 전환할 수 있으며 Ctrl+Space 단축키로 작업 중 어디서나 미니 팝업을 호출한다.
4. **기존 구독 모델 재활용**: A사이드 추가 결제 없이 기존 ChatGPT나 Claude 유료 계정을 연동하고 내장 스킬로 웹앱을 조작한다.
5. **안전한 로컬 파일 관리**: 3단계 권한과 파이널 컨펌으로 로컬 폴더를 안전하게 자동 정리하고 반복 업무를 3개 루틴으로 등록한다.
