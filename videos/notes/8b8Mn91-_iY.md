# 클로드 코드로 구글 Flow 돌려서 공학 쇼츠 만들었습니다 (스킬 무료 배포)

> 한 줄 요약: 고가의 GPU나 유료 API 비용 없이 **구글 Flow**의 일일 50 무료 크레딧 한도 내에서 **이미지 12장(0크레딧)**과 **핵심 영상 7개(49크레딧)**를 추출하고, **클로드 코드 스킬**과 **리모션(Remotion)**을 결합하여 자막·라벨·그래픽 합성과 컷 배분을 완벽히 제어하는 95초 분량의 고품질 공학 쇼츠 완전 자동화 파이프라인 구축 노하우를 상세히 제시한다.

## 1. ★구글 Flow와 크레딧 정책 및 쇼츠 컷 배분 전략★ · [00:00](https://youtu.be/8b8Mn91-_iY?t=0)
- **3줄 요약**
  - **구글 Flow**의 정책 변경으로 이미지 생성은 **0크레딧**으로 무료화되었으며, 4초 영상 클립만 개당 **7크레딧**이 차감된다.
  - 95초 분량(28컷) 쇼츠를 모두 영상으로 만들지 않고 정지 이미지에 미세한 카메라 무빙을 결합하여 비용을 극대화한다.
  - 훅, 문제 제기, 실패 장면, 발상 전환, 롱샷 등 **핵심 5대 구간**에만 7개 영상 클립(49크레딧)을 집중 배치한다.
- **핵심 인용**: "크레딧이 나가는 건 영상뿐이고 4초짜리 하나의 7크레딧이거든요 여기서 하나 솔직하게 짚고 갈게요"
- **내 팁**: 95초 쇼츠를 전부 비디오로 렌더링하려 하지 말고 필수 반전 구간 7개 컷에만 영상을 배치하여 일일 무료 50크레딧 한도 내에서 1편을 완결한다.

## 2. 공학 쇼츠 파이프라인 준비물과 소재 선정 3대 원칙 · [02:16](https://youtu.be/8b8Mn91-_iY?t=136)
- **3줄 요약**
  - 시스템 준비물은 구글 계정, 원격 디버깅 포트가 열린 크롬, 브라우저 하니스 도구, **파이썬 3.10 이상** 및 3개 외부 패키지만 필요하다.
  - 성공하는 공학 쇼츠 소재는 **인지도 있는 대상**, **상식적 해법의 실제 실패**, **직관에 반하는 진짜 해법**의 3대 요건을 모두 충족해야 한다.
  - 1차 출처 기반 팩트 체크를 거친 뒤 650자 내외의 대본을 작성하고 장면표보다 **나레이션 음성 생성**을 먼저 선행하여 분량을 확정한다.
- **핵심 인용**: "통과해야 하는 조건이 세 개 있습니다 하나 설명 없이 이름만 돼도 아는 대상이어야 해요 노안 안경 알죠"
- **내 팁**: 대본 완성 후 장면표를 먼저 짜면 나레이션 음성 속도에 따라 전체 타임라인이 밀리므로 반드시 나레이션 음성 렌더링부터 확정해야 한다.

## 3. ★앵커 참조 기반 이미지 생성 및 클립 변환 자동화 워크플로우★ · [05:08](https://youtu.be/8b8Mn91-_iY?t=308)
- **3줄 요약**
  - `flow.json` 설정 파일 하나에 화면 비율, 공통 룩 프롬프트, 이미지 목록, 비디오 클립 목록을 정의하여 자동화를 제어한다.
  - **앵커(Anchor)** 기준 이미지 1장을 먼저 생성한 뒤 다른 이미지 생성 시 참조로 물려 스튜디오 조명과 색감의 **시각적 일관성**을 유지한다.
  - 부정문 프롬프트는 의도와 반대로 요소를 그릴 수 있으므로 배제하고, 완성된 이미지 ID를 기반으로 단일 문장 모션 프롬프트를 주어 클립을 추출한다.
- **핵심 인용**: "앵커라고 부르는 기준 이미지를 딱 한 장 먼저 만들어요 그리고 나머지 이미지를 만들 때마다 그 앵커를 참조 이미지로 물립니다"
- **내 팁**: 프롬프트에 글자 넣지 마 같은 부정어를 기재하면 모델이 도리어 문자를 그리므로 배제할 대상은 아예 언급하지 않고 존재해야 할 피사체만 긍정문으로 기술한다.

## 4. 리모션(Remotion) 코드 기반 그래픽 합성 및 자막 단일행 원칙 · [07:18](https://youtu.be/8b8Mn91-_iY?t=438)
- **3줄 요약**
  - 생성형 비디오 모델의 한글 표기 왜곡과 오탈자 재작업 비용을 방지하기 위해 한글 자막과 그래픽은 플로우에 맡기지 않는다.
  - **리모션(Remotion)** 도구를 사용해 28컷에 걸쳐 59개의 한글 라벨, 수치, 화살표, 치수선을 코드로 렌더링하여 정확도를 확보한다.
  - 시청자의 시선 흐름이 끊기지 않도록 **자막은 항상 단일행**으로 유지하며 길이가 길 경우 글자 크기 축소나 시간 분할로 대응한다.
- **핵심 인용**: "한글은 생성 모델이 틀립니다 못할 자 하나 고치려고 영상을 다시 뽑아야 하는 상황이 나와요 그래서 화면에 한글 라벨 수치 자막 화살표는 전부 리모션이란 도구로 따로 합성합니다"
- **내 팁**: 화면 내 수치와 다이어그램을 비디오 자체에 생성시키지 말고 리모션을 통한 웹 기반 오버레이 합성 방식으로 분리해야 텍스트 수정 시 재렌더링 비용을 아낄 수 있다.

## 5. 실전 자동화 구축 시 7대 필수 주의사항 · [08:08](https://youtu.be/8b8Mn91-_iY?t=488)
- **3줄 요약**
  - 개인정보 및 대화 내역 유출을 차단하기 위해 업무용 크롬과 분리된 **별도 포트·프로필 전용 브라우저**를 띄워 탭 단위로 녹화해야 한다.
  - 로컬 음성 복제 도구 사용 시 레퍼런스 대본이 합성 음성에 섞여 들어가지 않도록 5~20초 분량만 지정하고 독립 전사 검증을 수행한다.
  - 스킬 코드 수정 후에는 하니스 데몬을 재시작해야 하며, 생성 완료 판정은 불안정한 주소나 개수 대신 **카드 제목 증가**를 기준으로 삼는다.
- **핵심 인용**: "화면 녹화는 화면을 찍는데 자동화는 탭을 조작합니다 제가 다른 탭을 보고 있어도 생성은 계속 성공해요 근데 녹화에는 제가 보던게 들어가는 거죠"
- **내 팁**: 브라우저 자동화 녹화 시 다른 작업 화면이 녹화본에 캡처되는 대형 사고를 방지하기 위해 반드시 별도 디버깅 포트의 전용 프로필 크롬을 실행하고 탭 단위 녹화를 설정한다.

## 6. 완성본 검증과 크레딧 관리 및 스킬 유지보수 요령 · [11:08](https://youtu.be/8b8Mn91-_iY?t=668)

  - 영상 클립 추가가 필요할 경우 4초당 7크레딧 소모 산수를 선행하고, 정지 컷 비율 조정이나 제작 분할 일정을 계획한다.
  - 구글 플로우의 웹 UI 변경으로 자동화가 중단될 때를 대비해 실패 시점 화면 스크린샷을 자동 저장하여 신속한 위치 보정이 가능하게 한다.

## TL;DR (5줄)
1. **무료 크레딧 극대화**: 구글 Flow에서 0크레딧인 이미지 12장과 7크레딧 영상 클립 7개(49크레딧)를 조합해 일일 50크레딧 내에서 95초 쇼츠를 제작한다.
2. **엄격한 소재 및 대본**: 이름만 대도 아는 대상과 상식적 해법의 실패 및 반전 원리를 갖춘 소재를 선정하고 팩트 체크 후 650자 8구간 대본을 작성한다.
3. **앵커 기반 룩 통일**: flow.json 설정으로 기준 앵커 이미지를 지정하고 나머지 컷에 참조로 물려 스타일 일관성을 유지하며 부정문 프롬프트를 배제한다.
4. **리모션 코드 그래픽 분리**: AI 모델의 한글 오탈자를 방지하기 위해 자막, 수치, 화살표 등 59개 그래픽을 리모션 코드로 오버레이 합성하며 단일행 자막을 준수한다.
5. **독립 환경 및 에러 대응**: 개인정보 유출 방지를 위해 전용 포트 브라우저와 탭 녹화를 사용하고 UI 변경 실패에 대비해 자동 화면 캡처로 셀렉터를 보정한다.
