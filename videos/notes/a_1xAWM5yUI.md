# 맥미니 없이 헤르메스 에이전트 24시간 돌리는 법 — 호스팅어(Hostinger) VPS에 5분 설치

> 한 줄 요약: 헤르메스 에이전트는 **24시간 켜진 환경**이 필요해 보통 맥미니(150만원↑·대기 김·오버스펙·보안/업데이트 부담)를 쓰는데, **VPS면 충분**하다. 호스팅어의 **헤르메스 원클릭 설치 배포** 상품을 골라 서버 위치(지연 최소)·계정만 정하면 **약 5분 만에 자동 배포**. 접속 후 CLI에서 모델을 코덱스 로그인으로 바꾸고(GPT-5.6), **파일 폴더에 설계도(HTML)를 드래그 업로드** → **리즈닝을 맥스로 올려** "이 파일대로 마케팅 팀 만들어 줘" → **에이전트 19명 + 소울 MD + 칸반 실행보드 + 모델 라우팅**(대량=루나/균형=테라/품질=솔)까지 자동 구성. 회사 홈페이지를 주자 현재진단·포지셔닝·90일 로드맵·콘텐츠 12개·측정 체계까지 담긴 전략 HTML을 산출. **슬랙 연결**은 클로드 크롬 확장이 브라우저를 직접 조작해 앱 생성·토큰 발급·설정을 대신 수행 → 슬랙에서 '김서현 팀장'으로 동작하고, 지시한 일이 **칸반보드에 할일/진행중/승인대기**로 관리된다. 기본 제공 **스킬 76개**·플러그인·MCP·크론잡(정기 작업)·키 보관까지 갖췄고, **도커 컨테이너+방화벽·멀웨어 스캐너·DNS**로 기업 보안 요구도 커버. 핵심 동기: **내 PC가 아니라 프라이빗 서버에서 구동**.

## 1. ★왜 VPS인가 — 맥미니의 4가지 문제★ · [01:31](https://youtu.be/a_1xAWM5yUI?t=91)
- **3줄 요약**
  - 헤르메스는 **24시간 365일 켜진 환경**이 전제. 보통 맥미니를 사지만 **150만원 이상**에 대기 기간도 길다.
  - 문제 4가지: 헤르메스만 쓰기엔 **오버스펙**, **인터넷 끊김**, **보안**, **업데이트 관리 부담**.
  - 대안은 **VPS(개인 전용 프라이빗 서버)** — 그중 헤르메스를 한 번에 설치하고 안정적·저렴한 곳으로 **호스팅어**를 선택(한국어 제공).
- **핵심 인용**: "맥미니를 이미 사용하시는 분들은 맥미니에 설치하시면 되겠지만, 그렇지 않은 분들은 VPS로 충분할 것 같아요."
- **내 팁**: 이 갤러리 [헤르메스 강의 1](https://youtu.be/j8UPHTc24H0)·[Hermes 데스크톱앱 VPS 연동](https://youtu.be/Lkk2ubF1AZ8)의 후속 — 그 편들이 '무엇을/어떻게 설정'이었다면 이 편은 **어디서 24시간 돌릴까(인프라)**를 다룬다.

## 2. 설치 — 원클릭 배포 5분 + 모델 전환 · [02:33](https://youtu.be/a_1xAWM5yUI?t=153)
- **3줄 요약**
  - 상품에서 **헤르메스 에이전트 원클릭 설치 배포** 선택, 입문은 **KVM1**(상위는 GPU·램·디스크 차이). 기간 선택 후 **쿠폰 코드로 10% 할인**(전용 링크로 진입해야 표시).
  - 설정: **서버 위치는 지연 시간이 가장 적은 곳**, 검색창에 '헤르메스'→에이전트 선택→유저명·패스워드 입력→배포. **VPS 세팅+헤르메스 설치가 약 5분 자동**(완료 시 이메일).
  - 접속(열기/터미널 열기)→로그인. 모델은 기본 클로드 소넷이며, **모델 변경은 CLI에서** — 코덱스 선택 시 **API 대신 '코덱스 로그인'**으로 디바이스 코드 인증(→ GPT-5.6 솔).
- **핵심 인용**: "VPS 설정을 자동으로 해 주고, 여기에 헤르메스를 자동으로 설치를 해 줍니다. 한 5분 정도 시간이 걸리는데."
- **내 질문**: '모델 변경은 GUI가 아니라 CLI'라는 점은 이 프로젝트의 CLI vs GUI 경계 사례 — 설정 계층은 터미널, 운영은 웹 UI로 나뉜 것 아닐까?

## 3. ★마케팅 팀 구성 — 설계도 업로드 + 리즈닝 맥스★ · [08:09](https://youtu.be/a_1xAWM5yUI?t=489)
- **3줄 요약**
  - 만들 구조는 **루프 엔지니어링(자기 개선 루프) + 그래프 엔지니어링**(여러 루프를 엮어 기준 충족 시에만 다음 단계로) 설계도를 HTML로 준비.
  - **파일→프로젝트/마케팅 팀 폴더 생성 후 드래그 앤 드롭 업로드** → 채팅에서 읽기 확인. 복잡한 작업이므로 **리즈닝을 미디엄→맥스**로 상향.
  - "파일 내용대로 마케팅 팀을 만들어 줘" → **에이전트 19명**, 실행 엔진, 마케팅 운영 스킬, **소울 MD**, **칸반 실행보드**, 캠페인 자동 구성, 설치 엔진·검증기까지 자동 생성. **모델 라우팅**: 대량=루나 / 균형=테라 / 품질 추론=솔, 역할별 리즈닝도 자동 구분.
- **핵심 인용**: "복잡한 걸 잘 처리하려면 리즈닝 이폴트를 최대로 맞춰 주시는 게 좋습니다."
- **내 팁**: '설계도를 파일로 주고 그대로 구현시키기'는 이 갤러리 [orca 그래프 엔지니어링](https://youtu.be/-pk2umNC-18)·[매니페스트 기획](https://youtu.be/w5XO8zYGJ2Y)과 같은 계열 — **기획 산출물을 실행 에이전트에 넘기는** 패턴.

## 4. ★실전 산출 + 슬랙 연결(클로드가 브라우저 조작)★ · [11:16](https://youtu.be/a_1xAWM5yUI?t=676)
- **3줄 요약**
  - 회사 홈페이지 URL만 주자 **현재 진단·우선 고객·포지셔닝·업셀 사다리·90일 로드맵·채널 전략·콘텐츠 12개·측정 체계·필요한 결정·하지 말 것**을 담은 전략 HTML(+PDF 인쇄)을 캠페인 폴더에 저장.
  - 외부 사용을 위해 **채널 연결**(디스코드·텔레그램·슬랙). 슬랙 설정값은 **클로드 크롬 확장**에 물었더니, "1단계를 대신해 줘"만으로 **클로드가 마우스를 직접 조작**해 앱 생성→매니페스트 붙여넣기→봇 토큰 발급→리스타트·테스트까지 수행.
  - 결과: 회사 슬랙에서 **'김서현 팀장'**으로 동작(멤버 태그 인사 등). 지시한 일은 **칸반보드**에 할일/진행중/차단/승인대기로 올라오고 승인 시 진행.
- **핵심 인용**: "지금 제 마우스랑 다르죠? 얘가 지금 마우스를 가지고 컨트롤하고 있습니다."
- **내 질문**: 'AI가 브라우저를 대신 조작해 OAuth 앱까지 세팅'은 이 프로젝트가 쓰는 브라우저 자동화와 동일 기술 — 토큰 발급 같은 민감 작업을 어디까지 위임할지가 관건 아닐까?

## 5. 운영 기능 + 보안(도커·방화벽) · [16:24](https://youtu.be/a_1xAWM5yUI?t=984)
- **3줄 요약**
  - 운영: 채팅·세션 확인, 파일 업로드, 모델 전환, **크론잡**(정기 작업 — 발표자는 LLM 위키를 리플렉션마다 생성 예약), **스킬 76개 기본 설치**(LM 위키 등, 추가는 채팅 요청으로 자동), **플러그인**(브라우저 유즈·깃허브), **MCP**(블렌더·리니어·n8n 등), **채널** 다중 연결, **프로필의 소울 MD 편집**, **API 키 안전 보관**.
  - 보안: **안전한 도커 컨테이너**에서 구동(현재 우분투, 다른 OS 설치 가능), 백업·모니터링, **멀웨어 스캐너·방화벽·DNS 관리**. VPS에 **도메인 신청 시 1년 무료**.
  - 기업 사용 시 법인이 맥미니를 사고 어디에 둘지 고민하는 것보다, 비용·보안 면에서 VPS가 합리적. 핵심은 **내 컴퓨터가 아닌 프라이빗 서버 구동**.
- **핵심 인용**: "제일 이제 호스팅어에다가 회사 관련된 슬랙을 연결시킨 이유는 이 보안입니다. 멀웨어 스캐너라든지 방화벽 이런 것들을 설치해서 사용할 수가 있어요."
- **내 팁**: '검증된 스킬 76개 선탑재'는 이 갤러리 코워크·오르카 편의 스킬 주입과 같은 흐름 — 에이전트 플랫폼이 **스킬 마켓을 기본 번들로** 흡수 중.

## TL;DR (5줄)

1. **문제(★)**: 헤르메스는 24시간 환경 필요 → 맥미니는 150만원↑·오버스펙·인터넷/보안/업데이트 부담. **VPS로 충분**.
2. **설치**: 호스팅어 원클릭 배포(KVM1부터, 쿠폰 10%), 서버 위치는 지연 최소 → **5분 자동 설치**. 모델 변경은 **CLI**에서 코덱스 로그인.
3. **구성(★)**: 설계도(HTML) 드래그 업로드 + **리즈닝 맥스** → 에이전트 19명·소울 MD·칸반보드·모델 라우팅(루나/테라/솔) 자동 생성.
4. **실전**: 홈페이지 URL만으로 90일 로드맵·콘텐츠 12개 전략 산출. **슬랙 연결은 클로드가 브라우저를 직접 조작**해 앱·토큰까지 세팅 → '김서현 팀장'으로 근무, 업무는 칸반으로 승인 관리.
5. **운영·보안**: 크론잡·스킬 76개·플러그인·MCP·키 보관 + **도커 컨테이너·방화벽·멀웨어 스캐너·DNS**, 도메인 1년 무료. 요지는 **내 PC가 아닌 프라이빗 서버**.
