# 클로드 코워크 실전 활용법 — 교과 세특 자동화 워크플로우 (생기부 작성 꿀팁, feat. 전정선 선생님)

> 한 줄 요약: 학생 수행평가 PDF를 **① 데이터 정리(엑셀) → ② 세특 작성 → ③ 검수**의 3단계로 클로드 코워크에서 자동화하고, 최종적으로 **플러그인('세특 워크플로우')으로 패키징**해 명령 한 번에 실행하는 실전. 핵심 도구는 **스킬**(세특 라이팅/휴먼 티처/휴머나이저)과 **코워크 3꿀팁**(선계획·서브에이전트 병렬·검증 강화). 교과세특뿐 아니라 '반복적이고 복잡한 일'을 세트로 묶어 자동화하는 워크플로우 설계가 진짜 주제.

## 1. 복습 — 스킬 vs 코워크 · [03:11](https://youtu.be/AFVEpW0-X8U?t=191)
- **3줄 요약**
  - **스킬** = 클로드가 업무 전에 읽는 상세 업무 매뉴얼(반복·형식 일정한 작업에 유용). "…하는 스킬 만들어 줘" 한 마디로 생성, "고쳐줘"로 수정, 남의 스킬도 업로드해 변형.
  - **코워크** = 답변 챗봇이 아니라 **계획→실행→검증**하는 에이전트. 데스크탑 앱+프로 요금제 필요, 폴더를 주면 파일을 읽고 수정·생성.
  - 커넥터(구글·Gmail·캔바·노션)·예약 시행으로 확장. (UI: '협업' 탭이 코워크.)
- **핵심 인용**: "스스로 계획을 세우고 실행하며 검증까지 수행하는 에이전트형 AI가 코워크."
- **내 팁**: 공문·품의서·가정통신문·활동지·PPT처럼 '형식이 일정한' 반복 업무를 스킬로 굳히면 결과물이 즉시 일정하게 나온다.

## 2. ★코워크 3꿀팁 — 계획·병렬·검증★ · [10:37](https://youtu.be/AFVEpW0-X8U?t=637)
- **3줄 요약**
  - 채팅 vs 코워크는 토큰 차이 큼(코워크는 3단계라 토큰↑) → 간단한 건 채팅, 복잡·다단계는 코워크.
  - ① **선계획**: "바로 실행 말고 계획을 먼저 보여 줘"(방향 어긋나면 도중 교정이 결과 후 수정보다 효율·토큰 절약).
  - ② **서브에이전트 병렬**: "서브에이전트로 병렬 처리해 줘"(독립 작업을 여러 에이전트가 동시에→시간 단축, 토큰↑). ③ **검증 강화**: "최종 검증 한 번 더"(원본 대조·글자수·형식).
- **핵심 인용**: "얘가 손오공이 분신하듯이 서브 에이전트를 자동으로 만들어서 일을 처리할 수 있습니다."
- **내 질문**: '선계획 승인'은 앞 영상들의 플랜 모드와 같은 원리 — AI에게 도면부터 받는 습관이 토큰·품질을 동시에 지킨다.

## 3. 3대 스킬 + 업로드 + 휴머나이저 · [15:44](https://youtu.be/AFVEpW0-X8U?t=944)
- **3줄 요약**
  - **세특 라이팅 플러스**(세특 작성), **휴먼 티처**(교사 관찰 시점·글자수 등 검증 + 인간 글화), **휴머나이저**(AI 냄새 제거 — 콤마 남발·과장·번역투 등 **40가지 패턴을 논문 기반**으로 제거).
  - 휴머나이저 원본 = 깃허브 '달래소'님의 코리안 스킬(S1/S2/S3 패턴). 이를 교과세특 특화로 변형한 게 휴먼 티처.
  - 업로드: 사용자 지정 → 스킬 → 추가 → 드래그. 수정은 채팅으로. (협업 비활성 시 윈도우 '가상 머신 플랫폼'·'하이퍼바이저 플랫폼' 켜기.)
- **핵심 인용**: "AI가 쓴 글은 … 콤마를 많이 쓰고, 지나친 과장, 외국어를 번역한 듯한 문체 … 40가지 패턴이 있어요."
- **내 팁**: '내가 만든 스킬'이 결과 품질을 좌우 — 범용 스킬로 시작하되 내 과목·과제에 맞게 대화로 다듬어 나만의 스킬로.

## 4. 1단계 데이터 정리 + 수집 꿀팁 · [25:38](https://youtu.be/AFVEpW0-X8U?t=1538)
- **3줄 요약**
  - 손글씨 기획서 PDF를 폴더에 넣고 코워크로 "예시 제외, 학생 답변만 그대로 추출, 확인 불가 표시, 계획 먼저" → 엑셀로 정리(바이트수 계산·나이스 붙여넣기에 유리).
  - 수집 꿀팁: **제미나이 인 크롬**(PDF를 크롬에 열고 옆에서 "그대로 적어 봐"로 바로 대조), **NotebookLM**(한 번에 3명씩 추출이 정확), 데이터 표, **구글시트 AI 함수** `=AI("500자 세특 작성해 줘", 범위)`.
  - 보안: 학교 구글 계정은 "학습에 사용 안 함" 명시 → 민감 데이터는 학교 계정. 코워크 정리 정확도 90%+(노트북LM보다 높음).
- **핵심 인용**: "학교 계정에서는 … 구글이 절대 학습에 사용하지 않는다라고 명시 … 민감한 데이터를 다루실 때에는 학교 계정."
- **내 질문**: 같은 '추출'도 코워크(정확·느림)·NotebookLM(빠름·3명씩)·제미나이 크롬(대조 확인)으로 나뉘는데, 데이터 성격에 따라 도구를 섞는 게 정석 아닐까?

## 5. 2단계 세특 작성 — 스킬 + 서브에이전트 병렬 · [45:25](https://youtu.be/AFVEpW0-X8U?t=2725)
- **3줄 요약**
  - 정리된 엑셀을 폴더로 지정하고 "**세특 라이팅 플러스 스킬**로 학생 세특 작성. 10명을 3등분해 **서브에이전트 3개 병렬**. 엑셀로 저장. 계획 먼저."
  - 에이전트 A·B·C가 팀을 나눠 쓰고 메인(팀장)이 검수·조정 → 순차보다 빠르고 정확. 스킬이 시점·어미·인용부호·분량·형식을 매뉴얼대로 통제.
  - 작년까지는 한 명씩 프롬프트→복사→엑셀 붙이기였으나, 이제 데이터만 있으면 10·20·30명을 스킬+병렬로 한 번에.
- **핵심 인용**: "서브 에이전트로 병렬로 시키면 동시에 이것들을 팀을 나눠서 지들이 쓰고 전체 검수를 하거든요."
- **내 팁**: 세특 스킬은 새 채팅에서 결과물 하나로 다듬다가 "위 과정으로 세특 쓰는 스킬 만들어 줘"로 내 것으로 만든다.

## 6. 3단계 검수 + ★플러그인 패키징★ · [53:34](https://youtu.be/AFVEpW0-X8U?t=3214)
- **3줄 요약**
  - **휴먼 티처 스킬**로 "글자수·교사 관찰 사실 근거·인간 교사가 직접 쓴 듯한 자연스러움 점검. 3등분 서브에이전트 병렬. **다단계 검증 강화**. 엑셀로." → 상투어·콤마·분량을 고쳐 최종 세특.
  - **플러그인 = 여러 스킬 + 커넥터 + 서브에이전트를 하나로 묶는 기능**. "세 스킬을 '세특 워크플로우' 플러그인으로 패키징, 실행하면 과정이 한 번에 이어지도록."
  - 이후엔 PDF만 폴더에 넣고 이 플러그인 하나만 실행하면 **정리→작성→검수가 자동**.
- **핵심 인용**: "플러그인은 여러 개의 스킬 더하기 커넥터 더하기 서브 에이전트를 하나로 묶는 기능이에요."
- **내 질문**: '스킬을 조립해 플러그인으로 굳히기'는 앞 영상들의 '반복 워크플로우 자동화'의 종착점 — 나의 반복 업무 중 무엇을 이렇게 한 명령으로 묶을 수 있을까?

## TL;DR (5줄)

1. **목표**: 학생 수행평가 PDF → **데이터 정리(엑셀) → 세특 작성 → 검수** 3단계를 코워크로 자동화, 최종 **플러그인으로 패키징**.
2. **코워크 3꿀팁(★)**: ① 계획 먼저 보여줘 ② 서브에이전트 병렬(3등분) ③ 검증 강화 — 토큰·시간·품질을 함께 관리.
3. **스킬 3종**: 세특 라이팅 플러스 / 휴먼 티처(관찰 시점·검증) / 휴머나이저(AI 냄새 40패턴 제거, 논문 기반). 내 것으로 다듬는 게 품질의 핵심.
4. **데이터 수집**: 코워크(정확)·NotebookLM(3명씩)·제미나이 크롬(대조)·구글시트 `=AI()` 함수. 민감 데이터는 **학교 계정**(학습 미사용).
5. **패키징**: 세 스킬+서브에이전트를 '세특 워크플로우' **플러그인** 하나로 → 이후 PDF만 넣고 실행하면 전 과정 자동. 교과세특 넘어 반복·복잡 업무 자동화의 틀.
