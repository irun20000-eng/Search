# (오픈소스 제공) 클로드 코드로 긴 영상을 100% 자동으로 만들어보았습니다 (Claude Code)

> 한 줄 요약: 텍스트만 넣으면 **대본 조사→일러스트→나레이션→자막→편집**까지 하는 롱폼(오디오북) 영상 자동화 에이전트 팀을 클로드 코드로. 구조는 **서브에이전트(고도·고토큰 작업: 감독·작가)** + **스킬(반복·저토큰 작업: 이미지·TTS·자막·편집)**의 분업. 도구: **제미나이 API 하나로 이미지(나노바나/3 Pro)+TTS(2.5 Pro)** 해결, **Whisper large-v3(로컬 2GB)로 자막**, **FFmpeg로 합성**. 실전 팁 = 증상을 정확히 말해 **반복 개선**(이미지 깨짐·자막 싱크 등 3차까지), 모델은 **Pro로 상향** 필수. 현실 경고: **API 비용**(15초 100~200원, 30분 5천~1만 원)·**Veo3 하루 호출 제한**·**유튜브 AI 검열 강화**로 업로드는 비권장 — 용도는 뉴스레터·블로그의 영상화.

## 1. 동기 + 에이전트 팀 구조 · [00:00](https://youtu.be/JQRr7xhr4OM?t=0)
- **3줄 요약**
  - 텍스트만 입력하면 AI가 대본 조사·일러스트·나레이션·자막·편집까지 하는 롱폼 영상 워크플로우. 노트북LM의 "소스→팟캐스트"를 영상으로 확장하려는 동기.
  - 가능한 이유는 클로드 코드의 **서브에이전트 + 스킬 구조**. 이전 마케팅 팀 에이전트에서 빠졌던 '긴 영상 만들기'를 채움.
  - 구조: 내 명령 → **영상 감독(기획 총괄) 에이전트**가 오케스트레이션(대본·그림·나레이션·싱크·합치기 지시) → 작가 팀부터 하달.
- **핵심 인용**: "이게 가능한 이유는 현재 클로드 코드 내에 있는 서브 에이전트와 스킬 구조 덕분입니다."
- **내 팁**: 감독→작가→프로덕션의 오케스트레이션은 이 프로젝트의 '독립 에이전트 팀(빌더/리뷰어/검증)'과 같은 계층 구조.

## 2. ★서브에이전트 vs 스킬 — 분업 원칙★ · [01:57](https://youtu.be/JQRr7xhr4OM?t=117)
- **3줄 요약**
  - **서브에이전트 = 고도화·생각·고토큰 작업**: 감독(디렉터), 작가(리서치+대본, 명언 선별·자료 조사). 대본 퀄리티를 책임.
  - **스킬 = 반복·저토큰 작업**(클로드 공식 권장 용도): 영상 프로덕션 팀 4직원 — 일러스트·음향(TTS)·자막·편집.
  - 작업이 감독에서 작가로, 다시 프로덕션 팀으로 순차 하달되는 오케스트레이션.
- **핵심 인용**: "서브 에이전트는 … 고도화된 일 … 스킬은 … 반복적인 업무 혹은 토큰을 적게 쓰는 그런 업무에 써라."
- **내 질문**: '고도=서브에이전트 / 반복=스킬' 분업은 앞 영상(스펙주도개발의 스크립트 고정, 유튜브 요약의 collect 스크립트)의 '토큰 경제성' 원칙과 정확히 같은 것 아닐까?

## 3. 프로덕션 팀 4직원 — 도구 스택 · [03:07](https://youtu.be/JQRr7xhr4OM?t=187)
- **3줄 요약**
  - **일러스트**: 제미나이 API(나노바나/Gemini 3 Pro)로 그림. **음향(TTS)**: 제미나이 2.5 Pro TTS(AI 스튜디오). → **제미나이 API 하나로 이미지+TTS 해결**.
  - **자막**: OpenAI **Whisper**(로컬 large-v3, 약 2GB 필요, 생성 영상 인식→자막) 또는 OpenAI API 키.
  - **편집**: **FFmpeg**(파이썬 라이브러리)로 영상·음성·자막 합성+효과. 자동이지만 퀄리티는 '완벽'까진 아니고 다수 일러스트+음성+자막+약간의 효과 수준.
- **핵심 인용**: "제미나이 API 하나면 이 모든 것들이 다 해결이 된다."
- **내 팁**: 이미지·TTS·자막·편집을 각각 스킬로 두는 건 앞 영상(힉스필드 스킬 5개, 데키랩 모션그래픽)의 '기능별 스킬화'와 동일 — 파이프라인 각 단계를 도구로 고정.

## 4. 세팅 — init·API 키(.env)·무료 에셋(폰트/BGM) · [05:32](https://youtu.be/JQRr7xhr4OM?t=332)
- **3줄 요약**
  - 커서/클로드 데스크탑에서 폴더 생성 후 클로드 코드 호출 → 긴 시스템 프롬프트(오디오북 가이드, 오픈소스 제공)를 붙이고 **`init`로 초기화** → agents(video·writer 서브에이전트)/skills(video·image·subtitle·TTS) 폴더 자동 생성.
  - **API 키**: AI 스튜디오 Get API Key(프로젝트 생성 필수) → **`.env`에 GEMINI 키** 저장(결제 연동 필요, 클로드 코드는 $20 Pro 필요). 모델은 **이미지 3.0 Pro·TTS Pro로 상향** 필수.
  - **무료 에셋**: 폰트는 **눈누**(상업용 무료, 코트라 손글씨체), BGM은 유튜브 스튜디오 오디오 보관함(저작권 해소) → 폴더에 넣고 지정.
- **핵심 인용**: "프롬프트를 제안해 줘라고 하면 오히려 클로드가 저희에게 제안을 다시 해주고 그 계획도를 볼 수가 있습니다."
- **내 질문**: `.env`에 API 키를 두고 결제 연동을 요구하는 건 앞 영상(신영선 블로그 자동화, 인스타 토큰)과 같은 '자격증명 관리' 지점 — 사용자가 직접 다뤄야 하는 영역 아닐까?

## 5. ★반복 개선(3차) + 비용·검열 경고★ · [13:43](https://youtu.be/JQRr7xhr4OM?t=823)
- **3줄 요약**
  - 1차 결과는 **이미지 깨짐·자막 싱크 불일치** → 터미널에 **증상을 정확히** 말해 개선("이미지 깨짐, 제미나이 3 Pro 미사용, 자막 불일치") → 2차(이미지 개선)→ "Whisper 스킬 확인해 자막 고쳐" → 3차에서 일러스트·자막·BGM 싱크 정합. **파이프라인 정합성 테스트 필요**.
  - **비용**: 15초 100~200원, 30분이면 API만 5천~1만 원 → **긴 영상은 보수적으로**. **Veo3**(구글 영상 API)는 하루 ~10회 제한이라 비권장, 자체 사운드는 옵션으로 꺼야.
  - **경고·용도**: 유튜브 **AI 영상 검열 강화** 예정이라 업로드 비권장. 진짜 용도는 **뉴스레터·블로그 콘텐츠의 영상화**(노트북LM 팟캐스트의 영상판).
- **핵심 인용**: "너무 긴 영상을 제작한다든가 이런 데 있어서는 조금 더 보수적으로 접근을 했으면 좋겠습니다."
- **내 팁**: '증상을 정확히 말해 반복 개선'은 이 프로젝트의 품질 루프(build→review→fix→반복)와 동일. 비용·검열 경고는 힉스필드·인스타 영상의 '리스크 관리'와 같은 결.
