# 왜 다들 Cursor 클라우드 에이전트로 갈아탈까? | Cursir 클라우드 에이전트 사용법!

> 한 줄 요약: **코드 한 줄 없이 메시지 다섯 개**로 빈 깃허브 저장소에서 소개 홈페이지를 만들고 배포까지 가는 과정을 처음부터 끝까지 보여 준다 — 구조는 **나(사장) → 그록봇(팀장, 내 말을 지시서로 바꿈) → 커서 클라우드 에이전트(팀원, 코드·브라우저 확인·스크린샷) → PR → 내가 머지**다. 준비는 **빈 저장소 만들기 · 커서 대시보드에서 깃허브 저장소 하나만 연결 · 클라우드 에이전트의 PR 자동 생성과 이미지 설정 확인 · 그록봇에 저장소 알려 주기** 네 단계이고, 프롬프트는 **무엇을 만들지 · 확인 기준 · 지킬 것** 세 덩어리라고 정리한다. 실측은 **첫 PR 32분, 머지·배포 1분, 말로 고친 2차 PR 11분, 전체 53분**으로 화자 예상 20분의 두 배가 넘었고, **고친 코드가 300줄이 넘지만 한 줄도 읽지 않고 스크린샷과 실제 화면으로만 확인했다**고 말한다. 요금은 **새로 가입하면 프리미엄 30달러부터 포함이고 8달러 플러스에는 없다**고 짚으며 **이미 커서 프로나 예전 슈퍼그룹을 쓰고 있다면 지금 요금제로 되는지 먼저 확인하라**고 권하고, **AI 의 보고도 한 번은 직접 확인하라**로 닫는다.

## 1. ★코드 0줄, 메시지 5개 — 사장·팀장·팀원★ · [00:00](https://youtu.be/v5PMhN4YDuY?t=0)
- **3줄 요약**
  - 이 홈페이지를 **AI 팀원한테 카톡 보내듯 시켜서 만들었고 마음에 안 드는 곳은 말로 고쳤다**고 열면서, 오늘은 그것을 **빈 저장소에서 처음부터 다시 해 보겠다**고 말한다. 솔직히 자신도 반신반의라며 **예상은 20분**이라고 미리 밝힌다.
  - 지켜볼 것 세 가지를 제시한다 — **문장 하나로 정말 만들어지는지, AI 가 스스로 확인까지 하는지, 마음에 안 드는 곳을 말로 고칠 수 있는지**다. **실패하면 실패한 대로 보여 주겠다**고 덧붙인다.
  - 역할 비유를 먼저 깔아 둔다. **본인은 사장, 그록봇은 팀장, 커서 클라우드 에이전트는 클라우드 사무실의 개발자 팀원**이고 **사장은 말하고 마지막에 도장만 찍는다**고 설명한다.
- **핵심 인용**: "그록봇은 팀장, 커서 클라우드 에이전트는 클라우드 사무실의 개발자 팀원이에요. 사장은 말하고 마지막에 도장만 찍습니다."

## 2. 구조 — 그록봇이 지시서로 바꾸고 팀원이 PR을 올린다 · [00:49](https://youtu.be/v5PMhN4YDuY?t=49)
- **3줄 요약**
  - 화자가 하는 일은 **그록봇에게 말하는 것뿐**이라고 말한다. **그록봇 앱에 코딩 일을 맡기는 봇을 하나 만들어 뒀고**, 거기에 원하는 것을 적으면 **그록봇이 그 말을 지시서로 바꿔 커서 클라우드 에이전트에게 넘긴다**고 설명한다.
  - 클라우드 에이전트는 **깃허브 저장소에서 코드를 짜고 직접 열어서 확인한 다음 PR 을 올린다**고 말한다(자막은 PR 을 「결제 서류」와 「결재 서류」로 뒤섞어 부르고, 설명란은 「결재 서류」로 적었다). 화자가 **확인하고 머지하라고 말하면 실제 주소로 배포된다**고 말하며 흐름을 닫는다.
  - 이렇게 **말로 시켜서 코딩하는 것을 바이브 코딩이라고 부른다**고 용어를 짚고 다음 구간으로 넘어간다.
- **핵심 인용**: "클라우드 에이전트는 깃허브 저장소에서 코드를 짜고 직접 열어서 확인한 다음 결제 서류인 PR을 올려요."
- **내 질문**: 그록봇 안의 **「코딩」 봇을 어떻게 만들었는지**는 이 구간에서 다루지 않는다 — 준비 단계에서 그 봇에 저장소를 알려 주는 대목만 나온다.

## 3. ★클라우드 에이전트를 쓰는 이유 네 가지와 요금★ · [01:22](https://youtu.be/v5PMhN4YDuY?t=82)
- **3줄 요약**
  - 커서 클라우드 에이전트인 이유를 네 가지로 든다 — **내 컴퓨터가 아니라 클라우드에 있는 자기 컴퓨터에서 일하고**, **코드만 짜는 게 아니라 브라우저를 직접 열어 눌러 보며 확인하고**, **확인한 화면을 스크린샷으로 PR 에 붙여 줘 코드를 몰라도 결과를 눈으로 검토할 수 있고**, **여러 일을 동시에 맡길 수도 있다**고 설명한다.
  - 그리고 **마지막 머지는 언제나 사람**이라고 못 박는데, 뒤의 체크리스트·팁 구간에서도 **스크린샷과 실제 화면을 보고 괜찮을 때만 머지하라**고 다시 말한다.
  - 요금은 커서 요금제 화면을 띄워 짚는다. **새로 가입하면 프리미엄 30달러부터 클라우드 에이전트와 그록봇이 들어 있고 8달러 플러스에는 없으며, 사용량은 하나의 풀에서 함께 빠진다**고 말한다. **이미 커서 프로나, 자막이 「예전 슈퍼그룹」이라 적은 요금제를 쓰고 있다면 지금 요금제로 되는지 먼저 확인하라**고 권한다(설명란에는 예전 SuperGrok 으로 적혀 있다).
- **핵심 인용**: "새로 가입하시면 프리미엄 30달러부터 클라우드 에이전트와 그록봇이 들어있어요. 8달러 플러스에는 없어요."
- **내 팁**: 설명란은 이 요금 화면을 **2026-11-26 기준**이라고 적어 두었다 — 영상이 직접 당부한 대로 가입 전에 지금 요금제로 되는지 확인하는 편이 낫다.

## 4. 준비 네 단계 — 빈 저장소부터 그록봇 연결까지 · [02:17](https://youtu.be/v5PMhN4YDuY?t=137)
- **3줄 요약**
  - 첫째 **깃허브에서 빈 저장소를 하나 만든다**. 깃허브를 **코드를 넣어 두는 회사 서류 보관함**으로 비유하고, **저장소 이름을 적고 공개로 둔 다음 크리에이트 리포지토리를 누르면 끝**이라고 설명한다.
  - 둘째 **커서 대시보드의 인테그레이션스 메뉴에서 깃허브를 연결**한다. 이때 **모든 저장소가 아니라 오늘 쓸 저장소 하나만 고르라**고 강조하며 **팀원에게 필요한 서랍 열쇠만 주는 것**이라고 비유한다. **그록봇도 이 연결을 그대로 쓴다**고 덧붙인다.
  - 셋째 **클라우드 에이전트 메뉴**에서 **일이 끝나면 PR 을 자동으로 만드는 설정이 켜져 있는지** 보고, 그 아래 **PR 에 이미지를 붙이는 설정을 포스트 아티팩트로 바꾸면 팀원이 찍은 스크린샷이 PR 에 바로 보인다**고 설명한다. 다만 **이 이미지는 주소를 아는 사람이면 볼 수 있으니 다 쓰고 나면 링크 온리로 돌려 두라**고 당부한다. 넷째는 **그록봇의 코딩 봇에게 저장소 이름을 알려 주고 접근할 수 있는지 먼저 확인하게 하는 것**이고, **이미 접근할 수 있고 다른 저장소 권한은 그대로라고 답하면 준비가 끝난다**고 말한다.
- **핵심 인용**: "이때 모든 저장소가 아니라 오늘 쓸 저장소 하나만 고르세요. 팀원에게 필요한 서랍 열쇠만 주는 거예요."
- **내 팁**: **저장소 하나만 연결하기**와 **다 쓰고 링크 온리로 되돌리기**는 영상이 직접 당부한 두 가지다 — 준비를 따라 할 때 이 둘만은 빠뜨리지 않는 편이 좋다.

## 5. 프롬프트 세 덩어리 — 무엇을 만들지·확인 기준·지킬 것 · [03:29](https://youtu.be/v5PMhN4YDuY?t=209)
- **3줄 요약**
  - 프롬프트는 어렵게 생각할 필요 없이 **세 덩어리만 넣으면 된다**고 말한다. 첫째 **무엇을 만들지**로, **첫 화면·숫자·카드·최근 영상·구독 버튼처럼 위에서부터 순서대로 적었다**고 설명한다.
  - 둘째 **확인 기준**이다. **빌드가 되는지, 스크린샷을 붙였는지, 링크가 맞는지**를 적는다고 말한다(자막은 이 대목의 한 구절을 또렷이 잡지 못했다).
  - 셋째 **지킬 것**으로, **로그인·서버는 쓰지 말고 PR 은 한국어로 쓰고 머지는 하지 말라고 적는다**고 설명한다. **여기서 잠깐 멈추고 이 틀을 적어 가라**고 권한다. 설명란에는 이 세 덩어리의 템플릿과 영상에서 실제로 보낸 1·2단계 요청이 실려 있는데, **1단계 쪽에는 업로더가 「링크 주소는 줄임」이라고 밝혀 두었다**. 지킬 것의 자막이 뭉개진 자리를 설명란 템플릿은 「로그인·서버·외부 API는 쓰지 말 것」으로 적어 두었다.
- **핵심 인용**: "셋째 지킬 것 로그인이냐 서버는 쓰지 말고 PR은 한국어로 쓰고 머지는 하지 말라고 적어요."
- **내 팁**: 세 덩어리 중 **확인 기준**이 뒤의 스크린샷 검토를 가능하게 만든 자리다 — 설명란 템플릿도 그 자리에 **브라우저로 직접 열어 본 스크린샷을 PR 에 붙일 것**을 적어 둔다.

## 6. ★32분 만에 올라온 첫 PR과 말로 고치기★ · [04:08](https://youtu.be/v5PMhN4YDuY?t=248)
- **3줄 요약**
  - 텅 빈 저장소에서 그록봇에게 요청을 보내자 **그록봇이 지시서로 바꿔 팀원에게 넘기고**, 화자가 쓴 한 문단이 **목표·그대로 둘 것·확인 기준·규칙으로 나뉘었다**고 말한다. **머지는 하지 말라는 줄도 들어 있다**고 짚는다.
  - 팀원이 클라우드에서 **파일을 만들고 직접 브라우저를 열어 확인까지** 한 뒤 PR 이 올라왔는데 **32분이 걸렸고 직접 스크롤하며 찍은 화면까지 붙어 있었다**고 말한다. 머지·배포를 지시하니 **1분 만에 주소가 나왔고**, 요청한 다섯 가지(첫 화면·숫자·카드 세 장·최근 영상·구독 버튼)가 **다 들어갔다**고 확인한다.
  - 다만 사장 눈으로 보면 **분위기가 평범하고 제목이 왼쪽에 몰려 있다**고 아쉬워하며 말로 고치기로 넘어간다. 디자인을 모른다며 **팀장에게 참고 자료부터 찾아오라고 했고**, 그록봇이 **앱 디자인 모음집과 연결돼 실제 앱 화면 세 개를 찾아왔다**고 설명한다(자막은 그 모음집을 「모빈」, 화자가 고른 화면을 「포트레이트」로 적었고, 설명란에는 Mobbin · Portrait 로 적혀 있다). 그 느낌(밝은 바탕, 가운데 큰 제목, 둘레에 사진 카드)으로 바꾸고 구독 버튼도 크게 해 달라고 한 번에 보냈더니 **11분 만에 올라왔고 고치기 전과 후가 데스크톱·휴대폰 모두 표로 나란히 붙어 있었다**고 말한다. **팀장이 먼저 아쉬운 점(설명 한 줄이 조금 작아 보인다)도 말해 줬다**고 덧붙인다.
- **핵심 인용**: "32분 걸렸네요. 팀원이 직접 스크롤하며 찍은 화면까지 붙여 놨어요."
- **내 팁**: 말로 고칠 때 화자가 한 일은 **마음에 드는 참고 화면 하나를 고르고 말로 부탁한 것뿐**이라고 스스로 정리한다 — 디자인 어휘가 없을 때 쓸 수 있는 방식이다.

## 7. 정산 — 53분·메시지 5개·머지 승인 2번 · [06:30](https://youtu.be/v5PMhN4YDuY?t=390)

## 8. 따라 할 순서와 팁 세 가지 · [07:07](https://youtu.be/v5PMhN4YDuY?t=427)
- **3줄 요약**
  - 따라 할 순서를 한 번에 정리한다. 준비 네 단계는 **빈 저장소 만들기, 커서에 깃허브 연결하기, 클라우드 에이전트 설정 확인하기, 그록봇에 저장소 알려주기**이고, 프롬프트는 **무엇을 만들지 · 확인 기준 · 지킬 것** 세 덩어리라고 되짚는다.
  - **PR 이 올라오면 스크린샷과 실제 화면을 보고 괜찮을 때만 머지하라고 말하고, 마음에 안 들면 말로 고쳐 달라고 하면 된다**고 설명한다.
  - 팁 세 가지는 **한 번에 하나만 맡기기, 머지는 꼭 직접 보고 허락하기, 마지막 확인은 사장인 내가 하기**다. 그 근거로 **오늘도 팀장이 설정이 켜져 있다고 했는데 확인해 보니 꺼져 있었다**는 일을 들며 **AI 의 보고도 한 번은 직접 확인하라**고 닫는다.
- **핵심 인용**: "오늘도 팀장이 설정이 켜져 있다고 했는데 확인해보니 꺼져 있었어요. AI에 보고도 한 번은 직접 확인하세요."
- **내 팁**: 팁 세 가지는 모두 **사람이 마지막에 보는 자리**를 지키라는 말로 모인다 — 설정이 꺼져 있었던 실제 사례가 그 자리가 필요한 이유로 바로 이어 붙는다.

## TL;DR (5줄)
1. **무엇**: **코드 한 줄 없이 메시지 다섯 개**로 빈 깃허브 저장소에서 소개 홈페이지를 만들고 배포까지 가는 과정을 처음부터 끝까지 보여 준다.
2. **구조**: **나(사장) → 그록봇(팀장, 말을 지시서로 바꿈) → 커서 클라우드 에이전트(팀원, 코드·브라우저 확인·스크린샷) → PR → 내가 머지**이고, **마지막 머지는 언제나 사람**이라고 못 박는다.
3. **준비·프롬프트**: 준비는 **빈 저장소 · 깃허브 저장소 하나만 연결 · 클라우드 에이전트 설정 확인 · 그록봇에 저장소 알려 주기** 네 단계, 프롬프트는 **무엇을 만들지 · 확인 기준 · 지킬 것** 세 덩어리라고 정리한다.
4. **실측**: **첫 PR 32분, 머지·배포 1분, 말로 고친 2차 PR 11분, 전체 53분**으로 예상 20분의 두 배가 넘었고, **300줄 넘는 코드를 한 줄도 읽지 않고 스크린샷과 실제 화면으로만 확인했다**고 말한다.
5. **주의**: 요금은 **새로 가입하면** 프리미엄 30달러부터 포함이고 8달러 플러스에는 없으며 **기존 요금제 사용자는 지금 요금제로 되는지 먼저 확인하라**고 짚고, PR 이미지 설정은 **다 쓰고 나면 링크 온리로 되돌리라**고 당부하며, **AI 의 보고도 한 번은 직접 확인하라**로 닫는다.
