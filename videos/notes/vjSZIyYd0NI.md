# [시즌 3] 온갖 크롤링 코드 안녕 — 공개된 페이지를 모두 긁어버리는 Insane-search (thanks to 지피타쿠)

> 한 줄 요약: **Insane-search**는 "웹브라우저로 볼 수 있으면 클로드 코드도 볼 수 있어야 한다"는 발상의 **한국산 클로드 코드 플러그인**. 봇 탐지로 403을 뱉는 사이트(X·레딧·유튜브·네이버·쿠팡·링크드인·미디엄 등)를 **합법 방법을 단계적으로 상승시켜(내부 API 발견→Playwright 브라우저까지) 될 때까지** 공개 데이터를 가져온다. **로그인·결제 뒤 데이터는 우회하지 않음**(불법 배제). 설치는 플러그인 마켓 명령 한 줄. 실증: 유튜브 메타데이터·자막 자동 추출, 네이버 쇼핑 핫딜 308개 CSV, 쿠팡·알리익스프레스까지. 원리는 화면 상품을 감싼 봇 방어 대신 **내부 프리패치 API 콜을 찾아 호출**하는 것. ※ 이 프로젝트의 자막 수집(YT-DLP/공식 API 차단) 대안으로 특히 유의미.

## 1. 무엇 + 본질(공개 데이터 우선) · [00:00](https://youtu.be/vjSZIyYd0NI?t=0)
- **3줄 요약**
  - **Insane-search**(지피타쿠 제작, 한국산) = "웹브라우저로 볼 수 있으면 에이전트도 봐야 한다"에서 출발한 **클로드 코드 플러그인**.
  - 클로드 코드/코덱스로 쿠팡 등을 조회하면 **봇 탐지로 몇 번 만에 403** → 이걸 해결.
  - 카피 "포기는 배추 셀 때나 쓰는 말" — **공개 웹페이지면 결국 가져온다**(단 우회·불법 아님).
- **핵심 인용**: "웹브라우저에 접속을 해서 볼 수 있는 것이라면 우리 클로드 코드도 볼 수 있어야 되는 거 아니냐."
- **내 팁**: 이 프로젝트가 겪는 '에이전트 IP 차단으로 자막 못 가져옴'(YT-DLP/API 차단)의 정확한 해법 후보 — Glasp 스크레이프 대신 시도해볼 대안.

## 2. ★뚫는 원리 & 한계선(합법)★ · [01:11](https://youtu.be/vjSZIyYd0NI?t=71)
- **3줄 요약**
  - 지원 사이트: X·레딧·유튜브·해커뉴스·네이버·쿠팡·링크드인·미디엄·섭스택 등.
  - 원리: **합법 방법을 단계적으로 상승**시켜 될 때까지 시도(단일 클로드 코드는 다 막힘 ↔ Insane-search는 단계 상승으로 완수).
  - **한계선**: **로그인해야 볼 수 있는 것·결제해야 볼 수 있는 것은 우회하지 않음**(불법 배제) — 어디까지나 '공개된 것'만.
- **핵심 인용**: "수단과 방법을 가리지 않고 한다는 건 맞는데 이제 불법적인 방법 빼고."
- **내 질문**: '공개 데이터만'이라는 선은 이 프로젝트의 재사용 원칙과도 맞물림 — 자막이 공개(자동생성)면 수집 가능, 이 도구의 경계가 우리 워크플로우 정당성과 같은 결 아닐까?

## 3. 설치 — 플러그인 마켓 명령 한 줄 · [03:28](https://youtu.be/vjSZIyYd0NI?t=208)
- **3줄 요약**
  - 폴더 만들고(`mkdir`/드래그) `cd`로 이동 → 클로드 코드 실행 → 소개 페이지의 **설치 명령을 복사해 클로드 코드 안에서 실행**(내장 슬래시 명령이라 클로드 코드 세션 내부에서).
  - 마켓플레이스 add → `plugin install insane-search` → **reload plugins** 하면 그 세션부터 사용 가능.
  - 응원 방법은 **GitHub 별(star)** — 돈 안 들고 개발자 인기 투표(발표자 이득 없음 강조).
- **핵심 인용**: "인세인 서치는 이제 여기서 여러분들이 더 이상 할 게 없습니다. 평소에 데이터가 잘 안 가져와지던 거를 시도하면 된다."
- **내 팁**: 플러그인=스킬 등을 묶은 패키지 — 설치 후엔 자연어로 "이 데이터 가져와"만 하면 됨(앞 영상들의 스킬 패키징과 동일 UX).

## 4. 실증 — 유튜브 자막 + 네이버 핫딜 CSV · [06:26](https://youtu.be/vjSZIyYd0NI?t=386)
- **3줄 요약**
  - **유튜브**: "이 영상의 자막을 가져와" → Insane-search가 메타데이터+**한국어 자동생성 자막**을 텍스트로 추출 → 학습용 웹페이지로 정리도 가능.
  - **네이버 쇼핑 핫딜**: "여기 상품 싹 가져와 CSV로 저장" → 내부 API 탐색 등 온갖 시도를 알아서 → **308개 중복 제거까지** 깔끔히 CSV(3분). (브라이트데이터엔 없던 네이버가 이걸론 됨.)
  - 마케터의 **가격 비교·이벤트가 산정**에 바로 활용. 생 클로드 코드면 "이것도 해봐 저것도 해봐"를 다 시켜야 할 걸 **알아서 대신**.
- **핵심 인용**: "생 클로드 코드로 하면 이것도 해 봐, 저것도 해 봐 … 다 시켜야 되는데 그거를 알아서 해 준다."
- **내 질문**: 유튜브 자막을 플러그인이 바로 뽑는다면, 이 프로젝트의 Glasp ⌄ 픽셀클릭 수동 수집을 대체할 수 있는지 검증해볼 가치가 크지 않을까?

## 5. 쿠팡·알리 + 내부 API 원리 + 포지셔닝 · [12:10](https://youtu.be/vjSZIyYd0NI?t=730)
- **3줄 요약**
  - **쿠팡·알리익스프레스**(해외)도 시도 — 알리는 봇 탐지가 강해 제일 오래 걸리지만, 안 되면 **Playwright로 실제 브라우저까지 띄워** 완수하려 함.
  - **핵심 원리**: 화면 상품은 **내부 프리패치 API 콜**로 채워지고 그 위를 봇 방어가 감쌈 → 단순 크롤링은 방어에 막힘 → **내부 API 콜(공식 제공)을 찾아 직접 호출** → 불법 아님, 100개 호출도 쉬움.
  - 포지셔닝: **크롤링 강의가 필요 없어질 정도**. "바이브 코딩에만 집중 말고 일상 업무 지원 능력도 활용하라." 무료·업데이트 활발.
- **핵심 인용**: "페이지는 내부 API로 상품을 프리패치하기 때문에 … 그걸 찾아서 하겠다. 그래서 절대 불법적인 건 아닌 거예요."
- **내 팁**: '내부 API 콜 발견→호출'은 이 프로젝트에서 시도했던 InnerTube/timedtext 접근과 같은 계열 — Insane-search가 그 단계 상승을 자동화한 셈. 봇 탐지 회피가 핵심 가치.

## TL;DR (5줄)

1. **정체**: **Insane-search** = "브라우저로 보이면 에이전트도 봐야 한다"는 **한국산 클로드 코드 플러그인**(봇 탐지 403 해결).
2. **원리(★)**: **합법 방법을 단계적으로 상승**(내부 API 발견→Playwright)시켜 **공개 데이터를 될 때까지** 가져옴. **로그인·결제 뒤는 우회 안 함**.
3. **설치**: 폴더 이동 후 클로드 코드 내부에서 마켓 명령 한 줄(`plugin install`+reload). 응원은 GitHub 별.
4. **실증**: 유튜브 메타+**자막** 추출, 네이버 핫딜 **308개 CSV(3분)**, 쿠팡·알리익스프레스(내부 API 콜 호출). 마케터 가격 비교에 유용.
5. **의의(★)**: 크롤링 강의가 무색할 정도. ※ **이 프로젝트의 자막 수집(YT-DLP/API 차단) 대안**으로 검증 가치 큼 — Glasp 수동 수집을 대체할 후보.
