# 누구나 따라할 수 있는 카드뉴스 자동화 | 콘텐츠 제작 시간이 90% 줄어듭니다

> 한 줄 요약: 인스타 카드뉴스 제작(한 장 만들고 복사·색 맞추다 두세 시간)을 **클로드 디자인**으로 자동화 — 필요한 건 **가장 저렴한 유료 구독 하나**. 실수는 전체를 한 번에 자동화하려는 것 → 오늘은 **기획·이미지 준비가 끝난 뒤 '카드뉴스를 만들어내는 구간'만** 노림. 핵심 공식: **①브랜드 인스타 계정 명시 + ②디자인 가이드(디자인 MD)를 한 번만 넣기** → 그다음엔 **주제+이미지만 던지면** 템플릿대로 쫙 뽑힘. 편집은 이제 **피그마 같은 툴 느낌**(트윅=인덱스/해시태그 토글, 에디트=영역 직접 조작, 커멘트=말로 수정, 폰트 변경·Ctrl Z). **세션 하나가 카드뉴스 제작 공간** — 계속 그 안에서 주제·이미지만 교체. 가이드 문서가 없으면 **내가 만든 카드뉴스를 이미지로 넣어** 컨셉을 따르게 하거나 핀터레스트·미리캔버스·**모빈 MCP** 활용. 검수 포인트: **오타·수치·상업 폰트 라이선스**. 큰 메시지: 시간 절약을 넘어 **회사의 자산화**(담당자가 나가도 톤 유지, 사람에 의존 않는 시스템).

## 1. ★문제 정의 + 자동화할 구간만 노리기★ · [00:35](https://youtu.be/u_o-wrU7g-Y?t=35)
- **3줄 요약**
  - 인스타 카드뉴스는 한 장 만들고 복사, 색이 미묘하게 달라 계속 손대다 두세 시간 — 다음번에도 반복. 이를 클로드로 해결(가장 저렴한 유료 구독이면 충분).
  - 흔한 실수: **전체를 한 번에 AI 자동화**하려다 아무것도 못 만듦.
  - 오늘 목표는 딱 하나 — 기획·디자인·이미지 준비가 끝난 뒤 **실제 카드뉴스를 만들어내는 구간**만.
- **핵심 인용**: "여기서 실수하시는 게 이 전체를 한 번에 AI로 자동화하려고 하거든요. 그러다가 아무것도 못 만들고 끝나 버립니다."
- **내 팁**: '전 과정 자동화 대신 한 구간만'은 이 큐레이션 레인(3스테이지)·투쏠(기획 먼저)과 같은 분할 정복 — 범위를 좁혀야 완성된다는 공통 교훈.

## 2. ★핵심 공식 — 브랜드 명시 + 디자인 가이드 1회 주입★ · [01:09](https://youtu.be/u_o-wrU7g-Y?t=69)
- **3줄 요약**
  - 좌측 사이드→디자인. "인스타 카드뉴스 만들어줘" + **어떤 브랜드 계정인지**(예: 나이키 최근 신발 캠페인).
  - 카드뉴스는 브랜드 결이 중요 → **디자인 룰/템플릿**을 넣어야. 나이키는 **디자인 MD 사이트**(회사별 디자인 레퍼런스)에서 나이키 디자인 MD를 복사해 "컨셉은 이걸 참고".
  - 클로드가 알아서 질문(신발·장수·비율·카피) → 17장·4:5 등 선택 후 Continue → 블랙&화이트 나이키 느낌 결과.
- **핵심 인용**: "한 번만이라도 제대로 디자인에 대한 가이드를 넣어 놓으면 그다음엔 이미지만 주면 된다는 거예요."
- **내 질문**: '디자인 MD를 참고 자료로 주입'은 이 큐레이션 투쏠(디자인 MD 사이트)·에디스(디자인 시스템)와 같은 브랜드 고정 기법 — 디자인 MD가 사실상 표준 브랜드 컨텍스트 파일 아닐까?

## 3. ★편집 자유도 — 트윅·에디트·커멘트(피그마 느낌)★ · [03:01](https://youtu.be/u_o-wrU7g-Y?t=181)
- **3줄 요약**
  - 빈 자리에 준비한 이미지를 넣으면 제품 퀄리티로 들어감. **트윅**으로 인덱스(페이지 수)·해시태그 껐다 켜기.
  - **에디트**: 영역 선택해 직접 조작(배경색 변경). **커멘트**: 영역 클릭 후 "4개가 다 안 들어오고 잘려" → 프레임에 맞게 조절.
  - 클로드 디자인의 진화: 원래 결과물 수정 자유도가 낮았으나 이제 **피그마 같은 디자인 툴 느낌**(폰트 변경·Ctrl Z 에디터).
- **핵심 인용**: "이번에는 되게 디자인 툴 마치 피그마 같은 걸 쓰는 느낌… 폰트도 바꿀 수 있고 컨트롤 Z 하면 다시 돌아오는 것도."
- **내 팁**: 트윅·에디트·커멘트는 이 큐레이션 에디스(30분 마스터) 편의 같은 3편집 기능 — 두 편이 클로드 디자인 편집 UX를 상보적으로 설명.

## 4. ★재사용 — 세션 템플릿 + 이미지만 교체★ · [05:22](https://youtu.be/u_o-wrU7g-Y?t=322)
- **3줄 요약**
  - 매번 틀 만들기는 비효율 → **세션(카드뉴스 제작) 안에서 주제·이미지만 교체**. 마라톤 대회 가정: 달리기 이미지 넣고 "마라톤 행사 카드뉴스 5장" → 같은 나이키 테마 유지.
  - 이슈: **파일명이 한글이면 이미지가 안 들어감** → 영문 파일명으로 바꾸니 해결.
  - 저장: 쉐어→**PNG 한 장씩** 또는 프로젝트 **HTML 전체**. 가이드 문서가 없으면 **내가 만든 카드뉴스를 이미지로 넣어** 컨셉을 따르게 하거나 핀터레스트·미리캔버스·**모빈 MCP**.
- **핵심 인용**: "한 번만 제대로 디자인 가이드를 넣어 놓으면 그다음엔 이미지만 주면 된다… 세션 자체가 하나의 카드 뉴스 제작 공간이 된다."
- **내 질문**: '파일명 영문' 같은 실무 함정은 이 프로젝트 LESSONS의 실수 모음과 같은 성격 — 자동화의 성패는 이런 사소한 입력 위생에 갈리는 것 아닐까?

## 5. ★검수 포인트 + 회사 자산화★ · [09:33](https://youtu.be/u_o-wrU7g-Y?t=573)
- **3줄 요약**
  - 결과의 **오타·수치·숫자는 직접 검수**, **상업 폰트 라이선스** 확인. 디자인 가이드 없이 만들면 무난한 아무거나(나이키는 온라인 정보가 많아 예외).
  - 그래서 **디자인 가이드가 정말 중요**. 회사라면 담당자가 나가면 톤이 무너지거나 발행이 멈추는데, 파일을 만들어 두면 **회사의 시스템**이 됨.
  - 카드뉴스뿐 아니라 영상·마케팅·제안서 모두 동일. 시간 절약을 넘어 **자산화** — 사람·컨디션에 의존하지 않고 같은 스타일로 계속 배포.
- **핵심 인용**: "이 파일을 만들어 놓으면 이게 우리 회사의 마치 시스템이 되는 거예요. 사람에 의존하지 않고… 계속 배포할 수 있는 거죠."
- **내 팁**: '가이드 파일=시스템=자산'은 이 프로젝트의 build_gallery·디자인 시스템 정본화와 같은 철학 — 산출물이 아니라 재현 규칙을 자산으로 남기는 것.

## TL;DR (5줄)

1. **범위(★)**: 전체 자동화 대신 '카드뉴스 만들어내는 구간'만. 가장 저렴한 클로드 구독이면 충분.
2. **공식(★)**: 브랜드 계정 명시 + **디자인 가이드(디자인 MD) 1회 주입** → 이후 주제+이미지만.
3. **편집**: 트윅(인덱스·해시태그)·에디트(영역 직접)·커멘트(말로 수정)·폰트·Ctrl Z — 피그마 느낌.
4. **재사용**: 세션 하나가 제작 공간, 이미지만 교체(파일명 영문 주의). 저장은 PNG/HTML. 가이드 없으면 내 카드뉴스 이미지·핀터레스트·모빈 MCP.
5. **검수·자산화(★)**: 오타·수치·상업 폰트 확인. 디자인 가이드=회사 시스템/자산 → 사람에 의존 않고 톤 유지.
