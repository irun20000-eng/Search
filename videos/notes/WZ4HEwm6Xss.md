# [바이브디자인] AI 가챠뽑기는 그만! 클로드코드에서 디자이너가 정확히 원하는대로 작업하는 방법

> 한 줄 요약: '가챠 뽑기'식 AI 디자인을 끝내고 **디자이너가 정확히 통제**하는 실무 워크플로우. 도구는 **클로드 데스크탑 앱**(CLI 아님) — 코드 탭의 클로드 코드로 작업. 흐름: ①프로젝트 폴더 세팅→②기획(레고 공식몰)+디자인 컨셉(핀터레스트 **네오브루탈리즘** 레퍼런스 3장)을 주고 **HTML/CSS로 7분 만에 랜딩 초안** 생성(반응형+퍼블리시까지). ★핵심 통찰: 이제 이 결과물이 **디폴트 베이스** — 누구나 이 수준은 만드니 디자이너는 여기서부터 **감각으로 폴리싱**해야 살아남는다. ②**디자인 폴리싱**: 클로드 데스크탑의 **브라우저 기능+셀렉트**로 요소를 클릭 선택→"이거 폰트/컬러 바꿔줘"(터미널로 말로 지정하는 번거로움 제거). 이미지는 프롬프트로 그리지 말고 **따로 생성**(피그마 메이크·GPT·제미나이)해 **에셋 폴더**로. ★모델 전략: 자잘한 디자인 수정은 **소넷5로 충분**(고급 모델은 토큰 낭비), 초기 UX·BM·기획에만 옵스/페이블. 마무리: **깃 레포 주소만 주면 클로드가 커밋/푸시**, 개발 후 수정은 **디자인 브랜치**로("기능은 절대 건드리지 말 것" 선언). 이 방식으로 실무 제작 기간을 압도적 단축, 피그마↔개발 왕복 노가다 제거.

## 1. ★도구·마인드 — 클로드 데스크탑 앱 + "막히면 AI에게 물어라"★ · [00:38](https://youtu.be/WZ4HEwm6Xss?t=38)
- **3줄 요약**
  - 바이브 디자인이 대세지만 직접 디자인 능력+AI 효율을 함께. **피그마를 거치지 않고** AI로 UI 디자인(클로드 프로 필요).
  - 도구는 **클로드 데스크탑 앱**의 코드 탭(=클로드 코드). CLI(터미널)보다 디자인에 효과적(후술).
  - ★강력한 팁: 모르거나 막히면 **무조건 AI에게 물어보기**. AI 공부의 최고 선생은 다른 AI. 설치 문제도 홈 채팅에서 "클로드 코드 쓰려면 뭘 설치?"로 해결.
- **핵심 인용**: "AI 공부에 있어서 가장 훌륭한 선생님은 다른 AI고, 적극적으로 AI에게 물어보면서 헤쳐 나가는 게 가장 실력이 빨리 늘고."
- **내 팁**: 'CLI 대신 데스크탑 앱'은 이 갤러리 구씨(MCP vs CLI) 편과 반대 결처럼 보이나 목적이 다름 — 여기선 **시각 편집(브라우저 셀렉트)** 때문에 GUI 앱을 택함.

## 2. ★7분 랜딩 초안 — 기획(공식몰)+컨셉(네오브루탈리즘 레퍼런스)★ · [03:21](https://youtu.be/WZ4HEwm6Xss?t=201)
- **3줄 요약**
  - 프로젝트 폴더 경로를 AI에게 주고 새 프로젝트 지시. 구현 방식은 배포 없는 예제라 **순수 HTML/CSS**(배포용이면 넥스트JS=SSR·SEO 유리).
  - 기획은 **레고 공식몰(영어)** 랜딩을 그대로 참고, 단 본뜨면 의미 없으니 컨셉은 다르게 — 핀터레스트 "네오브루탈리즘 웹디자인" **레퍼런스 3장**을 첨부.
  - 프롬프트 두 줄+레퍼런스로 **7분 만에 반응형 랜딩** 생성(디자인+프론트엔드 퍼블리시). 기능만 붙이면 출시 가능.
- **핵심 인용**: "이제부터는 이 결과물을 디폴트 베이스로 시작을 해야 된다는 점이에요."
- **내 질문**: '공식 기획 참고 + 레퍼런스로 컨셉 차별화'는 이 갤러리 잭피디·데키랩 웹 생성 편과 같은 레퍼런스 기반 — 차이는 여기서 **디자이너 통제**를 강조하는 점 아닐까?

## 3. ★디자이너 생존 + 모델 전략(소넷5로 충분)★ · [09:09](https://youtu.be/WZ4HEwm6Xss?t=549)
- **3줄 요약**
  - 링크+레퍼런스 3장으로 이 수준이 나오니 **누구나 만드는 세상** → 디자이너는 여기서부터 **감각·능력**으로 아쉬운 점을 보고 개선할 수 있어야 살아남음.
  - ★모델: 디자이너가 다듬을 수 있으면 **자잘한 디자인 수정은 소넷5로 충분**. 고급 모델(옵스·페이블)은 **초기 UX·BM·기획** 등 고도 추론에만.
  - 자잘한 수정에 고급 모델을 쓰면 **토큰 낭비 심함** — 작업 성격에 맞춰 모델 배분.
- **핵심 인용**: "자잘한 디자인 수정 같은 걸 할 때 고급 모델을 쓰면 토큰 낭비가 정말 심하니까."
- **내 팁**: '작업 성격별 모델 배분(설계=고급, 수정=경량)'은 이 큐레이션 에디스(와이어프레임)·오빠두엑셀(2단계 분리)와 같은 토큰 경제 원칙.

## 4. ★디자인 폴리싱 — 브라우저 셀렉트 + 에셋 분리★ · [09:52](https://youtu.be/WZ4HEwm6Xss?t=592)
- **3줄 요약**
  - **디자인 폴리싱**: 로고·아이콘 통일·더미 상품→실제 이미지·불필요 배너 제거 등. 클로드 데스크탑의 **브라우저 기능**으로 화면 보며 작업.
  - ★**셀렉트로 요소를 클릭 선택**→클로드가 자동 인지 → "이거 폰트/컬러 바꿔줘"로 수정. 터미널로 "히어로 브라우저 테마 배경색을 흰→파랑"처럼 말로 지정하는 번거로움 제거.
  - **이미지는 프롬프트로 그리면 불확실**하니 따로 생성(피그마 메이크·GPT·제미나이) → **에셋 폴더**에 분류해 소스 적용. 대략적 구도는 사람이 더 빠를 수 있음(AI 100% 집착 불필요).
- **핵심 인용**: "셀렉터로 셀렉트 할 경우… 클로드가 자동으로 인지를 하기 때문에 너무 구구절절하게 설명하지 않고 이거의 폰트를 바꿔 줘."
- **내 질문**: '클릭 선택→맥락 자동 전달'은 클로드 코드 브라우저 도구의 시각적 컨텍스트 주입 — 텍스트로 좌표·이름을 설명하는 비용을 없애는 UI 아닐까?

## 5. 마무리 — 깃 커밋/푸시 자동화 + 디자인 브랜치 협업 · [20:15](https://youtu.be/WZ4HEwm6Xss?t=1215)
- **3줄 요약**
  - 완성본을 **깃허브에 올림**: 이제 명령어 순차 입력 대신 **깃 레포 주소만 주면 클로드가 커밋/푸시**.
  - 개발자가 파일 받아 개발, 이후 디자인 수정은 **디자인 브랜치**로(개발자와 상의해 브랜치 파고 풀). 수정 시 **"만들어진 기능은 절대 건드리지 말 것" 선언** 후 시작.
  - 디자인 브랜치에 커밋 푸시→개발자 확인 후 최종 병합. 이 방식으로 **제작 기간 압도적 단축**, 피그마↔개발 왕복 코멘트·퍼블리싱 노가다 제거. (Config 2026 **코드 레이어** 출시 기대)
- **핵심 인용**: "이 방식이 제가 최근 몇 달간 실무에서 디자인을 할 때 진행하는 방식이었고, 전체 제작 기간을 압도적으로 단축시킬 수 있었습니다."
- **내 팁**: '디자인 브랜치로 기능 보호하며 협업'은 이 프로젝트의 브랜치 작업·기능 보존 원칙과 동일 — 디자이너도 깃 워크플로우에 편입되는 실무 모델.

## TL;DR (5줄)

1. **도구·마인드(★)**: 클로드 데스크탑 앱(코드 탭). 막히면 무조건 AI에게 물어라 — 최고 선생은 다른 AI.
2. **7분 초안(★)**: 폴더 세팅→공식몰 기획+핀터레스트 네오브루탈리즘 레퍼런스→HTML/CSS 반응형 랜딩. 이게 디폴트 베이스.
3. **디자이너 생존+모델(★)**: 누구나 이 수준 → 감각으로 폴리싱해야 생존. 자잘한 수정은 소넷5(고급은 초기 기획·토큰 절약).
4. **폴리싱(★)**: 브라우저 셀렉트로 요소 클릭→"이거 바꿔줘". 이미지는 따로 생성해 에셋 폴더. 사람이 빠른 건 사람이.
5. **협업**: 깃 레포 주소만 주면 클로드가 커밋/푸시. 디자인 브랜치로 수정("기능 건드리지 마" 선언). 피그마↔개발 노가다 제거.
