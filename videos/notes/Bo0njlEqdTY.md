# 확 바뀐 제미나이: 모르고 있던 기능들이 이렇게나 많다고? (프롬프트 제공)

> 한 줄 요약: 메뉴 자리가 바뀐 제미나이 화면을 **예약·맞춤 설정(커넥터·노트북·스킬)·노트북** 세 군데로 먼저 훑고, **사내 AI 활용 간담회 준비**라는 하나의 업무를 끝까지 끌고 가며 기능을 붙여 쓴다. 입력창 아래 **채팅과 작업 모드**를 단골 카페의 바리스타와 키오스크로 가른 뒤, 자주 쓰는 보고서 요청을 **업무 보고 스킬**로 저장하고, 채팅 한 문장으로 **조회수 5천 이상·최근 3개월 이내 영상 열 개를 찾아 노트북까지 만들어 달라고** 맡겨 참고 자료로 쓴다(조건이 지켜졌는지는 열어서 확인하라고 덧붙인다). 그 노트북을 켠 상태에서 **골뱅이로 스킬을 불러**(예전에는 스킬이 슬래시·커넥터가 골뱅이였는데 **모두 골뱅이로 통합**됐다) 기획안을 쓰고 **구글 문서로 내보내고**, 대화가 뒤섞이지 않게 **브랜치 생성**으로 갈라 안내 메일과 **구글 폼 응답 시 접수 확인 메일을 자동 발송하는 앱스 스크립트**를 받아 **양식 제출 시 트리거**까지 걸어 테스트한다. 마지막은 **작업 모드**에 단일 HTML 3D 스트레칭 앱을 맡겨 **2분 정도**에 받아 보지만, **플랭크 자세가 뒤집혀** 한 번 더 수정을 요청한다.

## 1. 자리가 바뀐 화면에서 오늘 볼 세 군데 · [00:00](https://youtu.be/Bo0njlEqdTY?t=0)
- **3줄 요약**
  - 출발점은 **메뉴가 낯설어진 상태**다. 업데이트가 이어지면서 익숙했던 메뉴의 자리가 바뀌고 처음 보는 메뉴도 많아져, 막상 업무에 쓰려 하면 어디서 시작할지 막막하다는 데서 영상이 시작한다.
  - 화면 왼쪽에서 오늘 볼 메뉴로 **예약 · 맞춤 설정 · 노트북**을 꼽는다. **예약**은 정해진 시간에 같은 작업을 반복해 실행하고 싶을 때 쓰는 기능이고, 개인 구글 계정으로 쓰려면 **만 18세 이상**이어야 하며 **제미나이 활동 기록을 보관하도록 설정**해야 한다고 조건을 밝힌다.
  - **맞춤 설정**에서는 실습에 필요한 세 가지를 확인한다 — 상단 **커넥터**에서 **구글 워크스페이스가 연결되어 있는지**(연결해 두면 채팅에서 구글 드라이브 자료를 불러오거나 메일·캘린더 등과 연동할 수 있다), 그 아래 **제미나이 노트북**(보통 기본으로 연결되어 있고 채팅에서 새 노트북을 만들고 참고 자료도 추가할 수 있다), **스킬** 메뉴(기본 제공 스킬과 내가 만든 스킬을 보고 **만들기**로 자주 쓰는 프롬프트나 문서 양식을 저장해 둔다)다. 왼쪽 **노트북**은 프로젝트별로 자료를 모아 두는 공간으로 소개한다.
- **핵심 인용**: "재미나이가 계속 업데이트되면서 익숙했던 메뉴도 자리가 바뀌고 처음 보는 메뉴도 많아져서 막상 업무해 쓰려고 하면 어디서부터 어떻게 시작해야 할지 좀 막막한 거 같으시죠?"
- **내 팁**: 실습을 따라가기 전에 **커넥터의 구글 워크스페이스 연결 상태**부터 확인해 두는 편이 낫다. 뒤에서 구글 문서로 내보내기·메일 초안·캘린더 등록이 연달아 나오는데, 영상의 순서는 그 연결을 전제로 진행된다.

## 2. ★채팅과 작업 모드 — 바리스타와 키오스크★ · [02:06](https://youtu.be/Bo0njlEqdTY?t=126)
- **3줄 요약**
  - 새 채팅을 열면 입력창 아래에 **채팅**과 **테스크**가 있고, 영상은 이 테스크를 **작업 모드**라고 부르기로 한다. **채팅**은 단골 카페에서 바리스타와 메뉴를 고르는 것에 가깝다 — 한 번씩 의견을 주고받으며 원하는 결과에 가까워지는 방식이다.
  - **작업 모드**는 키오스크에서 주문하는 쪽이다. 원하는 결과물과 필요한 조건이 **구체적으로 정해져 있을 때** 쓰고, **분량이 긴 문서나 여러 기능이 들어가는 웹**처럼 한 번에 맡기고 싶은 작업에 쓴다고 정리한다.
  - 입력창 주변도 함께 짚는다 — **플러스 버튼**으로 드라이브나 노트북에서 참고 자료를 가져오고, 문서·코드를 따로 보면서 다듬고 싶을 때는 **캔버스**, 웹에서 여러 출처를 찾아 깊이 조사할 때는 **딥 리서치**를 고른다. 오른쪽에서는 **모델과 사고 수준**을 고르는데, 영상은 기존 모델 외에 **하이드로젠·아르곤·카본이라는 새 이름들이 보인다**고 말하고 그중 하이드로젠은 **응답이 빠르면서 성능도 뛰어나고 모든 사용자가 무료로 쓸 수 있다**고 소개한다. 사고 수준은 **낮음·보통·높음** 중에서 고른다.
- **핵심 인용**: "작업 모드는 키오스크에서 주문하는 것과 같습니다. 원하는 메뉴가 정해져 있으면 버튼을 누르고 결과를 기다리죠. 즉 만들고 싶은 결과물과 필요한 조건이 구체적일 때 써 보시면 됩니다."
- **내 팁**: 둘의 갈림길은 **결과물이 머릿속에 다 그려져 있는가**다. 조건을 아직 정하지 못한 일을 작업 모드에 던지면 키오스크에서 메뉴를 고민하는 셈이니, 조건을 채팅으로 먼저 다듬고 확정된 뒤에 작업 모드로 옮기는 순서가 안전하다.

## 3. 쓸 일을 하나 정하고, 반복 요청을 스킬로 저장한다 · [03:33](https://youtu.be/Bo0njlEqdTY?t=213)
- **3줄 요약**
  - 실습의 가정은 **사내 AI 활용 간담회 준비**다. 참고 영상을 모으고 늘 쓰는 보고서 양식으로 기획안을 만든 다음, **안내 메일과 참석 신청 자동화**까지 이어 가고, 마지막에 간담회에서 소개할 **직원용 3D 스트레칭 앱**도 만든다는 순서를 미리 밝힌다.
  - 스킬을 만드는 이유를 반복 비용으로 설명한다 — 행사 기획안을 쓸 때마다 개요는 두세 줄로, 시간표는 표로 만들어 달라고 매번 설명하려면 번거롭다. 이런 요청을 **한 번 저장해 두면 다음 행사에서도 같은 양식을 바로 불러올 수 있다**.
  - 경로는 왼쪽에서 **맞춤 설정 → 스킬 → 만들기 → 수동으로 만들기** 순이다. 이름은 **업무 보고**, 요청 사항에는 **한 해 보고에 적합한 공식적이고 격식 있는 어조의 기획안을 작성해 달라는 문장**과 상세 내용을 넣고 **만들기**를 누르면 스킬 목록에 나타난다.
- **핵심 인용**: "회사에서 형사 기회관을 쓸 때마다 개요는 두 세 줄로 써 줘, 시간표는 표로 만들어 줘라고 설명하려면 번거롭죠."
- **내 팁**: 첫 스킬은 **이미 여러 번 써 본 문서 하나**로 잡는 편이 낫다. 영상이 마지막에도 같은 조언을 하는데, 양식이 머릿속에 있는 문서여야 저장할 요청 사항을 적어 넣을 수 있다.

## 4. 한 문장으로 영상 열 개를 찾아 노트북까지 만들기 · [04:43](https://youtu.be/Bo0njlEqdTY?t=283)
- **3줄 요약**

- **핵심 인용**: "유튜브에서 직장인 재미나의 실무 활용에 관한 영상 중 조회수 5천 이상 업로드 날짜 최근 3개월 이내인 영상 열개를 찾아서 노트북 AI 실무 레퍼런스를 생성한 후에 소스로 넣어줘."
- **내 팁**: 조건을 적었다는 것과 **지켜졌다는 것은 다른 일**이다. 영상도 날짜와 조회수를 열어 확인하라고 시키니, 노트북이 생겼다는 알림만 보고 넘어가지 말고 소스 목록을 한 번 훑어 보는 편이 좋다.

  - 요청은 **구글 폼으로 신청이 들어오면 신청자에게 접수 완료 안내 메일이 자동 발송되도록 구글 스프레드시트용 앱스 스크립트 코드를 짜 달라**는 것이다. 코드가 나오면 **설치 및 트리거 설정 방법까지** 함께 알려 준다.
  - 적용 순서는 신청 폼 → **응답 → 시트에서 보기** → 그 시트에서 **확장 프로그램 → 앱스 스크립트** → 기존 코드를 지우고 붙여 넣어 저장, 이어서 **시계 모양 메뉴 → 트리거 → 트리거 추가**에서 이벤트 소스를 **스프레드시트**, 이벤트 유형을 **양식 제출 시**로 고르고 저장한다. 권한 승인 팝업에서는 **프로젝트 이름으로 이동한 뒤 허용**을 누르고, **오류처럼 보이는 창이 떠도 계속 허용**하면 된다고 안내한다. 테스트 응답을 넣어 **응답 시트의 발송 상태가 발송 완료**로 바뀌는 것과 실제 메일이 간 것까지 확인한다.
- **핵심 인용**: "복잡한 코드 내용은 모르셔도 됩니다. 우리는이 코드를 복사해서 사용하기만 하면 되는데요."
- **내 팁**: 트리거를 걸었으면 **자기 주소로 테스트 응답을 한 번 넣어 보는 것**까지가 한 묶음이다. 영상도 발송 상태 표시와 실제 받은 메일을 둘 다 열어 봤는데, 둘 중 하나만 보면 권한 승인이 덜 끝난 상태를 못 잡는다.

## TL;DR (5줄)
1. **화면 먼저**: 왼쪽의 예약·맞춤 설정·노트북을 훑고, 맞춤 설정에서 커넥터의 구글 워크스페이스 연결·제미나이 노트북·스킬 세 자리를 확인하는 것으로 시작한다.
2. **두 모드의 갈림길**: 채팅은 주고받으며 다듬는 자리, 작업 모드는 결과물과 조건이 구체적일 때 한 번에 맡기는 자리이고, 모델과 사고 수준(낮음·보통·높음)은 오른쪽에서 고른다.
3. **반복을 스킬로**: 맞춤 설정 → 스킬 → 만들기 → 수동으로 만들기로 업무 보고 스킬을 저장해 두면, 다음 행사에서는 골뱅이로 불러 달라진 정보만 알려 주면 된다(스킬·커넥터 호출이 골뱅이로 통합됐다).
4. **대화를 갈라 두기**: 기획안 답변 아래 브랜치 생성으로 대화를 이어받은 새 채팅을 열어 안내 메일과 앱스 스크립트를 처리하면, 기획안은 원래 방에 남아 나중에 찾기 쉽다.
5. **자동화와 검증**: 구글 폼 응답 시 접수 확인 메일이 나가도록 앱스 스크립트를 붙이고 양식 제출 시 트리거를 걸어 테스트하며, 작업 모드로 2분 만에 받은 3D 스트레칭 앱도 플랭크 자세가 뒤집혀 한 번 더 고쳐야 했다.
