# 평균이라는 착시(Size Bias) — 이해편

> 목표: "평균 말고 중앙값을 보라"에서 한 걸음 더 들어가, **평균이 부풀려지는 두 가지 서로 다른 이유**를 구분하고 직접 계산해 보기. 분포 추정과 가중평균의 일반형은 확장편 [[평균이라는 착시 확장편]] 으로.

## TL;DR
- 평균은 거짓말하지 않는다. 다만 **누구를 세었는지**에 따라 전혀 다른 값이 된다.
- **첫째 이유 — 쏠림.** 오른쪽 꼬리가 길면 평균이 중앙값보다 커진다. 2025년 우리나라 가구 **평균 순자산은 4억 7,144만 원**인데, 상위 20%는 11억 1,365만 원, 하위 20%는 1억 4,244만 원이다 [1(국내)].
- 그래서 정부는 복지 기준선에 평균이 아니라 **중위값**을 쓴다. 2026년 기준 중위소득은 4인 가구 **649만 4,738원** — 이름부터 '중위'다 [2(국내)][3(국내)].
- **둘째 이유 — 크기 편향.** 큰 집단이 뽑힐 확률이 크면 평균이 저절로 부풀려진다. 학교가 계산한 평균 학급 인원과 **학생이 실제로 겪는** 평균 학급 인원이 다르다 [7].
- 이 부풀림에는 정확한 크기가 있다. **σ² ÷ μ** 만큼이다. 같은 공식이 "내 친구는 나보다 친구가 많다"(Feld 1991)와 "버스는 늘 더 오래 기다린다"를 동시에 설명한다 [6][8].

## 핵심 포인트
1. **평균과 중앙값이 다르다는 건 오류가 아니라 정보다.** 둘의 차이가 곧 분포의 비뚤어짐이다 [4(국내)].
2. **평균이 부풀려지는 이유는 하나가 아니다.** 쏠림(꼬리)과 크기 편향(뽑히는 방식)은 서로 다른 문제다 [7][8].
3. **"누구를 단위로 세었나"가 값을 정한다.** 학급을 세면 36명, 학생을 세면 64명 — 같은 학교다 [7].
4. **부풀림의 크기는 분산에 비례한다.** 흩어짐이 없으면 착시도 없다 [6].
5. **중앙값이 늘 옳은 것도 아니다.** 총액이 필요한 문제에서는 평균이 맞는 답이다.

## 1. 평균은 무엇을 말하고 무엇을 말하지 않나

평균은 **총합을 인원수로 나눈 값**이다. 그러니 평균이 정확히 답하는 질문은 하나다 — **"전부 똑같이 나눠 가지면 얼마씩인가?"**

이건 유용한 질문이다. 예산을 짤 때, 총량을 추정할 때는 평균이 맞다. 평균 급여 × 직원 수 = 인건비 총액이다. 중앙값으로는 이 계산이 안 된다.

문제는 우리가 평균에게 **다른 질문**을 던질 때 생긴다. **"보통 사람은 얼마인가?"** 평균은 이 질문에 답하도록 만들어지지 않았다.

중앙값은 **줄을 세웠을 때 정확히 한가운데 있는 값**이다. 이쪽이 "보통"에 가깝다. 오른쪽 꼬리가 긴 분포에서 평균이 중앙값보다 커지는 것은 왜도(skewness)의 정의에서 바로 따라 나온다 [5]. 한 사람이 아무리 큰 값을 가져도 중앙값은 꿈쩍하지 않는다.

## 2. 첫째 함정 — 쏠림

우리나라 가구 자산은 오른쪽 꼬리가 아주 긴 분포다. 2025년 가계금융복지조사(국가데이터처·금융감독원·한국은행 공동, 약 2만 가구)를 보자 [1(국내)].

| 구분 | 순자산 |
|---|---|
| 전체 **평균** | **4억 7,144만 원** |
| 소득 5분위(상위 20%) 평균 | 11억 1,365만 원 |
| 소득 1분위(하위 20%) 평균 | 1억 4,244만 원 |

전체 평균 4.7억은 상위 20%(11.1억)와 하위 20%(1.4억) **어느 쪽의 삶도 설명하지 못한다.** 이게 평균이라는 착시의 첫 얼굴이다.

여기서 국내 제도가 하나의 답을 보여 준다. **기초생활보장 급여의 기준선은 평균소득이 아니라 중위소득이다.**

> **기준 중위소득**: 보건복지부장관이 중앙생활보장위원회 심의·의결을 거쳐 고시하는 **국민 가구소득의 중위값** [2(국내)]

2026년 기준 중위소득은 4인 가구 **649만 4,738원**(2025년 609만 7,773원 대비 6.51% 인상), 1인 가구 **256만 4,238원** [3(국내)].

정부가 굳이 중위값을 쓰는 이유는 분명하다. **소득 분포가 오른쪽으로 쏠려 있어, 평균을 기준선으로 잡으면 지원 대상이 실제보다 좁아진다.** 제도가 이미 이 착시를 알고 설계돼 있는 셈이다.

## 3. 손으로 확인하기 — 학급 규모의 역설

두 번째 함정은 성격이 완전히 다르다. **쏠림이 없어도 일어난다.**

어느 학교에 강좌가 5개 있다. 수강 인원은 다음과 같다.

```
20명 · 20명 · 20명 · 20명 · 100명   (합계 180명)
```

**학교가 계산한 평균 학급 인원**

```
(20 + 20 + 20 + 20 + 100) ÷ 5 = 180 ÷ 5 = 36명
```

이제 **학생에게 물어보자.** "네 강의는 몇 명이야?"

- 20명짜리 강의를 듣는 학생은 80명 → 각각 "20명"이라고 답한다
- 100명짜리 강의를 듣는 학생은 100명 → 각각 "100명"이라고 답한다

**학생이 겪는 평균 학급 인원**

```
(20×80 + 100×100) ÷ 180 = (1,600 + 10,000) ÷ 180 = 11,600 ÷ 180 ≈ 64.4명
```

| 누구를 세었나 | 평균 학급 인원 |
|---|---|
| 강좌를 셌다 (학교 관점) | **36명** |
| 학생을 셌다 (학생 관점) | **64.4명** |

**둘 다 맞다.** 계산에 틀린 데가 없다. 다만 **세는 단위가 다르다.** 조사·연구에서도 집단 관점과 개체 관점을 섞으면 같은 자료가 다른 결론을 낳는다 [9].

1977년 펠드와 그로프먼이 이 현상을 **'학급 규모의 역설(class size paradox)'** 이라 이름 붙이고 한 대학의 49개 학과 자료로 보였다. 대학 행정은 평균 학급 규모만 보는데, **학생들이 실제로 겪는 규모는 그 두 배가 넘었다** [7].

## 4. 왜 이런 일이 생기나 — 크기 편향의 공식

학생을 단위로 세면, **큰 강의가 그만큼 여러 번 세어진다.** 100명짜리 강의는 100번, 20명짜리는 20번. 이렇게 **크기에 비례해 뽑히는** 것을 **크기 편향(size bias)** 이라고 한다.

식으로 쓰면 이렇다. 집단 크기를 X라 할 때

```
집단을 세었을 때 평균  =  E[X]           = μ
개체를 세었을 때 평균  =  E[X²] / E[X]
```

그리고 `E[X²] = σ² + μ²` 이므로

```
개체 관점 평균 =  (σ² + μ²) / μ  =  μ  +  σ²/μ
```

**부풀림의 크기가 정확히 σ²/μ 다.** 위 학교로 확인해 보자.

```
μ  = 36
σ² = E[X²] − μ² = 11,600/5 − 36² = 2,320 − 1,296 = 1,024   (σ = 32)
μ + σ²/μ = 36 + 1,024/36 = 36 + 28.4 = 64.4 ✓
```

앞의 64.4명과 정확히 같다.

이 식이 알려 주는 것이 하나 더 있다. **σ² = 0 이면 부풀림도 0이다.** 모든 강의가 36명이면 두 평균이 같아진다. **착시를 만드는 것은 크기 자체가 아니라 크기의 흩어짐이다.**

## 5. 같은 공식, 다른 얼굴 — 내 친구는 왜 나보다 친구가 많나

1991년 사회학자 **스콧 펠드**가 『미국 사회학 저널』에 낸 논문 제목이 이렇다 — **"Why Your Friends Have More Friends Than You Do"** [6].

농담이 아니다. 거의 모든 관계망에서 **평균적인 사람은 자기 친구들보다 친구가 적다.** 이유는 3장과 똑같다.

작은 관계망으로 확인해 보자. 한가운데 한 명(A)이 있고 나머지 넷(B·C·D·E)이 A와만 친구인 별 모양이다.

```
친구 수:  A=4,  B=1,  C=1,  D=1,  E=1
```

**사람을 세었을 때 평균 친구 수**

```
(4 + 1 + 1 + 1 + 1) ÷ 5 = 8 ÷ 5 = 1.6명
```

**"친구"를 세었을 때 평균 친구 수** — 친구 관계 8개를 하나씩 따라가 상대의 친구 수를 적으면

```
(4² + 1² + 1² + 1² + 1²) ÷ 8 = 20 ÷ 8 = 2.5명
```

| 관점 | 평균 |
|---|---|
| 나 자신 | **1.6명** |
| 내 친구들 | **2.5명** |

공식으로도 맞다. `σ² = 20/5 − 1.6² = 4 − 2.56 = 1.44`, `1.6 + 1.44/1.6 = 2.5` ✓

**친구가 많은 사람은 여러 사람의 친구 목록에 들어간다.** 친구가 없는 사람은 아무의 목록에도 없다. 그래서 "친구를 통해 본 세상"은 언제나 인기 있는 쪽으로 기울어 있다.

펠드는 여기에 한 줄을 덧붙였다. **사람들이 자기를 친구와 비교하면, 대부분이 자기가 부족하다고 느끼게 된다.** SNS를 보며 느끼는 감정에는 이런 수학적 이유도 한 겹 깔려 있다.

## 6. 버스는 왜 늘 더 오래 기다리게 되나

배차 간격이 **5분과 15분이 번갈아** 오는 노선이 있다. 안내문에는 이렇게 적힌다 — **"평균 배차 간격 10분"**.

아무 때나 정류장에 도착하면 얼마나 기다릴까? "평균 10분 간격이니 평균 5분"이 상식적인 답이지만 틀렸다.

**내가 5분 구간에 도착할 확률은 5/20 = 25%, 15분 구간에 도착할 확률은 15/20 = 75%다.** 긴 구간이 더 넓으니 거기 걸릴 확률이 크다.

```
내가 겪는 배차 간격의 평균 = (5² + 15²) ÷ (5 + 15) = 250 ÷ 20 = 12.5분
평균 기다리는 시간 = 12.5 ÷ 2 = 6.25분      (상식적 답 5분보다 25% 길다)
```

또 `E[X²]/E[X]` 다. 이걸 **검사 역설(inspection paradox)** 이라고 부른다 [8].

승객은 "버스가 늘 늦는다"고 느끼고 회사는 "평균 10분 지켰다"고 말한다. **둘 다 사실이다.**

## 7. 평균을 만나면 물을 것 셋

| 물음 | 무엇을 잡아내나 |
|---|---|
| ① 중앙값은 얼마인가 | 쏠림 — 평균과 크게 다르면 꼬리가 길다 |
| ② **무엇을 하나로 세었나** | 크기 편향 — 강좌인가 학생인가, 노선인가 승객인가 |
| ③ 가장 큰 값 하나를 빼면 어떻게 되나 | 한 개체가 전체를 끌고 있는지 |

카드뉴스가 ①과 ③을 다뤘다면, **이해편에서 새로 얻는 것은 ②** 다. 그리고 실무에서 놓치기 쉬운 쪽도 ②다. 중앙값은 그래도 습관이 되어 있지만, **"이 표의 한 줄은 무엇인가"** 는 잘 묻지 않는다.

## 8. 한계 — 중앙값 만능주의도 착시다

- **총액이 필요하면 평균이 맞다.** 예산·매출·인건비는 평균 × 개수로 계산된다. 중앙값으로는 총액이 안 나온다.
- **중앙값도 분포를 다 말하지 않는다.** 중앙값이 같아도 흩어짐이 전혀 다를 수 있다. 그래서 통계는 대개 **평균·중앙값·분위수**를 함께 낸다 [1(국내)].
- **크기 편향은 '틀린 값'이 아니다.** 학생이 겪는 64.4명은 학생 관점에서 옳은 값이다. 문제는 **한쪽 값을 다른 쪽 질문에 쓸 때** 생긴다.
- **어느 쪽을 봐야 하는지는 목적이 정한다.** 교실을 몇 개 지을지 정할 때는 학급 기준, 수업의 질을 볼 때는 학생 기준이다.

## 9. 한 줄로 남기면

> **평균을 묻기 전에 "이 표의 한 줄이 무엇인지"를 먼저 물어야 한다.**

같은 학교가 36명이 되기도 하고 64명이 되기도 한다. 숫자가 바뀐 게 아니라 **세는 단위가 바뀐 것**이다.
