# 표본평균의 평균과 분산 — 이해편

> 목표: `E(X̄) = μ` 와 `V(X̄) = σ²/n` 을 외우는 대신 **왜 그렇게 되는지**를 종이 위에서 확인하기. 주사위 두 개로 실제 값을 세어 공식과 맞춰 보고, **평균은 그대로인데 분산만 줄어든다**는 것이 무슨 뜻인지까지 간다. 교과 단원은 확률과 통계의 통계 파트다 [1].

## TL;DR
- 표본평균 X̄ 는 **숫자가 아니라 확률변수**다. 표본을 다시 뽑으면 값이 달라지므로, 그 자체가 평균과 분산을 가진다 [1][2].
- **평균은 안 변한다** — `E(X̄) = μ`. 모집단의 평균이 그대로 나온다. 표본평균이 모평균의 **비편향추정량**이라는 말이 이 뜻이다 [2].
- **분산은 n 으로 나뉜다** — `V(X̄) = σ²/n`, 표준편차는 `σ/√n` [1][2][4].
- 그러니 표본을 키워서 얻는 것은 **정확도가 아니라 안정성**이다. 과녁의 중심은 처음부터 맞아 있었고 **흔들림만 줄어든다**.
- 줄어드는 속도는 n 이 아니라 **√n** 이다. 흔들림을 절반으로 줄이려면 표본을 **네 배**로 늘려야 한다 [4].
- 이 공식은 **복원추출**(또는 사실상 무한 모집단)을 전제로 한다 [1][2]. 유한 모집단에서 표본이 전체의 5% 를 넘으면 보정이 필요하다 [4].
- 헷갈리기 쉬운 두 가지 — **σ 와 σ/√n 은 다른 것**이고 [4], **σ²/n 의 n 과 표본분산 S² 의 n−1 은 아무 관계가 없다** [2].

## 핵심 포인트
1. **X̄ 가 확률변수라는 것이 출발점이다.** 이것을 놓치면 "평균의 평균"이라는 말 자체가 이상하게 들린다 [2][6].
2. **평균이 그대로인 이유는 기댓값이 덧셈을 그냥 통과하기 때문**이다. 독립이든 아니든 상관없다 [2].
3. **분산이 줄어드는 이유는 독립 때문**이다. 독립이 아니면 이 공식은 깨진다 [5].
4. **σ/√n 은 「표본평균들이 모평균 둘레에 퍼진 정도」**이고 이것을 표준오차라 한다 [4][6].
5. **표본을 한 번만 뽑아도 이 분포는 존재한다.** 관측은 하나지만 분포는 이론적으로 구할 수 있다 [6].

## 1. 먼저 확인부터 — 같은 모집단인데 값이 달라진다

주사위 하나를 모집단으로 삼는다. 눈은 1부터 6이고 각각 확률이 같다. 이 모집단의 평균과 분산은 정의대로 계산하면 이렇다.

```
μ  = (1+2+3+4+5+6) / 6 = 7/2 = 3.5
σ² = ((1−3.5)² + (2−3.5)² + … + (6−3.5)²) / 6 = 35/12 ≈ 2.9167
σ  = √(35/12) ≈ 1.7078
```

이제 **두 번 던져 평균을 낸다**. 이것이 크기 2 인 표본의 표본평균이다.

| 던진 결과 | 표본평균 X̄ |
|---|---|
| 2, 5 | 3.5 |
| 1, 1 | 1.0 |
| 6, 4 | 5.0 |
| 3, 4 | 3.5 |

**같은 주사위인데 답이 매번 다르다.** 그래서 X̄ 는 고정된 수가 아니라 **확률변수**다 [2]. 확률변수이므로 평균과 분산을 물을 수 있고, 그 두 값이 이 노트의 주제다 [1].

## 2. 무엇의 평균이고 무엇의 분산인가

말이 헷갈리는 자리라 이름부터 갈라 둔다 [1][2].

| 이름 | 기호 | 무엇인가 |
|---|---|---|
| 모평균 | μ (또는 m) | 모집단 전체의 평균 — **고정된 값** |
| 모분산 | σ² | 모집단 전체의 분산 — **고정된 값** |
| 표본평균 | X̄ | 크기 n 인 표본의 평균 — **확률변수** |
| 표본평균의 평균 | E(X̄) | X̄ 를 무한히 반복해 뽑았을 때의 평균 |
| 표본평균의 분산 | V(X̄) | X̄ 가 흩어진 정도 |

표본평균의 정의는 산술평균 그대로다 [2].

```
X̄ = (X₁ + X₂ + … + Xₙ) / n
```

여기서 X₁, …, Xₙ 은 **각각이 확률변수**다. 복원추출로 뽑으면 이들은 서로 **독립**이고, 각각의 평균과 분산은 모집단의 것과 같다 — 즉 평균 μ, 분산 σ² 다 [2]. 이 한 문장이 다음 두 절의 재료 전부다.

## 3. 평균은 왜 그대로인가

기댓값에는 성질이 하나 있다 — **합의 기댓값은 기댓값의 합**이고, 상수배는 밖으로 빠진다. 이것만 쓰면 끝난다 [2].

```
E(X̄) = E( (X₁ + … + Xₙ) / n )
      = (1/n) · ( E(X₁) + … + E(Xₙ) )
      = (1/n) · ( μ + μ + … + μ )     ← μ 가 n 개
      = (1/n) · nμ
      = μ
```

**n 이 어디로도 남지 않는다.** 표본을 2개 뽑든 1,000개 뽑든 표본평균의 평균은 μ 다 [1][2].

이것을 통계 용어로 **표본평균은 모평균의 비편향추정량**이라고 한다 [2]. 「치우치지 않았다」는 뜻이고, 과녁 비유로는 **조준이 애초에 중심에 맞아 있다**는 말이다.

여기서 한 가지를 못 박아 두자. 이 유도에는 **독립이 쓰이지 않았다.** 기댓값의 덧셈 성질은 독립 여부와 무관하게 성립한다 [2]. 독립이 필요해지는 곳은 다음 절이다.

## 4. 분산은 왜 n 으로 나뉘는가

분산은 기댓값처럼 순순히 통과하지 않는다. 두 규칙이 필요하다.

**규칙 ①** — 상수배는 **제곱**이 되어 나온다. `V(aX) = a²V(X)`

**규칙 ②** — 합의 분산은, 확률변수들이 **쌍마다 독립이거나 무상관이면** 분산의 합이다 [5].

```
V(X₁ + … + Xₙ) = V(X₁) + … + V(Xₙ)      (독립 또는 무상관일 때)
```

두 번째가 이 노트의 핵심이다. 일반적으로는 공분산 항이 따라붙는다 [5].

```
V(ΣXᵢ) = ΣV(Xᵢ) + 2 · Σ(i<j) Cov(Xᵢ, Xⱼ)
```

**독립이면 공분산이 0 이므로 뒤 항이 통째로 사라진다** [5]. 이 항등식에는 이름이 있다 — 비에나메 항등식이고, 큰 수의 법칙의 어떤 변형들을 증명하는 데 쓰인다 [5].

이제 둘을 이어 붙인다.

```
V(X̄) = V( (X₁ + … + Xₙ) / n )
      = (1/n²) · V(X₁ + … + Xₙ)        ← 규칙 ①, 1/n 이 1/n² 로
      = (1/n²) · ( σ² + … + σ² )        ← 규칙 ②, 독립이므로
      = (1/n²) · nσ²
      = σ² / n
```

**1/n² 로 나갔다가 σ² 이 n 개 모여 1/n 이 남는다.** 표준편차는 제곱근을 씌워 `σ/√n` 이다 [1][4].

| | 평균 | 분산 | 표준편차 |
|---|---|---|---|
| 모집단 | μ | σ² | σ |
| 표본평균 X̄ | **μ**(그대로) | **σ²/n** | **σ/√n** |

## 5. 종이 위에서 검산 — 주사위 두 개

공식을 믿기 전에 세어 보자. 주사위 두 개를 던지는 36가지 경우를 **전부** 놓고 표본평균의 분산을 직접 계산하면 이렇게 나온다.

| n | 공식이 말하는 V(X̄) | 36(또는 216)가지를 다 세어 계산한 값 |
|---|---|---|
| 1 | 35/12 ≈ 2.9167 | 35/12 ≈ 2.9167 |
| 2 | (35/12)/2 = 35/24 ≈ 1.4583 | 35/24 ≈ 1.4583 |
| 3 | (35/12)/3 = 35/36 ≈ 0.9722 | 35/36 ≈ 0.9722 |

E(X̄) 는 세 경우 모두 정확히 3.5 다. **평균은 안 움직이고 분산만 줄어든다** — 표에서 눈으로 확인되는 그대로다.

교과서 예제도 같은 것을 말한다. 모평균 4, 표준편차 2 인 정규분포에서 크기 2 인 표본을 복원추출하면 **평균은 그대로 4** 이고 분산은 모분산을 표본 크기로 나눠 `4/2 = 2` 다 [1].

## 6. √n 의 벽 — 흔들림을 절반으로 줄이려면 표본을 네 배로

`σ/√n` 에서 분모가 n 이 아니라 **√n** 이라는 점이 실전에서 가장 큰 결과를 낳는다. 위 주사위 모집단(σ ≈ 1.7078)으로 표를 만들어 보자.

| 표본 크기 n | 표준오차 σ/√n | n=1 대비 |
|---|---|---|
| 1 | 1.7078 | 1배 |
| 4 | 0.8539 | **1/2** |
| 16 | 0.4270 | **1/4** |
| 25 | 0.3416 | 1/5 |
| 100 | 0.1708 | **1/10** |
| 400 | 0.0854 | 1/20 |

**표본을 4배 키워야 흔들림이 절반이 된다.** 16배를 키워야 1/4 이 된다. 조사 비용은 대체로 n 에 비례하는데 정밀도는 √n 으로만 좋아지니, 표본을 무작정 키우는 것이 수지가 맞지 않는 지점이 반드시 생긴다.

n 이 커질 때 무슨 일이 벌어지는지는 이렇게 정리된다 — **모집단 표준편차가 유한하면 표본평균의 표준오차는 표본 크기가 커질수록 0 으로 간다** [4]. 표본평균들이 모평균 둘레로 점점 몰린다는 뜻이고 [4][6], 표본 크기가 커질수록 표본평균은 모평균으로 수렴한다는 **큰 수의 법칙**이 이것이다 [2].

## 7. 왜 「복원추출」이라고 못 박는가

교과서 서술이 굳이 **복원추출**을 명시하는 데는 이유가 있다 [1][2]. §4 의 규칙 ②가 **독립**을 요구하기 때문이다.

한 번 뽑은 것을 도로 넣지 않으면(비복원추출), 두 번째 뽑기는 첫 번째 결과에 영향을 받는다. 독립이 깨지면 공분산 항이 0 이 아니게 되고 [5], `σ²/n` 이 그대로 성립하지 않는다.

실제로는 이렇게 처리한다. 위 공식은 **모집단이 무한하다는 가정** 위에 서 있고, 유한 모집단이라도 **표본이 전체에서 차지하는 비율(표집률)이 작으면** 차이가 작아서 그냥 쓴다 [4]. 표집률이 대략 **5% 이상**으로 커지면 **유한모집단 보정(FPC)** 을 곱해 줄여야 한다 [4].

```
FPC = √( (N − n) / (N − 1) )        N = 모집단 크기, n = 표본 크기
```

n = 100 으로 고정하고 모집단 크기만 바꿔 계산하면 이렇다.

| 모집단 N | 표집률 f | FPC | 표준오차가 |
|---|---|---|---|
| 10,000 | 1% | 0.9950 | 0.5% 줄어든다 |
| 1,000 | 10% | 0.9492 | 5.1% 줄어든다 |
| 500 | 20% | 0.8953 | 10.5% 줄어든다 |
| 200 | 50% | 0.7089 | 29.1% 줄어든다 |

**표집률이 1% 면 무시할 만하고, 절반을 뽑으면 무시할 수 없다.** 고등학교 문제는 앞쪽 상황을 전제하므로 보정이 나오지 않는다.

## 8. 자주 하는 오해 넷

**오해 ① — "표본을 키우면 표본의 분산도 줄어든다."**
아니다. 줄어드는 것은 **표본평균의 분산**이지 표본 자체의 흩어짐이 아니다. 오히려 반대다 — n 이 커지면 **표본의 표준편차는 모표준편차 σ 에 가까워지고**, 표본평균의 표준오차는 0 으로 간다 [4]. 두 값이 서로 **반대 방향으로** 간다.

**오해 ② — "σ 와 σ/√n 은 비슷한 것."**
다르다. 이 둘을 섞어 쓰는 혼동이 실제로 흔하다고 자료가 적는다 [4].

| | 표본의 표준편차 | 표준오차 σ/√n |
|---|---|---|
| 무엇을 재나 | 표본 **안의 개체들**이 표본평균에서 벗어난 정도 [4] | **표본평균**이 모평균에서 벗어날 만한 정도 [4] |
| 성격 | 기술통계 — 측정값의 변동을 서술 [4] | 표본추출이라는 **과정**을 서술 [4] |
| n 이 커지면 | σ 에 가까워진다 [4] | 0 으로 간다 [4] |

**오해 ③ — "σ²/n 의 n 은 표본분산의 n−1 과 관련이 있다."**
관련이 없다. 둘은 다른 질문의 답이다 [2].

| | 무엇을 구하나 | 답 |
|---|---|---|
| σ²/n | 표본평균이 얼마나 흔들리나 | `V(X̄) = σ²/n` [1][2] |
| n−1 | 모분산을 표본으로 어떻게 추정하나 | `S² = Σ(Xᵢ − X̄)² / (n−1)` [2] |

n 으로 나눈 **비수정 표본분산**의 기댓값은 `((n−1)/n)σ²` 이라서 σ² 보다 조금 작다. 그래서 n/(n−1) 을 곱해 바로잡은 것이 **수정 표본분산** S² 이고, 이것이 모분산의 비편향추정량이다 [2]. **σ²/n 은 이 이야기와 무관하게 나온 식**이다.

**오해 ④ — "표본을 한 번만 뽑는데 분산이라니?"**
이건 오해라기보다 좋은 질문이고, §9 가 답한다.

## 9. 표본을 한 번만 뽑는데 왜 「분포」를 말하나

현실에서는 여론조사를 한 번 하고, 표본도 한 번 뽑는다. 그런데 우리는 "표본평균의 분산"을 말한다. 무엇의 분산인가.

답은 이렇다. 표본평균의 분포는 **같은 모집단에서 뽑을 수 있는 크기 n 인 모든 표본**에 대해 그 통계량이 갖는 분포다 [6]. 실제로 뽑은 것은 그중 하나일 뿐이다.

> **대개 표본은 하나만 관측되지만, 그 표본분포는 이론적으로 구할 수 있다** [6].

이것이 통계적 추론을 가능하게 하는 지점이다. 표본분포 덕분에 **개별 표본값 전부의 결합분포**를 다루는 대신 **통계량 하나의 확률분포**만 보면 된다 [6].

정리하면 이렇다.

| | 실제로 하는 일 | 이론이 말하는 것 |
|---|---|---|
| 표본 | 한 번 뽑는다 | 뽑을 수 있는 모든 표본을 생각한다 [6] |
| X̄ | 값 하나를 얻는다 | 그 값들의 분포를 안다 [6] |
| 쓸모 | — | 그 하나가 μ 에서 얼마나 벗어날 만한지 잰다 [4] |

## 10. 어디로 이어지나

여기까지가 **X̄ 의 평균과 분산**이다. 그다음은 **X̄ 의 분포 모양**이다 [1].

- 모집단이 정규분포 N(m, σ²) 을 따르면, 표본평균도 정규분포 **N(m, σ²/n)** 을 따른다 [1].
- 모집단이 정규분포가 아니어도 **n 이 충분히 크면**(이 자료는 n ≥ 50 을 기준으로 든다) 표본평균은 근사적으로 같은 정규분포를 따른다 [1].

모양까지 알면 확률을 계산할 수 있고, 그러면 "모평균이 어느 구간에 있을 것 같다"고 말할 수 있게 된다. 표본추출분포가 **점추정·구간추정·가설검정의 핵심 요소**라고 하는 이유가 이것이다 [3]. 다음 단원인 **모평균의 추정**이 바로 그 자리다 [1].

## 11. 수업에서 쓸 만한 대목

- **주사위 두 개로 직접 세게 한다 (고2~고3).** 36가지를 조별로 나눠 세면 `35/24` 가 실제로 나온다. 공식을 외우기 전에 값이 맞는 것을 보는 편이 오래 간다.
- **"평균은 왜 안 변하나"를 먼저 묻는다.** §3 의 유도는 세 줄이고 독립이 필요 없다. **독립이 필요한 곳은 분산**이라는 대비가 여기서 선명해진다.
- **√n 표를 그대로 보여 준다 (§6).** "표본을 두 배로 늘리면 오차가 절반이 되나요?"에 표 한 장으로 답한다 — 네 배다.
- **σ 와 σ/√n 을 한 문장씩으로 갈라 적게 한다 (§8-②).** 시험에서 가장 자주 섞이는 자리이고, 혼동이 흔하다는 것이 자료에도 적혀 있다 [4].
- **n−1 은 다른 이야기라고 못 박는다 (§8-③).** 두 식이 같은 단원에 나오기 때문에 학생들이 자동으로 연결한다.

## 검증 메모

- **직접 계산한 값**: §1 의 μ = 3.5 · σ² = 35/12, §5 의 표(n = 1·2·3 의 V(X̄)), §6 의 σ/√n 표, §7 의 FPC 표는 **이 노트에서 파이썬으로 계산해 확인한 값**이다. 출처가 그 숫자를 적어 준 것이 아니라, 출처가 준 **공식에 값을 넣어 얻은 결과**다. §5 의 "다 세어 계산한 값" 열은 실제로 36가지(n=2)·216가지(n=3) 경우를 전부 열거해 분산을 구한 것이고, 공식이 주는 값과 소수점 아래까지 일치했다.
- **§10 의 n ≥ 50**: 이것은 **출처 1 이 든 기준**이다. 다른 자료는 30 을 쓰기도 하지만, 이 노트는 인용한 자료가 말한 값만 적는다.
- **출처 2 의 표기**: 원문 본문에 비수정 표본분산의 기댓값이 `E(σₙ) = ((n−1)/n)σ²` 로 제곱 없이 적힌 자리가 있다. 같은 문서의 요약은 `σₙ²` 로 적고 문맥상으로도 분산의 기댓값이므로, 이 노트는 **E(σₙ²)** 로 옮겼다.
- **출처 3 의 범위**: 이 항목은 본문 전체를 받아 오지 못했고 검색 결과 스니펫과 페이지 요약에서 같은 두 문장을 확인했다. 그래서 **그 두 문장 밖의 내용은 인용하지 않았다.** 노트의 논지는 출처 1·2·4·6 만으로도 선다.
